# Nightly Ansible Survival Tip Rotator\n\n## Overview\n\nThis utility is an Ansible playbook that selects a random (or user‑specified) survival tip from a predefined list and writes it to `/tmp/survival_tip.txt` on the target hosts.  It can be used to display a daily reminder for post‑apocalypse preparedness, team morale, or just a bit of whimsical fun.\n\n## Files\n\n- `src/tip_rotator.yml` – The main playbook.\n- `src/tips.yml` – YAML list of survival tips.\n- `src/inventory.ini` – Simple local inventory for testing.\n- `tests/test_tip_rotator.yml` – An Ansible test playbook that runs the rotator and asserts the output.\n\n## Usage\n\n```bash\nansible-playbook -i src/inventory.ini src/tip_rotator.yml\n```\n\n### Selecting a specific tip\n\nBy default the playbook picks a random tip.  You can force a particular tip (zero‑based index) by passing the `tip_index` extra variable:\n\n```bash\nansible-playbook -i src/inventory.ini src/tip_rotator.yml -e "tip_index=2"\n```\n\nThe selected tip will be written to `/tmp/survival_tip.txt` on each host in the inventory.\n\n## Testing\n\nRun the bundled test playbook with Ansible (no external dependencies required):\n\n```bash\nansible-playbook -i src/inventory.ini tests/test_tip_rotator.yml\n```\n\nThe test forces `tip_index=0` and verifies that the first tip from `tips.yml` is written to the file.\n
