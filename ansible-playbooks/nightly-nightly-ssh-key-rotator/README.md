# Nightly SSH Key Rotator\n\nUtility that rotates SSH host keys across your inventory, backing up old keys and restarting the SSH service. Perfect for post‑apocalypse security drills.\n\n## Features\n- Backs up existing host keys with timestamped filenames.\n- Generates a new mock host key (replace the mock step with `ssh-keygen` for production).\n- Restarts `sshd` (ignores errors on systems without `sshd`).\n\n## Usage\n```sh\nansible-playbook -i inventory.ini src/rotate_ssh_keys.yml\n```\n\nYou can override the default variables if needed:\n```yaml\nssh_key_path: /etc/ssh/ssh_host_rsa_key\nbackup_dir: /etc/ssh/backup_keys\n```\n\n## Variables\n- `ssh_key_path` (string): Path to the SSH host private key to rotate.\n- `backup_dir` (string): Directory where old keys will be stored with a timestamped filename.\n\n## Disclaimer\nThe playbook uses a placeholder key (`MOCK_SSH_HOST_KEY`). For real deployments replace the *Generate new SSH host key* task with an appropriate `ssh-keygen` command.
