# nightly-ssh-key-rotator

## Overview

`nightly-ssh-key-rotator` is a whimsical yet practical Ansible playbook that simulates rotating SSH keys on a set of hosts. Instead of touching real keys (which could be risky in a demo environment), the playbook creates a timestamped marker file under `/tmp/ssh_key_rotator/rotated_at.txt`. The presence of this file indicates that a rotation *would* have occurred.

## How to Run

```bash
# From the repository root
ansible-playbook -i ansible-playbooks/nightly-ssh-key-rotator/inventory.ini ansible-playbooks/nightly-ssh-key-rotator/src/rotate_ssh_keys.yml
```

The playbook will:
1. Ensure a temporary directory `/tmp/ssh_key_rotator` exists on each target host.
2. Write a file `rotated_at.txt` containing the ISO‑8601 timestamp of the run.

## Testing

A self‑contained test suite lives in `tests/test_rotate_ssh_keys.yml`. It runs the playbook against `localhost`, verifies that the marker file was created and contains data, then cleans up.

```bash
ansible-playbook -i ansible-playbooks/nightly-ssh-key-rotator/inventory.ini ansible-playbooks/nightly-ssh-key-rotator/tests/test_rotate_ssh_keys.yml
```

The test is deterministic and does **not** require any external services.

## Why This Is Useful

* **Safety** – No real SSH keys are touched, making it safe for CI runners.
* **Visibility** – The timestamp file provides a clear audit trail for when a rotation was simulated.
* **Extensibility** – Replace the `copy` task with a real key‑generation module (e.g., `community.crypto.openssh_keypair`) when you need production‑grade rotation.
