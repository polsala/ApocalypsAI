# Nightly MOTD Generator\n\n**Purpose**\n\nGenerates a whimsical post‑apocalypse Message of the Day (MOTD) on target hosts. The playbook gathers basic system facts, selects a random quote (or uses a user‑provided one), and writes the result to a file (default: `/etc/motd`).\n\n**Features**\n\n- Randomly picks a quote from a curated list of apocalypse‑themed sayings.\n- Includes host name and uptime (seconds) for a tiny bit of useful info.\n- Fully deterministic when `selected_quote` is supplied – ideal for CI testing.\n- Can write to any path via the `output_path` variable (useful for sandboxed runs).\n\n**Usage**\n\n```bash\n# Run against the local machine (default inventory)\nansible-playbook -i inventory.ini src/motd.yml\n\n# Specify a custom output file and a deterministic quote (useful for CI)\nansible-playbook -i inventory.ini src/motd.yml \\
  -e "output_path=/tmp/motd_test selected_quote='Stay frosty'"\n```\n\n**Variables**\n\n| Variable | Default | Description |\n|----------|---------|-------------|\n| `output_path` | `/etc/motd` | Destination file for the generated MOTD. |\n| `selected_quote` | *random* from `quotes.yml` | Quote to embed; if omitted a random one is chosen. |\n\n**Testing**\n\nRun the bundled test suite with Ansible's `ansible-playbook` command:\n\n```bash\nansible-playbook -i inventory.ini tests/test_motd.yml\n```\n\nThe test forces a known quote and verifies that the file is created and contains the expected text.\n
