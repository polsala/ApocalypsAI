# Nightly Survival Environment Setup\n\n## Overview\n\n`nightly-survival-env-setup` is an Ansible playbook that prepares a host for post‑apocalyptic (or just everyday) survival scenarios. It:\n\n- Installs a small set of essential packages (curl, git, htop) on Debian‑based systems.\n- Creates a `/opt/survival` directory with a ready‑made checklist file.\n- Sets up a daily cron job placeholder for log rotation.\n\nThe playbook is safe to run on any machine – package installation can be disabled via the `install_packages` variable (useful for CI testing).\n\n## Files\n\n- `src/setup_survival.yml` – The main playbook.\n- `src/inventory.ini` – Simple inventory targeting the local host.\n- `tests/test_setup_survival.yml` – An Ansible test that runs the playbook, verifies the directory and checklist, then cleans up.\n\n## Usage\n\n```bash\n# Install Ansible if you don't have it\npython3 -m pip install ansible\n\n# Run the playbook\nansible-playbook -i src/inventory.ini src/setup_survival.yml\n```\n\n### Skipping package installation (e.g., in CI)\n\n```bash\nansible-playbook -i src/inventory.ini src/setup_survival.yml -e install_packages=false\n```\n\n## Testing\n\n```bash\nansible-playbook -i src/inventory.ini tests/test_setup_survival.yml\n```\n\nThe test will:\n\n1. Execute the playbook with `install_packages` disabled.\n2. Assert that `/opt/survival` exists and contains the checklist.\n3. Remove the created directory afterwards.\n\n## License\n\nMIT – see the repository LICENSE file.\n
