# Nightly Ansible Apt Cleanup\n\n## Overview\n\n`nightly-ansible-apt-cleanup` is a whimsical yet practical Ansible playbook that helps you **scavenge** your Debian/Ubuntu system for leftover packages after the apocalypse. It can:\n\n- Gather a list of installed APT packages\n- Count how many packages are present\n- (Optionally) Run `apt-get autoremove` and `apt-get clean` to free space\n- Produce a concise report stored in the variable `apt_cleanup_report`\n\nThe playbook is safe to run in *mock mode* – no real package operations are performed – which makes it perfect for automated testing or dry‑run scenarios.\n\n## Files\n\n- `src/apt_cleanup.yml` – The main playbook\n- `src/inventory.ini` – Minimal inventory targeting `localhost`\n- `tests/test_apt_cleanup.yml` – An offline deterministic test using mock data\n\n## Usage\n\n```bash\n# Real run (will modify the system)\nansible-playbook -i src/inventory.ini src/apt_cleanup.yml\n\n# Dry‑run / test mode (no changes)\nansible-playbook -i src/inventory.ini src/apt_cleanup.yml \\\\n  -e "mock_mode=true mock_packages='alpha beta gamma'"\n```\n\nThe `mock_mode` flag tells the playbook to skip any real `apt` commands and instead use the supplied `mock_packages` string as the list of installed packages. This is used by the automated test suite.\n\n## License\n\nThis utility is released under the same MIT license as the rest of the ApocalypsAI repository.\n
