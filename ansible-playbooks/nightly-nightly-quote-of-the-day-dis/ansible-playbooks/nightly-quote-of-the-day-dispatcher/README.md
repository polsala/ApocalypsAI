Quote of the Day Dispatcher\n\nThis utility provides an Ansible playbook that writes a predefined quote to /tmp/quote_of_the_day.txt on the target hosts. It is deterministic and includes a test playbook to verify the file creation and content.\n\nUsage:\n1. Ensure Ansible is installed.\n2. Run the playbook with: ansible-playbook -i src/inventory.ini src/quote_dispatch.yml\n\nThe playbook is safe to run on any host; it only creates or overwrites the quote file in /tmp.\n
