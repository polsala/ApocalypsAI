# Nightly Ansible SSH Key Rotator\n\n## Overview\n\nThis Ansible playbook rotates the SSH host keys on all hosts in the inventory. It backs up existing keys, generates fresh RSA, ECDSA, and ED25519 host keys, and restarts the SSH service. Perfect for a whimsical yet useful post‑apocalypse security refresh.\n\n## Files\n\n- `src/rotate_ssh_keys.yml` – The main playbook.\n- `inventory.ini` – Sample inventory (defaults to localhost).\n- `tests/test_rotate_ssh_keys.yml` – Automated test that runs the playbook in check mode and asserts success.\n\n## Usage\n\n```bash\n# Install Ansible if not already installed\npython3 -m pip install ansible\n\n# Run the playbook against your inventory\nansible-playbook -i inventory.ini src/rotate_ssh_keys.yml\n```\n\nRun the test suite with:\n\n```bash\nansible-playbook -i inventory.ini tests/test_rotate_ssh_keys.yml\n```\n\n## Safety\n\nThe playbook backs up existing host keys (`*.bak`) before overwriting them. Review the backup files if you need to restore the previous keys.\n
