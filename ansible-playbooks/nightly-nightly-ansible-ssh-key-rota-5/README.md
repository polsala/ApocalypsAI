# Nightly Ansible SSH Key Rotator\n\n## Overview\n\nThis utility provides an Ansible playbook that generates fresh SSH host keys on every target machine and automatically updates the control node's `known_hosts` file with the new public keys.  It is perfect for post‑apocalypse scenarios where you want to regularly refresh trust anchors without manual fiddling.\n\n## Requirements\n\n- Ansible 2.9+ installed on the control node\n- Password‑less sudo (or appropriate privilege escalation) on target hosts\n- SSH access to the target hosts\n\n## Directory Layout\n\n```.\n├── README.md\n├── src\n│   ├── rotate_ssh_keys.yml   # The main playbook\n│   └── inventory.ini         # Sample inventory (edit for your environment)\n└── tests\n    └── test_rotate_ssh_keys.yml  # Simple offline test (uses mocks)\n```\n\n## Usage\n\n1. **Edit the inventory** (`src/inventory.ini`) to list the hosts you want to rotate keys for.\n2. Run the playbook in check mode first to preview changes:\n\n```bash\nansible-playbook -i src/inventory.ini src/rotate_ssh_keys.yml --check\n```\n\n3. If everything looks good, run the actual rotation:\n\n```bash\nansible-playbook -i src/inventory.ini src/rotate_ssh_keys.yml\n```\n\nThe playbook will:\n\n- Ensure SSH host keys exist (generates them if missing)\n- Regenerate all host keys (`ssh-keygen -A`)\n- Pull the new public RSA host key from each target\n- Add/replace the entry in the control node's `~/.ssh/known_hosts` file\n\n## Safety Notes\n\n- The playbook uses `become: true` to run privileged commands on the target.\n- Rotating host keys will cause existing SSH sessions to drop; schedule during maintenance windows.\n- The `known_hosts` update runs on the control node only, so you must execute the playbook from a machine that maintains the SSH trust store.\n\n## Testing\n\nA deterministic, offline test suite lives in `tests/`. It runs the playbook in check mode with a mocked localhost inventory and asserts successful execution. Run it with:\n\n```bash\nansible-playbook -i tests/inventory_mock.ini tests/test_rotate_ssh_keys.yml\n```\n\n## License\n\nMIT – see the root LICENSE file.\n
