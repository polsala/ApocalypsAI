# Nightly Ansible SSH Key Rotator\n\n## Overview\nThis utility provides an Ansible playbook that safely rotates SSH key pairs on a set of remote hosts. It generates a fresh key pair locally, distributes the new public key to each host, updates the authorized_keys file, and optionally removes the old key. Running the playbook in ``--check`` mode allows you to preview changes without affecting production systems.\n\n## Files\n- ``src/rotate_ssh_keys.yml`` – The main playbook.\n- ``src/inventory.ini`` – Sample inventory (replace with your own).\n- ``tests/test_rotate_ssh_keys.yml`` – Ansible test that runs the playbook in check mode.\n\n## Prerequisites\n- Ansible 2.9+ installed on the control machine.\n- SSH access to target hosts with a user that has permission to edit ``~/.ssh/authorized_keys``.\n- ``ssh-keygen`` available (standard on most *nix systems).\n\n## Usage\n```bash\n# Clone the repository and cd into the utility directory\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd ansible-playbooks/nightly-ansible-ssh-key-rotator\n\n# Review the inventory and adjust hosts as needed\ncat src/inventory.ini\n\n# Run the playbook in check mode (dry run)\nansible-playbook -i src/inventory.ini src/rotate_ssh_keys.yml --check\n\n# When satisfied, run the actual rotation\nansible-playbook -i src/inventory.ini src/rotate_ssh_keys.yml\n```\n\n## Variables\nThe playbook uses the following variables (can be overridden via ``-e``):\n- ``new_key_path`` (default: ``./generated_ssh_key``) – Path where the new key pair will be stored locally.\n- ``old_key_fingerprint`` (optional) – Fingerprint of the old key to be removed from ``authorized_keys``. If omitted, the playbook will only add the new key.\n\n## Safety Notes\n- The playbook backs up the existing ``authorized_keys`` file on each host as ``authorized_keys.bak`` before making changes.\n- Always run in ``--check`` mode first to verify the target hosts are reachable and the user has sufficient privileges.\n\n## Testing\nThe included test playbook runs the rotation in check mode against a mock inventory. It uses ``assert`` statements to ensure the playbook exits with a ``SUCCESS`` status. Run it with:\n```bash\nansible-playbook -i src/inventory.ini tests/test_rotate_ssh_keys.yml\n```\n
