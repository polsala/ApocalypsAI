# Nightly Ansible SSH Key Rotator\n\n## Overview\n\nThis playbook generates a fresh SSH key pair on each target host, backs up the existing `authorized_keys`, replaces it with the new public key, and stores the old keys in a backup directory.  It is useful for rotating credentials in a chaotic or post‑apocalyptic environment where security hygiene is still important.\n\n## Requirements\n\n- Ansible 2.9+\n- `ssh-keygen` available on target hosts\n\n## Usage\n\n```bash\nansible-playbook -i src/inventory.ini src/rotate_ssh_keys.yml\n```\n\nThe playbook runs with privilege escalation (`become: true`).  It creates a temporary marker file `/tmp/ssh_key_rotated` which the test suite uses to verify successful execution.\n\n## Files\n\n- `src/rotate_ssh_keys.yml` – The main playbook\n- `src/inventory.ini` – Simple inventory targeting localhost (or any hosts you add)\n- `tests/test_rotate_ssh_keys.yml` – Automated test that runs the playbook and checks the marker file
