# Nightly Ansible SSH Key Rotator\n\n## Overview\n\nThis utility provides an Ansible playbook that rotates SSH host keys for every host in your inventory. It backs up any existing keys, generates fresh RSA keys, and stores them in a configurable directory. Perfect for post‑apocalypse security hygiene or regular key rotation policies.\n\n## Features\n\n- **Backup** existing SSH keys before replacement.\n- **Generate** new 2048‑bit RSA keys using `ssh-keygen`.\n- **Configurable** key storage location (default: `/tmp/ssh_keys`).\n- **Idempotent** – running the playbook again will replace keys with new ones while preserving previous versions in a timestamped backup folder.\n\n## Requirements\n\n- Ansible 2.9+ installed on the control machine.\n- `ssh-keygen` available on target hosts (standard on most Unix‑like systems).\n\n## Usage\n\n1. Clone the repository and navigate to the utility directory.\n2. Review or edit `src/inventory.ini` to list the hosts you want to rotate keys for.\n3. Run the playbook:\n\n```bash\nansible-playbook -i src/inventory.ini src/rotate_ssh_keys.yml -e "key_dir=/desired/key/path"\n```\n\nIf you omit the `key_dir` extra variable, keys will be placed under `/tmp/ssh_keys`.\n\n## Testing\n\nA deterministic offline test suite is provided. It runs the playbook against `localhost` using a temporary directory and asserts that a new key file is created. Execute the test with:\n\n```bash\nansible-playbook -i src/inventory.ini tests/test_rotate_ssh_keys.yml\n```\n\nThe test cleans any previous artifacts, runs the rotator, and verifies the presence of the private key file.\n\n## License\n\nThis utility is released under the MIT License.\n
