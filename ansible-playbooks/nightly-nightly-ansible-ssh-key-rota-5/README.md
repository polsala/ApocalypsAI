# Nightly Ansible SSH Key Rotator\n\n## Overview\n\nThis utility provides an Ansible playbook that safely rotates SSH key pairs for a given user on one or more target hosts. It creates a new key pair, updates the user's `authorized_keys`, and cleans up any old keys.\n\n## Features\n\n- Idempotent: runs safely multiple times.\n- Works with any user account (default: `{{ target_user }}`).\n- Uses Ansible's built‑in modules (`file`, `command`, `slurp`, `authorized_key`).\n- Designed for local or remote hosts via standard inventory.\n\n## Requirements\n\n- Ansible 2.9+ installed on the control machine.\n- Sufficient privileges to write to the target user's `.ssh` directory (use `become`).\n\n## Usage\n\n```bash\n# Create an inventory (example provided in `src/inventory.ini`)\nansible-playbook -i src/inventory.ini src/rotate_ssh_keys.yml -e "target_user=deploy"\n```\n\nYou can also run in check mode to preview changes:\n\n```bash\nansible-playbook -i src/inventory.ini src/rotate_ssh_keys.yml -e "target_user=deploy" --check\n```\n\n## Variables\n\n- `target_user` (required): The username whose SSH keys will be rotated.\n\n## How It Works\n\n1. Ensures the user's `.ssh` directory exists with proper permissions.\n2. Generates a new RSA key pair (if not already present).\n3. Reads the public key and installs it via the `authorized_key` module.\n4. Optionally removes any old key files (placeholder task).\n\n## Testing\n\nAutomated tests are provided under `tests/`. They verify that the playbook runs successfully in Ansible's `--check` mode without making real changes.\n\n## License\n\nMIT License – see the repository LICENSE file.
