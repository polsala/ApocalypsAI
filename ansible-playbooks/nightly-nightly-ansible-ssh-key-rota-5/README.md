# Nightly Ansible SSH Key Rotator\n\n## Overview\n\n`nightly-ansible-ssh-key-rotator` is a tiny, self‑contained Ansible playbook that generates fresh SSH host keys (RSA 4096 and Ed25519) on the target host, places them in a configurable directory, and restarts the SSH daemon.  It is useful for periodic key rotation in a fleet of servers without manual intervention.\n\n## Features\n\n- Generates RSA 4096 and Ed25519 host keys if they are missing.\n- Idempotent – will not overwrite existing keys unless you delete them first.\n- Configurable key directory (defaults to `/etc/ssh`).\n- Optional service restart – you can skip the restart on systems where the service name differs or during dry‑run testing.\n\n## Variables\n\n| Variable | Description | Default |\n|----------|-------------|---------|\n| `key_dir` | Directory where the host keys will be stored. | `/etc/ssh` |\n| `ssh_service_name` | Name of the SSH service to restart. Set to an empty string to skip the restart. | `sshd` |\n\n## Usage\n\n```bash\n# Run against a single host\nansible-playbook -i inventory.ini rotate_ssh_keys.yml -e "key_dir=/etc/ssh ssh_service_name=sshd"\n\n# Run against a group of hosts, skipping service restart (useful for CI tests)\nansible-playbook -i inventory.ini rotate_ssh_keys.yml -e "ssh_service_name=''"\n```\n\n## Testing\n\nA deterministic test suite lives in `tests/test_rotate_ssh_keys.yml`. It creates a temporary directory, runs the playbook against `localhost`, and asserts that the expected key files are present.\n\n```bash\nansible-playbook -i localhost, tests/test_rotate_ssh_keys.yml\n```\n\n## License\n\nMIT – feel free to adapt and improve!\n
