# Nightly Ansible SSH Key Rotator\n\n## Overview\n\nThis utility provides an Ansible playbook that generates a new RSA SSH key pair on the control node and distributes the public key to all target hosts. It is designed to be whimsical – think of it as the post‑apocalyptic ritual of swapping out old keys for fresh ones to keep the wasteland secure.\n\n## Features\n\n- Generates a 2048‑bit RSA key pair only if it does not already exist.\n- Distributes the new public key to the `authorized_keys` of the remote user (default: `root`).\n- Idempotent – running the playbook multiple times will not recreate keys or duplicate entries.\n\n## Directory Layout\n\n```.\n├── README.md                # This file\n├── src/\n│   ├── playbook.yml        # The Ansible playbook\n│   └── inventory.ini       # Simple inventory targeting localhost (or your hosts)\n└── tests/\n    └── test_playbook.yml   # Syntax‑check test for CI\n```\n\n## Prerequisites\n\n- Ansible 2.9+ installed on the control machine.\n- SSH access to the target hosts (the playbook uses `become: true`).\n\n## Usage\n\n1. **Clone the utility** (or copy the files into your repo).\n2. Edit `src/inventory.ini` to list the hosts you want to rotate keys on.\n3. Run the playbook:\n\n```bash\nansible-playbook -i src/inventory.ini src/playbook.yml\n```\n\nThe playbook will create a key pair at `/tmp/rotated_id_rsa` (if not present) and add the public key to each host's `authorized_keys`.\n\n## Testing\n\nA simple syntax‑check test is provided under `tests/test_playbook.yml`. It can be executed with:\n\n```bash\nansible-playbook -i src/inventory.ini tests/test_playbook.yml\n```\n\nThe test will fail if the main playbook contains syntax errors.\n\n## Cleanup\n\nIf you need to remove the generated key pair from the control node, delete `/tmp/rotated_id_rsa` and `/tmp/rotated_id_rsa.pub`. The public key can be removed from remote hosts by editing their `authorized_keys` manually or by extending the playbook with an `authorized_key` task using `state: absent`.\n
