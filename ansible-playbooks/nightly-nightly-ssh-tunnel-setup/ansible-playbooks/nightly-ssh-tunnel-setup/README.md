# Nightly SSH Tunnel Setup\n\n## Overview\n\nThis utility provides an Ansible playbook that sets up a **persistent reverse SSH tunnel** using `autossh` and a `systemd` service. It is useful when you need to expose a local service (web server, database, etc.) to a remote host without opening inbound ports on the local firewall.\n\n## Features\n\n- Installs `autossh` on the target host (Debian/Ubuntu).\n- Generates a `systemd` unit file from a Jinja2 template.\n- Enables and starts the service so the tunnel survives reboots.\n- Fully configurable via Ansible variables (remote user, host, ports, SSH key).\n\n## Requirements\n\n- Ansible 2.9+\n- Target hosts running a Debian‑based distribution (uses `apt`).\n- SSH key that can authenticate to the remote host without a password.\n\n## Variables\n\n| Variable | Description | Default |\n|----------|-------------|---------|\n| `remote_user` | User on the remote host that will receive the tunnel. | `{{ ansible_user }}` |\n| `remote_host` | Hostname or IP of the remote machine. | *required* |\n| `remote_port` | Remote port that will forward to the local service. | `2222` |\n| `local_port` | Local port of the service you want to expose. | `80` |\n| `ssh_key_path` | Path to the private SSH key used for authentication. | `~/.ssh/id_rsa` |\n| `ssh_tunnel_service_path` | Destination path for the generated systemd unit file. | `/etc/systemd/system/ssh-tunnel.service` |\n| `skip_package_install` | When `true`, the role will skip installing `autossh` (useful for offline tests). | `false` |\n\n## Usage\n\n```bash\n# Create an inventory file (e.g., inventory.ini)\ncat > inventory.ini <<'EOF'\n[targets]\nmyserver ansible_host=192.0.2.10 ansible_user=ubuntu\nEOF\n\n# Run the playbook\nansible-playbook -i inventory.ini ansible-playbooks/nightly-ssh-tunnel-setup/src/tunnel.yml \\\\n  -e "remote_user=ubuntu remote_host=example.com remote_port=2222 local_port=8080 ssh_key_path=~/.ssh/id_rsa"\n```\n\nThe playbook will install `autossh`, place a systemd unit at the location defined by `ssh_tunnel_service_path`, reload the daemon, and enable/start the service.\n\n## Testing\n\nA deterministic, offline test suite is provided under `tests/`. It runs the role against `localhost` with a temporary service file path and skips package installation.\n\n```bash\nansible-playbook -i tests/inventory.ini tests/test_tunnel.yml\n```\n\n## License\n\nMIT – see the repository LICENSE file.
