# Bunker Alarm Systemd Service\n\nDeploys a whimsical "Bunker Alarm" systemd service that logs random apocalypse warnings every minute. Useful for learning systemd unit and timer deployment via Ansible.\n\n## Usage\n\n```bash\nansible-playbook src/deploy_bunker_alarm.yml -i localhost,\n```\n\nThe playbook copies the script, unit, and timer to the target, enables and starts the timer.\n\n## Files\n\n- `bunker_alarm.sh` – script that picks a random warning and appends to `/var/log/bunker_alarm.log`.\n- `bunker_alarm.service` – systemd service that runs the script.\n- `bunker_alarm.timer` – triggers the service every minute.\n\n## Testing\n\nRun the provided test playbook:\n\n```bash\nansible-playbook tests/test_deploy_bunker_alarm.yml -i localhost,\n```\n
