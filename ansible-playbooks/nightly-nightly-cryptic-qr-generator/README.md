# nightly-cryptic-qr-generator\n\n## Overview\n\n`nightly-cryptic-qr-generator` is a tiny Ansible playbook that generates a QR‑code‑style text file containing a cryptic phrase.  By default the phrase is a random base64 string, but you can override it with a variable – perfect for daily mystery notes, Easter eggs, or just a bit of post‑apocalyptic fun.\n\n## Files\n\n- `src/main.yml` – The playbook implementation.\n- `inventory.ini` – Simple localhost inventory.\n- `tests/test_cryptic_qr.yml` – Automated test that runs the playbook with a deterministic phrase and asserts the output file exists and is non‑empty.\n\n## Usage\n\n```bash\n# Run with a random phrase\nansible-playbook -i inventory.ini src/main.yml\n\n# Run with a custom phrase (useful for testing or deterministic runs)\nansible-playbook -i inventory.ini src/main.yml -e "phrase=YOUR_SECRET"\n```\n\nThe generated file will be written to `/tmp/qr.png` (the extension is kept for realism, but the content is plain text).\n\n## Testing\n\n```bash\nansible-playbook -i inventory.ini tests/test_cryptic_qr.yml\n```\n\nThe test sets `phrase` to `TESTPHRASE` and verifies that `/tmp/qr.png` exists and contains data.\n
