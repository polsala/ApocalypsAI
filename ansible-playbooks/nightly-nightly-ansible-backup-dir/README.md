# Nightly Ansible Backup Directory Utility\n\n## Overview\n\n`nightly-ansible-backup-dir` provides a simple, reusable Ansible playbook that backs up a specified directory on any target host. It creates a timestamped ``.tar.gz`` archive in a configurable destination directory and can optionally fetch the archive back to the control machine.\n\n## Files\n\n- ``src/backup.yml`` – The main playbook.\n- ``src/inventory.ini`` – Minimal inventory (defaults to ``localhost``).\n- ``tests/test_backup.yml`` – Automated test that validates the backup process on the local host.\n\n## Usage\n\n```bash\nansible-playbook -i src/inventory.ini src/backup.yml \\\\n  -e "backup_src=/path/to/dir backup_dest=/tmp/backups fetch_backup=true"\n```\n\n- ``backup_src`` – Absolute path of the directory to back up (default: ``/var/www``).\n- ``backup_dest`` – Destination directory for the archive on the target host (default: ``/tmp/backups``).\n- ``fetch_backup`` – Set to ``true`` to copy the archive to ``./backups/<host>/`` on the control machine (default: ``false``).\n\n## Testing\n\nRun the test playbook with:\n\n```bash\nansible-playbook -i src/inventory.ini tests/test_backup.yml\n```\n\nThe test creates a temporary source directory with a sample file, runs the backup playbook, and asserts that a ``.tar.gz`` archive appears in the destination directory.\n
