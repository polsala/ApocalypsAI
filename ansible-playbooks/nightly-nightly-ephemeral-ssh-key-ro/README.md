# Nightly Ephemeral SSH Key Rotator\n\n## Overview\n\n`nightly-ephemeral-ssh-key-rotator` is a tiny, whimsical‑yet‑practical Ansible playbook that creates a brand‑new SSH key pair on the control machine and pushes the public key to the specified inventory hosts.  It is perfect for:\n\n- Temporary access for CI runners or short‑lived collaborators\n- Rotating keys on a set of servers without manual copy‑paste\n- Demonstrating how to automate SSH key management with Ansible\n\nThe playbook runs in **check mode** by default when used with the provided test suite, so no real changes are made unless you remove the `--check` flag.\n\n## Files\n\n- `src/rotate_ssh_keys.yml` – The main playbook\n- `src/inventory.ini` – Sample inventory (defaults to `localhost`)\n- `tests/test_rotate_ssh_keys.yml` – Automated test that runs the playbook in dry‑run mode\n\n## Usage\n\n```bash\n# Clone the repository (or copy this folder)\ncd nightly-ephemeral-ssh-key-rotator\n\n# Install Ansible if you don't have it\npython3 -m pip install ansible\n\n# Run the playbook (dry‑run)\nansible-playbook -i src/inventory.ini src/rotate_ssh_keys.yml --check\n\n# Run for real (be sure you trust the target hosts)\nansible-playbook -i src/inventory.ini src/rotate_ssh_keys.yml\n```\n\n## Variables\n\n| Variable | Description | Default |\n|----------|-------------|---------|\n| `ssh_key_path` | Path where the new key pair will be stored on the control node. | `~/.ssh/ansible_rotated_key` |\n| `ssh_user` | Remote user that will receive the public key. | `{{ ansible_user | default('root') }}` |\n\nYou can override variables on the command line, e.g.:\n\n```bash\nansible-playbook -i src/inventory.ini src/rotate_ssh_keys.yml -e "ssh_key_path=/tmp/temp_key ssh_user=deploy"\n```\n\n## Testing\n\nThe repository includes a deterministic, offline test that executes the playbook in check mode against the `localhost` inventory.
