# Nightly Chaos Garden Orchestrator

A whimsical yet practical Ansible playbook that orchestrates chaos engineering experiments across a garden of servers, ensuring resilience while keeping the team entertained.

## Features
- Orchestrates chaos experiments across multiple servers
- Provides detailed reports with whimsical messaging
- Includes cleanup tasks to restore order
- Supports various chaos scenarios (network, resource, service, time)
- Easy to extend with new chaos scenarios

## Usage
1. Clone this repository
2. Configure your inventory file
3. Run the playbook: `ansible-playbook chaos_garden_orchestrator.yml`

## Requirements
- Ansible 2.9+
- Python 3.6+
