# nightly-ansible-apt-repo-mirror\n\n## Overview\n\n`nightly-ansible-apt-repo-mirror` is a whimsical yet practical Ansible playbook that sets up a local mirror of a Debian/Ubuntu apt repository using the `apt-mirror` tool.  It is perfect for post‑apocalypse scenarios where internet connectivity is scarce, but you still need to install packages on many machines.\n\n## Features\n\n- Installs `apt-mirror` if it is not already present.\n- Generates a minimal `mirror.list` pointing at a user‑provided repository URL.\n- Executes the mirroring process (or runs in `--check` mode for dry‑run).\n- Ensures the mirror directory exists and is world‑readable.\n\n## Requirements\n\n- Ansible 2.9+ installed on the control node.\n- Target host(s) must be Debian/Ubuntu based (the playbook uses the `apt` module).\n\n## Usage\n\n```bash\n# Clone the utility (if you are browsing the repo)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/nightly-ansible-apt-repo-mirror\n\n# Run the playbook against localhost (or any inventory)\nansible-playbook -i src/inventory.ini src/playbook.yml \\\\n    -e "mirror_url=http://archive.ubuntu.com/ubuntu"\n```\n\n### Variables\n\n| Variable   | Description                                 | Default                               |\n|------------|---------------------------------------------|---------------------------------------|\n| `mirror_url` | Base URL of the remote apt repository.      | `http://archive.ubuntu.com/ubuntu`    |\n\nYou can override the variable on the command line as shown above or by editing `src/playbook.yml`.\n\n## Testing\n\nA minimal test suite lives in the `tests/` directory.  Run it with:\n\n```bash\nansible-playbook -i src/inventory.ini tests/test_playbook.yml\n```\n\nThe test runs the playbook in `--check` mode and asserts that the required variables are defined.\n\n## License\n\nMIT – see the root `LICENSE` file.\n
