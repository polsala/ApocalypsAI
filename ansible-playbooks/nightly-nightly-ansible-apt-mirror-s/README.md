# nightly-ansible-apt-mirror-sync\n\nSynchronize an APT repository mirror from a source server to one or more target hosts. Useful for ensuring offline package caches in post‑apocalypse environments.\n\n## Usage\n\n```bash\nansible-playbook -i src/inventory.ini src/mirror_sync.yml -e \"source_url=http://archive.ubuntu.com/ubuntu/ target_dir=/var/mirror\"\n```\n\n## Variables\n\n- `source_url` (required): URL of the remote apt repository.\n- `target_dir` (required): Destination directory on the target hosts.\n\n## What it does\n\n1. Installs `rsync` if missing.\n2. Uses `rsync` to mirror the repository.\n3. Ensures correct permissions.\n\n## Testing\n\nRun `pytest tests/test_mirror_sync.py`.\n
