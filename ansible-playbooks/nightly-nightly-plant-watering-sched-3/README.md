# Nightly Plant Watering Scheduler\n\n## Overview\nThis Ansible playbook automates watering houseplants by toggling a smart plug at a scheduled time. It demonstrates using Ansible's `cron` module and a mock smart‑plug control via debug messages.\n\n## Prerequisites\n- Ansible 2.9+\n- An inventory with a host named `plant_controller` (see `inventory.ini`)\n\n## Usage\n```sh\nansible-playbook -i inventory.ini water_plants.yml --extra-vars "water_time='07:00'"\n```\n\nThe playbook creates a daily cron job at the specified time that turns on the plug for 5 minutes then turns it off.\n\n## Files\n- `water_plants.yml` – main playbook that sets up the cron job.\n- `toggle_plug.yml` – helper playbook that actually toggles the plug (simulated with debug messages).\n- `inventory.ini` – sample inventory.\n- `tests/` – pytest suite verifying playbook structure.\n
