# Nightly Ansible Plant Watering Scheduler\n\n## Overview\n\nThis utility is an Ansible playbook that helps you keep track of when your houseplants were last watered. It stores the last‑watered date in a hidden file and, if the configured interval has passed, it simulates watering the plants (you'll see a friendly water‑drop emoji in the output) and updates the date.\n\n## Features\n\n- Stores the last‑watered date in a local file (`.plant_watered_date`).\n- Configurable watering interval (default: every 3 days).\n- Runs entirely on the local machine – no remote hosts required.\n- Completely offline; no external services are contacted.\n\n## Usage\n\n```bash\n# Clone the repository (or copy the utility folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd ansible-playbooks/nightly-ansible-plant-watering-scheduler\n\n# Run the playbook\nansible-playbook -i src/inventory.ini src/water_plants.yml\n```\n\nThe first run will create the tracking file and simulate watering. Subsequent runs will only water if the interval has elapsed.\n\n## Customisation\n\nYou can adjust the watering interval by editing the `water_interval_days` variable in `src/water_plants.yml`.\n\n## Testing\n\nA simple Ansible test is provided under `tests/`. Run it with:\n\n```bash\nansible-playbook -i src/inventory.ini tests/test_water_plants.yml\n```\n\nThe test ensures the playbook executes without errors.\n
