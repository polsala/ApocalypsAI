Nightly Ansible Quote of the Day\n\nThis utility provides an Ansible playbook that copies a motivational quote to a target file on each host in the inventory. The quote is taken from a bundled list and the first entry is used for deterministic testing.\n\nDirectory layout\n-----------------\nsrc/quote_of_the_day.yml   – The main playbook\nsrc/quotes.txt            – Plain‑text file with one quote per line\nsrc/inventory.ini         – Simple inventory (defaults to localhost)\ntests/test_quote_of_the_day.yml – Automated test that runs the playbook and verifies the output file contains the expected quote.\n\nUsage\n-----\n1. Ensure Ansible is installed (ansible >=2.9).\n2. From the repository root run:\n   ansible-playbook -i src/inventory.ini src/quote_of_the_day.yml\n3. After execution the file /tmp/motd_test on each host will contain the quote.\n\nThe playbook is deliberately simple and deterministic so that the automated test can run offline without external dependencies.
