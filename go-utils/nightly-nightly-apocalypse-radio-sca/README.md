# Apocalyptic Radio Frequency Scanner\n\nA whimsical utility that scans a list of radio frequencies (host:port) to see which are still broadcasting in the post‑apocalypse. It uses Go's concurrency primitives to probe many frequencies at once.\n\n## Build\n\n```sh\ngo build -o radio-scanner ./src\n```\n\n## Usage\n\n```sh\n./radio-scanner host1:1234 host2:5678\n```\n\nThe program prints one line per target, prefixed with a check or cross emoji:\n\n- `✅ host:port reachable`\n- `❌ host:port unreachable`\n\n## Testing\n\n```sh\ngo test ./...\n```\n\nThe test suite uses a mock dialer so it runs deterministically offline.
