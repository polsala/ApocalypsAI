Apocalypse Portal Ping\n\nA whimsical concurrent TCP ping tool for the end‑times. It attempts a TCP connection to each supplied host:port, measures round‑trip time, and prints a JSON array of results. Useful for quick health checks in scripts or for fun during a bunker drill.\n\nUsage:\n  portal-ping host1:port [host2:port ...]\n\nExample:\n  $ portal-ping example.com:80 8.8.8.8:53\n  [\n    {\n      "host": "example.com:80",\n      "latency_ms": 23\n    },\n    {\n      "host": "8.8.8.8:53",\n      "latency_ms": 12\n    }\n  ]\n\nBuild:\n  go build -o portal-ping ./src\n\nTests:\n  go test ./tests
