Nightly Concurrent Ping\n\nA whimsical Go utility that concurrently pings multiple hosts (TCP port 80) and reports latency statistics. Useful for quick network health checks in a post‑apocalyptic bunker.\n\nFeatures:\n- Configurable concurrency\n- Human‑readable table output\n- Deterministic offline tests with mock dialer\n\nInstallation:\n```sh\ngo build -o nightly-concurrent-ping ./src\n```\n\nUsage:\n```sh\n./nightly-concurrent-ping -c 5 host1.com host2.com ...\n```
