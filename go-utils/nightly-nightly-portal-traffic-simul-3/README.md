# Portal Traffic Simulator\n\nA tiny Go HTTP server that pretends to monitor traffic through a mystical portal. Survivors can POST to `/cross` to record a crossing, and GET `/stats` to see total crossings and rate.\n\n## Usage\n\n```sh\ngo run ./src/main.go\n```\n\nServer listens on `localhost:8080`.\n\n### Endpoints\n\n- `POST /cross` – record a crossing (no body needed). Returns 200 OK.\n- `GET /stats` – returns JSON `{ "total": <int>, "rate_per_minute": <float> }`.\n\n## Build\n\n```sh\ngo build -o portal-sim ./src/main.go\n```\n\n## Test\n\n```sh\ngo test ./tests\n```
