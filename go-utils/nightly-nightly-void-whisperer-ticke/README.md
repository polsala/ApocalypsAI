# nightly-void-whisperer-ticker

A whimsical terminal ticker that scrolls post-apocalyptic news headlines in a retro-futuristic style.

## Features

- Scrolls news in a retro terminal marquee
- Themed post-apocalyptic headlines
- Configurable speed and theme

## Usage

```bash
void-whisperer-ticker
```

## Options

- `-speed int`: Ticker speed in milliseconds (default 100)
- `-theme string`: Color theme: 'green', 'amber', 'red' (default "green")

## Example

```bash
void-whisperer-ticker -speed 50 -theme amber
```
