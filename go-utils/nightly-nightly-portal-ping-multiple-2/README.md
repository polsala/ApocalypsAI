# Nightly Portal Ping Multiplexer\n\n**What it does**\n\n`portal-ping-multiplexer` is a playful Go CLI that concurrently attempts a TCP handshake to a list of hosts (port 80) and reports the round‑trip latency.  Think of each successful connection as a portal opening to another dimension – the faster the portal, the lower the latency.\n\n**Why it’s useful**\n\n- Quickly gauge reachability of many services without leaving the terminal.\n- Demonstrates Go’s lightweight concurrency model.\n- Works offline in tests via a mockable ping function.\n\n**Installation**\n\n```bash\n# Clone the repository (or copy the utility folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/nightly-portal-ping-multiplexer\n# Build the binary\ngo build -o portal-ping-multiplexer ./src/main.go\n```\n\n**Usage**\n\n```bash\n./portal-ping-multiplexer [-t seconds] host1 host2 host3 ...\n```\n\n- `-t` sets the timeout for each individual ping (default 2 seconds).\n- Hosts are specified without a scheme; the tool always dials TCP port 80.\n\n**Example**\n\n```bash\n./portal-ping-multiplexer -t 3 example.com google.com nonexist.local\n```\n\nPossible output:\n\n````\nHost                           Latency\n----                           -------\nexample.com                    12.3ms\ngoogle.com                     8.7ms\nnonexist.local                 ✖\n````\n\n**Testing**\n\nThe utility includes deterministic unit tests that replace the network call with a mock implementation, so they run offline and never hit real hosts. Run them with:\n\n```bash\ngo test ./tests\n```\n\n**License**\n\nMIT – see LICENSE file in the repository root.\n
