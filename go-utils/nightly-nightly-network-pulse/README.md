# nightly-network-pulse\n\n**nightly-network-pulse** is a tiny Go utility that acts like a post‑apocalypse radio beacon, probing a list of HTTP endpoints concurrently and reporting each endpoint's status code and round‑trip latency.\n\n## Features\n\n- Reads URLs from command‑line arguments or STDIN (one per line)\n- Configurable worker pool (default 5 concurrent checks)\n- Uses HTTP HEAD requests to minimise bandwidth\n- Outputs a pretty‑printed JSON array of results\n- Fully tested with deterministic `httptest` servers\n\n## Installation\n\n```bash\n# Clone the repository (or copy the generated folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd go-utils/nightly-network-pulse\n\n# Build the binary\ngo build -o nightly-network-pulse ./src/main.go\n```\n\n## Usage\n\n```bash\n# Provide URLs as arguments\n./nightly-network-pulse https://example.com https://golang.org\n\n# Or pipe a list via STDIN\ncat urls.txt | ./nightly-network-pulse -workers 10\n```\n\nThe program will emit JSON like:\n\n```json\n[\n  {\n    "url": "https://example.com",\n    "status": 200,\n    "latency_ms": 123.45\n  },\n  {\n    "url": "https://golang.org",\n    "status": 200,\n    "latency_ms": 98.76\n  }\n]\n```\n\n## Testing\n\n```bash\ngo test ./tests\n```\n\n## License\n\nMIT – see LICENSE file in the repository root.
