# nightly-portal-ping\n\nA whimsical concurrent TCP latency checker that pings multiple hosts at once and reports the round‑trip time. Perfect for explorers navigating the digital portals of the apocalypse.\n\n## Build\n\n```bash\ngo build -o portal-ping ./src/main.go\n```\n\n## Usage\n\n```bash\n./portal-ping host1.com host2.org ...\n```\n\nThe tool attempts a TCP connection to port 80 (or the port specified with `host:port`) for each host, measures how long the connection takes, and prints the results in a table.\n\n## Example\n\n```bash\n$ ./portal-ping example.com google.com:443\n┌───────────────┬───────────────┐\n│ Host          │ Latency (ms)  │\n├───────────────┼───────────────┤\n│ example.com   │ 23            │\n│ google.com:443│ 12            │\n└───────────────┴───────────────┘\n```\n\n## Testing\n\nRun the unit tests with:\n\n```bash\ngo test ./... \n```
