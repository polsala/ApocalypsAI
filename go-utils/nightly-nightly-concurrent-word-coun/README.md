# Nightly Concurrent Word Counter\n\n## Overview\n\n`nightly-concurrent-word-counter` is a tiny Go utility that reads one or more text files, counts the words in each file **concurrently**, and prints a JSON summary containing per‑file counts and the overall total. It demonstrates Go's goroutine and channel patterns while providing a handy tool for quick word‑counting tasks.\n\n## Installation\n\n```bash\n# Clone the repository (or copy the utility folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd go-utils/nightly-concurrent-word-counter\n\n# Build the binary (optional)\ngo build -o wordcounter ./src/main.go\n```\n\nYou can also run it directly with `go run` without building a binary.\n\n## Usage\n\n```bash\n# Using the built binary\n./wordcounter file1.txt file2.txt\n\n# Or using go run\ngo run ./src/main.go file1.txt file2.txt\n```\n\nIf no files are provided, the program prints a usage message and exits with code 1.\n\n## Output\n\nThe program writes a single JSON object to **STDOUT**. Example:\n\n```json\n{\n  "files": {\n    "file1.txt": 42,\n    "file2.txt": 17\n  },\n  "total": 59\n}\n```\n\nAny errors encountered while reading a file are printed to **STDERR**, but the program continues processing the remaining files.\n\n## Testing\n\nRun the test suite with:\n\n```bash\ngo test ./tests\n```\n\nThe tests are deterministic and do not require network access.\n\n## License\n\nThis utility is released under the MIT License.\n
