Nightly Port Scanner\n\nA whimsical concurrent TCP port scanner written in Go. It scans a range of ports on a target host using goroutines and reports any open ports. Perfect for post‑apocalyptic network reconnaissance.\n\nUsage:\n  go run . -host <target> -start <port> -end <port> [-timeout <ms>]\n\nExample:\n  go run . -host localhost -start 80 -end 85\n\nThe tool limits concurrency to 100 workers to avoid overwhelming the system.\n
