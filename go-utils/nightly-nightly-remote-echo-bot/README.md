# Nightly Remote Echo Bot\n\nA whimsical concurrent TCP port scanner written in Go. It scans a target host for open ports using configurable workers, perfect for post-apocalyptic network reconnaissance.\n\n## Build\n\n```sh\ngo build -o remote-echo-bot ./src\n```\n\n## Usage\n\n```sh\n./remote-echo-bot -host example.com -start 1 -end 1024 -workers 100\n```\n\nOutputs open ports line by line.\n\n## Flags\n\n- `-host` target hostname or IP (required)\n- `-start` start port (inclusive, default 1)\n- `-end` end port (inclusive, default 65535)\n- `-workers` number of concurrent workers (default 100)\n- `-timeout` dial timeout (default 500ms)\n\n## License\n\nMIT
