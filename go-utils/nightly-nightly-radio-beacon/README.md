# Radio Beacon\n\nA tiny Go utility that concurrently checks a list of URLs and reports their \"signal strength\" and \"radiation level\". Useful for monitoring services in a post‑apocalyptic setting.\n\n## Usage\n\n```sh\ngo run ./src/main.go https://example.com https://example.org\n```\n\nOutput example:\n\n````\n[✔] https://example.com – Signal: 87% | Radiation: 12µSv\n[✖] https://example.org – Signal: 0%  | Radiation: 0µSv (unreachable)\n````\n\n## How it works\n\n- Accepts URLs as command‑line arguments.\n- Launches a goroutine per URL with a timeout.\n- Calculates a pseudo‑random signal strength based on HTTP status.\n- Radiation level is derived from response time.\n\n## Testing\n\nRun `go test ./...` to execute deterministic tests that use a local mock server.\n
