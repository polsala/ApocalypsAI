# Nightly Emoji Echo Server\n\n## Overview\n\n`nightly-emoji-echo-server` is a tiny Go program that listens on a TCP port and echoes back every line it receives, but with a whimsical twist – each line is prefixed by a randomly chosen emoji.  It is useful for quick network‑client demos, testing line‑based protocols, or just adding a bit of fun to your terminal.\n\n## Features\n\n- Concurrent handling of multiple client connections\n- One‑liner per message echo with a random emoji prefix\n- Deterministic behaviour when the random seed is set (useful for testing)\n\n## Build & Run\n\n```bash\n# Clone the repository (or copy the utility folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/nightly-emoji-echo-server\n\n# Build the binary\ngo build -o emoji-echo src/main.go\n\n# Run (default port 4000)\n./emoji-echo\n```\n\nThe server will start listening on `0.0.0.0:4000`.  You can connect with any TCP client, e.g.:\n\n```bash\n$ telnet localhost 4000\nTrying 127.0.0.1...\nConnected to localhost.\nEscape character is '^]'.\nhello world\n😀 hello world\n```\n\n## Configuration\n\n- **Port** – Change the listening address by passing it as the first argument, e.g. `./emoji-echo :8080`.\n- **Emoji set** – The list of emojis is defined in the source code (`emojis` slice). Feel free to edit it.\n\n## Testing\n\nRun the automated test suite with:\n\n```bash\ngo test ./tests\n```\n\nThe test forces a deterministic random seed, so the first echoed line is always prefixed with the 😀 emoji.\n
