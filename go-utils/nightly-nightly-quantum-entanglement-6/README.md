## Nightly Quantum Entanglement Checker

A whimsical-yet-useful Go utility that simulates quantum entanglement verification for distributed systems. Perfect for testing distributed consensus algorithms and demonstrating concurrent programming concepts.

### Features
- Simulates quantum particle pairs with entangled states
- Demonstrates Go's goroutines and channels for concurrent processing
- Includes distributed consensus simulation
- Provides educational visualization of quantum concepts

### Usage
```bash
# Build the utility
make build

# Run entanglement simulation
./bin/nightly-quantum-entanglement-checker --particles 100 --duration 5s

# Run distributed consensus simulation
./bin/nightly-quantum-entanglement-checker --consensus --nodes 5
```

### Installation
```bash
# Clone the repository
git clone <repo-url>

cd go-utils/nightly-quantum-entanglement-checker

# Build
make build

# Or install globally
make install
```
