Nightly Echo Multicast Utility\n\nOverview\n--------\nThis utility starts a TCP server (default port 8080) that accepts any number of client connections. For each line of text received from a client, the server replies with the same line prefixed by a randomly chosen whimsical phrase such as \"Beware the dancing llama!\". The server runs concurrently, handling each client in its own goroutine.\n\nBuild\n-----\nEnsure you have Go 1.22 or later installed.\n\n    go build -o echo-multicast ./src/main.go\n\nRun\n---\nStart the server (optionally specify a port via the PORT environment variable):\n\n    PORT=9090 ./echo-multicast\n\nIf PORT is not set, the server listens on 8080.\n\nClient Example\n----------------\nYou can test the server with netcat or telnet:\n\n    nc localhost 8080\n    hello world\n    // server replies, e.g.:\n    Beware the dancing llama! hello world\n\nTesting\n-------\nRun the automated test suite with:\n\n    go test ./tests\n\nThe tests use in‑memory pipes to simulate client/server interaction and are deterministic.\n
