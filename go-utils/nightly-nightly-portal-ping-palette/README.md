Nightly Portal Ping Palette\n\nOverview:\nThis utility concurrently checks the availability of a list of URLs and prints a colorful status line for each. Useful for quick health checks of services.\n\nInstallation:\nRun: go build -o portal-ping ./src\n\nUsage:\nPipe a list of URLs (one per line):\necho -e "https://example.com\nhttps://bad.example" | ./portal-ping -t 2s\n\nOr pass them as arguments:\n./portal-ping -t 3s https://example.com https://another.com\n\nFlags:\n-t duration : request timeout (default 5s)\n\nThe tool prints each URL followed by a colored status (OK in green, FAIL in red, ERR in yellow).\n\nLicense: MIT
