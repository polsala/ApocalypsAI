# nightly-quick-quote-fetcher

Fetches a random inspirational quote from a public API and prints it to the console.

## Usage

```bash
go run src/main.go
```

or build:

```bash
go build -o quick-quote src/main.go
./quick-quote
```

## Output

```
"Believe you can and you're halfway there." — Theodore Roosevelt
```

## Testing

Run tests:

```bash
go test ./...
```
