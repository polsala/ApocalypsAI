# nightly-ping-pong-multichecker\n\nA tiny Go utility that dashes across the network, concurrently connecting to a list of `host:port` endpoints, measuring the round‑trip latency, and sprinkling the results with whimsical speed emojis.\n\n## Features\n\n- **Concurrent checks** – fire off all connections at once using goroutines.\n- **Timeout safety** – each attempt aborts after 3 seconds to avoid hanging.\n- **Whimsical rating** – latency is mapped to fun emojis (⚡, 🚀, 🐇, 🐢, 🦥).\n- **Zero external dependencies** – pure Go standard library.\n\n## Installation\n\n```bash\n# Clone the repository (or copy the utility folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/go-utils/nightly-ping-pong-multichecker\n\n# Build the binary\ngo build -o ping-multi src/main.go\n```\n\n## Usage\n\n```bash\n./ping-multi example.com:80 8.8.8.8:53 localhost:22\n```\n\nThe output looks like:\n\n````\nTARGET                   LATENCY    RATING\n--------------------------------------------------\nexample.com:80           23.4ms     ⚡ Lightning fast\n8.8.8.8:53               45.1ms     🚀 Fast\nlocalhost:22             1.2s       🐢 Slow\n````\n\n## Testing\n\nRun the deterministic test suite with:\n\n```bash\ngo test ./tests\n```\n\nThe tests spin up local TCP listeners with controlled delays, ensuring repeatable results without any external network calls.\n\n## License\n\nMIT – see the root LICENSE file.
