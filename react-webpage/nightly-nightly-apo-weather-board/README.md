# nightly-apo-weather-board\n\nInteractive React dashboard that shows whimsical post‑apocalyptic weather forecasts.\n\n## Features\n\n- Randomly selects a weather condition from a curated list.\n- Refresh button to generate a new forecast.\n- Simple, zero‑dependency UI (React + Vite).\n\n## Usage\n\n```bash\nnpm install\nnpm run dev\n```\n\nOpen `http://localhost:5173` to view the dashboard.\n\n## Testing\n\n```bash\nnpm test\n```\n
