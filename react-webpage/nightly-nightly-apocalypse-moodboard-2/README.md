# Apocalypse Moodboard\n\nAn interactive React dashboard that shows a daily post‑apocalyptic quote and lets you jot down whimsical survival notes. Notes are saved in your browser's local storage.\n\n## Usage\n\n```sh\nnpm install\nnpm start\n```\n\nOpen http://localhost:3000 to view.\n\n## Features\n\n- Deterministic daily quote based on calendar.\n- Add and persist personal notes.\n- Fully tested with Jest & React Testing Library.\n
