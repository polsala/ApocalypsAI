# Apocalypse Moodboard\n\nAn interactive React web page that conjures whimsical post‑apocalypse weather forecasts and suggests a matching mood. Click "Generate" to get a new forecast.\n\n## Features\n- Randomly generated weather description with emojis.\n- Corresponding mood suggestion.\n- Simple, zero‑config start with Vite.\n\n## Getting Started\n\n```sh\nnpm install\nnpm run dev\n```\n\nOpen http://localhost:5173 to view.\n\n## Testing\n\n```sh\nnpm test\n```\n\n## License\n\nMIT
