# Apocalypse Moodboard\n\nA tiny React web app that serves up random post‑apocalyptic weather moods. Click the **Generate** button to receive a new whimsical forecast.\n\n## Features\n\n- Randomly picks a mood from a curated list.\n- Simple UI with a single button.\n- Fully tested with Jest and React Testing Library.\n\n## Development\n\n```sh\nnpm install\nnpm start   # runs the dev server at http://localhost:3000\nnpm test    # runs the test suite\n```\n\n## Build\n\n```sh\nnpm run build\n```\n\nEnjoy the chaos!
