## Whimsical Survival Kit Builder

Create survival kits with essential items plus randomized fun additions like 'rubber duck for morale' or 'disco ball for night signaling'. Export your kit as a shareable JSON or PDF.

### Features
- Drag-and-drop item organizer
- Scenario-based item suggestions (post-apocalyptic, space colony, etc.)
- Whimsy slider (0-100% absurd items)
- Shareable kit URLs

Run locally with `npm start` or deploy to any static host.
