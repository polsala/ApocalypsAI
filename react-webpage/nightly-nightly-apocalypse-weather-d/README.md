## Run locally

1. Install dependencies:

```sh
npm install
```

2. Start a static server (any will do, e.g., `npx serve public`).

3. Open `http://localhost:3000` in your browser.

## Tests

Run the deterministic unit test:

```sh
npm test
```

The test checks that `getForecast("Radiated Ruins")` returns the expected string.
