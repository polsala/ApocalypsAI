# Nightly Apocalypse Weather Dashboard\n\nA whimsical React web app that generates post‑apocalyptic weather forecasts for fictional locations.\n\n## How it works\n\n- Choose a location from the dropdown (e.g., "Radiated Ruins", "Dusty Wasteland").\n- Click **Generate** to see a deterministic, yet random‑looking forecast.\n- The forecast is generated by a pure JavaScript function `getForecast` that hashes the location name, so the same location always yields the same forecast – perfect for offline testing.\n\n## Run locally\n\n1. Install dependencies:\n\n```sh\nnpm install\n```\n\n2. Start a static server (any will do, e.g., `npx serve public`).\n\n3. Open `http://localhost:3000` in your browser.\n\n## Tests\n\nRun the deterministic unit test:\n\n```sh\nnpm test\n```\n\nThe test checks that `getForecast("Radiated Ruins")` returns the expected string.
