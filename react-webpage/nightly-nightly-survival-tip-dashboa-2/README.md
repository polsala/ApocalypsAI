# Survival Tip Dashboard\n\nA whimsical React web app that displays a random survival tip from a curated list. Users can filter tips by category (e.g., \"water\", \"food\", \"navigation\") and click a button to get a new tip. Perfect for post‑apocalyptic brainstorming or just a daily dose of practical fun.\n\n## How to run\n\n```bash\nnpm install\nnpm start\n```\n\nOpen http://localhost:3000 in a browser.\n\n## Scripts\n\n- `npm test` – runs the Jest test suite.\n\n## License\n\nMIT
