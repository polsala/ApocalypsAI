# Nightly Quantum Entanglement Simulator

A whimsical web-based quantum entanglement simulator that visualizes the spooky action at a distance. Watch as particles become entangled and observe how measuring one instantly affects its partner, no matter how far apart they are!

## Features

- Interactive quantum particle visualization
- Real-time entanglement simulation
- Measurement effects with instant state collapse
- Educational tooltips explaining quantum concepts
- Whimsical animations and sound effects

## Usage

1. Open `index.html` in any modern browser
2. Click "Create Entangled Pair" to generate two particles
3. Drag particles around the canvas
4. Click "Measure" on one particle to see instant effects on its partner
5. Observe the quantum state collapse in real-time

## Technologies

- HTML5 Canvas for rendering
- Vanilla JavaScript for simulation logic
- CSS3 animations for visual effects
- Web Audio API for quantum sound effects

## Educational Value

This tool demonstrates:
- Quantum superposition
- Entanglement and non-locality
- Wave function collapse
- The measurement problem

## Fun Facts

- In quantum mechanics, entangled particles remain connected such that the state of one instantly influences the other, regardless of distance
- Einstein famously called this "spooky action at a distance"
- This simulator is simplified for educational purposes and doesn't represent actual quantum physics complexity
