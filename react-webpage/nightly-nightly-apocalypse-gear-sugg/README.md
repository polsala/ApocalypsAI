# Apocalypse Gear Suggester\n\nA whimsical React web app that helps you pick random survival gear based on a scenario you type in. Perfect for post‑apocalypse brainstorming or just for fun.\n\n## How to run\n\n```bash\nnpm install\nnpm start\n```\n\nOpen http://localhost:3000 in your browser.\n\n## Features\n\n- Enter any scenario (e.g., "crossing the desert").\n- Click **Suggest Gear** to get a random piece of gear.\n- Gear list is hard‑coded, no external API calls.\n\n## Testing\n\n```bash\nnpm test\n```
