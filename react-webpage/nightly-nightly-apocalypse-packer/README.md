# Apocalyptic Gear Packer\n\nA tiny React web app that lets you add survival items with their weight and shows the total weight. Useful for planning what to carry on a post‑apocalyptic trek.\n\n## Development\n\n```bash\nnpm install\nnpm start   # runs on http://localhost:3000\nnpm test    # runs jest tests\n```\n\n## How it works\n\n1. Enter an item name and its weight (kg).\n2. Click **Add**.\n3. The item appears in the list and the total weight updates.\n\nFeel free to customize the styling or extend the logic (e.g., weight limits, categories, export to JSON).
