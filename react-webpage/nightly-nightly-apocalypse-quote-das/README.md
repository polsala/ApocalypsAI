# Apocalypse Quote Dashboard\n\nAn interactive, single‑page React app that shows a rotating list of post‑apocalyptic quotes.\n\n## Features\n- Displays a quote from a curated list.\n- "Next" button cycles through quotes.\n- Fully tested with React Testing Library.\n\n## Getting Started\n\n```bash\n# Clone the repository (or copy the generated folder)\ngit clone <repo-url>\ncd nightly-apocalypse-quote-dashboard\n\n# Install dependencies\nnpm install\n\n# Run the development server\nnpm start\n# Open http://localhost:3000 in your browser\n\n# Run the test suite\nnpm test\n```\n\nThe app uses only standard React dependencies and works offline – the quotes are bundled with the source.\n\n## Project Structure\n- `src/` – React source files.\n- `src/quotes.js` – static array of quotes.\n- `tests/` – Jest + React Testing Library tests.\n- `package.json` – scripts and dependencies.\n\nEnjoy the bleak wisdom!\n
