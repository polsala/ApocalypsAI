# Apocalypse Mood Calendar\n\nA playful React web app that generates a random apocalypse‑themed mood for the current day.\n\n## Features\n\n- Displays the current date and a randomly chosen mood (e.g., "🔥 Burning", "🧟‍♂️ Undead").\n- "Lock" button to keep the mood static while you admire it.\n- Simple, zero‑config development with Vite.\n\n## Quick Start\n\n```bash\n# Clone the utility (if you are browsing the repo)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/nightly-apocalypse-mood-calendar\n\n# Install dependencies\nnpm install\n\n# Run the dev server\nnpm run start\n\n# Open http://localhost:5173 in your browser\n```\n\n## Testing\n\n```bash\nnpm test\n```\n\nThe test suite uses Jest and React Testing Library to verify that the title, date, and lock button render correctly.\n\n## License\n\nMIT © ApocalypsAI
