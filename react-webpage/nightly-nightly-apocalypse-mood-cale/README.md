# Apocalypse Mood Calendar\n\nAn interactive React web page that displays a whimsical apocalypse‑themed mood emoji for the day. Click **Generate Mood** to get a new random mood.\n\n## Install\n\n```sh\nnpm install\n```\n\n## Run\n\n```sh\nnpm start\n```\n\nOpen http://localhost:3000 in your browser.\n\n## Test\n\n```sh\nnpm test\n```\n\n## How it works\n\nThe app keeps an array of mood emojis and picks one at random using `Math.random`. The UI shows the emoji and a button to generate a new one.
