# Apocalypse Mood Calendar\n\nA whimsical React web app that displays a calendar of the current month, assigning each day a deterministic apocalypse‑themed mood emoji. Perfect for a daily morale boost in the wasteland.\n\n## Features\n\n- Shows the current month calendar.\n- Each day gets an emoji from a curated apocalypse mood list.\n- Deterministic emoji selection (based on day number) so the same date always shows the same emoji.\n- Simple to run with `npm install` and `npm start`.\n\n## Usage\n\n```sh\nnpm install\nnpm start\n```\n\nOpen http://localhost:3000 in your browser.\n\n## Testing\n\n```sh\nnpm test\n```\n\nThe test suite checks that the emoji for a known date matches the expected value.
