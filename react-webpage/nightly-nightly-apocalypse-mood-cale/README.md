# Apocalypse Mood Calendar\n\nA whimsical React web app that displays a daily apocalypse‑themed mood emoji based on the current date. The mood is deterministic, so the same date always yields the same emoji.\n\n## How it works\n\nThe app computes a simple hash of the ISO date string (`YYYY‑MM‑DD`) and uses it to pick an emoji from a predefined list.\n\n## Running locally\n\n```sh\nnpm install\nnpm run dev   # starts Vite dev server\nnpm test      # runs Jest tests\n```\n\n## License\n\nMIT\n
