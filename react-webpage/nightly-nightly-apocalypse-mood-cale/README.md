# Apocalypse Mood Calendar\n\nA tiny React web app that displays a random apocalypse‑themed mood emoji for the current day.\nYou can lock the mood so it stays the same while you admire it.\n\n## Features\n- Random emoji from a curated list each day\n- "Lock" button to keep the current mood\n- Simple, zero‑config start with Vite\n\n## Getting Started\n\n```bash\n# Clone the repository (or copy the generated folder)\ngit clone <repo‑url>\ncd nightly-apocalypse-mood-calendar\n\n# Install dependencies\nnpm install\n\n# Run the dev server\nnpm start\n\n# Open http://localhost:5173 in your browser\n```\n\n## Running Tests\n\n```bash\nnpm test\n```\n\nThe test suite uses Jest and React Testing Library and runs completely offline.\n\n## License\n\nMIT
