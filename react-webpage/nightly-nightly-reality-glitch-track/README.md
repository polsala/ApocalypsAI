# Nightly Reality Glitch Tracker

An interactive web interface for community members to report and visualize minor, everyday reality glitches and temporal echoes. Ever felt like your keys moved on their own, or experienced a sudden, inexplicable déjà vu? This tool helps you log those peculiar moments and see if others are experiencing similar anomalies!

## Features

*   **Report Glitches**: Easily submit a new "glitch" with a description, type (e.g., Object Displacement, Time Skip, Auditory Echo, Déjà Vu Loop), and timestamp.
*   **Visualize Anomalies**: View a chronological list of reported glitches.
*   **Whimsical Interface**: A fun, user-friendly interface designed to make tracking the bizarre enjoyable.

## How to Run

This is a standard React application.

1.  **Navigate to the utility directory**:
    ```bash
    cd react-webpage/nightly-reality-glitch-tracker
    ```
2.  **Install dependencies**:
    ```bash
    npm install
    ```
3.  **Start the development server**:
    ```bash
    npm start
    ```
    This will open the application in your browser, usually at `http://localhost:3000`.

## How to Use

1.  **Open the application** in your web browser.
2.  **Fill out the "Report a New Glitch" form**:
    *   **Description**: Briefly describe the glitch you experienced.
    *   **Type**: Select the category that best fits your anomaly.
3.  **Click "Report Glitch"**: Your new glitch will appear in the list below.
4.  **Browse the list**: See all reported glitches, including their type, description, and when they were reported.
