# Wasteland Tip Generator\n\nAn interactive React web page that gives you a whimsical survival tip based on chosen environment and time of day. No network calls; all data is baked in.\n\n## How to run\n\n1. Install Node.js (>=14).\n2. Run `npm install`.\n3. Start a static server: `npx serve src` or open `src/index.html` in a browser.\n4. Choose environment and time, click "Get Tip".\n\n## Tests\n\nRun `npm test` to execute Jest tests.
