# Nightly Apoc Tip Day\n\nA tiny React web app that displays a random post‑apocalyptic survival tip each time you visit the page.\n\n## Features\n\n- Shows one tip from a curated list on load\n- "New Tip" button to fetch another random tip without reloading\n- Fully offline – all data is baked into the bundle\n\n## Getting Started\n\n```bash\n# Clone the repository (or copy the generated folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd react-webpage/nightly-apoc-tip-day\n\n# Install dependencies\nnpm install\n\n# Run the development server\nnpm start\n```\n\nOpen your browser at `http://localhost:3000` and enjoy a fresh tip each time you click the button.\n\n## Building for Production\n\n```bash\nnpm run build\n```\n\nThe production build will be placed in the `dist/` folder and can be served with any static file server.\n\n## Testing\n\nThe project uses **Jest** and **@testing-library/react**. Tests are deterministic – they mock `Math.random` to ensure repeatable results.\n\n```bash\nnpm test\n```\n\n## License\n\nMIT – see the root LICENSE file.
