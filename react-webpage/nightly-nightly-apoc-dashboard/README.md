# Nightly Apoc Dashboard

A whimsical, interactive React dashboard for the ApocalypsAI community. Visualize utility stats, simulated wasteland weather, and morale metrics with animated charts and playful UI elements.

## Features
- **Utility Ecosystem**: Bar chart showing distribution of utilities by classifier
- **Wasteland Weather**: Simulated weather conditions with animated icons
- **Morale Meter**: Gauge showing community morale with whimsical messages
- **Temporal Rifts**: Live countdown to next temporal anomaly
- **Resource Tracker**: Animated progress bars for essential survival resources
- **Compliment Corner**: Random whimsical compliments

## Tech Stack
- React 18
- Chart.js for visualizations
- CSS animations and transitions

## Installation
1. Clone this repository
2. Navigate to the dashboard directory
3. Run `npm install` to install dependencies
4. Run `npm start` to launch the dashboard

## Usage
Open your browser and navigate to `http://localhost:3000` to view the dashboard. All data is simulated and runs entirely in the browser.
