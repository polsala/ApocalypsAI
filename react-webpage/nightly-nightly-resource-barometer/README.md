# Nightly Resource Barometer\n\n## Overview\nA whimsical yet useful React web app that visualises three essential post‑apocalyptic resources – **Water**, **Food**, and **Ammo** – as adjustable sliders. The app computes an overall *Survival Rating* (the average of the three percentages) so you can quickly gauge how prepared you are for the next fallout.\n\n## Features\n- Three sliders (0‑100%) for water, food, and ammo.\n- Real‑time update of each resource value.\n- Automatic calculation of a Survival Rating.\n- Simple, zero‑dependency UI (just React).\n\n## Installation\n```bash\n# Clone the repository (or copy the generated folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/nightly-resource-barometer\n\n# Install dependencies\nnpm install\n```\n\n## Running the App\n```bash\nnpm start\n```\nThe app will be available at `http://localhost:3000`.\n\n## Testing\n```bash\nnpm test\n```\nThe test suite uses **Jest** and **@testing-library/react** to verify that the sliders correctly affect the Survival Rating.\n\n## License\nMIT – see the root LICENSE file.
