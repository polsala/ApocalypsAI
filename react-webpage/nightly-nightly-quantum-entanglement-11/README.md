# Nightly Quantum Entanglement Simulator

A whimsical web-based quantum entanglement simulator that lets you create, manipulate, and measure entangled particles in a beautiful interactive visualization.

## Features

- **Interactive Particle Creation**: Drag and drop particles onto the quantum field
- **Entanglement Visualization**: See particles become entangled with animated connections
- **Measurement Tools**: Use various measurement devices to observe quantum states
- **Quantum Superposition**: Watch particles exist in multiple states until measured
- **Bell State Demonstrations**: Explore different types of quantum entanglement
- **Educational Mode**: Learn about quantum mechanics concepts through interactive examples

## Technologies Used

- React 18 with TypeScript
- D3.js for physics-based particle animations
- Web Audio API for quantum sound effects
- CSS-in-JS for responsive styling

## Installation

```bash
# Clone the repository
git clone <repository-url>
cd nightly-quantum-entanglement-simulator

# Install dependencies
npm install

# Start development server
npm run dev
```

## Usage

1. **Create Particles**: Click anywhere on the quantum field to create particles
2. **Entangle Particles**: Select two particles and click 'Entangle' to create quantum connections
3. **Measure States**: Use measurement devices to observe particle properties
4. **Reset**: Clear the field and start over

## Educational Concepts

- **Superposition**: Particles exist in multiple states until measured
- **Entanglement**: Measuring one particle instantly affects its partner
- **Bell States**: Different types of quantum correlations
- **Wave Function Collapse**: How measurement affects quantum systems

## Browser Support

Modern browsers with ES6+ support (Chrome 60+, Firefox 55+, Safari 11+, Edge 79+)
