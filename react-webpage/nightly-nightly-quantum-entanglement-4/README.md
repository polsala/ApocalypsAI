# Nightly Quantum Entanglement Simulator

A whimsical yet educational quantum circuit simulator that visualizes quantum entanglement in real-time. Perfect for learning quantum computing concepts!

## Features

- 🎮 Interactive quantum circuit builder
- 🌀 Visual entanglement visualization
- 📚 Educational tooltips and explanations
- 🧪 Pre-built quantum algorithms (Bell states, teleportation)
- 📊 Real-time probability measurements
- 🎨 Beautiful, animated quantum state visualization

## Usage

1. Open `index.html` in any modern browser
2. Drag and drop quantum gates onto the circuit
3. Watch entanglement patterns emerge
4. Measure and observe quantum collapse

## Technologies

- React 18
- D3.js for visualizations
- Web Audio API for quantum sound effects

## Example

Create Bell states, quantum teleportation circuits, or design your own quantum algorithms!
