# Apocalypse Resource Dashboard\n\nAn interactive React web app to track and visualize your post‑apocalyptic supplies. Add resources with quantities, see them in a table, and view the total amount.\n\n## Development\n\n```bash\nnpm install\nnpm start   # runs on http://localhost:3000\nnpm test    # runs the test suite\n```\n\n## Features\n\n- Add / delete resources\n- Live total calculation\n- Simple, zero‑dependency UI
