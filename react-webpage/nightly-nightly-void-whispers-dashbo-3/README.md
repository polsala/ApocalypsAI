# nightly-void-whispers-dashboard

A whimsical React dashboard that visualizes affirmations received from the cosmic void. Perfect for developers seeking inspiration or a moment of levity.

## Features

- Displays a rotating list of void affirmations
- Allows users to favorite affirmations
- Includes a "Whisper to the Void" submission form
- Responsive design with playful animations

## Usage

1. Clone the repo
2. Run `npm install`
3. Run `npm start`
4. Visit `http://localhost:3000`

## Development

- Built with React and styled-components
- Fully typed with TypeScript
- Includes unit tests with Jest and React Testing Library
