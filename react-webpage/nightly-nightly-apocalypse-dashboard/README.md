## Nightly Apocalypse Dashboard

This is a whimsical React-based web application designed to provide a visual overview of the current state of the apocalypse. It's a fun, interactive dashboard that uses mock data to simulate various apocalyptic scenarios.

### Features

*   **Resource Tracker:** Visualize the availability of essential survival resources.
*   **Threat Level Indicator:** A dynamic gauge showing the current global threat level.
*   **Safe Zone Status:** Map-like display of known safe zones and their population.
*   **Whispers of the Void:** A scrolling feed of cryptic, generated messages.

### Getting Started

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/polsala/ApocalypsAI.git
    cd ApocalypsAI
    ```

2.  **Navigate to the utility directory:**
    ```bash
    cd utils/nightly-apocalypse-dashboard
    ```

3.  **Install dependencies:**
    ```bash
    npm install
    ```

4.  **Start the development server:**
    ```bash
    npm start
    ```

    The dashboard will be accessible at `http://localhost:3000`.

### Running Tests

To run the unit tests, execute:

```bash
npm test
```

### Development Notes

This utility is built using React and uses mock data for all its visualizations. The data is generated and updated periodically to simulate a dynamic apocalyptic environment. The goal is to provide a fun, albeit fictional, representation of survival preparedness and the general state of the world.
