# Nightly Weather Moodboard\n\nAn interactive React web page that generates whimsical weather forecasts and a random survival tip. Perfect for a quick smile during post‑apocalyptic planning.\n\n## Features\n\n- Randomly selects a weather condition (e.g., \"Acid Rain\", \"Glowing Fog\").\n- Shows a matching emoji/icon.\n- Provides a random survival tip.\n- Click **Generate** to get a new forecast.\n\n## Installation\n\n```bash\nnpm install\nnpm start\n```\n\n## Development\n\nRun tests:\n\n```bash\nnpm test\n```
