# nightly-apocalypse-survival-dashboard

A whimsical React dashboard for tracking survival metrics and resource allocations in post-apocalyptic scenarios.

## Features

- Track water, food, and ammunition levels
- Visualize shelter integrity over time
- Log daily survival activities
- Responsive design for mobile and desktop

## Usage

1. Clone the repository
2. Install dependencies with `npm install`
3. Start the development server with `npm start`
4. Open [http://localhost:3000](http://localhost:3000) to view the dashboard
