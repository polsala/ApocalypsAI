Survival Gear Dashboard\n\nOverview:\nAn interactive web dashboard built with React that lets users view, filter, and check off survival gear items. State is saved in the browser's local storage so the checklist persists across sessions.\n\nFeatures:\n- List of gear items with categories (Food, Tools, Medicine, etc.)\n- Filter by category\n- Mark items as owned/unowned with checkboxes\n- Persistent state via localStorage\n- Simple responsive layout\n\nInstallation:\n1. Ensure Node.js (>=14) and npm are installed.\n2. Navigate to the utility directory.\n3. Run `npm install` to install dependencies.\n4. Run `npm start` to launch the development server at http://localhost:3000.\n\nTesting:\nRun `npm test` to execute the Jest test suite.
