Usage
-----
1. Install dependencies: npm install

3. Open http://localhost:3000 in a browser.
4. Click the **Refresh** button to get a new forecast.

Testing
-------
Run the test suite with: npm test
The tests verify that the main component renders and that a forecast is displayed after a refresh.
