Nightly Weather Moodboard\n\nA whimsical React web app that generates a random post‑apocalyptic weather description with an emoji and suggests a mood‑matching activity. Perfect for a quick smile during a chaotic day.\n\nUsage\n-----\n1. Install dependencies: npm install\n2. Start the development server: npm start\n3. Open http://localhost:3000 in a browser.\n4. Click the **Refresh** button to get a new forecast.\n\nTesting\n-------\nRun the test suite with: npm test\nThe tests verify that the main component renders and that a forecast is displayed after a refresh.\n
