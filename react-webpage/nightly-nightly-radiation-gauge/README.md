# Radiation Gauge\n\nAn interactive React web page that lets you input a radiation level (0‑1000 µSv/h) and shows a gauge with color‑coded safety zones:\n\n- **Green**: 0‑200 µSv/h (safe)\n- **Yellow**: 200‑500 µSv/h (caution)\n- **Orange**: 500‑800 µSv/h (danger)\n- **Red**: 800‑1000 µSv/h (critical)\n\n## How to run\n\n```bash\nnpm install\nnpm start\n```\n\nOpen `http://localhost:3000` in your browser.\n\n## Testing\n\n```bash\nnpm test\n```\n\nThe test suite uses Jest and React Testing Library to verify that the gauge updates its colour correctly when different radiation levels are entered.\n
