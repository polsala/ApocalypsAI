## Getting Started
```bash
# Clone the repository (or copy the utility folder)
git clone https://github.com/polsala/ApocalypsAI.git
cd utils/react-webpage/nightly-survival-gear-recommender

# Install dependencies
npm install

# Run the development server
npm start
```

Open `http://localhost:3000` in your browser to see the app.

## Running Tests
```bash
npm test
```

The test suite uses Jest and React Testing Library to verify that the gear list appears correctly after an environment is selected.
