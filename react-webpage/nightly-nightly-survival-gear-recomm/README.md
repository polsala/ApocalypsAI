# Nightly Survival Gear Recommender\n\nAn interactive React web page that helps you pick whimsical survival gear for different post‑apocalyptic environments.\n\n## Features\n- Choose an environment (Desert, Tundra, Urban, Forest) from a dropdown.\n- Instantly see a curated list of quirky gear items.\n- Pure client‑side, no external APIs required.\n\n## Getting Started\n```bash\n# Clone the repository (or copy the utility folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/react-webpage/nightly-survival-gear-recommender\n\n# Install dependencies\nnpm install\n\n# Run the development server\nnpm start\n```\n\nOpen `http://localhost:3000` in your browser to see the app.\n\n## Running Tests\n```bash\nnpm test\n```\n\nThe test suite uses Jest and React Testing Library to verify that the gear list appears correctly after an environment is selected.\n\n## License\nMIT
