# Resource Barter Calculator\n\nA whimsical React web app that lets you input quantities of common post‑apocalyptic resources and instantly see the total trade value in "Barter Points". Useful for role‑playing games, story planning, or just fun.\n\n## Features\n\n- Live calculation as you type\n- Adjustable resource values in source\n- Responsive layout\n\n## Getting Started\n\n```bash\nnpm install\nnpm start\n```\n\nOpen http://localhost:3000 in your browser.\n\n## Running Tests\n\n```bash\nnpm test\n```\n\n## License\n\nMIT
