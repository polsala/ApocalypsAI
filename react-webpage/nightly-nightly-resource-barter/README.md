# Nightly Resource Barter\n\nAn interactive React web app that helps survivors determine fair trade ratios between two resources. Enter the names and quantities of each resource, and the app shows the ratio and suggests how many units of one resource are needed to match the other.\n\n## How to run\n\n```bash\nnpm install\nnpm start\n```\n\nOpen `http://localhost:3000` in your browser.\n\n## Testing\n\n```bash\nnpm test\n```\n\n## License\n\nMIT
