# Resource Barter Calculator\n\nA whimsical React web app that helps survivors determine fair trade ratios between resources like water, food, ammo, and medicine.\n\n## Usage\n\n1. Install dependencies: `npm install`\n2. Run the development server: `npm start`\n3. Open http://localhost:3000 in your browser.\n\nEnter amounts for two resources and the app will display the ratio (A per B).\n\n## Files\n\n- `src/App.jsx` – main component with the calculator UI\n- `src/index.jsx` – React entry point\n- `package.json` – minimal dependencies and scripts\n- `tests/BarterCalculator.test.jsx` – Jest test suite\n\n## Tests\n\nRun `npm test` to execute the Jest tests. The test suite renders the component, simulates user input, and verifies the calculated ratio.\n
