# Nightly Survival Kit Dashboard\n\nAn interactive web dashboard built with React that lets you create, weight, and prioritize items for your apocalypse survival kit.\n\n## Features\n- Add items with name, weight (kg), and priority (1‑5)\n- Real‑time total weight calculation\n- Sort items by priority or weight\n- Simple, zero‑dependency UI (only React and standard tooling)\n\n## Getting Started\n\n```bash\n# Clone the repository (or copy the generated folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/react-webpage/nightly-survival-kit-dashboard\n\n# Install dependencies\nnpm install\n\n# Run the development server\nnpm start\n```\n\nThe app will be available at `http://localhost:3000`.\n\n## Running Tests\n\n```bash\nnpm test\n```\n\nThe test suite uses Jest and React Testing Library and runs completely offline.\n\n## Project Structure\n- `src/` – React source files\n- `tests/` – Jest test files\n- `package.json` – Project metadata and scripts\n\n## License\nMIT
