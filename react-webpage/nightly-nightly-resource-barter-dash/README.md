# Resource Barter Dashboard\n\nAn interactive web dashboard that lets you input quantities of common post‑apocalyptic resources (food, water, ammo, medicine) and instantly see suggested fair trade ratios based on configurable weight values.\n\n## Usage\n\n```sh\nnpm install\nnpm start   # runs the development server at http://localhost:3000\nnpm test    # runs the unit tests\n```\n\n## How it works\n\nEach resource has a base weight (food=1, water=1, ammo=2, medicine=3). The app calculates the total weight of your inventory and suggests how many units of each resource you could trade for a single unit of another resource.\n\n## Customisation\n\nEdit `src/weights.js` to change the base weights.\n
