# Wasteland Emoji Clock\n\nA whimsical React web app that shows the current time using emojis. Useful for quick visual time checks in a post‑apocalyptic setting.\n\n## Features\n\n- Displays hours, minutes, seconds as clock‑face emojis.\n- Updates every second.\n- Fully offline, no external APIs.\n\n## Usage\n\n```sh\nnpm install\nnpm start\n```\n\nOpen `http://localhost:3000` to see the emoji clock.\n\n## Testing\n\n```sh\nnpm test\n```
