# nightly-emoji-mood-dashboard\n\n## Overview\n\n`nightly-emoji-mood-dashboard` is a tiny, self‑contained React web page that lets users record their current mood with three emoji buttons (😀, 😐, 😞).  Each click increments a counter that is persisted in the browser's `localStorage` and displayed live on the page.  No build step or server is required – just open `src/index.html` in a browser.\n\n## Features\n\n- **Zero‑install**: loads React and ReactDOM from a CDN.\n- **Persistent state**: counts survive page reloads via `localStorage`.\n- **Simple visualisation**: shows the current tally for each emoji.\n- **Testable core logic**: the pure function `updateCounts` is exported for Node tests.\n\n## How to run\n\n1. Open `src/index.html` in any modern browser.\n2. Click an emoji button – the count updates instantly.\n3. Reload the page – the counts are restored from `localStorage`.\n\n## Development & testing\n\nThe project ships with a minimal Node test harness that validates the pure JavaScript logic without needing a browser.  It runs with the standard `npm test` command.\n\n```bash\nnpm install\nnpm test\n```\n\nThe test suite lives in the `tests/` directory and uses only Node's built‑in `assert` module, so no extra dependencies are required.\n\n## Files\n\n- `src/index.html` – the HTML entry point loading React via CDN.\n- `src/app.js` – React component and helper functions.\n- `package.json` – npm metadata and test script.\n- `tests/` – Node tests for the core logic.\n\nEnjoy logging your moods!\n
