# Nightly Barter Board\n\nAn interactive React dashboard that lets a post‑apocalyptic community track items they have for barter, add new items, and record trades.\n\n## Features\n\n- View a list of available items with quantities.\n- Add new items via a simple form.\n- Record a trade (subtract quantities from both parties).\n- All data is stored in the browser's `localStorage`, so it persists across page reloads without a backend.\n\n## Getting Started\n\n```sh\nnpm install\nnpm start\n```\n\nOpen `http://localhost:3000` to view the board.\n\n## Running Tests\n\n```sh\nnpm test\n```\n\nThe test suite uses Jest and `ReactDOMServer` to verify that the main component renders correctly.\n\n## License\n\nMIT
