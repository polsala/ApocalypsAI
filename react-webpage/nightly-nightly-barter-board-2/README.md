Nightly Barter Board\nA whimsical web app that lets survivors list items they have and items they need, and matches potential trades locally. No backend, data stored in browser localStorage.\n\nUsage:\n1. Install dependencies: npm install\n2. Start dev server: npm run dev\n3. Open http://localhost:3000\n\nFeatures:\n- Add items you have\n- Add items you want\n- See matching pairs where someone else has what you want and wants what you have (simulated with same user data for demo)\n
