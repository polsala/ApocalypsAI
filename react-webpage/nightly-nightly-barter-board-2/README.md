# Nightly Barter Board\n\nA whimsical React web app for post‑apocalypse survivors to list items they have and need, and instantly see matching barter partners.\n\n## Features\n\n- Add items you have and items you need.\n- Real‑time matching: shows other users whose needs intersect with your offers.\n- Simple, offline‑first UI.\n\n## Usage\n\n```sh\nnpm install\nnpm start\n```\n\nOpen http://localhost:3000.\n\n## Testing\n\n```sh\nnpm test\n```
