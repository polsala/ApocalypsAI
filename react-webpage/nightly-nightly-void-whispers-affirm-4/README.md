# nightly-void-whispers-affirmations

A retro terminal-styled React app that delivers whimsical, cosmic affirmations to uplift your spirit in the digital void.

## Features

- Cosmic-themed affirmations
- Retro terminal UI
- Fully responsive design
- Lightweight and fast

## Usage

1. Clone the repo
2. Run `npm install`
3. Run `npm start`
4. Open [http://localhost:3000](http://localhost:3000) to view the app

## Testing

Run `npm test` to execute the test suite.
