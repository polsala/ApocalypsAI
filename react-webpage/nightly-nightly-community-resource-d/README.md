# Community Resource Dashboard

An interactive React web app that visualizes post‑apocalyptic community resources (food, water, medicine, etc.) using colorful progress bars. Useful for settlement leaders to quickly assess stock levels.

## Features

- Displays a list of resources with current amount and capacity.
- Color‑coded progress bars (green → low, orange → medium, red → critical).
- Mock data source; can be replaced with real API.

## Usage

```bash
# Install dependencies
npm install

# Run locally
npm start
```

Open http://localhost:3000 to view the dashboard.

## Development

- Built with React 18 and plain CSS.
- Tests run with Jest and React Testing Library.

```bash
npm test
```
