# Nightly Supply Dashboard\n\nA whimsical yet useful React web app that lets you track your post‑apocalypse supplies. Add items with quantities, see a running total, and visualize the distribution with a simple bar chart.\n\n## Features\n\n- Add, edit, and remove supply items\n- Live total quantity\n- Responsive bar chart (pure CSS)\n\n## Getting Started\n\n```bash\ngit clone <repo-url>\ncd utils/react-webpage/nightly-supply-dashboard\nnpm install\nnpm start   # opens http://localhost:3000\nnpm test    # runs the test suite\n```\n\n## Development\n\n- Built with React 18 and functional components.\n- No external API calls; all data lives in browser memory.\n\n## License\n\nMIT
