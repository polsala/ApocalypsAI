# Nightly Supply Dashboard\n\nA whimsical yet useful React web app that lets post‑apocalypse wanderers track their supplies. Add items with quantities and see a live bar‑chart visualization.\n\n## Features\n\n- Add supply items (name + quantity)\n- Real‑time bar chart using plain CSS\n- No external charting libraries\n\n## Getting Started\n\n```bash\nnpm install\nnpm start\n```\n\nOpen http://localhost:3000 to view.\n\n## Testing\n\n```bash\nnpm test\n```\n\nThe test suite uses Jest and React Testing Library and runs offline.
