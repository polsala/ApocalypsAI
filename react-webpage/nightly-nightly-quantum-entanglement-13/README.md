# Nightly Quantum Entanglement Simulator

A whimsical web-based quantum circuit simulator that visualizes quantum entanglement in real-time. Perfect for learning quantum computing concepts through interactive play!

## Features

- Drag-and-drop quantum gates
- Real-time entanglement visualization
- Bloch sphere representation
- Measurement simulation
- Educational tooltips
- Save/load circuit configurations

## Usage

1. Open `index.html` in any modern browser
2. Drag gates from the toolbox onto the circuit
3. Connect qubits to create entanglement
4. Click 'Measure' to see quantum collapse
5. Use 'Save' and 'Load' to preserve your experiments

## Educational Value

- Learn about quantum superposition
- Understand entanglement and quantum gates
- Visualize quantum state changes
- Experiment with measurement collapse

## Technologies

- Vanilla JavaScript (ES6+)
- HTML5 Canvas for visualization
- CSS Grid/Flexbox for layout
- No frameworks required
