# Nightly Barter Board\n\nA whimsical yet useful React web app that lets you keep track of items you have and items you need in a post‑apocalypse barter system. All data is stored locally in your browser via `localStorage`.\n\n## Features\n\n- Add items you have\n- Add items you need\n- View combined lists\n- Data persists across sessions\n\n## Usage\n\n1. Install dependencies: `npm install`\n2. Run the dev server: `npm start`\n3. Open `http://localhost:3000` in your browser\n\n## Build\n\n`npm run build` creates a static site in the `dist/` folder.\n\n## Test\n\n`npm test` runs the Jest test suite.\n
