# Nightly Quantum Entanglement Simulator

A whimsical web-based quantum entanglement simulator that lets you create, manipulate, and measure entangled particles in a beautiful interactive visualization.

## Features

- **Interactive Particle Creation**: Drag and drop to create entangled particle pairs
- **Quantum State Visualization**: Real-time visualization of particle spin states and entanglement
- **Measurement Tools**: Click particles to measure their state and observe wave function collapse
- **Entanglement Effects**: Watch as measuring one particle instantly affects its entangled partner
- **Educational Mode**: Learn about quantum mechanics concepts through interactive examples

## Usage

1. Open `index.html` in any modern web browser
2. Click 'Create Entangled Pair' to generate two linked particles
3. Drag particles around the canvas to position them
4. Click any particle to measure its state
5. Observe the instant correlation between entangled particles

## Educational Concepts Demonstrated

- Quantum superposition
- Wave function collapse
- Non-locality and entanglement
- Measurement problem in quantum mechanics

## Technical Details

Built with vanilla JavaScript and HTML5 Canvas for maximum compatibility. No frameworks required!

## Fun Facts

- In quantum mechanics, entangled particles remain connected such that the state of one instantly influences the other, regardless of distance
- This simulator demonstrates the 'spooky action at a distance' that Einstein famously questioned
- The colors represent different quantum states (spin up/down, polarization, etc.)
