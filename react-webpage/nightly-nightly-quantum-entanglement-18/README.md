# Nightly Quantum Entanglement Simulator

A whimsical web-based quantum circuit simulator that visualizes quantum entanglement in real-time. Perfect for learning quantum computing concepts or just watching spooky action at a distance!

## Features

- 🎮 Interactive quantum circuit builder
- 🌀 Real-time entanglement visualization
- 📊 Bloch sphere representation
- 🎨 Beautiful animations and particle effects
- 🧪 Educational tooltips and explanations
- 💾 Save and load circuit configurations

## Usage

1. Open `index.html` in any modern browser
2. Drag and drop quantum gates onto the circuit
3. Watch the entanglement visualization come to life
4. Use the measurement buttons to collapse the quantum state
5. Save your favorite circuits for later

## Quantum Gates Available

- **Hadamard (H)**: Creates superposition
- **Pauli-X (X)**: Quantum NOT gate
- **Pauli-Y (Y)**: Y-rotation gate
- **Pauli-Z (Z)**: Z-rotation gate
- **CNOT**: Creates entanglement between qubits
- **Phase (S)**: Adds phase to quantum state
- **T Gate**: π/4 phase rotation

## Educational Value

This simulator demonstrates:
- Quantum superposition
- Quantum entanglement
- Measurement collapse
- Quantum gate operations
- Bloch sphere representation

## Technical Details

Built with vanilla JavaScript and HTML5 Canvas for maximum compatibility. No frameworks required!
