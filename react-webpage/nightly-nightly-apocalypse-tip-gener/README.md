# Apocalypse Tip Generator\n\nA whimsical React web app that displays a random post‑apocalyptic survival tip. Click **New Tip** to get another one.\n\n## Install\n\n```sh\nnpm install\nnpm start\n```\n\n## Test\n\n```sh\nnpm test\n```\n\n## How it works\n\nThe app stores a static array of tips and shows one at a time. The **New Tip** button selects the next tip in the array (wrapping around). The component is fully tested with Jest and React Testing Library.\n
