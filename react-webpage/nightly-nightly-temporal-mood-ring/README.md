# Nightly Temporal Mood Ring

A whimsical React web application that visualizes the "mood" or "severity" of detected temporal anomalies. Ever wondered if the fabric of spacetime is feeling "Mild Ripples" or "Chronal Chaos!"? This utility provides a fun, color-coded interface to give you a quick glance at the temporal vibes.

## Features

*   **Dynamic Mood Display**: A central "Temporal Orb" changes color and displays a descriptive mood based on a simulated anomaly severity.
*   **Anomaly Scan Button**: Trigger a new scan to get an updated temporal mood.
*   **Severity Scale**: Understand the current temporal state from calm to chaotic.

## Installation

1.  **Navigate to the utility directory:**
    ```bash
    cd react-webpage/nightly-temporal-mood-ring
    ```
2.  **Install dependencies:**
    ```bash
    npm install
    # or
    yarn install
    ```

## Usage

1.  **Start the development server:**
    ```bash
    npm start
    # or
    yarn start
    ```
    This will open the application in your browser, usually at `http://localhost:3000`.

2.  **Interact with the Mood Ring:**
    Click the "Scan for Anomalies" button to generate a new temporal mood. Observe the orb's color and the displayed text change.

## Development

The project was bootstrapped with Create React App.

### Available Scripts

In the project directory, you can run:

*   `npm start`: Runs the app in the development mode.
*   `npm test`: Launches the test runner in the interactive watch mode.
*   `npm run build`: Builds the app for production to the `build` folder.

## How it Works (Whimsical Lore)

The Temporal Mood Ring doesn't actually detect real temporal anomalies (yet!). Instead, it simulates a "Temporal Anomaly Severity Index" (TASI) using a pseudo-random algorithm. Based on the TASI, it assigns a "mood" and a corresponding color to the Temporal Orb, allowing you to playfully gauge the current state of spacetime.
