# Survival Gear Dashboard\n\nA whimsical React web app that lets you catalog post‑apocalypse survival gear, view total weight, and see a simple list. Perfect for role‑playing games or actual prepper planning.\n\n## Features\n\n- Add gear items (name, weight in kg, durability rating)\n- See total weight calculated instantly\n- Simple, zero‑dependency UI (just React)\n\n## Usage\n\n```sh\nnpm install\nnpm start\n```\n\nOpen http://localhost:3000 to view.\n\n## Testing\n\n```sh\nnpm test\n```
