# Nightly Quantum Entanglement Simulator

A whimsical, interactive quantum circuit simulator that visualizes quantum entanglement in real-time. Perfect for learning quantum computing concepts through playful experimentation!

## Features

✨ Drag-and-drop quantum gates

🔮 Real-time entanglement visualization

🎲 Interactive qubit measurement

📊 Bloch sphere visualization

🎨 Beautiful quantum circuit animations

## Quick Start

1. Clone this repository
2. Navigate to the directory
3. Open `index.html` in your browser

## Usage

- **Add Gates**: Drag gates from the sidebar onto qubit lines
- **Entanglement**: Watch qubits become entangled with CNOT gates
- **Measure**: Click the measure button to observe quantum collapse
- **Reset**: Clear the circuit and start over

## Quantum Concepts Demonstrated

- Superposition
- Entanglement
- Measurement collapse
- Quantum gates (Hadamard, Pauli-X, CNOT)
