# Emoji Mood Dashboard\n\nA whimsical React web page that shows an emoji representing the current time of day and a random uplifting quote. Perfect for a quick mood boost while coding.\n\n## Features\n\n- Determines the current hour and selects an appropriate emoji (🌅 sunrise, ☀️ day, 🌆 evening, 🌙 night).\n- Shows a random quote from a curated list each time the page loads.\n- Fully client‑side, no external API calls.\n\n## Usage\n\n```bash\ngit clone <repo>\ncd nightly-emoji-mood-dashboard\nnpm install\nnpm start\n```\n\nOpen http://localhost:3000 in your browser.\n\n## Development\n\nRun tests:\n\n```bash\nnpm test\n```
