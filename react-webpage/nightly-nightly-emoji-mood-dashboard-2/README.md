# Emoji Mood Dashboard\n\nAn interactive React web page that shows a whimsical emoji representing the current time of day and a random uplifting quote. Perfect for a quick mood boost while coding in the apocalypse.\n\n## Features\n\n- Determines the time of day and displays a matching emoji.\n- Shows a random quote from a curated list.\n- Fully client‑side, no external API calls.\n\n## Usage\n\n```sh\nnpm install\nnpm start\n```\n\nOpen http://localhost:3000 to see the dashboard.\n\n## Testing\n\n```sh\nnpm test\n```\n\nThe tests mock the current time and random number to ensure deterministic output.
