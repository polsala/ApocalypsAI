# Nightly Emoji Shuffle Board\n\nA whimsical React web app that displays a grid of emojis which can be shuffled at the click of a button. Useful for quick mood boards, icebreakers, or just a fun distraction.\n\n## Usage\n\n1. **Install dependencies**\n   ```\n   npm install\n   ```\n2. **Run the development server**\n   ```\n   npm start\n   ```\n3. Open `http://localhost:3000` in your browser. Click the **Shuffle** button to randomize the emoji layout.\n\n## Files\n\n- `src/App.jsx` – Main React component implementing the emoji board.\n- `src/index.js` – Entry point that renders the app into the DOM.\n- `tests/App.test.jsx` – Jest + React Testing Library tests.\n\n## License\n\nMIT
