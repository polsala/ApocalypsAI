# Nightly Radiation Level Dashboard

A whimsical interactive React web app that lets you simulate post‑apocalyptic radiation levels. Move the slider to adjust the radiation level (0‑100) and watch the gauge change color and warning messages.

## Features

- Slider to set radiation level.
- Color‑coded gauge: green (0‑30), yellow (31‑70), red (71‑100).
- Dynamic warning text.
- Fully tested with Jest & React Testing Library.

## Development

```bash
npm install
npm run dev   # starts Vite dev server
npm test      # runs the test suite
```

## Build

```bash
npm run build
```
