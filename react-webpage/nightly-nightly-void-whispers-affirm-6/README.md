# nightly-void-whispers-affirmations

A whimsical React-based web app that delivers cosmic affirmations with a touch of the unknown. Perfect for those seeking a moment of levity and inspiration in their day.

## Features

- Cosmic-themed affirmations
- Responsive design
- Lightweight and fast

## Usage

1. Clone the repo
2. Run `npm install`
3. Run `npm start`
4. Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

## Testing

Run `npm test` to launch the test runner in interactive watch mode.

## Deployment

Run `npm run build` to create a production-ready build.
