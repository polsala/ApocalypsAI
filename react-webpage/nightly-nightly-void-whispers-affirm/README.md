# nightly-void-whispers-affirmations

A React-based web application that generates whimsical, post-apocalyptic affirmations to uplift and inspire in the darkest of times.

## Features

- Generates random uplifting affirmations
- Mysterious void-themed UI with dynamic background
- Fully responsive design
- Lightweight and fast

## Usage

1. Open `index.html` in a web browser
2. Click the "Whisper Another Truth" button to generate a new affirmation
3. Refresh the page for a new experience

## Development

To run locally:

```bash
npm install
npm start
```

## Build

To build for production:

```bash
npm run build
```

## Tests

Run tests with:

```bash
npm test
```
