# nightly-emoji-calendar

A lightweight React calendar that displays a deterministic emoji for each day of the month.

## Features

- Shows the current month with each day labeled by a unique emoji.
- Deterministic mapping: the emoji for a day is derived from the day number, so the same day always shows the same emoji.
- Simple to run locally with `npm install` and `npm start`.

## Installation

```bash
npm install
```

## Running

```bash
npm start
```

This will start a development server on `http://localhost:3000`.

## Building

```bash
npm run build
```

## Testing

```bash
npm test
```
