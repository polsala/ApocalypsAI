# nightly-void-whispers-dashboard

A whimsical React dashboard that visualizes temporal anomalies, survival metrics, and void whispers in real-time.

## Features

- Real-time anomaly tracking
- Survival metric visualization
- Void whisper sentiment analysis
- Responsive design

## Usage

1. Clone the repo
2. Run `npm install`
3. Run `npm start`
4. Open http://localhost:3000

## Mock Data

The dashboard uses mock data to simulate real-time updates. No external dependencies required.
