# Nightly Quantum Entanglement Simulator

A whimsical web-based quantum entanglement simulator that demonstrates the spooky action at a distance with interactive particle visualization.

## Features

- **Interactive Quantum Particles**: Drag and drop entangled particles to see their quantum states
- **Measurement Visualization**: Click particles to measure their spin and see instant correlation
- **Bell State Explorer**: Toggle between different quantum entanglement states
- **Spooky Action**: Watch as measuring one particle instantly affects its entangled partner
- **Educational Tool**: Learn about quantum mechanics in a fun, visual way

## Usage

1. Open `index.html` in any modern browser
2. Drag the entangled particles around the canvas
3. Click on a particle to measure its spin (up or down)
4. Observe how the measurement instantly affects its entangled partner
5. Use the controls to switch between different Bell states

## Technical Details

- Built with vanilla JavaScript and HTML5 Canvas
- No external dependencies
- Responsive design works on desktop and mobile
- Uses CSS-in-JS for styling
- Includes comprehensive unit tests

## Educational Value

This simulator demonstrates key quantum mechanics concepts:

- **Quantum Entanglement**: Particles that share a quantum state
- **Superposition**: Particles existing in multiple states until measured
- **Measurement Collapse**: How observation forces a definite state
- **Non-locality**: Instantaneous correlation regardless of distance
