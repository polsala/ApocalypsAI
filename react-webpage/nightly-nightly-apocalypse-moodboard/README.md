# Apocalypse Moodboard\n\nA tiny React web app that displays a daily "survival mood" with a whimsical phrase and matching background color. Refresh to get a new mood, or wait for the next day. Perfect for adding a splash of post‑apocalyptic optimism to your browser.\n\n## Usage\n\n```bash\nnpm install\nnpm start\n```\n\n## How it works\n\nThe app selects a mood based on the current date (YYYY‑MM‑DD) using a deterministic hash, ensuring the same mood is shown throughout the day for all users. The mood list is defined in `src/moodData.js`.\n\n## Testing\n\n```bash\nnpm test\n```\n\n## License\n\nMIT
