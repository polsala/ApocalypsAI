## Cosmic Journal

A whimsical web application for logging your thoughts and dreams, inspired by the vastness of the cosmos.

### Features

*   **Dream Weaver:** Log your dreams with descriptive fields.
*   **Thought Nebula:** Capture fleeting thoughts and ideas.
*   **Cosmic Inspiration:** Receive a daily dose of celestial wisdom.
*   **Stellar Search:** Easily find past entries.

### Technology Stack

*   **Frontend:** React
*   **Styling:** Basic CSS (can be expanded)

### Getting Started

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/polsala/ApocalypsAI.git
    cd ApocalypsAI/utils/nightly-cosmic-journal
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    ```

3.  **Start the development server:**
    ```bash
    npm start
    ```

    This will open the Cosmic Journal in your browser.

### Usage

Navigate through the different sections to log your dreams and thoughts. The "Cosmic Inspiration" section will provide a new quote each day.

### Testing

To run the tests, execute:

```bash
npm test
```
