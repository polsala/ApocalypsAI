A whimsical web application for logging thoughts and dreams, inspired by the cosmos.

## Features

*   **Dream Journaling**: Record your dreams with a starry background.
*   **Thought Log**: Jot down your daily musings.
*   **Cosmic Themes**: Choose from various celestial themes.
*   **Simple Interface**: Easy to use and navigate.

## Getting Started

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/polsala/ApocalypsAI.git
    cd ApocalypsAI
    ```

2.  **Navigate to the utility directory**:
    ```bash
    cd utils/nightly-cosmic-journal
    ```

3.  **Install dependencies**:
    ```bash
    npm install
    ```

4.  **Start the development server**:
    ```bash
    npm start
    ```

    This will open the Cosmic Journal in your browser.

## Usage

*   On the main page, you'll see two main sections: "Dream Journal" and "Thought Log".
*   Click the "Add Entry" button in either section to open a modal.
*   Enter your text, select a theme (for dreams), and click "Save".
*   Your entries will appear in the respective lists.

## Testing

To run the tests, execute:
