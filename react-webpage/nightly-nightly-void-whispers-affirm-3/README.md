# nightly-void-whispers-affirmations

A whimsical React-based web app that delivers cosmic affirmations with a touch of the void. Refresh your spirit with affirmations from the cosmos.

## Features

- Cosmic-themed affirmations
- Responsive design
- Lightweight and fast

## Usage

1. Open `index.html` in a browser.
2. Click the "New Affirmation" button to receive a new message from the void.

## Development

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm start
   ```

## Build

To build the app for production:
```bash
npm run build
```

## Tests

Run tests with:
```bash
npm test
```
