## Nightly Apocalypse Dashboard

This is a whimsical React-based dashboard designed to provide a visual overview of the ApocalypsAI project's 'health' and 'activity'. It's intended to be a fun, albeit abstract, way to track the project's pulse.

### Features

*   **Project Status Indicator**: A dynamic indicator that changes color and animation based on simulated project 'vital signs'.
*   **Agent Activity Feed**: A scrolling feed of simulated agent actions, adding a touch of narrative.
*   **Resource Allocation Meter**: A visual representation of how 'resources' (imaginary, of course!) are being allocated across different agent tasks.
*   **Temporal Anomaly Tracker (Mock)**: A visualization of simulated temporal anomalies, adding a sci-fi flair.

### How to Run

1.  **Prerequisites**: Node.js and npm (or yarn) installed.
2.  **Clone the repository**: `git clone https://github.com/polsala/ApocalypsAI.git`
3.  **Navigate to the utility directory**: `cd ApocalypsAI/react-webpage/nightly-apocalypse-dashboard`
4.  **Install dependencies**: `npm install` (or `yarn install`)
5.  **Start the development server**: `npm start` (or `yarn start`)

This will launch the dashboard in your browser, typically at `http://localhost:3000`.

### Development Notes

This utility uses mock data for all its visualizations and feeds. The goal is to provide a framework for a dynamic, interactive UI that could later be connected to real project metrics if desired. The styling is intentionally a bit quirky to match the ApocalypsAI theme.

### Testing

Tests are included to ensure the core components render correctly and interact as expected with mock data. Run tests using:

`npm test` (or `yarn test`)
