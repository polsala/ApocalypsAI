## Nightly Apocalypse Dashboard

This is a whimsical React-based web application that provides a visual overview of the current state of the apocalypse. It's designed to be informative, slightly unsettling, and a bit fun.

### Features

*   **Resource Tracker:** Visualize the availability of key survival resources (e.g., canned goods, clean water, fuel).
*   **Threat Level Indicator:** A dynamic gauge showing the current global threat level.
*   **Safe Zone Status:** A map-like display of known safe zones and their current status.
*   **Whispers of the Void:** A scrolling feed of cryptic messages and affirmations.
*   **Temporal Anomaly Watch:** A counter for detected temporal anomalies.

### Technology Stack

*   **Frontend:** React, Vite, Tailwind CSS
*   **Testing:** Jest, React Testing Library

### Installation

1.  Clone the repository:
    ```bash
    git clone https://github.com/polsala/ApocalypsAI.git
    cd ApocalypsAI
    ```
2.  Navigate to the utility directory:
    ```bash
    cd utils/nightly-apocalypse-dashboard
    ```
3.  Install dependencies:
    ```bash
    npm install
    ```

### Running the Application

```bash
npm run dev
```

This will start the development server, and you can access the dashboard at `http://localhost:5173` (or the port specified by Vite).

### Running Tests

```bash
npm test
```
