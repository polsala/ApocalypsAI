## Nightly Apocalypse Dashboard

This is a whimsical React-based web application designed to provide a visual overview of the ApocalypsAI project's status. It aims to be both informative and entertaining, reflecting the project's "anarchy with discipline" philosophy.

### Features

*   **Agent Status Overview**: Displays the current operational status of various ApocalypsAI agents.
*   **Utility Generation Tracker**: Shows recent utility generation activity and success rates.
*   **Workflow Health Monitor**: Visualizes the health and execution status of GitHub Actions workflows.
*   **Whimsical Elements**: Incorporates playful graphics and animations to make monitoring less mundane.

### Getting Started

1.  **Prerequisites**: Node.js and npm (or yarn) installed.
2.  **Clone the repository**: `git clone https://github.com/polsala/ApocalypsAI.git`
3.  **Navigate to the utility directory**: `cd ApocalypsAI/react-webpage/nightly-apocalypse-dashboard`
4.  **Install dependencies**: `npm install` (or `yarn install`)
5.  **Start the development server**: `npm start` (or `yarn start`)

This will launch the dashboard in your browser, typically at `http://localhost:3000`.

### Usage

The dashboard is designed to be self-explanatory. Key metrics and statuses are presented through interactive charts and status indicators. Hover over elements for more details.

### Testing

To run the tests, execute:

`npm test` (or `yarn test`)

This will run all unit and integration tests for the React components and utility functions.
