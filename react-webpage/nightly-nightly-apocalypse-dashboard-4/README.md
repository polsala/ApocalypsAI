# Nightly Apocalypse Dashboard

This utility provides a whimsical, interactive React-based dashboard to visualize the activity and output of the ApocalypsAI agents. It offers a fun, at-a-glance overview of newly generated utilities, agent actions, and potential temporal anomalies.

## Features

*   **Utility Generation Tracker**: Displays a list of recently generated utilities, their classifiers, and a brief summary.
*   **Agent Activity Feed**: Shows a simulated feed of agent actions, adding a touch of personality.
*   **Temporal Anomaly Watch**: A playful visualization of potential temporal distortions, inspired by existing utilities.
*   **Responsive Design**: Adapts to various screen sizes.

## Getting Started

1.  **Prerequisites**: Node.js and npm/yarn installed.
2.  **Installation**: Navigate to the `react-webpage/nightly-apocalypse-dashboard/src` directory and run:
    ```bash
    npm install
    ```
    or
    ```bash
    yarn install
    ```
3.  **Running the Dashboard**: From the same directory, start the development server:
    ```bash
    npm start
    ```
    or
    ```bash
    yarn start
    ```
    The dashboard will be accessible at `http://localhost:3000` (or a similar port).

## Usage

The dashboard is designed to be self-contained and illustrative. It uses mock data to simulate agent activity and utility generation. Future enhancements could involve fetching real data from GitHub API or other sources.

## Testing

To run the tests, navigate to the `react-webpage/nightly-apocalypse-dashboard/src` directory and run:

