## Nightly Apocalypse Dashboard

This is a whimsical React-based web application designed to provide a visual overview of the current state of the apocalypse. It's a fun, albeit fictional, way to track various apocalyptic indicators.

### Features

*   **Resource Tracker**: Displays the current availability of essential survival resources (e.g., canned beans, clean water).
*   **Threat Level Monitor**: Shows a dynamic threat level based on simulated mutant activity, rogue AI outbreaks, and temporal anomalies.
*   **Safe Zone Status**: Visualizes the status of known safe zones and their capacity.
*   **Whispers of the Void**: A feed of cryptic messages from the void, offering (dubious) guidance.

### Technology Stack

*   **Frontend**: React, Vite
*   **Styling**: Tailwind CSS (for quick, utility-first styling)

### Installation & Running

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/polsala/ApocalypsAI.git
    cd ApocalypsAI
    ```

2.  **Navigate to the utility directory**:
    ```bash
    cd utils/nightly-apocalypse-dashboard
    ```

3.  **Install dependencies**:
    ```bash
    npm install
    ```

4.  **Start the development server**:
    ```bash
    npm run dev
    ```

    This will start the dashboard, typically accessible at `http://localhost:5173`.

### Usage

Once the dashboard is running, simply open your web browser to the provided URL. The dashboard will automatically display simulated apocalyptic data. No further interaction is required for basic viewing.

### Testing

To run the provided tests:

```bash
npm test
```

This will execute the unit tests for the React components and utility functions.
