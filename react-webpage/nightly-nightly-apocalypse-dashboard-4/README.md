A whimsical React dashboard to visualize the state of the ApocalypsAI project.

## Features

*   **Agent Status Overview**: See the current status of various ApocalypsAI agents.
*   **Utility Count Tracker**: Monitor the number of utilities generated across different classifiers.
*   **Workflow Health Indicator**: A fun, visual representation of the health of GitHub workflows.
*   **Resource Scarcity Meter**: A playful gauge showing the perceived scarcity of development resources (e.g., compute time, API tokens).

## Getting Started

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/polsala/ApocalypsAI.git
    cd ApocalypsAI
    ```

2.  **Navigate to the utility directory**:
    ```bash
    cd utils/nightly-apocalypse-dashboard
    ```

3.  **Install dependencies**:
    ```bash
    npm install
    ```

4.  **Start the development server**:
    ```bash
    npm start
    ```

    The dashboard will be accessible at `http://localhost:3000`.
