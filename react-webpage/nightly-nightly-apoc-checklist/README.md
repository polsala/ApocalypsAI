# Apocalypse Checklist Dashboard\n\nAn interactive React web app that lets you manage a survival checklist, mark items as completed, and see progress.\n\n## Features\n\n- Add, edit, delete checklist items\n- Toggle completion status\n- Visual progress bar\n- Persist state in `localStorage`\n\n## Usage\n\n```bash\nnpm install\nnpm start\n```\n\nOpen `http://localhost:3000` in your browser.\n\n## Development\n\nRun the test suite with:\n\n```bash\nnpm test\n```\n\n## License\n\nMIT
