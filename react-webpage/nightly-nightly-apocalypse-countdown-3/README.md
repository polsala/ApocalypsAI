# Nightly Apocalypse Countdown\n\nA tiny React web app that displays a countdown to a far‑future apocalypse date (2099‑12‑31) and shows a random whimsical omen each time the page loads or updates hourly.\n\n## Features\n\n- Live countdown in days (updates every hour)\n- Random daily omen chosen from a curated list\n- Pure client‑side; no backend required\n- Simple `npm start` development server\n\n## Getting Started\n\n1. **Install Node.js** (>= 18) if you don't have it.\n2. Clone the repository and navigate to this utility's folder.\n3. Install dependencies:\n   ```bash\n   npm install\n   ```\n4. Run the development server:\n   ```bash\n   npm start\n   ```\n   The app will be available at `http://localhost:8080`.\n\n5. To run the deterministic test suite (offline):\n   ```bash\n   npm test\n   ```\n\n## Project Structure\n\n- `src/` – React source files\n- `src/countdown.js` – Core logic that computes days left and selects an omen\n- `src/App.jsx` – Main React component\n- `src/index.jsx` – Entry point that mounts the app\n- `tests/` – Node test for the core logic\n- `package.json` – npm scripts and dependencies\n\n## License\n\nThis utility is released under the MIT License.\n
