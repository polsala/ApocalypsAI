# Wasteland Weather Dashboard\n\nA whimsical React dashboard that displays fictional post‑apocalyptic weather forecasts for various wasteland locations. Great for role‑playing games, storytelling, or just a fun break.\n\n## Features\n\n- Fixed list of locations with quirky weather descriptions.\n- Responsive layout using plain CSS.\n- No external API calls – works completely offline.\n\n## Usage\n\n```bash\nnpm install\nnpm start\n```\n\nOpen http://localhost:3000 to view the dashboard.\n\n## Testing\n\n```bash\nnpm test\n```
