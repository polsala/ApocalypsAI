# Wasteland Weather Dashboard\n\nAn interactive React web app that serves random post‑apocalyptic weather forecasts.\n\n## Features\n- Generates a whimsical forecast from a curated list of wasteland‑themed conditions.\n- Click **Refresh Forecast** to get a new prediction.\n- Built with React 18 and TypeScript.\n\n## Getting Started\n\n```bash\n# Clone the repository (or copy the generated folder)\ngit clone <repo-url>\ncd nightly-wasteland-weather\n\n# Install dependencies\nnpm install\n\n# Run the development server\nnpm run start\n\n# Open http://localhost:5173 in your browser.\n```\n\n## Running Tests\n\n```bash\nnpm run test\n```\n\nThe test suite uses Jest and React Testing Library to verify that the forecast updates correctly when the button is clicked.\n\n## Project Structure\n- `src/` – React source files.\n- `tests/` – Jest test files.\n- `package.json` – Scripts and dependencies.\n\nEnjoy the chaotic climate of the wasteland!\n
