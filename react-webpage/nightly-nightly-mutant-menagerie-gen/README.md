# Mutant Menagerie Generator

Create custom post-apocalyptic animal companions by mixing traits like glowing eyes, radiation resistance, and mechanical limbs. Export your creations as shareable JSON cards!

## Features
- Interactive trait mixer
- Random mutation generator
- Export/share companion profiles

## Usage
1. Select traits from the sidebar
2. Adjust mutation intensity slider
3. Click 'Generate' to create your mutant
4. Use the export button to save/share
