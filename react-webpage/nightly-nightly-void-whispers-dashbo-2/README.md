# nightly-void-whispers-dashboard

A whimsical React dashboard that visualizes temporal anomalies, survival skill progress, and wasteland resource trends.

## Features

- Real-time anomaly graphs
- Survival skill radar charts
- Resource tracker heatmap
- Void whisper affirmations ticker

## Usage

```bash
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000) to view the dashboard.

## Tests

```bash
npm test
```
