# Nightly Quantum Entanglement Checker

A whimsical web-based tool that simulates quantum entanglement verification with real-time visualization and educational explanations.

## Features

- **Real-time Entanglement Simulation**: Watch particles interact in a beautiful visualization
- **Educational Mode**: Learn about quantum mechanics concepts with interactive explanations
- **Measurement Tools**: Simulate quantum measurements and observe wave function collapse
- **Bell State Explorer**: Explore different quantum states and their properties
- **Entanglement Metrics**: Track entanglement quality and coherence over time

## Usage

1. Open `index.html` in any modern browser
2. Click "Initialize Entanglement" to create a pair of entangled particles
3. Use the measurement tools to observe quantum behavior
4. Toggle educational mode for detailed explanations

## Technologies

- React 18
- D3.js for visualizations
- CSS Grid/Flexbox for responsive layout
- Vanilla JavaScript for quantum simulation

## Educational Concepts Covered

- Superposition
- Wave function collapse
- Bell states
- Quantum decoherence
- Measurement problem
- Entanglement swapping
