## Nightly Chrono Echo Tracker

A whimsical React dashboard that visualizes temporal anomalies and echoes across different time zones. Perfect for monitoring temporal distortions in your post-apocalyptic world.

### Features
- Real-time temporal anomaly detection
- Interactive timeline visualization
- Multi-timezone echo tracking
- Whimsical animations and sound effects

### Installation
```bash
npm install
npm start
```

### Usage
1. Open the dashboard in your browser
2. Select your preferred time zone
3. Watch as temporal echoes appear on the timeline
4. Click on anomalies to get detailed information

### Technologies Used
- React
- D3.js for visualizations
- Web Audio API for sound effects
- CSS animations
