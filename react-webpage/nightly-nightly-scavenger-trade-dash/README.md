# Scavenger Trade Dashboard\n\nA whimsical React web app that lets you input quantities of scavenged items and instantly see the total trade value based on rarity‑adjusted pricing. Perfect for community barter events in a post‑apocalyptic setting.\n\n## Features\n\n- Pre‑defined list of common scavenged items with rarity multipliers.\n- Live calculation of total value as you edit quantities.\n- Responsive table view.\n\n## Usage\n\n```bash\nnpm install\nnpm run start   # launches at http://localhost:3000\nnpm test        # runs the Jest/React Testing Library suite\n```\n\n## Adding Items\n\nEdit `src/data/items.ts` to add new items with `name`, `baseValue`, and `rarity`.\n\n## License\n\nMIT
