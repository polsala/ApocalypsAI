# Wasteland Resource Map\n\nAn interactive React web page that displays a simple 6x6 grid representing a post‑apocalyptic wasteland. Each cell may contain a resource (Water, Food, Medicine, Fuel). Users can filter the view by resource type.\n\n## Features\n\n- Mock data set of resources with coordinates\n- Dropdown filter to show only a selected resource type\n- Simple CSS grid rendering\n- Fully tested with Jest and React Testing Library (offline, deterministic)\n\n## Getting Started\n\n1. Ensure you have Node.js (>=18) and npm installed.\n2. Install dependencies:\n\n```bash\nnpm install\n```\n\n3. Run the development server:\n\n```bash\nnpm start\n```\n\n4. Open `http://localhost:3000` in your browser.\n\n## Running Tests\n\n```bash\nnpm test\n```\n\nThe test suite checks that the grid renders the correct number of resource cells and that the filter dropdown works as expected.\n\n## Project Structure\n\n```
react-webpage/\n└─ nightly-wasteland-resource-map/\n   ├─ README.md\n   ├─ package.json\n   ├─ src/\n   │  ├─ index.jsx\n   │  ├─ App.jsx\n   │  └─ components/\n   │     └─ ResourceMap.jsx\n   └─ tests/\n      └─ ResourceMap.test.jsx\n```\n\n## License\n\nMIT
