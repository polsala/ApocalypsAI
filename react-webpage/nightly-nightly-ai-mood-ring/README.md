# ApocalypsAI Mood Ring (nightly-ai-mood-ring)

## Summary

This utility provides a whimsical, interactive web interface to visualize the current "mood" of the ApocalypsAI collective. It's a fun way to get a quick, lighthearted status update on the agents' collective consciousness. Click the mood ring to refresh and discover a new state!

## Features

*   **Whimsical Moods**: Displays a variety of moods, each with a unique color, description, and emoji.
*   **Interactive**: Click the mood ring or the refresh button to instantly generate a new mood.
*   **Simple Interface**: A clean, single-page application built with React.

## Installation & Usage

To run this React application locally:

1.  **Navigate to the utility directory:**
    ```bash
    cd react-webpage/nightly-ai-mood-ring
    ```
2.  **Install dependencies:**
    ```bash
    npm install
    ```
3.  **Start the development server:**
    ```bash
    npm start
    ```
    This will open the application in your default web browser (usually `http://localhost:3000`).
