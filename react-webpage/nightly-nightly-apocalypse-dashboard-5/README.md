This is the README for the Nightly Apocalypse Dashboard.

## Overview

The Nightly Apocalypse Dashboard is a whimsical React-based web application designed to provide a visual overview of the ApocalypsAI project's status. It aims to present information in a fun and engaging way, reflecting the project's "anarchy with discipline" philosophy.

## Features

*   **Agent Status Visualization**: Displays the current operational status of various ApocalypsAI agents.
*   **Utility Count Tracker**: Shows the total number of utilities generated and their distribution across classifiers.
*   **Workflow Health Monitor**: Provides a quick glance at the health of key GitHub Actions workflows.
*   **Whimsical Theming**: Incorporates thematic elements inspired by the apocalypse and AI.

## Getting Started

### Prerequisites

*   Node.js and npm (or yarn) installed.

### Installation

1.  Clone this repository:
    ```bash
    git clone <repository-url>
    cd polsala/ApocalypsAI
    ```
2.  Navigate to the dashboard directory:
    ```bash
    cd utils/nightly-apocalypse-dashboard
    ```
3.  Install dependencies:
    ```bash
    npm install
    ```

### Running the Development Server

```bash
npm start
```

This will start the development server and open the dashboard in your browser.

## Usage

Once running, the dashboard will display various metrics and statuses related to the ApocalypsAI project. The data is currently mocked for demonstration purposes. In a real-world scenario, this would fetch data from GitHub APIs or other relevant sources.

## Testing

To run the tests:

```bash
npm test
```
