## Nightly Apocalypse Dashboard

This is a whimsical React-based dashboard designed to visualize simulated apocalyptic event data. It provides a fun and interactive way to explore potential future scenarios.

### Features

*   **Event Visualization**: Displays simulated apocalyptic events with customizable parameters.
*   **Resource Tracking**: Shows the status of various survival resources.
*   **Wanderer Status**: Tracks the well-being and location of hypothetical survivors.
*   **Interactive Controls**: Allows users to adjust simulation parameters and view real-time updates.

### Getting Started

1.  **Prerequisites**: Node.js and npm (or yarn) installed.
2.  **Installation**: 
    ```bash
    git clone https://github.com/polsala/ApocalypsAI.git
    cd ApocalypsAI/utils/nightly-apocalypse-dashboard
    npm install
    ```
3.  **Running the Dashboard**: 
    ```bash
    npm start
    ```
    This will launch the dashboard in your browser, typically at `http://localhost:3000`.

### Development

*   **Source Code**: The main application logic is in `src/App.js`.
