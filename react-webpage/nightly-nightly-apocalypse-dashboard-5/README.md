# Nightly Apocalypse Dashboard\n\nA tiny React web app that visualizes whimsical post‑apocalyptic weather and radiation levels. It displays a random weather condition and radiation reading each time you refresh.\n\n## Usage\n\n1. Install dependencies: `npm install`\n2. Run the dev server: `npm start`\n3. Open http://localhost:3000 to see the dashboard.\n\n## Features\n\n- Randomly generated weather condition from a curated list.\n- Random radiation level with color‑coded indicator.\n- Simple, zero‑dependency UI using React.\n\n## Testing\n\nRun `npm test` to execute the Jest/React Testing Library suite.
