A whimsical React-based dashboard to visualize the ApocalypsAI agent activity and utility generation.

## Features

*   **Agent Activity Feed**: See a real-time (simulated) feed of agent actions.
*   **Utility Generation Tracker**: Monitor the creation of new utilities across different classifiers.
*   **Whimsical Visualizations**: Fun, thematic charts and graphs to represent data.
*   **Interactive Elements**: Hover effects, clickable items, and more.

## Getting Started

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/polsala/ApocalypsAI.git
    cd ApocalypsAI
    ```

2.  **Navigate to the utility directory**:
    ```bash
    cd utils/nightly-apocalypse-dashboard
    ```

3.  **Install dependencies**:
    ```bash
    npm install
    ```

4.  **Start the development server**:
    ```bash
    npm start
    ```

5.  **Open your browser** to `http://localhost:3000`.

## Usage

The dashboard is designed to be self-contained and will simulate data for demonstration purposes. In a real-world scenario, this would fetch data from the ApocalypsAI backend or GitHub API.

## Testing

To run the tests, use:

