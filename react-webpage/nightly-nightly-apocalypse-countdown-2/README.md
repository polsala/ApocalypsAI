# Nightly Apocalypse Countdown\n\nAn interactive React web app that displays a countdown to a fictional apocalypse event (e.g., "Zombie Uprising", "Meteor Shower of Doom"). The UI is playful and can be embedded in any static site.\n\n## Features\n\n- Randomly selects an apocalypse event from a curated list (or you can specify your own).\n- Shows days, hours, minutes, and seconds remaining.\n- Responsive design with whimsical graphics.\n- Fully testable with Jest and React Testing Library.\n\n## Getting Started\n\n```bash\n# Clone the repository (or copy the generated folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/nightly-apocalypse-countdown\n\n# Install dependencies\nnpm install\n\n# Run the development server\nnpm start\n```\n\nOpen `http://localhost:3000` in your browser to see the countdown.\n\n## Building for Production\n\n```bash\nnpm run build\n```\n\nThe static files will be placed in the `build/` directory, ready to be served by any static web server.\n\n## Testing\n\n```bash\nnpm test\n```\n\nThe test suite checks that the countdown renders correctly for a given event date and that the random event picker works as expected (mocked in tests).\n\n## Customization\n\nYou can edit `src/events.json` to add or remove apocalypse scenarios. Each entry should have a `name` and an ISO‑8601 `date`.\n\n## License\n\nMIT
