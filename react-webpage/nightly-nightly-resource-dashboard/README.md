# Nightly Resource Dashboard\n\nAn interactive React dashboard that shows a list of post‑apocalyptic resources with randomly assigned scarcity levels. Press **Reshuffle** to generate a new random distribution.\n\n## Install\n\n```sh\nnpm install\n```\n\n## Run\n\n```sh\nnpm start\n```\n\n## Test\n\n```sh\nnpm test\n```\n\n## How it works\n\nThe app defines a static array of resource names. On each render it pairs each name with a random scarcity level (Low, Medium, High). The UI displays each resource with a colored bar: green for Low, orange for Medium, red for High.
