# nightly-apoc-weather\n\nA whimsical React web app that generates random post‑apocalypse weather forecasts.\n\n## Features\n\n- Click a button to generate a new forecast.\n- Each forecast includes an emoji, a short description, and a temperature range.\n- Fully offline – no external API calls.\n\n## Development\n\n```bash\nnpm install\nnpm start\n```\n\n## Testing\n\n```bash\nnpm test\n```
