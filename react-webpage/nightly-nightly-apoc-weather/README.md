# Nightly Apoc Weather\n\nA whimsical React dashboard that generates post‑apocalyptic weather forecasts with matching mood emojis. Click "Generate" to see a new forecast.\n\n## How to run\n\n```bash\nnpm install\nnpm start\n```\n\n## Testing\n\n```bash\nnpm test\n```\n\n## Features\n\n- Randomly picks a weather condition from a curated list.\n- Associates each condition with a mood emoji.\n- Simple, zero‑dependency UI.\n
