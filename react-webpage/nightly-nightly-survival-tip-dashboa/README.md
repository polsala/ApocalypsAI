# Nightly Survival Tip Dashboard\n\nAn interactive React web page that displays a random post‑apocalypse survival tip. Click **New Tip** to get another whimsical suggestion.\n\n## Install\n\n```sh\nnpm install\n```\n\n## Run\n\n```sh\nnpm start\n```\n\nOpens `http://localhost:3000` in your browser.\n\n## Test\n\n```sh\nnpm test\n```\n\n## How it works\n\nThe app keeps a list of tips and picks one at random on load and when the button is pressed.\n
