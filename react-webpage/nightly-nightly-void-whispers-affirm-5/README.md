# nightly-void-whispers-affirmations

A whimsical React-based web app that delivers randomized affirmations with a post-apocalyptic twist.

## Features

- Displays a randomly selected affirmation on each visit or click
- Post-apocalyptic themed messages for emotional resilience
- Fully responsive design
- Lightweight and fast

## Usage

1. Open `index.html` in your browser.
2. Click the "New Affirmation" button to get a new message.

## Development

To run the development server:

```bash
npm install
npm start
```

## Build

To build the static site:

```bash
npm run build
```
