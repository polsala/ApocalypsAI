# Nightly Barter Board\n\nA tiny React web application that lets you record what you have and what you need in a post‑apocalypse setting.\n\n## Features\n- Add offers consisting of a "have" item and a "need" item.\n- View a live list of all offers.\n- Pure client‑side – no backend required.\n\n## Getting Started\n\n1. **Install dependencies**\n\n```bash\nnpm install\n```\n\n2. **Run the development server**\n\n```bash\nnpm start\n```\n\n   The app will be available at `http://localhost:3000`.\n\n3. **Run the tests**\n\n```bash\nnpm test\n```\n\n## How It Works\nThe app is a single `App` component that maintains an array of offers in React state. Each offer records a `have` string and a `need` string. Adding an offer updates the state, which re‑renders the list.\n\n## License\nMIT – see the repository LICENSE file.
