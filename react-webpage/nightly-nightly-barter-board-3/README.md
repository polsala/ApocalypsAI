# Nightly Barter Board\n\nA whimsical React web app that helps post‑apocalyptic survivors barter items. Users can list items they have and items they want; the app instantly shows potential matches.\n\n## Features\n\n- Add items with "have" or "want" status\n- Live matching list showing complementary offers\n- Simple, zero‑dependency UI (uses React)\n\n## Development\n\n```bash\nnpm install\nnpm start\n```\n\n## Testing\n\n```bash\nnpm test\n```
