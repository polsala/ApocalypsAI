# Nightly Barter Board\n\nA whimsical post‑apocalyptic barter board built with React and TypeScript. Users can list items they have and items they want, and see matching offers.\n\n## Usage\n\n```bash\nnpm install\nnpm start\n```\n\nOpen `http://localhost:3000` in your browser.\n\n## Development\n\nRun the test suite with:\n\n```bash\nnpm test\n```\n\nThe app is intentionally tiny but demonstrates state handling, forms, and list rendering in a fun setting.
