# Nightly Barter Board\n\nA tiny React web app for tracking barter items in a post‑apocalyptic setting.\n\n## Features\n\n- Add items with a name and a numeric value (e.g., "Canned Beans" – 5)\n- View a live list of items\n- See the total barter value\n- Data persisted in `localStorage` so it survives page reloads\n\n## Getting Started\n\n```bash\n# Clone the repository (or copy the generated folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/react-webpage/nightly-barter-board\n\n# Install dependencies\nnpm install\n\n# Run the development server\nnpm start\n```\n\nOpen your browser at `http://localhost:3000` to use the app.\n\n## Running Tests\n\n```bash\nnpm test\n```\n\nThe test suite uses **Jest** and **React Testing Library** to verify core functionality.\n\n## Project Structure\n\n- `src/` – React source files\n- `public/` – Static HTML template\n- `tests/` – Jest test files\n- `package.json` – Project metadata and scripts\n\nEnjoy bartering!\n
