# Nightly Barter Board\n\nA whimsical React web app that lets post‑apocalyptic survivors list items they have and need, automatically matching barter opportunities.\n\n## Features\n\n- Add items you have and items you need.\n- Automatic matching: when another entry satisfies both sides, a match appears.\n- Simple, offline‑first UI – no backend required.\n\n## Development\n\n```sh\nnpm install\nnpm start\n```\n\nOpen http://localhost:3000.\n\n## Testing\n\n```sh\nnpm test\n```
