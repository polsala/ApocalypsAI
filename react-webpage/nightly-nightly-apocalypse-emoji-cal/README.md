# Apocalypse Emoji Calendar\n\nAn interactive React web page that displays a whimsical apocalypse‑themed emoji for each day of the current month. Perfect for adding a touch of fun to your daily stand‑up or terminal dashboard.\n\n## Features\n\n- Generates a deterministic emoji per date (same date → same emoji)\n- Simple, zero‑dependency React app\n- Responsive grid layout\n- Includes Jest + React Testing Library tests\n\n## Usage\n\n```sh\n# Install dependencies\nnpm install\n\n# Run the development server\nnpm start\n```\n\nOpen http://localhost:3000 to see the calendar.\n\n## Build\n\n```sh\nnpm run build\n```\n\nThe static files will be placed in `build/`.\n\n## License\n\nMIT
