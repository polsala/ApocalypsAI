# Nightly Quantum Entanglement Simulator

A whimsical web-based quantum circuit simulator that visualizes quantum entanglement and measurement collapse with animated particle effects.

## Features

- **Interactive Quantum Circuit Builder**: Drag-and-drop quantum gates to build circuits
- **Entanglement Visualization**: See qubits become entangled with glowing connections
- **Measurement Collapse Animation**: Watch quantum states collapse in real-time
- **Bell State Demonstrator**: Pre-built circuits showing famous quantum phenomena
- **Educational Tool**: Learn quantum computing concepts through visualization

## Usage

1. Open `index.html` in any modern browser
2. Drag quantum gates from the toolbox onto the circuit grid
3. Connect gates to qubits to build your quantum circuit
4. Click 'Simulate' to see the quantum state evolution
5. Use 'Measure' to collapse the quantum state and see the results

## Quantum Gates Available

- **Hadamard (H)**: Creates superposition
- **Pauli-X (X)**: Quantum NOT gate
- **Pauli-Y (Y)**: Y-axis rotation
- **Pauli-Z (Z)**: Z-axis rotation
- **CNOT**: Creates entanglement between qubits
- **Phase (S)**: Adds phase to quantum state
- **T Gate**: π/4 phase rotation

## Educational Examples

- **Bell State**: Create maximally entangled qubits
- **Quantum Teleportation**: Simulate quantum information transfer
- **Superposition Demo**: See single qubit in superposition
- **Measurement Paradox**: Observe wave function collapse

## Technical Details

Built with vanilla JavaScript and HTML5 Canvas for smooth animations. No frameworks required - just pure web technology!
