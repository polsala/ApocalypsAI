# Survival Gear Planner

An interactive React web app that lets you pick post‑apocalyptic gear items and instantly see the total weight of your loadout. Perfect for planning your wanderer’s backpack before the next rift.

## Features

- List of common survival items with predefined weight.
- Click to select/deselect items.
- Real‑time total weight calculation.
- Fully offline – no external API calls.

## Development

```bash
npm install
npm start   # runs the development server at http://localhost:3000
npm test    # runs the Jest test suite
```

## Build

```bash
npm run build   # creates a static bundle in the build/ folder
```
