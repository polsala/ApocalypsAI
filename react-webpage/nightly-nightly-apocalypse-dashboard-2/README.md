# ApocalypsAI Dashboard

This is a whimsical React-based dashboard designed to provide a visual overview of the ApocalypsAI project's activity. It aims to display key metrics and recent events in a fun and engaging way, reflecting the project's "anarchy with discipline" philosophy.

## Features

*   **Agent Activity Feed**: Displays recent actions taken by different ApocalypsAI agents.
*   **Utility Generation Tracker**: Shows the rate and types of new utilities being generated.
*   **Workflow Status Overview**: A high-level view of GitHub Actions workflow statuses.
*   **Whimsical Visualizations**: Uses fun graphics and animations to represent data.

## Getting Started

### Prerequisites

*   Node.js and npm (or yarn) installed.

### Installation

1.  Clone the repository:
    ```bash
    git clone https://github.com/polsala/ApocalypsAI.git
    cd ApocalypsAI
    ```

2.  Navigate to the dashboard directory:
    ```bash
    cd utils/nightly-apocalypse-dashboard/react-app
    ```

3.  Install dependencies:
    ```bash
    npm install
    # or
    yarn install
    ```

### Running the Development Server

```bash
npm start
# or
yarn start
```

This will start the development server and open the dashboard in your browser, usually at `http://localhost:3000`.

## Building for Production

```bash
npm run build
# or
yarn build
```

This will create a `build` folder with the optimized static assets for deployment.

## Testing

To run the unit tests:

```bash
npm test
# or
yarn test
```

## Data Simulation

This dashboard uses mock data for demonstration purposes. In a real-world scenario, this would fetch data from the GitHub API or a dedicated backend service.
