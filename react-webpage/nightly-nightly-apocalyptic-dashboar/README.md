# Nightly Apocalyptic Dashboard

Visualize system resources as post-apocalyptic survival metrics. Track CPU as 'Zombie Hordes', Memory as 'Survival Supplies', and Disk as 'Radiation Zones' with interactive charts and survival alerts.

## Usage
1. Open `index.html`
2. Input system metrics manually or use demo mode
3. View whimsical visualizations

## Features
- Themed resource graphs
- Survival status alerts
- Nuclear glow aesthetic
- Offline-friendly design
