# Nightly Wasteland Weather Ticker\n\nAn interactive React widget that conjures random, whimsical weather forecasts for a post‑apocalyptic wasteland.\n\n## Features\n- Generates a new forecast on button click\n- Uses a curated list of funny, thematic weather descriptions\n- Fully test‑covered with Jest and React Testing Library\n\n## Installation\n```bash\n# Clone the repository (or copy the generated folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/nightly-wasteland-weather-ticker\n\n# Install dependencies\nnpm install\n```\n\n## Development\n```bash\n# Start the development server (uses Vite for fast HMR)\nnpm run dev\n```\n\nOpen http://localhost:5173 in your browser to see the widget.\n\n## Build\n```bash\nnpm run build\n```\n\nThe production build will be output to the `dist/` folder.\n\n## Testing\n```bash\nnpm test\n```\n\nThe test suite checks that a new forecast is rendered after clicking the "Refresh" button.\n\n## License\nMIT
