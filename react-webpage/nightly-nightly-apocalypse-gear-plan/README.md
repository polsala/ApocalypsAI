# Apocalypse Gear Planner\n\nAn interactive React web page that lets you select survival items and instantly see the total weight and total value of your loadout. Perfect for planning your post‑apocalypse backpack.\n\n## Features\n\n- List of common survival items with weight (kg) and value (credits).\n- Checkboxes to include/exclude items.\n- Live calculation of total weight and total value.\n- Responsive layout.\n\n## Getting Started\n\n```bash\nnpm install\nnpm run dev   # starts Vite dev server at http://localhost:5173\n```\n\n## Build\n\n```bash\nnpm run build   # creates production build in dist/\n```\n\n## Test\n\n```bash\nnpm test\n```
