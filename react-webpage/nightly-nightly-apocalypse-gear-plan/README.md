# Apocalypse Gear Planner\n\nAn interactive React web app that lets you select survival items, see total weight, and export your gear list. Perfect for role‑playing games or real‑world prepping.\n\n## Features\n\n- Browse a catalog of items (name, weight, description)\n- Add / remove items to your loadout\n- Live total weight calculation\n- Export list as JSON\n\n## Usage\n\n```bash\n# Install dependencies\nnpm install\n\n# Run development server\nnpm start\n```\n\nOpen http://localhost:3000 in your browser.\n\n## Testing\n\n```bash\nnpm test\n```
