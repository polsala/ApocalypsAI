# Nightly Barter Calculator\n\nA tiny, whimsical React web app that helps you figure out the trade value of common post‑apocalyptic items.\n\n## Features\n\n- Select an item (water, food, ammo, medicine)\n- Enter a quantity\n- Instantly see the total barter value based on a static price list\n- Pure client‑side, no backend required\n\n## Getting Started\n\n```bash\n# Clone the repository (or copy the generated folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/react-webpage/nightly-barter-calculator\n\n# Install dependencies\nnpm install\n\n# Run the development server\nnpm start\n```\n\nThe app will be available at `http://localhost:3000`.\n\n## Build\n\n```bash\nnpm run build\n```\n\nThe production build will be placed in the `build/` directory.\n\n## Testing\n\n```bash\nnpm test\n```\n\nThe test suite uses Jest and React Testing Library to verify that the calculator works as expected.\n\n## License\n\nMIT – see the LICENSE file in the root of the repository.\n
