# Nightly Barter Calculator\n\nA playful React web app that helps you compute the total barter value of your post‑apocalypse supplies. Add items with custom names and values, see the running total, and share the results.\n\n## Usage\n\n```sh\nnpm install\nnpm start\n```\n\nOpen http://localhost:3000 in your browser.\n\n## Features\n\n- Add, edit, and remove items.\n- Automatic total calculation.\n- Simple, zero‑dependency UI (uses React only).\n\n## Development\n\nRun tests with:\n\n```sh\nnpm test\n```
