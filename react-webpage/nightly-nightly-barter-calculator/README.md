# Nightly Barter Calculator\n\nAn interactive, zero‑dependency web page that lets you input quantities of common post‑apocalyptic items (water, canned food, ammo, fuel, medicine, scrap metal) and instantly see the total trade value based on a configurable price list.\n\n## Features\n\n- Simple UI built with React loaded from a CDN – no build step required.\n- Live calculation as you type.\n- Adjustable price list (edit `src/BarterCalculator.jsx`).\n- Fully tested with Jest and React Test Renderer.\n\n## How to run locally\n\n1. Clone the repository and navigate to the utility folder:\n   ```\n   cd react-webpage/nightly-barter-calculator\n   ```\n2. Open `src/index.html` in a browser (you can use any static‑file server, e.g., `python -m http.server`).\n\n   ```\n   python -m http.server 8000 --directory src\n   # then open http://localhost:8000 in your browser\n   ```\n\n3. The page will display a table where you can enter quantities. The total value updates instantly.\n\n## Running the tests\n\nThe test suite uses Jest with the `react-test-renderer` package. No external network calls are made – all data is mocked.\n\n```\nnpm install\nnpm test\n```\n\n## License\n\nMIT – see the root LICENSE file.\n
