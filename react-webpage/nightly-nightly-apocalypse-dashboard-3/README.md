## Nightly Apocalypse Dashboard

This is a whimsical React-based web application designed to provide a visual overview of the current, imagined state of the apocalypse. It's a fun, self-contained utility for the ApocalypsAI community to track various (fictional) apocalyptic metrics.

### Features

*   **Resource Tracker**: Displays the current availability of essential survival resources (e.g., canned beans, clean water).
*   **Threat Level Monitor**: Shows the fluctuating threat levels from various apocalyptic agents (e.g., rogue AI, mutant squirrels).
*   **Survivor Count**: A (likely dwindling) counter of remaining brave souls.
*   **Temporal Anomaly Gauge**: Visualizes the stability of the spacetime continuum.

### How to Run

1.  **Prerequisites**: Node.js and npm (or yarn) installed.
2.  **Clone the repository**: `git clone <repository-url>`
3.  **Navigate to the utility directory**: `cd utils/nightly-apocalypse-dashboard`
4.  **Install dependencies**: `npm install` (or `yarn install`)
5.  **Start the development server**: `npm start` (or `yarn start`)

This will launch the dashboard in your browser, typically at `http://localhost:3000`.

### Development

This utility is built using React. The `src/` directory contains the main components and logic. The `tests/` directory contains unit tests for the components.
