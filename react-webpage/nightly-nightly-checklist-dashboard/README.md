Apocalypse Checklist Dashboard\n\nThis utility provides a small React web application that displays a list of survival tasks. Users can check off items, and progress is saved in the browser's local storage so it persists across reloads.\n\nHow to run:\n1. Ensure Node.js (>=14) and npm are installed.\n2. In the utility folder, run `npm install` to install dependencies.\n3. Start the development server with `npm start`. The app will be available at http://localhost:3000.\n\nThe source code lives in the src/ directory and tests are in the tests/ directory.\n
