# Nightly Emoji Calendar\n\nA whimsical React component that displays a month‑long calendar where each day is assigned an apocalypse‑themed emoji. Perfect for adding a touch of fun to your dashboard.\n\n## Usage\n\n```bash\nnpm install\nnpm start\n```\n\nThe app runs on `http://localhost:3000`.\n\n## How it works\n\n- The component generates a list of days (1‑30).\n- For each day it selects an emoji from a predefined list using a deterministic algorithm.\n- The calendar is rendered as a simple table.\n\n## Customisation\n\nEdit `src/App.jsx` to change the emoji set or the month length.\n\n## License\n\nMIT
