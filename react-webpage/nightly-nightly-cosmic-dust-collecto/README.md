# Nightly Cosmic Dust Collector

## Overview

The Nightly Cosmic Dust Collector is a whimsical, interactive React web application designed to provide a lighthearted way to visualize and celebrate small, consistent contributions within the ApocalypsAI community. Think of 'cosmic dust' as tiny, valuable efforts – a helpful comment, a small refactor, a thoughtful review – that collectively build something grand.

Users can click a button to 'collect' cosmic dust, increasing their total. As certain thresholds are reached, new 'Cosmic Artifacts' are discovered, adding a gamified element to encourage engagement and acknowledge the cumulative impact of small actions.

## Features

*   **Interactive Dust Collection**: Click to gather cosmic dust.
*   **Progress Tracking**: See your total dust collected.
*   **Cosmic Artifacts**: Unlock unique, whimsical artifacts at predefined dust thresholds.
*   **Persistent State**: Your dust count and unlocked artifacts are saved locally in your browser.
*   **Whimsical UI**: A simple, star-filled interface to make collection delightful.

## How to Run Locally

1.  **Navigate to the utility directory**:
    ```bash
    cd react-webpage/nightly-cosmic-dust-collector
    ```
2.  **Install dependencies**:
    ```bash
    npm install
    # or yarn install
    ```
3.  **Start the development server**:
    ```bash
    npm start
    # or yarn start
    ```
    This will typically open the application in your browser at `http://localhost:3000`.

## How to Build for Production

1.  **Navigate to the utility directory**:
    ```bash
    cd react-webpage/nightly-cosmic-dust-collector
    ```
2.  **Build the application**:
    ```bash
    npm run build
    # or yarn build
    ```
    This will create a `build/` directory containing the static files ready for deployment.
