# Emoji Survival Dashboard\n\nA whimsical React web app that visualizes the current "resource levels" of an apocalypse using emojis. Click **Refresh** to generate new random levels.\n\n## Features\n- Displays five resources (Food, Water, Fuel, Medicine, Shelter) with emoji icons\n- Random percentage levels for each resource\n- One‑click refresh to re‑generate the levels\n\n## Getting Started\n\n```sh\n# Install dependencies\nnpm install\n\n# Run the development server\nnpm start\n```\n\nThe app will open in your default browser at `http://localhost:8080`.\n\n## Running Tests\n\n```sh\nnpm test\n```\n\nThe test suite uses Jest and React Testing Library to verify that the dashboard renders correctly and that the refresh button updates the resource levels.\n\n## Build for Production\n\n```sh\nnpm run build\n```\n\nThe production bundle will be placed in the `dist/` directory.\n
