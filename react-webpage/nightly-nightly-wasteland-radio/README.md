# Nightly Wasteland Radio

A whimsical React web app that simulates a post‑apocalyptic radio station. Press the **Play** button to hear static and get a random retro‑futuristic song title and a survival quote. No external APIs; all data is bundled.

## Usage

```sh
npm install
npm run dev
```

Open `http://localhost:5173` to enjoy the radio.

## Testing

```sh
npm test
```
