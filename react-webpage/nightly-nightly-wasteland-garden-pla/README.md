# Wasteland Garden Planner\n\nAn interactive React web app that lets you plan a post‑apocalyptic garden by adding plants with their sun and water requirements. The app visualizes a simple grid showing where each plant can thrive.\n\n## Features\n\n- Add plants with name, sun exposure (Full, Partial, Shade) and water needs (Low, Medium, High).\n- See a color‑coded garden grid.\n- Export the plan as JSON.\n\n## Getting Started\n\n```sh\nnpm install\nnpm start\n```\n\nOpen http://localhost:3000 in your browser.\n\n## Testing\n\n```sh\nnpm test\n```\n\n## License\n\nMIT
