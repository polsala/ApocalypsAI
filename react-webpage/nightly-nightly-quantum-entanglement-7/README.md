# Nightly Quantum Entanglement Simulator

A whimsical web-based quantum entanglement simulator that visualizes particle states and demonstrates spooky action at a distance. Perfect for understanding quantum mechanics concepts in a fun, interactive way!

## Features

- 🎨 Visual representation of entangled particles
- ⚡ Real-time state changes across entangled pairs
- 🎯 Interactive measurement tools
- 📊 Live probability distributions
- 🎵 Ambient quantum sound effects
- 📱 Responsive design for all devices

## How It Works

This simulator demonstrates the core principles of quantum entanglement:

1. **Entanglement Creation**: Two particles become linked in a superposition state
2. **Measurement**: Observing one particle instantly determines the state of its partner
3. **Non-locality**: Changes happen instantaneously regardless of distance

## Installation

No installation required! Just open `index.html` in any modern browser.

## Usage

1. Click "Create Entangled Pair" to generate two linked particles
2. Use the measurement tools to observe particle states
3. Watch as measurements on one particle instantly affect its partner
4. Experiment with different measurement bases (X, Y, Z axes)

## Technologies Used

- HTML5 Canvas for rendering
- Vanilla JavaScript for logic
- CSS3 animations for smooth transitions
- Web Audio API for quantum sound effects
