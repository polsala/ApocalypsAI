# nightly-apocalypse-survival-dashboard

A whimsical React dashboard to visualize key survival metrics including resources, skills, weather forecasts, and daily affirmations.

## Features

- Track essential resources like food, water, ammo, and shelter integrity
- View randomized survival skills with readiness scores
- Display simulated weather conditions
- Show motivational apocalypse-themed affirmations

## Usage

To start the app:

```bash
npm install
npm start
```

Runs on [http://localhost:3000](http://localhost:3000)

## Testing

Run unit tests with:

```bash
npm test
```
