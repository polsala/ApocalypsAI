# Survival Kit Planner\n\nA whimsical web tool to generate a post‑apocalypse survival kit checklist based on your chosen environment (Desert, Tundra, Urban, Forest). Select an environment and click \"Generate\" to see a curated list of items.\n\n## Usage\n\nOpen `src/index.html` in a web browser. No server is required.\n\n## Development\n\nThe project uses **Jest** for unit testing. To run the tests:\n\n```bash\nnpm install\nnpm test\n```\n\n## Files\n\n- `src/index.html` – The main HTML page loading React via CDN.\n- `src/kit.js` – Data module exporting environments and a helper function.\n- `tests/kit.test.js` – Jest tests for the helper function.\n- `package.json` – Minimal Node project definition (only Jest as a dev dependency).
