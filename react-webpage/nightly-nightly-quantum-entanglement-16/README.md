# Nightly Quantum Entanglement Simulator

A whimsical web-based quantum entanglement simulator that visualizes the spooky action at a distance. Watch as entangled particles dance across the screen, maintaining their mysterious connection regardless of distance.

## Features

- Interactive particle entanglement visualization
- Real-time quantum state updates
- Spooky measurement effects
- Educational tooltips explaining quantum concepts
- Responsive design for all screen sizes

## Usage

1. Open `index.html` in any modern browser
2. Click the "Create Entangled Pair" button to generate entangled particles
3. Observe how measuring one particle instantly affects its partner
4. Use the controls to adjust simulation speed and particle count

## Technology

Built with React for the UI and Canvas API for smooth particle animations. No build tools required - just open and enjoy!

## Educational Value

This simulator demonstrates key quantum mechanics concepts:
- Quantum entanglement
- Superposition
- Wave function collapse
- Non-locality
