# Apocalypse Kit Planner\n\nAn interactive React web app that helps you build a custom survival kit for the apocalypse. Choose items, set a weight limit, and see a live summary of your kit.\n\n## Usage\n\n1. Install dependencies: `npm install`\n2. Start the development server: `npm start`\n3. Open http://localhost:3000 in your browser.\n\n## Features\n\n- Add items to your kit while respecting a maximum weight limit\n- Real‑time total weight calculation\n- Save and load your kit automatically via `localStorage`\n- Simple, zero‑configuration build using Webpack and Babel\n\n## Scripts\n\n- `npm start` – Launches the dev server with hot‑reloading\n- `npm run build` – Produces a production bundle in `dist/`\n- `npm test` – Runs the Jest test suite\n\n## License\n\nMIT\n
