# Meme Generator\n\nA whimsical React web app that lets you create custom memes by adding top and bottom text to classic meme templates.\n\n## Features\n\n- Choose from a few classic meme images.\n- Add top and bottom captions.\n- Live preview rendered on a canvas.\n- Download the generated meme as PNG.\n\n## Getting Started\n\n```bash\nnpm install\nnpm start\n```\n\nOpen http://localhost:3000 in your browser.\n\n## Running Tests\n\n```bash\nnpm test\n```\n\n## License\n\nMIT
