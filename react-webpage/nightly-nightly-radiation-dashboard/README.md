# Radiation Dashboard\n\nA whimsical React web app that visualizes fictional radiation levels across zones in a post‑apocalyptic wasteland. Each zone gets a deterministic random radiation level (0‑100). Safe zones (<30) are highlighted and can be filtered.\n\n## Usage\n\n```sh\nnpm install\nnpm start\n```\n\nOpen `http://localhost:3000` to view the dashboard.\n\n## Testing\n\n```sh\nnpm test\n```\n\nThe test suite runs with Jest and @testing-library/react, using a mocked zone generator for deterministic results.
