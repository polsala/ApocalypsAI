# Nightly Quantum Entanglement Simulator

A whimsical web-based quantum circuit simulator that visualizes quantum entanglement in real-time. Perfect for learning quantum computing concepts or just watching spooky action at a distance!

## Features

- Interactive quantum circuit builder
- Real-time entanglement visualization with animated particles
- Bell state demonstrations
- Quantum gate operations (Hadamard, Pauli-X, CNOT)
- Measurement simulation
- Whimsical particle effects and sound effects

## Usage

1. Open `index.html` in any modern browser
2. Drag and drop quantum gates onto the circuit
3. Connect qubits with CNOT gates to create entanglement
4. Click 'Measure' to collapse the quantum state
5. Watch the entangled particles react in real-time

## Technologies

- React.js for UI components
- Three.js for 3D visualization
- Tone.js for quantum sound effects
- CSS-in-JS for styling

## Educational Value

This tool demonstrates:
- Superposition (Hadamard gates)
- Quantum entanglement (CNOT gates)
- Measurement collapse
- Bell states and quantum correlations

## Whimsical Features

- Animated 'spooky action at a distance' effects
- Quantum sound effects when gates are applied
- Particle trails that show entanglement connections
- Random quantum 'glitches' for fun
- Easter egg: Try creating a GHZ state for extra sparkle!
