# Nightly Cosmic Dust Bunny Collector

## 🌌 Collect Your Cosmic Clutter! 🌌

Welcome, fellow traveler of the digital void! Have you ever had a brilliant, tiny idea, or a minuscule task, only for it to drift away into the cosmic ether, lost forever among the stars? Fear not! The `Nightly Cosmic Dust Bunny Collector` is here to help you wrangle those fleeting thoughts and tasks into a delightful, visual collection.

This whimsical React web application provides a simple dashboard where you can 'collect' your 'cosmic dust bunnies' – those small, often overlooked items that, when gathered, can lead to great things. Watch your collection grow, and feel the satisfaction of bringing order to your personal cosmos.

## ✨ Features

*   **Add Dust Bunnies**: Quickly jot down a small task, idea, or reminder.
*   **Visual Collection**: See your collected dust bunnies accumulate in a charming, animated display.
*   **Persistence**: Your dust bunnies are safely stored in your browser's local storage, so they'll be there even after you close your cosmic portal.
*   **Clear All**: When your cosmic chamber gets too dusty, you can sweep them all away!

## 🚀 Getting Started

To run this stellar application locally, follow these steps:

1.  **Navigate to the utility directory:**
    ```bash
    cd react-webpage/nightly-cosmic-dust-bunny
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    ```

3.  **Start the development server:**
    ```bash
    npm start
    ```
    This will open the application in your browser, usually at `http://localhost:3000`.

## 🌠 Usage

Simply type your cosmic thought or task into the input field and click "Collect Dust Bunny". Watch as your new bunny appears in the collection. To clear all your collected bunnies, click "Sweep Away All Dust Bunnies".

## 🛠️ Technologies Used

*   React
*   JavaScript (ES6+)
*   CSS
*   Local Storage for persistence
