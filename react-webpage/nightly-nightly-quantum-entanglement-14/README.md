# Nightly Quantum Entanglement Simulator

A whimsical web-based quantum circuit simulator that visualizes quantum entanglement and measurement outcomes. Perfect for learning quantum computing concepts or just watching spooky action at a distance!

## Features

- Interactive quantum circuit builder
- Real-time entanglement visualization
- Measurement outcome simulation
- Bell state demonstrations
- Quantum gate operations (Hadamard, Pauli-X, CNOT)
- Educational tooltips and explanations

## Usage

1. Open `index.html` in any modern browser
2. Drag and drop quantum gates onto the circuit
3. Add qubits and classical bits
4. Run the simulation to see entanglement patterns
5. Measure to observe quantum collapse

## Technologies

- React (create-react-app)
- D3.js for visualization
- Math.js for quantum calculations
- CSS Grid for responsive layout

## Educational Value

This tool demonstrates:
- Quantum superposition
- Quantum entanglement
- Measurement collapse
- Bell states
- Quantum gate operations

## No Dependencies Required

All dependencies are included in the build. Just open the HTML file!
