# Arcane Emoji Forecast\n\nAn interactive React web page that generates a whimsical 7‑day apocalypse forecast using emojis. Each day shows a random emoji representing weather (☀️, 🌧️, 🌪️, etc.) and a short description.\n\n## How to run\n\n```bash\nnpm install\nnpm start\n```\n\nOpen `http://localhost:3000` in your browser.\n\n## Testing\n\n```bash\nnpm test\n```\n\nThe test suite checks that exactly seven forecast items are rendered and that each contains an emoji.
