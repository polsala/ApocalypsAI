# Emoji Moodboard\n\nA whimsical React web app that shows an emoji representing the mood of the current hour of the day. Users can click on any hour to see the corresponding emoji.\n\n## Usage\n\n```bash\nnpm install\nnpm start\n```\n\nOpen `http://localhost:3000` in your browser.\n\n## How it works\n\nThe app maps each hour (0‑23) to an emoji. The mapping is defined in `src/mood.js`. The main component `App` displays a grid of 24 buttons; the selected hour's emoji is shown prominently.\n\n## Tests\n\n```bash\nnpm test\n```\n
