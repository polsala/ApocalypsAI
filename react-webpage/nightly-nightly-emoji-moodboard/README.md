# Emoji Moodboard\n\nAn interactive React web app that shows a 3x3 grid of emojis reflecting the current time of day and a random mood. Refresh to get new moods.\n\n## How to run\n\n```bash\nnpm install\nnpm start\n```\n\nOpen `http://localhost:3000`.\n\n## Testing\n\n```bash\nnpm test\n```\n\n## Implementation\n\nThe app determines a base mood (morning, afternoon, evening, night) from the system clock and selects random emojis from a predefined list.
