# Emoji Moodboard\n\nA whimsical React web app that lets you select emojis to represent your current mood and generates a shareable collage.\n\n## Features\n\n- Choose from a palette of emojis.\n- See your selections displayed in a growing collage.\n- Export the collage as a PNG (placeholder for future feature).\n\n## Usage\n\n```bash\nnpm install\nnpm start\n```\n\nOpen `http://localhost:3000` in your browser.\n\n## Build\n\n```bash\nnpm run build\n```\n\n## Tests\n\n```bash\nnpm test\n```\n
