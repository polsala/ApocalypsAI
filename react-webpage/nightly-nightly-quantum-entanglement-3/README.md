# Nightly Quantum Entanglement Simulator

A whimsical web-based quantum circuit simulator that visualizes quantum entanglement and measurement outcomes. Perfect for learning quantum computing concepts or just watching spooky action at a distance!

## Features

- 🌀 Interactive quantum circuit builder
- 🎨 Visual entanglement visualization with animated connections
- 📊 Real-time probability distribution display
- 🎲 Random quantum state generation
- 📱 Responsive design for all devices

## Usage

1. Open `index.html` in any modern browser
2. Add quantum gates to the circuit
3. Observe entanglement visualization
4. Measure and see probability distributions

## Technologies

- React 18
- D3.js for SVG animations
- CSS Grid & Flexbox
- Vanilla JavaScript

## Example

```javascript
// Create a Bell state
Hadamard gate on qubit 0
CNOT gate between qubits 0 and 1
// Watch the entanglement visualization!
```
