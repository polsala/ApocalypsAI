# Apocalypse Weather Dashboard\n\nA whimsical React web app that generates random post‑apocalyptic weather forecasts for fictional locations. Great for role‑playing games, story‑telling, or just a fun break.\n\n## Features\n\n- Randomly generated weather (e.g., "Acid rain", "Radiation fog").\n- Five fictional locations.\n- Refresh button to generate new forecasts.\n\n## Getting Started\n\n```bash\nnpm install\nnpm start\n```\n\nOpen http://localhost:3000 to view.\n\n## Testing\n\n```bash\nnpm test\n```
