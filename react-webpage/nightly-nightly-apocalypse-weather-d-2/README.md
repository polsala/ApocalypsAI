# Apocalypse Weather Dashboard\n\nA tiny React web app that lets you pick a post‑apocalyptic zone and shows a whimsical weather forecast.\n\n## Features\n- Choose from four fictional zones.\n- Deterministic forecasts (no external API calls).\n- Fully typed with modern React (hooks, functional components).\n\n## Getting Started\n```bash\n# Clone the repository (or copy the generated folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/nightly-apocalypse-weather-dashboard\n\n# Install dependencies\nnpm install\n\n# Run the development server\nnpm start\n```\n\nOpen your browser at `http://localhost:3000` and enjoy the chaotic weather!\n\n## Testing\n```bash\nnpm test\n```\nThe test suite checks the deterministic forecast logic and the React component rendering.\n\n## License\nMIT
