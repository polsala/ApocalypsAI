# Survival Quest Board\n\nA whimsical React web app that lets you jot down post‑apocalypse quests, track them, and cross them off. Perfect for role‑playing sessions or personal survival planning.\n\n## Features\n\n- Add a quest with a short description.\n- Mark quests as completed.\n- Persist quests in local storage (so they survive page reloads).\n\n## Development\n\n```sh\nnpm install\nnpm start   # opens http://localhost:3000\nnpm test    # runs Jest + React Testing Library\n```\n\n## Build\n\n```sh\nnpm run build   # creates a static bundle in ./dist\n```
