# nightly‑apoc‑forecast\n\nAn interactive React web page that lets you pick a fictional post‑apocalyptic zone and shows a randomly generated weather forecast.  It’s whimsical, lightweight, and completely offline – perfect for a quick laugh or a demo of React components.\n\n## Features\n\n- Choose from several imagined zones (e.g., "Radiated Wasteland", "Dust‑Covered Ruins", "Frozen Bunker").\n- Each selection displays a colorful, randomly‑chosen forecast (e.g., "Acid rain with a chance of mutant fireflies").\n- Pure client‑side – no network calls, no API keys.\n- Includes a Jest test suite using React Testing Library.\n\n## Getting Started\n\n```bash\n# Clone the repository (or copy the generated folder)\ngit clone <repo‑url>\ncd utils/react-webpage/nightly-apoc-forecast\n\n# Install dependencies\nnpm install\n\n# Run the development server (uses parcel for zero‑config bundling)\nnpm run dev\n\n# Open http://localhost:1234 in your browser\n```\n\n## Scripts\n\n- `npm run dev` – Starts a development server with hot‑reloading (parcel).\n- `npm run build` – Produces a production build in the `dist/` folder.\n- `npm test` – Runs the Jest test suite.\n\n## Project Structure\n\n```.\n├─ package.json          # npm metadata, scripts, deps\n├─ .babelrc              # Babel config for JSX\n├─ src/\n│  ├─ index.html        # Simple HTML entry point\n│  ├─ index.jsx         # ReactDOM render entry\n│  └─ App.jsx           # Main component\n└─ tests/\n   └─ App.test.jsx      # Component tests\n```\n\n## License\n\nMIT – feel free to remix, share, and apocalyptically forecast away!\n
