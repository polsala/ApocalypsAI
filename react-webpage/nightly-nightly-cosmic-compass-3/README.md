## Nightly Cosmic Compass

A whimsical React web application that provides a daily "cosmic alignment" visualization. It simulates a celestial event and presents it in a fun, interactive way.

### How to Run

1.  **Prerequisites**: Ensure you have Node.js and npm (or yarn) installed.
2.  **Clone the repository** (if you haven't already).
3.  **Navigate to the utility directory**: `cd utils/nightly-cosmic-compass`
4.  **Install dependencies**: `npm install` (or `yarn install`)
5.  **Start the development server**: `npm start` (or `yarn start`)
6.  Open your browser to `http://localhost:3000` (or the port specified by your React setup).

### Usage

Upon loading the page, you will see a stylized visualization representing your "cosmic alignment" for the day. The elements are purely for aesthetic and whimsical purposes, offering a moment of lighthearted reflection.

### Development Notes

This utility is built using React. The core logic for generating the "cosmic alignment" is simulated and deterministic for testing purposes. The visualization uses basic SVG elements for simplicity.

### Testing

Run the tests using `npm test` (or `yarn test`). The tests are designed to be deterministic and offline, using mocked data for the celestial event simulation.
