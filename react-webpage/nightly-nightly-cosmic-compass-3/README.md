# Nightly Cosmic Compass

## Overview

The Nightly Cosmic Compass is a whimsical, interactive web application designed to help you visualize the cosmos through the lens of potential apocalyptic scenarios. It presents a stylized view of celestial bodies, assigning them a 'survival readiness' score based on user-selected doomsday events. It's a fun, albeit fictional, way to ponder our place in the universe and the resilience of celestial phenomena.

## Features

*   **Interactive Celestial Map**: View a dynamic representation of planets, stars, and nebulae.
*   **Scenario Selection**: Choose from a variety of pre-defined apocalyptic scenarios (e.g., 'Solar Flare Frenzy', 'Asteroid Avalanche', 'Cosmic Dust Bunny Infestation').
*   **Survival Readiness Scores**: Each celestial body is assigned a whimsical score indicating its 'readiness' for the chosen scenario.
*   **Customizable Parameters**: Adjust certain parameters within scenarios to see how they affect the readiness scores.
*   **Responsive Design**: Works on various screen sizes.

## Technology Stack

*   **Frontend**: React, Vite, Tailwind CSS
*   **Testing**: Jest, React Testing Library

## Setup

1.  **Prerequisites**: Ensure you have Node.js and npm/yarn installed.
2.  **Clone the repository**: (Assuming this utility is part of a larger repo)
    ```bash
    git clone <repository_url>
    cd <repository_directory>
    ```
3.  **Install dependencies**: 
    ```bash
    npm install
    # or
    yarn install
    ```
4.  **Run the development server**: 
    ```bash
    npm run dev
    # or
    yarn dev
    ```
    This will start the application, typically at `http://localhost:5173`.

## Usage

Once the application is running, navigate to the web interface. You will see a celestial map. Use the controls to select an apocalyptic scenario. The celestial bodies on the map will update their visual indicators and readiness scores based on your selection. Hover over celestial bodies for more details.

## Development and Testing

*   **Development**: Run `npm run dev` or `yarn dev`.
*   **Building for production**: Run `npm run build` or `yarn build`.
*   **Running tests**: Run `npm test` or `yarn test`.
