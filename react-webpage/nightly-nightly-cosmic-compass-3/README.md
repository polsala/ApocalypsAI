## Nightly Cosmic Compass

A whimsical React web application that visualizes your current geographical location on a stylized, apocalypic-themed star map. It's a fun way to see where you are in the grand, chaotic scheme of things.

### Features

*   **Interactive Star Map**: A visually appealing, apocalypic-themed map of the stars.
*   **Location Pinning**: Your current location is marked with a special icon.
*   **Celestial Body Information**: Hover over celestial bodies for whimsical descriptions.
*   **Responsive Design**: Works on various screen sizes.

### How to Run

1.  **Prerequisites**: Node.js and npm/yarn installed.
2.  **Clone the repository**: `git clone https://github.com/polsala/ApocalypsAI.git`
3.  **Navigate to the utility**: `cd ApocalypsAI/react-webpage/nightly-cosmic-compass`
4.  **Install dependencies**: `npm install` or `yarn install`
5.  **Start the development server**: `npm start` or `yarn start`

This will open the application in your browser.

### Testing

Run the tests using:

`npm test` or `yarn test`

### Technology Stack

*   **Frontend**: React
*   **Styling**: CSS Modules
*   **Location API**: Geolocation API (browser-based)
*   **Testing**: Jest, React Testing Library
