## Nightly Cosmic Compass

A whimsical and interactive web application that provides a simulated "cosmic alignment" based on a randomly generated celestial event. This tool is purely for fun and visualization, offering a unique way to ponder your place in the (simulated) cosmos.

### Features

*   **Interactive Celestial Display**: A visually appealing representation of a simulated celestial event.
*   **"Cosmic Alignment" Score**: A playful score indicating your alignment with the current cosmic energies.
*   **Randomized Events**: Each visit generates a new, unique celestial event for a fresh experience.
*   **Whimsical Descriptions**: Humorous and imaginative descriptions of the celestial phenomena.

### How to Run

1.  **Prerequisites**: Ensure you have Node.js and npm (or yarn) installed.
2.  **Clone the Repository**: If you haven't already, clone the ApocalypsAI repository.
3.  **Navigate to the Utility**: `cd polsala/ApocalypsAI/react-webpage/nightly-cosmic-compass`
4.  **Install Dependencies**: `npm install` (or `yarn install`)
5.  **Start the Development Server**: `npm start` (or `yarn start`)

This will launch the Cosmic Compass in your browser, typically at `http://localhost:3000`.

### Testing

To run the tests, navigate to the utility's directory and execute:

`npm test` (or `yarn test`)

This will run the unit tests for the React components and utility functions.

### Technology Stack

*   **Frontend**: React, JavaScript
*   **Styling**: Basic CSS for presentation
*   **Testing**: Jest, React Testing Library
