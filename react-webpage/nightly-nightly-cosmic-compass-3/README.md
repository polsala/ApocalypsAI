## Nightly Cosmic Compass

A whimsical React web application that visualizes your current geographical location on a stylized, post-apocalyptic star map. Discover your place in the cosmos, even after the world has changed!

### Features

*   **Interactive Star Map**: A visually engaging map with celestial bodies and post-apocalyptic landmarks.
*   **Location Pinning**: Your current location is marked with a special beacon.
*   **Whimsical Lore**: Discover snippets of lore about the stars and the new world.
*   **Responsive Design**: Works on various screen sizes.

### Getting Started

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/polsala/ApocalypsAI.git
    cd ApocalypsAI
    ```

2.  **Navigate to the utility directory**:
    ```bash
    cd utils/nightly-cosmic-compass
    ```

3.  **Install dependencies**:
    ```bash
    npm install
    ```

4.  **Start the development server**:
    ```bash
    npm start
    ```

5.  Open your browser to `http://localhost:3000`.

### Usage

Upon loading, the application will attempt to get your current location using the browser's Geolocation API. This location will be displayed as a marker on the cosmic map. You can pan and zoom the map to explore different regions.

### Testing

To run the tests, use:

```bash
npm test
```
