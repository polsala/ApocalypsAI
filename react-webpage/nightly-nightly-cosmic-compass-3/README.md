## Nightly Cosmic Compass

Embark on a whimsical journey through the cosmos with the Nightly Cosmic Compass! This interactive web application allows you to visualize hypothetical celestial navigation routes. Input your 'cosmic dust' levels and 'starlight intensity' to see where the cosmic winds might take you.

### Backstory

In the far-flung reaches of the ApocalypsAI galaxy, where time itself bends and twists, brave navigators rely on more than just stars. They use the subtle currents of cosmic dust and the ethereal glow of distant starlight to chart their course. The Cosmic Compass is a tool born from ancient, forgotten lore, designed to translate these ephemeral whispers into tangible, albeit fantastical, routes.

### Setup

1.  **Prerequisites**: Node.js and npm (or yarn) installed.
2.  **Clone the repository**: `git clone https://github.com/polsala/ApocalypsAI.git`
3.  **Navigate to the utility**: `cd ApocalypsAI/react-webpage/nightly-cosmic-compass`
4.  **Install dependencies**: `npm install` (or `yarn install`)

### Usage

1.  **Start the development server**: `npm start` (or `yarn start`)
2.  Open your browser to `http://localhost:3000`.
3.  Enter values for 'Cosmic Dust' (e.g., 1-10) and 'Starlight Intensity' (e.g., 1-10).
4.  Click 'Chart Course' to see your celestial path visualized.

### How it Works

The application uses a simple algorithm to generate a path based on your inputs. Higher 'cosmic dust' might lead to more erratic, winding paths, while brighter 'starlight intensity' could suggest straighter, more direct routes. The visualization uses a basic canvas drawing to represent the journey.
