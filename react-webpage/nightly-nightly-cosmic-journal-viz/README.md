## Cosmic Journal Visualizer

This is a whimsical web application that allows you to visualize your personal "cosmic journal" entries. It helps you spot trends, patterns, and recurring themes in your thoughts and experiences.

### Features

*   **Entry Input**: A simple form to add new journal entries with a title, date, and your thoughts.
*   **Visualization**: Displays entries on a timeline and uses a word cloud to highlight frequently used words.
*   **Whimsical Theme**: Designed with a playful, cosmic aesthetic.

### Getting Started

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/polsala/ApocalypsAI.git
    cd ApocalypsAI
    ```

2.  **Navigate to the utility directory**:
    ```bash
    cd utils/nightly-cosmic-journal-viz
    ```

3.  **Install dependencies**:
    ```bash
    npm install
    ```

4.  **Start the development server**:
    ```bash
    npm start
    ```

    The application will be available at `http://localhost:3000`.

### Usage

*   On the main page, you'll see a form to add new journal entries. Fill in the title, select a date, and write your thoughts in the text area.
*   Click "Add Entry" to save your entry.
*   The displayed entries will update, showing a timeline and a word cloud of your most frequent words.
