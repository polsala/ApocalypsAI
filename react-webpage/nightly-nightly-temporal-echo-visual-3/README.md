# Nightly Temporal Echo Visualizer

## Overview
The Nightly Temporal Echo Visualizer is a whimsical-yet-crucial React web interface designed to help survivors of the temporal apocalypse understand and navigate the ever-shifting landscape of temporal distortions. It provides a clear, interactive dashboard to visualize detected "temporal echoes" – remnants or projections of past, present, or future events bleeding into our reality. By categorizing and mapping these echoes, we aim to prevent accidental temporal entanglement and optimize resource scavenging.

## Features
*   **Echo List Display**: View a list of all detected temporal echoes with their key attributes.
*   **Filtering**: Filter echoes by type (e.g., "Temporal Ripple", "Echo Cascade", "Void Whisper") to focus on specific phenomena.
*   **Severity Indicator**: Quickly identify high-severity echoes that require immediate attention or avoidance.
*   **Mock Data**: Comes pre-loaded with simulated temporal echo data for demonstration and testing purposes.

## Installation & Setup

1.  **Navigate to the utility directory**:
    ```bash
    cd react-webpage/nightly-temporal-echo-visualizer
    ```

2.  **Install dependencies**:
    ```bash
    npm install
    ```

3.  **Run the application**:
    ```bash
    npm start
    ```
    This will open the application in your browser, usually at `http://localhost:3000`.

## Running Tests

To run the automated tests for this utility:

```bash
npm test
```

The tests are designed to be deterministic and run offline, using mock data to ensure consistent results.

## Usage
Upon launching the application, you will see a list of temporal echoes. Each echo displays its timestamp, location, type, severity, and a brief description. Use the filter dropdown to narrow down the echoes by their temporal classification. Stay vigilant, wanderer!
