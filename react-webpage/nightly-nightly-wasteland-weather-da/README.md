Wasteland Weather Dashboard\n\nThis utility is a small React web application that displays a 7‑day weather forecast for a post‑apocalyptic setting. The forecast is generated deterministically using a simple seeded pseudo‑random algorithm, so the output is the same on every run, making testing easy.\n\nHow to run:\n1. Ensure Node.js (>=14) and npm are installed.\n2. In the utility directory, run `npm install` to install dependencies.\n3. Run `npm start` to launch the development server (defaults to http://localhost:3000).\n4. Open the URL in a browser to view the dashboard.\n\nTesting:\nRun `npm test` to execute the Jest test suite, which verifies that the forecast renders exactly seven days with expected deterministic values.
