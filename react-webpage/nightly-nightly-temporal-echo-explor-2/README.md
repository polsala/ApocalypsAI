# nightly-temporal-echo-explorer

A whimsical React-based web app for visualizing and exploring temporal echoes in a post-apocalyptic timeline.

## Overview

Temporal echoes are residual imprints of past events that linger in unstable time zones. This tool allows users to explore these echoes through an interactive timeline, view event details, and simulate echo propagation.

## Features

- Interactive timeline visualization
- Echo event details panel
- Simulated echo propagation
- Responsive design

## Usage

1. Open `index.html` in a browser.
2. Click on echo events to view details.
3. Use the "Simulate" button to see echo propagation.

## Development

To run the development server:

```bash
npm install
npm start
```

## Testing

Tests are written with Jest and React Testing Library:

```bash
npm test
```
