# nightly-temporal-echo-explorer

A whimsical React dashboard to visualize and explore temporal echo patterns.

## Features

- Interactive timeline of temporal echoes
- Visualize echo intensity and frequency
- Fun animations and sound effects
- Responsive design

## Usage

1. Clone the repo
2. Run `npm install`
3. Run `npm start`
4. Open [http://localhost:3000](http://localhost:3000) to view the dashboard

## Tests

Run `npm test` to execute the test suite.
