# Scavenger Map\n\nAn interactive React web page that displays a list of fictional post‑apocalypse scavenging locations, each with a resource and danger level. Users can refresh to get a new random ordering.\n\n## Usage\n\n```sh\nnpm install\nnpm start   # runs the dev server at http://localhost:3000\nnpm test    # runs the test suite\n```\n\n## Features\n\n- Randomized order of locations on each load\n- Simple, zero‑backend UI\n- Fully tested with Jest and React Testing Library\n
