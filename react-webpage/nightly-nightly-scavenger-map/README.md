# Nightly Scavenger Map\n\nAn interactive React web page that generates random scavenger locations with whimsical resources for post‑apocalypse role‑play.\n\n## Features\n\n- Click **Generate** to add a new random location.\n- Each location shows a name, resource, and distance.\n- Simple, offline, no external APIs.\n\n## Development\n\n```bash\nnpm install\nnpm start\n```\n\nThe app will be available at `http://localhost:3000`.\n\n## Testing\n\n```bash\nnpm test\n```\n\nThe test suite uses Jest and React Testing Library to verify core UI behaviour.
