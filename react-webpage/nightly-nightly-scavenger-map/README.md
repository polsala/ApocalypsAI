# Nightly Scavenger Map\n\nAn interactive React web page that displays a 5×5 grid of potential scavenging spots. Each spot may hide a useful resource (Water, Food, Medicine, Ammo, Tools). Click a cell to reveal what lies beneath. The layout is deterministic for offline testing but can be shuffled for fun.\n\n## Features\n\n- Simple, zero‑dependency front‑end (React only)\n- Deterministic resource placement for reliable tests\n- Whimsical post‑apocalyptic theme\n\n## Getting Started\n\n```bash\n# Clone the repository (or copy the utility folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/nightly-scavenger-map\n\n# Install dependencies\nnpm install\n\n# Run the development server\nnpm start\n```\n\nOpen `http://localhost:3000` in your browser to explore the map.\n\n## Running Tests\n\n```bash\nnpm test\n```\n\nThe test suite uses @testing-library/react and verifies that cells start hidden and reveal the correct resource when clicked.\n\n## License\n\nMIT © ApocalypsAI
