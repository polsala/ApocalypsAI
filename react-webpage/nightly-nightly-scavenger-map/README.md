# Nightly Scavenger Map\n\nAn interactive React web page that simulates a post‑apocalypse scavenger map. A 5×5 grid of locations is displayed; clicking a cell reveals a random resource (Food, Water, Medicine, Ammo, or Nothing). Great for quick fun demos or teaching React state handling.\n\n## How to run\n\n```bash\nnpm install\nnpm start\n```\n\nOpen http://localhost:3000 to explore.\n\n## Testing\n\n```bash\nnpm test\n```
