# nightly-void-whispers-affirmations

A React-based web application that delivers whimsical, post-apocalyptic affirmations to uplift your spirit in the wasteland.

## Features

- Generates a new affirmation with each click
- Hauntingly beautiful UI with apocalyptic themes
- Fully responsive design
- Offline support

## Usage

1. Open `index.html` in your browser
2. Click the "New Affirmation" button
3. Receive your daily dose of wasteland wisdom

## Development

To run the development server:

```bash
npm install
npm start
```

## Build

To build the static site:

```bash
npm run build
```
