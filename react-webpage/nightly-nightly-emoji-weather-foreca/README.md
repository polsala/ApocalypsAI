# nightly-emoji-weather-forecast

A whimsical React web page that displays a 5‑day weather forecast using emojis.  Open `src/index.html` in a browser to see the interactive forecast.

## Features

- 5‑day forecast with emojis (☀️, ☁️, 🌧️, ⛈️, ❄️)
- Toggle button to show/hide the forecast
- Pure client‑side – no server required

## Usage

```bash
# Just open the file in a browser
open src/index.html
```

## Development

The component is written in plain JavaScript (ES6) and uses React via CDN.  No build step is required.
