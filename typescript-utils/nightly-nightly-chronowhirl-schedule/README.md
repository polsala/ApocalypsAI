# ChronoWhirl Scheduler

Assign playful emoji-themed time slots to tasks based on your timezone. Example:

```bash
$ npx chronowhirl --tz=America/New_York --tasks="Write report,Attend meeting,Code" 

🌅 Sunrise Samurai Slot: Write report
💻 Cybernetic Core Time: Code
🤝 Zoom Zenith: Attend meeting
```
