# nightly-palette-pickr\n\nGenerate a whimsical random color palette for designers.\n\n## Installation\n\n```sh\nnpm install -g ts-node\n# Clone the utility (if not already in your repo)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/nightly-palette-pickr\nnpm install\n```\n\n## Usage\n\n```sh\nts-node src/index.ts [count]\n```\n\nIf `count` is omitted, it defaults to **5**. The output is a JSON array of objects, each with a `name` and a `hex` field.\n\n## Example\n\n```json\n[\n  {\n    "name": "Azure",\n    "hex": "#3fa9c2"\n  },\n  {\n    "name": "Crimson",\n    "hex": "#e0145d"\n  }\n]\n```\n\n## Testing\n\nRun the bundled test script to verify functionality:\n\n```sh\nts-node tests/test_index.ts\n```\n\nAll tests should pass, confirming that the palette size matches the request and that each hex code is valid.\n
