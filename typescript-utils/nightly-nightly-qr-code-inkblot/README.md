# nightly-qr-code-inkblot\n\nGenerate a whimsical ASCII "inkblot" QR‑like code from any text. Handy for embedding secret messages in plain‑text logs or terminal chats.\n\n## Installation\n\n```sh\nnpm install -g nightly-qr-code-inkblot\n```\n\n## Usage\n\n```sh\nnpx nightly-qr-code-inkblot "Hello, world!"\n```\n\nOutputs an 8×8 block of █ and space characters.\n\n## How it works\n\nThe tool hashes the input string with a simple DJB2 algorithm, then maps the resulting bits onto an 8×8 grid. The pattern is deterministic – the same input always yields the same inkblot.
