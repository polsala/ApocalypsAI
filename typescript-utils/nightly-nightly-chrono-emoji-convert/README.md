# nightly-chrono-emoji-converter\n\nA tiny TypeScript CLI that turns an ISO‑8601 timestamp into a friendly emoji representing the time of day.\n\n## Why?\n\nWhen you want to sprinkle a little personality into logs, chat bots, or commit messages, a single emoji can instantly convey whether something happened at sunrise, midday, sunset, or deep night.\n\n## Installation\n\n```bash\n# Clone the repository (or copy the utility folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/nightly-chrono-emoji-converter\n\n# Install dependencies\nnpm install\n```\n\n## Usage\n\n```bash\n# Run the CLI with an ISO timestamp\nnpx ts-node src/main.ts 2024-03-31T07:45:00Z\n# => 🌅 07:45\n\n# You can also pipe a timestamp\necho 2024-03-31T22:15:00Z | npx ts-node src/main.ts\n# => 🌙 22:15\n```\n\nThe output consists of the emoji followed by the hour and minute in 24‑hour format.\n\n## Emoji Legend\n\n| Hour range (UTC) | Emoji | Description |\n|------------------|-------|-------------|\n| 05‑08            | 🌅    | Sunrise     |\n| 09‑16            | ☀️    | Daytime     |\n| 17‑19            | 🌇    | Sunset      |\n| 20‑04            | 🌙    | Night       |\n\nIf the input cannot be parsed, the tool returns the “❓” emoji.\n\n## Testing\n\n```bash\nnpm test\n```\n\nThe test suite lives in `tests/` and runs with Jest.\n\n## License\n\nMIT – see the LICENSE file in the root of the repository.\n
