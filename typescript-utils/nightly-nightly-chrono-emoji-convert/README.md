# nightly-chrono-emoji-converter\n\n**Convert timestamps into clock‑face emojis**\n\nEver wanted to sprinkle your messages with a tiny clock emoji that matches the time you’re talking about? This tiny TypeScript utility takes an ISO‑8601 date‑time string (or any format `Date` can parse) and returns the nearest hour or half‑hour clock emoji.\n\n## Features\n\n- Accepts any string that JavaScript `Date` can parse.\n- Rounds minutes to the nearest half hour (e.g., 13:14 → 🕐, 13:45 → 🕝).\n- Works as a library function **or** a simple CLI tool.\n\n## Installation\n\n```bash\n# Install ts-node globally (or use npx)\nnpm install -g ts-node typescript\n# Clone the utility (or copy the files)\n# No other dependencies required\n```\n\n## Usage as a library\n\n```ts\nimport { convertToClockEmoji } from "./src/main";\n\nconst emoji = convertToClockEmoji("2023-10-31T13:45:00Z");\nconsole.log(emoji); // 🕝\n```\n\n## Usage as a CLI\n\n```bash\n# Run directly with ts-node\nts-node src/main.ts "2023-10-31T13:45:00Z"\n# Or compile first\ntsc src/main.ts && node src/main.js "2023-10-31T13:45:00Z"\n```\n\nThe CLI prints the emoji to stdout. If the input cannot be parsed, it prints an error message to stderr and exits with code 1.\n\n## Testing\n\n```bash\n# Run the TypeScript tests with ts-node\nnpm install -D @types/node\n# Assuming you have ts-node installed globally\nts-node tests/test_main.ts\n```\n\n## License\n\nMIT – feel free to copy, remix, and spread the emoji love!\n
