# nightly-ansi-color-palette\n\nUtility that prints the 256‑color ANSI palette as a table of colored sample blocks. Helpful for terminal theming, debugging, or just for fun.\n\n## Install\n\n```sh\nnpm install -g nightly-ansi-color-palette\n```\n\n## Usage\n\n```sh\nnacp          # prints full 0‑255 palette\nnacp 16 31    # prints colors 16‑31 only\n```\n\n## API\n\n```ts\nimport { getAnsiColors } from "nightly-ansi-color-palette";\n\n// Returns an array of objects {code, sample}\nconst colors = getAnsiColors(0, 15);\n```\n\n## License\n\nMIT
