# nightly-rot13-cli\n\nA whimsical yet useful command‑line utility that applies the classic ROT13 cipher to any input string.\n\n## Installation\n\n```sh\nnpm install -g ts-node typescript\nnpm install\n```\n\n## Usage\n\n```sh\nnpx ts-node src/rot13.ts \"Hello, World!\"\n```\n\nOutputs:\n\n```\nUryyb, Jbeyq!\n```\n\nYou can also pipe data:\n\n```sh\necho \"Secret Message\" | npx ts-node src/rot13.ts\n```\n\n## API\n\n```ts\nexport function rot13(input: string): string\n```\n\n## Testing\n\n```sh\nnpm test\n```
