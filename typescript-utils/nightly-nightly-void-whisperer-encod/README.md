# nightly-void-whisperer-encoder

A TypeScript utility to encode and decode secret messages using a whimsical void-inspired cipher.

## Usage

Install dependencies:

```bash
npm install
```

Run encoding:

```bash
tsx src/index.ts encode "hello world"
```

Run decoding:

```bash
tsx src/index.ts decode "svool dliow"
```

## Test

```bash
npm test
```
