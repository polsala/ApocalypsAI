# nightly-braille-art\n\nConvert plain text into Unicode Braille characters, turning your messages into tactile‑looking art for the terminal.\n\n## Installation\n\n```sh\nnpm install -g ts-node\n```\n\n## Usage\n\n```sh\nts-node src/index.ts "Hello World"\n```\n\nOutputs:\n\n````\n⠓⠑⠇⠇⠕ ⠺⠕⠗⠇⠙\n````\n\n## API\n\n```ts\nimport { toBraille } from "./src/index";\n\nconst art = toBraille("Your text");\n```\n\n## Testing\n\nRun the bundled test with:\n\n```sh\nnpm install\nnpx ts-node tests/braille.test.ts\n```\n
