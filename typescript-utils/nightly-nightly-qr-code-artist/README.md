# nightly-qr-code-artist\n\nA whimsical command‑line utility that turns any string into an ASCII QR‑code.  Perfect for leaving cryptic messages in the wasteland without any external services.\n\n## Installation\n\n```bash\n# Clone the repo (or copy the generated folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/nightly-qr-code-artist\n# Install dependencies\nnpm install\n# Build and link globally (optional)\nnpm run build && npm link\n```\n\n## Usage\n\n```bash\nnqr [--size N] <text>\n```\n\n- `--size N` – optional odd integer ≥ 11 that controls the QR‑code dimensions (default: 21).\n- `<text>` – the message to encode.\n\nExample:\n\n```bash\nnqr "HELLO WORLD"\n```\n\nWill print an ASCII QR‑code to stdout.\n\n## How it works\n\nThe tool does **not** generate a real QR‑code; instead it creates a deterministic, stylized pattern that mimics a QR‑code using block characters.  The algorithm is pure TypeScript, runs offline, and is fully type‑safe.\n\n## Testing\n\n```bash\nnpm test\n```\n\nRuns the Jest test suite located in `tests/`.\n\n## License\n\nMIT – see LICENSE file in the repository root.\n
