# nightly-qr-cryptic\n\nA whimsical command‑line utility that turns any text into an ASCII QR code, then adds a “radiation” overlay to give it a post‑apocalyptic feel.\n\n## Installation\n\n```sh\nnpm install -g nightly-qr-cryptic\n```\n\n## Usage\n\n```sh\nnqr "Hello, wasteland!"\n```\n\nThe command prints an ASCII QR code to stdout. Use `--no-radiation` to get a plain QR.\n\n## How it works\n\n- Uses `qrcode-terminal` to generate a standard ASCII QR.\n- If radiation mode is enabled, every space character is replaced with the `☢` symbol.\n- Built with TypeScript and packaged as a global CLI via `commander`.\n\n## License\n\nMIT
