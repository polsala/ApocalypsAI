# nightly-dice-roller-cli\n\nA whimsical yet useful command‑line utility written in TypeScript that parses classic RPG dice notation (e.g. `2d6+3`) and rolls the dice, showing each individual roll with a Unicode dice face (when possible) and the final total.\n\n## Features\n\n- Supports notation `NdM`, optional `+K` or `-K` modifiers.\n- Handles default values (`d6` is interpreted as `1d6`).\n- Shows each roll using Unicode dice characters for six‑sided dice (⚀‑⚅).\n- Deterministic unit tests with mocked randomness.\n\n## Installation\n\n```bash\n# Clone the repository (or let the ApocalypsAI agent generate it)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd ApocalypsAI/utils/nightly-dice-roller-cli\n\n# Install dependencies (only dev dependencies needed for testing)\nnpm install\n```\n\n## Usage\n\n```bash\n# Run with npx (requires ts-node)\nnpx ts-node src/main.ts 2d6+3\n\n# Or compile first\n npx tsc src/main.ts && node src/main.js 1d20\n```\n\nThe output will look like:\n\n```
Rolling 2d6+3\nRoll 1: ⚄ (4)\nRoll 2: ⚂ (3)\nModifier: +3\nTotal: 10\n```\n\n## Development\n\nThe core logic lives in `src/main.ts`. Tests are written with Node's built‑in `assert` module and can be run via:\n\n```bash\nnpm test\n```\n\n## License\n\nMIT
