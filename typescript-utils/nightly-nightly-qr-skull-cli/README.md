# nightly-qr-skull-cli\n\nGenerate a tiny QR‑code‑like ASCII art from any text. For a spooky twist, use `--emoji` to replace the black squares with skull emojis. This is a whimsical demo utility; the output is not a real scannable QR code.\n\n## Installation\n\n```sh\nnpm install -g .\n# or run with npx ts-node src/index.ts\n```\n\n## Usage\n\n```sh\nnode dist/index.js "Hello World"\nnode dist/index.js "Secret" --emoji\n```\n\n## Options\n\n- `--emoji` – replace `#` characters with 💀.\n\n## License\n\nMIT
