# nightly-dice-roller\n\nA whimsical CLI utility that rolls dice expressed in standard RPG notation (e.g., `2d6+3`). It prints each die as a Unicode face (for d6) and shows the total.\n\n## Installation\n\n```sh\nnpm install -g nightly-dice-roller\n```\n\n## Usage\n\n```sh\nnpx nightly-dice-roller 3d6+2\n```\n\nOutput example:\n\n```\n⚄ ⚂ ⚁ +2 = 12\n```\n\n## API\n\nExported functions `parseNotation`, `rollDice`.
