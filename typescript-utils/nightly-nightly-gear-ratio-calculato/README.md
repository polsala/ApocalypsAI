# Nightly Gear Ratio Calculator\n\nA whimsical yet practical TypeScript utility that calculates the overall gear ratio and determines whether the final gear rotates in the same direction as the first gear.\n\n## Features\n\n- Accepts an arbitrary list of gear tooth counts.\n- Computes the simplified gear ratio as a fraction (e.g., `3/2`).\n- Indicates if the final gear rotates in the **same** or **opposite** direction as the input gear.\n- Zero‑dependency, runnable with `ts-node` or after compilation with `tsc`.\n\n## Installation\n\n```bash\n# Clone the repository (or copy the utility folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/nightly-gear-ratio-calculator\n\n# Install TypeScript and ts-node (if you don't have them globally)\nnpm install\n```\n\n## Usage\n\nRun the CLI directly with `ts-node`:\n\n```bash\nnpx ts-node src/main.ts 20 40 30\n```\n\n**Output**\n\n```
Gear ratio: 3/2\nDirection: opposite\n```\n\nThe numbers `20 40 30` represent three gears with 20, 40, and 30 teeth respectively.\n\n## API\n\nYou can also import the core function in your own TypeScript projects:\n\n```ts\nimport { computeGearRatio } from "./src/main";\n\nconst result = computeGearRatio([20, 40, 30]);\nconsole.log(result.ratio); // "3/2"\nconsole.log(result.direction); // "opposite"\n```\n\n## Testing\n\nRun the bundled tests with:\n\n```bash\nnpm test\n```\n\nThe test suite uses Node's built‑in `assert` module and does not require any external testing framework.\n\n## License\n\nMIT © ApocalypsAI
