# nightly-emoji-base64-encoder\n\nA tiny, whimsical utility that takes a string, encodes it to Base64, and wraps the result with fun emojis.\n\n## Features\n\n- **Deterministic mode** – provide a numeric seed to get reproducible emoji decorations (useful for testing).\n- **Random mode** – without a seed the utility picks random emojis each run.\n- Pure TypeScript, runs with `ts-node` or after compilation with `tsc`.\n\n## Installation\n\n```bash\n# Clone the repository (or copy the utility folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/typescript-utils/nightly-emoji-base64-encoder\n\n# Install TypeScript and ts-node globally if you don't have them\nnpm install -g typescript ts-node\n\n# Install local dependencies (none required beyond the standard library)\n# No external packages are used, so this step is optional\n```\n\n## Usage\n\n### As a CLI\n\n```bash\n# Encode a string with random emojis\nts-node src/main.ts "Hello, world!"\n\n# Encode with a deterministic seed (e.g., 42)\nts-node src/main.ts "Hello, world!" --seed 42\n```\n\nThe output will look like:\n\n```
🌟SGVsbG8sIHdvcmxkIQ==🔥
```\n\n### As a library\n\n```ts\nimport { encodeWithEmojis } from "./src/main";\n\nconst encoded = encodeWithEmojis("Apocalypse", 7); // deterministic\nconsole.log(encoded); // 🧩QXBvY2FseXNlIQ==🦄\n```\n\n## Testing\n\nRun the bundled tests with:\n\n```bash\nnpm install -g jest\njest\n```\n\nThe test suite checks both deterministic and random behaviours (the random test only verifies format).\n\n## License\n\nMIT – see the root LICENSE file.\n
