# Nightly Wasteland Calendar\n\nA tiny TypeScript utility that translates ordinary Gregorian dates into the **Wasteland Calendar**, a fictional post‑apocalypse dating system.\n\n## How it works\n\n* The **Great Cataclysm** (the start of the wasteland) defaults to `2023-01-01`.\n* One wasteland year = **360 days** (12 months of 30 days each).\n* The utility provides a library function `toWasteland` and a simple CLI.\n\n## Installation\n\n```bash\n# Clone the repo (or copy the generated folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/nightly-wasteland-calendar\n\n# Install dev dependencies (jest, ts‑node, typescript)\nnpm install\n```\n\n## Build & Test\n\n```bash\nnpm run build   # compile TypeScript (optional for CLI)\nnpm test       # run the Jest test suite\n```\n\n## CLI usage\n\n```bash\n# Using ts-node (no build step required)\nnpx ts-node src/index.ts 2024-03-15\n# Optionally specify a custom apocalypse date\nnpx ts-node src/index.ts 2024-03-15 2022-06-01\n```\n\nOutput example:\n\n```
Wasteland Date: Year 1, Month 3, Day 15\n```\n\n## Library usage\n\n```ts\nimport { toWasteland } from './src/index';\n\nconst wc = toWasteland(new Date('2024-03-15'));\nconsole.log(wc); // { year: 1, month: 3, day: 15 }\n```\n\n## License\n\nMIT © ApocalypsAI
