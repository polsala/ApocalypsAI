# nightly-hash-visualizer\n\nUtility that computes SHA-256 hash of a given string and renders a simple visual bar chart of the hash bytes.\n\n## Installation\n\n```sh\nnpm install -g .\n# or\nnpx ts-node src/index.ts "your text"\n```\n\n## Usage\n\n```sh\nnpx ts-node src/index.ts "hello world"\n```\n\nOutputs:\n\n````\nHash: <hex>\nVisual: <bars>\n````\n\n## Development\n\nRun tests:\n\n```sh\nnpm test\n```
