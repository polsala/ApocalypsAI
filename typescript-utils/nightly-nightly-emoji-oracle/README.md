# Nightly Emoji Oracle\n\nA whimsical CLI utility that interprets a string of emojis into short textual meanings, offering a playful fortune‑telling experience.\n\n## Installation\n\n```bash\nnpm install -g ts-node typescript\nnpm install\n```\n\n## Usage\n\n```bash\nnpx ts-node src/index.ts "🤖🌧️"\n```\n\nThe above command will output:\n\n````\nRobot Rain\n````\n\nYou can also install the tool globally:\n\n```bash\nnpm link\nemoji-oracle "🔥💧"\n```\n\n## How it works\n\nThe utility contains a small built‑in dictionary mapping common emojis to words. Unknown emojis are rendered as `???`.\n\n## Testing\n\nRun the tests with:\n\n```bash\nnpm test\n```\n
