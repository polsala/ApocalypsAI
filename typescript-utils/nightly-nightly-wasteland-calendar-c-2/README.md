# Nightly Wasteland Calendar Converter\n\nA tiny TypeScript CLI that translates ordinary Gregorian dates into the **Wasteland Calendar** – the official time‑keeping system after the Great Collapse.\n\n## How the Wasteland Calendar works\n\n* The calendar starts on **2077‑01‑01** (the day the world fell).\n* Each year has **13 months**, each month is exactly **28 days** (364 days total).\n* The 365th day is a special **Sol** day that sits at the end of the year (think of it as a post‑apocalyptic leap day).\n\nThe format is:\n\n```
<year>-<MM>-<DD>   // regular days, e.g. 2090-04-12\n<year> Sol         // the Sol day, e.g. 2090 Sol\n```\n\nIf a date is before the apocalypse the tool reports `Pre‑apocalypse`.\n\n## Install & Run\n\n```bash\n# Clone the repository (or copy the generated folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/nightly-wasteland-calendar-converter\n\n# Install dependencies (Node.js ≥ 18 required)\nnpm install\n\n# Compile TypeScript\nnpm run build\n\n# Run the CLI – give a date string (ISO format) or let it use today\nnode dist/index.js 2080-05-14\n# or\nnode dist/index.js\n```\n\n## Development\n\nThe source lives in `src/index.ts`.  The CLI uses `process.argv[2]` as the input date; if omitted it defaults to the current UTC date.\n\n### Testing\n\n```bash\nnpm test\n```\n\nThe test suite lives in `tests/test_index.ts` and uses Node's built‑in `assert` module – no extra test framework is required.\n\n## Example\n\n```bash\n$ node dist/index.js 2077-12-31\n2077 Sol\n\n$ node dist/index.js 2078-01-01\n2078-01-01\n```\n\nEnjoy tracking time in the new world!\n
