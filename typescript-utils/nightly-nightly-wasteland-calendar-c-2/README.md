Nightly Wasteland Calendar Converter\n\nThis tiny utility translates dates between the standard Gregorian calendar and the Wasteland Calendar, which counts the number of days that have passed since the Great Apocalypse (fixed at 2023-01-01).\n\nFeatures\n--------\n* Convert a Gregorian date (YYYY-MM-DD) to a wasteland day count.\n* Convert a wasteland day count back to a Gregorian date.\n* Simple zero‑dependency command‑line interface.\n\nInstallation\n------------\n1. Ensure you have Node.js (>=14) and npm installed.\n2. Clone the repository and navigate to this utility's folder.\n3. Install TypeScript and build the project:\n   ```\n   npm install\n   npm run build\n   ```\n   (The provided package.json scripts handle compilation.)\n\nUsage\n-----\nAfter building, run the compiled script with Node:\n\n```\nnode dist/index.js to-wasteland 2023-03-15\n```\nOutputs the number of days since the apocalypse (e.g., 73).\n\n```\nnode dist/index.js to-gregorian 73\n```\nOutputs the Gregorian date corresponding to that wasteland day (e.g., 2023-03-15).\n\nThe utility will print a short help message if invoked with incorrect arguments.\n\nTesting\n-------\nRun the test suite with:\n```\nnpm test\n```\nAll tests are deterministic and run offline.\n\nLicense\n-------\nMIT
