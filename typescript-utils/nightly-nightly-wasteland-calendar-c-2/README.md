# Nightly Wasteland Calendar Converter\n\nA tiny TypeScript utility that translates ordinary Gregorian dates into the **Wasteland Calendar**, a fictional dating system used by survivors after the Great Cataclysm (year 2020).\n\n## Features\n\n- **toWasteland(date: Date): string** – Returns a human‑readable Wasteland date like `3 Ember 12`.\n- **toGregorian(year: number, monthName: string, day: number): Date** – Converts a Wasteland date back to a Gregorian `Date` object.\n- Simple command‑line interface (CLI) for quick conversions.\n\n## Calendar Details\n\n- **Wasteland Year** = Gregorian Year – 2020 (the year of the Cataclysm).\n- **Months** are renamed to reflect the harsh new world:\n  1. Mold\n  2. Ash\n  3. Scorch\n  4. Frost\n  5. Radiant\n  6. Gloom\n  7. Tide\n  8. Dust\n  9. Bloom\n 10. Shade\n 11. Ember\n 12. Void\n\n## Installation\n\n```bash\n# Clone the repository (or copy the utility folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/typescript-utils/nightly-wasteland-calendar-converter\n\n# Install TypeScript (if not already installed)\nnpm install -g typescript ts-node\n```\n\n## Usage\n\n### As a library\n\n```ts\nimport { toWasteland, toGregorian } from "./src/index";\n\nconst wasteland = toWasteland(new Date("2023-07-15"));\nconsole.log(wasteland); // "3 Ember 15"\n\nconst gregorian = toGregorian(3, "Ember", 15);\nconsole.log(gregorian.toISOString().split('T')[0]); // "2023-07-15"\n```\n\n### Via CLI\n\n```bash\n# Convert Gregorian → Wasteland\nnpx ts-node src/index.ts --to-wasteland 2023-07-15\n# Output: 3 Ember 15\n\n# Convert Wasteland → Gregorian\nnpx ts-node src/index.ts --to-gregorian "3 Ember 15"\n# Output: 2023-07-15\n```\n\n## Testing\n\n```bash\n# Run the test suite\nnpx ts-node tests/test_index.ts\n```\n\nAll tests should pass without external network access.\n\n---\n\n*Created by the ApocalypsAI Nightly Integrator.*
