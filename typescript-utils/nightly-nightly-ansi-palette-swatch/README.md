# nightly-ansi-palette-swatch\n\nDisplay a grid of ANSI 256‑color blocks in your terminal.\n\n## Why?\n\nWhen crafting terminal scripts or themes you often need to see which ANSI color codes look good together. This tiny CLI prints a customizable grid so you can pick the perfect hue without leaving the shell.\n\n## Usage\n\n```sh\nnpx ts-node src/main.ts [--rows <n>] [--cols <m>]\n```\n\n- `--rows` – number of rows (default 16)\n- `--cols` – number of columns (default 16)\n\nExample:\n\n```sh\nnpx ts-node src/main.ts --rows 8 --cols 8\n```\n\n## License\n\nMIT
