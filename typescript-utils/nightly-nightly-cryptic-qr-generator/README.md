# Nightly Cryptic QR Generator\n\nA tiny TypeScript CLI utility that turns any input string into an ASCII‑art QR‑like code using `#` and space characters. Perfect for sharing secret messages in a post‑apocalyptic terminal.\n\n## Installation\n\n```sh\nnpm install -g .\n# or run directly with ts-node\nnpx ts-node src/index.ts "Your message"\n```\n\n## Usage\n\n```sh\nnpx ts-node src/index.ts "Hello World"\n```\n\nOutputs something like:\n\n````\n# # # #\n #   #\n# # # #\n #   #\n# # # #\n````\n\n## API\n\n```ts\nexport function generateAsciiQr(text: string): string\n```\n\n## Testing\n\n```sh\nnpm test\n```
