# nightly-epic-quest-generator\n\nA whimsical command‑line utility that generates a random epic quest in the style of tabletop role‑playing games. You can provide an optional numeric seed to get reproducible quests.\n\n## Installation\n\n```sh\nnpm install -g ts-node typescript\n```\n\nThen run the script directly with `ts-node`:\n\n```sh\nts-node src/main.ts          # random quest\nts-node src/main.ts --seed 123   # deterministic quest\n```\n\n## Usage\n\n```sh\n$ ts-node src/main.ts\nYour quest: As a Wise Wizard, you must rescue the captive prince in the Mystic Mountain, facing the Evil Sorcerer but the artifact is cursed.\n```\n\n## API\n\n```ts\ngenerateQuest(seed?: number): string\n```\n\nReturns a quest string. If `seed` is supplied, the same quest will be generated each time.\n\n## License\n\nMIT
