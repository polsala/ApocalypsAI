nightly-apocalypse-countdown\n\nA whimsical command line utility that displays a countdown to a user‑specified apocalypse date.\n\nInstallation\n------------\nRun the following command to install globally:\n\n    npm install -g nightly-apocalypse-countdown\n\nUsage\n-----\nInvoke the tool with an ISO‑8601 date string:\n\n    npx nightly-apocalypse-countdown 2025-01-01T00:00:00Z\n\nThe program will print the remaining days, hours, minutes, and seconds until the given date, followed by a random doom message.\n\nDevelopment\n-----------\nTo work on the source code:\n\n    npm install\n    npm run build   # compile TypeScript\n    npm test        # run tests\n\nLicense\n-------\nMIT
