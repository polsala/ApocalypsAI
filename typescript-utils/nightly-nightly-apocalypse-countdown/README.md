# Apocalypse Countdown\n\nA tiny TypeScript CLI that tells you how much time is left until the apocalypse (or any future date you choose).\n\n## Install\n\n```bash\n# If you have Node.js and npm installed\nnpm install -g typescript ts-node\n# Clone the utility (or copy the files) and run it with ts-node\n```\n\n## Usage\n\n```bash\n# Run directly with ts-node\nts-node src/index.ts 2025-12-31T23:59:59Z\n```\n\nOutput example:\n\n```
365d 5h 12m 30s remaining\n```\n\nIf the date is in the past, you will see:\n\n```
The apocalypse has already arrived!\n```\n\n## API\n\nYou can also import the `getCountdown` function in your own TypeScript/JavaScript code:\n\n```ts\nimport { getCountdown } from './src/index';\nconst msg = getCountdown('2030-01-01T00:00:00Z');\nconsole.log(msg);\n```\n\n## Testing\n\nRun the tests with `ts-node` (no extra test framework required):\n\n```bash\nts-node tests/test_index.ts\n```\n\nAll tests should pass and print `All tests passed`.\n
