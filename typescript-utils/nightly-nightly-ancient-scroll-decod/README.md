# nightly‑ancient‑scroll‑decoder\n\n## Overview\n\n`nightly‑ancient‑scroll‑decoder` is a tiny TypeScript command‑line utility that pretends to translate mysterious ancient scrolls.\n\nThe scrolls are just regular English text that has been Caesar‑shifted by a number of positions equal to the current weekday (Monday = 1, Tuesday = 2, …, Sunday = 0). The tool reads the encoded string from the command line (or STDIN) and prints the decoded message.\n\n## Installation\n\n```bash\n# Clone the repository (or copy the utility folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/nightly-ancient-scroll-decoder\n# Install dependencies (only dev dependencies for testing)\nnpm install\n# Run with ts-node (no compilation needed)\nnpx ts-node src/index.ts "Uifsf jt b tfdsfu dpnf!"\n```\n\n## Usage\n\n```bash\n# Decode a scroll passed as an argument\nnpx ts-node src/index.ts "Uifsf jt b tfdsfu dpnf!"\n\n# Or pipe it via STDIN\necho "Uifsf jt b tfdsfu dpnf!" | npx ts-node src/index.ts\n```\n\nThe utility will automatically determine the shift based on the current weekday (according to the system clock).\n\n## How it works\n\n1. Determine the shift: `weekdayShift = (currentDay % 7)` where Monday = 1, …, Sunday = 0.\n2. Apply a reverse Caesar shift to each alphabetic character. Non‑alphabetic characters are left untouched.\n\n## Testing\n\n```bash\nnpm test\n```\n\nThe test suite verifies the decoding logic for each weekday using mocked dates, ensuring deterministic results.\n\n## License\n\nMIT © ApocalypsAI
