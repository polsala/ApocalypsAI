# nightly‑iso8601‑duration‑parser\n\nA tiny, zero‑dependency TypeScript CLI that turns ISO‑8601 duration strings (e.g. `P3DT4H5M6S`) into a friendly, human‑readable description like `3 days, 4 hours, 5 minutes, 6 seconds`.\n\n## Install\n\n```bash\n# Clone the utility (or copy the folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/nightly-iso8601-duration-parser\n# Install TypeScript locally (dev dependency)\nnpm install typescript@5 --save-dev\n# Compile\nnpx tsc\n```\n\n## Usage\n\n```bash\nnode dist/index.js P3DT4H5M6S\n# → 3 days, 4 hours, 5 minutes, 6 seconds\n\nnode dist/index.js PT20M\n# → 20 minutes\n```\n\nYou can also import the library in your own TypeScript/JavaScript code:\n\n```ts\nimport { parseDuration } from "./src/index";\nconsole.log(parseDuration("P2D")); // "2 days"\n```\n\n## Testing\n\n```bash\n# Run the bundled test (requires ts-node)\nnpm install ts-node@10 --save-dev\nnpx ts-node tests/test_index.ts\n```\n\nAll tests should output `All tests passed`.\n\n## License\n\nMIT – see LICENSE file in the repository root.\n
