Nightly Radiation Calculator\n\nThis tiny utility helps post‑apocalyptic survivors estimate their total radiation exposure based on time spent in different zones.\n\nInput format (JSON array)\n--------------------------------\nEach element must be an object with two numeric fields:\n  - durationHours: number of hours spent in the zone\n  - levelSieverts: radiation level in sieverts per hour\n\nExample input (file or stdin)\n[\n  {\n    "durationHours": 2,\n    "levelSieverts": 0.1\n  },\n  {\n    "durationHours": 3,\n    "levelSieverts": 0.05\n  }\n]\n\nRunning the tool\n----------------\n  npx ts-node src/main.ts path/to/input.json\n  # or pipe via stdin\n  cat input.json | npx ts-node src/main.ts\n\nOutput (JSON)\n{\n  "totalSievertHours": 0.35,\n  "warning": null\n}\nIf the total exceeds 1 sievert‑hour, a warning string is returned.\n\nTesting\n-------\nRun the bundled tests with:\n  npm test\n
