# nightly-plant-care-scheduler\n\n**What it does**\n\n`nightly-plant-care-scheduler` reads a JSON file describing your houseplants, each with a watering interval (in days) and the date it was last watered. It then prints a list of plants with the next watering date, sorted by the soonest due date.\n\n**Why it exists**\n\nBecause remembering when to water each plant can be a nightmare, especially when you have a jungle on your windowsill. This tiny utility turns that chaos into a tidy schedule – and it does it with a dash of TypeScript type‑safety and a sprinkle of whimsy.\n\n**Installation**\n\n```bash\n# Clone the repository (or copy the generated folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/nightly-plant-care-scheduler\n\n# Install dependencies (only dev dependencies are needed for testing)\nnpm install\n\n# Build the TypeScript source\nnpm run build\n\n# Run the CLI (see usage below)\nnode dist/index.js plants.json\n```\n\n**Usage**\n\n1. Create a JSON file describing your plants. Example (`plants.json`):\n\n```json\n[\n  {\n    "name": "Spider Plant",\n    "intervalDays": 7,\n    "lastWatered": "2024-05-20"\n  },\n  {\n    "name": "Aloe Vera",\n    "intervalDays": 14,\n    "lastWatered": "2024-05-15"\n  }\n]\n```\n\n2. Run the scheduler:\n\n```bash\nnode dist/index.js plants.json\n```\n\nThe output will look like:\n\n````\nNext watering schedule (as of 2024-06-02):\n1. Spider Plant – 2024-06-03\n2. Aloe Vera – 2024-06-09\n````\n\n**Running the tests**\n\n```bash\nnpm test\n```\n\nThe test suite validates the core scheduling logic with deterministic, offline data.\n\n**License**\n\nMIT – see LICENSE file in the repository root.\n
