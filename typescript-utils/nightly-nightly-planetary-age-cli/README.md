# nightly-planetary-age-cli\n\nCalculate your age on each planet of the solar system.\n\n## Installation\n\nThe utility is a single TypeScript file with no external dependencies. To run it you need Node.js (>=14) and `ts-node`.\n\n```sh\n# Install ts-node globally if you haven't already\nnpm install -g ts-node\n```\n\n## Usage\n\n```sh\n# Replace <earth_years> with your age in Earth years\nnpx ts-node src/main.ts <earth_years>\n```\n\nExample:\n\n```sh\nnpx ts-node src/main.ts 30\n```\n\nOutput (rounded to two decimal places):\n\n```
Your age on each planet (in planetary years):\nMercury: 124.58\nVenus: 48.73\nEarth: 30\nMars: 15.95\nJupiter: 2.53\nSaturn: 1.02\nUranus: 0.36\nNeptune: 0.18\nPluto: 0.12\n```\n\n## How it works\n\nThe script divides the Earth‑year age by each planet's orbital period (in Earth years) and rounds the result to two decimal places.\n\n## Testing\n\nRun the test suite with Node (no test framework required):\n\n```sh\nnode tests/test_main.ts\n```\n\nAll tests should pass and print a confirmation message.
