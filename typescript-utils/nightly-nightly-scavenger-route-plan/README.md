# nightly‑scavenger‑route‑planner\n\nA tiny TypeScript CLI that takes a JSON file describing locations (name and x/y coordinates) and outputs an ordered scavenger route using a simple nearest‑neighbor heuristic. Perfect for post‑apocalyptic map‑making or any adventure‑planning scenario.\n\n## Install\n\n```bash\n# Clone the repo (or copy the utility folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/nightly-scavenger-route-planner\n\n# Install dependencies (only Node.js is required)\nnpm install\n```\n\n## Usage\n\n```bash\n# Prepare a JSON file with your locations, e.g. locations.json\nnode dist/main.js locations.json\n```\n\nThe input file must be an array of objects with the shape:\n\n```json\n[\n  {"name": "Abandoned Store", "x": 12, "y": 5},\n  {"name": "Radiated Lake", "x": 3, "y": 8},\n  {"name": "Old Factory", "x": 9, "y": 2}\n]\n```\n\nThe program prints the ordered list of location names that constitute the route, starting from the first entry in the input file.\n\n## Build\n\n```bash\n# Compile TypeScript to JavaScript\nnpm run build\n```\n\n## Test\n\n```bash\nnpm test\n```\n\n## License\n\nMIT
