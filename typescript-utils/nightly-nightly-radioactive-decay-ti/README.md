# Nightly Radioactive Decay Timer\n\nA tiny TypeScript CLI that calculates how much of a radioactive substance remains after a given elapsed time, based on its half‑life. Perfect for post‑apocalypse scientists (or anyone curious about decay).\n\n## Installation\n\n```sh\nnpm install -g ts-node typescript\n```\n\nSave the utility files and run:\n\n```sh\nts-node src/main.ts <initial> <half-life> <elapsed>\n```\n\n- `<initial>` – initial amount (grams)\n- `<half-life>` – half‑life (years)\n- `<elapsed>` – elapsed time (years)\n\n## Example\n\n```sh\n$ ts-node src/main.ts 100 30 90\nInitial amount: 100 g\nHalf‑life: 30 years\nElapsed time: 90 years\nRemaining amount: 12.5 g\n```\n\n## How it works\n\nThe remaining amount is computed with the formula:\n\n````\nremaining = initial * 0.5^(elapsed / halfLife)\n````\n\n## License\n\nMIT
