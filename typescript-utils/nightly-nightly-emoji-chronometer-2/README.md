# nightly-emoji-chronometer\n\nA whimsical CLI that displays a countdown timer as an emoji progress bar.\n\n## Installation\n\n```sh\nnpm install -g ts-node typescript\n```\n\n## Usage\n\n```sh\nts-node src/main.ts --duration "1h30m"\n```\n\nThe tool will print an emoji bar representing the remaining time.\n\n## How it works\n\n- `--duration` accepts a human‑readable duration (e.g., "2h15m10s").\n- The bar consists of 🟩 for elapsed time and 🟥 for remaining time.\n- The length of the bar defaults to 10 emojis but can be changed with `--length`.\n\n## Testing\n\nRun the tests with:\n\n```sh\nts-node tests/test_util.ts\n```
