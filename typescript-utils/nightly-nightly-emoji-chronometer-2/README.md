# Emoji Chronometer\n\nConvert a time string (HH:MM) into a clock‑face emoji.\n\n## Installation\n\n```sh\nnpm install -g nightly-emoji-chronometer\n```\n\n## Usage\n\n```sh\nemoji-chronometer 13:45\n🕑\n```\n\nThe tool rounds minutes <15 to the hour, 15‑44 to the half‑hour, and >=45 to the next hour.\n\n## API\n\n```ts\nimport { timeToEmoji } from 'emoji-chronometer';\nconsole.log(timeToEmoji('09:15')); // 🕤\n```\n\n## License\n\nMIT
