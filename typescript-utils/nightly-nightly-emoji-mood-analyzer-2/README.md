# nightly-emoji-mood-analyzer\n\nAnalyzes a short text and returns a fitting emoji that reflects its mood.\n\n## Install\n\n```sh\nnpm install -g ts-node typescript\n```\n\n## Usage\n\n```sh\nnpx ts-node src/index.ts "I love sunny days!"\n```\n\nOutputs: 😊\n\n## How it works\n\nUses a tiny built‑in sentiment dictionary to score words and picks an emoji from three buckets: positive 😊, neutral 😐, negative 😞.\n
