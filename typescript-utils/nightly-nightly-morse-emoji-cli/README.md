# nightly-morse-emoji-cli\n\nConvert any text into Morse code displayed with emojis.\n\n## What it does\n\n- Takes an input string from the command line\n- Translates each character to Morse code\n- Renders dots as `🔹` and dashes as `🔸`\n- Outputs the result to stdout\n\n## Installation\n\n```bash\n# Clone the repository (or install via npm if published)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/nightly-morse-emoji-cli\nnpm install -g .\n```\n\n## Usage\n\n```bash\nmorse-emoji "SOS"\n# => 🔸🔸🔸 🔹🔹🔹 🔸🔸🔸\n\nmorse-emoji "Hello World"\n# => 🔹🔹🔹🔹 🔹🔹 🔹🔹🔹🔹 🔹🔹🔹🔹 🔹🔹🔹🔹 / 🔸🔹🔹🔹 🔹🔹🔹🔹 🔹🔹🔹🔹 🔹🔹🔹🔹 🔸🔹🔹🔹\n```\n\n## Development\n\nThe source lives in `src/main.ts`.  Run the tests with:\n\n```bash\nnpm test\n```\n\n## License\n\nMIT
