# nightly-wasteland-gear-opt\n\nA whimsical yet practical command‑line utility that helps post‑apocalypse survivors pick the best combination of gear without exceeding a weight limit. It uses the classic 0/1 knapsack algorithm.\n\n## Installation\n\n```sh\nnpm install -g ts-node typescript\nnpm install\n```\n\n## Usage\n\nCreate a JSON file describing your gear, e.g. `gear.json`:\n\n```json\n[\n  {"name": "Water Bottle", "weight": 3, "value": 10},\n  {"name": "Canned Food", "weight": 2, "value": 9},\n  {"name": "Radio", "weight": 4, "value": 7}\n]\n```\n\nRun the optimizer:\n\n```sh\nnpx ts-node src/index.ts gear.json 5\n```\n\nOutput:\n\n````\nSelected gear:\n- Water Bottle (weight: 3, value: 10)\n- Canned Food (weight: 2, value: 9)\nTotal weight: 5, total value: 19\n````\n\n## Testing\n\n```sh\nnpm test\n```\n\n## License\n\nMIT
