# QR Message Encoder\n\nA whimsical yet handy CLI that encrypts a text message with a passphrase and encodes the ciphertext into a QR code. Perfect for leaving secret notes for future survivors.\n\n## Install\n\n```sh\nnpm install -g commander qrcode\nnpm install -g .\n```\n\n(Or run with `npx ts-node` after cloning.)\n\n## Usage\n\n```sh\nqr-message -m "Meet at sunrise" -p "s3cr3t" -o secret.png\n```\n\n- `-m, --message` – The plain‑text message.\n- `-p, --passphrase` – Passphrase used for AES‑256‑CBC encryption.\n- `-o, --output` – Optional file path to write the PNG. If omitted, the QR data URL is printed.\n\n## How it works\n\n1. The message is encrypted with a random IV and a key derived from the passphrase.\n2. The ciphertext (hex‑encoded) is turned into a QR code.\n3. The QR code can be scanned and decrypted with the same passphrase using the companion library.\n\n## Testing\n\n```sh\nnpm test\n```\n
