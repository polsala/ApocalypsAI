# nightly-passphrase-emoji-cli\n\nA whimsical yet practical command‑line utility written in TypeScript that creates strong, memorable passphrases.\n\n## Features\n\n- Randomly selects words from a built‑in list\n- Optional inclusion of a numeric digit\n- Optional inclusion of a fun emoji (perfect for post‑apocalyptic passwords)\n- Customizable word count and delimiter\n- Zero external dependencies – just Node.js (v14+) and the built‑in `crypto` module\n\n## Installation\n\n```bash\n# Clone the repository (or copy the utility folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/typescript-utils/nightly-passphrase-emoji-cli\n\n# Install TypeScript and ts-node globally if you don't have them\nnpm install -g typescript ts-node\n\n# Install local dependencies (none required)\nnpm install\n```\n\n## Usage\n\nYou can run the utility directly with `ts-node` or compile it first.\n\n```bash\n# Run without compilation\nts-node src/main.ts 5 _ --num --emoji\n\n# Compile to JavaScript and run with node\ntsc src/main.ts --outDir dist\nnode dist/main.js 4 - --emoji\n```\n\n### Arguments\n\n1. **wordCount** (optional) – Number of words in the passphrase (default: 4)\n2. **delimiter** (optional) – String used to join parts (default: `-`)\n3. `--num` – Append a random digit at the end\n4. `--emoji` – Append a random emoji at the end\n\n## Example\n\n```bash\n$ ts-node src/main.ts 3 _ --num --emoji\nalpha_bravo_charlie_7_⚡\n```\n\n## Testing\n\nRun the bundled test with Node:\n\n```bash\nnpm test\n```\n\nThe test uses a deterministic mock of `crypto.randomInt` to ensure repeatable results.\n\n## License\n\nMIT – see the LICENSE file in the repository root.
