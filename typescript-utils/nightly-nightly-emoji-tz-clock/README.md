# nightly-emoji-tz-clock\n\nConvert a time from one timezone to another and receive a whimsical emoji that represents the time of day.\n\n## Installation\n\n```sh\nnpm install -g nightly-emoji-tz-clock\n```\n\n## Usage\n\n```sh\nemoji-tz-clock --time "2023-08-01T14:30:00Z" --to-tz "Asia/Tokyo"\n```\n\nThe tool will output the converted time together with an emoji, for example:\n\n```
2023-08-02 23:30 (🌙)\n```\n\n## Options\n\n- `--time <ISO>`: The source time in ISO‑8601 format (must include a trailing `Z` or offset).\n- `--to-tz <IANA tz>`: Target timezone (e.g., `America/New_York`).\n\n## How it works\n\n1. The ISO string is parsed into a `Date` (UTC).\n2. `Intl.DateTimeFormat` formats the date in the target timezone.\n3. The hour of the formatted time is mapped to an emoji:\n   - 05‑11 → 🌅 (sunrise)\n   - 12‑17 → ☀️ (sun)\n   - 18‑21 → 🌇 (sunset)\n   - 22‑04 → 🌙 (moon)\n\n## License\n\nMIT\n
