# nightly‑color‑palette‑cli\n\n**What it does**\n\n`nightly‑color‑palette‑cli` is a tiny Node.js command‑line utility written in TypeScript.  Give it a hex colour (e.g. `#3498db`) and it prints a five‑colour palette:\n\n1. **Original** – the colour you supplied\n2. **Complementary** – the colour opposite on the colour wheel (implemented as RGB inversion for simplicity)\n3. **Lighter** – the original colour brightened by 20 %\n4. **Darker** – the original colour darkened by 20 %\n5. **Grayscale** – the original colour converted to a shade of gray\n\nThe output is colour‑coded in the terminal (using ANSI escape codes) and also listed as plain hex strings for copy‑pasting.\n\n## Installation\n\n```bash\n# Clone the repository (or copy the folder into your project)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd ApocalypsAI/typescript-utils/nightly-color-palette-cli\n\n# Install dependencies (only dev‑dependencies are needed)\nnpm install\n\n# Build the TypeScript source\nnpm run build\n```\n\n## Usage\n\n```bash\n# After building, run the CLI with a hex colour\nnode dist/main.js #3498db\n```\n\nYou should see something like:\n\n```
Original   : #3498db [38;2;52;152;219m█[0m\nComplement : #cb6724 [38;2;203;103;36m█[0m\nLighter    : #5aa9e6 [38;2;90;169;230m█[0m\nDarker     : #2879a9 [38;2;40;121;169m█[0m\nGrayscale  : #7a7a7a [38;2;122;122;122m█[0m\n```\n\n## Development\n\nThe source lives in `src/main.ts`.  The test suite lives in `tests/main.test.ts` and can be run with:\n\n```bash\nnpm test\n```\n\nThe tests are deterministic and do not require any network access.\n\n## License\n\nMIT – see the root LICENSE file.
