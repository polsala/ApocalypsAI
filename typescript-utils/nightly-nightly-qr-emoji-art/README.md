# nightly-qr-emoji-art\n\nUtility that converts a text string into a whimsical QR‑like emoji art block. Useful for adding fun visual markers to logs, chat messages, or README files.\n\n## Installation\n\n```sh\nnpm install -g nightly-qr-emoji-art\n```\n\n## Usage\n\n```sh\nnpx nightly-qr-emoji-art "Hello World"\n```\n\nOutputs a 10‑column block of colored square emojis representing the input.\n\n## How it works\n\nEach character is mapped to one of four emojis based on its Unicode code point. The resulting sequence is arranged into rows of 10 emojis.\n
