# nightly-qr-emoji-art\n\nA tiny TypeScript CLI that turns any string into a QR‑code‑style emoji art.\nEach character is rendered as an 8‑pixel column using black (⬛) and white (⬜) squares, making the output easy to copy‑paste or display in any terminal.\n\n## Install\n\n```bash\n# Clone the repository (or copy the generated folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/nightly-qr-emoji-art\n# Install dependencies (only Node's built‑in modules are used)\nnpm install\n```\n\n## Usage\n\n```bash\n# Run with npx (no global install needed)\nnpx ts-node src/index.ts "Hello, world!"\n```\n\nThe command prints something like:\n\n```
⬜⬛⬜⬜⬜⬜⬜⬛\n⬛⬜⬜⬜⬜⬛⬜⬜\n⬜⬜⬜⬛⬜⬜⬜⬜\n...\n```\n\n## How it works\n\nThe utility converts each character to its UTF‑16 code point, formats it as an 8‑bit binary string, and maps `1` → ⬛, `0` → ⬜. The resulting rows are joined with newlines.\n\n## Testing\n\n```bash\nnpm test\n```\n\nThe test suite checks that known inputs produce the expected emoji art.\n\n## License\n\nMIT © ApocalypsAI
