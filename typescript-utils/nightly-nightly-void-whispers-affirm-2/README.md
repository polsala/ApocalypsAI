# nightly-void-whispers-affirmations

A whimsical command-line utility written in TypeScript that generates affirmations whispered from the cosmic void. Perfect for developers seeking a touch of existential levity.

## Features

- Generates random affirmations with a sci-fi twist
- Lightweight and fast
- Zero dependencies outside of Node.js built-ins

## Usage

```bash
npx ts-node src/index.ts
```

Example output:

```
The void murmurs: You are a radiant anomaly in the cosmic silence.
```

## Tests

Run tests with:

```bash
npm test
```

Tests use mocked outputs to ensure deterministic results.
