# nightly-emoji-crypt\n\nEncode and decode messages using a whimsical emoji substitution cipher.\n\n## Installation\n\n```sh\nnpm install\n```\n\n## Usage\n\n```ts\nimport { encode, decode } from "./src/index";\n\nconst secret = encode("hello world");\nconsole.log(secret); // 😀😁😂...\n\nconst plain = decode(secret);\nconsole.log(plain); // hello world\n```\n\n## CLI\n\nThe module can also be executed directly as a CLI.\n\n```sh\nnode dist/index.js encode "hello world"\nnode dist/index.js decode "😀😁😂..."\n```\n\n## License\n\nMIT
