# nightly-emoji-crypt\n\nUtility to encode and decode strings into a whimsical emoji cipher.\n\n## Installation\n\n```sh\nnpm install -g .\n```\n\n## Usage\n\n```sh\nnode src/main.js encode "Hello World"\n# => 😀🔑🔒🔒🔓 🌍🔓🔒🔒🔑\n\nnode src/main.js decode "😀🔑🔒🔒🔓 🌍🔓🔒🔒🔑"\n# => hello world\n```\n\n## How it works\n\nThe tool maps alphanumeric characters (a‑z, 0‑9) to a fixed set of emojis. Characters not in the map are left unchanged. Encoding lower‑cases the input, and decoding restores the original lower‑cased text.\n\n## License\n\nMIT
