# Nightly Temporal Task Juggler\n\nA whimsical-yet-useful utility to prioritize your daily (or hourly, or minute-ly) tasks in a world where time itself is... shifty. This tool helps you sort your to-dos based on their urgency and their inherent "temporal stability," ensuring you tackle the most critical and least likely-to-vanish tasks first.\n\n## Features\n\n*   **Temporal Stability Classification**: Assign tasks one of four stability levels: `Rift-Prone`, `Unstable`, `Flickering`, or `Stable`.\n*   **Urgency Prioritization**: Define a numerical urgency for each task (higher is more urgent).\n*   **Intelligent Sorting**: Tasks are prioritized first by urgency (highest first), then by temporal stability (most stable first), and finally alphabetically by name.\n*   **Type-Safe**: Built with TypeScript for robust data handling and fewer temporal paradoxes.\n\n## Installation\n\n1.  Navigate to the `nightly-temporal-task-juggler` directory.\n2.  Install dependencies:\n    ```bash\n    npm install\n    ```\n3.  Compile the TypeScript code:\n    ```bash\n    npm run build\n    ```\n\n## Usage\n\nThe `nightly-temporal-task-juggler` expects a JSON array of tasks as input, either piped to stdin or provided as a file path argument.\n\n### Task Structure\n\nEach task should be a JSON object with the following properties:\n\n*   `name`: `string` - A descriptive name for the task.\n*   `urgency`: `number` - A numerical value indicating urgency (higher is more urgent).\n*   `stability`: `number` - A numerical value corresponding to `TemporalStability`:\n    *   `0`: `RiftProne` (Might vanish at any moment!)\n    *   `1`: `Unstable` (Likely to be disrupted)\n    *   `2`: `Flickering` (Occasionally shifts, but generally present)\n    *   `3`: `Stable` (Solid, reliable, won't disappear)\n*   `description`?: `string` (Optional) - Additional details about the task.\n\n### Example Input (`tasks.json`)\n\n```json\n[\n  {\n    "name": "Secure the Chrono-Capacitor",\n    "urgency": 10,\n    "stability": 0,\n    "description": "Critical component, highly susceptible to temporal distortion."\n  },\n  {\n    "name": "Scavenge for Rations",\n    "urgency": 7,\n    "stability": 3,\n    "description": "Daily necessity, usually a stable endeavor."\n  },\n  {\n    "name": "Repair Flux Regulator",\n    "urgency": 8,\n    "stability": 1,\n    "description": "Important, but the regulator itself is a bit wobbly."\n  },\n  {\n    "name": "Calibrate Temporal Anomaly Detector",\n    "urgency": 7,\n    "stability": 2,\n    "description": "Needs regular adjustment, sometimes the readings flicker."\n  },\n  {\n    "name": "Organize Spare Parts",\n    "urgency": 3,\n    "stability": 3,\n    "description": "Low priority, but a very stable task."\n  }\n]\n```\n\n### Running the Juggler\n\n#### From a file:\n\n```bash\nnpm start tasks.json\n```\n\n#### From stdin:\n\n```bash\necho '[{"name":"Task A","urgency":5,"stability":3},{"name":"Task B","urgency":8,"stability":1}]' | npm start\n```\n\n### Example Output (for `tasks.json` above)\n\n```json\n[\n  {\n    "name": "Secure the Chrono-Capacitor",\n    "urgency": 10,\n    "stability": 0,\n    "description": "Critical
