# nightly-quest-randomizer\n\nGenerate a whimsical quest for tabletop RPGs.\n\n## Installation\n\n```sh\nnpm install -g nightly-quest-randomizer\n```\n\n## Usage\n\n```sh\nnqr [--seed <number>]\n```\n\nOutputs a quest like: \"Brave adventurers must retrieve the Lost Spoon from the Cursed Bakery, guarded by a mischievous pastry golem.\"\n\n## How it works\n\nUses a deterministic pseudo‑random generator seeded by the provided number (default 42) to combine random elements.
