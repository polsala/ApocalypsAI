# nightly‑passphrase‑emoji‑mixer\n\nA tiny TypeScript CLI that creates a passphrase made of random words followed by a handful of emojis.\n\n## Features\n\n- Choose how many words and emojis you want.\n- Fully type‑safe implementation.\n- No external dependencies – just plain Node.js.\n- Deterministic tests using a mocked random generator.\n\n## Installation\n\n```bash\n# Clone the repository (or copy the utility folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/typescript-utils/nightly-passphrase-emoji-mixer\n\n# Install TypeScript (if you don\'t have it)\nnpm install -g typescript\n\n# Compile the source\ntsc\n```\n\n## Usage\n\n```bash\nnode dist/index.js --words 4 --emojis 2\n```\n\nThe command above might output something like:\n\n```
alpha delta golf hotel 🚀 🌟
```\n\n## CLI Options\n\n- `--words <number>` – Number of words in the passphrase (default: 4).\n- `--emojis <number>` – Number of emojis to append (default: 2).\n\n## Development\n\nTo run the tests:\n\n```bash\nnpm install\nnpm test\n```\n\n## License\n\nMIT – see the LICENSE file in the repository root.
