# Nightly Apocalypse Color Namer\n\nA whimsical TypeScript utility that converts a hex color code into an apocalypse‑themed name.\n\n## Installation\n\n```sh\nnpm install -g nightly-apocalypse-color-namer\n```\n\n## Usage\n\n```sh\nnpx nightly-apocalypse-color-namer #ff4500\n```\n\nThe command prints a name such as `Scorched Red`.\n\n## API\n\n```ts\nimport { getApocalypseColorName } from "./src";\n\nconst name = getApocalypseColorName("#ff4500");\nconsole.log(name); // => "Scorched Red"\n```\n\n## How it works\n\nThe tool parses the hex value, converts it to HSV to determine a base color (Red, Orange, Yellow, Green, Blue, Purple) and then adds a post‑apocalyptic adjective based on the overall brightness.\n
