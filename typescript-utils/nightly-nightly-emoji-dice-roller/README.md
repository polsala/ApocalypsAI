nightly-emoji-dice-roller\n\nA whimsical CLI utility that rolls dice and displays the results using emoji faces.\n\nInstallation\n------------\nRun the following command in the utility directory to install globally (requires Node.js and npm):\n\n    npm install -g .\n\nUsage\n-----\nInvoke the tool with two arguments: the number of sides on the dice and how many dice to roll.\n\n    npx nightly-emoji-dice-roller <sides> <count>\n\nExample\n-------\n\n    npx nightly-emoji-dice-roller 6 3\n\nPossible output:\n\n    🎲 3️⃣ 5️⃣ 2️⃣ (total: 10)\n\nHow it works\n------------\nThe program maps numbers 1‑6 to the corresponding digit emojis. It uses Math.random to generate each roll.\n\nTesting\n-------\nRun the test suite with:\n\n    npm test\n\nThe tests mock Math.random to produce deterministic results.
