# nightly-emoji-clock\n\nConvert a time string (``HH:MM``) into the nearest clock‑face emoji.\n\n## Why?\n\nSometimes you just want to sprinkle a little visual flair into logs, chat messages, or terminal output. This tiny utility maps any 24‑hour time to the closest emoji clock (hour or half‑hour).\n\n## Installation\n\n```bash\n# Clone the repository (or copy the utility folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/nightly-emoji-clock\n# Install TypeScript and ts-node if you don't have them\nnpm install -g typescript ts-node\n```\n\n## Usage\n\n```bash\n# Directly via ts-node\nts-node src/main.ts 14:45\n# => 🕔\n\n# Or compile to JavaScript first\ntsc src/main.ts --outDir dist\nnode dist/main.js 09:20\n# => 🕘\n```\n\nThe script prints the emoji to ``stdout``. Invalid inputs result in an error message and a non‑zero exit code.\n\n## API\n\nThe core function is exported from ``src/emojiClock.ts`` and can be used programmatically:\n\n```ts\nimport { timeToEmoji } from "./emojiClock";\n\nconst emoji = timeToEmoji("07:30"); // "🕢"\n```\n\n## Testing\n\nRun the bundled tests with ``ts-node``:\n\n```bash\nts-node tests/test_main.ts\n```\n\nYou should see ``All tests passed`` if everything is working.\n
