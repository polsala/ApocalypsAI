# nightly-roman-numeral-cli\n\nConvert between Arabic numbers (1‑3999) and Roman numerals.\n\n## Installation\n\nYou need Node.js (v14+) and `ts-node` (or compile the TypeScript).\n\n```sh\nnpm install -g ts-node typescript\n```\n\n## Usage\n\n```sh\n# Convert a number to a Roman numeral\nnpx ts-node src/index.ts 42\n# => XLII\n\n# Convert a Roman numeral to a number\nnpx ts-node src/index.ts XLII\n# => 42\n```\n\nThe tool validates input and prints an error message for out‑of‑range values or invalid Roman numerals.\n\n## Development\n\nRun the test suite with:\n\n```sh\nnpm install\nnpm test\n```\n\nThe tests are deterministic and run offline.\n
