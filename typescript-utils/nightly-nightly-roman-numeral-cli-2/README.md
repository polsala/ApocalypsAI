# nightly-roman-numeral-cli\n\nA tiny, type‑safe utility written in TypeScript that converts between Arabic numbers and Roman numerals.\n\n## Features\n\n- `to-roman <number>` – converts an integer (1‑3999) to its Roman representation.\n- `from-roman <roman>` – parses a Roman numeral (uppercase) back to an integer.\n- Exposes `toRoman` and `fromRoman` functions for programmatic use.\n- No external dependencies – pure TypeScript/Node.js.\n\n## Installation\n\n```bash\n# Clone the repository (or copy the generated folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/nightly-roman-numeral-cli\n# Install dev dependencies (only for testing)\nnpm install --save-dev typescript ts-node @types/node\n```\n\n## Usage\n\n```bash\n# Run the CLI with ts-node\nnpx ts-node src/index.ts to-roman 1999\n# → MCMXCIX\n\nnpx ts-node src/index.ts from-roman MCMXCIX\n# → 1999\n```\n\nYou can also import the helpers in your own TypeScript project:\n\n```ts\nimport { toRoman, fromRoman } from './src/index';\n\nconsole.log(toRoman(2023)); // MMXXIII\nconsole.log(fromRoman('MMXXIII')); // 2023\n```\n\n## Testing\n\n```bash\n# Run the bundled tests\nnpm test\n```\n\nThe test suite uses Node's built‑in `assert` module and runs with `ts-node`.\n\n## License\n\nMIT – see LICENSE file in the repository root.\n
