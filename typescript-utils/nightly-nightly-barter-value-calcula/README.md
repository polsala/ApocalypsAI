# Nightly Barter Value Calculator

A tiny TypeScript command‑line utility that takes a JSON string describing quantities of common wasteland resources and returns the total barter value.

## How it works

The tool ships with a built‑in price list (you can edit `src/index.ts` to customise):

| Resource | Price per unit |
|----------|----------------|
| water    | 2              |
| food     | 5              |
| ammo     | 10             |
| medicine | 20             |

The CLI expects a single argument – a JSON object where keys are resource names and values are numeric quantities. It validates the input, looks up each resource’s price, multiplies, and sums the results.

## Installation

```bash
# Clone the repository (or copy the utility folder)
git clone https://github.com/polsala/ApocalypsAI.git
cd utils/nightly-barter-value-calculator

# Install dependencies (Node.js >= 18 required)
npm install
```

## Usage

```bash
# Direct execution with ts-node
npx ts-node src/index.ts '{"water":10,"food":5,"ammo":2}'
# => Total barter value: 70

# After building
npm run build
node dist/index.js '{"medicine":3}'
# => Total barter value: 60
```

## Testing

The utility includes a Jest test suite. Run it with:

```bash
npm test
```

All tests are deterministic and use no external services.

## Extending the price list

Edit the `PRICE_TABLE` constant in `src/index.ts` to add or modify resource prices.
