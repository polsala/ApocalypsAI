Nightly Duration Parser\n\nOverview:\nA tiny command‑line utility written in TypeScript that can turn human‑readable duration strings such as \"1d 2h 30m\" into total seconds, and can turn a number of seconds back into a readable string.\n\nInstallation:\n1. Ensure Node.js (>=14) and npm are installed.\n2. From the utility directory run `npm install` to install dependencies.\n3. Run the tool with `npm start -- <command> [args]` or use npx after linking.\n\nUsage:\n  parse "<duration>"\n    Parses a duration string and prints the total number of seconds.\n  format <seconds>\n    Formats a number of seconds into a string like \"1d 2h 3m 4s\".\n\nExamples:\n  npm start -- parse "1h 20m"\n  => 4800\n  npm start -- format 3661\n  => 1h 1m 1s\n\nLicense: MIT
