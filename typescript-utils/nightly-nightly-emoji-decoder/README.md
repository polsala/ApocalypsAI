# nightly-emoji-decoder\n\n## Summary\n\nA whimsical CLI that translates a string of fruit emojis into readable text using a secret emoji‑to‑letter cipher.\n\n## Installation\n\n```sh\nnpm install -g ts-node typescript\n```\n\nOr run directly with `npx ts-node`.\n\n## Usage\n\n```sh\nnpx ts-node src/index.ts "🍎🍌🍒"\n```\n\nOutputs:\n\n````\nabc\n````\n\n## How it works\n\nEach fruit emoji maps to a letter (🍎→a, 🍌→b, 🍒→c, …). Unknown emojis become `?`.\n\n## Testing\n\n```sh\nnpm test\n```\n\nThe test suite runs a few deterministic cases to ensure the decoder behaves as expected.
