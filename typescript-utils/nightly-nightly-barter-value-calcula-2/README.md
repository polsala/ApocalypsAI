# Nightly Barter Value Calculator\n\nA whimsical utility for the post‑apocalyptic trader. It computes a fair trade value for a list of scavenged items based on their rarity and condition.\n\n## Installation\n\n```bash\nnpm install -g ts-node typescript\n```\n\n## Usage\n\n```bash\ncat items.json | ts-node src/main.ts\n```\n\n`items.json` should be an array of objects, for example:\n\n```json\n[\n  {"name":"Rusty Pipe","rarity":"Common","condition":80},\n  {"name":"Solar Panel","rarity":"Rare","condition":55}\n]\n```\n\nThe program prints the total barter value as a number.\n\n## How it works\n\n- **Rarity weights**: Common=1, Uncommon=2, Rare=3, Epic=5, Legendary=8\n- **Condition factor** = `condition / 100` (clamped between 0 and 1)\n- **Item value** = `weight * condition factor * 10`\n- **Total value** = sum of all item values, rounded to the nearest integer.\n\n## Example\n\n```bash\necho '[{"name":"Rusty Pipe","rarity":"Common","condition":80},{"name":"Solar Panel","rarity":"Rare","condition":55}]' | ts-node src/main.ts\n```\n\nOutput:\n\n``\n49\n```\n\nEnjoy fair trades in the wasteland!
