# Nightly Apocalypse Timer\n\nA whimsical TypeScript CLI that turns a number of seconds into a stylized apocalypse countdown using emojis.\n\n## Installation\n\n```sh\nnpm install -g ts-node\n```\n\n## Usage\n\n```sh\nnpx ts-node src/main.ts <seconds>\n```\n\nExample:\n\n```sh\nnpx ts-node src/main.ts 90061\n# Output: 🌎 1 day ⏰ 1 hour 🕑 1 minute ⏱️ 1 second\n```\n\n## API\n\n```ts\nexport function formatApocalypseTimer(seconds: number): string;\n```\n\n## Testing\n\n```sh\nnpm test\n```\n
