# nightly-qr-crypt\n\nA whimsical command‑line utility that turns any text into an ASCII QR code, perfect for secret messages in the wasteland.\n\n## Install\n\n```sh\nnpm install -g nightly-qr-crypt\n```\n\n## Usage\n\n```sh\nnqr "Hello, survivor!"\n```\n\nOptions:\n\n* `-s, --size <n>` – size multiplier (default 1)\n* `-h, --help` – show help\n\nThe tool prints the QR code to stdout using Unicode block characters.
