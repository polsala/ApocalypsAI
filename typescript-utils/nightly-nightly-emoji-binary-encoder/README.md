# nightly-emoji-binary-encoder\n\nEncode a string into a sequence of emojis representing its binary bits (⚪ for 0, ⚫ for 1). Useful for playful secret messages.\n\n## Installation\n\n```sh\nnpm install -g .\n# or run with npx ts-node src/index.ts\n```\n\n## Usage\n\n```sh\nnpx ts-node src/index.ts "Hello"\n```\n\nOutputs an emoji string where each character is represented by eight emojis.\n\n## How it works\n\nEach character is converted to its UTF‑8 code point, then to an 8‑bit binary string. 0 → ⚪, 1 → ⚫. The binary strings for all characters are joined with spaces.\n\n## Example\n\n```sh\n$ npx ts-node src/index.ts A\n⚪⚫⚪⚪⚪⚪⚪⚫\n```\n\n## License\n\nMIT
