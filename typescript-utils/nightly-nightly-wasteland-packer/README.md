# Wasteland Packer\n\nUtility to help scavengers decide which items to carry in the post‑apocalyptic wasteland.\n\n## Installation\n\n```sh\nnpm install -g ts-node\nnpm install\n```\n\n## Usage\n\nRun the script with a JSON string describing the items and the maximum weight you can carry.\n\n```sh\nts-node src/main.ts '{"items":[{"name":"Water","weight":3,"value":10},{"name":"Food","weight":2,"value":7},{"name":"Medkit","weight":5,"value":15}],"maxWeight":5}'\n```\n\nThe program will output a JSON array of the selected item names, e.g.\n\n```json\n["Water","Food"]\n```\n\n## API\n\n```ts\nexport interface Item {\n  name: string;\n  weight: number;\n  value: number;\n}\n\n/**\n * Returns the list of item names that maximize total value without exceeding maxWeight.\n */\nexport function packItems(items: Item[], maxWeight: number): string[];\n```\n\n## Testing\n\n```sh\nnpm test\n```\n\nThe test suite runs a few deterministic scenarios to ensure the algorithm works correctly.
