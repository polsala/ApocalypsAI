# Nightly Wasteland Date Converter\n\nA tiny TypeScript library that translates ordinary Gregorian dates into the post‑apocalyptic **Wasteland Calendar**.\n\n## What is the Wasteland Calendar?\n\n- 13 months, each exactly 28 days long (364 days total)\n- An extra *Year Day* (and *Leap Year Day* on Gregorian leap years) sits at the end of the year\n- Month names are themed for a desolate world\n\n| Month Index | Name   |\n|-------------|--------|\n| 1           | Dust   |\n| 2           | Ash    |\n| 3           | Scorch |\n| 4           | Blaze  |\n| 5           | Ember  |\n| 6           | Cinder |\n| 7           | Char   |\n| 8           | Smog   |\n| 9           | Gloom  |\n| 10          | Dusk   |\n| 11          | Night  |\n| 12          | Shade  |\n| 13          | Wraith |\n\n## Installation\n\n```bash\nnpm install nightly-wasteland-date-converter\n```\n\n## Usage\n\n```ts\nimport { convertToWasteland } from 'nightly-wasteland-date-converter';\n\nconst today = new Date();\nconsole.log(convertToWasteland(today));\n// Example output: "Dust 1, Wasteland Year 2023"\n```\n\n## API\n\n```ts\n/**\n * Convert a Gregorian `Date` object to a Wasteland calendar string.\n * @param date - The Gregorian date to convert.\n * @returns A human‑readable Wasteland date, e.g. "Scorch 3, Wasteland Year 2023" or "Year Day, Wasteland Year 2023".\n */\nexport function convertToWasteland(date: Date): string;\n```\n\n## Testing\n\n```bash\nnpm test\n```\n\nThe test suite runs offline and uses deterministic dates to verify the conversion logic.\n
