# Nightly Barter Calculator\n\nA whimsical utility to compute the total barter value of items in a post‑apocalyptic setting based on scarcity multipliers.\n\n## Usage\n\n```sh\nnpx ts-node src/index.ts --items '{"water":2,"food":3}' --scarcity '{"water":5,"food":2}'\n```\n\nThe command prints the total value (e.g., `16`).\n\n## API\n\n```ts\nimport { calculateBarterValue } from './src/index';\n\nconst items = { water: 2, food: 3 };\nconst scarcity = { water: 5, food: 2 };\nconst total = calculateBarterValue(items, scarcity); // 16\n```\n\n## Testing\n\nRun `npm test` (uses Jest).
