# nightly-emoji-box-cli\n\nCreate a decorative emoji box around any text, perfect for whimsical terminal messages.\n\n## Installation\n\n```sh\nnpm install -g typescript ts-node\n```\n\nCompile or run directly with ts-node:\n\n```sh\nts-node src/index.ts "Hello World"\n```\n\n## Usage\n\n```sh\nnightly-emoji-box-cli "Your message"\n```\n\nOutputs an emoji box, for example:\n\n````\n🟦🟦🟦🟦🟦🟦🟦🟦🟦\n🟦 Your message 🟦\n🟦🟦🟦🟦🟦🟦🟦🟦🟦\n````\n\n## API\n\n```ts\nimport { generateEmojiBox } from "./index";\n\nconst box = generateEmojiBox("Hello");\n```\n\n## License\n\nMIT
