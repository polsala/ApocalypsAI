# nightly-qr-code-cli

Generate QR codes as ASCII art directly from the command line.

## Installation

```sh
npm install -g nightly-qr-code-cli
```

## Usage

```sh
npx nightly-qr-code-cli "Hello, world!"
```

The command prints an ASCII QR code to the terminal.

## How it works

The utility uses the `qrcode` npm package to generate a terminal‑friendly QR code.
