# nightly-void-whisperer-ts

A TypeScript utility that generates whimsical, post-apocalyptic affirmations.

## Usage

```ts
import { generateAffirmation } from './src/void-whisperer';

console.log(generateAffirmation());
```

## Example Output

> "Even in the wasteland, your courage is a beacon."

## Test

Run tests with:

```sh
npm test
```
