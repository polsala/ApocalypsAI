# nightly-braille-art\n\nGenerate Unicode Braille art from plain text for terminal display.\n\n## Usage\n\n```sh\n# Install TypeScript and ts-node if you haven't\nnpm install -g typescript ts-node\n\n# Run the converter\nts-node src/braille.ts "Hello World"\n```\n\nThe command prints a string of Braille characters representing the input.\n\n## API\n\n```ts\nimport { textToBraille } from "./braille";\n\nconst art = textToBraille("Hello");\nconsole.log(art); // → Braille representation\n```\n\n## How it works\n\nEach ASCII character is mapped to a Braille Unicode code point (U+2800 + charCode). The lower 8 bits of the character code are used, so the conversion is reversible for standard ASCII.\n\n## License\n\nMIT
