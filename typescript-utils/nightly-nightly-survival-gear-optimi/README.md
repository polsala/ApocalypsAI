# Survival Gear Optimizer\n\nA tiny TypeScript CLI that selects the best combination of survival items to maximize utility while staying within a weight limit (0/1 knapsack). Perfect for post‑apocalyptic scavengers who need to pack light.\n\n## Install\n\n```sh\nnpm install -g ts-node typescript\n```\n\n## Usage\n\n```sh\nts-node src/main.ts --max-weight 10 --items '[{\"name\":\"Water\",\"weight\":3,\"value\":5},{\"name\":\"Food\",\"weight\":4,\"value\":6},{\"name\":\"Tent\",\"weight\":5,\"value\":7}]'\n```\n\nThe tool will output the names of the selected items.\n\n## How it works\n\nImplements the classic 0/1 knapsack dynamic programming algorithm.\n
