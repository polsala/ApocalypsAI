# Nightly ROT13 Emoji Encoder\n\n## Overview\n\n`nightly-rot13-emoji-encoder` is a tiny TypeScript command‑line utility that takes any input string, applies the classic ROT13 cipher, and then maps each alphabetic character to a distinct emoji. Non‑alphabetic characters are left untouched.\n\nThe result is a fun, emoji‑rich representation of your text – perfect for secret messages, quirky signatures, or just a smile in the apocalypse.\n\n## Installation\n\n```bash\n# Clone the repository (or copy the generated folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/nightly-rot13-emoji-encoder\n\n# Install dependencies (Node.js >= 16)\nnpm install\n```\n\n## Usage\n\nRun the tool with a string argument:\n\n```bash\nnode src/index.js "Hello World!"\n```\n\nOutput (example):\n\n```
🤩😚😑😑😁 😎🥰😚😚😐😑!\n```\n\nYou can also pipe input:\n\n```bash\necho "Secret" | node src/index.js\n```\n\n## Development\n\nThe source lives in `src/index.ts`. Tests are written with Jest and can be run via:\n\n```bash\nnpm test\n```\n\n## License\n\nMIT © ApocalypsAI
