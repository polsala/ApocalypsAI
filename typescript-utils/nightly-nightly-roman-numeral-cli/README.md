# nightly-roman-numeral-cli\n\nConvert between Arabic numbers (1-3999) and Roman numerals.\n\n## Usage\n\n```sh\n# Convert a number to a Roman numeral\nnpx ts-node src/index.ts 42\n# => XLII\n\n# Convert a Roman numeral to a number\nnpx ts-node src/index.ts --from-roman XLII\n# => 42\n```\n\n## Options\n\n- `--from-roman <roman>`: Convert the supplied Roman numeral to an Arabic number.\n- If a single positional argument is provided and it looks like a number, the tool converts it to a Roman numeral.\n\n## Limitations\n\n- Only supports numbers in the range **1‑3999** (the conventional range for Roman numerals).\n- Input is case‑insensitive for Roman numerals.\n\n## Development\n\nThe utility is written in TypeScript and can be run directly with `ts-node` or compiled with `tsc`.\n\n```sh\n# Run tests\nnpm test\n```\n
