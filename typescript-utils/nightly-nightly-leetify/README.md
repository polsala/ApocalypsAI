# nightly-leetify\n\n**Convert any text into playful leet speak** – a whimsical utility that transforms ordinary strings into their leet (1337) equivalents.\n\n## Features\n\n- Simple command‑line interface (CLI)\n- Exported `leetify` function for programmatic use\n- Optional custom mapping to override or extend the default leet dictionary\n\n## Installation\n\n```bash\n# Clone the repository (or copy the utility folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/nightly-leetify\n\n# Install dependencies (none required beyond Node.js)\nnpm install\n```\n\n> **Note**: This utility only relies on the Node.js standard library, so no external packages are needed.\n\n## Usage\n\n### CLI\n\n```bash\nnode src/main.ts "Your text here"\n```\n\nExample:\n\n```bash\nnode src/main.ts "Leet speak is fun!"\n# Output: L33t 5p34k 15 fun!\n```\n\n### Programmatic\n\n```typescript\nimport { leetify } from "./src/main";\n\nconst result = leetify("Hello World");\nconsole.log(result); // H3ll0 W0rld\n```\n\nYou can also provide a custom mapping:\n\n```typescript\nconst custom = { h: "#", e: "&" };\nconsole.log(leetify("hello", custom)); // #&llo\n```\n\n## Testing\n\nRun the bundled tests with Node:\n\n```bash\nnode tests/leetify.test.ts\n```\n\nYou should see `All tests passed` if everything is working.\n\n## License\n\nMIT – see the root LICENSE file.\n
