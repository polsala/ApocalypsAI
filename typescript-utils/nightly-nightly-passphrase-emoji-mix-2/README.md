# nightly-passphrase-emoji-mixer\n\nGenerate whimsical yet strong passphrases composed of random words and optional emojis.\n\n## Installation\n\n```sh\nnpm install -g nightly-passphrase-emoji-mixer\n```\n\n## Usage\n\n```sh\nnpx nightly-passphrase-emoji-mixer --words 4 --emoji\n# example output: "solar 🌞 river 🌊 echo 🌟"\n```\n\n## Options\n\n- `--words <number>`: number of words (default 4)\n- `--emoji`: include a random emoji after each word\n- `--separator <string>`: separator between tokens (default space)\n\n## How it works\n\nUses Node's `crypto` module for cryptographically secure randomness, selects words from a built‑in list, optionally appends emojis.\n
