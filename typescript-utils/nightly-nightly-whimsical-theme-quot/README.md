# Whimsical Theme Quote Generator

CLI tool that generates themed quotes with emoji flair. Use `--theme` and `--mood` flags to customize output.

Example:
```bash
whimsical-quote --theme apocalypse --mood sardonic
# Output: "The end is nigh 🌑, but at least the Wi-Fi will be free! 💻"```

Themes: apocalypse, tech, survival, dystopia
Moods: uplifting, sardonic, hopeful, cryptic
