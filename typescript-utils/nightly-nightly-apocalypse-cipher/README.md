# Nightly Apocalypse Cipher\n\nEncode and decode messages using a whimsical post‑apocalyptic symbol cipher.\n\n## Installation\n\n```sh\nnpm install -g ts-node typescript\n```\n\n## Usage\n\n```sh\n# Encode a message\nts-node src/main.ts encode "your message"\n\n# Decode a message\nts-node src/main.ts decode "encoded message"\n```\n\nThe utility maps each latin letter to a unique apocalyptic symbol. Unknown characters are passed through unchanged.\n\n## Example\n\n```sh\n$ ts-node src/main.ts encode "Apocalypse"\n☢☥☮☯☭☤☥☣☢\n\n$ ts-node src/main.ts decode "☢☥☮☯☭☤☥☣☢"\napocalypse\n```\n\n## License\n\nMIT
