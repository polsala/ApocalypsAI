# nightly-hex-color-cli\n\nA whimsical yet handy CLI that takes a color name or hex code and prints the color’s name, hex value, and a small colored block in your terminal.\n\n## Install\n\n```sh\nnpm install -g .\n```\n\n## Usage\n\n```sh\nhex-color-cli red\n# output: red (#FF0000)   (colored block)\n\nhex-color-cli #00ff7f\n# output: custom (#00FF7F)   (colored block)\n```\n\n## Supported names\n\nred, green, blue, yellow, cyan, magenta, black, white, orange, purple.\n\nAny valid 3‑ or 6‑digit hex code is also accepted.\n\n## Testing\n\n```sh\nnpm test\n```\n\n## License\n\nMIT
