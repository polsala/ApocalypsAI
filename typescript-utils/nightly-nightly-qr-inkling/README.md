# nightly-qr-inkling\n\nA whimsical TypeScript CLI that turns any text into a pseudo‑QR code rendered as ASCII art. Not a real QR scanner, but great for adding mysterious blocks to terminal logs or README files.\n\n## Installation\n\n```sh\nnpm install -g ts-node\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/nightly-qr-inkling\nnpm install\n```\n\n## Usage\n\n```sh\nnpx ts-node src/main.ts "Your secret message"\n```\n\nThe command prints an ASCII block representing the input text.\n\n## How it works\n\nThe tool converts each character to its UTF‑16 code point, then to an 8‑bit binary string. These bits are arranged into a square grid (padding with zeros) and rendered using `█` for 1 and a space for 0.\n\n## Testing\n\nRun the test suite with:\n\n```sh\nnpm test\n```\n\nThe tests are deterministic and run offline.\n
