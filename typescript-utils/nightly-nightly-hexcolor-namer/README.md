# nightly-hexcolor-namer\n\n**nightly-hexcolor-namer** is a tiny TypeScript command‑line utility that converts a hexadecimal colour code (e.g. `#ff5733`) into a whimsical, fantasy‑style colour name such as "Red Fury" or "Indigo Twilight".\n\n## Features\n\n- Accepts colour codes with or without a leading `#`.\n- Works in any Node.js environment (no external dependencies).\n- Deterministic mapping based on the colour's hue, so the same input always yields the same name.\n\n## Installation\n\n```bash\n# Clone the repository (or copy the generated files into your project)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/nightly-hexcolor-namer\n\n# Install TypeScript and ts-node if you don't have them\nnpm install -g typescript ts-node\n```\n\n## Usage\n\n```bash\n# Run the CLI directly with ts-node\nts-node src/index.ts "#ff5733"\n# → Red Fury\n\n# Or compile to JavaScript first\ntsc src/index.ts --outDir dist\nnode dist/index.js "00ff00"\n# → Green Meadow\n```\n\n## API\n\nThe core function is exported for programmatic use:\n\n```ts\nimport { getColorName } from "./src/index";\n\nconst name = getColorName("#3498db");\nconsole.log(name); // Blue Ocean\n```\n\n## Testing\n\nRun the test suite with Jest (already bundled as a dev dependency):\n\n```bash\nnpm install\nnpm test\n```\n\n## License\n\nMIT © ApocalypsAI\n
