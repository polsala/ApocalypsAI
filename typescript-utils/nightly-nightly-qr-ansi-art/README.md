# nightly-qr-ansi-art\n\nUtility that converts a text string into a whimsical ANSI‑art "QR‑like" code using black and white squares. Useful for sharing short messages in a visually distinct way in the terminal.\n\n## Installation\n\n```sh\nnpm install -g nightly-qr-ansi-art\n```\n\n## Usage\n\n```sh\nnightly-qr-ansi-art "Hello World"\n```\n\nThe command prints a block representation of the input text.\n\n## How it works\n\nEach character is turned into its 8‑bit binary representation, where `1` becomes a black square (⬛) and `0` becomes a white square (⬜). Lines are separated by a newline, producing a simple QR‑like visual.\n\n## Example\n\n```text\nInput: A\nOutput:\n⬜⬛⬜⬜⬜⬜⬜⬛\n```\n\n## License\n\nMIT
