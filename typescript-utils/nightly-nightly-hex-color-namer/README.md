# Nightly Hex Color Namer\n\nGenerate whimsical, apocalypse‑themed names for hex color codes.\n\n## Installation\n\n```sh\nnpm install -g ts-node typescript\n```\n\n## Usage\n\n```sh\nts-node src/cli.ts #ff5733\n# => Radiant Ember\n```\n\nYou can also use the library programmatically:\n\n```ts\nimport { nameColor } from "./src/hexColorNamer";\nconst colorName = nameColor("#ff5733");\nconsole.log(colorName); // Radiant Ember\n```\n\n## How it works\n\nThe utility hashes the numeric value of the hex code and deterministically picks an adjective and a noun from two short word lists, producing a memorable name like "Radiant Ember" or "Dusty Breeze".
