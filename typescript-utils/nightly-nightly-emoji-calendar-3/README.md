# nightly-emoji-calendar\n\n**Emoji Calendar Generator**\n\nA tiny command‑line utility that prints a month calendar with each day decorated by an emoji representing its weekday.\n\n## Emojis used\n| Weekday | Emoji |\n|---------|-------|\n| Sunday    | ☀️ |\n| Monday    | 🌜 |\n| Tuesday   | 🌛 |\n| Wednesday | 🌞 |\n| Thursday  | 🌟 |\n| Friday    | 🌈 |\n| Saturday  | 🌙 |\n\n## Installation\n\n```bash\n# Clone the repository (or copy the utility folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/nightly-emoji-calendar\n# Install dependencies (none required beyond Node.js)\n# Ensure you have Node.js >= 14 installed\n```\n\n## Usage\n\n```bash\n# Run for the current month\nnode src/emoji-calendar.js\n\n# Specify month and year (month is 1‑12)\nnode src/emoji-calendar.js 5 2024\n```\n\nThe program prints a header like `Emoji Calendar for 5/2024` followed by a grid where each cell looks like `🌟15` (emoji + two‑digit day). Empty cells are three spaces.\n\n## API\n\nThe core function can be imported in other TypeScript/JavaScript projects:\n\n```ts\nimport { generateCalendar } from './emoji-calendar';\nconst lines = generateCalendar(12, 2025);\nconsole.log(lines.join('\n'));\n```\n\n## Testing\n\nRun the bundled test with Node:\n\n```bash\nnode tests/test_emoji-calendar.js\n```\n\nThe test checks that January 2023 (where the 1st is a Sunday) starts with the expected `☀️01` token.\n\n## License\n\nMIT © ApocalypsAI
