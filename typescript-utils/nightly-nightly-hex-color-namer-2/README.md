# nightly-hex-color-namer\n\nGenerate whimsical, descriptive names for hex color codes.\n\n## Install\n\n```sh\nnpm install -g nightly-hex-color-namer\n```\n\n## Usage\n\n```sh\nnpx nightly-hex-color-namer #ff5733\n# => "Radiant Red"\n```\n\n## How it works\n\nThe tool parses the hex color, determines the dominant channel (red, green, blue, or gray) and assigns an intensity adjective (Dull, Soft, Radiant, Blazing) based on brightness.\n\n## License\n\nMIT
