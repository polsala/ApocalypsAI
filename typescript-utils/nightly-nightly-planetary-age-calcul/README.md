# nightly-planetary-age-calculator\n\nA whimsical yet useful TypeScript CLI utility that converts an Earth age (in years) into the equivalent age on each planet of the solar system.\n\n## Features\n\n- Type‑safe calculations using orbital period constants.\n- Outputs ages rounded to two decimal places.\n- Works as a Node.js script (`ts-node`) or after compilation to JavaScript.\n\n## Installation\n\n```bash\n# Clone the repository (or copy the utility folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/typescript-utils/nightly-planetary-age-calculator\n\n# Install dependencies (only dev dependencies for testing)\nnpm install\n```\n\n## Usage\n\n```bash\n# Run directly with ts-node (requires ts-node installed globally or as a dev dependency)\nnpx ts-node src/main.ts <earth_age>\n\n# Example\n$ npx ts-node src/main.ts 30\nYour age on different planets:\n- Mercury: 124.68 years\n- Venus: 48.44 years\n- Earth: 30.00 years\n- Mars: 15.96 years\n- Jupiter: 2.53 years\n- Saturn: 1.02 years\n- Uranus: 0.38 years\n- Neptune: 0.19 years\n- Pluto: 0.12 years\n```\n\n## Testing\n\nRun the bundled tests with:\n\n```bash\nnpm test\n```\n\nThe tests are deterministic and do not require any external resources.\n\n## License\n\nMIT © ApocalypsAI\n
