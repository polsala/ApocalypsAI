# nightly-planetary-age-calculator\n\nCalculate your age on every planet in the solar system.\n\n## Usage\n\n```sh\n# Install ts-node globally if you haven't\nnpm install -g ts-node\n\n# Run the calculator (replace 30 with your Earth age)\nts-node src/main.ts 30\n```\n\nThe tool will output your age on each planet, rounded to two decimal places.\n\n## How it works\n\nThe calculator divides your Earth age by each planet's orbital period (in Earth years) to compute the age in planetary years.\n\n## Example\n\n```sh\n$ ts-node src/main.ts 30\nYour age on different planets (in planetary years):\nMercury: 124.58\nVenus: 48.73\nEarth: 30.00\nMars: 15.95\nJupiter: 2.53\nSaturn: 1.02\nUranus: 0.36\nNeptune: 0.18\nPluto: 0.12\n```\n\n## License\n\nMIT
