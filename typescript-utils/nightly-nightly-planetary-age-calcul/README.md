# nightly-planetary-age-calculator\n\nCalculate your age on each planet in the solar system.\n\n## Install\n\n```sh\nnpm install -g ts-node typescript\n```\n\n## Usage\n\n```sh\nnpx ts-node src/main.ts <earth-age>\n```\n\nReplace `<earth-age>` with your age in Earth years.\n\n### Example\n\n```sh\nnpx ts-node src/main.ts 30\n```\n\nWill output something like:\n\n````\nYour age on each planet (in Earth years):\nMercury : 124.58\nVenus   : 48.73\nEarth   : 30\nMars    : 15.95\nJupiter : 2.53\nSaturn  : 1.02\nUranus  : 0.36\nNeptune : 0.18\nPluto   : 0.12\n````\n\n## How it works\n\nThe tool uses the orbital period of each planet relative to Earth to convert an Earth age into the equivalent age on that planet. Ages are rounded to two decimal places for readability.\n\n## License\n\nMIT
