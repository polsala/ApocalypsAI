# nightly-planetary-age-calculator\n\nA whimsical yet useful TypeScript CLI utility that converts an Earth age (in years) into the equivalent age on each planet of the solar system.\n\n## Features\n\n- Supports Mercury, Venus, Earth, Mars, Jupiter, Saturn, Uranus, Neptune, and Pluto.\n- Outputs ages rounded to two decimal places.\n- Works as a command‑line tool or as a library function.\n\n## Installation\n\n```bash\n# Clone the repository (or copy the utility folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/typescript-utils/nightly-planetary-age-calculator\n\n# Install dependencies (only dev dependencies for testing)\nnpm install\n```\n\n## Usage\n\n### CLI\n\n```bash\n# Run the CLI with an Earth age (e.g., 30 years)\nnpx ts-node src/index.ts 30\n```\n\nThe output will be a table of ages on each planet.\n\n### As a library\n\n```typescript\nimport { calculatePlanetaryAges } from "./src/index";\n\nconst ages = calculatePlanetaryAges(30);\nconsole.log(ages); // { Mercury: 124.58, Venus: 48.73, ... }\n```\n\n## Testing\n\n```bash\nnpm test\n```\n\nThe test suite validates the conversion logic against known orbital periods.\n\n## License\n\nMIT
