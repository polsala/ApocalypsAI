# Nightly Planetary Age Calculator\n\nA whimsical CLI utility that converts an Earth age (in years) into your age on each planet of the solar system.\n\n## Installation\n\n```sh\nnpm install -g ts-node typescript\n```\n\n## Usage\n\n```sh\nnpx ts-node src/main.ts 30\n```\n\nThe command prints ages on Mercury, Venus, Earth, Mars, Jupiter, Saturn, Uranus, Neptune, and Pluto.\n\n## How it works\n\nThe tool uses each planet's orbital period relative to Earth to compute the age, rounding results to two decimal places.\n\n## License\n\nMIT
