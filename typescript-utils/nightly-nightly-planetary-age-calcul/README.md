# nightly-planetary-age-calculator\n\nA whimsical command‑line utility that tells you how old you would be on every planet in the Solar System (yes, even Pluto).\n\n## Installation\n\n```sh\nnpm install -g ts-node typescript\n```\n\n## Usage\n\n```sh\nnpx ts-node src/main.ts 30\n```\n\nOutput:\n\n```\nMercury: 124.55 years\nVenus: 48.75 years\nEarth: 30.00 years\nMars: 15.95 years\nJupiter: 2.53 years\nSaturn: 1.02 years\nUranus: 0.36 years\nNeptune: 0.18 years\nPluto: 0.12 years\n```\n\n## How it works\n\nThe tool divides your Earth age by each planet's orbital period (in Earth years) to compute the equivalent age.\n\n## Testing\n\nRun the tests with:\n\n```sh\nnpx ts-node tests/test_calc.ts\n```\n\n## License\n\nMIT
