# nightly-planetary-age-calculator\n\nA tiny TypeScript CLI that converts an Earth age into ages on the other planets of the Solar System (including dwarf planet Pluto).\n\n## Features\n\n- Type‑safe calculations using a literal `orbitalPeriods` map\n- Rounded to two decimal places for readability\n- Zero‑dependency runtime – just `node` and optional `ts-node` for TypeScript execution\n- Whimsical output that lists each planetary age\n\n## Installation\n\n```bash\n# Clone the utility (or copy the files into your project)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/nightly-planetary-age-calculator\n\n# Install TypeScript and ts-node globally if you want to run the source directly\nnpm install -g typescript ts-node\n```\n\n## Usage\n\n```bash\n# Run the CLI (you can also compile to JavaScript first)\nts-node src/main.ts <earth-age>\n\n# Example\nts-node src/main.ts 30\n```\n\nOutput example:\n\n```
Your age on Earth: 30 years\n- Mercury: 124.58 years\n- Venus: 48.73 years\n- Mars: 15.95 years\n- Jupiter: 2.53 years\n- Saturn: 1.02 years\n- Uranus: 0.36 years\n- Neptune: 0.18 years\n- Pluto: 0.12 years\n```\n\n## Testing\n\nThe utility ships with a tiny self‑contained test suite that can be run with Node. No external testing framework is required.\n\n```bash\nnode -r ts-node/register tests/ageCalculator.test.ts\n```\n\nIf all assertions pass you will see:\n\n```
All tests passed.\n```\n\n## License\n\nMIT – see the LICENSE file in the repository root.\n
