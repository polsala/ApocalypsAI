# Nightly Planetary Age Calculator\n\nCalculate your age on various planets based on their orbital periods.\n\n## Usage\n\n```bash\nnpx ts-node src/index.ts <earth-age>\n```\n\nThe command prints a JSON object mapping each planet to your age on that planet.\n\n## Example\n\n```bash\n$ npx ts-node src/index.ts 30\n{\n  "Mercury": 124.5,\n  "Venus": 48.73,\n  "Earth": 30,\n  "Mars": 15.95,\n  "Jupiter": 2.53,\n  "Saturn": 1.02,\n  "Uranus": 0.36,\n  "Neptune": 0.18,\n  "Pluto": 0.12\n}\n```\n\n## API\n\nThe module exports a single function:\n\n```ts\ncalculatePlanetaryAges(earthAge: number): Record<string, number>\n```\n\nIt returns an object where keys are planet names and values are your age on that planet, rounded to two decimal places.\n\n## Testing\n\nRun the tests with:\n\n```bash\nnpx ts-node tests/index.test.ts\n```\n\nThe test suite validates conversion accuracy and error handling.
