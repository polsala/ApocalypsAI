# nightly-planetary-age-calculator

Calculate your age on various planets. Provide your birthdate (YYYY-MM-DD) and the tool returns ages on Mercury, Venus, Earth, Mars, Jupiter, Saturn, Uranus, Neptune, each accompanied by a planet emoji.

## Installation

```sh
npm install -g nightly-planetary-age-calculator
```

## Usage

```sh
npx nightly-planetary-age-calculator 1990-05-15
```

Outputs JSON.

## Example

```json
{
  "Mercury": "131 ☿ Mercury",
  "Venus": "51 ♀ Venus",
  "Earth": "33 🌍 Earth",
  "Mars": "17 ♂ Mars",
  "Jupiter": "2 ♃ Jupiter",
  "Saturn": "1 ♄ Saturn",
  "Uranus": "0 ♅ Uranus",
  "Neptune": "0 ♆ Neptune"
}
```
