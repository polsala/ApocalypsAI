# nightly-emoji-daily-mood

A whimsical CLI that prints a random emoji mood and a short motivational phrase.

## Usage

```bash
# Using ts-node
npx ts-node src/main.ts

# Or using the compiled JavaScript
node dist/main.js
```

## Example Output

```
😎 Keep pushing forward!
```

## Installation

```bash
npm install -g ts-node
```
