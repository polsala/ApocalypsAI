# nightly-ruin-rucksack-optimizer\n\nA whimsical TypeScript command‑line utility that helps post‑apocalyptic scavengers pack the most valuable loot without exceeding their carrying capacity. It solves the classic 0/1 knapsack problem.\n\n## Features\n\n* Type‑safe TypeScript implementation\n* Simple CLI: `node dist/main.js --items items.json --capacity 50`\n* Returns the optimal subset of items as JSON\n\n## Installation\n\n```sh\nnpm install\nnpm run build\n```\n\n## Usage\n\nCreate an `items.json` file:\n\n```json\n[\n  { \"name\": \"Canned Beans\", \"weight\": 2, \"value\": 3 },\n  { \"name\": \"Water Bottle\", \"weight\": 3, \"value\": 4 },\n  { \"name\": \"First Aid Kit\", \"weight\": 5, \"value\": 10 }\n]\n```\n\nRun the optimizer:\n\n```sh\nnode dist/main.js --items items.json --capacity 5\n```\n\nOutput:\n\n```json\n[\n  { \"name\": \"First Aid Kit\", \"weight\": 5, \"value\": 10 }\n]\n```\n\n## Testing\n\n```sh\nnpm test\n```\n\n## License\n\nMIT
