# nightly-emoji-timezone-converter\n\nA tiny TypeScript CLI that converts a timestamp from one timezone to another and decorates the result with an emoji that reflects the time of day in the target zone.\n\n## Features\n\n- Accepts an ISO‑8601 timestamp or a simple "HH:MM" time string.\n- Source and target IANA timezone identifiers (e.g. `America/New_York`).\n- Uses the built‑in `Intl` API – no external dependencies.\n- Returns the converted time formatted as `YYYY-MM-DD HH:MM` followed by an emoji: \n  - 🌅 sunrise (05:00‑10:59)\n  - 🌞 day (11:00‑16:59)\n  - 🌇 sunset (17:00‑21:59)\n  - 🌙 night (22:00‑04:59)\n\n## Installation\n\n```bash\n# Clone the repository (or copy the utility folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/nightly-emoji-timezone-converter\n\n# Install TypeScript and ts-node globally if you don't have them\nnpm install -g typescript ts-node\n```\n\n## Usage\n\n```bash\n# Basic form – ISO timestamp\nts-node src/index.ts "2023-08-13T15:30:00" "America/New_York" "Asia/Tokyo"\n# => 2023-08-14 04:30 🌙\n\n# Simple HH:MM (assumes today in source tz)\nts-node src/index.ts "14:45" "Europe/London" "Australia/Sydney"\n# => 2023-08-14 23:45 🌙\n```\n\n## Development\n\nThe source lives in `src/index.ts`. Tests are in `tests/test_index.ts` and can be run with:\n\n```bash\nnpm install -D @types/node\n# Run the test with ts-node\nts-node tests/test_index.ts\n```\n\nFeel free to fork, improve, or embed this tiny utility in larger scripts!\n
