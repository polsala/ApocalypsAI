# nightly-ansi-color-palette\n\nA tiny TypeScript utility that prints the complete 256‑color ANSI palette to the terminal. Each cell shows the color background and its numeric code, making it easy to pick the right color for scripts, prompts, or terminal UI work.\n\n## Features\n\n- Generates a 16×16 grid covering all 256 colors.\n- Uses only built‑in Node APIs – no external dependencies.\n- Exposes a `generatePalette()` function for programmatic use and a CLI entry point for ad‑hoc inspection.\n\n## Installation\n\n```bash\n# Clone the repository (or copy the folder into your project)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/typescript-utils/nightly-ansi-color-palette\n\n# Install TypeScript and ts-node if you don't have them\nnpm install -g typescript ts-node\n```\n\n## Usage\n\n### As a CLI\n\n```bash\n# Run the script directly\nts-node src/main.ts\n```\n\nYou will see a colourful grid like this (truncated for brevity):\n\n````\n  0   1   2 ... 15\n 16  17  18 ... 31\n ...\n240 241 242 ...255\n````\n\n### Programmatically\n\n```ts\nimport { generatePalette } from './src/main';\n\nconst palette = generatePalette();\nconsole.log(palette); // same output as the CLI\n```\n\n## Testing\n\nThe utility ships with a simple test that verifies the presence of a known colour code (196 – bright red). Run it with:\n\n```bash\nnpm test\n```\n\nThe test script is located in `tests/test_main.ts` and uses only Node's `assert` module.\n\n## License\n\nMIT – see the root LICENSE file.\n
