# Whimsical Tech Stack Generator

A CLI tool that combines absurd tech terms with whimsical adjectives to create hilarious or creative tech stack names.

## Usage
```bash
npx tsx src/index.ts [number-of-stacks]
```

Example output:
```
1. Quantum Pickle Orchestration
2. Neon Velociraptor API
3. Hyperloop Jello Framework
```
