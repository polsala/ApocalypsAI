# nightly-cryptic-qr-cli\n\nGenerate whimsical ASCII QR codes from any text directly in the terminal.\n\n## Installation\n\n```sh\nnpm install -g nightly-cryptic-qr-cli\n```\n\n## Usage\n\n```sh\nnpx nightly-cryptic-qr-cli "Your secret message"\n```\n\nThe tool prints an ASCII QR code using the `qrcode-terminal` library. Perfect for sharing hidden messages in post‑apocalyptic chat rooms.\n\n## Development\n\n```sh\nnpm install\nnpm run build   # compiles TypeScript\nnpm test        # runs the test suite\n```\n\n## License\n\nMIT
