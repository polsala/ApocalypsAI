# nightly-cryptic-qr-cli\n\nA whimsical command‑line utility that turns any text into a tiny QR‑style ASCII art. Not a real QR code, but a fun visual representation useful for sharing short strings in terminal‑only environments.\n\n## Installation\n\n```sh\nnpm install -g nightly-cryptic-qr-cli\n```\n\n## Usage\n\n```sh\nnpx nightly-cryptic-qr-cli "Hello, world!"\n```\n\nOutputs something like:\n\n```\n+--------+\n| 48 65  |\n| 6c 6c  |\n| 6f 2c  |\n| 20 77  |\n| 6f 72  |\n| 6c 64  |\n| 21     |\n+--------+\n```\n\n## How it works\n\nThe tool converts each character to its two‑digit hexadecimal code and arranges them in rows of two bytes, surrounded by a simple box.\n\n## License\n\nMIT
