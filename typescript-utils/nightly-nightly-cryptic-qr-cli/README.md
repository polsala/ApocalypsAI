# nightly-cryptic-qr-cli\n\nA whimsical yet useful TypeScript CLI that turns any text into a deterministic ASCII‑art QR‑like code.\n\n## Install\n\n```bash\n# Clone the utility (or copy the folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/typescript-utils/nightly-cryptic-qr-cli\n# Install dependencies (none required beyond Node)\nnpm install\n```\n\n## Usage\n\n```bash\n# Run the CLI with a string argument\nnode src/index.js "Hello, world!"\n```\n\nIf no argument is supplied the tool reads from STDIN.\n\n## How it works\n\nThe utility converts each character of the input into its 8‑bit binary representation and maps `1` to a solid block (`██`) and `0` to two spaces (`  `). The resulting rows are printed line‑by‑line, producing a QR‑like pattern that is fully deterministic – the same input always yields the same output.\n\n## Testing\n\n```bash\nnpm test\n```\n\nThe test suite checks that the generated pattern matches the expected output for a known input.\n
