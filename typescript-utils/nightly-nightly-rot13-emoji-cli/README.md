# nightly-rot13-emoji-cli\n\nA tiny, self‑contained TypeScript command‑line utility that\n\n* transforms any input string using the classic ROT13 cipher, and\n* (optionally) replaces each alphabetic character with a corresponding emoji, turning your text into a quirky, emoji‑fied secret message.\n\n## Installation\n\n```bash\n# Clone the repository (or copy the utility folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/nightly-rot13-emoji-cli\n\n# Install Node.js (>=18) if you don't have it\n# Then install the tiny runtime dependencies (none required – pure TS/JS)\nnpm install -g typescript\n\n# Compile the TypeScript source\ntsc src/main.ts --outDir dist\n\n# Make the CLI globally available (optional)\nchmod +x dist/main.js\nln -s $(pwd)/dist/main.js /usr/local/bin/rot13emoji\n```\n\n## Usage\n\n```bash\n# Basic ROT13\nnode dist/main.js "Hello World"\n# => Uryyb Jbeyq\n\n# ROT13 with emojis\nnode dist/main.js "Hello" --emoji\n# => 🅷🅴🅻🅻🅾\n```\n\n* `--emoji` (or `-e`) toggles the emoji decoration.\n* If no argument is supplied, the utility reads from STDIN.\n\n## How it works\n\nThe core logic lives in `src/rot13.ts`. It implements a pure function\n`rot13(str: string): string` and a helper `toEmoji(str: string): string` that maps\nletters A‑Z to regional indicator symbols (🅰️‑🆉). The CLI (`src/main.ts`) parses\ncommand‑line flags, reads input, applies the transformations, and prints the result.\n\n## Testing\n\nRun the bundled tests with Node's built‑in `assert` module:\n\n```bash\nnpm run test\n```\n\nThe test script simply executes `node tests/rot13.test.ts`.\n\n## License\n\nMIT – see the root LICENSE file.\n
