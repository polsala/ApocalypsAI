# Nightly QR Code ASCII Generator\n\nUtility that converts a short text into a simple ASCII QR‑like pattern. Not a real QR code, but a fun visual representation for the apocalypse.\n\n## Installation\n\n```sh\nnpm install -g nightly-qr-ascii\n```\n\n## Usage\n\n```sh\nnpx nightly-qr-ascii "Hello"\n```\n\nOutputs an ASCII block.\n\n## API\n\n```ts\nexport function generateQR(text: string): string\n```\n\nThe function returns a multiline string where each line represents 8 bits of the input text, with `1` rendered as `█` and `0` as a space.
