# Clipboard Chronicle\n\nUtility to record clipboard entries with timestamps into a JSON log file. Useful for tracking what you've copied over time.\n\n## Installation\n\n```sh\nnpm install -g .\n```\n\n## Usage\n\nPipe text into the utility:\n\n```sh\necho "Hello world" | npx nightly-clipboard-chronicle --log ./clipboard.log.json\n```\n\nOr run without arguments to use the default log `clipboard.log.json` in the current directory.\n\n## API\n\n```ts\nexport interface Entry {\n  timestamp: string; // ISO string\n  content: string;\n}\n\nexport async function loadLog(logPath: string): Promise<Entry[]>;\nexport async function addEntry(content: string, logPath: string): Promise<void>;\n```\n\n## License\n\nMIT
