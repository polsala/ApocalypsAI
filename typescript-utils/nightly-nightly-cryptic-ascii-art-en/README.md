# Nightly Cryptic ASCII Art Encoder\n\n**What it does**\n\nConverts a string into a series of lines where each line represents one character of the input. Each character is rendered as its 8‑bit binary representation, with `1` shown as `#` and `0` shown as a space. The result is a compact, eye‑catching ASCII‑art that can be pasted into terminals, chat, or any plain‑text medium.\n\n**Why it’s useful**\n\n* Quick visual encoding of short messages without external tools.\n* Fun way to embed “secret” messages in logs or commit messages.\n* Works entirely offline – no network calls.\n\n**Installation**\n\nYou need Node.js (v14 or newer) and `ts-node` (or compile the TypeScript yourself).\n\n```sh\n# Clone the repository (or copy the utility folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/nightly-cryptic-ascii-art-encoder\n\n# Install ts-node globally if you don\'t have it\nnpm install -g ts-node typescript\n```\n\n**Usage**\n\n```sh\n# Directly via ts-node\nts-node src/main.ts "Hello World"\n\n# Or compile first\ntsc src/main.ts && node src/main.js "Hello World"\n```\n\nThe command prints something like:\n\n````\n #    #   \n #   #   \n #   #   \n #   #   \n #   #   \n #   #   \n #   #   \n #   #   \n````\n\nEach line corresponds to a character in the input string.\n\n**API**\n\nThe core function is exported for programmatic use:\n\n```ts\nimport { encodeToAsciiArt } from "./src/main";\nconst art = encodeToAsciiArt("ABC");\nconsole.log(art.join("\n"));\n```\n\n**Testing**\n\nRun the bundled test with:\n\n```sh\nts-node tests/test_main.ts\n```\n\nThe test validates the encoding of known characters.\n
