# nightly-emoji-encoder\n\nA whimsical command‑line utility that translates plain text into a sequence of emojis and back again. Great for secret notes, playful chats, or just adding a splash of color to your terminal.\n\n## Installation\n\n```bash\n# Install globally via npm\nnpm install -g nightly-emoji-encoder\n```\n\nOr run without installing using npx:\n\n```bash\nnpx nightly-emoji-encoder <command> <text>\n```\n\n## Usage\n\n```bash\n# Encode a message\nnightly-emoji-encoder encode "hello world"\n\n# Decode a message\nnightly-emoji-encoder decode "👋🌍 🌙🌍🌍🌍"\n```\n\nThe tool supports the English alphabet (a‑z) and digits (0‑9). Characters outside this set are passed through unchanged.\n\n## Development\n\n```bash\n# Install dependencies\nnpm install\n\n# Run tests\nnpm test\n\n# Build the CLI (tsc)\nnpm run build\n```\n\n## License\n\nMIT © ApocalypsAI
