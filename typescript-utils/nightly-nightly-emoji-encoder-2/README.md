# nightly-emoji-encoder\n\nEncode and decode plain text to a whimsical sequence of emojis and back again.\n\n## Installation\n\n```sh\nnpm install -g nightly-emoji-encoder\n```\n\n## Usage\n\n```sh\nnemoji encode "hello world"\n# 🇭🇪🇱🇱🇴⬜🇼🇴🇷🇱🇩\n\nnemoji decode "🇭🇪🇱🇱🇴⬜🇼🇴🇷🇱🇩"\n# hello world\n```\n\n## How it works\n\nEach latin letter is mapped to its corresponding regional indicator symbol (🇦‑🇿). Digits use keycap emojis (0️⃣‑9️⃣). Spaces become a white square ⬜. Characters outside this set are left unchanged.\n\n## Development\n\n```sh\ngit clone <repo-url>\ncd nightly-emoji-encoder\nnpm install\nnpm test\n```
