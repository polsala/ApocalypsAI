# Nightly Mood Chronicle\n\nA tiny CLI to record your daily mood in a local JSON file and view a quick summary.\n\n## Installation\n\n```bash\npip install .\n```\n\n## Usage\n\n```bash\n# Log a mood (optionally with a note)\npython -m nightly_mood_chronicle log happy "Found fresh water"\n\n# Show a summary of recorded moods\npython -m nightly_mood_chronicle summary\n```\n\n## Commands\n\n- `log <mood> [note]` – record a mood with an optional note.\n- `summary` – display counts of each mood and the most recent entry.\n\n## Supported moods\n\n| Mood      | Emoji |\n|-----------|-------|\n| happy     | 😊    |\n| sad       | 😢    |\n| angry     | 😠    |\n| scared    | 😨    |\n| hopeful   | 🌟    |\n| exhausted | 😩    |\n\nThe tool stores data in `~/.apocalypse_mood.json`. It is safe to delete this file to reset the log.
