# nightly-qr-ansi\n\nA tiny Rust CLI that converts a short string into an ANSI QR code rendered with block characters. Perfect for sharing secret messages in the terminal.\n\n## Usage\n\n```sh\ncargo run --quiet -- "Hello"\n```\n\nThe command prints a QR code made of `██` (black) and two spaces (white).\n\n## Build\n\n```sh\ncargo build --release\n```\n\n## Test\n\n```sh\ncargo test\n```\n
