# Nightly Scavenge Sorter\n\nA high-performance CLI tool for the ApocalypsAI community to quickly categorize scavenged items and assign a 'Glimmer Value' based on predefined rules. This helps survivors prioritize their finds in the wasteland.\n\n## ✨ Glimmer Value System\n\nItems are sorted into categories, each with an associated 'Glimmer Value' indicating its general usefulness or rarity.\n\n*   **Vital Spark (100-90 Glimmer)**: Essential for immediate survival (e.g., water, food, medicine, fuel).\n*   **Resource Bloom (50-20 Glimmer)**: Raw materials for crafting and repair (e.g., metal, wood, cloth).\n*   **Tech Whisper (80-60 Glimmer)**: Components for advanced tools and communication (e.g., circuits, radios, tools).\n*   **Curio Shard (35-10 Glimmer)**: Items with sentimental or trade value, or minor utility (e.g., books, jewelry, coins).\n*   **Dust & Debris (10-1 Glimmer)**: Mostly junk, but might have a tiny, obscure use (e.g., broken items, rocks, dirt).\n*   **Uncategorized (0 Glimmer)**: Items not recognized by the current rule set.\n\n## 🚀 Usage\n\nThe `nightly-scavenge-sorter` can read item descriptions from standard input or a specified file.\n\n### From Standard Input\n\nPipe a list of items directly to the tool:\n\n```bash\n$ echo -e "Rusty Water Bottle\nCanned Beans\nBroken Radio\nShiny Rock" | nightly-scavenge-sorter\n```\n\nExpected Output:\n\n```\nItem                           | Category             | Glimmer Value\n------------------------------------------------------------\nRusty Water Bottle             | Vital Spark          | 100\nCanned Beans                   | Vital Spark          | 100\nBroken Radio                   | Tech Whisper         | 80\nShiny Rock                     | Dust & Debris        | 2\n```\n\n### From a File\n\nProvide a path to a file containing one item description per line:\n\n```bash\n$ cat items.txt\nMedical Kit\nOld Circuit Board\nEmpty Can\nMysterious Orb\n\n$ nightly-scavenge-sorter --input-file items.txt\n```\n\nExpected Output:\n\n```\nItem                           | Category             | Glimmer Value\n------------------------------------------------------------\nMedical Kit                    | Vital Spark          | 100\nOld Circuit Board              | Tech Whisper         | 75\nEmpty Can                      | Dust & Debris        | 5\nMysterious Orb                 | Uncategorized        | 0\n```\n\n## 🛠️ Installation\n\nTo build and run this utility, you need Rust installed (https://www.rust-lang.org/tools/install).\n\n1.  **Clone the repository (if you haven't already):**\n    ```bash\n    git clone https://github.com/polsala/ApocalypsAI.git\n    cd ApocalypsAI/rust-utils/nightly-scavenge-sorter\n    ```\n2.  **Build the utility:**\n    ```bash\n    cargo build --release\n    ```\n3.  **Run from the target directory:**\n    ```bash\n    ./target/release/nightly-scavenge-sorter\n    ```\n    Or add `target/release` to your PATH for easier access.\n\n## ⚙️ Customization (Future Enhancements)\n\nCurrently, the categorization rules are hardcoded within the `src/main.rs` file. Future versions could allow for external configuration files (e.g., TOML, YAML) to define custom rules, patterns (including regex), and Glimmer Values, offering greater flexibility for different scavenging scenarios.
