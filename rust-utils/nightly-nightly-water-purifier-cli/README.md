# Nightly Water Purifier CLI\n\n## Overview\n\n`nightly-water-purifier-cli` is a tiny Rust command‑line tool that helps survivors decide how to treat water in a post‑apocalyptic setting.  By providing the water source (e.g., river, rain, well) and a measured contamination level in parts‑per‑million (ppm), the tool prints an ordered list of recommended purification steps such as pre‑filtering, boiling, and chemical treatment.\n\n## Installation\n\n```bash\n# Install Rust toolchain if you don\'t have it\ncurl https://sh.rustup.rs -sSf | sh\n\n# Clone the utility (or let the ApocalypsAI agent generate it)\ngit clone <repo‑url>\ncd nightly-water-purifier-cli\n\n# Build the binary\ncargo build --release\n```\n\nThe compiled binary will be located at `target/release/nightly-water-purifier-cli`.\n\n## Usage\n\n```bash\nnightly-water-purifier-cli <source> <contamination_ppm>\n```\n\n* `<source>` – one of `rain`, `well`, `river`, `pond`, `lake`, or any other string for an unknown source.\n* `<contamination_ppm>` – non‑negative integer representing parts‑per‑million of contaminants.\n\n### Example\n\n```bash\nnightly-water-purifier-cli river 150\n```\n\nOutput:\n\n```
1. Pre‑filter through coarse material\n2. Boil for 5 minutes\n3. Add chlorine tablets (1 per liter)\n```\n\n## How It Works\n\nThe core logic lives in `src/lib.rs`.  It first adds a source‑specific pre‑treatment step, then selects boiling time and optional chemical treatment based on contamination thresholds:\n\n* **0‑50 ppm** – simple boil (1 min).\n* **51‑200 ppm** – longer boil (5 min) + one chlorine tablet per litre.\n* **>200 ppm** – extended boil (10 min), two chlorine tablets per litre, and an activated‑carbon filter.\n\n## Testing\n\nThe utility includes a suite of deterministic unit tests that run with `cargo test`.  No external resources are required.\n\n```bash\ncargo test\n```\n\n## License\n\nMIT – see the LICENSE file in the repository.\n
