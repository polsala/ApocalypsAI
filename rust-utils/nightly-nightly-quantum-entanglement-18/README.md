# Nightly Quantum Entanglement Checker

Ever wondered if two files are quantum-entangled? This whimsical tool checks if two files share the same quantum state by comparing their hashes with a touch of randomness.

## Features

- 🚀 Fast hash comparison using Rust
- 🎲 Adds a touch of quantum randomness
- 📁 Supports any file type
- 🧪 Includes comprehensive tests

## Usage

```bash
# Check if two files are quantum-entangled
./nightly-quantum-entanglement-checker file1.txt file2.txt

# Output:
# 📁 Files: file1.txt and file2.txt
# 🔬 Hash A: a1b2c3d4e5f6...
# 🔬 Hash B: a1b2c3d4e5f6...
# 🎲 Quantum randomness: 0.123456
# ✨ Quantum entanglement detected!
```

## Installation

```bash
cargo build --release
```

The binary will be available at `target/release/nightly-quantum-entanglement-checker`.
