# nightly-binary-art-cli\n\nConvert input text into binary art representation.\n\n## Usage\n\n```sh\ncargo run -- <text>\n```\n\nExample:\n\n```sh\ncargo run -- A\n```\n\nOutputs:\n\n````\n █    █\n````\n\n## How it works\n\nEach character is converted to its 8‑bit binary representation. Bits set to 1 are shown as a solid block (█), bits set to 0 as a space.\n\n## Tests\n\nRun `cargo test`.
