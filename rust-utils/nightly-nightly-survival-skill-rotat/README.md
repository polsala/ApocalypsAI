# Nightly Survival Skill Rotator\n\n## Overview\n\n`nightly-survival-skill-rotator` is a tiny Rust CLI that spits out a random survival skill useful in a post‑apocalyptic setting, together with a short, whimsical description.  It can also operate in a deterministic mode using a numeric seed, which makes it perfect for automated testing.\n\n## Installation\n\n```bash\n# Clone the repository (or copy the generated folder)\ngit clone <repo‑url>\ncd rust-utils/nightly-survival-skill-rotator\n\n# Build the binary\ncargo build --release\n```\n\nThe compiled binary will be located at `target/release/nightly-survival-skill-rotator`.\n\n## Usage\n\n```bash\n# Random skill (uses true randomness)\ncargo run --quiet\n\n# Deterministic skill for testing or scripting\ncargo run --quiet -- --seed 42\n```\n\n### Example Output\n\n```
Your survival skill: Improvised Weaponry - Craft weapons from scrap.
