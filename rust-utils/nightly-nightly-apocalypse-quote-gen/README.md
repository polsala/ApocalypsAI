# Nightly Apocalypse Quote Generator\n\nA tiny Rust CLI that prints a random post‑apocalyptic themed quote each time you run it. Perfect for adding a bit of grim optimism to your terminal.\n\n## Installation\n\n```sh\ncargo install --path .\n```\n\n## Usage\n\n```sh\napocalypse-quote\n```\n\nWill output a random quote, e.g.:\n\n> "Even the wasteland whispers hope."\n\n## How it works\n\nThe program ships with a built‑in list of quotes and selects one uniformly at random using the `rand` crate.\n\n## Testing\n\nRun `cargo test` to execute the deterministic unit tests.
