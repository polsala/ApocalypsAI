# Nightly Scavenger Inventory Generator\n\nA whimsical Rust CLI tool that creates a random post‑apocalyptic scavenger inventory. Each run lists items with quantities and rarity.\n\n## Build\n\n```sh\ncargo build --release\n```\n\n## Run\n\n```sh\ncargo run --release\n```\n\nExample output:\n\n````\n🛠️ 3 x Rusty Pipe (Common)\n🍶 1 x Stale Water (Uncommon)\n🔋 0 x Solar Battery (Rare)\n````\n\n## Test\n\n```sh\ncargo test\n```
