# Nightly QR Whisperer\n\nA whimsical Rust CLI that turns any message into a tiny ASCII QR‑like pattern. Perfect for leaving secret notes in the wasteland.\n\n## Installation\n\n```sh\ncargo install --path .\n```\n\n## Usage\n\n```sh\nqr-whisper "Hello, apocalypse!"\n```\n\nOutputs a 5×5 pattern of `#` and spaces.\n\n## How it works\n\nThe tool hashes the input string with a simple deterministic hash and maps the first 25 bits to a fixed 5×5 grid, rendering `#` for a `1` bit and a space for a `0` bit.
