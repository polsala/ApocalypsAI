Scavenger Map Generator\n\nGenerate a random ASCII map of scavenging resources for post‑apocalyptic tabletop games.\n\nUsage:\n  cargo run -- --width <W> --height <H> [--seed <N>]\n\nOptions:\n  --width   Width of the map (default 10)\n  --height  Height of the map (default 5)\n  --seed    Optional numeric seed for deterministic maps\n\nThe map uses '.' for empty ground and the letters:\n  F  Food\n  W  Water\n  M  Medicine\n  T  Tools\n\nExample:\n  cargo run -- --width 8 --height 4 --seed 42\n\nWill output an 8x4 grid like:\n  .F.W..M.\n  ..T...F.\n  .W..M...\n  ...F.T..\n\nTests can be run with:\n  cargo test
