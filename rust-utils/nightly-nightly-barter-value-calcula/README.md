# Nightly Barter Value Calculator\n\nA whimsical CLI tool for post‑apocalypse traders. It assigns a fair trade value to common scavenged items based on a built‑in scarcity table.\n\n## Usage\n\n```sh\ncargo run -- <item> <quantity>\n```\n\nExample:\n\n```sh\ncargo run -- water 3\n# => 30 barter points\n```\n\n## Adding items\n\nEdit the `ITEMS` map in `src/main.rs` to add new items or adjust values.\n
