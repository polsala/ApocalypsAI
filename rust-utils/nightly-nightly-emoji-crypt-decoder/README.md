# Nightly Emoji Crypt Decoder\n\n`nightly-emoji-crypt-decoder` is a tiny, fun command‑line tool written in Rust that can **encode** plain words into emojis and **decode** those emojis back into words using a built‑in dictionary.\n\n## Features\n\n- Encode a space‑separated list of known words into their emoji equivalents.\n- Decode a space‑separated list of emojis back into words.\n- No external network calls – everything is self‑contained.\n\n## Installation\n\n```bash\n# Clone the repository (or copy the generated folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/rust-utils/nightly-emoji-crypt-decoder\n# Build the binary\ncargo build --release\n# The binary will be at target/release/emoji-crypt\n```\n\n## Usage\n\n```bash\n# Encode words\n./target/release/emoji-crypt encode "apple rocket fire"\n# => 🍎 🚀 🔥\n\n# Decode emojis\n./target/release/emoji-crypt decode "🍎 🚀 🔥"\n# => apple rocket fire\n```\n\nOnly the words listed in the internal dictionary are translated; unknown tokens are left unchanged.\n\n## Dictionary\n\n| Word   | Emoji |\n|--------|-------|\n| apple  | 🍎    |\n| rocket | 🚀    |\n| fire   | 🔥    |\n| heart  | ❤️    |\n| star   | ⭐    |\n| coffee | ☕    |\n| book   | 📚    |\n\n## Testing\n\nRun the test suite with:\n\n```bash\ncargo test\n```\n\nAll tests are deterministic and run offline.\n
