# nightly‑scavenger‑inventory

A tiny Rust CLI that helps you keep track of your scavenged supplies in a post‑apocalypse setting.

## Features

- Add items with a name, category, quantity and days‑until‑expiration.
- List all stored items.
- Show the *most urgent* item (the one that will expire soonest).

The tool stores data in a local `inventory.json` file in the current working directory.

## Installation

```bash
# Clone the repository (or copy the generated folder) and build
cargo build --release
```

The binary will be located at `target/release/scavenger_inventory`.

## Usage

```bash
# Add a new item
scavenger_inventory add "Canned Beans" food 12 180

# List all items
scavenger_inventory list

# Show the most urgent item
scavenger_inventory prioritize
```
