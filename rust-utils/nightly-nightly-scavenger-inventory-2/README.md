# Scavenger Inventory Generator\n\nA whimsical Rust CLI that spits out a post‑apocalyptic scavenger inventory. Useful for role‑playing games, story prompts, or just a fun terminal surprise.\n\n## Usage\n\n```sh\ncargo run --release\n```\n\nOutputs something like:\n\n````\n3x Canned Beans\n1x Water Bottle\n2x Bandage\n...\n````\n\n## How it works\n\nThe generator uses a simple deterministic linear‑congruential generator (LCG) seeded with a constant, so the output is reproducible. The `generate_inventory` function can be called with a custom seed for varied results.\n\n## Testing\n\nRun `cargo test` to execute the deterministic unit test.\n
