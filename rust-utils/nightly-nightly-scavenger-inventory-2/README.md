# Nightly Scavenger Inventory\n\nA whimsical Rust CLI tool to track your post‑apocalypse scavenged items. Add items, list inventory, and get a suggestion of what to use next based on soonest expiration.\n\n## Usage\n\n```sh\n# Add an item\nnightly-scavenger-inventory add "Canned Beans" food 30 5\n\n# List items\nnightly-scavenger-inventory list\n\n# Suggest next item to consume\nnightly-scavenger-inventory suggest\n```\n\nThe inventory is stored in a JSON file at `$HOME/.scavenger_inventory.json`. Use `--file <path>` to specify a custom location.\n\n## Build\n\n```sh\ncargo build --release\n```
