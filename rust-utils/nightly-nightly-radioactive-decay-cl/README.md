Nightly Radioactive Decay CLI\n\nA tiny Rust command‑line tool that computes the remaining fraction of a radioactive material after a given time based on its half‑life and prints a simple ASCII bar visualisation.\n\nUsage:\n  nightly-radioactive-decay-cli --half-life <value> --time <value>\n\nExample:\n  nightly-radioactive-decay-cli --half-life 5.0 --time 10.0\n  Remaining fraction: 0.250000\n  Visual: [#####               ]\n\nOptions:\n  --half-life   Half‑life of the material (positive number)\n  --time        Elapsed time for which to compute decay\n\nThe tool rounds the visual bar to a width of 20 characters.\n
