# nightly-battery-forecast\n\nA tiny Rust CLI that estimates how many hours of power you have left before the lights go out. Perfect for the post‑apocalyptic wanderer who still cares about their laptop charge.\n\n## Install\n\n```bash\n# Clone the repo and build\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/rust-utils/nightly-battery-forecast\ncargo build --release\n# The binary will be at target/release/nightly-battery-forecast\n```\n\n## Usage\n\n```bash\nnightly-battery-forecast <capacity_percent> <drain_per_hour_percent> [--survival]\n```\n\n- `capacity_percent` – current battery charge (0‑100).\n- `drain_per_hour_percent` – average consumption per hour (e.g., `5.2`).\n- `--survival` – activates *survival mode* which applies a 10 % safety margin (you’ll want a little buffer when the world is ending).\n\n### Example\n\n```bash\nnightly-battery-forecast 57 5.2\n# Estimated remaining time: 10.96 hours\n\nnightly-battery-forecast 57 5.2 --survival\n# Estimated remaining time: 9.86 hours\n```\n\n## Testing\n\n```bash\ncargo test\n```\n\nAll tests run offline and use deterministic mock data.\n
