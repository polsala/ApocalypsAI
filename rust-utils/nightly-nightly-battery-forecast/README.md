# Nightly Battery Forecast\n\nA tiny Rust CLI that tells you how many hours of power remain given your current battery percentage and average consumption per hour. Perfect for scavengers roaming the wasteland.\n\n## Build\n\n```bash\ncargo build --release\n```\n\n## Run\n\n```bash\ncargo run -- <current_percent> <consumption_per_hour>\n```\n\n- `<current_percent>` – current battery level (0‑100).\n- `<consumption_per_hour>` – average percent drained per hour.\n\n### Example\n\n```bash\ncargo run -- 45 5\n```\n\nOutput:\n\n```
Estimated battery life: 9.00 hours\n```\n\nIf the consumption rate is zero or negative, the tool reports infinite battery life.\n\n## Tests\n\nRun the unit tests with:\n\n```bash\ncargo test\n```
