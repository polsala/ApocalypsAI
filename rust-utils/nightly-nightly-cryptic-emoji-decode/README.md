# nightly-cryptic-emoji-decoder

A whimsical CLI tool that translates a sequence of emojis into a readable phrase using a built‑in dictionary. Useful for quick fun decoding or generating secret messages.

## Installation

```sh
cargo install --path .
```

## Usage

```sh
emoji-decoder "🚀 🌕"
# => launch moon
```

Supported emojis:

- 🚀 → launch
- 🌕 → moon
- 🔥 → fire
- 💧 → water
- ⚡ → electric
- 🧊 → ice
- 🌟 → star
- 🪐 → planet
- 👽 → alien
- 🤖 → robot
