nightly-uptime-emoji

A whimsical CLI that prints system uptime with emojis.

Usage:
nightly-uptime-emoji [--uptime-file <path>]

If no file is provided, the utility reads /proc/uptime.
Example:
$ nightly-uptime-emoji
ð 1 days, 10 hours, 17 minutes

The output is intentionally friendly and can be piped into other scripts or logs.
