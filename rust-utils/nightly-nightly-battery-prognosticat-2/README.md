# Nightly Battery Prognosticator\n\nA whimsical CLI tool that estimates how many hours of power remain in your post‑apocalyptic device based on current charge, normal consumption rate, and an optional radiation factor.\n\n## Installation\n\n```sh\n# Build with Cargo\ncargo build --release\n# The binary will be at target/release/nightly-battery-prognosticator\n```\n\n## Usage\n\n```sh\nnightly-battery-prognosticator <current_percent> <consumption_per_hour> [radiation_factor]\n```\n\n- `current_percent` – Current battery level (0‑100).\n- `consumption_per_hour` – Percent of battery drained per hour under normal conditions.\n- `radiation_factor` (optional) – Multiplier for radiation exposure; defaults to `1.0`.\n\n### Example\n\n```sh\n$ nightly-battery-prognosticator 75 15 1.2\nEstimated remaining battery life: 4.17 hours\n```\n\nIf consumption is zero, the tool reports that the battery will last indefinitely.\n\n## Testing\n\nRun the test suite with:\n\n```sh\ncargo test\n```\n\n## License\n\nMIT
