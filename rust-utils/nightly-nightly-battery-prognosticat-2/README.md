# Nightly Battery Prognosticator\n\nEstimates how many hours of power remain given current charge and average consumption, with whimsical apocalypse-themed messages.\n\n## Build\n\n```sh\ncargo build --release\n```\n\n## Usage\n\n```sh\ncargo run --release -- <charge_percent> <consumption_per_hour>\n```\n\nExample:\n\n```sh\ncargo run --release -- 73 5.2\n```\n\nOutputs something like:\n\n`⚡️ 73.0% charge left, consuming 5.2%/h → ~14.04 hours remaining. Stay powered, survivor!`\n\n## Testing\n\n```sh\ncargo test\n```
