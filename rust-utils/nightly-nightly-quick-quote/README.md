# nightly-quick-quote\n\nA whimsical Rust CLI that prints a random inspirational quote or a specific one by index.\n\n## Usage\n\n```bash\n# Print a random quote\nnightly-quick-quote\n\n# Print the quote at index 2 (0-based)\nnightly-quick-quote --index 2\n\n# Print 5 random quotes\nnightly-quick-quote --count 5\n```\n\nThe utility ships with a small curated list of 10 quotes. It is deterministic when using `--index` and random otherwise.\n\n## Building\n\n```bash\ncargo build --release\n```\n\nThe binary will be located at `target/release/nightly-quick-quote`.\n\n## Testing\n\nRun the test suite with:\n\n```bash\ncargo test\n```\n\n
