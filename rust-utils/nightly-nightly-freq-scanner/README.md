# nightly-freq-scanner\n\nDeterministic CLI tool that tells if a radio frequency is clear in a post‑apocalyptic world.\n\n## Build\n\n```sh\ncargo build --release\n```\n\n## Usage\n\n```sh\n./target/release/nightly-freq-scanner <frequency1> [<frequency2> ...]\n```\n\nEach frequency is interpreted as MHz. The tool prints whether the frequency is **CLEAR** or **BLOCKED** based on a deterministic algorithm.\n\n## Algorithm\n\nA frequency is considered clear if the fractional part of `frequency * 31.4159` is less than 0.5.\n\n## Testing\n\n```sh\ncargo test\n```
