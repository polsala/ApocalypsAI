# ANSI Artifier\n\nA tiny Rust CLI that turns any text into a rainbow‑colored string using ANSI escape codes.\nPerfect for adding a splash of color to terminal output, logs, or chat messages.\n\n## Installation\n\n```sh\n# Build with Cargo\ncargo build --release\n# The binary will be at target/release/ansi-artifier\n```\n\n## Usage\n\n```sh\nansi-artifier "Hello, world!"\n```\n\nThe program prints the supplied text with each character colored in a rotating\npalette (red, yellow, green, cyan, blue, magenta). The output ends with the\nANSI reset code so subsequent terminal output is unaffected.\n\n## How it works\n\nThe library function `rainbow` iterates over the characters of the input string,\nassigns a color from a six‑color palette, and concatenates the colored characters.\nThe CLI (`src/main.rs`) simply forwards the command‑line argument to this function\nand prints the result.\n\n## Testing\n\nRun the test suite with:\n\n```sh\ncargo test\n```\n\nThe tests verify that the color sequence cycles correctly and that the reset code\nis always appended.\n\n## License\n\nMIT
