# nightly-epic-quest-generator\n\nA tiny, zero‑dependency Rust CLI that spits out a random, whimsical quest description for tabletop role‑playing games.\n\n## Features\n\n- Completely offline – no network calls.\n- Deterministic output when a `--seed` is supplied (useful for testing or reproducible story seeds).\n- No external crates required; uses only the Rust standard library.\n\n## Installation\n\n```bash\n# Clone the repository (or copy the generated folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/rust-utils/nightly-epic-quest-generator\n\n# Build the binary\ncargo build --release\n\n# The binary will be at target/release/nightly-epic-quest-generator\n```\n\n## Usage\n\n```bash\n# Random quest (non‑deterministic)\n./target/release/nightly-epic-quest-generator\n\n# Deterministic quest with a seed\n./target/release/nightly-epic-quest-generator --seed 42\n```\n\n## Example Output\n\n```
Quest: Retrieve the Whispering Amulet from the Sunken Library guarded by the Crimson Dragon.
```\n\n## Testing\n\nThe project includes a built‑in test suite that can be run with:\n\n```bash\ncargo test\n```\n\nThe tests verify that a known seed produces the expected quest string.\n
