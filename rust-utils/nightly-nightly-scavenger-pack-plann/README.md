Scavenger Pack Planner\n\nA whimsical CLI tool to help post‑apocalypse scavengers choose the most valuable items to carry without exceeding a weight limit. Implements the classic 0/1 knapsack algorithm.\n\nUsage:\n  cargo run --release -- <MAX_WEIGHT> [INPUT]\n\nIf INPUT is omitted, the program reads from standard input.\n\nInput format (one item per line):\n  name weight value\n\nExample:\n  apple 2 3\n  water 5 10\n  medkit 3 7\n\nThe program outputs the selected items, total weight, and total value.\n
