# Scavenger Pack Planner\n\nA whimsical CLI tool that helps post‑apocalypse scavengers choose the most valuable items to carry given a weight limit.\n\n## Usage\n\n```sh\ncargo run --release -- <weight_limit> "<item1_name>:<weight>:<value>,<item2_name>:<weight>:<value>,..."\n```\n\nExample:\n\n```sh\ncargo run -- 15 "water:5:10,food:7:12,radio:3:5,medkit:4:8"\n```\n\nOutput:\n\n````\nSelected items: water, food, medkit\nTotal value: 30\n````\n\n## How it works\n\nImplements the classic 0/1 knapsack dynamic programming algorithm.\n
