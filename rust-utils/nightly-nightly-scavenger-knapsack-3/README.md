# Scavenger Knapsack\n\nA whimsical CLI tool to help post‑apocalypse scavengers decide which items to carry given a weight limit. Implements the classic 0/1 knapsack algorithm.\n\n## Usage\n\n```sh\ncargo run --release -- <capacity> <item1_weight>:<item1_value> <item2_weight>:<item2_value> ...\n```\n\nExample:\n\n```sh\ncargo run -- 15 3:4 4:5 7:10 8:11 9:13\n```\n\nOutputs the maximum total value achievable.\n\n## Build\n\n```sh\ncargo build --release\n```\n\n## Test\n\n```sh\ncargo test\n```
