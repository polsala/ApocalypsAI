# Scavenger Map Generator\n\n`nightly-scavenger-map-generator` is a tiny Rust command‑line tool that spits out an ASCII map of a post‑apocalyptic landscape filled with resources you specify.  It’s perfect for tabletop RPGs, improv storytelling, or just for fun.\n\n## Installation\n\n```sh\n# Clone the repository (or copy the generated folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd rust-utils/nightly-scavenger-map-generator\n\n# Build and install locally\ncargo install --path .\n```\n\n## Usage\n\n```sh\nscavenger-map \\\n    --width 20 \\\n    --height 10 \\\n    --resources water,food,ammo,medicine \\\n    --seed 42\n```\n\n* `--width` and `--height` define the size of the map.\n* `--resources` is a comma‑separated list; the first letter of each resource is used as the map symbol (e.g., `water` → `W`).\n* `--seed` makes the placement deterministic – useful for testing or sharing the same map with friends.\n\nThe output looks like this (example with the arguments above):\n\n````\n....................\n..W...........A.....\n......F.............\n...........M........\n....................\n......A.............\n....................\n..F.................\n....................\n........W...........\n````\n\n## How It Works\n\n1. The program parses the command‑line arguments.\n2. It creates a `StdRng` seeded with the provided `--seed` (or a random seed if omitted).\n3. For each resource it picks a random empty cell and places the resource’s capitalised first letter there.\n4. All remaining cells are filled with `.` (dot).\n5. The final grid is printed to STDOUT.\n\n## Testing\n\nRun the test suite with:\n\n```sh\ncargo test\n```\n\nThe tests verify deterministic placement, correct dimensions, and that each resource appears exactly once.\n\n## License\n\nMIT – see the LICENSE file in the repository root.
