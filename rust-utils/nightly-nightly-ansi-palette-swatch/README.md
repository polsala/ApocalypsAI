# nightly-ansi-palette-swatch\n\nA whimsical yet useful Rust CLI that displays a swatch of ANSI 256‑color codes in your terminal. Perfect for picking colors for scripts, themes, or just marveling at the rainbow of terminal hues.\n\n## Usage\n\n```sh\ncargo run --quiet -- --list   # prints colors 0‑15\ncargo run --quiet -- --all    # prints all 256 colors\n```\n\nThe output shows each color code followed by a colored block.\n\n## Build\n\n```sh\ncargo build --release\n```\n\n## License\n\nMIT
