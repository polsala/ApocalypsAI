Ruinous City Namer\n\nA whimsical Rust CLI that generates post-apocalyptic city names by stitching together random syllables. Useful for world-building, games, or just a fun name generator.\n\nUsage:\n  ruinous_city_namer [seed]\nIf a numeric seed is provided, the output is deterministic, making it easy to test or reproduce names. Without a seed, the current Unix time is used.\n\nExample:\n  $ ruinous_city_namer 42\n  ra-ka\n
