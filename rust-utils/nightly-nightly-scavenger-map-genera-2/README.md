# Nightly Scavenger Map Generator\n\nA tiny Rust CLI that creates a random scavenging map for post‑apocalypse role‑playing games or tabletop sessions. Each map consists of a list of locations, each with X/Y coordinates and a resource type (food, water, medicine, ammo, or scrap).\n\n## Features\n\n- Deterministic output when a seed is supplied (useful for reproducible sessions).\n- Adjustable number of locations.\n- Outputs JSON to stdout, ready to be piped into other tools.\n\n## Build\n\n```bash\n# Clone the repository (or copy the generated folder)\ngit clone <repo-url>\ncd nightly-scavenger-map-generator\n\n# Build the binary\ncargo build --release\n```\n\n## Usage\n\n```bash\n# Generate a map with default seed (42) and 5 locations\n./target/release/scavenger-map\n\n# Specify a custom seed and count\n./target/release/scavenger-map --seed 12345 --count 10\n```\n\nThe program prints a JSON array, e.g.:\n\n```json\n[\n  {\n    "x": -23,\n    "y": 57,\n    "resource": "water"\n  },\n  {\n    "x": 12,\n    "y": -8,\n    "resource": "ammo"\n  }\n]\n```\n\n## Testing\n\n```bash\ncargo test\n```\n\nThe test suite checks that the generator is deterministic for a given seed and that the requested number of locations is produced.\n
