# Nightly Scavenger Map Generator\n\n## Overview\n\n`nightly-scavenger-map-generator` is a tiny Rust CLI tool that turns a list of scavenger‑hunt items into a compact ASCII map.  Each item is represented by the uppercase first letter of its name and placed on a square grid sized to fit all entries.  The result is a quick visual aid for post‑apocalyptic role‑playing games, escape‑room puzzles, or any situation where you need a printable map of resources.\n\n## Installation\n\n```bash\n# Clone the repository (or copy the generated folder)\ngit clone <repo‑url>\ncd nightly-scavenger-map-generator\n\n# Build the binary\ncargo build --release\n```\n\nThe compiled binary will be located at `target/release/scavenger_map_generator`.\n\n## Usage\n\n```bash\n# Provide a space‑separated list of item names\n./target/release/scavenger_map_generator water food medicine ammo\n```\n\nOutput example (for the four items above):\n\n````\nWF\nMA\n````\n\n- The grid size is the ceiling of the square root of the number of items.\n- Items are placed row‑wise in the order they are supplied.\n- Empty cells are shown as `.`.\n\n## Testing\n\nRun the test suite with:\n\n```bash\ncargo test\n```\n\nAll tests are deterministic and do not require external resources.\n
