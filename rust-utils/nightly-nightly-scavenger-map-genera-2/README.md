# Scavenger Map Generator\n\nA tiny Rust CLI that creates a random ASCII map of a post‑apocalypse scavenging area.\n\n## Features\n\n- Deterministic output when a seed is supplied (useful for testing or sharing maps).\n- Adjustable width and height.\n- Randomly places four resource symbols:\n  - `F` – Food\n  - `W` – Water\n  - `M` – Medicine\n  - `A` – Ammo\n- Empty cells are shown as `.`\n\n## Installation\n\n```bash\n# Clone the repository (or copy the utility folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd rust-utils/nightly-scavenger-map-generator\n# Build the binary\ncargo build --release\n# The executable will be at target/release/scavenger-map-generator\n```\n\n## Usage\n\n```bash\n# Basic usage (random seed based on system time)\n./scavenger-map-generator <width> <height>\n\n# Provide an explicit seed for reproducible maps\n./scavenger-map-generator <width> <height> <seed>\n```\n\nExample:\n\n```bash\n./scavenger-map-generator 10 5 42\n```\n\nMight output:\n\n```.F..W...A\n..M...F...\n...A..W...\n.F...M....\n..W...A.F.\n```\n\n## Testing\n\nThe utility includes a Rust test suite. Run it with:\n\n```bash\ncargo test\n```\n\nAll tests should pass.\n
