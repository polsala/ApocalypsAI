# Nightly Scavenger Knapsack\n\nA whimsical command‑line utility that helps you pick the most valuable items to carry after the apocalypse, given a weight limit. It solves the classic 0/1 knapsack problem.\n\n## Usage\n\n```sh\ncargo run --release -- items.json\n```\n\n`items.json` format:\n\n```json\n{\n  "capacity": 15,\n  "items": [\n    {"name": "Canned Beans", "weight": 3, "value": 4},\n    {"name": "Water Bottle", "weight": 5, "value": 7},\n    {"name": "First Aid Kit", "weight": 8, "value": 10}\n  ]\n}\n```\n\nThe program prints the selected item names (one per line) followed by the total value, e.g.:\n\n````\nWater Bottle\nFirst Aid Kit\nTotal value: 17\n````\n\n## Tests\n\nRun `cargo test` to execute deterministic unit tests.\n
