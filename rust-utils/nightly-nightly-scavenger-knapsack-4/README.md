Nightly Scavenger Knapsack Utility\n\nOverview\nThis command line tool helps post‑apocalyptic scavengers decide which items to carry.\nGiven a weight capacity and a list of items (name weight value), it computes the combination that yields the highest total value while staying within the weight limit.\n\nInput Format\nThe program reads from standard input. The first line is the maximum weight (integer). Each subsequent line describes one item in the form:\n\n<name> <weight> <value>\n\n- name: a single word identifier for the item\n- weight: integer weight units (positive)\n- value: integer value units (positive)\n\nLines that do not contain at least three whitespace‑separated fields are ignored.\n\nOutput Format\nThe program writes to standard output. The first line is the maximum total value achievable. If at least one item is selected, the second line lists the chosen item names separated by spaces.\n\nExample\nInput:\n10\ngold 5 10\nsilver 4 7\nfood 3 4\nwater 2 3\n\nPossible optimal selections are:\n- gold + silver (weight 9, value 17)\n- gold + food + water (weight 10, value 17)\n\nThe program will output one of these optimal solutions, for example:\n17\ngold silver\n\nBuild and Run\nEnsure you have Rust toolchain installed (rustc and cargo). Then execute:\n\ncargo run --quiet < input.txt\n\nReplace "input.txt" with a file containing the input format described above, or pipe data directly.
