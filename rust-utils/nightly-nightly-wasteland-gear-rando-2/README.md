# nightly-wasteland-gear-randomizer\n\nGenerates a random list of post‑apocalyptic gear items for tabletop RPGs.\n\n## Usage\n\n```sh\ncargo run --release -- [--seed <u64>] [--count <N>]\n```\n\n- `--seed` optional seed for reproducible results.\n- `--count` number of items to generate (default 5).\n\n## Example\n\n```sh\n$ cargo run -- --seed 42 --count 3\nRadiation Suit\nMakeshift Knife\nWater Purifier\n```\n\n## Build\n\n```sh\ncargo build --release\n```
