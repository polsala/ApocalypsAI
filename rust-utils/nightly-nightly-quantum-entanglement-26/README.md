# Nightly Quantum Entanglement Checker

A whimsical Rust utility that checks if two strings are quantum-entangled using a playful hash comparison algorithm. Perfect for verifying if your messages are truly connected across the multiverse!

## Features

- 🚀 Fast Rust implementation
- 🌀 Quantum-inspired hash algorithm
- 🎭 Whimsical entanglement metaphors
- 📊 Entanglement strength scoring
- 🧪 Comprehensive test suite

## Installation

```bash
# Clone the repository
git clone <repo-url>
cd <repo-url>/rust-utils/nightly-quantum-entanglement-checker

# Build the project
cargo build --release
```

## Usage

```bash
# Check if two strings are entangled
cargo run --release -- "Hello World" "Hello World"

# Check with custom threshold
cargo run --release -- "Hello" "World" --threshold 0.8

# Interactive mode
cargo run --release --interactive
```

## Output

The tool will output:
- Whether the strings are entangled
- Entanglement strength (0.0 to 1.0)
- Whimsical quantum metaphors
- Quantum decoherence warnings if applicable

## Examples

```bash
$ cargo run --release -- "Hello World" "Hello World"
✨ Quantum Entanglement Confirmed! ✨
Entanglement Strength: 1.0/1.0
"These strings are perfectly entangled across all quantum states!"

$ cargo run --release -- "Hello" "World"
⚠️  Quantum Decoherence Detected!
Entanglement Strength: 0.2/1.0
"These strings show minimal quantum connection."
```
