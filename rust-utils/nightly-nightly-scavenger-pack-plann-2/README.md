# Nightly Scavenger Pack Planner\n\nA whimsical CLI tool that solves the 0/1 knapsack problem, helping post‑apocalypse scavengers choose the most valuable items that fit within a weight limit.\n\n## Usage\n\n```sh\ncargo run -- <capacity> "<item1:name:weight:value,...>"\n```\n\n- **capacity** – maximum total weight the pack can hold.\n- Each item is described as `name:weight:value`.\n\n## Example\n\n```sh\ncargo run -- 50 "water:10:30,food:20:50,radio:5:10,medicine:15:40"\n```\n\n## Output\n\n``\nBest pack (total value 120): water, food, medicine\n``\n\nThe program prints the optimal subset of items and the total value.\n
