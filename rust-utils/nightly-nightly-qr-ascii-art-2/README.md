# nightly-qr-ascii-art\n\nA tiny Rust CLI that converts input text into an ASCII QR code, perfect for sharing secrets on terminals.\n\n## Installation\n\n```sh\ncargo install --path .\n```\n\n## Usage\n\n```sh\necho "Hello, world!" | nightly-qr-ascii-art\n```\n\nThe command reads from STDIN, generates a QR code, and prints an ASCII representation where dark modules are rendered as `██` and light modules as two spaces.\n\n## How it works\n\nThe tool uses the `qrcode` crate to generate a QR matrix and then maps each boolean module to either `██` (dark) or `  ` (light).\n
