# nightly‑scavenger‑route‑planner

**What it does**

A tiny Rust command‑line tool that takes a list of location names (e.g., "Abandoned Mall", "Ruined Library") and spits out a deterministic “scavenger route”.

The route is generated by sorting the locations alphabetically and then rotating the list by a seed value, so the same input always yields the same output – perfect for reproducible jokes or game‑master prep.

**Installation**

```bash
# From the utility directory
cargo build --release
# The binary will be at target/release/nightly-scavenger-route-planner
```

**Usage**

```bash
./target/release/nightly-scavenger-route-planner "Abandoned Mall" "Ruined Library" "Old Farm" "Collapsed Bridge"
```

Output (seed is fixed at 42 in the binary):

```
1. Old Farm
2. Ruined Library
3. Abandoned Mall
4. Collapsed Bridge
```

**Custom seed (for developers)**

The core library function `generate_route` accepts a `seed: u64`. You can call it from your own Rust code to control the rotation.

**Testing**

Run the test suite with:

```bash
cargo test
```

The tests verify that the route generation is deterministic.
