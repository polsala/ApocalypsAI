Nightly Scavenger Distance Utility\n\nCalculate the Manhattan distance between two points and estimate a whimsical radiation exposure for post‑apocalyptic scavengers.\n\nUsage:\n  nightly-scavenger-distance <x1> <y1> <x2> <y2>\n\nExample:\n  $ nightly-scavenger-distance 0 0 3 4\n  Distance: 7\n  Estimated radiation exposure: 0.93 Sieverts\n\nThe exposure is computed with a playful formula: exposure = 0.05 * distance^{1.5}.  The result is shown with two decimal places.
