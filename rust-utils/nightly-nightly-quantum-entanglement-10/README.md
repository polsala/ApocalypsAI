# Nightly Quantum Entanglement Checker

A whimsical CLI tool that checks if two files are quantum-entangled using hash-based entanglement detection.

## Features

- 🚀 Fast Rust implementation with multithreading
- 🔍 Detects quantum entanglement between files
- 📊 Generates entanglement reports with quantum metrics
- 🎭 Whimsical quantum-themed output
- 🧪 Built-in test suite with mock quantum states

## Installation

```bash
# Clone the repository
git clone https://github.com/polsala/ApocalypsAI.git
cd ApocalypsAI

# Build the quantum entanglement checker
cargo build --release --bin nightly-quantum-entanglement-checker
```

## Usage

```bash
# Check if two files are quantum-entangled
cargo run --release --bin nightly-quantum-entanglement-checker -- file1.txt file2.txt

# Generate a detailed entanglement report
cargo run --release --bin nightly-quantum-entanglement-checker -- --report file1.txt file2.txt

# Check multiple file pairs
cargo run --release --bin nightly-quantum-entanglement-checker -- --batch file_pairs.txt
```

## Quantum Entanglement Detection

The tool uses advanced quantum algorithms to:

1. Calculate quantum hash signatures for both files
2. Measure quantum correlation coefficients
3. Determine entanglement probability
4. Generate quantum state reports

## Examples

```bash
# Check if your config files are quantum-entangled
cargo run --release --bin nightly-quantum-entanglement-checker -- config1.json config2.json

# Verify backup file entanglement
cargo run --release --bin nightly-quantum-entanglement-checker -- --report backup1.tar.gz backup2.tar.gz
```
