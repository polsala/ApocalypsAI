# Nightly Quantum Entanglement Checker

A whimsical CLI tool that checks if two code files are 'quantum entangled' by comparing their hashes with a playful quantum physics theme.

## Features

- 🚀 Blazing fast hash comparison using Rust
- 🎭 Whimsical quantum physics-themed output
- 🔍 Detects if files are identical (entangled) or different (decohered)
- 📊 Shows hash values with quantum-inspired formatting
- 🧪 Perfect for verifying file integrity with a fun twist

## Installation

```bash
# Clone the repository
git clone <repo-url>
cd utils/nightly-quantum-entanglement-checker

# Build the tool
cargo build --release

# Run the tool
./target/release/quantum-entanglement-checker <file1> <file2>
```

## Usage

```bash
# Check if two files are quantum entangled
quantum-entanglement-checker file1.rs file2.rs

# Example output:
# 📄 File 1: file1.rs
# 📄 File 2: file2.rs
# 
# 🌀 Quantum State Analysis:
# 📊 Hash 1: 0x1a2b3c4d5e6f7890
# 📊 Hash 2: 0x1a2b3c4d5e6f7890
# 
# ✅ QUANTUM ENTANGLEMENT DETECTED!
# These files are perfectly synchronized across the quantum realm.
```

## Quantum States

- **Entangled**: Files have identical hashes
- **Decohered**: Files have different hashes
- **Superposition**: One or both files couldn't be read

## Why Quantum?

Because checking file hashes should be as exciting as exploring the quantum realm! This tool brings a touch of whimsy to the otherwise mundane task of file comparison.
