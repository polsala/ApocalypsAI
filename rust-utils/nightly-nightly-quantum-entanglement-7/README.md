# Nightly Quantum Entanglement Checker

A whimsical utility that checks if two code snippets are quantum-entangled (i.e., identical) using Rust for speed. Includes a React dashboard for visualization.

## Features

- Fast comparison using Rust's efficient string handling
- Whimsical quantum-themed output messages
- React dashboard for visualizing comparison results
- Deterministic tests with mocked inputs

## Installation

1. Clone the repository
2. Navigate to the utility directory
3. Run `cargo build --release` for the Rust binary
4. Navigate to the dashboard directory and run `npm install && npm start` for the React dashboard

## Usage

```bash
./target/release/nightly-quantum-entanglement-checker <file1> <file2>
```

## Dashboard

The React dashboard provides a visual interface for comparing files and viewing results.
