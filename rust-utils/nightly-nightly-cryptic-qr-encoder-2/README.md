# nightly-cryptic-qr-encoder\n\nA tiny Rust command‑line utility that turns any short text into an ASCII‑art QR code printed to STDOUT.\n\n## Installation\n\n```bash\n# From the repository root\ncd rust-utils/nightly-cryptic-qr-encoder\ncargo install --path .\n```\n\n## Usage\n\n```bash\n$ nightly-cryptic-qr-encoder "HELLO WORLD"\n████████████████████████\n█ ░░░░░░░░░░░░░░░░░ █\n█ ░████ ████ ░██ █ █\n█ ░████ ████ ░██ █ █\n█ ░████ ████ ░██ █ █\n█ ░░░░░░░░░░░░░░░░░ █\n████████████████████████\n```\n\nThe output uses the full‑block character (`█`) for dark modules and a space for light modules, making it copy‑paste‑friendly.\n\n## Why?\n\n* **Whimsical** – share secret messages in a way that looks like terminal art.\n* **Useful** – no external image viewer needed; perfect for SSH sessions or CI logs.\n* **Fast** – pure Rust, zero‑cost abstraction, instant generation.\n\n## Testing\n\nRun the test suite with:\n\n```bash\ncargo test\n```\n\nThe integration test checks that the binary runs successfully and that the output contains at least one dark block (`█`).
