# Scavenger Route Planner\n\nA whimsical CLI tool that reads a list of locations with coordinates and outputs a simple scavenger route with total travel distance. Useful for tabletop games, post‑apocalypse role‑play, or just fun walks.\n\n## Usage\n\nCreate a file `locations.txt` with lines:\n\n````\nName,x,y\n````\n\nExample:\n\n````\nVault,0,0\nBunker,3,4\nOasis,6,8\n````\n\nRun:\n\n```sh\ncargo run -- locations.txt\n```\n\nOutput:\n\n````\nRoute:\n1. Bunker (3,4)\n2. Oasis (6,8)\n3. Vault (0,0)\nTotal distance: 15.00 units\n````\n\n## Build\n\n```sh\ncargo build --release\n```\n\n## Test\n\n```sh\ncargo test\n```
