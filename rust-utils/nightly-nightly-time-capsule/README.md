# Nightly Time Capsule\n\nA whimsical CLI tool that lets you seal a message with a future date into a simple capsule string, and later open it to verify integrity.\n\n## Usage\n\n```sh\n# Seal a message\nnightly-time-capsule seal "Your secret" 2099-12-31\n\n# Open a capsule\nnightly-time-capsule open "Your secret|2099-12-31|1a2b3c"\n```\n\nThe capsule format is `message|date|hash`. The hash is a deterministic sum of the UTF‑8 bytes of the message and date, shown in hexadecimal.\n\n## Build\n\n```sh\ncargo build --release\n```\n\n## Test\n\n```sh\ncargo test\n```
