Apocalypse Calendar Converter\n\nConvert Gregorian dates to the whimsical Apocalypse Calendar used by survivors.\n\nUsage:\n  cargo run -- 2023-02-01\n\nOutputs:\n  Wasteland Year 0, Month 2, Day 2\n\nBuild:\n  cargo build --release\n\nHow it works:\n- The apocalypse is assumed to have started on 2023-01-01 (Wasteland Year 0, Month 1, Day 1).\n- Each year = 365 days, each month = 30 days, remaining days form the last month.\n- Dates before the apocalypse produce negative years.
