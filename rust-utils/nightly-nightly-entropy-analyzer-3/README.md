# nightly-entropy-analyzer\n\n**What it does**\n\n`nightly-entropy-analyzer` reads text from a file or STDIN, prints a sorted histogram of character frequencies, and reports the Shannon entropy of the input.  It’s a fun way to peek at the randomness of your logs, poems, or secret messages.\n\n**Installation**\n\n```bash\n# Clone the repository (or let the ApocalypsAI bot generate it)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/rust-utils/nightly-entropy-analyzer\n\n# Build the binary\ncargo build --release\n\n# The binary will be at target/release/entropy-analyzer\n```\n\n**Usage**\n\n```bash\n# From a file\n./entropy-analyzer path/to/file.txt\n\n# From STDIN\necho "Hello, world!" | ./entropy-analyzer\n```\n\n**Example output**\n\n```\nCharacter frequencies (sorted by count):\n  ' ' : 2\n  '!' : 1\n  ',' : 1\n  'H' : 1\n  'd' : 1\n  'e' : 1\n  'l' : 3\n  'o' : 2\n  'r' : 1\n  'w' : 1\n\nShannon entropy: 3.1808329872361905 bits per character\n```\n\n**Testing**\n\n```bash\ncargo test\n```\n\n**License**\n\nMIT
