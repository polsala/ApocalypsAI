# Nightly Entropy Analyzer\n\n**What it does**\n\n`nightly-entropy-analyzer` is a small, zero‑dependency Rust command‑line tool that reads a file and prints its Shannon entropy in bits per byte.  High entropy (≈8 bits) usually means the data is compressed or encrypted, while low entropy indicates plain text or repetitive content.\n\n**Why it’s useful**\n\n* Quick sanity check for backups, logs, or unknown files\n* Helps decide whether a file should be compressed further\n* Fun way to explore information theory on the command line\n\n**Build & Run**\n\n```bash\n# Clone the repository (or copy the generated folder)\ncd rust-utils/nightly-entropy-analyzer\n# Build the binary\ncargo build --release\n# Run it on a file\n./target/release/entropy-analyzer path/to/file\n```\n\nThe program prints a single line, e.g. `7.92 bits per byte`.\n\n**Testing**\n\n```bash\ncargo test\n```\n\nAll tests are deterministic and run offline.\n
