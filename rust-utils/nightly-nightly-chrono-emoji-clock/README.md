# Chrono Emoji Clock\n\nA tiny Rust CLI that turns a 24‑hour time (HH:MM) into the nearest clock‑face emoji. Perfect for adding a whimsical timestamp to logs, chats, or commit messages.\n\n## Usage\n\n```sh\ncargo run -- <HH:MM>\n```\n\n## Examples\n\n```sh\n$ cargo run -- 14:05\n🕑\n$ cargo run -- 14:30\n🕞\n$ cargo run -- 14:55\n🕒\n```\n\nIf the input is malformed the program exits with a non‑zero status and prints a usage hint.\n\n## Installation\n\n```sh\ngit clone <repo>\ncd nightly-chrono-emoji-clock\ncargo build --release\n./target/release/chrono-emoji-clock 09:45\n```
