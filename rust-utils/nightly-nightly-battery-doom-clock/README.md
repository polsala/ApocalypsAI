Nightly Battery Doom Clock\n\nA whimsical command-line tool that estimates how many days your device's battery will last in the post-apocalyptic wasteland.\n\nInstallation:\n- Ensure Rust and Cargo are installed.\n- Run: cargo install --path .\n\nUsage:\nnightly-battery-doom-clock <capacity_mAh> <draw_mA> [hours_per_day]\n\nIf hours_per_day is omitted, it defaults to 24 (full day operation).\n\nExample:\nnightly-battery-doom-clock 3000 500\nEstimated battery life: 0.25 days\n⚠️  You might not survive the night!\n
