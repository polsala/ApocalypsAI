# Nightly Quantum Entanglement Checker

Ever wondered if two files are quantum entangled? This whimsical CLI tool checks if two files share the same quantum state by comparing their hashes with a probabilistic twist!

## Features

- 🚀 Fast Rust implementation
- 🔬 Probabilistic entanglement detection
- 🎲 Quantum randomness simulation
- 📊 Detailed entanglement reports
- 🧪 Built-in tests with mock files

## Installation

```bash
# Clone the repo and navigate to the utility
cd utils/nightly-quantum-entanglement-checker

# Build with Cargo
cargo build --release

# Run the tool
./target/release/quantum-entanglement-checker <file1> <file2>
```

## Usage

```bash
# Check if two files are entangled
quantum-entanglement-checker file1.txt file2.txt

# Output:
# 📄 File 1: file1.txt
# 📄 File 2: file2.txt
# 🔗 Entanglement Status: Quantumly Entangled! 🪐
# 📊 Confidence Level: 99.7%
# 🎲 Quantum Randomness: 0.003
```

## How It Works

The tool uses SHA-256 hashing with a quantum randomness factor to determine if files are entangled. It's completely serious. Probably.
