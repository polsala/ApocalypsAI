# nightly-terminal-qr\n\n**nightly-terminal-qr** is a tiny, blazing‑fast Rust command‑line tool that turns any short text into a QR code rendered as Unicode block characters in your terminal.\n\n## Features\n\n- Zero‑dependency runtime (only the `qrcode` crate at compile time)\n- Outputs compact Unicode art (`█` and space) – works on any modern terminal\n- Perfect for sharing secret URLs, passwords, or apocalypse‑level messages without leaving your shell\n\n## Installation\n\n```bash\n# Clone the repository (or copy the generated folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/rust-utils/nightly-terminal-qr\n# Build the binary\ncargo build --release\n# The binary will be at target/release/nightly-terminal-qr\n```\n\n## Usage\n\n```bash\n# Encode a simple string\n./target/release/nightly-terminal-qr "https://example.com"\n\n# Encode a secret phrase\n./target/release/nightly-terminal-qr "The quick brown fox"\n```\n\nThe program prints the QR code directly to stdout. Pipe it into `pbcopy` (macOS) or `xclip` (Linux) to copy the visual representation, or simply share the terminal screenshot.\n\n## Example Output\n\n```\n████████████████████████\n██  ██  ████  ██  ██  ██\n██ █ █ ████ █ █ ███ ███\n██  ██  ████  ██  ██  ██\n████████████████████████\n```\n\n## Testing\n\nRun the bundled test suite with:\n\n```bash\ncargo test\n```\n\nAll tests are deterministic and run offline.\n\n## License\n\nMIT – see LICENSE file in the repository root.
