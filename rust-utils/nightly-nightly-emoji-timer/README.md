# Nightly Emoji Timer\n\nA whimsical CLI tool that counts down a given duration and displays emojis to visualize the passage of time.\n\n- **⏳** – hourglass for most of the countdown\n- **🔥** – fire for the final seconds\n- **✅** – checkmark when the timer finishes\n\n## Installation\n\n```bash\n# Clone the repository (or copy the utility folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd rust-utils/nightly-emoji-timer\n# Build the binary\ncargo build --release\n```\n\n## Usage\n\n```bash\n# Run the timer for 1 hour 30 minutes\ncargo run --release -- 1h30m\n```\n\nThe program will update the terminal each second with the appropriate emoji until the countdown reaches zero.\n
