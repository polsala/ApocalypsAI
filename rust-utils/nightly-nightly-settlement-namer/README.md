# Settlement Namer\n\nA tiny Rust CLI that spits out whimsical post‑apocalyptic settlement names, e.g. "Dusty Haven". Useful for world‑building, games, or naming your next bunker.\n\n## Installation\n\n```sh\ncargo build --release\n```\n\n## Usage\n\n```sh\n# Generate a single name\ncargo run --quiet\n\n# Generate 5 names\ncargo run --quiet -- 5\n```\n\n## How it works\n\nThe program picks a random adjective and a random noun from predefined lists and combines them.
