# nightly-survival-gear-optimizer\n\nA tiny Rust command‑line utility that solves the classic 0/1 knapsack problem for scavenged gear.\n\n## Why?\nIn a wasteland you can only carry so much weight, but you want the most useful items. This tool reads a list of items (name, weight, utility) from *stdin* and, given a weight limit, prints the optimal set of items and the total utility.\n\n## Installation\n```bash\n# Install Rust toolchain if you don't have it\ncurl https://sh.rustup.rs -sSf | sh\n\n# Build the binary\ncd utils/rust-utils/nightly-survival-gear-optimizer\ncargo build --release\n```\nThe binary will be at `target/release/nightly-survival-gear-optimizer`.\n\n## Usage\n```bash\n# Provide the weight limit as the sole argument\n# Then feed a CSV list of items (name,weight,utility) via stdin\ncat <<EOF | ./target/release/nightly-survival-gear-optimizer 10\nWater,3,10\nFood,4,12\nRadio,2,7\nTent,5,9\nEOF\n```\nOutput example:\n```
Selected items: Water, Radio\nTotal utility: 17\n```\n\n## Input format\nEach line must contain three comma‑separated fields:\n- **name** – a short identifier (no commas)\n- **weight** – integer weight units\n- **utility** – integer usefulness score\n\nEmpty lines are ignored.\n\n## Testing\n```bash\ncargo test\n```\nThe test suite covers basic scenarios and edge cases.\n
