# Nightly Rust Survival Tip Generator\n\nA tiny Rust CLI that prints a random post‑apocalyptic survival tip. Perfect for a quick morale boost during system maintenance.\n\n## Usage\n\n```sh\ncargo run --quiet\n```\n\nOr install and run the binary:\n\n```sh\ncargo install --path .\nsurvival-tip\n```\n\nEach execution prints one tip, e.g.:\n\n````\nAlways keep a spare can‑opener in your bunker.\n````\n\n## How it works\n\nThe program stores a static list of tips and selects one at random using the `rand` crate.\n\n## Testing\n\nRun the test suite with:\n\n```sh\ncargo test\n```\n\nThe test verifies that a deterministic seed returns a tip that belongs to the predefined list.
