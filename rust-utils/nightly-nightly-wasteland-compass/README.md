# nightly-wasteland-compass\n\nA tiny Rust CLI that spits out a post‑apocalyptic navigation tip for a given cardinal direction.\n\n## Build\n\n```bash\n# Install Rust toolchain (if not already installed)\ncurl https://sh.rustup.rs -sSf | sh\n\n# Clone the repository and build\ngit clone <repo-url>\ncd nightly-wasteland-compass\ncargo build --release\n```\n\nThe binary will be located at `target/release/nightly-wasteland-compass`.\n\n## Usage\n\n```bash\n# Basic usage – direction only (random seed based on system time)\n./nightly-wasteland-compass north\n\n# Provide an explicit seed for deterministic output\n./nightly-wasteland-compass east 12345\n```\n\n### Arguments\n- **direction**: one of `north`, `south`, `east`, `west` (case‑insensitive).\n- **seed** (optional): unsigned 64‑bit integer used to pick a deterministic tip. If omitted, the current UNIX timestamp is used as the seed.\n\n## Example\n\n```bash\n$ ./nightly-wasteland-compass north 42\nFollow the broken radio tower\n```\n\n## Testing\n\nRun the test suite with:\n\n```bash\ncargo test\n```\n\nAll tests are deterministic and require no external resources.\n
