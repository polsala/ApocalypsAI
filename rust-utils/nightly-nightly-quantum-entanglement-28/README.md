# Nightly Quantum Entanglement Checker

A whimsical-yet-useful Rust utility that generates and verifies quantum entanglement pairs for fun and pseudo-scientific validation. Perfect for adding a touch of quantum mystique to your codebase!

## Features

- Generate quantum entanglement pairs with unique identifiers
- Verify entanglement integrity using quantum algorithms
- Whimsical quantum state visualization
- Deterministic testing with mock quantum states

## Installation

```bash
# Clone the repository
git clone https://github.com/polsala/ApocalypsAI.git

cd ApocalypsAI/rust-utils/nightly-quantum-entanglement-checker

# Build the project
cargo build --release

# Run the utility
./target/release/nightly-quantum-entanglement-checker
```

## Usage

```bash
# Generate a new entanglement pair
./target/release/nightly-quantum-entanglement-checker generate

# Verify an existing entanglement pair
./target/release/nightly-quantum-entanglement-checker verify <pair_id>

# List all entanglement pairs
./target/release/nightly-quantum-entanglement-checker list

# Visualize quantum states
./target/release/nightly-quantum-entanglement-checker visualize <pair_id>
```
