# nightly-emoji-picker\n\nA tiny Rust CLI that prints a random emoji.\n\n## Features\n\n- **Deterministic mode**: Provide a numeric seed to get the same emoji every time.\n- **Random mode**: No seed? It picks an emoji based on the current time.\n- **Zero‑dependency runtime** (apart from `rand` for randomness).\n\n## Installation\n\n```bash\n# Clone the utility (or let the ApocalypsAI generator add it)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/rust-utils/nightly-emoji-picker\n# Build the binary\ncargo build --release\n# The binary will be at target/release/nightly-emoji-picker\n```\n\n## Usage\n\n```bash\n# Random emoji\n./nightly-emoji-picker\n# Deterministic emoji with seed 42\n./nightly-emoji-picker --seed 42\n```\n\n## How it works\n\nThe tool contains a hard‑coded list of 50+ Unicode emojis. When a seed is supplied, it creates a `ChaCha8Rng` seeded with that value and selects an emoji uniformly at random. Without a seed, it falls back to a time‑based seed, making each run different.\n\n## Testing\n\nRun the test suite with:\n\n```bash\ncargo test\n```\n\nThe tests verify that a given seed always yields the same emoji.\n
