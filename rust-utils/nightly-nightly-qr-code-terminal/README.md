# nightly-qr-code-terminal\n\n**Generate QR codes rendered as Unicode art directly in the terminal.**\n\n## Overview\n\n`nightly-qr-code-terminal` is a tiny Rust CLI tool that takes an arbitrary string and prints a QR code using Unicode block characters ("██" for black modules and two spaces for white modules). The output is pure text, so it works in any terminal without external image viewers.\n\n## Installation\n\n```bash\n# Clone the repository (or copy the generated folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/rust-utils/nightly-qr-code-terminal\n\n# Build and install locally\ncargo install --path .\n```\n\n## Usage\n\n```bash\nnightly-qr-code-terminal "Hello, world!"\n```\n\nThe command prints a QR code that encodes the supplied text.\n\n## Example\n\n```bash\nnightly-qr-code-terminal "A"\n```\n\nWill output something like (the exact pattern depends on the QR version):\n\n````\n████████████████████\n██          ██    ██\n██  ████  ████  ████\n██  ████  ████  ████\n██  ████  ████  ████\n██          ██    ██\n████████████████████\n````\n\n## License\n\nMIT – see the LICENSE file in the repository root.\n
