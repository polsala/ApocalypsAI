# nightly-dice-roller

A whimsical CLI tool that rolls dice using standard dice notation (e.g., "2d6+3"). Perfect for post‑apocalyptic tabletop sessions.

## Installation

```sh
cargo install --path .
```

## Usage

```sh
nightly-dice-roller 3d8+2
```

Outputs:

```
Result: 17
```

## Testing

```sh
cargo test
```
