# nightly-clipboard-xor\n\nA whimsical yet handy command‑line utility written in Rust that lets you XOR‑encrypt or decrypt a piece of text with a passphrase. The encrypted output is shown as a hex string, making it easy to copy‑paste into chat, notes, or anywhere else.\n\n## Features\n\n- **Encrypt** a string with a key, producing a hex representation.\n- **Decrypt** a previously‑encrypted hex string back to the original text.\n- No external dependencies – pure Rust standard library.\n\n## Installation\n\n```bash\n# Clone the repository (or let the ApocalypsAI bot generate it)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/rust-utils/nightly-clipboard-xor\n# Build the binary\ncargo build --release\n# The binary will be at target/release/clipboard-xor\n```\n\n## Usage\n\n```bash\n# Encrypt a message\n./clipboard-xor encrypt -k mysecret "Hello, world!"\n# => 0b0c0d0c0c0b0e0c0d0c0c0b\n\n# Decrypt the hex string\n./clipboard-xor decrypt -k mysecret 0b0c0d0c0c0b0e0c0d0c0c0b\n# => Hello, world!\n```\n\n## Command‑line interface\n\n```
clipboard-xor <mode> -k <key> <payload>\n\nmode:\n  encrypt   Encrypt <payload> (plain text) and output hex\n  decrypt   Decrypt <payload> (hex) back to plain text\n\nkey:\n  The passphrase used for XOR operation.\n\npayload:\n  The text to encrypt or the hex string to decrypt.\n```\n\n## Testing\n\nThe utility ships with a small test suite that checks encryption, decryption, and a known‑vector example. Run the tests with:\n\n```bash\ncargo test\n```\n\nEnjoy encrypting your secret notes in the apocalypse!\n
