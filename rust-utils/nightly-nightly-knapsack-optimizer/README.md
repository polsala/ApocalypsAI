# nightly-knapsack-optimizer\n\nA tiny Rust CLI that solves the 0/1 knapsack problem for survival inventory planning. Provide a JSON file describing items (name, weight, value) and a maximum weight capacity; the tool outputs the optimal set of item names.\n\n## Usage\n\n```sh\ncargo run -- <items.json> <max_weight>\n```\n\nExample `items.json`:\n\n```json\n[\n  {"name":"Water","weight":3,"value":10},\n  {"name":"Food","weight":2,"value":7},\n  {"name":"Medkit","weight":5,"value":12}\n]\n```\n\nRunning:\n\n```sh\ncargo run -- items.json 5\n```\n\nOutputs:\n\n```\n["Water","Food"]\n```\n\n## Building\n\n```sh\ncargo build --release\n```\n\n## Testing\n\n```sh\ncargo test\n```
