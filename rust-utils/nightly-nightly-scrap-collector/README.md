# Nightly Scrap Collector\n\nA whimsical CLI utility for post‑apocalyptic scavengers. Given a list of potential loot items (name, weight, value) and a maximum carry weight, it selects a subset of items that maximizes total value using a simple greedy algorithm.\n\n## Installation\n\n```sh\ncargo install --path .\n```\n\n## Usage\n\n```sh\nnightly-scrap-collector --capacity 50 --items items.csv\n```\n\n`items.csv` format:\n\n```\nname,weight,value\nCanned Beans,5,10\nWater Bottle,3,8\nFirst Aid Kit,10,25\n```\n\nThe program prints selected items and total weight/value.\n\n## Example\n\n```sh\n$ cat items.csv\nname,weight,value\nCanned Beans,5,10\nWater Bottle,3,8\nFirst Aid Kit,10,25\nRope,2,5\n\n$ nightly-scrap-collector --capacity 15 --items items.csv\nSelected items:\n- First Aid Kit (weight: 10, value: 25)\n- Rope (weight: 2, value: 5)\n- Water Bottle (weight: 3, value: 8)\nTotal weight: 15\nTotal value: 38\n```\n\n## License\n\nMIT
