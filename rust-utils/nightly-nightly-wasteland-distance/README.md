# Nightly Wasteland Distance\n\nA tiny Rust CLI that computes the great‑circle distance between two points on the post‑apocalyptic map. Perfect for scavengers plotting routes across the wasteland.\n\n## Features\n\n* Uses the haversine formula for accurate Earth‑scale distances.\n* No external dependencies – just pure Rust std.\n* Whimsical output suitable for survival logs.\n\n## Installation\n\n```sh\n# Build the binary\ncargo build --release\n# The executable will be at target/release/nightly-wasteland-distance\n```\n\n## Usage\n\n```sh\nnightly-wasteland-distance <lat1> <lon1> <lat2> <lon2>\n```\n\nExample:\n\n```sh\n$ nightly-wasteland-distance 48.8566 2.3522 51.5074 -0.1278\nThe distance between (48.8566, 2.3522) and (51.5074, -0.1278) is 343.77 km\n```\n\n## Testing\n\n```sh\ncargo test\n```\n\nAll tests run offline and are deterministic.\n\n## License\n\nMIT
