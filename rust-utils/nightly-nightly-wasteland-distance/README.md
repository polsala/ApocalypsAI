# nightly-wasteland-distance\n\nCompute the straight‑line distance between two points in the post‑apocalypse wasteland and receive a whimsical travel difficulty rating.\n\n## Usage\n\n```sh\nnightly-wasteland-distance <x1> <y1> <x2> <y2>\n```\n\nExample:\n\n```sh\nnightly-wasteland-distance 0 0 3 4\n```\n\nOutput:\n\n````\nDistance: 5.00 units\nRating: a short stroll through the ruins\n````\n\n## Build\n\n```sh\ncargo build --release\n```\n\n## Test\n\n```sh\ncargo test\n```
