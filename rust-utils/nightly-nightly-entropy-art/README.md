# nightly-entropy-art\n\nGenerate an 8×8 ASCII art pattern from the SHA‑256 hash of a given string. Perfect for adding a touch of post‑apocalyptic flair to logs, commit messages, or terminal greetings.\n\n## Usage\n\n```sh\ncargo run -- <your text>\n```\n\nExample:\n\n```sh\n$ cargo run -- "Hello, wasteland!"\n█  ████\n█    ██ \n██ █    \n█      █\n█   █   \n █  ██  \n █████ █\n ██  █ █\n```\n\n## How it works\n\nThe tool hashes the input with SHA‑256, takes the first 64 bits, and maps each bit to a character:\n\n* `1` → `█`\n* `0` → space\n\nThe bits are laid out row‑major to form an 8×8 grid.\n\n## Testing\n\n```sh\ncargo test\n```
