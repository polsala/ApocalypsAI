# Nightly Wasteland Distance Calculator\n\n## Overview\n\n`nightly-wasteland-distance-calculator` is a tiny Rust command‑line utility that reads a list of 2‑D coordinates representing waypoints in a post‑apocalyptic wasteland, computes the total Euclidean distance travelled in the given order, and prints the result with a whimsical message.\n\n## Usage\n\n```bash\n# Build the binary\ncargo build --release\n\n# Run with a file containing coordinates\n./target/release/wasteland-distance-calculator path/to/points.txt\n\n# Or pipe coordinates via stdin (use "-" as the filename)\necho -e "0 0\n3 4\n6 8" | ./target/release/wasteland-distance-calculator -\n```\n\n### Input format\n\nEach line must contain exactly two numbers separated by whitespace: `x y`. Both numbers are parsed as `f64`. Blank lines or malformed lines are ignored.\n\nExample `points.txt`:\n\n```
0 0\n3 4\n6 8\n```\n\n### Output\n\nThe program prints the total distance rounded to two decimal places, followed by a short post‑apocalyptic remark. Example output for the above file:\n\n```
Total wasteland distance: 10.00 units.\nThe desert winds carry the tale of your journey.\n```\n\n## Building\n\nThe project uses only the Rust standard library – no external crates are required.\n\n```bash\ncargo build --release\n```\n\n## Testing\n\nRun the test suite with:\n\n```bash\ncargo test\n```\n\nAll tests are deterministic and run offline.\n
