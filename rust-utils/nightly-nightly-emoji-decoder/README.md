# nightly-emoji-decoder\n\nA tiny Rust CLI that translates a sequence of emojis into their textual descriptions.\n\n## Installation\n\n```sh\n# Clone the repository\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/rust-utils/nightly-emoji-decoder\n\n# Build the binary\ncargo build --release\n```\n\n## Usage\n\n```sh\n# Run the tool with an emoji string\n./target/release/nightly-emoji-decoder "🚀🌕"\n```\n\nOutput:\n\n```
rocket moon\n```\n\nThe tool maps a handful of common post‑apocalyptic emojis to words. Unknown emojis are echoed back unchanged.\n\n## Adding New Mappings\n\nEdit `src/lib.rs` and add entries to the `get_mapping` function.\n
