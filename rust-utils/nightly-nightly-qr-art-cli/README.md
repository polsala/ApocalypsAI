# nightly-qr-art-cli\n\n**nightly-qr-art-cli** is a whimsical yet practical command‑line utility written in Rust that turns any short text into a QR code rendered as Unicode block characters (█ and space).  It works entirely offline, has no external binaries, and can be dropped into any terminal that supports UTF‑8.\n\n## Features\n\n- Zero‑runtime dependencies beyond the tiny `qrcode` crate.\n- Outputs a square QR code using double‑width block characters for a clear visual appearance.\n- Deterministic output – the same input always yields the same art.\n- Small binary (≈ 200 KB) suitable for scripting or quick sharing.\n\n## Installation\n\n```bash\n# Clone the repository (or copy the generated folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/rust-utils/nightly-qr-art-cli\n\n# Build the binary\ncargo build --release\n\n# The executable will be at target/release/qr-art\n```\n\n## Usage\n\n```bash\n# Print a QR code for the string "Hello, world!"\n./target/release/qr-art "Hello, world!"\n\n# If no argument is supplied, the tool prints a short help message.\n```\n\nThe output looks like this (example for "Hi"):\n\n````\n████████████\n██      ██\n██ ████ ██\n██ ████ ██\n██ ████ ██\n██      ██\n████████████\n````\n\n## Testing\n\nThe crate ships with a tiny test suite that checks the deterministic nature of the generator. Run it with:\n\n```bash\ncargo test\n```\n\n## License\n\nMIT – see the LICENSE file in the repository root.\n
