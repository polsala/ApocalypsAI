# Nightly Gear Weight Calculator\n\nA tiny Rust CLI that reads a JSON file describing survival gear items and their weights, sums the total weight, and warns if it exceeds a configurable limit.\n\n## Usage\n\n```sh\ncargo run --release -- path/to/items.json [MAX_WEIGHT]\n```\n\n- `items.json` should contain an array of objects with `name` and `weight` (kg).\n- `MAX_WEIGHT` optional, default 30.0 kg.\n\n## Example\n\n```json\n[\n  { "name": "Backpack", "weight": 2.5 },\n  { "name": "Water Bottle", "weight": 1.2 },\n  { "name": "Tent", "weight": 5.0 }\n]\n```\n\nRunning:\n\n```sh\ncargo run -- items.json 10\n```\n\nOutput:\n\n````\nTotal weight: 8.70 kg\n✅ Within limit (10.00 kg)\n````\n\nIf exceeds:\n\n````\nTotal weight: 12.30 kg\n⚠️ Exceeds limit (10.00 kg)\n````\n\n## Testing\n\n```sh\ncargo test\n```
