# nightly-knapsack-scout\n\n**nightly‑knapsack‑scout** is a tiny Rust command‑line utility that helps a post‑apocalyptic scavenger decide which items to carry when their pack has a limited weight capacity.\n\nIt solves the classic 0/1 knapsack problem using dynamic programming and prints the optimal set of items together with the total value.\n\n## Installation\n\n```bash\n# Clone the repository (or copy the generated folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/rust-utils/nightly-knapsack-scout\n# Build the binary\ncargo build --release\n# The binary will be at target/release/nightly-knapsack-scout\n```\n\n## Usage\n\n```bash\n# Prepare a JSON file describing the available items\ncat > items.json <<EOF\n[\n  {\"name\": \"gold\",   \"weight\": 5, \"value\": 10},\n  {\"name\": \"silver\", \"weight\": 3, \"value\": 7},\n  {\"name\": \"bronze\", \"weight\": 4, \"value\": 8}\n]\nEOF\n\n# Run the tool with a capacity of 7 units\n./target/release/nightly-knapsack-scout 7 items.json\n```\n\n### Expected output\n\n```
Selected items (total value 15):\n- silver (weight 3, value 7)\n- bronze (weight 4, value 8)\n```\n\n## How it works\n\n1. The program reads the capacity (a positive integer) and a JSON file containing an array of items.\n2. Each item has a `name`, `weight`, and `value`.\n3. Using a classic DP table it computes the maximum achievable value for every sub‑capacity.\n4. It then back‑tracks to reconstruct the exact items that give this optimum.\n\nThe implementation lives in `src/main.rs` and includes a unit test (`tests` module) that verifies the algorithm on a small example.\n\n## License\n\nMIT – see the root LICENSE file.\n
