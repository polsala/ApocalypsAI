# nightly-qr-encoder\n\nA tiny Rust CLI that takes a string and prints a QR code rendered as ASCII art to the terminal.\n\n## Features\n\n- No external binaries required – pure Rust.\n- Uses the `qrcode` crate for standards‑compliant QR generation.\n- Adds a quiet zone and renders each module as a double‑width block (`██`) for readability.\n\n## Installation\n\n```bash\n# Clone the repository (or copy the generated folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/rust-utils/nightly-qr-encoder\n\n# Build the binary\ncargo build --release\n```\n\nThe compiled binary will be located at `target/release/nightly-qr-encoder`.\n\n## Usage\n\n```bash\n# Print a QR code for the string "Hello, world!"\n./target/release/nightly-qr-encoder "Hello, world!"\n```\n\nThe program writes the QR code directly to stdout.\n\n## Testing\n\n```bash\ncargo test\n```\n\nThe test suite checks that the generated ASCII art has the correct dimensions for a given input.\n
