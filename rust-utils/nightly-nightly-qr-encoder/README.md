# nightly-qr-encoder\n\nA tiny Rust CLI that takes a string from stdin and prints an ASCII QR code to stdout. Useful for quickly sharing URLs or secrets in a terminal.\n\n## Installation\n\n```sh\ncargo install --path .\n```\n\n## Usage\n\n```sh\necho "https://example.com" | nightly-qr-encoder\n```\n\n## How it works\n\nThe tool uses the `qrcode` crate to generate a QR matrix and renders it with Unicode dense block characters.
