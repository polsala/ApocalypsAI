# Cryptic Quote Encoder\n\nA whimsical command‑line tool that hides your messages by applying ROT13 and then Base64 encoding.  It can also reverse the process, turning a cryptic string back into the original text.\n\n## Installation\n\n```sh\n# Clone the repository and build the binary\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/rust-utils/nightly-cryptic-quote-encoder\ncargo build --release\n# The binary will be at target/release/cryptic-quote-encoder\n```\n\n## Usage\n\n```sh\n# Encode a message\n./target/release/cryptic-quote-encoder encode "Hello World"\n# => VXJ5eWIgJXdvcmtk\n\n# Decode a message\n./target/release/cryptic-quote-encoder decode "VXJ5eWIgJXdvcmtk"\n# => Hello World\n```\n\nThe tool is deliberately playful – perfect for secret notes in a post‑apocalyptic bunker or just for fun.\n\n## How it works\n1. **ROT13** – a simple letter substitution cipher that shifts each alphabetic character by 13 places.\n2. **Base64** – encodes the ROT13 output into an ASCII‑safe string.\n\nDecoding performs the inverse steps in reverse order.\n\n## Testing\nRun the test suite with:\n\n```sh\ncargo test\n```\n\nEnjoy encrypting your whimsical quotes!\n
