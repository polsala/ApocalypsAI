# QR ANSI CLI\n\nA tiny Rust command‑line tool that takes a string and prints a QR code made of Unicode full‑block (█) and space characters, suitable for copying into terminals, chat, or logs.\n\n## Build\n\n```sh\ncargo build --release\n```\n\n## Usage\n\n```sh\nnightly-qr-ansi-cli "Hello, world!"\n```\n\nThe program writes the QR code to stdout.\n\n## How it works\n\nIt uses the `qrcode` crate to generate a matrix, then maps dark modules to `█` and light modules to a space.\n\n## Tests\n\n```sh\ncargo test\n```
