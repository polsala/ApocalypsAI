# Scavenger Knapsack Optimizer\n\nA whimsical CLI tool that helps post‑apocalypse scavengers pick the most valuable items to carry without exceeding their weight limit. Implements the classic 0/1 knapsack algorithm.\n\n## Usage\n\n```sh\ncargo run -- <max_weight> <item1> <item2> ...\n```\n\nEach item is specified as `name:weight:value`. Example:\n\n```sh\ncargo run -- 15 water:3:10 food:5:8 medkit:4:12 radio:2:5\n```\n\nThe program prints the selected items and the total value.\n\n## Building\n\n```sh\ncargo build --release\n```\n\n## Testing\n\n```sh\ncargo test\n```
