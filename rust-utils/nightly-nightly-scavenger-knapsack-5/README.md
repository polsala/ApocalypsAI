# nightly‑scavenger‑knapsack\n\n**What it does**\n\n`nightly‑scavenger‑knapsack` is a tiny Rust command‑line tool that helps you pick the most valuable items you can carry after the world ends.  It solves the classic 0/1 knapsack problem: given a weight limit and a list of items (each with a name, weight, and value), it returns the optimal subset of items that maximises total value without exceeding the weight limit.\n\n**Why it’s useful**\n\n* Plan your scavenging runs with a clear, optimal packing list.\n* Fun demo of dynamic programming in Rust.\n* Completely offline – no external services required.\n\n**Installation**\n\n```bash\n# Clone the repository (or copy the generated folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/rust-utils/nightly-scavenger-knapsack\n\n# Build the binary\ncargo build --release\n```\n\nThe compiled binary will be at `target/release/nightly-scavenger-knapsack`.\n\n**Usage**\n\n```bash\n# Prepare a JSON file describing your loot\ncat > loot.json <<EOF\n[\n  {\"name\": \"Canned Beans\", \"weight\": 2, \"value\": 3},\n  {\"name\": \"Water Bottle\", \"weight\": 1, \"value\": 2},\n  {\"name\": \"First‑Aid Kit\", \"weight\": 5, \"value\": 9},\n  {\"name\": \"Radiation Suit\", \"weight\": 8, \"value\": 15}\n]\nEOF\n\n# Run the optimizer with a weight limit of 10\n./target/release/nightly-scavenger-knapsack 10 loot.json\n```\n\nThe program will output a JSON array of the selected item names, e.g.:\n\n```json\n[\"First‑Aid Kit\", \"Water Bottle\"]\n```\n\n**Testing**\n\n```bash\ncargo test\n```\n\nAll tests are deterministic and run offline.\n
