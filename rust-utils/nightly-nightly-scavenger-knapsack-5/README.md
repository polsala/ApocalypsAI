# nightly‑scavenger‑knapsack\n\n**What it does**\n\nA tiny command‑line tool that solves the classic 0/1 knapsack problem for your post‑apocalypse scavenging runs.  Give it a weight capacity and a list of items (name, weight, value) and it will tell you which combination gives the highest total value without exceeding the limit.\n\n**Why it is useful**\n\n* Quickly decide what to carry when supplies are scarce.\n* Fun demonstration of a classic algorithm in pure Rust.\n* No external dependencies – just compile and run.\n\n**Installation**\n\n```bash\n# Clone the repository (or copy the generated folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/rust-utils/nightly-scavenger-knapsack\n# Build the binary\ncargo build --release\n# The executable will be at target/release/nightly-scavenger-knapsack\n```\n\n**Usage**\n\n```bash\nnightly-scavenger-knapsack <capacity> <item1> <item2> ...\n```\n\nEach *item* must be expressed as `name:weight:value` (no spaces).  Example:\n\n```bash\nnightly-scavenger-knapsack 15 water:3:10 food:5:8 medkit:4:12 radio:2:4\n```\n\n**Output**\n\nThe program prints the selected items and the total value, e.g.:\n\n````\nSelected items (total value 22):\n- water (weight 3, value 10)\n- medkit (weight 4, value 12)\n````\n\n**Testing**\n\nRun the test suite with:\n\n```bash\ncargo test\n```\n\nAll tests are deterministic and run offline.\n
