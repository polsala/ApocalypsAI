# Nightly Scavenger Knapsack\n\n**What it does**\n\nA tiny Rust CLI that reads a JSON list of scavenged items (each with a name, weight, and value) and a backpack capacity, then computes the optimal subset of items to carry using the classic 0/1 knapsack algorithm. Perfect for role‑playing games, survival simulations, or just a fun algorithm demo.\n\n## Usage\n\n```bash\n# Build the binary (requires Rust toolchain)\ncargo build --release\n\n# Run the program\n./target/release/nightly-scavenger-knapsack <items.json> <capacity>\n```\n\n* `<items.json>` – Path to a JSON file containing an array of items.\n* `<capacity>` – Maximum total weight your backpack can hold (integer).\n\n### Example `items.json`\n\n```json\n[\n  {"name": "Water Bottle", "weight": 3, "value": 10},\n  {"name": "Canned Food", "weight": 4, "value": 12},\n  {"name": "Medkit", "weight": 2, "value": 7},\n  {"name": "Flashlight", "weight": 1, "value": 4}\n]\n```\n\nRunning the tool with a capacity of `5` yields:\n\n```bash\n./target/release/nightly-scavenger-knapsack items.json 5\n```\n\n```json\n{\n  "selected": [\n    {\n      "name": "Water Bottle",\n      "weight": 3,\n      "value": 10\n    },\n    {\n      "name": "Medkit",\n      "weight": 2,\n      "value": 7\n    }\n  ]\n}\n```\n\n## Testing\n\n```bash\ncargo test\n```\n\nThe test suite includes a deterministic unit test that verifies the algorithm picks the optimal combination for a known dataset.\n
