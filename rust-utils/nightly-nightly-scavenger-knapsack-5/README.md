# Scavenger Knapsack\n\nA whimsical CLI for post‑apocalypse scavengers to maximize loot value within a weight limit.\n\n## Usage\n\n```sh\ncargo run -- <capacity> <item1_weight>:<item1_value> <item2_weight>:<item2_value> ...\n```\n\nExample:\n\n```sh\ncargo run -- 50 10:60 20:100 30:120\n```\n\nThe program prints the maximum total value that can be carried.\n\n## Build\n\n```sh\ncargo build --release\n```\n\n## Test\n\n```sh\ncargo test\n```
