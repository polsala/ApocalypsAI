# Nightly Scavenger Knapsack\n\n**Utility:** `nightly-scavenger-knapsack`\n\nA tiny Rust CLI that solves the classic 0/1 knapsack problem for your post‑apocalypse scavenging runs.  Give it a weight limit and a list of items (name, weight, value) and it will tell you which combination maximises total value while staying within the limit.\n\n## Installation\n\n```bash\n# Clone the repository (or copy the generated folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/rust-utils/nightly-scavenger-knapsack\n\n# Build the binary\ncargo build --release\n```\n\nThe compiled binary will be at `target/release/nightly-scavenger-knapsack`.\n\n## Usage\n\n```bash\n./target/release/nightly-scavenger-knapsack <capacity> <item1> [<item2> ...]\n```\n\n* `<capacity>` – maximum total weight you can carry (integer).\n* Each `<item>` must be in the form `name:weight:value`.\n\n### Example\n\n```bash\n./target/release/nightly-scavenger-knapsack 10 water:3:10 food:4:12 medkit:2:7 radio:5:8\n```\n\n**Output**\n\n````\nSelected items:\n- water (weight: 3, value: 10)\n- medkit (weight: 2, value: 7)\n- radio (weight: 5, value: 8)\nTotal weight: 10\nTotal value: 25\n````\n\n## How it works\n\nThe program implements a dynamic‑programming solution to the 0/1 knapsack problem.  It builds a DP table of optimal values for every sub‑capacity and then back‑tracks to recover the chosen items.\n\n## Testing\n\nRun the test suite with:\n\n```bash\ncargo test\n```\n\nAll tests are deterministic and run offline.\n\n## License\n\nMIT – see the repository LICENSE file.
