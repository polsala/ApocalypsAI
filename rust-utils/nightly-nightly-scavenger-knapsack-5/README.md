# Nightly Scavenger Knapsack\n\n**Overview**\nA tiny Rust CLI that computes the optimal set of scavenged items to carry given a weight capacity. It solves the classic 0/1 knapsack problem using dynamic programming. Perfect for planning your post‑apocalyptic loot!\n\n**Installation**\n```bash\n# Clone the utility (or copy the folder into your repo)\ngit clone <repo‑url>\ncd nightly-scavenger-knapsack\n# Build the binary\ncargo build --release\n```\n\n**Usage**\nThe program reads a JSON array of items from *STDIN* and takes the maximum weight capacity as the sole command‑line argument. It outputs a JSON array of the selected items.\n\n```bash\n# Example input (items.json)\ncat > items.json <<EOF\n[\n  {"name": "Canned Food", "weight": 2, "value": 3},\n  {"name": "Water Bottle", "weight": 3, "value": 4},\n  {"name": "First Aid Kit", "weight": 5, "value": 8}\n]\nEOF\n\n# Run the tool with a capacity of 7\ncat items.json | cargo run --quiet -- 7\n```\n\n**Expected output**\n```json\n[\n  {"name":"Canned Food","weight":2,"value":3},\n  {"name":"First Aid Kit","weight":5,"value":8}\n]\n```\n\n**Testing**\nRun the bundled integration test with:\n```bash\ncargo test\n```\n\n**License**\nMIT
