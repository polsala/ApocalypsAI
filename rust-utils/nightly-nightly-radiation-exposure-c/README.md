# nightly-radiation-exposure-cli\n\nA whimsical yet practical command‑line tool written in Rust that estimates how much ionising radiation (in millisieverts, mSv) you might accumulate based on your activity level and the number of hours spent.\n\n## Why?\nIn a post‑apocalyptic world you might want to keep track of radiation exposure while scavenging, resting, or performing heavy labor. This tiny utility gives you a quick ball‑park figure without any external data sources.\n\n## Build & Run\n```bash\n# Clone the repository (or copy the generated files into a folder)\ngit clone <repo‑url>\ncd nightly-radiation-exposure-cli\n\n# Build the binary\ncargo build --release\n\n# Run the tool\n./target/release/nightly-radiation-exposure-cli <activity> <hours>\n```\n\n## Parameters\n- `activity` – one of `resting`, `moderate`, or `heavy`.\n- `hours` – number of hours (can be fractional, e.g., `1.5`).\n\n## Dose rates (mSv per hour)\n| Activity | Dose rate |\n|----------|-----------|\n| resting  | 0.01      |\n| moderate | 0.05      |\n| heavy    | 0.20      |\n\n## Example\n```bash\n$ ./nightly-radiation-exposure-cli moderate 3\nEstimated radiation dose: 0.15 mSv\n```\n\n## Testing\nRun the test suite with:\n```bash\ncargo test\n```\nAll tests are deterministic and require no network access.\n
