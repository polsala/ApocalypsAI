# nightly-time-capsule\n\n**A whimsical Rust CLI utility** that lets you *seal* a secret message for a future date and later *open* it, verifying integrity with a SHA‑256 checksum.\n\n## Features\n\n- `seal` – create a base64‑encoded capsule containing your message, a target date, and a checksum.\n- `open` – decode a capsule, verify the checksum, and reveal the original message and date.\n- No network access – everything runs locally, making the tool safe for offline use.\n\n## Installation\n\n```bash\n# Clone the repository (or copy the utility folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/rust-utils/nightly-time-capsule\n\n# Build the binary\ncargo build --release\n\n# The binary will be at target/release/time_capsule\n```\n\n## Usage\n\n```bash\n# Seal a message for a future date\n./time_capsule seal --message "Remember the sunrise" --date 2099-12-31\n# => Outputs a capsule string, e.g.\n# eyJtZXNzYWdlIjogIlJlbWVtYmVyIHRoZSBzdW5yaXNlIiwgImRhdGUiOiAiMjA5OS0xMi0zMSIsICJjaGVja3N1bSI6ICJkZ...\n\n# Open a capsule\n./time_capsule open --capsule eyJtZXNzYWdlIjogIlJlbWVtYmVyIHRoZSBzdW5yaXNlIiwgImRhdGUiOiAiMjA5OS0xMi0zMSIsICJjaGVja3N1bSI6ICJkZ...\n# => Prints the original message and date if the checksum matches.\n```\n\n## Testing\n\n```bash\ncargo test\n```\n\nThe test suite includes deterministic checks that the seal/open round‑trip works and that tampered capsules are rejected.\n
