# nightly-echo-echo

A whimsical Rust CLI that echoes your input, prints the reversed string, and appends a deterministic whimsical phrase based on the input.

## Usage

```bash
cargo run -- "Hello, world!"
```

Output:

```
Original: Hello, world!
Reversed: !dlrow ,olleH
Whimsy: Your future is bright!
```

## Features

- Echoes the original string.
- Reverses the string.
- Adds a deterministic whimsical phrase chosen from a small list.

## Installation

```bash
cargo install nightly-echo-echo
```
