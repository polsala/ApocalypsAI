# nightly-cryptic-qr-generator\n\n**What it does**\n\n`nightly-cryptic-qr-generator` turns any short text into a tiny ASCII‑art representation that looks like a QR code.  It isn’t a real QR encoder – it’s a fun, deterministic visual hash that can be pasted into chat, logs, or terminal output.\n\n**Why it exists**\n\n* Quick visual fingerprint for a string without needing external services.\n* Works offline, pure Rust, no external crates.\n* Perfect for post‑apocalyptic notes where you want a “secret” visual tag.\n\n**Installation**\n\n```bash\n# Clone the repository (or copy the generated folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd rust-utils/nightly-cryptic-qr-generator\n\n# Build the binary\ncargo build --release\n```\n\n**Usage**\n\n```bash\n# Run the tool with a single argument\ncargo run --release -- "Hello World"\n\n# Or use the compiled binary directly\n./target/release/nightly-cryptic-qr-generator "Hello World"\n```\n\nThe output will be an 8‑character‑wide block per input byte, using `█` for a set bit and a space for an unset bit.\n\n**Example**\n\n```bash\n$ cargo run -- "A"\n █      █\n```\n\n**Testing**\n\n```bash\ncargo test\n```\n\nAll tests run offline and are deterministic.\n
