# nightly-rad-decay-viz\n\n**Nightly Rad Decay Viz** is a tiny Rust command‑line utility that visualises the exponential decay of a radioactive substance.\n\nIt takes an initial amount and a number of half‑life steps, then prints an ASCII bar chart showing how the quantity shrinks over time.\n\n## Installation\n\n```bash\n# Clone the repository (or copy the generated folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/rust-utils/nightly-rad-decay-viz\n# Build the binary\ncargo build --release\n# The executable will be at target/release/nightly-rad-decay-viz\n```\n\n## Usage\n\n```bash\n# Show help\n./nightly-rad-decay-viz --help\n\n# Example: start with 100 units, visualise 5 half‑life steps\n./nightly-rad-decay-viz 100 5\n```\n\nThe output looks like:\n\n````\nStep 0: ██████████████████████████████████████████████████ 100.00\nStep 1: ████████████████████████████ 50.00\nStep 2: ███████████ 25.00\nStep 3: █████ 12.50\nStep 4: ██ 6.25\nStep 5: █ 3.12\n````\n\n## Arguments\n\n- `INITIAL_AMOUNT` (required): Starting quantity (floating point).\n- `STEPS` (required): Number of half‑life steps to visualise (integer).\n\n## License\n\nMIT – see LICENSE file in the repository.\n
