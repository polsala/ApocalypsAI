# nightly-emoji-replacer

A whimsical Rust CLI that replaces common words with emojis for a playful touch.

## Usage

```bash
cargo run -- "I am happy and in love"
```

Output:

```
I am 😊 and in ❤️
```

## Features

- Simple word-to-emoji mapping.
- Works on any string passed as a single argument.
- No external dependencies.

## Installation

```bash
cargo install nightly-emoji-replacer
```
