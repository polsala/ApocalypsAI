# Nightly Cryptic Plant Namer\n\n**nightly-cryptic-plant-namer** is a tiny Rust command‑line utility that spits out whimsical, Latin‑flavored plant names. Perfect for world‑builders, game masters, or anyone who needs a touch of botanical mystery.\n\n## Features\n\n- Generates one or many names in a single run\n- Deterministic name generation (useful for testing)\n- No external dependencies – just pure Rust\n\n## Installation\n\n```bash\n# Clone the repository (or copy the generated folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/rust-utils/nightly-cryptic-plant-namer\n\n# Build the binary\ncargo build --release\n```\n\nThe compiled binary will be located at `target/release/cryptic-plant-namer`.\n\n## Usage\n\n```bash\n# Generate a single name (default)\n./target/release/cryptic-plant-namer\n\n# Generate 5 names\n./target/release/cryptic-plant-namer --count 5\n```\n\n### Options\n\n- `-c, --count <N>` – Number of names to generate (default: 1)\n- `-h, --help` – Show help message\n\n## Example Output\n\n```\nGleaming folia\nMournful barkus\nSilent petalus\nRadiant stigma\nTwisted cactus\n```\n\n## Testing\n\nThe project includes a deterministic unit test suite. Run it with:\n\n```bash\ncargo test\n```\n\n## License\n\nMIT – see the LICENSE file in the repository root.\n
