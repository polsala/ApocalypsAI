# Nightly Scavenger Loadout Planner\n\n**Overview**\n\nA whimsical yet practical command‑line utility for post‑apocalypse scavengers.  Given a list of potential loot items (name, weight, value) and a maximum carry weight, the tool computes the optimal subset of items that maximises total value – the classic 0/1 knapsack problem.\n\n**Features**\n\n- Reads items from a JSON file.\n- Uses a dynamic‑programming algorithm to guarantee the optimal solution.\n- Prints the selected item names in order of selection.\n- Zero‑dependency runtime (only `serde`/`serde_json` for JSON handling).\n\n**Build & Run**\n\n```bash\n# Clone the repository (or copy the generated folder)\ngit clone <repo‑url>\ncd nightly-scavenger-loadout-planner\n\n# Build the binary\ncargo build --release\n\n# Prepare an items file (example below)\ncat > items.json <<'EOF'\n[\n  {"name": "Canned Beans", "weight": 2, "value": 3},\n  {"name": "Water Bottle", "weight": 3, "value": 4},\n  {"name": "First Aid Kit", "weight": 5, "value": 10},\n  {"name": "Flashlight", "weight": 1, "value": 2}\n]\nEOF\n\n# Run the planner: max weight = 7\ncargo run --release -- 7 items.json\n```\n\n**Expected Output**\n\n```
Selected items:\n- First Aid Kit\n- Flashlight\n```\n\n**Testing**\n\n```bash\ncargo test\n```\n\nThe test suite includes a deterministic scenario that verifies the optimal selection.
