# nightly-cryptic-qr-encoder\n\n**Nightly Cryptic QR Encoder** is a tiny, blazing‑fast Rust command‑line tool that converts arbitrary text into an ASCII QR code.  For a little extra flair you can wrap the QR in a glowing radiation border – perfect for secret messages in a post‑apocalyptic bunker.\n\n## Features\n\n- Zero‑dependency runtime (only standard Rust crates).\n- Generates QR codes as Unicode dense blocks for compact terminal display.\n- Optional `--radiation` flag adds a decorative ☢ border.\n- Works offline – no network calls.\n\n## Installation\n\n```bash\n# Clone the repository (or copy the generated folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/rust-utils/nightly-cryptic-qr-encoder\n\n# Build the binary\ncargo build --release\n```\n\nThe compiled binary will be at `target/release/nightly-cryptic-qr-encoder`.\n\n## Usage\n\n```bash\n# Basic QR code\n./target/release/nightly-cryptic-qr-encoder "HELLO WORLD"\n\n# QR code with radiation border\n./target/release/nightly-cryptic-qr-encoder "HELLO WORLD" --radiation\n```\n\n## Example
