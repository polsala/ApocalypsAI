# Nightly Cryptic Map Generator\n\n## Overview\n\n`nightly-cryptic-map-generator` is a tiny Rust CLI that creates a random‑looking ASCII map from a user‑provided seed.  The same seed always yields the same map, making it perfect for tabletop RPGs, storytelling, or just a bit of post‑apocalyptic fun.\n\n## Installation\n\nYou need a working Rust toolchain (rustc and cargo).  Clone the repository and build the binary:\n\n```bash\ngit clone <repo‑url>\ncd nightly-cryptic-map-generator\ncargo build --release\n```\n\nThe compiled binary will be at `target/release/cryptic_map_generator`.\n\n## Usage\n\n```bash\n./target/release/cryptic_map_generator <seed>\n```\n\nReplace `<seed>` with any string – a word, a phrase, or even a date.  The program prints a 40×20 map where `#` marks the traversed path and `.` marks untouched terrain.\n\n### Example\n\n```bash\n$ ./target/release/cryptic_map_generator sunrise\n........................................\n........................................\n........................................\n........................................\n..............####......................\n...........###....#.....................\n.........##........#....................\n........#..........#....................\n........#..........#....................\n........#..........#....................\n........#..........#....................\n........#..........#....................\n........#..........#....................\n........#..........#....................\n........#..........#....................\n........#..........#....................\n........#..........#....................\n........#..........#....................\n........#..........#....................\n........................................\n```\n\n## License\n\nMIT – see LICENSE file in the repository.\n
