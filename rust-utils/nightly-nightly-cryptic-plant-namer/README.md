# Nightly Cryptic Plant Namer\n\nA tiny Rust CLI that spits out whimsical plant names for world‑building, tabletop RPGs, or creative writing. The name generation is deterministic based on an optional numeric seed, making it perfect for reproducible storytelling.\n\n## Usage\n\n```bash\n# Build the binary\ncargo build --release\n\n# Run with a seed (optional)\n./target/release/cryptic-plant-namer 42\n```\n\nIf no seed is provided, the tool defaults to `0`.\n\n## Example Output\n\n```bash\n$ ./cryptic-plant-namer 0\nGlowing Fernleaf\n\n$ ./cryptic-plant-namer 42\nRadiant Dawnbark\n```\n\n## How It Works\n\nThe generator combines an adjective and a noun from two fixed lists. The seed determines the indices, ensuring the same seed always yields the same name.\n\n## Testing\n\nRun the test suite with:\n\n```bash\ncargo test\n```\n\nThe tests verify that specific seeds produce expected names.\n
