# nightly-emoji-weather

A tiny Rust CLI that maps weather codes to emojis for quick terminal use.

## Usage

```bash
cargo run -- clear
# ☀️

cargo run -- rain
# 🌧️
```

## Supported Codes

- clear
- partly_cloudy
- cloudy
- rain
- thunderstorm
- snow
- fog

## Installation

```bash
cargo install nightly-emoji-weather
```
