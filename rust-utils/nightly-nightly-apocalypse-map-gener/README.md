# Apocalyptic Map Generator\n\nGenerates a random ASCII map for post‑apocalyptic exploration. Useful for tabletop games, story prompts, or just fun.\n\n## Usage\n\n```sh\ncargo run --release -- [WIDTH] [HEIGHT] [SEED]\n```\n\n- `WIDTH` (optional, default 40) – map width in characters.\n- `HEIGHT` (optional, default 20) – map height in lines.\n- `SEED` (optional) – integer seed for reproducible maps.\n\nExample:\n\n```sh\ncargo run -- 30 15 12345\n```\n\nOutputs something like:\n\n````\n..^^..##~~...\n...\n````\n\n## Testing\n\n```sh\ncargo test\n```\n\n## License\n\nMIT
