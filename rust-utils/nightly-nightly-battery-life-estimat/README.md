# Nightly Battery Life Estimator\n\nA tiny Rust CLI that estimates how long a battery will last given its capacity (mAh), voltage (V), and device power consumption (W). Useful for post‑apocalypse scavengers planning power usage.\n\n## Usage\n\n```bash\ncargo run -- <capacity_mAh> <voltage> <consumption_watts>\n```\n\nAll three arguments must be positive numbers.\n\n## Example\n\n```bash\ncargo run -- 5000 3.7 5\n```\n\nOutput:\n\n```
Estimated runtime: 3.70 hours\n```\n\n## Building\n\n```bash\ncargo build --release\n```\n\nThe binary will be located at `target/release/battery-life-estimator`.\n
