# nightly-qr-code-cli\n\n## Overview\n\n`nightly-qr-code-cli` is a tiny, blazing‑fast Rust command‑line tool that reads a string (either from the command line or from STDIN) and prints a QR code directly to your terminal using Unicode block characters. No external image viewers required – just copy‑paste the output wherever you need it!\n\n## Installation\n\n```bash\n# Clone the repository (or copy the generated folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/rust-utils/nightly-qr-code-cli\n\n# Build the binary\ncargo build --release\n\n# The binary will be at target/release/nightly-qr-code-cli\n```\n\n## Usage\n\n```bash\n# Pass the text as an argument\n./target/release/nightly-qr-code-cli "Hello, world!"\n\n# Or pipe data into it\necho "Secret Message" | ./target/release/nightly-qr-code-cli\n```\n\nThe tool prints a QR code made of `██` (dark) and two spaces (light). Each QR module is rendered as two characters wide to keep the aspect ratio roughly square.\n\n## Example\n\n```bash\n$ ./target/release/nightly-qr-code-cli "ApocalypsAI"\n████████████████████████████████████████\n██                                      ██\n██  ██  ██  ████  ██  ████  ████  ██  ██\n██  ████  ████  ████  ████  ████  ████  ██\n██  ██  ██  ████  ██  ████  ████  ██  ██\n██                                      ██\n████████████████████████████████████████\n```\n\n## Testing\n\nThe utility includes a suite of deterministic tests that verify the QR code dimensions for a known input.
