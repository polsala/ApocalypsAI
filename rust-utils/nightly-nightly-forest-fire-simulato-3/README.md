# nightly-forest-fire-simulator\n\n**What it does**\n\n`nightly-forest-fire-simulator` is a tiny Rust command‑line tool that visualises a classic forest‑fire cellular automaton.  The world is a rectangular grid where each cell can be one of three states:\n\n- `.` – empty ground\n- `T` – a tree\n- `F` – a burning tree (fire)\n\nThe rules are applied simultaneously to every cell each tick:\n\n1. A burning tree (`F`) turns into empty ground (`.`).\n2. A tree (`T`) catches fire (`F`) if **any** of its eight neighbours is burning.\n3. Empty ground stays empty.\n\nThe simulation runs for a user‑specified number of steps and prints the grid after each step, giving a quick, entertaining visual of fire spreading.\n\n## Building\n\n```bash\n# Clone the repository (or copy the generated folder)\ngit clone <repo‑url>\ncd utils/rust-utils/nightly-forest-fire-simulator\n\n# Build the binary\ncargo build --release\n```\n\nThe binary will be located at `target/release/forest_fire_simulator`.\n\n## Usage\n\n```bash\n# Basic run with default size (20×10) and 5 steps\n./target/release/forest_fire_simulator\n\n# Custom width, height and steps\n./target/release/forest_fire_simulator 30 15 10\n```\n\nIf no arguments are supplied the program defaults to a 20‑column by 10‑row grid and runs for 5 steps. The initial world is a forest of trees with a single fire in the centre.\n\n## Testing\n\nThe crate includes deterministic unit tests that verify the automaton logic. Run them with:\n\n```bash\ncargo test\n```\n\nAll tests should pass on any platform without external dependencies.\n\n## License\n\nMIT – see the LICENSE file in the repository root.\n
