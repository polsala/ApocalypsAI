# Nightly Quantum Entanglement Checker

A whimsical utility that generates and verifies quantum entanglement pairs for fun and pseudo-scientific validation. Perfect for adding a touch of quantum mystique to your daily workflow!

## Features

- Generates quantum entanglement pairs with unique identifiers
- Verifies entanglement compatibility using pseudo-quantum algorithms
- Provides whimsical quantum status messages
- Completely deterministic for testing purposes

## Installation

```bash
# Clone the repository
git clone <repo-url>
cd <repo-url>/rust-utils/nightly-quantum-entanglement-checker

# Build the project
cargo build --release

# Run the binary
./target/release/nightly-quantum-entanglement-checker
```

## Usage

```bash
# Generate a new entanglement pair
./target/release/nightly-quantum-entanglement-checker generate

# Verify two particles are entangled
./target/release/nightly-quantum-entanglement-checker verify <particle1> <particle2>

# Check quantum coherence status
./target/release/nightly-quantum-entanglement-checker status
```
