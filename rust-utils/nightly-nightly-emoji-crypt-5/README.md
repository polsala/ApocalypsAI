# nightly-emoji-crypt\n\nEncode and decode text to a whimsical emoji sequence for secret messages.\n\n## Installation\n\n```sh\ncargo install --path .\n```\n\n## Usage\n\n```sh\n# Encode a message\necho "Hello, world!" | emoji-crypt encode\n\n# Decode a message\necho "🔟🅰️🅱️🆒..." | emoji-crypt decode\n```\n\n## How it works\n\nEach byte of the input is split into two 4‑bit nibbles. Each nibble is mapped to one of 16 emojis representing the hexadecimal digits 0‑F. The resulting emoji pairs form the encoded string. Decoding reverses the process.\n\n## Example\n\n```sh\n$ echo "A" | emoji-crypt encode\n4️⃣1️⃣\n\n$ echo "4️⃣1️⃣" | emoji-crypt decode\nA\n```
