# Nightly Emoji Crypt\n\n**Nightly Emoji Crypt** is a tiny Rust command‑line utility that lets you *encode* plain text into a sequence of emojis and *decode* that emoji sequence back to the original text. It’s perfect for adding a playful layer of secrecy to your messages without any external dependencies.\n\n## Features\n\n- Simple substitution cipher mapping each latin letter (a‑z) to a unique emoji.\n- Supports both encoding and decoding via sub‑commands.\n- Preserves spaces and non‑alphabetic characters unchanged.\n- Zero‑dependency binary (only the Rust standard library).\n\n## Installation\n\n```bash\n# Clone the repository (or copy the generated files into a new folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/nightly-emoji-crypt\n\n# Build the binary\ncargo build --release\n\n# The executable will be at target/release/emoji-crypt\n```\n\n## Usage\n\n```bash\n# Encode a message\n./target/release/emoji-crypt encode "hello world"\n# => 😃😄😊😉😍 🥳😍😄😅😆\n\n# Decode the emoji string back\n./target/release/emoji-crypt decode "😃😄😊😉😍 🥳😍😄😅😆"\n# => hello world\n```\n\n## How It Works\n\nThe utility contains a static mapping of the 26 lowercase letters to distinct emojis. During *encoding* each alphabetic character is replaced by its emoji counterpart; during *decoding* the process is reversed. Characters outside `a‑z` (including uppercase letters, numbers, punctuation, and whitespace) are left untouched.\n\n## Testing\n\nRun the built‑in test suite with:\n\n```bash\ncargo test\n```\n\nAll tests are deterministic and run offline.\n\n## License\n\nMIT – see the LICENSE file in the repository root.\n
