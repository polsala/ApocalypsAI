# Scavenger Route Generator

Generates a whimsical post‑apocalypse scavenger route.

## Usage

```sh
cargo run -- [SEED]
```

If `SEED` is omitted, the current timestamp is used.

### Example output

```
1. Abandoned Mall
2. Crumbling Library
3. Rusty Bridge
```

## Testing

Run `cargo test` to verify deterministic behavior.
