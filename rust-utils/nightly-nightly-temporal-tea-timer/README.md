# Temporal Tea Timer

A CLI break timer that enforces productive work sessions with tea-themed notifications. Use `tea_timer [work_minutes] [break_minutes]` to start your workflow.

Example:
```bash
$ tea_timer 25 5
Brewing focus... Work for 25 minutes (until 15:40)
Time for a tea break! 5 minutes of relaxation (until 15:45)
```

Notifications include ASCII tea art and motivational quotes about tea and productivity.
