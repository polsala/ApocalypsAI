# Nightly Barter Calculator\n\n**What it does**\n\nIn a world where resources are scarce, trading becomes an art. `nightly-barter-calculator` is a tiny Rust CLI that takes a list of items you want to trade and tells you the *fair* total value based on each item's base worth and a scarcity multiplier.\n\n**Why it’s useful**\n\n- Quickly estimate the worth of a loot haul.\n- Helps you avoid being short‑changed in a barter.\n- Fun, self‑contained, and runs on any platform with a Rust toolchain.\n\n**Installation**\n\n```bash\n# Clone the repository (or copy the generated folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/nightly-barter-calculator\n# Build the binary\ncargo build --release\n# The binary will be at target/release/nightly-barter-calculator\n```\n\n**Usage**\n\n```bash\n# Basic syntax: <item>:<quantity>\n./target/release/nightly-barter-calculator water:3 canned-food:5 ammo:10\n\n# Example output\nTotal barter value: 237.5 credits\n```\n\n**Supported items** (hard‑coded for demo purposes)\n\n| Item | Base Value | Scarcity Multiplier | Description |\n|------|------------|---------------------|-------------|\n| water | 5.0 | 1.2 | Fresh water bottles |\n| canned-food | 8.0 | 1.1 | Preserved meals |\n| ammo | 12.0 | 1.5 | Bullets and shells |\n| medicine | 20.0 | 2.0 | Healing supplies |\n| fuel | 15.0 | 1.8 | Fuel canisters |\n\n**Testing**\n\n```bash\ncargo test\n```\n\nAll tests run offline and use deterministic mock data.\n
