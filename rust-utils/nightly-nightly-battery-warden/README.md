# Nightly Battery Warden\n\n**Nightly Battery Warden** is a tiny Rust‑based command‑line utility that estimates how many hours of power you have left given a battery capacity (in mAh) and an average draw (in mA).  For a little extra fun it can also spit out a random post‑apocalypse survival tip.\n\n## Installation\n\n```bash\n# Install via Cargo (requires Rust toolchain)\ncargo install --path .\n```\n\n## Usage\n\n```bash\n# Basic estimation\nbattery-warden <capacity_mAh> <draw_mA>\n\n# With apocalypse mode (adds a random tip)\nbattery-warden <capacity_mAh> <draw_mA> --apocalypse\n```\n\n### Example\n\n```bash\n$ battery-warden 5000 250\nEstimated remaining time: 20.00 hours\n\n$ battery-warden 5000 250 --apocalypse\nEstimated remaining time: 20.00 hours\nApocalypse tip: Keep a spare battery pack in your bunker.\n```\n\n## How it works\n\nThe tool simply divides the capacity by the draw to get the number of hours.  When `--apocalypse` is supplied it selects one of five tongue‑in‑cheek survival tips based on the capacity value, ensuring deterministic output for testing.\n\n## Testing\n\nRun the test suite with:\n\n```bash\ncargo test\n```\n
