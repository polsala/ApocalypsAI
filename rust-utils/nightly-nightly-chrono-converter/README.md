# Nightly Chrono Converter\n\nA tiny Rust CLI that converts between human‑readable duration strings (e.g., `1d2h3m4s`) and total seconds.\n\n## Installation\n\n```sh\ncargo install --path .\n```\n\n## Usage\n\n```sh\n# Convert to seconds\nchrono-converter --to-seconds "1d2h3m4s"\n# => 93784\n\n# Convert from seconds\nchrono-converter --from-seconds 93784\n# => 1d2h3m4s\n```\n\n## Supported units\n\n- `d` – days (24 h)\n- `h` – hours\n- `m` – minutes\n- `s` – seconds\n\nUnits may appear in any order, numbers must be non‑negative integers.\n\n## Testing\n\n```sh\ncargo test\n```
