# Nightly Capsule Time Traveler\n\nA tiny Rust CLI that lets you *seal* a secret message into a pseudo‑time‑capsule and later *open* it again.\n\nThe tool uses a simple XOR cipher with a passphrase and encodes the result as hexadecimal, making it easy to copy‑paste into any text field (e.g., a GitHub issue, a note, or a stone tablet).\n\n## Features\n\n- **Seal** a message with a passphrase: `capsule seal <passphrase> <message>`\n- **Open** a sealed string with the same passphrase: `capsule open <passphrase> <sealed>`\n- No external dependencies – pure Rust standard library.\n\n## Installation\n\n```bash\n# Clone the repository (or copy the generated folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/nightly-capsule-time-traveler\n\n# Build the binary\ncargo build --release\n\n# The binary will be at target/release/capsule\n```\n\n## Usage\n\n```bash\n# Seal a message\n./target/release/capsule seal mysecret "Future generations will read this"\n# => 3a0c0f... (hex string)\n\n# Open the sealed message\n./target/release/capsule open mysecret 3a0c0f...\n# => Future generations will read this\n```\n\n## How it works\n\n1. The message bytes are XOR‑ed with the passphrase bytes (repeating the passphrase as needed).\n2. The resulting bytes are hex‑encoded for safe textual transport.\n3. Opening reverses the process: hex‑decode, XOR with the same passphrase, and interpret as UTF‑8.\n\n## Testing\n\n```bash\ncargo test\n```\n\nThe test suite includes a round‑trip test ensuring that sealing and then opening a message returns the original text.\n
