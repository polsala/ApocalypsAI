# Apocalypse Countdown\n\nA whimsical command‑line tool that tells you how many days are left until a configurable apocalypse date and prints a fun quote.\n\n## Installation\n\n```sh\ncargo install --path .\n```\n\n## Usage\n\n```sh\napocalypse-countdown            # uses default date 2099‑12‑31\napocalypse-countdown --date 2025-06-01\n```\n\nYou can also set the environment variable `APOCALYPSE_TODAY` to mock the current date (useful for testing).\n\n## Example\n\n````\n$ APOCALYPSE_TODAY=2023-01-01 apocalypse-countdown --date 2023-01-10\n9 days until the apocalypse!\nThe end is nigh!\n````\n\n## License\n\nMIT
