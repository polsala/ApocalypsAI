# Nightly Echo Echo

A whimsical CLI that echoes your input, then its reverse, then a doubled version, all with a playful echo effect.

## Usage

```bash
cargo run -- <text>
```

or

```bash
./target/debug/nightly-echo-echo "Hello world"
```

## Output

```
ECHO: Hello world
ECHO: dlrow olleH
ECHO: HHeelllloo  wwoorrlldd
```
