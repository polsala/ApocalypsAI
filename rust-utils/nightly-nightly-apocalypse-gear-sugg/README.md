# Apocalypse Gear Suggester\n\nA whimsical Rust CLI that picks a random apocalypse scenario and suggests three pieces of survival gear.\n\n## Build\n\n```bash\n# Ensure you have Rust toolchain installed (rustc and cargo)\ncargo build --release\n```\n\n## Run\n\n```bash\n# Run the binary (it uses the current timestamp as a seed)\n./target/release/apocalypse_gear_suggester\n```\n\nEach execution prints something like:\n\n```
Apocalypse scenario: Zombie outbreak\nRecommended gear:\n- Multi-tool\n- Water purification tablets\n- Gas mask\n```\n\n## Testing\n\n```bash\ncargo test\n```\n\nThe tests verify that the output always contains a valid scenario and three valid gear items.
