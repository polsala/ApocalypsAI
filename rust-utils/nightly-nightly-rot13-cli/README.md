# nightly-rot13-cli\n\nA tiny Rust command‑line utility that applies the classic ROT13 cipher to text. ROT13 is its own inverse, so the same command both encodes and decodes.\n\n## Installation\n\n```sh\ncargo build --release\n```\n\nThe binary will be at `target/release/nightly-rot13-cli`.\n\n## Usage\n\n```sh\n# Encode a string passed as arguments\nnightly-rot13-cli "Hello, World!"\n\n# Read from stdin\necho "Hello" | nightly-rot13-cli\n```\n\n## How it works\n\nThe program walks each byte, rotates alphabetic characters by 13 positions while leaving other characters untouched.\n\n## License\n\nMIT
