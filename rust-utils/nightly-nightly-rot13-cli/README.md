# nightly-rot13-cli\n\nA tiny, blazing‑fast command‑line utility written in Rust that applies the classic ROT13 substitution cipher to any input text.\n\n## Features\n\n- Accepts input as command‑line arguments or via standard input (pipe).\n- No external dependencies – pure Rust standard library.\n- deterministic, pure function `rot13` for easy testing.\n\n## Installation\n\n```bash\n# Clone the repository (or copy the generated folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/rust-utils/nightly-rot13-cli\n\n# Build the binary\ncargo build --release\n```\n\nThe compiled binary will be located at `target/release/nightly-rot13-cli`.\n\n## Usage\n\n### Direct argument\n\n```bash\n./nightly-rot13-cli "Hello, World!"\n# => Uryyb, Jbeyq!\n```\n\n### Piped input\n\n```bash\necho "Secret Message" | ./nightly-rot13-cli\n# => Frperg Zrffntr\n```\n\n### Multiple words as arguments\n\n```bash\n./nightly-rot13-cli The quick brown fox\n# => Gur dhvpx oebja sbk\n```\n\n## Testing\n\nRun the test suite with:\n\n```bash\ncargo test\n```\n\nAll tests are deterministic and run offline.\n
