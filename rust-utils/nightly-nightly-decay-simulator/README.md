Decay Simulator Utility\n\nThis command-line tool calculates the remaining amount of a radioactive substance after a given elapsed time, based on its half-life.\n\nUsage:\n  decay-simulator simulate --half-life <hours> --initial <amount> --time <hours>\n\nExample:\n  decay-simulator simulate --half-life 10 --initial 100 --time 10\n  Output: Remaining amount: 50.00\n\nThe tool uses the exponential decay formula: remaining = initial * e^(-ln(2) * time / half_life).\n\nThe binary is built with Rust and requires no external services.
