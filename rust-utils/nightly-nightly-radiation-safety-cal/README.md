# Radiation Safety Calculator\n\nA tiny Rust CLI tool that estimates radiation exposure based on distance from a source and time spent, and tells you if you\'re safe.\n\n## Usage\n\n```sh\ncargo run -- <distance_meters> <minutes>\n```\n\nExample:\n\n```sh\ncargo run -- 2 30\n```\n\nOutputs total dose in mSv and safety level.\n\n## Safety Levels\n\n- **Safe**: < 0.1 mSv\n- **Moderate**: 0.1 – 1.0 mSv\n- **High**: > 1.0 mSv\n\n## Build & Test\n\n```sh\ncargo build --release\ncargo test\n```
