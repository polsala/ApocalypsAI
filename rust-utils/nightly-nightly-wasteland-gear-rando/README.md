# Nightly Wasteland Gear Randomizer

A whimsical CLI tool that generates random postâapocalyptic gear items. Useful for tabletop RPGs, story prompts, or just fun.

## Installation

```sh
cargo install --path .
```

## Usage

```sh
wgrandom
```

Outputs something like:

````
Item: Rusty Pipe Wrench
Rarity: Uncommon
Description: A battered pipe wrench, still functional enough to tighten bolts on a broken generator.
````

## Options

- `-n, --number <N>`: Generate N items (default 1).
