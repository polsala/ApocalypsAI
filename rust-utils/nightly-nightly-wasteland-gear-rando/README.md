# Nightly Wasteland Gear Randomizer\n\nA whimsical CLI tool that generates random post‑apocalyptic gear items. Useful for tabletop RPGs, story prompts, or just fun.\n\n## Installation\n\n```sh\ncargo install --path .\n```\n\n## Usage\n\n```sh\nwgrandom\n```\n\nOutputs something like:\n\n````\nItem: Rusty Pipe Wrench\nRarity: Uncommon\nDescription: A battered pipe wrench, still functional enough to tighten bolts on a broken generator.\n````\n\n## Options\n\n- `-n, --number <N>`: Generate N items (default 1).\n\n## License\n\nMIT
