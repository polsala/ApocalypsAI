Nightly SSH Key Rotator\n\nUtility to rotate SSH key pair for a user. It backs up existing keys with a timestamp, generates a new key using ssh-keygen, and updates authorized_keys.\n\nUsage:\n  ./rotate_ssh_keys.sh [--ssh-dir PATH] [--key-type TYPE] [--bits BITS] [--comment COMMENT]\n\nOptions:\n  --ssh-dir PATH   Path to .ssh directory (default: $HOME/.ssh)\n  --key-type TYPE  rsa or ed25519 (default: ed25519)\n  --bits BITS      Key size for RSA (default: 4096)\n  --comment COMMENT  Comment for the key (default: current user@hostname)\n\nThe script is safe to run repeatedly; it will backup previous keys with a .bak.<timestamp> suffix.\n
