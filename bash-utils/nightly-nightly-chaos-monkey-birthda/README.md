# nightly-chaos-monkey-birthday-prank

A fun Bash utility that simulates a 'Chaos Monkey' birthday prank by temporarily renaming files in a directory with festive names.

## Usage

```bash
./src/chaos_monkey.sh /path/to/directory
```

> ⚠️ Warning: This is a simulation. No actual renaming occurs. Names are restored instantly.

## Example

```bash
./src/chaos_monkey.sh ~/Desktop
```

## Test

Run the test suite:

```bash
./tests/test_chaos_monkey.sh
```
