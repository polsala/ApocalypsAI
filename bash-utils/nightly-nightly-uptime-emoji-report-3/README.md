# nightly-uptime-emoji-report\n\nA whimsical Bash utility that reads the system uptime and prints a friendly message adorned with an emoji reflecting how long the system has been running.\n\nUsage:\n\n    ./uptime_emoji.sh            # reads /proc/uptime\n    ./uptime_emoji.sh /path/to/file   # for testing or custom uptime source\n\nEmoji Legend:\n\n    🌱  less than 1 day\n    🌿  1 to 7 days\n    🌳  more than 7 days\n\nExample:\n\n    $ ./uptime_emoji.sh\n    Uptime: 3 days 4 hours 12 minutes 🌿\n\nThe script is self‑contained and has no external dependencies beyond standard Unix utilities.
