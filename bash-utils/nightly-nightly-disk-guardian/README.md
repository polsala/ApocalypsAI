# nightly-disk-guardian\n\n**Utility:** Monitors the root filesystem's disk usage and emits a playful apocalypse‑themed warning when usage exceeds a configurable threshold.\n\n## Features\n\n- Checks disk usage of `/` using `df`.\n- Configurable warning threshold (default **80%**).\n- Randomly selects an apocalypse‑style warning message (deterministic in test mode).\n- Returns exit code **0** when safe, **1** when over threshold, **2** for invalid arguments.\n\n## Installation\n\n```bash\n# Clone the repository (or copy the utility folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/nightly-disk-guardian\nchmod +x src/disk_guardian.sh\n```\n\n## Usage\n\n```bash\n# Use default threshold of 80%\n./src/disk_guardian.sh\n\n# Specify a custom threshold (e.g., 70%)\n./src/disk_guardian.sh 70\n```\n\nThe script prints a status line and, if the threshold is exceeded, a whimsical warning message.\n\n## Testing\n\n```bash\ncd tests\n./test_disk_guardian.sh\n```\n\nThe test suite mocks the disk usage values to verify both safe and warning paths.\n
