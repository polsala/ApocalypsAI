# nightly-disk-guardian\n\nA whimsical Bash utility that watches your disk usage and alerts you with ASCII art when space runs low. Perfect for keeping your server happy.\n\n## Usage\n\n```sh\n./src/disk-guardian.sh /path/to/check\n```\n\nIf usage >80%, prints a warning with a skull; otherwise prints a smiling sun.\n\n## Options\n\n- Path to monitor (default: /)\n\n## Exit codes\n\n- 0: usage below threshold\n- 1: usage above threshold\n- 2: error determining usage\n
