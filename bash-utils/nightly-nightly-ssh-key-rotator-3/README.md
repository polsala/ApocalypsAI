nightly-ssh-key-rotator\n\nSpin your SSH keys like a DJ. This Bash utility backs up your existing Ed25519 SSH key pair, generates a new dummy key pair, and appends the new public key to your authorized_keys file.\n\nUsage:\n  ./src/rotate_ssh_keys.sh [ssh_directory]\n\n  ssh_directory (optional): Path to the .ssh directory. Defaults to $HOME/.ssh.\n\nThe script is safe to run on any system; it creates placeholder keys for demonstration purposes. Replace the dummy key generation with a real ssh-keygen command for production use.\n\nHow it works:\n  1. Backs up existing id_ed25519 and id_ed25519.pub with a timestamp.\n  2. Writes new dummy key files.\n  3. Ensures authorized_keys exists and appends the new public key.\n\nTesting:\n  cd tests\n  ./test_rotate_ssh_keys.sh\n\nAll tests should pass, confirming correct backup, key creation, and authorized_keys update.
