# nightly-terminal-qr

Generate a QR code for a given string directly in your terminal.

## Usage

```sh
./src/qr.sh "Hello, world!"
```

The script will output an ANSI-colored QR code using `qrencode`. If `qrencode` is not installed, the script will suggest installing it.

## Requirements

- `qrencode` (available via most package managers)
