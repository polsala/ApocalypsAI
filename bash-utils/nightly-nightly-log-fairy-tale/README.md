# nightly-log-fairy-tale

Turns boring logs into magical stories! Adds emojis 🧙‍♂️, ASCII creatures 🐉, and whimsical metaphors to help spot issues while keeping your sanity intact.

## Usage
```bash
./src/main.sh < /var/log/syslog
# Or pipe logs:
journald | ./src/main.sh
```

## Features
- Error messages become "dragon attacks" 🔥
- Warnings turn into "mischievous goblins" 🧙‍♀️
- Info logs become "elf deliveries" 🛷
- Color-coded for apocalyptic moods 🌑
