nightly-uptime-emoji\n\nDescription:\n  A tiny Bash utility that reads the system's human‑readable uptime (via `uptime -p`) and prints it back with fun emoji symbols for each time unit (days, hours, minutes, weeks, months).\n\nUsage:\n  ./src/uptime-emoji.sh\n\nThe script can be sourced and its `main` function called directly, which is useful for testing.\n\nOutput example:\n  Uptime: 🌞 2 days; ⏰ 3 hours; 🕒 4 minutes; \n\nNo external dependencies are required beyond standard Unix utilities.\n\nTesting:\n  Run the provided test scripts in the `tests/` directory. They replace the `uptime` command with a mock to ensure deterministic results.
