# nightly-emoji-timestamp\n\nPrints the current date and time accompanied by an emoji that reflects the time of day.\n\n## Usage\n\n```sh\n./src/main.sh\n```\n\nYou can override the current time for testing by setting the `MOCK_DATE` environment variable in the format `YYYY-MM-DD HH:MM`.\n\n## Example\n\n```sh\n$ MOCK_DATE="2023-10-31 07:45" ./src/main.sh\n2023-10-31 07:45 ☀️\n```\n\n## How it works\n\nThe script parses the hour from the supplied (or real) timestamp and selects one of three emojis:\n- 🌅  before 06:00 (sunrise)\n- ☀️  between 06:00 and 17:59 (day)\n- 🌙  18:00 and later (night)\n\nThe implementation is pure Bash and has no external dependencies.\n
