nightly-uptime-lyric\n\nA whimsical Bash utility that reports system uptime in a human‑readable format and adds a playful lyric based on how long the system has been running.\n\nUsage:\n  ./src/uptime_lyric.sh          # reads real uptime from /proc/uptime\n  ./src/uptime_lyric.sh 123456   # for testing: provide uptime in seconds\n\nHow it works:\n- Reads uptime in seconds.\n- Converts to days, hours, minutes.\n- Chooses a lyric from a short list based on total minutes modulo the list length.\n- Prints a single line.\n\nTests:\nRun ./tests/test_uptime_lyric.sh
