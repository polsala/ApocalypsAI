# Nightly Chaos Chaos Cha

A whimsical Bash utility that introduces controlled chaos into your development workflow. Perfect for testing resilience and keeping your team on their toes!

## Features

- Randomly injects delays into your scripts
- Spews cryptic log messages
- Adds harmless surprises to keep things interesting
- Configurable chaos levels

## Usage

```bash
# Basic chaos
./src/main.sh

# High chaos mode
./src/main.sh --chaos-level 9

# Quiet chaos (no log spam)
./src/main.sh --quiet
```

## Installation

```bash
cp src/main.sh /usr/local/bin/chaos-chaos-cha
chmod +x /usr/local/bin/chaos-chaos-cha
```
