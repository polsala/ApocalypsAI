## nightly-sys-health-report

This utility generates a whimsical yet informative system health report using a series of bash commands. It checks for disk space, memory usage, running processes, and network connectivity, presenting the information in a fun, apocalypse-ready format.

### Usage

Run the script from your terminal:

```bash
./src/main.sh
```
