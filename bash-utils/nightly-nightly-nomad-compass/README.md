# Nightly Digital Nomad's Compass

Guiding you through the digital wilderness, the Nightly Digital Nomad's Compass provides a quick-glance overview of your current system and local environment. Perfect for those constantly shifting digital landscapes, it helps you stay oriented with vital information at your fingertips.

## Features

*   **Uptime**: How long your system has been running.
*   **IP Address**: Your primary network interface's IP.
*   **Disk Usage**: Current directory's disk usage.
*   **Memory Usage**: System's total and used memory.
*   **Current Path**: Your present working directory.
*   **Git Status**: A summary of your current Git repository's status (if applicable).

## Usage

1.  **Make the script executable:**
    ```bash
    chmod +x src/nomad_compass.sh
    ```
2.  **Run the compass:**
    ```bash
    ./src/nomad_compass.sh
    ```
