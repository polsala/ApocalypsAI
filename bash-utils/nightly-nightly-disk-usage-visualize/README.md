# Nightly Disk Usage Visualizer\n\n**What it does**\n\n`nightly-disk-usage-visualizer` walks a directory tree (default: current directory) and prints a concise, bar‑chart style report of the disk usage of each sub‑directory up to a configurable depth.  It is handy for quickly spotting which folders are eating up space without opening a full‑blown GUI tool.\n\n**Features**\n\n- Pure Bash – no external Python/Rust dependencies.\n- Adjustable depth (default: 2 levels).\n- Human‑readable sizes (kilobytes).\n- Scales bar length to the largest folder (max 40 `#` characters).\n- Testable – the size‑gathering command can be overridden via the `DU_CMD` environment variable, allowing deterministic unit tests.\n\n**Installation**\n\n```bash\n# Clone the repository (or copy the files into your own project)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd ApocalypsAI/utils/nightly-disk-usage-visualizer\n# Make the script executable\nchmod +x src/main.sh\n```\n\n**Usage**\n\n```bash\n# Basic usage – scan current directory, depth 2 (default)\n./src/main.sh\n\n# Scan a specific directory with custom depth\n./src/main.sh /var/log 3\n\n# Override the du command (useful for testing)\nDU_CMD="/path/to/mock_du.sh" ./src/main.sh /tmp 1\n```\n\n**Example Output**\n\n```\nmyapp                         1024K ########################################\nlogs                           512K ########################\ncache                           256K ############\n```\n\n**Testing**\n\nThe test suite lives in the `tests/` directory and can be run with any POSIX‑compatible shell (e.g., `bash tests/test_main.sh`). It uses a mock `du` script to provide deterministic sizes.\n\n```bash\nbash tests/test_main.sh\n```\n\n**License**\n\nMIT – see the top‑level LICENSE file.
