# nightly-env-var-diff\n\n**Utility**: Compare two `.env` files and list variables that were added, removed, or changed.\n\n## Usage\n\n```bash\n./diff_env.sh <old.env> <new.env>\n```\n\n- `<old.env>` – the original environment file\n- `<new.env>` – the updated environment file\n\nThe script prints one line per difference:\n\n- `Added: VAR_NAME` – variable present only in the new file\n- `Removed: VAR_NAME` – variable present only in the old file\n- `Changed: VAR_NAME ("old" -> "new")` – variable exists in both but with a different value\n\n## Example\n\n```bash\ncat > old.env <<EOF\nDB_HOST=localhost\nDB_PORT=5432\nDEBUG=true\nEOF\n\ncat > new.env <<EOF\nDB_HOST=db.example.com\nDB_PORT=5432\nVERBOSE=false\nEOF\n\n./diff_env.sh old.env new.env\n```\n\nOutput:\n\n```
Changed: DB_HOST ("localhost" -> "db.example.com")\nRemoved: DEBUG\nAdded: VERBOSE\n```\n\n## Notes\n\n- Lines starting with `#` or empty lines are ignored.\n- Keys and values are trimmed of surrounding whitespace.\n- Requires Bash 4+ for associative arrays.\n
