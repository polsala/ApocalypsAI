# Nightly Bash Uptime Emoji 2

A whimsical Bash utility that displays system uptime with animated emoji progress bars and ASCII art.

## Features

- Shows system uptime in a fun, animated format
- Displays progress bar with emoji characters
- Includes ASCII art representation of the uptime
- Works on any Unix-like system with Bash

## Installation

1. Clone or download this utility
2. Make the script executable: `chmod +x src/main.sh`
3. Run it: `./src/main.sh`

## Usage

```bash
./src/main.sh
```
