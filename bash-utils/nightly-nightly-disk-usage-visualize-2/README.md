nightly-disk-usage-visualizer\n\nUtility that shows an ASCII bar graph of disk usage for each mounted filesystem.\n\nUsage:\n  ./disk-usage.sh            # reads live df -h output\n  ./disk-usage.sh data.txt   # reads df output from a file (useful for testing)\n\nThe script parses the output of df, extracts the usage percentage, and draws a 20‑character bar where \"#\" represents used space and \"-\" represents free space.\n\nExample output (live run):\n  /                     45% [#########-----------]\n  /run                  10% [##------------------]\n  /data                 90% [##################--]\n\nThe tool requires no external dependencies and works on any Unix‑like system with bash and the standard df command.
