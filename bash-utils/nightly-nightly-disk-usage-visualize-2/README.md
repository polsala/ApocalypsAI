# nightly-disk-usage-visualizer\n\nUtility to display a quick visual bar chart of disk usage for subdirectories.\n\n## Usage\n\n```sh\n./src/main.sh [directory]\n```\n\nIf no directory is provided, the current directory is used.\n\nThe script reads `du -b --max-depth=1` output. For testing, set the environment variable `MOCK_DU_OUTPUT` to a newline-separated list of `<bytes>\t<path>` lines.\n\n## Example\n\n```sh\n$ MOCK_DU_OUTPUT=$'1000\t./dirA\n5000\t./dirB\n2000\t./dirC' ./src/main.sh\n1000B  ########                              ./dirA\n5000B  ######################################## ./dirB\n2000B  ################                        ./dirC\n```
