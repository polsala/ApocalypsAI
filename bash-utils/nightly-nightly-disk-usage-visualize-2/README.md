# Nightly Disk Usage Visualizer\n\n## Overview\n\n`nightly-disk-usage-visualizer` is a tiny Bash utility that scans a directory and prints an ASCII bar‑chart of the biggest sub‑directories (by disk usage).  It is handy for a quick sanity‑check of what is eating space on a server without opening a full‑blown GUI tool.\n\n## Usage\n\n```bash\n./src/main.sh [directory] [count]\n```\n\n- **directory** – Path to scan.  Defaults to the current directory (`.`).\n- **count** – How many top entries to display.  Defaults to `5`.\n\nThe script prints a table like:\n\n````\nname                 sizeK ████████████████████████\na                     400K ████████████████████████\nb                     200K ███████████\nc                     100K ███\n````\n\n## Example\n\n```bash\n$ ./src/main.sh /var/log 3\nlog                  10240K ██████████████████████████████████████████\nsyslog               5120K ███████████████████████\naudit                2560K █████████\n```\n\n## Installation\n\n1. Clone the repository (or copy the `nightly-disk-usage-visualizer` folder).\n2. Ensure the script is executable: `chmod +x src/main.sh`.\n3. Run it as shown above.\n\n## Testing\n\nThe utility includes a deterministic test suite that uses a mock `du` command, so it runs offline and does not depend on actual disk contents. Run the tests with:\n\n```bash\ncd tests && bash test_main.sh\n```\n\nIf everything is correct you will see `All tests passed`.\n
