# Nightly Dotfile Chronicle\n\n**dotchronicle** is a tiny bash utility that lets you create timestamped snapshots of your most treasured dotfiles, list existing snapshots, and roll back to a previous state.  It’s perfect for the post‑apocalyptic coder who wants to keep their `.bashrc` and friends safe from the ravages of time (or a rogue `rm -rf`).\n\n## Features\n\n- **Backup**: Copies a configurable list of dotfiles into `~/.dotfile_backups/<timestamp>` using a human‑readable `YYYYMMDD_HHMMSS` format.\n- **List**: Shows all available backup IDs in chronological order.\n- **Restore**: Restores the selected backup, overwriting the current files.\n\nThe tool is deliberately simple, has zero external dependencies, and works on any POSIX‑compatible shell.\n\n## Installation\n\n```bash\n# Clone the utility into your preferred location\ngit clone https://github.com/polsala/ApocalypsAI.git\n# Or just copy the src/ directory into your PATH\ncp -r utils/nightly-dotfile-chronicle/src /usr/local/bin/dotchronicle\nchmod +x /usr/local/bin/dotchronicle/main.sh\nln -s /usr/local/bin/dotchronicle/main.sh /usr/local/bin/dotchronicle\n```\n\nMake sure the script is executable and available on your `$PATH`.\n\n## Configuration\n\nBy default the utility backs up the following files:\n\n```.bashrc .vimrc .gitconfig```\n\nYou can override this list by setting the environment variable `DOTFILE_LIST` to a space‑separated list of filenames (relative to `$HOME`). For example:\n\n```bash\nexport DOTFILE_LIST=".bashrc .zshrc .tmux.conf"\n```\n\n## Usage\n\n```bash\n# Create a new backup\n$ dotchronicle backup\nBackup created at 20241031_142530\n\n# List all backups\n$ dotchronicle list\n20241031_142530\n20241030_091200\n\n# Restore a specific backup\n$ dotchronicle restore 20241031_142530\nRestored backup 20241031_142530\n```\n\n## Testing\n\nThe utility ships with a self‑contained Bash test suite located in `tests/`. Run it with:\n\n```bash\ncd utils/nightly-dotfile-chronicle\nbash tests/test_main.sh\n```\n\nThe test creates a temporary `$HOME`, backs up dummy dotfiles, mutates them, restores the snapshot, and verifies the original contents are recovered.\n\n## License\n\nMIT – see the root `LICENSE` file.\n
