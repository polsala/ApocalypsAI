# Nightly Uptime Emoji Reporter\n\nA whimsical yet useful Bash utility that reads the system's load average and uptime, then prints a friendly emoji representing the current system stress level.\n\n## Features\n- Detects load average (first value from /proc/loadavg)\n- Determines an emoji: 🌞 for low load (< 0.5), 😐 for moderate load (0.5‑2.0), 😱 for high load (>= 2.0)\n- Shows a human‑readable uptime string\n- Supports environment variable overrides for deterministic testing (MOCK_LOAD, MOCK_UPTIME)\n\n## Usage\n```bash\n./src/uptime_emoji.sh\n```\n\nExample output:\n```
Uptime: 3d 4h 12m, Load: 0.23 🌞\n```\n\n## Testing\nRun the provided test script:\n```bash\nbash tests/test_uptime_emoji.sh\n```\nAll tests should pass without external dependencies.
