# Nightly SSH Key Rotator\n\n## Overview\n\nThis utility generates a fresh SSH key pair for a given user and distributes the public key to a list of remote hosts, optionally removing an old key fingerprint. It helps enforce regular key rotation across a fleet of servers.\n\n## Prerequisites\n\n- Bash 4+\n- `ssh` client installed\n- `ssh-keygen` available\n- Existing SSH access to the target hosts (the script uses your current authentication method to connect)\n\n## Usage\n\n```\n./rotate_ssh_keys.sh -u USER -f hosts.txt [-k OLD_FINGERPRINT]\n```\n\n### Options\n\n- `-u USER` : Remote username for SSH connections.\n- `-f FILE` : Path to a file containing hostnames (one per line).\n- `-k FINGERPRINT` : (Optional) Exact public‑key line (as appears in `authorized_keys`) that should be removed from each host before adding the new key.\n\nThe script creates a temporary RSA‑4096 key pair, copies the public key to each host's `~/.ssh/authorized_keys`, and prints the **private key** to stdout. Store the private key securely (e.g., in a password‑manager or a secret store).\n\n## Example\n\n```\n# Rotate the key for user "deploy" on three hosts\ncat > my_hosts.txt <<EOF\nhost1.example.com\nhost2.example.com\nhost3.example.com\nEOF\n\n./rotate_ssh_keys.sh -u deploy -f my_hosts.txt -k "ssh-rsa AAAAB3NzaC1yc2EAAAADAQABAAABAQC..." > new_deploy_key.pem\n```\n\n## Testing\n\nRun the bundled test suite with:\n\n```\nbash tests/test_rotate_ssh_keys.sh\n```\n\nThe test uses a mock `ssh` binary to verify that the script attempts the correct remote calls without touching real servers.
