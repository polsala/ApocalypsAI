# Nightly SSH Key Rotator\n\nUtility to rotate an SSH public key across multiple host `authorized_keys` files. It generates a new key pair, distributes the public key to each host, and removes the old key identified by its fingerprint.\n\n## Usage\n\n```sh\n./rotate_ssh_key.sh <old-key-fingerprint> <hosts-directory>\n```\n\n- `<old-key-fingerprint>`: Unique string that appears in the old key line (e.g., the key comment or part of the key).\n- `<hosts-directory>`: Directory containing subdirectories for each host; each host directory must have an `authorized_keys` file.\n\nThe script creates a new key pair in a temporary location and prints the path to the private key. It updates each `authorized_keys` file by appending the new public key and removing any line containing the old fingerprint.\n\n## Example\n\n```sh\nmkdir -p hosts/host1 hosts/host2\n\necho "ssh-ed25519 AAAAC3... oldkey user@example.com" > hosts/host1/authorized_keys\necho "ssh-ed25519 AAAAC3... oldkey user@example.com" > hosts/host2/authorized_keys\n\n./rotate_ssh_key.sh oldkey hosts\n```\n\nAfter execution, each `authorized_keys` contains the new key and no lines with `oldkey`.\n\n## Notes\n\n- The script uses a dummy key generation method for speed; replace the key generation block with `ssh-keygen` for production use.\n- Ensure you have write permissions to the `authorized_keys` files.\n
