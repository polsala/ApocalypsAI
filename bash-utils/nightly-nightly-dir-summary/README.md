Nightly Dir Summary Utility\n\nOverview:\nThis bash utility scans a directory and prints a whimsical summary:\n- Total number of files\n- Cumulative size in human‑readable format\n- Most common file extension (or “none” if no extensions)\n- A random mood emoji based on the total size\n\nUsage:\n  ./summary.sh [directory]\n\nIf no directory is supplied, the current working directory is used.\n\nExample:\n  $ ./summary.sh /var/log\n  📂 Scanned 42 files, total size 13.5M, most common type: .log 😎
