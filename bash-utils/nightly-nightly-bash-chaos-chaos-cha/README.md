# Nightly Bash Chaos Chaos Chaos 2

A whimsical chaos generator that randomly disrupts system resources, network, and time to test resilience in a safe, controlled manner.

## Features
- Randomly disrupts CPU, memory, network, and time
- Safe and controlled chaos
- Configurable chaos levels
- Detailed chaos reports

## Usage
```bash
./src/main.sh --level <level>
```
