nightly-quick-disk-waste-report\n\nA whimsical Bash utility that scans a directory and lists the largest files and directories, helping you spot disk waste before the apocalypse.\n\nUsage:\n  ./quick-disk-waste-report.sh [-d DIR] [-n N] [-e PATTERN]\n\nOptions:\n  -d DIR      Directory to scan (default: current directory)\n  -n N        Number of top entries to show (default: 10)\n  -e PATTERN  Exclude files matching PATTERN (glob)\n\nExample:\n  ./quick-disk-waste-report.sh -d /var/log -n 5\n\nThe script uses find, stat, and sort to compute sizes and prints human‑readable sizes.
