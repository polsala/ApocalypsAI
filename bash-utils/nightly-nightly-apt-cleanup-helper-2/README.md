# nightly-apt-cleanup-helper\n\n**What it does**\n\n`nightly-apt-cleanup-helper` is a tiny Bash utility that inspects your Debian/Ubuntu system for packages that are no longer needed (the ones `apt-get autoremove` would purge) and offers to clean them up.  It adds a little post‑apocalyptic flavor to the output so you feel like you’re clearing debris after a fallout.\n\n**Features**\n\n- Detects packages that would be removed by `apt-get autoremove` (dry‑run).\n- Optional `-y` flag to perform the actual removal automatically.\n- Colorful, themed messages ("Scavenging the wasteland…", "Debris cleared!").\n- Fully testable without touching a real system – the script looks for a mock `apt-get` in `$PATH` when run in test mode.\n\n**Installation**\n\n```bash\n# Clone the repo (or copy the script)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd ApocalypsAI/utils/nightly-apt-cleanup-helper\n# Make it executable\nchmod +x src/apt_cleanup.sh\n# (Optional) symlink to a directory in your PATH\nln -s $(pwd)/src/apt_cleanup.sh /usr/local/bin/apt-cleanup\n```\n\n**Usage**\n\n```bash\n# Dry‑run – just see what would be removed\napt-cleanup\n\n# Automatic removal (be careful!)\napt-cleanup -y\n```\n\n**Example output**\n\n```
[⚙️] Scavenging the wasteland for abandoned packages...\n[📦] Packages to be removed: libfoo-old libbar-deprecated\n[❓] Proceed with removal? (y/N) \n```\n\nWith `-y`:\n\n```
[⚙️] Scavenging the wasteland for abandoned packages...\n[📦] Packages to be removed: libfoo-old libbar-deprecated\n[🚀] Initiating purge...\nRemoving libfoo-old... Done.\nRemoving libbar-deprecated... Done.\n[✅] Debris cleared!\n```\n\n**Testing**\n\nThe test suite lives in `tests/` and uses a mock `apt-get` binary to simulate apt behaviour. Run the tests with:\n\n```bash\ncd utils/nightly-apt-cleanup-helper\n./tests/test_apt_cleanup.sh\n```\n\n**License**\n\nMIT – see LICENSE file in the repository root.\n
