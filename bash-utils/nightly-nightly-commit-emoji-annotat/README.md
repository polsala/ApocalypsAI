Nightly Commit Emoji Annotator\nA whimsical bash utility that reads recent git commit messages and prefixes them with emojis based on keywords, giving a quick visual summary of recent work.\n\nUsage:\n  ./src/main.sh [N]\n\nIf N is omitted, the last 5 commits are shown.\n\nThe script works offline; set GIT_LOG_MOCK environment variable to a newline-separated list of commit messages for testing.\n\nExample:\n  $ ./src/main.sh 3\n  🛠️ Fix bug in parser\n  ➕ Add new feature\n  📚 Update docs\n
