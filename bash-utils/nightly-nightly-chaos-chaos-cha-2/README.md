# Nightly Chaos Chaos Cha

A whimsical chaos orchestrator that introduces controlled, reversible chaos into systems for testing resilience.

## Features
- Introduce controlled chaos (network latency, CPU load, memory pressure)
- Reversible chaos with cleanup
- Whimsical chaos modes (e.g., 'chaos-chaos-cha')
- Configurable chaos scenarios

## Usage
```bash
./src/main.sh --mode chaos-chaos-cha --duration 60
```

## Installation
1. Clone the repository
2. Make the script executable: `chmod +x src/main.sh`
3. Run with desired mode and duration
