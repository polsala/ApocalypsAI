# Nightly Chaos Chaos Chaos 3

A whimsical chaos generator that randomly disrupts system resources, network conditions, and services to test resilience in a safe, controlled manner.

## Features
- Randomly disrupts system resources
- Simulates network latency and packet loss
- Randomly stops and starts services
- Generates a chaos report
- Safe for testing environments

## Usage
```bash
./src/main.sh
```

## Requirements
- Linux with systemd
- tc (traffic control)
- stress (optional)
