# Nightly Disk Dragon\n\n## Overview\n\n`nightly-disk-dragon` is a tiny Bash utility that monitors your mounted filesystems and **roars** a warning (with a friendly dragon emoji) whenever a filesystem's usage exceeds a configurable threshold.  It’s perfect for keeping an eye on disk space in a playful way, especially on servers that love a bit of drama.\n\n## Features\n\n- Checks all mounted filesystems using `df -P` (portable output).\n- Configurable usage threshold (default **80%**).\n- Emits a clear, emoji‑filled warning line for each over‑filled mount point.\n- Zero external dependencies – just Bash.\n\n## Installation\n\n```bash\n# Clone the repository (or copy the files)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd ApocalypsAI/utils/nightly-disk-dragon\n# Make the script executable\nchmod +x src/disk_dragon.sh\n```\n\nYou can also symlink it into a directory on your `$PATH` for easy access.\n\n## Usage\n\n```bash\n./src/disk_dragon.sh [options]\n```\n\n### Options\n\n- `-t <percent>` – Set the usage threshold (default `80`).\n- `-h` – Show help and exit.\n\n### Example\n\n```bash\n# Warn when any filesystem reaches 90% usage\n./src/disk_dragon.sh -t 90\n```\n\nIf `/var` is at 92% you will see:\n\n```
🐉 Dragon warns: /var is at 92% capacity (threshold 90%).\n```\n\n## Testing\n\nThe utility includes a Bash test suite located in `tests/`.  Run it with:\n\n```bash\ncd tests\nbash test_disk_dragon.sh\n```\n\nAll tests should pass on any POSIX‑compatible system.\n\n## License\n\nThis utility is released under the MIT License.\n
