# Post‑Apocalyptic Safe‑House S3 Bucket\n\nThis Terraform module creates an AWS S3 bucket configured for versioning and a lifecycle rule that transitions objects to Glacier after 30 days and expires after 365 days. Ideal for storing critical survival data.\n\n## Usage\n\n```hcl\nmodule "safehouse_bucket" {\n  source      = "github.com/yourorg/polsala/terraform-modules/nightly-postapoc-s3-safehouse"\n  bucket_name = "my-safe-house-data"\n}\n```\n\n## Inputs\n\n- `bucket_name` (string, required): Name of the S3 bucket.\n- `aws_region` (string, optional): AWS region (default: `us-east-1`).\n- `tags` (map(string), optional): Tags to apply.\n\n## Outputs\n\n- `bucket_id`: The ID of the created bucket.\n- `bucket_arn`: ARN of the bucket.\n\n## Testing\n\nRun the provided test script to ensure the module validates correctly:\n\n```sh\ncd utils/terraform-modules/nightly-postapoc-s3-safehouse\n./tests/validate.sh\n```
