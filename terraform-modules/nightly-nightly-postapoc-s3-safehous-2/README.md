# nightly‑postapoc‑s3‑safehouse\n\nA whimsical yet practical Terraform module that creates a "safe‑house" S3 bucket. The bucket is:\n\n- **Versioned** – keep historical copies of objects\n- **Encrypted** – server‑side AES‑256 encryption\n- **Self‑cleaning** – deletes non‑current versions older than 30 days\n- **Randomly named** (optional) – uses `random_pet` for a fun, unique name\n\n## Features\n\n- Optional custom bucket name (if omitted a random name is generated)\n- Configurable tags\n- No real AWS credentials required for validation – the provider skips credential checks\n\n## Usage\n\n```hcl\nmodule "safehouse" {\n  source      = "github.com/yourorg/apocalypsai//terraform-modules/nightly-postapoc-s3-safehouse"\n  # bucket_name = "my‑postapoc‑bucket"   # optional\n  tags = {\n    Environment = "post‑apocalypse"\n    Owner       = "survivors"\n  }\n}\n\noutput "bucket_name" {\n  value = module.safehouse.bucket_name\n}\n```\n\n## Variables\n\n| Name | Type | Description | Default |\n|------|------|-------------|---------|\n| bucket_name | string | Custom bucket name (must be globally unique). If omitted a random name is generated. | `null` |\n| tags | map(string) | Tags to apply to the bucket. | `{}` |\n| region | string | AWS region for the bucket. | `"us-east-1"` |\n\n## Outputs\n\n| Name | Description |\n|------|-------------|\n| bucket_id | The ID of the created bucket. |\n| bucket_arn | The ARN of the created bucket. |\n| bucket_name | The final bucket name (custom or generated). |\n\n## Testing\n\nThe module includes a deterministic test script that runs `terraform init` (backend disabled) and `terraform validate`. It uses the AWS provider with credential checks disabled, so it works offline.\n\n```bash\ncd tests\n./test_module.sh\n```\n\n## License\n\nMIT – because even in the wasteland we share our tools.\n
