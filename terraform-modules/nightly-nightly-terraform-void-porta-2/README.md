# Terraform Void Portal Module\n\nA whimsical Terraform module that simulates a "void portal" using the `null_resource`. It allows you to specify a destination (any string) and an activation time (timestamp). The module outputs a fabricated portal URL that can be used in other configurations.\n\n## Usage\n\n```hcl\nmodule "my_portal" {\n  source          = "git::https://github.com/polsala/ApocalypsAI.git//terraform-modules/nightly-terraform-void-portal"\n  destination     = "Mars"\n  activation_time = "2026-07-01T00:00:00Z"\n}\n```\n\n## Inputs\n\n| Name | Description | Type | Default | Required |\n|------|-------------|------|---------|----------|\n| destination | Where the portal leads | string | n/a | yes |\n| activation_time | ISO8601 timestamp when portal activates | string | n/a | yes |\n\n## Outputs\n\n| Name | Description |\n|------|-------------|\n| portal_url | A fabricated URL representing the portal |\n
