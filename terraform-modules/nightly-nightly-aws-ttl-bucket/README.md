Terraform Module: AWS S3 Bucket with TTL\n\nThis module creates an S3 bucket that automatically expires objects after a configurable number of days. Ideal for temporary storage in a post‑apocalyptic scenario.\n\nVariables:\n- bucket_name (string): Name of the bucket.\n- ttl_days (number): Number of days after which objects expire.\n\nUsage:\nCreate a folder, add a main.tf that calls the module, and run terraform init & apply.\n\nExample:\nmodule \"temp_bucket\" {\n  source      = \"./path/to/module\"\n  bucket_name = \"my-temp-bucket\"\n  ttl_days    = 7\n}\n\nThe module requires the AWS provider.
