Nightly Terraform S3 Website Module\n\nThis module creates an AWS S3 bucket configured for static website hosting.\nOptionally it can also create a CloudFront distribution to serve the site via CDN.\n\nFeatures\n--------\n- S3 bucket with public‑read website configuration\n- Bucket policy granting public read access\n- Optional CloudFront distribution (enabled via var.enable_cloudfront)\n- Taggable resources\n\nVariables\n---------\n- bucket_name (string, required): Name of the S3 bucket.\n- index_document (string, default: "index.html"): Index page for the website.\n- error_document (string, default: "error.html"): Error page for the website.\n- enable_cloudfront (bool, default: false): Whether to provision a CloudFront distribution.\n- tags (map(string), default: {}): Tags applied to all resources.\n\nOutputs\n-------\n- bucket_id: ID of the created S3 bucket.\n- bucket_arn: ARN of the created S3 bucket.\n- cloudfront_domain: Domain name of the CloudFront distribution (empty string if disabled).\n\nUsage Example\n-------------\nmodule "static_site" {\n  source            = "./"\n  bucket_name       = "my‑awesome‑site"\n  enable_cloudfront = true\n  tags = {\n    Environment = "dev"\n  }\n}\n\nAfter applying, the website will be reachable at the S3 website endpoint or the CloudFront domain if enabled.
