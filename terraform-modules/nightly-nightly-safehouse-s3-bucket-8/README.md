# Safehouse S3 Bucket Terraform Module\n\nThis module creates an Amazon S3 bucket that is ready for a post‑apocalyptic safe‑house scenario. The bucket includes:\n\n- **Versioning** – keep every version of an object.\n- **Server‑side encryption (AES‑256)** – data at rest is encrypted.\n- **Lifecycle rule** – automatically delete objects older than 30 days to free space.\n- **Radiation‑level tag** – a random integer (0‑100) generated at apply time to simulate ambient radiation.\n\n## Usage\n\n```hcl\nmodule \"safehouse_bucket\" {\n  source      = "./utils/nightly-safehouse-s3-bucket"\n  bucket_name = \"my‑post‑apoc‑safehouse\"\n}\n```\n\n## Variables\n\n| Name | Type | Description |\n|------|------|-------------|\n| `bucket_name` | `string` | Name of the S3 bucket to create. Must be globally unique. |\n\n## Outputs\n\n| Name | Description |\n|------|-------------|\n| `bucket_id` | The ID of the created S3 bucket. |\n| `radiation_level` | The randomly generated radiation level tag (0‑100). |\n\n## Requirements\n\n- Terraform >= 1.0\n- AWS provider\n- Random provider (automatically pulled by the module)\n\n## Notes\n\nThe module is deliberately whimsical – the *radiation_level* tag has no functional effect, but it adds flavor to your infrastructure as code.\n
