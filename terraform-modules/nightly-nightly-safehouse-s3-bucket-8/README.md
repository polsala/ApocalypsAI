# Safehouse S3 Bucket\n\nA tiny Terraform module that creates an Amazon S3 bucket configured for\npost‑apocalyptic safe‑house storage. The bucket has versioning enabled and a\nlifecycle rule that expires non‑current object versions after 30 days.\n\n## Features\n\n- **Versioning** – protects against accidental overwrites.\n- **Lifecycle rule** – automatically cleans up old versions to save cost.\n- **Tagging** – marks the bucket with a purpose tag.\n\n## Usage\n\n```hcl\nmodule "safehouse" {\n  source      = "./utils/nightly-safehouse-s3-bucket"\n  bucket_name = "my‑post‑apoc‑safehouse"\n}\n\noutput "bucket_arn" {\n  value = module.safehouse.bucket_arn\n}\n```\n\nRun the usual Terraform workflow:\n\n```bash\nterraform init\nterraform apply\n```\n\n## Variables\n\n| Name | Description | Type |\n|------|-------------|------|\n| `bucket_name` | Name of the S3 bucket to create | string |\n\n## Outputs\n\n| Name | Description |\n|------|-------------|\n| `bucket_arn` | ARN of the created bucket |\n\n## Testing\n\nA simple validation script is provided under `tests/validate.sh`. It checks that the required resources and variables are present in the module files.\n\n```bash\ncd utils/nightly-safehouse-s3-bucket\nchmod +x tests/validate.sh\n./tests/validate.sh\n```\n\nIf all checks pass, you should see `All checks passed.`\n
