# Nightly Safehouse S3 Bucket\n\nUtility Terraform module that provisions a secure S3 bucket for storing post‑apocalyptic resources. Features include:\n\n- Randomly generated bucket name (prefix + pet name)\n- Versioning enabled\n- Server‑side encryption (AES‑256)\n- Lifecycle rule to transition non‑current versions to Glacier after 30 days\n- Optional public‑access block\n\n## Usage\n\n```hcl\nmodule "safehouse" {\n  source               = "./src"\n  aws_region           = "us-east-1"\n  bucket_prefix        = "my‑safehouse"\n  enable_public_access = false\n}\n\noutput "bucket_id" {\n  value = module.safehouse.bucket_id\n}\n```\n\n## Variables\n\n| Name | Type | Default | Description |\n|------|------|---------|-------------|\n| `aws_region` | string | `"us-east-1"` | AWS region for the bucket. |\n| `bucket_prefix` | string | `"safehouse"` | Prefix for the bucket name. |\n| `enable_public_access` | bool | `false` | If `true`, disables the public‑access block. |\n\n## Outputs\n\n| Name | Description |\n|------|-------------|\n| `bucket_id` | The ID (name) of the created bucket. |\n| `bucket_arn` | The ARN of the created bucket. |\n\n## Testing\n\nThe module includes an offline test that runs `terraform init` (without a backend) and `terraform validate`. See `tests/test_main.sh`.\n\n```bash\ncd tests\n./test_main.sh\n```\n\n## License\n\nMIT
