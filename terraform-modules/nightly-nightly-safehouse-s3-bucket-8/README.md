# Safehouse S3 Bucket\n\nA whimsical yet practical Terraform module that creates an Amazon S3 bucket configured for\nmaximum data resilience – versioning, server‑side encryption, and a lifecycle rule that\nremoves non‑current object versions after 30 days. Perfect for storing your post‑apocalyptic\nbackups, secret maps, or any valuable artifacts.\n\n## Features\n\n- **Versioning** – keep every version of an object.\n- **Server‑Side Encryption (SSE‑S3)** – data at rest is encrypted automatically.\n- **Lifecycle rule** – automatically delete non‑current versions older than 30 days to\n  limit storage costs.\n\n## Usage\n\n```hcl\nmodule "safehouse_bucket" {\n  source      = "./src"\n  bucket_name = "my‑safehouse‑bucket"\n}\n```\n\nYou can also override the AWS region if needed:\n\n```hcl\nmodule "safehouse_bucket" {\n  source      = "./src"\n  bucket_name = "my‑safehouse‑bucket"\n  region      = "us‑west‑2"\n}\n```\n\n## Running the Tests\n\nThe test suite is a tiny Bash script that runs `terraform init` (with backend disabled) and\n`terraform validate` to ensure the configuration is syntactically correct. No real AWS credentials are\nrequired, making the tests fully offline and deterministic.\n\n```bash\ncd utils/nightly-safehouse-s3-bucket\nchmod +x tests/test.sh\n./tests/test.sh\n```\n\nIf the script exits with `0` and prints `Tests passed`, the module is ready to be used.\n\n## Variables\n\n| Name | Description | Type | Required | Default |\n|------|-------------|------|----------|---------|\n| `bucket_name` | Name of the S3 bucket (must be globally unique) | `string` | yes | – |\n| `region` | AWS region for the bucket | `string` | no | `"us-east-1"` |\n\n## Outputs\n\n| Name | Description |\n|------|-------------|\n| `bucket_id` | The name of the created bucket |\n| `bucket_arn` | The ARN of the created bucket |\n\n---\n\n*This utility lives under the `terraform-modules` classifier to showcase infrastructure‑as‑code.*
