# Nightly Wasteland Bucket\n\nTerraform module to create a versioned S3 bucket with lifecycle expiration, ideal for storing precious data in a post‑apocalyptic setting.\n\n## Usage\n\n```hcl\nmodule "wasteland_bucket" {\n  source          = "./"\n  bucket_name     = "my-wasteland-archive"\n  expiration_days = 730\n}\n```\n\n## Inputs\n\n- `bucket_name` (string, required): Name of the bucket.\n- `expiration_days` (number, optional, default = 365): Days after which non‑current object versions are deleted.\n\n## Outputs\n\n- `bucket_arn`: ARN of the created bucket.\n\n## Testing\n\nRun the provided test script:\n\n```sh\ncd tests && ./validate.sh\n```
