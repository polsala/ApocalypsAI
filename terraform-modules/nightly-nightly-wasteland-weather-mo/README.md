# Nightly Wasteland Weather Module\n\nThis Terraform module creates a `weather.json` file in the current working directory containing a whimsical post‑apocalyptic weather forecast. It uses the `random` provider to pick a temperature range and a weather condition from a predefined list.\n\n## Usage\n\n```hcl\nmodule "wasteland_weather" {\n  source = "./"\n}\n```\n\nRun:\n\n```sh\nterraform init\nterraform apply -auto-approve\n```\n\nThe file `weather.json` will be created.\n\n## Variables\n\n| Name | Description | Type | Default |\n|------|-------------|------|---------|\n| location | Name of the location for the forecast | string | "The Wasteland" |\n| seed | Seed for random generator (optional) | number | null |\n\n## Outputs\n\n| Name | Description |\n|------|-------------|\n| forecast_path | Path to the generated JSON file |\n\n## Testing\n\n```sh\ncd tests && ./test_module.sh\n```
