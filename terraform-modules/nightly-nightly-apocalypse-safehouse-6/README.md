# Apocalypse Safehouse S3 Terraform Module\n\nThis module provisions an S3 bucket configured for post‑apocalyptic resource storage.\n\n## Features\n\n- Versioning enabled\n- Server‑side encryption (AES256)\n- Lifecycle rule to delete non‑current versions after 30 days\n- Optional tags\n\n## Usage\n\n```hcl\nmodule "safehouse" {\n  source      = "github.com/yourorg/apocalypsai//terraform-modules/nightly-apocalypse-safehouse-s3"\n  bucket_name = "my-safehouse-bucket"\n  tags = {\n    Environment = "production"\n    Project     = "Apocalypse"\n  }\n}\n```\n\nRun `terraform init` and `terraform apply`.
