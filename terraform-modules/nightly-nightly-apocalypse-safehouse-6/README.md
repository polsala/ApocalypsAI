# Nightly Apocalypse Safehouse S3\n\n## Overview\n\nThis Terraform module creates an AWS S3 bucket configured for a post‑apocalyptic safe‑house:\n\n* **Versioning** enabled – keep every revision of your critical files.\n* **Lifecycle rule** that expires objects older than 365 days (you can adjust).\n* Simple, reusable inputs for bucket name and region.\n\n## Usage\n\n```hcl\nmodule "safehouse" {\n  source      = "./src"\n  bucket_name = "my‑apocalypse‑vault"\n  region      = "us-east-1"\n}\n\noutput "bucket_id" {\n  value = module.safehouse.bucket_id\n}\n```\n\n## Inputs\n\n| Name | Description | Type | Required |\n|------|-------------|------|----------|\n| `bucket_name` | Name of the S3 bucket (must be globally unique) | `string` | yes |\n| `region`      | AWS region for the bucket | `string` | yes |\n\n## Outputs\n\n| Name | Description |\n|------|-------------|\n| `bucket_id` | The ID of the created S3 bucket |\n\n## Testing\n\nRun the provided Python test suite (requires only the standard library):\n\n```bash\npython -m unittest discover -s tests\n```\n\nThe test suite mocks the `terraform` CLI, so no real AWS credentials or Terraform binary are needed.\n
