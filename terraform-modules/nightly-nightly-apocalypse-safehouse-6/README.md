# Nightly Apocalyptic Safehouse S3\n\nThis Terraform module provisions an S3 bucket that acts as a "safehouse" for community data. The bucket name is generated with a random pet name, making each deployment unique and a bit whimsical.\n\n## Features\n\n- **Randomized bucket name** using `random_pet` (e.g., `apocalypse-safehouse‑fluffy‑dev`)\n- Versioning enabled\n- Server‑side encryption (AES‑256)\n- Lifecycle rule that expires objects older than 30 days\n- Configurable environment tag and AWS region\n\n## Usage\n\n```hcl\nmodule "safehouse" {\n  source        = "./utils/nightly-apocalypse-safehouse-s3"\n  environment   = "prod"\n  bucket_prefix = "apocalypse-safehouse"\n  aws_region    = "us-east-1"\n}\n```\n\nRun the usual Terraform workflow:\n\n```bash\nterraform init\nterraform apply -var \"environment=prod\"\n```\n\n## Inputs\n\n| Name | Description | Type | Default |\n|------|-------------|------|---------|\n| `environment` | Deployment environment (e.g., dev, prod). | string | n/a |\n| `bucket_prefix` | Prefix for the bucket name. | string | `\"apocalypse-safehouse\"` |\n| `aws_region` | AWS region for the bucket. | string | `\"us-east-1\"` |\n\n## Outputs\n\n| Name | Description |\n|------|-------------|\n| `bucket_name` | Name of the created S3 bucket. |\n| `bucket_arn` | ARN of the created S3 bucket. |\n\n## Testing\n\nA simple validation script is provided under `tests/validate.sh`. It runs `terraform init` (without a backend) and `terraform validate` to ensure the configuration is syntactically correct. No real AWS credentials are required for this test.\n
