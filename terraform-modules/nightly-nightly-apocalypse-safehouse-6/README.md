# Nightly Apocalypse Safehouse S3

Terraform module that creates a secure S3 bucket, versioned, encrypted, and with a lifecycle rule that deletes objects older than 30 days. Ideal for storing precious post‑apocalyptic data.

## Usage

```hcl
module "safehouse" {
  source      = "./"
  bucket_name = "my‑post‑apoc‑vault"
}
```

## Inputs

| Name | Description | Type | Default |
|------|-------------|------|---------|
| bucket_name | Name of the S3 bucket | string | autogenerated |

## Outputs

| Name | Description |
|------|-------------|
| bucket_id | ID of the bucket |
| bucket_arn | ARN of the bucket |
