# Apocalyptic Safehouse S3 Terraform Module\n\n## Overview\nCreates an S3 bucket configured for durability and secrecy, ideal for storing supplies in a post‑apocalyptic world.\n\n## Features\n- Server‑side encryption (AES‑256)\n- Versioning enabled\n- Lifecycle rule to delete objects older than 30 days\n- Optional random \"supply‑cache.txt\" object with placeholder content\n\n## Usage\n\n```hcl\nmodule \"safehouse_s3\" {\n  source = "git::https://github.com/yourorg/apocalypsai.git//terraform-modules/nightly-apocalypse-safehouse-s3"\n\n  bucket_name = \"my‑safehouse‑bucket\"\n  create_supply_cache = true\n}\n```\n\n## Inputs\n| Name | Description | Type | Default |\n|------|-------------|------|---------|\n| bucket_name | Name of the S3 bucket | string | n/a |\n| create_supply_cache | Whether to create a placeholder object | bool | false |\n| aws_region | AWS region for the bucket | string | us-east-1 |\n\n## Outputs\n| Name | Description |\n|------|-------------|\n| bucket_arn | ARN of the created bucket |\n| bucket_id | ID of the bucket |\n\n## Testing\nRun `bash tests/test_module.sh` to verify the module syntax.
