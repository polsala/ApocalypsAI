# Apocalyptic Safehouse S3 Module\n\nCreates an S3 bucket configured for post‑apocalyptic data storage with versioning, server‑side encryption, and a lifecycle rule that expires objects after 30 days. Also creates an IAM policy granting read/write access to a specified IAM role.\n\n## Usage\n\n```hcl\nmodule "safehouse" {\n  source        = "./utils/terraform-modules/nightly-apocalypse-safehouse-s3"\n  bucket_name   = "my-safehouse-bucket"\n  iam_role_name = "SurvivorRole"\n}\n```\n\n## Inputs\n\n- `bucket_name` (string, required): Name of the S3 bucket.\n- `iam_role_name` (string, required): Name of the IAM role to attach the policy to.\n\n## Outputs\n\n- `bucket_arn` – ARN of the created bucket.\n- `policy_arn` – ARN of the IAM policy.\n\n## Testing\n\nRun the test script from the module root:\n\n```bash\nbash tests/test_module.sh\n```
