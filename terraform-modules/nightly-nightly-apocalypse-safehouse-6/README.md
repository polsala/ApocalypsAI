# Apocalyptic Safehouse S3 Terraform Module\n\n## Overview\nCreates an S3 bucket with server‑side encryption, versioning, and a lifecycle rule that deletes non‑current object versions after 30 days. Ideal for storing critical data in a post‑apocalyptic scenario.\n\n## Usage\n```hcl\nmodule "safehouse" {\n  source = "./path/to/module"\n\n  bucket_name = "my-safehouse-bucket"\n}\n```\n\n## Variables\n- `bucket_name` (string, required): Name of the S3 bucket.\n\n## Outputs\n- `bucket_arn`: ARN of the created bucket.\n- `bucket_id`: ID of the bucket.\n\n## Testing\nRun the test script:\n\n```sh\ncd tests\nbash plan_test.sh\n```\nIt will init Terraform, validate the configuration and ensure the plan contains the expected resources.
