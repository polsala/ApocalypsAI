# Apocalyptic Safehouse S3 Module\n\nThis Terraform module creates an S3 bucket configured for post‑apocalyptic data hoarding:\n\n* **Versioning** enabled – never lose a revision of your survival manuals.\n* **Server‑side encryption (AES‑256)** – keep the secrets safe from raiders.\n* **Lifecycle rule** – automatically expire objects after 30 days to free up space for new supplies.\n* **Read‑only IAM policy** – grant wanderers access without letting them delete anything.\n\n## Usage\n\n```hcl\nmodule \"safehouse\" {\n  source      = "./src"\n  bucket_name = "my‑post‑apoc‑store"\n  tags = {\n    Environment = "production"\n    Owner       = "survivors"\n  }\n}\n\noutput \"bucket_arn\" {\n  value = module.safehouse.bucket_arn\n}\n\noutput \"read_only_policy_arn\" {\n  value = module.safehouse.read_only_policy_arn\n}\n```\n\n## Variables\n\n| Name | Type | Description | Default |\n|------|------|-------------|---------|\n| `bucket_name` | `string` | Name of the S3 bucket (must be globally unique). | n/a |\n| `tags` | `map(string)` | Optional tags to apply to the bucket and IAM policy. | `{}` |\n\n## Outputs\n\n| Name | Description |\n|------|-------------|\n| `bucket_arn` | ARN of the created S3 bucket. |\n| `read_only_policy_arn` | ARN of the generated read‑only IAM policy. |\n\n## Testing\n\nA simple deterministic test is provided in `tests/validate.sh`. It runs `terraform init`, `terraform validate`, and a dry‑run `terraform plan` without contacting AWS (the AWS provider is configured to skip credential validation). The test asserts that the bucket name appears in the generated plan.\n\n```bash\ncd tests\n./validate.sh\n```\n\n## Notes\n\n* The module uses the AWS provider with `skip_credentials_validation = true` and `skip_requesting_account_id = true` so the test can run offline.\n* In a real deployment you must provide appropriate AWS credentials and region.\n
