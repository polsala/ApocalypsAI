# Nightly Safehouse S3 Bunker\n\n## Overview\n\nA whimsical yet practical Terraform module that creates a secure S3 bucket – the "bunker" for your post‑apocalyptic data. The bucket gets a random name, has versioning enabled, server‑side encryption (AES‑256), and a lifecycle rule that automatically deletes objects older than 30 days.\n\n## Features\n\n- **Random bucket name** using `random_pet` (e.g., `dev‑fluffy‑otter`)\n- **Versioning** to protect against accidental overwrites\n- **Server‑side encryption** (AES‑256) for data at rest\n- **Lifecycle rule** that expires objects after 30 days\n- **Force destroy** enabled so the bucket can be removed without manual emptying\n\n## Usage\n\n```hcl\nmodule "safehouse" {\n  source      = "./src"\n  environment = "prod"\n}\n\noutput "bucket_name" {\n  value = module.safehouse.bucket_name\n}\n```\n\n## Inputs\n\n| Name | Description | Type | Default |\n|------|-------------|------|---------|\n| `environment` | Prefix for the bucket name (e.g., `dev`, `prod`) | `string` | `"dev"` |\n\n## Outputs\n\n| Name | Description |\n|------|-------------|\n| `bucket_name` | The name of the created S3 bucket |\n\n## Requirements\n\n- Terraform >= 1.0\n- AWS provider (configured via environment variables or shared credentials)\n\n## Testing\n\nRun the provided Bash test script to verify the module contains the expected resources and settings:\n\n```bash\ncd tests && ./test_main.sh\n```\n\nThe test is deterministic and runs offline – it simply greps the module files for required blocks.\n
