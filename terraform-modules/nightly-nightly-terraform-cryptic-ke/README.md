# nightly-terraform-cryptic-keep

## Overview

`nightly-terraform-cryptic-keep` is a playful yet practical Terraform module that creates:

1. An **S3 bucket** configured as a *secret vault* – versioning enabled, server‑side encryption, and a bucket policy that blocks public access.
2. An **AWS Secrets Manager** secret that holds a randomly generated password for the vault.

The module is completely self‑contained and can be dropped into any Terraform project that targets AWS.

## Usage

```hcl
module "cryptic_keep" {
  source          = "./utils/nightly-terraform-cryptic-keep"
  bucket_name     = "my‑secret‑vault"
  password_length = 24
}

output "vault_bucket_arn" {
  value = module.cryptic_keep.bucket_arn
}

output "vault_password_arn" {
  value = module.cryptic_keep.secret_arn
}
```

## Variables

| Name            | Type   | Description                                          | Default |
|-----------------|--------|------------------------------------------------------|---------|
| `bucket_name`   | string | Name of the S3 bucket that will act as the vault.    | n/a     |
| `password_length` | number | Length of the autogenerated password (min 8, max 64). | `16`    |

## Outputs

| Name       | Description                                 |
|------------|---------------------------------------------|
| `bucket_arn` | ARN of the created S3 bucket.               |
| `secret_arn` | ARN of the Secrets Manager secret containing the password. |

## Testing

The module includes a deterministic Python test suite that validates the presence of expected resources and default values without contacting AWS. Run the tests with:

```bash
python -m unittest discover -s utils/nightly-terraform-cryptic-keep/tests
```
