Nightly Safehouse Generator\n\nThis Terraform module creates a whimsical post‑apocalyptic safe‑house name using the random_pet resource and writes a friendly welcome file locally. It is useful for demo projects, naming conventions, or just for fun.\n\nUsage:\n\n1. Add the module to your Terraform configuration. Example:\n\nmodule "safehouse" {\n  source = "./path/to/this/module"\n  pet_length = 2\n}\n\n2. Initialise and apply the configuration:\n\nterraform init -backend=false\nterraform apply -auto-approve\n\nThe module will output `safehouse_name` and create a file named `safehouse_<name>.txt` in the module directory containing a welcome message.\n\nVariables:\n\n- `pet_length` (number, optional): Length of the random pet name (default 2).\n\nOutputs:\n\n- `safehouse_name`: The generated safe‑house name.
