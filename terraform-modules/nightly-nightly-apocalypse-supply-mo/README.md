# Nightly Apocalypse Supply Module\n\nA tiny Terraform module that pretends to generate a daily scavenged supply list for post‑apocalyptic wanderers. It uses the built‑in `null` provider and a `local‑exec` provisioner to write a `supply_list.txt` file containing a hard‑coded list of items.\n\n## Features\n\n- No external cloud resources – runs entirely locally.\n- Deterministic default supply list (easy to test).\n- Simple `terraform init` / `terraform apply` workflow.\n\n## Usage\n\n```hcl\nmodule \"apocalypse_supply\" {\n  source = "./"\n  # optional: override the default list\n  # supply_items = [\n  #   \"canned beans\",\n  #   \"bottled water\",\n  #   \"first aid kit\"\n  # ]\n}\n\noutput \"supply_file\" {\n  value = module.apocalypse_supply.supply_file\n}\n```\n\nRun the module:\n\n```bash\nterraform init -backend=false\nterraform apply -auto-approve\ncat supply_list.txt\n```\n\nYou should see something like:\n\n```
Today's scavenged supplies: [canned beans, bottled water, first aid kit, flashlight, batteries]\n```\n\n## Testing\n\nThe repository includes a simple Bash test that runs `terraform validate` and checks that the generated file exists and contains the expected text. See `tests/test_module.sh`.\n
