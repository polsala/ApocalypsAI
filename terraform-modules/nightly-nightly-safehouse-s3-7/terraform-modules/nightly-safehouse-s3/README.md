# Nightly Safehouse S3 Terraform Module\n\nProvision a versioned S3 bucket with lifecycle rules suitable for storing post‑apocalyptic safe‑house data, plus a generated random password for access.\n\n## Usage\n\n```hcl\nmodule "safehouse" {\n  source      = "github.com/yourorg/ApocalypsAI//terraform-modules/nightly-safehouse-s3"\n  bucket_name = "my-safehouse-bucket"\n}\n```\n\n## Inputs\n\n- `bucket_name` – Name of the S3 bucket (must be globally unique).\n\n## Outputs\n\n- `bucket_id` – The ID of the bucket.\n- `bucket_arn` – ARN of the bucket.\n- `access_password` – Randomly generated password (16 characters).\n\n## Requirements\n\n- Terraform >= 1.0\n- AWS provider configured\n- Random provider\n
