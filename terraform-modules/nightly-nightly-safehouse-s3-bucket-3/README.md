# Nightly Safehouse S3 Bucket\n\nA tiny Terraform module that creates an AWS S3 bucket suitable for storing critical post‑apocalyptic data. The bucket has versioning enabled and a lifecycle rule that expires objects older than 365 days.\n\n## Features\n\n- **Versioning** – never lose a previous version of a file.\n- **Lifecycle rule** – automatically delete objects older than one year to keep storage costs low.\n- **Zero‑runtime dependencies** – pure Terraform, works with any backend.\n\n## Usage\n\n```hcl\nmodule \"safehouse\" {\n  source      = "./"\n  bucket_name = \"my‑post‑apoc‑safehouse\"\n}\n\noutput \"bucket_arn\" {\n  value = module.safehouse.bucket_arn\n}\n```\n\n## Variables\n\n| Name | Description | Type | Required |\n|------|-------------|------|----------|\n| `bucket_name` | Name of the S3 bucket to create. Must be globally unique. | `string` | yes |\n\n## Outputs\n\n| Name | Description |\n|------|-------------|\n| `bucket_arn` | ARN of the created S3 bucket. |\n\n## Testing\n\nRun the provided test script (requires Terraform 1.0+):\n\n```bash\nchmod +x tests/test.sh\n./tests/test.sh\n```\n\nThe script validates the configuration and checks that the required blocks are present.\n
