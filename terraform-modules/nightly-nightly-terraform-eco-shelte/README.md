# Terraform Eco Shelter Module\n\nThis Terraform module creates an abstract representation of an eco‑friendly underground shelter, including variables for solar power capacity and water storage. It's whimsical but can serve as a template for real infrastructure.\n\n## Usage\n\n```hcl\nmodule "eco_shelter" {\n  source              = "./"\n  shelter_name        = "Haven"\n  solar_capacity_kw   = 5\n  water_tank_gallons  = 2000\n}\n```\n\n## Variables\n\n- `shelter_name` – Name of the shelter (string)\n- `solar_capacity_kw` – Solar panel capacity in kilowatts (number)\n- `water_tank_gallons` – Water tank size in gallons (number)\n\n## Outputs\n\n- `shelter_id` – A synthetic ID for the shelter.\n- `energy_production_estimate` – Estimated daily kWh production.\n\n## Note\n\nThis module uses `null_resource` and `local-exec` to simulate resources; no real cloud provider is required.
