# Apocalyptic Safehouse S3 Bucket\n\nThis Terraform module creates an S3 bucket designed to store precious supplies in a post‑apocalyptic world.\n\n## Features\n\n- Server‑side encryption (AES‑256)\n- Versioning enabled\n- Lifecycle rule to delete objects older than 30 days\n- Randomly generated `radiation_level` tag (0‑100)\n\n## Usage\n\n```hcl\nmodule "safehouse" {\n  source      = "./path/to/nightly-apocalypse-safeguard-s3"\n  bucket_name = "my‑post‑apoc‑supplies"\n}\n\noutput "bucket_id" {\n  value = module.safehouse.bucket_id\n}\n\noutput "radiation_level" {\n  value = module.safehouse.radiation_level\n}\n```\n\n## Variables\n\n| Name | Description | Type | Required |\n|------|-------------|------|----------|\n| `bucket_name` | Name of the S3 bucket | string | yes |\n\n## Outputs\n\n| Name | Description |\n|------|-------------|\n| `bucket_id` | ID of the created bucket |\n| `bucket_arn` | ARN of the created bucket |\n| `radiation_level` | Random radiation level tag (0‑100) |\n\n## Requirements\n\n- Terraform >= 1.0\n- AWS provider\n- Random provider\n\n## Notes\n\nThe `radiation_level` tag is purely whimsical and can be used by downstream automation to simulate environmental hazards.\n
