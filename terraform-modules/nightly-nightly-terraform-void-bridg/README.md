# Nightly Terraform Void Bridge\n\n## Overview\nThis Terraform module creates a `null_resource` that simulates the activation of a post‑apocalypse safe‑zone beacon. It writes a tiny text file `beacon.txt` containing the zone name and safety level.\n\n## Usage\n```hcl\nmodule "void_bridge" {\n  source       = "github.com/yourorg/polsala/terraform-modules/nightly-terraform-void-bridge"\n  zone_name    = "Eden"\n  safety_level = 5\n}\n```\n\n## Variables\n- `zone_name` (string, default: "Unknown Zone"): Name of the safe zone.\n- `safety_level` (number, default: 1): Safety rating from 1 (dangerous) to 10 (ultra‑safe).\n\n## Outputs\n- `beacon_path`: Path to the generated `beacon.txt` file.\n\n## Requirements\n- Terraform >= 1.0\n- No external providers required (uses the `null` provider).\n\n## License\nMIT
