# Nightly Safehouse S3 & DynamoDB Terraform Module\n\n## Overview\n\nThis Terraform module creates an S3 bucket with versioning and lifecycle rules, plus a DynamoDB table for logging. Ideal for storing post‑apocalyptic safe‑house data.\n\n## Usage\n\n```hcl\nmodule "safehouse_storage" {\n  source = "./src"\n\n  bucket_name          = "my-safehouse-bucket"\n  dynamodb_table_name  = "safehouse-logs"\n}\n```\n\n## Inputs\n\n| Name | Description | Type | Default | Required |\n|------|-------------|------|---------|----------|\n| bucket_name | Name of the S3 bucket | string | n/a | yes |\n| dynamodb_table_name | Name of the DynamoDB table | string | n/a | yes |\n| lifecycle_days | Days after which non‑current versions are deleted | number | 30 | no |\n\n## Outputs\n\n| Name | Description |\n|------|-------------|\n| bucket_arn | ARN of the created S3 bucket |\n| dynamodb_table_arn | ARN of the DynamoDB table |\n\n## Testing\n\nRun `bash tests/test_module.sh` to verify the module files contain required resources.\n
