Nightly Safehouse S3 Terraform Module\n\nThis Terraform module provisions an AWS S3 bucket configured as a post‑apocalyptic safe‑house. Features include:\n\n- Versioning enabled (so you never lose a file)\n- Lifecycle rule that expires non‑current versions after 30 days\n- Force destroy to allow bucket removal during testing\n- Tagging for easy identification\n\nUsage:\n\nmodule "safehouse" {\n  source      = "./src"\n  bucket_name = "my‑post‑apoc‑safehouse"\n}\n\nRun `terraform init` and `terraform apply` in the directory containing the module.\n
