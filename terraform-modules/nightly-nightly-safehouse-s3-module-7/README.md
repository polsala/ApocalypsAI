# Nightly Safehouse S3 Module\n\nCreates an S3 bucket named with a random pet name, with versioning, server‑side encryption (AES256), and a lifecycle rule that deletes non‑current versions after 30 days. Ideal for storing post‑apocalyptic data backups.\n\n## Usage\n\n```hcl\nmodule "safehouse" {\n  source = "./utils/terraform-modules/nightly-safehouse-s3-module"\n}\n```\n\n## Inputs\n\n| Name | Description | Type | Default |\n|------|-------------|------|---------|\n| bucket_prefix | Prefix for bucket name | string | \"safehouse-\" |\n| lifecycle_days | Days after which non‑current versions are deleted | number | 30 |\n\n## Outputs\n\n| Name | Description |\n|------|-------------|\n| bucket_id | The name of the created bucket |\n| bucket_arn | ARN of the bucket |\n\n## Testing\n\nRun the test script:\n\n```sh\ncd utils/terraform-modules/nightly-safehouse-s3-module\nbash tests/test_main.sh\n```
