# Nightly Safehouse S3 Terraform Module\n\n## Overview\nCreates an AWS S3 bucket configured for durability and privacy, ideal for storing critical data in a post‑apocalyptic setting.\n\n## Features\n- Versioning enabled\n- Server‑side encryption (AES‑256)\n- Public access blocked\n- Lifecycle rule: transition objects to Glacier after 30 days, delete after 365 days\n- Optional custom bucket name\n\n## Usage\n```hcl\nmodule "safehouse_s3" {\n  source      = "./modules/nightly-safehouse-s3"\n  bucket_name = "my‑post‑apoc‑vault"\n}\n```\n\n## Inputs\n| Name | Description | Type | Default |\n|------|-------------|------|---------|\n| bucket_name | Desired bucket name (optional). If omitted, a random name is generated. | string | null |\n\n## Outputs\n| Name | Description |\n|------|-------------|\n| bucket_id | The ID of the created bucket |\n| bucket_arn | The ARN of the created bucket |\n\n## Testing\nRun `bash tests/test_main.sh` to verify the module contains required resources.
