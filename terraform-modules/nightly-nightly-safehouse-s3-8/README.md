# Safehouse S3 Terraform Module\n\nCreates an S3 bucket suitable for storing precious post‑apocalyptic supplies. Features:\n\n- Randomized bucket name with optional prefix\n- Versioning enabled\n- Server‑side encryption (AES‑256)\n- Lifecycle rule to delete non‑current versions after 30 days\n- Optional tags\n\n## Usage\n\n```hcl\nmodule "safehouse" {\n  source       = "./"\n  name_prefix  = "my‑prefix"   # optional, can be empty\n  tags = {\n    Environment = "production"\n    Owner       = "apocalypse"\n  }\n}\n```\n\nThe module will create a bucket with a name like `my‑prefix‑fluffy‑rabbit` (or just `fluffy‑rabbit` if no prefix is supplied).\n\n## Inputs\n\n| Name | Description | Type | Default |\n|------|-------------|------|---------|\n| `name_prefix` | Optional prefix for bucket name | `string` | `""` |\n| `tags` | Tags to apply to the bucket | `map(string)` | `{}` |\n\n## Outputs\n\n| Name | Description |\n|------|-------------|\n| `bucket_id` | The ID of the created bucket |\n| `bucket_arn` | ARN of the bucket |\n\n## Testing\n\nRun the provided test script (requires Terraform >= 1.0):\n\n```bash\ncd <module‑directory>\nchmod +x tests/test_main.sh\n./tests/test_main.sh\n```\n\nThe test validates the configuration and performs a dry‑run plan using a dummy `name_prefix`. No AWS credentials are needed because the test uses the local backend.
