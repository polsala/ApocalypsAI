# Safehouse S3 Terraform Module\n\nA whimsical yet practical Terraform module that creates a secure S3 bucket with versioning, server‑side encryption, a random pet‑style name, and a lifecycle rule that deletes objects older than 30 days. Perfect for storing post‑apocalyptic logs, backups, or treasure maps.\n\n## Usage\n\n```hcl\nmodule "safehouse" {\n  source = "./path/to/module"\n\n  bucket_prefix = "safehouse"\n}\n```\n\n## Inputs\n\n| Name | Description | Type | Default |\n|------|-------------|------|---------|\n| bucket_prefix | Prefix for the bucket name (random pet suffix will be added) | string | `"safehouse"` |\n\n## Outputs\n\n| Name | Description |\n|------|-------------|\n| bucket_name | The name of the created S3 bucket |\n| bucket_arn  | ARN of the bucket |\n\n## Requirements\n\n- Terraform >= 1.0\n- AWS provider\n
