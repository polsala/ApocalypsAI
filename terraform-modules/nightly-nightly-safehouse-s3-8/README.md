# Nightly Safehouse S3 Terraform Module\n\nA whimsical yet practical Terraform module that provisions a secure, versioned, encrypted S3 bucket named after a random post‑apocalyptic pet. Ideal for storing critical data in a "safehouse".\n\n## Features\n\n- Random bucket name with `random_pet` (e.g., `safehouse‑fluffy‑fox`)\n- Server‑side AES‑256 encryption\n- Versioning enabled\n- Lifecycle rule to delete non‑current versions after configurable days (default 30)\n\n## Usage\n\n```hcl\nmodule "safehouse_s3" {\n  source               = "github.com/yourorg/ApocalypsAI//terraform-modules/nightly-safehouse-s3"\n  region               = "us-east-1"\n  bucket_name_prefix   = "safehouse"\n  lifecycle_days       = 30\n}\n```\n\nRun `terraform init && terraform apply` to create the bucket.\n\n## Inputs\n\n| Name | Description | Type | Default |\n|------|-------------|------|---------|\n| region | AWS region | string | n/a |\n| bucket_name_prefix | Prefix for bucket name | string | "safehouse" |\n| lifecycle_days | Days to retain non‑current versions | number | 30 |\n\n## Outputs\n\n| Name | Description |\n|------|-------------|\n| bucket_id | ID of the bucket |\n| bucket_arn | ARN of the bucket |\n| bucket_name | Name of the bucket |\n\n## Testing\n\n```sh\ncd tests && ./test_module.sh\n```
