# Nightly Safehouse S3 Terraform Module\n\nCreates an S3 bucket configured for post‑apocalyptic data hoarding.\n\n## Features\n\n- Versioning enabled\n- Server‑side encryption (AES‑256)\n- Lifecycle rule to delete non‑current versions after 30 days\n- IAM policy for read‑only access to the bucket\n\n## Usage\n\n```hcl\nmodule "safehouse" {\n  source      = "./src"\n  bucket_name = "my-safehouse-bucket"\n}\n```\n\nRun the usual Terraform commands:\n\n```bash\nterraform init\nterraform apply\n```\n\n## Variables\n\n| Name | Description | Type |\n|------|-------------|------|\n| `bucket_name` | Name of the S3 bucket to create | string |\n\n## Outputs\n\n| Name | Description |\n|------|-------------|\n| `bucket_id` | ID of the created S3 bucket |\n| `readonly_policy_arn` | ARN of the read‑only IAM policy |\n\n## Testing\n\nA simple offline test script is provided under `tests/` that validates the presence of required resources without contacting AWS.\n
