# Nightly Safehouse S3 Terraform Module\n\nCreates an S3 bucket with versioning and a lifecycle rule that deletes objects older than 30 days. The bucket name is prefixed with a user‑provided string and suffixed with a random 4‑character suffix to avoid collisions.\n\n## Usage\n\n```hcl\nmodule "safehouse_s3" {\n  source      = "./src"\n  name_prefix = "my-safehouse"\n}\n```\n\nRun `terraform init` and `terraform apply`.\n\n## Variables\n\n- `name_prefix` (string) – Prefix for bucket name.\n\n## Outputs\n\n- `bucket_name` – The name of the created bucket.\n\n## Testing\n\nRun `bash tests/test_main.sh` to verify the module contains required resources.\n
