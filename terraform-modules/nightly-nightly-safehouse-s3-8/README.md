# Nightly Safehouse S3 Terraform Module

Creates an S3 bucket configured for post‑apocalyptic safe‑house storage.

## Features
- Versioning enabled
- Server‑side encryption (AES‑256)
- Lifecycle rule that deletes objects older than 30 days
- Optional initial "supply" object with placeholder content

## Usage
```hcl
module "safehouse" {
  source               = "./utils/nightly-safehouse-s3"
  bucket_name          = "my‑post‑apoc‑safehouse"
  create_supply_object = true   # optional, defaults to true
  supply_content       = "Emergency supplies"
}
```

## Variables
| Name | Type | Description | Default |
|------|------|-------------|---------|
| `bucket_name` | `string` | Name of the S3 bucket to create. | n/a |
| `create_supply_object` | `bool` | Whether to create a starter `supply.txt` object. | `true` |
| `supply_content` | `string` | Content of the starter supply object. | `"Emergency supplies"` |

## Outputs
| Name | Description |
|------|-------------|
| `bucket_id` | The ID of the created bucket. |
| `bucket_arn` | The ARN of the created bucket. |
| `supply_object_key` | Key of the supply object (if created). |
