# Apocalyptic Safehouse S3 Bucket\n\nThis Terraform module creates an S3 bucket configured for a post‑apocalyptic safe‑house. It includes:\n\n- A **randomized bucket name** with a configurable prefix.\n- **Versioning** enabled to keep every change.\n- A **lifecycle rule** that moves objects to Glacier after 30 days and permanently deletes them after 365 days.\n- Optional **tags** for cost allocation or identification.\n\n## Usage\n\n```hcl\nmodule \"safehouse\" {\n  source        = "./"  # or a registry path if published\n  bucket_prefix = "apoc-safehouse"\n  tags = {\n    Environment = "post‑apocalypse"\n    Owner       = "survivors"\n  }\n}\n\noutput \"bucket_name\" {\n  value = module.safehouse.bucket_name\n}\n```\n\n## Variables\n\n| Name | Type | Description | Default |\n|------|------|-------------|---------|\n| `bucket_prefix` | `string` | Prefix for the bucket name. The final name will be `<prefix>-<random‑hex>` | `"apoc-safehouse"` |\n| `tags` | `map(string)` | Tags applied to the bucket. | `{}` |\n\n## Outputs\n\n| Name | Description |\n|------|-------------|\n| `bucket_name` | The name of the created S3 bucket. |\n\n## Testing\n\nA simple validation script is provided under `tests/validate.sh`. It runs `terraform init` (with a local backend) and `terraform validate` to ensure the module syntax is correct.\n\n```bash\ncd tests\n./validate.sh\n```\n\n## License\n\nMIT – use it to keep your supplies safe!\n
