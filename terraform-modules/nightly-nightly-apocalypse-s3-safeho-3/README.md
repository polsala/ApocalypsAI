# Nightly Apocalypse S3 Safehouse\n\n## Overview\n\nThis Terraform module creates an AWS S3 bucket that is:\n\n- **Versioned** – keeps all object versions.\n- **Encrypted** – uses AES‑256 server‑side encryption.\n- **Self‑pruning** – automatically deletes objects (and all their versions) that are older than 30 days.\n\nIt is intended as a whimsical yet practical "safehouse" for storing post‑apocalyptic data backups.\n\n## Usage\n\n```hcl\nmodule \"apocalypse_safehouse\" {\n  source      = "github.com/your-org/polsala/ApocalypsAI//terraform-modules/nightly-apocalypse-s3-safehouse"\n  bucket_name = \"my‑apocalypse‑backup\"\n}\n\noutput \"bucket_id\" {\n  value = module.apocalypse_safehouse.bucket_id\n}\n\noutput \"bucket_arn\" {\n  value = module.apocalypse_safehouse.bucket_arn\n}\n```\n\n## Inputs\n\n| Name | Type | Description | Default | Required |\n|------|------|-------------|---------|----------|\n| `bucket_name` | `string` | Name of the S3 bucket (must be globally unique). | n/a | yes |\n\n## Outputs\n\n| Name | Description |\n|------|-------------|\n| `bucket_id` | The name of the created bucket. |\n| `bucket_arn` | The ARN of the created bucket. |\n\n## Testing\n\nA simple validation script is provided under `tests/validate.sh`. It runs `terraform init` (with a local backend) and `terraform validate` to ensure the module syntax is correct. No real AWS credentials are required for this step.\n\n```bash\ncd $(git rev-parse --show-toplevel)/terraform-modules/nightly-apocalypse-s3-safehouse\n./tests/validate.sh\n```\n\n## License\n\nMIT – see the root LICENSE file.
