# Mutant Mushroom Mixer\n\nA Docker container that reads a CSV list of available pantry items and conjures whimsical post‑apocalypse recipes.\n\n## Usage\n\n```sh\n# Build the image\ndocker build -t mutant-mushroom-mixer .\n\n# Run the container, mounting your ingredients CSV\n# The CSV must be located at ./ingredients.csv relative to this command\n# and contain a header `ingredient` with one ingredient per line.\n\n# Example CSV content:\n# ingredient\n# canned beans\n# dried noodles\n# mutant mushroom\n\n# Run the container\ndocker run --rm -v $(pwd)/ingredients.csv:/data/ingredients.csv mutant-mushroom-mixer\n```\n\nThe container will output a playful recipe name and the selected ingredients, e.g.:\n\n````\nRecipe: Scavenger Stew\nIngredients: canned beans, dried noodles, mutant mushroom\n````\n\n## How it works\n\nThe container runs a tiny Python script that reads the CSV, picks up to three random ingredients, and generates a whimsical recipe name. No external dependencies are required – just the standard library.\n
