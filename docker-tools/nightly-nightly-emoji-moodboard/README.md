# Emoji Moodboard Service\n\nA whimsical Dockerized Flask service that returns a single emoji representing the current time of day.\n\n## How it works\n\n- **Morning** (5‑11): 🌅\n- **Afternoon** (12‑17): 🌞\n- **Evening** (18‑20): 🌇\n- **Night** (21‑4): 🌙\n\n## Build & Run\n\n```sh\ndocker build -t emoji-moodboard .\ndocker run -p 5000:5000 emoji-moodboard\n```\n\n## API\n\n`GET /` returns JSON: `{\"emoji\":\"🌞\"}`
