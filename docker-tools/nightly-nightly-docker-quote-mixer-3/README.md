# Nightly Docker Quote Mixer\n\n## Overview\n\n`nightly-docker-quote-mixer` is a tiny, self‑contained Docker image that runs an HTTP server exposing a single endpoint `/quote`.  The server returns a JSON payload with a whimsical quote that blends apocalyptic flair with inspirational wisdom.  The quote is deterministic based on the `QUOTE_SEED` environment variable, making it perfect for testing or for generating repeatable daily mottos.\n\n## Build the image\n\n```bash\ndocker build -t quote-mixer .\n```\n\n## Run the container\n\n```bash\n# Example: deterministic quote with seed 3\ndocker run --rm -e QUOTE_SEED=3 -p 8080:8080 quote-mixer\n```\n\nThe server will start on port **8080**.  You can query it with:\n\n```bash\ncurl http://localhost:8080/quote\n```\n\n## Expected response\n\n```json\n{\n  "quote": "Stars burn brighter when the night is darkest."\n}\n```\n\n## Testing\n\nThe repository includes a Python `unittest` suite that mocks Docker commands to verify that the image builds successfully and that the container returns the expected quote for a given seed.  Run the tests with:\n\n```bash\npython -m unittest discover -s tests\n```\n\nEnjoy the blend of doom and hope!\n
