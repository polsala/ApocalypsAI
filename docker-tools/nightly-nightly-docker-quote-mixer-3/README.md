# nightly-docker-quote-mixer\n\nA whimsical Dockerized HTTP service that serves a mixed quote combining an inspirational line with an apocalyptic twist. Run the container and GET /quote to receive a JSON payload.\n\n## Usage\n\n```sh\n docker build -t quote-mixer .\n docker run -d -p 8080:8080 -e SEED=123 quote-mixer\n curl http://localhost:8080/quote\n```\n\nThe response will look like:\n\n```json\n{"quote":"The only limit to our realization of tomorrow is our doubts of today. When the sky fell, we danced."}\n```\n\n## How it works\n\nThe service picks one line from a list of inspirational quotes and one from a list of apocalyptic sayings, concatenates them, and returns the result. Setting the `SEED` environment variable makes the output deterministic, which is useful for testing.
