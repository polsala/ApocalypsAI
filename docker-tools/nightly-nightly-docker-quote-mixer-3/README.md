# Nightly Docker Quote Mixer\n\nA whimsical Dockerized HTTP service that returns a mixed quote combining an inspirational line with an apocalyptic twist.\n\n## Build\n\n```sh\n docker build -t nightly-quote-mixer .\n```\n\n## Run\n\n```sh\n docker run -p 8080:8080 nightly-quote-mixer\n```\n\n## Usage\n\nSend a GET request to `http://localhost:8080/mix` to receive a JSON payload:\n\n```json\n{\n  "quote": "The early bird catches the worm — The sky burns with neon ash."\n}\n```\n\n## How it works\n\nThe service picks one phrase from an *inspirational* list and one from an *apocalyptic* list, joins them with an em dash, and returns the result.\n\n## Testing\n\nRun the unit tests with:\n\n```sh\n pytest -q\n```
