# Nightly Docker Quote Mixer\n\nA whimsical Dockerized Flask service that returns a randomly mixed quote combining an inspirational saying with an apocalyptic twist.\n\n## Usage\n\n```sh\n# Build the Docker image\ndocker build -t nightly-quote-mixer .\n\n# Run the container (exposes port 5000)\ndocker run -p 5000:5000 nightly-quote-mixer\n```\n\nOnce the container is running, request a quote:\n\n```sh\ncurl http://localhost:5000/quote\n```\n\nExpected JSON response format:\n\n```json\n{\n  "quote": "Reach for the stars as the world crumbles"\n}\n```\n\n## How it works\n\nThe service picks one phrase from an *inspirational* list and one from an *apocalyptic* list, joins them with a space, and returns the result as the `quote` field in a JSON payload.
