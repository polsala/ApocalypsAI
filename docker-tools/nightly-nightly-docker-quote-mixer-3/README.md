# Nightly Docker Quote Mixer\n\nA whimsical Dockerized service that serves a random mixed quote combining an inspirational saying with an apocalyptic twist. Run the container and query `http://localhost:8080/quote` to receive a JSON payload.\n\n## Usage\n\n```sh\n# Build the Docker image\ndocker build -t quote-mixer .\n\n# Run the container (exposes port 8080)\ndocker run -p 8080:8080 quote-mixer\n```\n\nOnce the container is running, you can fetch a quote:\n\n```sh\ncurl http://localhost:8080/quote\n# Example output: {\"quote\":\"The early bird catches the worm - but the sky is falling!\"}\n```\n\n## How it works\n\nThe service is a tiny Flask app that picks one line from each of two hard‑coded lists and joins them with a dash. The implementation lives in `src/app.py`.\n\n## Files\n\n- `Dockerfile` – builds the container\n- `src/` – Python source code and requirements\n- `tests/` – deterministic offline tests for the app and Dockerfile
