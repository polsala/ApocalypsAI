# Nightly Docker Quote Mixer\n\nA tiny Docker container that prints a random whimsical quote each time it runs. Perfect for a quick morale boost in the apocalypse.\n\n## Build\n\n```sh\n docker build -t nightly-docker-quote-mixer .\n```\n\n## Run\n\n```sh\n docker run --rm nightly-docker-quote-mixer\n```\n\nYou can also run the script directly:\n\n```sh\n ./src/entrypoint.sh\n```\n\n## Adding quotes\n\nEdit `src/quotes.txt`, one quote per line.\n\n## Tests\n\n```sh\n bash tests/test_entrypoint.sh\n```
