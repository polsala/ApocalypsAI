# nightly-docker-quote-mixer\n\nA lightweight Docker container that serves a random mixed quote via a tiny Flask HTTP API.\n\n## How it works\n\nThe service keeps two internal lists – one of classic inspirational quotes and another of post‑apocalyptic one‑liners. When you request `/quote`, it picks one entry from each list and concatenates them with a \" – \" separator, yielding a whimsical mash‑up.\n\n## Build the image\n\n```bash\ndocker build -t nightly-docker-quote-mixer .\n```\n\n## Run the container\n\n```bash\ndocker run -d -p 5000:5000 --name quote-mixer nightly-docker-quote-mixer\n```\n\nThe service will be reachable at `http://localhost:5000/quote`.\n\n## Example request\n\n```bash\ncurl http://localhost:5000/quote\n```\n\nTypical response (JSON):\n\n```json\n{\n  "quote": "The only limit is your imagination – The sky is falling, but the fire still burns.\"\n}\n```\n\n## Testing\n\nThe repository includes a deterministic pytest suite that mocks the random choices so the output is predictable. Run the tests with:\n\n```bash\npytest -q\n```\n\n## License\n\nMIT
