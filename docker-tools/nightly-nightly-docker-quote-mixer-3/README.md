# nightly-docker-quote-mixer\n\nA whimsical Dockerized HTTP service that returns a randomly mixed quote combining an inspirational phrase with a sci‑fi line. Perfect for sprinkling apocalyptic optimism into your logs.\n\n## Usage\n\n```sh\n# Build the Docker image\ndocker build -t quote-mixer .\n\n# Run the container (exposes port 8080)\ndocker run -p 8080:8080 quote-mixer\n```\n\nOnce the container is running, request a mixed quote:\n\n```sh\ncurl http://localhost:8080/mix\n```\n\nExample response:\n\n```json\n{\n  "quote": "Stay hungry, my friend. The stars are waiting."\n}\n```\n\n## How it works\n\nThe service holds two short lists (inspirational, sci‑fi). On each request it picks one from each list and concatenates them.\n\n## Testing\n\n```sh\npython -m unittest discover -s tests\n```\n
