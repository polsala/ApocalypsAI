# nightly-docker-quote-mixer\n\nA tiny Docker image that prints a random whimsical quote each time it runs. Perfect for a quick smile in the apocalypse or to spice up CI logs.\n\n## Build the image\n\n```sh\ndocker build -t nightly-docker-quote-mixer .\n```\n\n## Run the container\n\n```sh\n# Get a random quote\ndocker run --rm nightly-docker-quote-mixer\n```\n\nYou can also request a deterministic quote (useful for testing) by passing an index (0‑based) as an argument:\n\n```sh\n# Always prints the first quote\ndocker run --rm nightly-docker-quote-mixer 0\n```\n\n## How it works\n\nThe image is based on Alpine Linux and contains a tiny shell script (`quote.sh`) that stores three hand‑picked apocalyptic quotes. When invoked without arguments it pipes the list through `shuf` (installed via `coreutils`) to select a random line. Supplying an index bypasses the randomness and prints the corresponding line directly.\n\n## License\n\nMIT – feel free to remix, redistribute, or use in your own post‑apocalyptic projects.
