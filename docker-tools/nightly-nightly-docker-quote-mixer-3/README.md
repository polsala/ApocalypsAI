# Nightly Docker Quote Mixer\n\nA tiny Docker container that mixes two themed quotes into a single whimsical line.\n\n## Build\n\n```sh\n docker build -t nightly-quote-mixer .\n```\n\n## Run\n\n```sh\n docker run --rm -e QUOTE1_IDX=0 -e QUOTE2_IDX=1 nightly-quote-mixer\n```\n\nThe environment variables `QUOTE1_IDX` and `QUOTE2_IDX` select which quote from each list (0‑based). If omitted, the first quote from each list is used.\n\n## How it works\n\nThe container ships a Bash script that reads two quote files and concatenates the selected lines.
