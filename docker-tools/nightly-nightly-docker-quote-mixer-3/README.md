# Quote Mixer Docker Service\n\nA tiny Dockerized Flask microservice that returns a whimsical mixed quote by combining two random sayings. Perfect for adding a splash of randomness to your dev environment or CI pipelines.\n\n## Build\n\n```sh\n docker build -t quote-mixer .\n```\n\n## Run\n\n```sh\n docker run -p 8080:8080 quote-mixer\n```\n\n## Use\n\n```sh\n curl http://localhost:8080/quote\n # Example output: \"When life gives you lemons, remember to stay humble.\"\n```\n\n## How it works\n\nThe service holds two hard‑coded lists of sayings. On each request it picks one element from each list and concatenates them with a friendly connector.\n
