# Nightly Docker Quote Mixer\n\nUtility that runs in a Docker container and returns a whimsical mixed quote via HTTP GET `/quote`. It combines an inspirational quote and an apocalyptic phrase.\n\n## Build & Run\n```sh\ndocker build -t quote-mixer .\ndocker run -p 8080:8080 -e QUOTE_SEED=42 quote-mixer\n```\n\n## Example\n```sh\ncurl http://localhost:8080/quote\n```\nResponse:\n```json\n{\"quote\": \"Your future is bright, but the sky is falling.\"}\n```\n\n## How it works\nThe container runs a tiny Flask app that selects one line from each of two hard‑coded lists. The selection is deterministic when the `QUOTE_SEED` environment variable is set, making testing easy.\n
