# nightly-docker-quote-mixer\n\nA tiny, whimsical Docker container that serves a random mixed quote.\n\n## What it does\n\n- Picks a random motivational phrase.\n- Picks a random sci‑fi phrase.\n- Joins them with an em‑dash and returns the result as JSON.\n\n## Build the image\n\n```bash\ndocker build -t nightly-docker-quote-mixer .\n```\n\n## Run the container\n\n```bash\ndocker run -p 5000:5000 nightly-docker-quote-mixer\n```\n\nThe service will listen on port **5000**.\n\n## Use the API\n\n```bash\ncurl http://localhost:5000/quote\n```\n\nTypical response:\n\n```json\n{\n  "quote": "Keep going — Quantum flux engaged"\n}\n```\n\n## Testing\n\nThe repository includes a deterministic unit test that patches the random choices. Run it with:\n\n```bash\npython -m unittest discover -s tests\n```\n\n## License\n\nMIT
