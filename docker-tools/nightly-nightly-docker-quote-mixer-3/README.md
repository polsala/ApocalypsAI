# Nightly Docker Quote Mixer\n\nA whimsical Dockerized service that serves a random mixed quote combining inspiration and apocalypse vibes.\n\n## Usage\n\n```sh\n# Build the Docker image\ndocker build -t quote-mixer .\n\n# Run the container (exposes port 8080)\ndocker run -p 8080:8080 quote-mixer\n```\n\nOnce the container is running, request a quote:\n\n```sh\ncurl http://localhost:8080/quote\n```\n\nTypical response:\n\n```json\n{\"quote\":\"Hope is a candle in a storm of ash.\"}\n```\n\n## How it works\n\nThe container runs a tiny Flask app that picks a random quote from a predefined list each request. No external network calls are made; everything is self‑contained inside the image.
