# Nightly Emoji Apocalypse Encoder\n\n## Overview\n\nThis Dockerized utility converts plain text into a fun, post‑apocalyptic emoji representation. It runs entirely inside a container, so you don\'t need any dependencies on your host machine.\n\n## Build the image\n\n```sh\ndocker build -t emoji-encoder .\n```\n\n## Run the encoder\n\n### Pass text as arguments\n\n```sh\ndocker run --rm emoji-encoder "Hello World"\n```\n\n### Pipe text via STDIN\n\n```sh\necho "Survive" | docker run --rm -i emoji-encoder\n```\n\nBoth commands will output a string of emojis that represent the input characters. Unknown characters are rendered as the ❓ emoji.\n\n## Example\n\n```sh\n$ docker run --rm emoji-encoder "Apocalypse"\n🅰️📧⚡⚡⚡🅿️⚡📧\n```\n\nEnjoy the whimsical cipher and may your messages survive the wasteland!\n
