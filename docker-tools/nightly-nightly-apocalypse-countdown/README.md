Apocalypse Countdown Service\n\nOverview\nThis utility provides a tiny web service, containerized with Docker, that returns the number of days remaining until a user‑specified date. It is themed for post‑apocalyptic fun – imagine a countdown to the end of the world, a rescue mission, or any personal deadline.\n\nHow it works\nThe service runs a Flask application exposing a single HTTP endpoint:/countdown?date=YYYY-MM-DD\nIt responds with a JSON payload containing the requested date and the integer days_remaining (which may be negative for past dates).\n\nBuilding the Docker image\nFrom the utility directory, run:\n    docker build -t apocalypse-countdown .\n\nRunning the container\n    docker run -p 8080:8080 apocalypse-countdown\nThe service will be reachable at http://localhost:8080/countdown.\n\nExample request\n    curl \"http://localhost:8080/countdown?date=2025-01-01\"\nResponse\n    {\n      "date": "2025-01-01",\n      "days_remaining": 365\n    }\n\nTesting\nThe repository includes a pytest suite that can be executed with:\n    pip install -r requirements.txt\n    pip install pytest\n    pytest\n\nLicense\nMIT
