# Apocalypse Countdown Docker Utility\n\n## Overview\n\n`nightly-apocalypse-countdown` is a tiny Docker container that, given an environment variable `END_DATE` (in `YYYY-MM-DD` format), prints a stylised countdown of days, hours and minutes remaining until that date.  If the optional `CURRENT_DATE` variable is supplied, it is used as the "now" reference – this makes the tool deterministic for testing.  When `CURRENT_DATE` is omitted the container uses the actual current UTC date.\n\n## Build the image\n\n```sh\ndocker build -t apocalypse-countdown .\n```\n\n## Run the container\n\n```sh\n# Example: count down to 31 Dec 2026\nexport END_DATE=2026-12-31\n# (optional) set CURRENT_DATE for reproducible output\nexport CURRENT_DATE=2026-12-01\n\ndocker run -e END_DATE -e CURRENT_DATE apocalypse-countdown\n```\n\nIf `CURRENT_DATE` is not set, the container will use the real current date.\n\n## Expected output\n\n```
⏳ Time until apocalypse: 30 days, 00 hours, 00 minutes\n```\n\n## Error handling\n\n- If `END_DATE` is missing or malformed the script exits with an error message.\n- If the specified `END_DATE` is in the past, the script reports that the apocalypse has already arrived.\n\n## Testing\n\nThe repository includes a Bash test suite that runs the script directly (no Docker required) to verify the core logic.  Run the tests with:\n\n```sh\nchmod +x tests/test_countdown.sh\n./tests/test_countdown.sh\n```\n\nAll tests should pass on any POSIX‑compatible shell.\n
