Nightly Docker Apocalypse Clock\n\nSummary: A tiny Docker container that converts any ISO8601 timestamp into the number of days that have passed since the fictional apocalypse start date (2023-01-01). It prints a whimsical message.\n\nUsage:\n1. Build the image:\n   docker build -t apocalypse-clock .\n2. Run the container with a timestamp argument:\n   docker run --rm apocalypse-clock 2023-12-31T12:00:00+00:00\n\nThe container will output something like:\nIt has been 364 days since the apocalypse began.\n\nThe utility includes unit tests for the core calculation logic.
