# Apocalypse Cocktail Generator\n\nA tiny utility that conjures a post‑apocalyptic cocktail recipe.\n\n## How it works\nThe program picks a random apocalypse scenario, a base spirit, a mixer and a garnish, then prints a nicely formatted recipe.\n\n## Running with Docker\n```bash\n# Build the image\ndocker build -t apocalypse-cocktail .\n\n# Run the container (optionally pass a numeric seed for deterministic output)\ndocker run --rm apocalypse-cocktail            # random recipe\ndocker run --rm apocalypse-cocktail 1          # deterministic recipe (seed=1)\n```\n\n## Running locally (for development)\n```bash\npython -m src.app            # random recipe\npython -m src.app 1          # deterministic recipe (seed=1)\n```\n\n## Testing\n```bash\npython -m unittest discover -s tests\n```\n\n## License\nMIT
