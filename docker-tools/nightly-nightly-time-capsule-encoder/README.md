# Time Capsule Encoder\n\nA tiny Docker‑wrapped utility that turns any text into a JSON "time capsule" containing the original message, a base64‑encoded payload and an ISO‑8601 UTC timestamp.\n\n## Usage\n\n```sh\n# Pipe a message\n echo "Your secret" | docker run --rm -i time‑capsule-encoder\n\n# Or pass it as an argument\n docker run --rm time‑capsule-encoder "Your secret"\n```\n\nThe container will output something like:\n\n```json\n{\n  "original": "Your secret",\n  "encoded": "WW91ciBzZWNyZXQ=",\n  "timestamp": "2023-10-31T14:23:45Z"\n}\n```\n\n## Building the image\n\n```sh\n docker build -t time‑capsule-encoder .\n```\n\n## License\n\nMIT
