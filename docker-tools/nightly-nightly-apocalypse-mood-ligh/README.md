Apocalypse Mood Light\n\nDescription:\nA tiny HTTP service packaged in a Docker container that returns a single post-apocalyptic mood quote. The quote is deterministic based on the QUOTE_SEED environment variable, making it useful for scripts or as a whimsical status endpoint.\n\nUsage:\n1. Build the image:\n   docker build -t apocalypse-mood-light .\n2. Run the container, optionally setting QUOTE_SEED:\n   docker run -d -e QUOTE_SEED=42 -p 8080:5000 apocalypse-mood-light\n3. Query the service:\n   curl http://localhost:8080/\n\nThe response is JSON, e.g. {"mood":"Dusty silence"}.\n\nImplementation details:\n- The service is written in Python using Flask.\n- The seed selects the quote by index = seed % number_of_quotes.
