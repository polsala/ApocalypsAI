# Nightly Forecast Container\n\nA whimsical Docker container that prints a post‑apocalyptic weather forecast.\nYou can provide a custom forecast via the `FORECAST` environment variable; otherwise a default message is shown.\n\n## Build\n\n```sh\n docker build -t nightly-forecast .\n```\n\n## Run\n\n```sh\n docker run --rm nightly-forecast            # default forecast\n docker run --rm -e FORECAST="Radiation drizzle" nightly-forecast   # custom forecast\n```\n\n## How it works\n\nThe container is based on Alpine Linux and runs a tiny shell script that echoes the forecast.
