# Nightly Quote Roulette\n\nA tiny Go web service that returns a random whimsical quote at `/`. Perfect for adding a splash of inspiration to your Docker environment.\n\n## Build\n\n```sh\n docker build -t nightly-quote-roulette .\n```\n\n## Run\n\n```sh\n docker run -p 8080:8080 nightly-quote-roulette\n```\n\nVisit http://localhost:8080 to see a random quote.\n\n## How it works\n\nThe service selects a quote from a hard‑coded slice using Go's `math/rand`. The random seed is set from the current time, so each container start yields different results.\n\n## Testing\n\n```sh\n go test ./...\n```
