# nightly-zipline-compressor\n\nDockerized utility that zips a directory and reports the compression ratio with whimsical commentary.\n\n## Usage\n\n```sh\n# Build the Docker image\ndocker build -t zipline .\n\n# Run the container, mounting the directory you want to compress\n# Replace $(pwd)/data with the path to your source directory\n# The container will create /output/archive.zip inside the container and print a report\n\nmkdir -p output\n\n# Example: compress the ./data folder and write the zip to ./output/archive.zip\n# The host directory ./data is mounted to /data inside the container\n# The host directory ./output is mounted to /output inside the container\n\n# If you omit the output argument, the zip will be created as /data.zip inside the container\n\n# Build the image (once)\n# docker build -t zipline .\n\n# Run the container\n# docker run --rm -v $(pwd)/data:/data -v $(pwd)/output:/output zipline /data /output/archive.zip\n```\n\nIf the output path is omitted, the zip will be created as `/data.zip` inside the container.\n\n## How it works\n\nThe container runs a small Python script that walks the input directory, adds every file to a zip archive, computes the total original size and the compressed size, and prints a fun, post‑apocalyptic‑themed message with the compression ratio.\n\n## License\n\nMIT\n
