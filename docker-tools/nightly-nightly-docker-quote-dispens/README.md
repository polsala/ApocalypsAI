Nightly Docker Quote Dispenser\n\nDescription:\nA tiny Docker container that prints a whimsical quote each time it is run. The quote is chosen at random unless you set the QUOTE_INDEX environment variable to select a specific one.\n\nBuild the image:\n  docker build -t quote-dispenser .\n\nRun the container (random quote):\n  docker run --rm quote-dispenser\n\nRun the container with a specific quote (0‑based index):\n  docker run --rm -e QUOTE_INDEX=2 quote-dispenser\n\nThe container is based on Alpine Linux and uses a small Bash script to store and select quotes. Feel free to extend the list in src/quote.sh.\n
