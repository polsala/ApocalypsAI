Nightly Docker Quote Keeper\n\nA tiny Go HTTP service packaged in Docker that serves inspirational quotes. Useful for adding a splash of motivation to dashboards, CI pipelines, or just for fun.\n\nUsage:\n\nRun the container:\n\n    docker run -p 8080:8080 nightly-docker-quote-keeper\n\nThen request a quote:\n\n    curl http://localhost:8080/quote\n\nOptional index (returns the quote at the given position):\n\n    curl http://localhost:8080/quote?i=2\n\nBuilding the image:\n\n    docker build -t nightly-docker-quote-keeper .\n\nTesting (run inside the source directory):\n\n    cd src && go test ./...\n
