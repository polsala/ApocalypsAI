Nightly Docker QR Code Service\n\nUtility that runs in a Docker container and provides an HTTP endpoint to generate QR code PNG images from a supplied text query. Useful for quick QR generation without installing anything locally.\n\nUsage:\n1. Build the image: docker build -t nightly-docker-qr-code-service .\n2. Run the container: docker run -p 8080:8080 nightly-docker-qr-code-service\n3. Access: http://localhost:8080/qr?text=Hello%20World\n\nThe endpoint returns image/png.\n
