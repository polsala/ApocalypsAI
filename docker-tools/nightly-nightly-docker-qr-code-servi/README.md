# nightly-docker-qr-code-service\n\nA lightweight Docker container that runs a Flask web service to generate QR code PNG images on‑the‑fly.\n\n## How it works\n\n* The container runs a small Python Flask app.\n* Send a GET request to `/qr?text=YOUR_TEXT`.\n* The service returns a `image/png` response containing the QR code for the supplied text.\n\n## Running the container\n\n```bash\n# Build the image\ndocker build -t qr-code-service .\n\n# Run the container (exposes port 5000)\ndocker run -p 5000:5000 qr-code-service\n```\n\n## Example request\n\n```bash\ncurl -s http://localhost:5000/qr?text=Hello%20World --output hello.png\n```\n\nOpen `hello.png` with any image viewer – you should see a QR code that encodes "Hello World".\n\n## Testing\n\nThe repository includes a deterministic test suite that runs the Flask app in‑process and verifies that the PNG header is correct. Run the tests with:\n\n```bash\npython -m pytest tests\n```\n\n## License\n\nMIT
