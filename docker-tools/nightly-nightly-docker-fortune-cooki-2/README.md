# nightly-docker-fortune-cookie\n\nA tiny Docker image that runs a lightweight HTTP server.  When you request `GET /fortune` it returns a random, post‑apocalyptic fortune cookie message in JSON.  Perfect for adding a splash of humor to your CI pipelines, dev environments, or just for fun.\n\n## Build the image\n\n```sh\ndocker build -t apocalypse-fortune .\n```\n\n## Run the container\n\n```sh\n# Expose port 8080 on the host\ndocker run --rm -p 8080:8080 apocalypse-fortune\n```\n\nThe server will start and listen on port **8080**.  You can query a fortune with:\n\n```sh\ncurl http://localhost:8080/fortune\n```\n\nExample output:\n\n```json\n{\n  "fortune": "Remember: even mutants need coffee."\n}\n```\n\n## How it works\n\nThe image is based on the tiny `python:3.11-alpine` base image.  It copies a single Python script (`src/fortune_server.py`) that implements a minimal HTTP server using the standard library.  No external dependencies are required.\n\n## Testing\n\nThe repository includes a Python test suite that mocks Docker commands to verify that the build and run invocations are correct.  Run the tests with:\n\n```sh\npython -m unittest discover -s tests\n```\n\nEnjoy the fortunes!
