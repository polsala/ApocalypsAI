# Nightly Dockerfile Generator\n\nA whimsical utility that creates a Dockerfile with post‑apocalyptic themed comments for a given base image. Useful for quickly scaffolding containers while adding a touch of fun.\n\n## Usage\n\n```sh\n./src/generator.sh <base-image> [app]\n```\n- `<base-image>`: Docker base image (e.g., `alpine`, `python:3.11-slim`).\n- `[app]` (optional): `python` or `node`. Defaults to a minimal shell echo.\n\nThe script prints the Dockerfile to stdout.\n\n## Example\n\n```sh\n./src/generator.sh alpine python\n```\nProduces a Dockerfile that installs Python and runs a hello world script, with random apocalypse‑flavored comments.\n
