# nightly‑dc‑visualizer\n\n**What it does**\n\n`nightly‑dc‑visualizer` reads a `docker‑compose.yml` file and prints a tiny ASCII diagram showing each service and the services it depends on. It works with the most common subset of Compose files (service names and a `depends_on` list).\n\n**Why it is useful**\n\nWhen you have a handful of services, a quick visual overview helps you understand the startup order and spot missing dependencies without opening the full YAML file.\n\n**How to use**\n\n```bash\n# Build the Docker image\ndocker build -t nightly‑dc‑visualizer .\n\n# Run the visualizer against a compose file in the current directory\n# (the file is mounted into the container at /app)\ndocker run --rm -v $(pwd):/app nightly‑dc‑visualizer /app/docker‑compose.yml\n```\n\n**Example**\n\nGiven a `docker‑compose.yml` like:\n\n```yaml\nweb:\n  image: nginx\n  depends_on:\n    - db\n    - cache\n\ndb:\n  image: postgres\n\ncache:\n  image: redis\n```\n\nRunning the visualizer prints:\n\n````\nweb\n  └─ db\n  └─ cache\ndb\ncache\n````\n\n**Limitations**\n\n* Only service names (top‑level keys) and a simple `depends_on` list are parsed.\n* Nested extensions, conditionals, or complex YAML features are ignored.\n\n**Implementation**\n\nThe tool is a tiny Python script (`src/visualizer.py`) that uses regular expressions to extract service blocks and their dependencies, then prints an ASCII tree. The Docker image is based on `python:3.11‑slim` and contains only the script – no extra packages are required.\n
