# nightly-docker-emoji-clock

**What it does**

Runs a lightweight Docker container that prints the current UTC time as a clock‑face emoji (e.g., 🕒 for 3 o’clock, 🕟 for 4:30).  Great for adding a whimsical timestamp to CI logs, chat messages, or just for fun.

**How to use**

```bash
# Pull the image (once) – replace <repo> with your Docker registry if you push it
docker build -t nightly-docker-emoji-clock .

# Run the container – it prints a single emoji and exits
docker run --rm nightly-docker-emoji-clock
```

**Example output**

```
🕒
```

**Implementation details**

The container is based on `python:3.11‑slim`.  The core logic lives in `src/clock.py` and maps the current UTC hour/minute to the nearest full‑hour or half‑hour clock emoji.

**Testing**

Unit tests live in `tests/test_clock.py` and can be run locally without Docker:

```bash
python -m unittest discover -s tests
```
