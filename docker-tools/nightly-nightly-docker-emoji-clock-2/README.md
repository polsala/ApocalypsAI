# nightly-docker-emoji-clock\n\nA tiny Docker image that prints a clock‑face emoji representing the current hour.\n\n## How it works\n\nThe image is built on `python:3.11‑slim` and contains a single Python script (`emoji_clock.py`). When the container starts it runs the script, which reads the system time, maps the hour to the appropriate Unicode clock emoji (🕐‑🕛) and prints it to stdout.\n\n## Build the image\n\n```bash\ndocker build -t emoji-clock .\n```\n\n## Run the container\n\n```bash\ndocker run --rm emoji-clock\n```\n\nYou should see something like:\n\n```
🕒\n```\n\n## Why?\n\nBecause every apocalypse needs a reminder of the passing time, and emojis make it fun.\n\n## Files\n\n- `Dockerfile` – builds the image.\n- `src/emoji_clock.py` – the runtime script.\n- `tests/test_emoji_clock.py` – deterministic unit tests (no Docker required).\n
