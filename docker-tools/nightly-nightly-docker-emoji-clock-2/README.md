# Nightly Docker Emoji Clock\n\nUtility that prints the current hour as a Unicode clock‑face emoji. Packaged as a minimal Docker image (Alpine) so you can drop it into CI pipelines or just have fun.\n\n## Usage\n\n```sh\n# Build the image\ndocker build -t emoji-clock .\n\n# Run and show the current hour (uses the container's TZ or host TZ)\ndocker run --rm -e TZ=UTC emoji-clock\n\n# Force a specific hour for testing (e.g., 13 => 🕐)\ndocker run --rm emoji-clock 13\n```\n\nThe script also accepts an optional numeric argument to specify the hour (0‑23) for testing.
