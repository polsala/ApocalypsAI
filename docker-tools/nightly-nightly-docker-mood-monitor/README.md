# Nightly Docker Mood Monitor\n\n## Whimsical Utility: Container Companion\n\nThe Nightly Docker Mood Monitor is a delightful little utility that peeks into your Docker containers and assigns them a "mood" based on their current status and resource usage (CPU, Memory). Ever wondered if your database container is feeling "Anxious" or your web server is "Energetic"? Now you'll know!\n\nThis tool is designed to provide a quick, at-a-glance, and slightly whimsical overview of your container ecosystem's well-being. It can also suggest actions based on these moods, helping you keep your digital companions happy and healthy.\n\n## Features\n\n*   **Mood Assignment**: Assigns moods like "Energetic", "Sleepy", "Anxious", "Content", "Grumpy", or "Confused" based on real-time (or mocked) container stats.\n*   **Status Reporting**: Clearly displays each container's name, ID, and its current mood.\n*   **Action Suggestions**: Provides gentle nudges for containers that might need attention (e.g., "Perhaps a restart would cheer it up?").\n*   **Containerized**: Runs as a Docker container itself, making it easy to deploy alongside your other services.\n\n## How to Use\n\n### Prerequisites\n\n*   Docker installed and running on your host machine.\n*   The Docker daemon socket exposed (usually `/var/run/docker.sock`) for the monitor container to access.\n\n### Build the Docker Image\n\nNavigate to the `docker-tools/nightly-docker-mood-monitor` directory and build the image:\n\n```bash\ndocker build -t nightly-docker-mood-monitor .\n```\n\n### Run the Monitor\n\nTo run the monitor and see your containers' moods:\n\n```bash\ndocker run --rm -v /var/run/docker.sock:/var/run/docker.sock nightly-docker-mood-monitor\n```\n\nThis command mounts the Docker socket into the monitor container, allowing it to communicate with the Docker daemon on your host. The `--rm` flag ensures the container is removed after it exits.\n\n### Example Output\n\n```\n--- Docker Container Mood Report ---\nContainer: my-web-app (ID: abc123def456) is feeling Energetic! (CPU: 85.23%, Mem: 30.15%) - It's buzzing with activity!\nContainer: my-database (ID: fedcba987654) is feeling Anxious! (CPU: 15.78%, Mem: 90.01%) - It might need more memory to relax.\nContainer: my-worker (ID: 1a2b3c4d5e6f) is feeling Deeply Sleepy! (CPU: 5.00%, Mem: 10.00%) - Resting peacefully, barely a whisper.\nContainer: my-old-service (ID: 7890abc123de) is feeling Grumpy! (Status: exited) - Perhaps a restart would cheer it up?\n```\n\n## Development and Testing\n\n### Local Development\n\nYou can run the Python script directly if you have `docker-py` installed and access to a Docker daemon:\n\n```bash\npip install -r src/requirements.txt\npython src/mood_monitor.py\n```\n\n### Running Tests\n\nTests are self-contained and use `unittest.mock` to simulate Docker API interactions, ensuring determinism and offline execution.\n\n```bash\npython -m unittest tests/test_mood_monitor.py\n```\n\n## Configuration (Future Enhancements)\n\n*   Thresholds for CPU/Memory usage could be configurable via environment variables.\n*   Specific actions (e.g., `docker restart`) could be triggered for certain moods.\n*   Integration with notification systems.
