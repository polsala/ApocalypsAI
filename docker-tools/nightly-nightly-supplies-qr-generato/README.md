# Supplies QR Generator\n\nGenerate a QR code PNG that encodes a JSON array of your survival supplies. Handy for labeling boxes, backpacks, or caches.\n\n## Usage\n\n```sh\n# Build the Docker image\n docker build -t supplies-qr .\n\n# Run the container, mounting the current directory so you can read/write files\n docker run --rm -v "$(pwd)":/data supplies-qr python /app/src/main.py -i supplies.json -o supplies_qr.png\n```\n\nIf no input file is given, the utility reads JSON from STDIN.\n\n## Example\n\n```json\n[\"canned beans\",\"water bottles\",\"first aid kit\"]\n```\n\nRunning the above will produce `supplies_qr.png` containing a scannable QR code.
