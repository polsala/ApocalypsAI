# nightly-docker-rot13\n\nA lightweight Docker container that reads text from **STDIN**, applies the classic ROT13 cipher, and writes the transformed text to **STDOUT**.\n\n## Why ROT13?\n\n* Fun and whimsical – great for secret messages in CI logs.\n* No external dependencies – just a tiny Alpine image with `bash` and `tr`.\n\n## Usage\n\n```bash\n# Direct echo\n echo "Hello World!" | docker run --rm ghcr.io/your-org/nightly-docker-rot13\n#=> Uryyb Jbeyq!\n\n# From a file\n cat secret.txt | docker run --rm ghcr.io/your-org/nightly-docker-rot13 > encoded.txt\n```\n\n## Building the Image\n\n```bash\ndocker build -t nightly-docker-rot13 .\n```\n\n## Running the Tests\n\n```bash\npython -m pytest tests\n```\n\n## License\n\nMIT License – see LICENSE file in the repository.\n
