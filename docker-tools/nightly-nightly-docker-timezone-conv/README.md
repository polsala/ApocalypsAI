# Nightly Docker Timezone Converter\n\nA whimsical yet handy utility that runs inside a Docker container. It converts a given timestamp from one IANA time zone to another using only Python's standard library (zoneinfo).\n\n## Build the image\n\n```bash\ndocker build -t timezone-converter .\n```\n\n## Run the converter\n\n```bash\n# Convert 2023-10-31 15:00 from New York to London\ndocker run --rm timezone-converter \\\"2023-10-31 15:00\\\" America/New_York Europe/London\n```\n\nThe container will print the converted timestamp in ISO‑8601 format, e.g.:\n\n``\n2023-10-31T20:00:00+00:00\n``\n\n## How it works\n\nThe image is based on `python:3.11-slim`. The entrypoint runs `src/convert.py` which parses the arguments, loads the source and target zones via `zoneinfo.ZoneInfo`, and outputs the converted time.\n\n## Tests\n\nA simple Bash test builds the image, runs a conversion, and asserts the output. Run it with:\n\n```bash\n./tests/test_convert.sh\n```\n\n## License\n\nMIT
