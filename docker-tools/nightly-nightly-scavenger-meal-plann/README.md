# Nightly Scavenger Meal Planner\n\nA whimsical Dockerized utility that, given a list of pantry ingredients, suggests a post‑apocalypse‑ready recipe.\n\n## How it works\n\nThe container reads an `ingredients.txt` file (one ingredient per line) and prints a recipe that can be made with the available items.\n\n## Usage\n\n```sh\n# Create an ingredients file\necho -e "beans\\nrice\\nwater" > ingredients.txt\n\n# Build the Docker image (once)\ndocker build -t scavenger-meal-planner .\n\n# Run the planner\ndocker run --rm -v $(pwd)/ingredients.txt:/app/ingredients.txt scavenger-meal-planner\n```\n\n## Expected output\n\n````\nRecipe: Bean Rice Stew (needs: beans, rice, water)\n````\n
