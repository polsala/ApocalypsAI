# Nightly Scavenger Meal Planner\n\n**Utility**: Given a list of available pantry items, this Docker‑wrapped tool suggests a whimsical survival recipe.\n\n## How it works\n1. Provide an `ingredients.txt` file (one ingredient per line).\n2. Build the Docker image.\n3. Run the container – it reads `/app/ingredients.txt` and prints a suggested recipe or a friendly “no match” message.\n\n## Build the image\n```sh\ndocker build -t scavenger-meal-planner .\n```\n\n## Run the container\n```sh\n# Place your ingredients list in the current directory\ncat > ingredients.txt <<EOF\nnoodles\nwater\nspice\nEOF\n\n# Run the container, mounting the file into /app\ndocker run --rm -v $(pwd)/ingredients.txt:/app/ingredients.txt scavenger-meal-planner\n```\n\n## Expected output\n```
Suggested recipe: Radiation Ramen\n```\n\nIf no recipe matches, you will see:\n```
No matching recipe found. Consider foraging.\n```\n\n## Whimsical recipes included\n- **Radiation Ramen** – noodles, water, spice\n- **Mutant Stew** – beans, carrot, salt\n- **Canned Chili** – canned beans, canned tomatoes, chili powder\n\n## Testing\nRun the unit tests with:\n```sh\npython -m unittest discover -s tests\n```\n
