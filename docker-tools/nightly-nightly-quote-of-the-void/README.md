# nightly-quote-of-the-void\n\nA whimsical Docker container that prints a post‑apocalyptic quote when run.\n\n## Usage\n\n```sh\n# Build the image\ndocker build -t nightly-quote-of-the-void .\n\n# Run the container (default quote)\ndocker run --rm -e QUOTE_INDEX=0 nightly-quote-of-the-void\n```\n\nSet `QUOTE_INDEX` (0‑based) to choose a different quote. If omitted, defaults to 0.\n\n## How it works\n\nThe image is based on Alpine Linux and runs a tiny Bash script that selects a quote from an internal list.\n
