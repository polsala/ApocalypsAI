Dockerfile Size Estimator\n\nThis utility estimates the size of a Docker image based on its Dockerfile.\nIt uses a small heuristic database of base image sizes and assumes a fixed\nsize for each RUN, COPY, or ADD instruction.\n\nUsage:\n  docker build -t size-estimator .\n  docker run --rm -v $(pwd):/workspace size-estimator /workspace/Dockerfile\n\nThe tool prints the estimated total size in megabytes.
