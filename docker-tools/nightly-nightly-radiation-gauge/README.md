# Radiation Gauge\n\nA whimsical Dockerized web service that shows a post‑apocalypse radiation level gauge.\n\n## How it works\n\nThe service runs a tiny Flask app. When you visit the root URL it displays a gauge with a radiation level between 0 % and 100 %. You can force a specific level with the `level` query parameter, e.g. `http://localhost:8080/?level=42`.\n\n## Build & run\n\n```sh\n docker build -t radiation-gauge .\n docker run -p 8080:8080 radiation-gauge\n```\n\nThen open http://localhost:8080 in your browser.\n\n## Testing\n\n```sh\n pip install -r requirements.txt pytest\n pytest -q\n```
