Nightly Quote Mixer\n\nA whimsical Dockerized microservice that returns a randomly mixed quote combining a motivational phrase with a sci‑fi line. Useful for adding flavor to dashboards, bots, or terminal greetings.\n\nUsage:\n1. Build the image:\n   docker build -t quote-mixer .\n2. Run the container:\n   docker run -p 8080:8080 quote-mixer\n3. Request a quote:\n   curl http://localhost:8080/quote\n\nExample response:\n{\"quote\":\"Reach for the stars, but watch out for black holes.\"}\n\nHow it works:\nThe service runs a tiny Flask app that selects one line from each of two hard‑coded lists and concatenates them.\n\nTesting:\nRun the test script:\n   bash tests/test_docker_build.sh
