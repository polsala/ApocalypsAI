# Nightly Quote Mixer\n\nA tiny Docker‑wrapped Flask service that serves a whimsical quote.\n\n## How it works\n\nThe service exposes a single HTTP endpoint:`/quote?seed=<number>`\n\n* The `seed` query parameter selects a quote from an internal list.\n* If `seed` is omitted, it defaults to `0`.\n* The response is a JSON object: `{\"quote\": \"...\"}`\n\n## Build the image\n\n```bash\ndocker build -t nightly-quote-mixer .\n```\n\n## Run the container\n\n```bash\ndocker run -d -p 5000:5000 --name qm nightly-quote-mixer\n```\n\nNow you can query it:\n\n```bash\ncurl http://localhost:5000/quote?seed=2\n```\n\n## Testing\n\nA simple integration test is provided in `tests/test_container.sh`. It builds the image, runs the container, queries the service and verifies the output.\n\n```bash\ncd tests && bash test_container.sh\n```\n\n## License\n\nMIT
