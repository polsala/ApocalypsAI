# Nightly Quote Mixer\n\nA whimsical Dockerized service that returns a randomly mixed quote combining an uplifting line with an apocalyptic twist.\n\n## Usage\n\n```sh\ndocker build -t nightly-quote-mixer .\ndocker run -p 8080:8080 nightly-quote-mixer\n```\n\nThen request a quote:\n\n```sh\ncurl http://localhost:8080/quote\n```\n\nExample output:\n\n```
\"Keep calm and carry on. The sky is falling!\"\n```\n\n## How it works\n\nThe service runs a tiny Flask app that picks one phrase from an *inspirational* list and one from an *apocalyptic* list, concatenates them, and returns the result as plain text.\n\n## Testing\n\nRun the unit tests locally:\n\n```sh\npython -m unittest discover -s tests\n```
