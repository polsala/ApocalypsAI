# nightly-quote-mixer\n\nA whimsical Dockerized HTTP service that returns a randomly mixed inspirational‑apocalyptic quote.\n\n## Build\n\n```sh\n docker build -t nightly-quote-mixer .\n```\n\n## Run\n\n```sh\n docker run -p 8080:8080 nightly-quote-mixer\n```\n\n## Usage\n\n```sh\n curl http://localhost:8080/quote\n # {\"quote\":\"...\"}\n```\n\nThe service picks one line from an inspirational list and one from an apocalyptic list, concatenates them, and returns the result as JSON.
