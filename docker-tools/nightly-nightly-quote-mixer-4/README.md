# nightly‑quote‑mixer\n\nA tiny, containerized HTTP service that serves a random "mixed" quote – an inspirational line blended with a sci‑fi line. Perfect for adding a splash of optimism and futurism to your dev environment, CI pipelines, or just for fun.\n\n## Features\n\n- Runs in a lightweight Docker container (≈15 MB).\n- Single endpoint `GET /quote` returning JSON `{\"quote\": \"...\"}`.\n- No external network calls – all quotes are baked into the binary.\n- Deterministic unit tests using Go's standard library.\n\n## Build the image\n\n```bash\n# Clone the repository (or copy the generated folder)\ngit clone <repo‑url>\ncd utils/docker-tools/nightly-quote-mixer\n\n# Build the Docker image\ndocker build -t nightly‑quote‑mixer .\n```\n\n## Run the container\n\n```bash\n# Run and expose port 8080\ndocker run -d -p 8080:8080 --name quote-mixer nightly‑quote‑mixer\n\n# Test it\ncurl http://localhost:8080/quote\n```\n\nYou should see output similar to:\n\n```json\n{\"quote\": \"Believe you can and you're halfway there. – Live long and prosper.\"}\n```\n\n## Development\n\nThe service is written in Go (standard library only). To develop locally without Docker:\n\n```bash\ncd src\ngo run .\n```\n\nThen visit `http://localhost:8080/quote`.\n\n## Testing\n\n```bash\ncd src\ngo test ./...\n```\n\nAll tests run offline and are deterministic.\n\n## License\n\nMIT – see LICENSE file in the repository root.\n
