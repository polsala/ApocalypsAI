# Nightly Quote Mixer\n\nA tiny Dockerized Go HTTP service that returns a whimsical mixed quote at /quote.\n\nHow it works:\nThe service combines a random inspirational quote with a random apocalyptic phrase and returns them as JSON:\n{ "quote": "Every cloud has a silver lining. The end is just a new beginning." }\n\nBuild & Run:\ndocker build -t nightly-quote-mixer .\ndocker run -p 8080:8080 nightly-quote-mixer\n\nThen visit http://localhost:8080/quote\n\nTesting:\ngo test ./...\n
