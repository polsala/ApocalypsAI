# Nightly Quote Mixer\n\nA whimsical yet useful Dockerized service that serves mixed inspirational and apocalyptic quotes.\n\n## How it works\n\nThe service runs a small Flask app inside a Docker container.  It exposes a single endpoint:\n\n```
GET /quote?seed=<integer>\n```\n\nThe `seed` query parameter is used to deterministically pick one inspirational quote and one apocalyptic quote, concatenate them, and return the result as JSON.  If `seed` is omitted or invalid, it defaults to `0`.\n\n## Building the image\n\n```bash\ndocker build -t nightly-quote-mixer .\n```\n\n## Running the container\n\n```bash\n# Run and expose on host port 8080\ndocker run -d -p 8080:8080 nightly-quote-mixer\n```\n\n## Example request\n\n```bash\ncurl http://localhost:8080/quote?seed=42\n```\n\nExpected response (deterministic):\n\n```json\n{\n  "quote": "Dream big and dare to fail. The end is just a new beginning in disguise."\n}\n```\n\n## Testing\n\nA simple Bash test script is provided under `tests/test.sh`. It builds the image, runs the container, queries the endpoint with a known seed, and verifies the output.\n\n```bash\ncd tests && ./test.sh\n```\n\n## License\n\nMIT
