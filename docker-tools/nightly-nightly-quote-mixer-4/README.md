# Nightly Quote Mixer\n\nA lightweight Docker container that serves a random mixed quote (inspirational + apocalyptic) via a simple HTTP API.\n\n## Features\n- No external dependencies beyond Flask (included in the image)\n- Deterministic unit tests with mocked randomness\n- One‑liner Docker build and run commands\n\n## Build the image\n```bash\ndocker build -t nightly-quote-mixer .\n```\n\n## Run the container\n```bash\ndocker run -p 8080:8080 nightly-quote-mixer\n```\n\nThe service will listen on port **8080**.\n\n## Get a quote\n```bash\ncurl http://localhost:8080/quote\n```\n\nExample response:\n```json\n{\n  "quote": "Dream big and dare to fail. — When the sky falls, we shall dance."\n}\n```\n\n## Testing\nRun the Python tests locally (Docker is not required for unit tests):\n```bash\npython -m unittest discover -s tests\n```\n\n## License\nMIT
