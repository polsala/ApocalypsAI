# Nightly Quote Mixer\n\nA whimsical Dockerized HTTP service that returns a mixed quote combining a random opening phrase and a random ending phrase.\n\n## Usage\n\n```sh\n# Build the Docker image\ndocker build -t nightly-quote-mixer .\n\n# Run the container (exposes port 8080)\ndocker run -p 8080:8080 nightly-quote-mixer\n```\n\nThe service listens on port **8080** and provides a single endpoint:\n\n```sh\ncurl http://localhost:8080/quote\n```\n\nExample response:\n\n```json\n{\n  "quote": "When the moon whispers, the stars sing lullabies."\n}\n```\n\n## How it works\n\nThe container runs a tiny Python HTTP server that selects one opening and one closing phrase at random and concatenates them. The implementation lives in `src/app.py`.\n\n## License\n\nMIT
