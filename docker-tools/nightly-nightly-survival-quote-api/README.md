# Survival Quote API\n\nA tiny Dockerized Flask service that serves a daily survival‑style quote.\n\n## How it works\n\nThe service reads a list of quotes from `quotes.txt` and returns one based on the `QUOTE_INDEX` environment variable (default 0). This makes the output deterministic for testing.\n\n## Build & Run\n\n```sh\n docker build -t survival-quote .\n docker run -e QUOTE_INDEX=0 -p 5000:5000 survival-quote\n```\n\nVisit `http://localhost:5000/quote` to see the JSON response.\n\n## Testing\n\n```sh\n cd tests\n bash test.sh\n```
