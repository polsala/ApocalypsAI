# Survival Tip Server\n\nA lightweight Dockerized Flask server that returns a random post‑apocalyptic survival tip at `/tip`. Perfect for adding a daily dose of whimsy to your dev environment.\n\n## Build\n\n```sh\n docker build -t survival-tip-server .\n```\n\n## Run\n\n```sh\n docker run -p 8080:8080 survival-tip-server\n```\n\n## Use\n\n```sh\n curl http://localhost:8080/tip\n```\n\nWill return a JSON object, e.g. `{\"tip\":\"Always keep a spare can‑opener in your backpack.\"}`.
