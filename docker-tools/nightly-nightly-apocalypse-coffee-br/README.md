# Nightly Apocalypse Coffee Brewer\n\nA tiny Dockerized utility that serves whimsical coffee brewing instructions for the end of days. Build the image and run to get a random (or specified) coffee style with a fun tagline.\n\n## Usage\n\n```bash\n# Build the Docker image\ndocker build -t apocalypse-coffee .\n\n# Run for a random coffee style\ndocker run --rm apocalypse-coffee\n\n# Run for a specific style (e.g., espresso)\ndocker run --rm apocalypse-coffee espresso\n```\n\nThe script will print an ASCII‑art coffee cup and a message like "Brewing a Drip for the apocalypse!".
