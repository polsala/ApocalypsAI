# nightly-docker-ansi-art-server\n\nA whimsical yet useful utility that runs inside a Docker container and serves a random ANSI art piece on every HTTP request. Perfect for adding a splash of retro terminal art to your web pages, dashboards, or just for fun.\n\n## Features\n\n- Small footprint (multi‑stage Go build)\n- No external dependencies at runtime\n- Returns plain‑text ANSI art with proper escape codes\n- Deterministic list of art pieces (easy to extend)\n\n## Usage\n\n```bash\n# Build the image\ndocker build -t ansi-art-server .\n\n# Run the container (exposes port 8080)\ndocker run -d -p 8080:8080 --name ansi-art ansi-art-server\n\n# Fetch a random piece of art\ncurl http://localhost:8080/\n```\n\nEach request to `http://<host>:8080/` returns a different piece of ANSI art selected uniformly at random.\n\n## Development\n\nThe server is written in Go. To run it locally without Docker:\n\n```bash\ngo run src/main.go\n```\n\nThen visit `http://localhost:8080/`.\n\n## Testing\n\nRun the Go test suite:\n\n```bash\ngo test ./...\n```\n\nAll tests are deterministic and do not require network access.\n
