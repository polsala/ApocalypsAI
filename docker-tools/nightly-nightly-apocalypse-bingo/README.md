# Apocalypse Bingo\n\nGenerate a 5x5 Bingo card filled with post‑apocalyptic phrases. The utility runs inside a Docker container for easy, reproducible use.\n\n## Usage\n\n```sh\n# Build the image\ndocker build -t apocalypse-bingo .\n\n# Run the container (optional SEED for deterministic output)\ndocker run --rm -e SEED=123 apocalypse-bingo\n```\n\nIf `SEED` is not set, the card is random.\n\n## How it works\n\nThe container runs a small Python script that selects 24 unique phrases from a built‑in list, places a "FREE" space in the center, and prints the grid.
