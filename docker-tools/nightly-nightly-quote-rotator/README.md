# Nightly Quote Rotator\n\nA whimsical Dockerized HTTP service that returns a random quote on each request.\n\n## Build\n\n```sh\n docker build -t nightly-quote-rotator .\n```\n\n## Run\n\n```sh\n docker run -p 8080:8080 nightly-quote-rotator\n```\n\n## Usage\n\n```sh\n curl http://localhost:8080/quote\n```\n\nResponse example:\n\n```json\n {\n   "quote": "The early bird gets the worm, but the second mouse gets the cheese."\n }\n```\n\n## How it works\n\nThe service uses a small Flask app with a hard‑coded list of whimsical quotes. Each request selects a random entry.
