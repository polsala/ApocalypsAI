# Nightly Docker Quote Generator\n\nA whimsical Dockerized utility that fetches a random inspirational quote from an online API and displays it in the container's stdout. Perfect for a quick morale boost during post‑apocalyptic coding sessions.\n\n## Usage\n\n```bash\n# Build the Docker image\ndocker build -t nightly-quote .\n\n# Run the container (it will print a quote and exit)\ndocker run --rm nightly-quote\n```\n\nThe container will output a quote like:\n\n```
\"Stay hungry, stay foolish.\"\n— Steve Jobs\n```\n\n## How it works\n\nThe image runs a tiny Python script that calls the public API `https://api.quotable.io/random`. If the request fails, a fallback quote is shown.\n\n## Files\n- `Dockerfile` – builds the container\n- `requirements.txt` – Python dependencies\n- `src/app.py` – the quote‑fetching script\n- `tests/test_app.py` – deterministic offline tests using mocks\n
