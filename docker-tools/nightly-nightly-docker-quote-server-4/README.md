# Nightly Docker Quote Server\n\nA whimsical Docker container that serves a random quote at `/quote`. Great for adding a bit of inspiration to CI pipelines, local development, or any environment.\n\n## Usage\n\n```sh\n# Build the image\ndocker build -t nightly-quote-server .\n\n# Run the container (exposes port 8080)\ndocker run -p 8080:8080 nightly-quote-server\n```\n\nNow request a quote:\n\n```sh\ncurl http://localhost:8080/quote\n# {"quote":"..."}\n```\n\n## How it works\n\nThe server is written in Go, compiled into a tiny static binary and packaged in an Alpine image.\n\n## Extending\n\nAdd more quotes to the `quotes` slice in `src/main.go`.\n
