# Nightly Docker Quote Server\n\nA tiny containerized HTTP server that serves a random whimsical quote on each request. Perfect for sprinkling a bit of inspiration into your dev environment.\n\n## Build\n\n```sh\n docker build -t quote-server .\n```\n\n## Run\n\n```sh\n docker run -p 8080:8080 quote-server\n```\n\n## Use\n\n```sh\n curl http://localhost:8080\n```\n\nWill return a plain‑text quote, e.g.:\n\n> "When the code whispers, listen."\n\n## How it works\n\nThe server is written in Go, compiled in a multi‑stage Docker build, and serves quotes from an embedded list.\n
