# nightly-docker-quote-server\n\nA whimsical Dockerized Flask service that serves a random quote of the day at `/quote`. Perfect for adding a splash of inspiration to your local development environment.\n\n## Build\n\n```sh\n docker build -t nightly-docker-quote-server .\n```\n\n## Run\n\n```sh\n docker run -p 5000:5000 nightly-docker-quote-server\n```\n\nThen visit `http://localhost:5000/quote` to receive a JSON payload:\n\n```json\n {\"quote\":\"...\"}\n```\n\n## How it works\n\nThe container runs a tiny Flask app (`src/app.py`) that selects a random quote from an internal list.\n\n## Testing\n\n```sh\n pytest -q\n```
