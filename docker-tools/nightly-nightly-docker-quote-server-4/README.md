# nightly-docker-quote-server\n\nA tiny Docker image that serves a random quote of the day via a simple HTTP server.\n\n## How it works\n\n* `quotes.json` contains a list of whimsical quotes.\n* The Dockerfile builds an image based on `python:3.11-slim` that copies the JSON file and runs Python's built‑in `http.server` on port 8000.\n* `src/build_and_run.py` is a helper script that builds the image and runs a container exposing the service on host port 8080.\n\n## Quick start\n\n```bash\n# Build the Docker image\npython -m src.build_and_run build\n# Or use the helper script directly\npython src/build_and_run.py\n# The script will build the image and start a container\n# Access the quotes at http://localhost:8080/quotes.json\n```\n\n## Customisation\n\nAdd or edit entries in `quotes.json` before building the image to change the quote pool.\n\n## Testing\n\nThe test suite mocks Docker commands so it can run offline. Run tests with:\n\n```bash\npython -m unittest discover -s tests\n```\n\n## Cleanup\n\nTo stop and remove the container:\n\n```bash\ndocker rm -f quote-server\n```
