# Nightly Docker Quote Server\n\nA whimsical Dockerized HTTP server that returns a random quote on each request. Perfect for adding a splash of inspiration to your CI pipelines, terminal, or any script that can make an HTTP call.\n\n## Build\n\n```sh\n docker build -t nightly-docker-quote-server .\n```\n\n## Run\n\n```sh\n docker run -p 8080:8080 nightly-docker-quote-server\n```\n\nThen:\n\n```sh\n curl http://localhost:8080/\n```\n\nWill output a plain‑text quote.\n\n## How it works\n\nThe server is a tiny Go program compiled into a static binary and packaged in a minimal Alpine image.
