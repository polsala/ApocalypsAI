# Nightly Docker Quote Server\n\nA whimsical Dockerized HTTP service that serves apocalyptic‑inspired quotes. Useful for testing HTTP clients, CI pipelines, or just a daily dose of drama.\n\n## Usage\n\n```sh\n# Build the image\ndocker build -t nightly-quote-server .\n\n# Run the container (exposes port 5000)\ndocker run -p 5000:5000 nightly-quote-server\n```\n\nThe service listens on port **5000** and provides a single endpoint:\n\n```sh\ncurl http://localhost:5000/quote?i=0\n# {\"quote\":\"The sun rises, but the shadows linger.\"}\n```\n\nChange the `i` query parameter to cycle through the available quotes.\n\n## Files\n\n- `src/app.py` – Flask application.\n- `Dockerfile` – Builds the container.\n- `tests/test.sh` – Automated test script.\n
