# nightly-docker-quote-server\n\nA whimsical containerized Flask service that returns a random quote at `/quote`. Useful for injecting fun into CI pipelines or local development.\n\n## Usage\n\n```sh\n# Build the Docker image\ndocker build -t quote-server .\n\n# Run the container (exposes port 5000)\ndocker run -p 5000:5000 quote-server\n```\n\nThen open your browser or `curl` the endpoint:\n\n```sh\ncurl http://localhost:5000/quote\n```\n\nYou will receive a JSON response similar to:\n\n```json\n{\n  "quote": "The early bird gets the worm, but the second mouse gets the cheese."\n}\n```\n\n## Files\n\n- `Dockerfile` – builds the Docker image.\n- `src/app.py` – Flask application source.\n- `requirements.txt` – Python dependencies.\n- `tests/` – unit tests (run with `pytest`).\n
