Nightly Docker Quote Server\n\nA tiny Flask web service that returns a random post‑apocalyptic quote at /quote. Containerized for easy deployment.\n\nUsage:\n1. Build the image:\n   docker build -t nightly-quote-server .\n2. Run the container:\n   docker run -p 5000:5000 nightly-quote-server\n3. Query a quote:\n   curl http://localhost:5000/quote\n\nThe server selects a quote randomly from an internal list.
