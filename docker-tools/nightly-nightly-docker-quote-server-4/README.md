# nightly-docker-quote-server\n\nA whimsical, containerized HTTP service that returns a random post‑apocalyptic quote.\n\n## Features\n\n- Tiny Alpine‑based Docker image (≈ 50 MB)\n- Python 3.11 + Flask\n- Deterministic output when `QUOTE_SEED` is set (useful for testing)\n- No external network calls – all quotes are baked in\n\n## Build the image\n\n```bash\ndocker build -t quote-server .\n```\n\n## Run the server\n\n```bash\n# Run on host port 8080\ndocker run -d --rm -p 8080:8080 --name quote-server quote-server\n```\n\n## Get a quote\n\n```bash\ncurl -s http://localhost:8080/quote | jq\n```\n\nExample output:\n\n```json\n{\n  "quote": "Hope is a stubborn cactus."\n}\n```\n\n## Testing\n\nThe repository includes a deterministic test that builds the image, runs the container, queries the endpoint and verifies the response.\n\n```bash\npython -m pytest tests/test_docker_image.py\n```\n\n## License\n\nMIT
