# nightly-docker-quote-server\n\nA whimsical Dockerized HTTP server that serves random inspirational quotes at `/`. Built with Python and Flask. Perfect for adding a splash of positivity to any container environment.\n\n## Usage\n\n```sh\n# Build the image\ndocker build -t quote-server .\n\n# Run the container (exposes port 8080)\ndocker run -p 8080:8080 quote-server\n```\n\nThen visit `http://localhost:8080/` in your browser or via `curl` to receive a random quote.\n\n## How it works\n\nThe container runs a tiny Flask app (`src/app.py`) that selects a quote from an embedded list on each request.\n\n## Testing\n\nRun the offline unit tests with:\n\n```sh\npytest -q\n```\n\nThe tests exercise the Flask app directly without needing Docker.
