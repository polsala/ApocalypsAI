# Nightly Docker Quote Server\n\nA tiny Dockerized Go HTTP server that returns a random whimsical quote at `/quote`. Perfect for adding a splash of inspiration to your dev environment.\n\n## Build\n\n```sh\n docker build -t nightly-docker-quote-server .\n```\n\n## Run\n\n```sh\n docker run -p 8080:8080 nightly-docker-quote-server\n```\n\nVisit `http://localhost:8080/quote` to see a random quote in JSON:\n\n```json\n{\"quote\":\"...\"}\n```\n\n## Testing\n\n```sh\n go test ./...\n```
