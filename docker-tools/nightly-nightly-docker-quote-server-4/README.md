# Nightly Docker Quote Server\n\nA whimsical Dockerized HTTP service that serves a random inspirational quote on each request.\n\n## Usage\n\n```sh\n# Build the Docker image\ndocker build -t nightly-quote-server .\n\n# Run the container (exposes port 8080)\ndocker run -p 8080:8080 nightly-quote-server\n```\n\nIn another terminal, request a quote:\n\n```sh\ncurl http://localhost:8080/quote\n```\n\nYou will receive a JSON payload like:\n\n```json\n{"quote":"The early bird catches the worm, but the second mouse gets the cheese."}\n```\n\n## How it works\n\nThe container runs a tiny Flask app that selects a random quote from an internal list.\n\n## License\n\nMIT
