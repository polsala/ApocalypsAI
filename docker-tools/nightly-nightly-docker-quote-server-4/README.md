# Nightly Docker Quote Server\n\nA tiny Dockerized Flask app that returns a random whimsical quote at `/quote` and a health check at `/health`.\n\n## Build\n\n```sh\n docker build -t nightly-docker-quote-server .\n```\n\n## Run\n\n```sh\n docker run -p 8080:8080 nightly-docker-quote-server\n```\n\n## API\n\n- `GET /quote` – returns JSON `{ "quote": "..."}`\n- `GET /health` – returns JSON `{ "status": "ok" }`\n\n## Example\n\n```sh\n curl http://localhost:8080/quote\n```
