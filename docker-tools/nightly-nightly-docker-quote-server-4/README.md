# Nightly Docker Quote Server\n\nA whimsical Dockerized Flask service that serves a random (but deterministic when seeded) quote. Great for a quick morale boost in CI pipelines or local dev.\n\n## Build\n\n```sh\n docker build -t nightly-docker-quote-server .\n```\n\n## Run\n\n```sh\n docker run -p 5000:5000 -e SEED=0 nightly-docker-quote-server\n```\n\nThe server will listen on port 5000. Access a quote:\n\n```sh\n curl http://localhost:5000/quote\n```\n\nYou can also pass a seed query parameter to get a specific quote:\n\n```sh\n curl http://localhost:5000/quote?seed=3\n```\n\n## Testing\n\n```sh\n python -m unittest discover -s tests\n```\n\nThe test suite builds the Docker image, runs the container with a known seed, fetches the quote, and verifies it matches the expected text.
