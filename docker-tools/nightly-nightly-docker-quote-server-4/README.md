# nightly-docker-quote-server\n\nA tiny Dockerized HTTP server that returns a random whimsical quote on each request.\n\n## Features\n- Returns a JSON payload with a random quote each time you hit `/`.\n- Built with Flask, runs on any platform that supports Docker.\n- No external network calls – all quotes are baked in, making it safe for offline environments.\n\n## Quick start\n```bash\n# Build the image\ndocker build -t quote-server .\n\n# Run the container (exposes port 8080)\ndocker run -p 8080:8080 quote-server\n```\n\nNow open your browser or use `curl`:\n```bash\ncurl http://localhost:8080/\n```\nYou should see something like:\n```json\n{\n  "quote": "When in doubt, add more coffee."\n}\n```\n\n## Development\nIf you want to run the server locally without Docker:\n```bash\npython -m src.quote_server\n```\n\n## Testing\nRun the test suite with pytest (installed in the dev environment):\n```bash\npytest\n```\n\n## License\nMIT
