# Nightly Docker Quote of the Day\n\nA tiny Docker container that prints a random whimsical quote each time it runs.\n\n## Build\n\n```sh\n docker build -t nightly-quote .\n```\n\n## Run\n\n```sh\n docker run --rm nightly-quote\n```\n\nThe container will output one of the quotes from the bundled list.\n\n## Adding Quotes\n\nEdit `src/quotes.txt` to add your own lines.\n\n## Tests\n\nRun the tests with:\n\n```sh\n python -m pytest tests\n```
