# nightly-quote-mixer-service\n\nA whimsical Dockerized HTTP service that returns a mixed inspirational‑apocalyptic quote.\n\n## Usage\n\n```sh\n# Build the Docker image\ndocker build -t quote-mixer .\n\n# Run the container (exposes port 8080)\ndocker run -p 8080:8080 quote-mixer\n```\n\nThe service will listen on `http://0.0.0.0:8080`.\n\n### Get a mixed quote\n\n```sh\ncurl http://localhost:8080/mix\n```\n\nExample response:\n\n```json\n{\n  "quote": "The only limit is your imagination...and the sky fell in a cascade of ash."\n}\n```\n\n## How it works\n\nThe service stores two hard‑coded lists – one with inspirational fragments and one with apocalyptic fragments. When `/mix` is called it randomly picks one from each list and concatenates them.\n\n## Testing\n\nRun the unit tests locally (requires Python 3.11 and `pip install -r src/requirements.txt`):\n\n```sh\npython -m unittest discover -s tests\n```\n\n## License\n\nMIT
