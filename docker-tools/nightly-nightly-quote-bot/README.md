# Nightly Quote Bot\n\nA tiny Dockerized utility that prints a whimsical quote. Useful for adding a splash of inspiration to CI logs or terminal sessions.\n\n## Usage\n\n```sh\n# Print the default (first) quote\ndocker run --rm nightly-quote-bot\n\n# Print a specific quote by index (zero‑based)\ndocker run --rm -e QUOTE_INDEX=2 nightly-quote-bot\n```\n\nSet `QUOTE_INDEX` to select a specific quote (default `0`).\n\n## Building the image\n\n```sh\ndocker build -t nightly-quote-bot .\n```\n\n## How it works\n\nThe container runs a small Python script that stores a short list of whimsical sayings. The script reads the `QUOTE_INDEX` environment variable, selects the corresponding quote (wrapping around if the index is out of range), and prints it to stdout.\n
