# nightly-docker-quote-of-the-void\n\nA tiny containerized HTTP API that serves random post‑apocalyptic quotes.\n\n## Usage\n\n```sh\n# Build the Docker image\ndocker build -t quote-of-the-void .\n\n# Run the container (exposes port 8080)\ndocker run -p 8080:8080 quote-of-the-void\n```\n\nOnce the container is running, request a quote:\n\n```sh\ncurl http://localhost:8080/quote\n```\n\nTypical response (JSON):\n\n```json\n{\n  "quote": "Hope is the last candle that refuses to be snuffed."\n}\n```\n\n## How it works\n\nThe container runs a small Flask app that picks a random quote from an embedded list.\n\n## License\n\nMIT
