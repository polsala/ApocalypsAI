# Nightly Docker Tip Server\n\nA lightweight Docker container that runs a Flask API serving random post‑apocalyptic survival tips.\n\n## Build\n\n```sh\n docker build -t nightly-docker-tip-server .\n```\n\n## Run\n\n```sh\n docker run -p 8080:8080 nightly-docker-tip-server\n```\n\n## API\n\n- `GET /tip` – returns JSON `{ "tip": "<random tip>" }`.\n\n### Example\n\n```sh\n curl http://localhost:8080/tip\n # {\"tip\":\"Always keep a spare can of beans in your bunker.\"}\n```
