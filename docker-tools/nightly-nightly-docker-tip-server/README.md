# nightly-docker-tip-server\n\nA tiny Dockerized HTTP server that serves random post‑apocalyptic survival tips.\n\n## Usage\n\n```sh\n# Build the Docker image\ndocker build -t tip-server .\n\n# Run the container (exposes port 8080)\ndocker run -p 8080:8080 tip-server\n```\n\nOnce the server is running, request a tip:\n\n```sh\ncurl http://localhost:8080/\n```\n\nYou will receive a plain‑text tip, e.g.\n\n```
Always keep a spare can‑opener in your backpack.\n```\n\n## How it works\n\nThe server is written in Go, compiled into a static binary, and packaged in a minimal Alpine image.\n\n## Adding tips\n\nEdit `src/main.go` and modify the `tips` slice to add or change the available tips.\n
