# Quote Elf Docker Utility\n\nA whimsical Docker container that prints a random quote each time it runs. Optionally filter quotes by category using the `QUOTE_CATEGORY` environment variable.\n\n## Usage\n\n```sh\n# Build the image\ndocker build -t quote-elf .\n\n# Run without category (random quote)\ndocker run --rm quote-elf\n\n# Run with a specific category (e.g., humor)\ndocker run --rm -e QUOTE_CATEGORY=humor quote-elf\n```\n\n## Categories\n\n- inspiration\n- humor\n- wisdom\n\n## How it works\n\nThe container runs a tiny Python script that selects a quote from a hard‑coded list.\n
