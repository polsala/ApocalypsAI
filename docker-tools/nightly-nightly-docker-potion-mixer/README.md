# nightly-docker-potion-mixer\n\n**What it does**\n\n`nightly-docker-potion-mixer` is a tiny helper that generates a Dockerfile and an entrypoint script to brew a custom Docker image. When the resulting container starts, it prints a user‑provided "potion" message and then executes any command you pass to `docker run`.\n\n**Why it exists**\n\n- Whimsical: turn your favorite quote or meme into a Docker image.\n- Useful: quick way to create a container that announces something before doing work (e.g., CI notifications, debugging).\n\n**Installation**\n\nThe utility is a single Python script. It requires Python 3.11+ and Docker installed on the host. No external Python dependencies are needed.\n\n```bash\n# Clone the repository (or copy the src folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/nightly-docker-potion-mixer/src\npython3 -m venv .venv\nsource .venv/bin/activate\n# No extra packages required\n```\n\n**Usage**\n\n```bash\npython3 docker_potion.py --base alpine:3.18 \\
    --message "🧪 Your potion is ready!" \\
    --tag my-potion:latest\n```\n\nThis will:\n1. Create a temporary directory `.docker_potion`.\n2. Write a `Dockerfile` that uses the chosen base image.\n3. Write an `entrypoint.sh` that echoes the message.\n4. Run `docker build -t <tag> .docker_potion`.\n\n**Running the image**\n\n```bash\ndocker run --rm my-potion:latest\n# Output: 🧪 Your potion is ready!\n```\n\nYou can also pass a command after the image name; it will be executed after the message.\n\n**Testing**\n\nThe test suite lives in `tests/` and uses `unittest` with `unittest.mock` to avoid invoking Docker during CI. Run tests with:\n\n```bash\npython -m unittest discover -s ../tests\n```\n\n**License**\n\nMIT – see LICENSE file in the repository root.\n
