# nightly-docker-whimsy-quote\n\nA tiny, self‑contained Docker image that prints a whimsical quote each time it runs.\n\n## Features\n\n- **Random quote** on each start (using `shuf`).\n- **Deterministic mode** for testing via the `QUOTE_INDEX` environment variable.\n- Zero runtime dependencies – just Alpine Linux and a shell script.\n\n## Build the image\n\n```sh\ndocker build -t nightly-docker-whimsy-quote .\n```\n\n## Run the container (random mode)\n\n```sh\ndocker run --rm nightly-docker-whimsy-quote\n```\n\nYou will see something like:\n\n```
The cactus whispered: 'Stay sharp!'
```\n\n## Run the container in deterministic mode (useful for CI)\n\n```sh\ndocker run --rm -e QUOTE_INDEX=2 nightly-docker-whimsy-quote\n```\n\nThis will always print the second quote from the list.\n\n## Test suite\n\nThe repository includes a Bash test that builds the image and verifies deterministic output. Run it with:\n\n```sh\n./tests/test_container.sh\n```\n\n## License\n\nMIT – see LICENSE file in the repository.
