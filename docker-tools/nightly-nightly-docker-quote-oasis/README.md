# Nightly Docker Quote Oasis\n\nA whimsical Dockerized Flask API that serves a random desert-themed quote.\n\n## Overview\n\nThe container runs a tiny Flask web server on port 8080. When you GET `/` you receive a JSON payload with a desert quote.\n\n## Build\n\n```sh\n docker build -t nightly-docker-quote-oasis .\n```\n\n## Run\n\n```sh\n docker run -p 8080:8080 nightly-docker-quote-oasis\n```\n\n## Example\n\n```sh\n curl http://localhost:8080/\n # {\"quote\":\"The dunes whisper secrets to those who listen.\"}\n```\n\n## License\n\nMIT
