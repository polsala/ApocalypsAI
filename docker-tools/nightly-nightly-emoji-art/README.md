# Emoji Art Generator\n\nA whimsical Dockerized utility that converts plain text into a line of emojis, turning your messages into colorful emoji art. Perfect for adding flair to terminal output or chat messages.\n\n## Usage\n\n```sh\n# Build the image\ndocker build -t emoji-art .\n\n# Run with input from echo\necho \"Hello\" | docker run -i emoji-art\n```\n\nThe output will be a string of emojis representing each character.\n\n## How it works\n\nThe container runs a tiny Python script that maps alphanumeric characters to colored square emojis. Unknown characters are rendered as a black square.
