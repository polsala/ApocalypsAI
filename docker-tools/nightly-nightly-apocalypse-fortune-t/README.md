# Nightly Apocalypse Fortune Teller\n\n## Overview\nA tiny Dockerized Python app that gives a whimsical, deterministic fortune based on the string you provide.  Perfect for adding a splash of post‑apocalyptic fun to CI logs, terminal sessions, or chat bots.\n\n## Usage\n```sh\n# Build the Docker image\ndocker build -t apocalypse-fortune .\n\n# Run the container with your question or any input string\ndocker run --rm apocalypse-fortune "Will I survive the next raid?"\n```\n\nThe container will print one of five fixed fortunes.  The selection is deterministic – the same input always yields the same fortune.\n\n## Example\n```sh\n$ docker run --rm apocalypse-fortune "test"\nStars align over the wasteland.\n```\n\n## How it works\nThe Python script sums the UTF‑8 byte values of the supplied argument and uses the sum modulo the number of fortunes to pick a message.  No external services, no randomness, fully offline.\n
