# nightly-rot13-docker\n\nA tiny Docker container that reads text from **stdin** and outputs its ROT13 transformation.\n\n## Why?\n\n- Quick, reversible obfuscation for logs or pipelines\n- No external dependencies beyond a small Python image\n- Fun way to play with classic ciphers in a containerized environment\n\n## Build the image\n\n```bash\ndocker build -t nightly-rot13 .\n```\n\n## Run the container\n\nYou can pipe any text into the container and receive the ROT13 output:\n\n```bash\necho "Hello World!" | docker run -i nightly-rot13\n```\n\nExpected output:\n\n```
Uryyb Jbeyq!\n```\n\n## How it works\n\nThe container runs a minimal Python 3.11 Alpine image that executes `src/rot13.py`. The script reads from `stdin`, applies the ROT13 cipher using the standard library, and writes the result to `stdout`.\n\n## Testing\n\nRun the unit tests locally (outside Docker) with:\n\n```bash\npython -m unittest discover -s tests\n```\n\nAll tests should pass, confirming correct transformation logic.
