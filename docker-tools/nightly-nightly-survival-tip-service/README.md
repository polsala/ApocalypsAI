# Survival Tip Service\n\nA tiny Flask web service packaged in a Docker container that returns a random post‑apocalypse survival tip.\n\n## Build the image\n```bash\ndocker build -t survival-tip .\n```\n\n## Run the container\n```bash\ndocker run -p 5000:5000 survival-tip\n```\n\nThe service will be reachable at `http://localhost:5000/tip`.\n\n## API\n- **GET** `/tip` – Returns JSON with a random tip. Example response:\n```json\n{\n  "tip": "Always keep a spare can‑opener in your backpack.\"\n}\n```\n\n## Testing\nThe repository includes a deterministic pytest suite that mocks the random tip selection. Run tests with:\n```bash\npytest -q\n```\n
