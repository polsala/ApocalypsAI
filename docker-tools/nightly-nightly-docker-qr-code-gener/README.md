# nightly-docker-qr-code-generator\n\nA tiny Docker image that turns any text into an ASCII QR code.\n\n## How it works\n\nThe image runs a small Python script that uses the `qrcode` library to generate a QR matrix and renders it with block characters (\u2588\u2588) for black modules and spaces for white modules.\n\n## Build the image\n\n```bash\ndocker build -t qr-gen .\n```\n\n## Run the container\n\nYou can provide the message either via the `MESSAGE` environment variable or as a command‑line argument.\n\n```bash\n# Using env var\ndocker run --rm -e MESSAGE="Hello, apocalypse!" qr-gen\n\n# Using argument\ndocker run --rm qr-gen "Hello, apocalypse!"\n```\n\nThe container will print the QR code to stdout.\n\n## Example output\n\n```\n████████████████\n██          ██\n██  ████  ██\n██  ████  ██\n██          ██\n████████████████\n```\n\n## License\n\nMIT – see LICENSE file in the repository.
