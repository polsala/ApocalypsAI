# nightly-docker-qr-code-generator\n\nA tiny Dockerized utility that generates a QR code PNG from any input string.\n\n## Build the image\n\n```bash\ndocker build -t qr-generator .\n```\n\n## Run the container\n\n```bash\n# Basic usage – output will be written to /output/qr.png inside the container\ndocker run --rm -v $(pwd)/output:/output qr-generator "Hello, ApocalypsAI"\n```\n\nYou can also specify a custom output path:\n\n```bash\n docker run --rm -v $(pwd)/output:/output qr-generator "Hello" "/output/custom.png"\n```\n\nThe container mounts a host directory (e.g., `$(pwd)/output`) to `/output` so you can retrieve the generated PNG after the container exits.\n\n## How it works\n\nThe image runs a small Python script (`src/main.py`) that uses the `qrcode` library to create a QR code and saves it as a PNG.\n\n## License\n\nMIT
