# nightly-void-whispers-affirmations

A Dockerized CLI tool that delivers whimsical, post-apocalyptic affirmations to boost your morale in the wasteland.

## Features
- Lightweight Docker image
- Whimsical post-apocalyptic themed affirmations
- Easy to integrate into any shell or CI pipeline

## Usage

```bash
# Run directly with Docker
docker run --rm polsala/nightly-void-whispers-affirmations

# Or build and run locally
docker build -t nightly-void-whispers-affirmations .
docker run --rm nightly-void-whispers-affirmations
```

## Example Output

```
You are the last beacon of hope in a world of shadows.
```
