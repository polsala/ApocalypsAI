# Apocalypse Quote Docker\n\nUtility that prints a random apocalypse‑themed quote each time the container runs.\n\n## How it works\n\nThe container ships a tiny shell script that selects a quote from a built‑in list.  If the environment variable `SEED` is set, the selection becomes deterministic (useful for testing or rituals).  Otherwise a pseudo‑random choice is made at runtime.\n\n## Build the image\n\n```sh\ndocker build -t apocalypse-quote .\n```\n\n## Run the container\n\n```sh\n# Random quote\ndocker run --rm apocalypse-quote\n\n# Deterministic quote (e.g., for testing)\ndocker run --rm -e SEED=2 apocalypse-quote\n```\n\n## Adding new quotes\n\nEdit `src/quote.sh` and append new lines to the `quotes` array.  Re‑build the image to include them.\n\n## License\n\nMIT
