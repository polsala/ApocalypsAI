# nightly-void-whistle

A containerized utility for emitting eerie sounds from the terminal to signal temporal anomalies.

## Features

- Play pre-packaged eerie sound effects
- Simulate temporal anomaly warnings
- Lightweight Docker image

## Usage

```bash
# Pull and run the void whistle
$ docker run --rm polsala/nightly-void-whistle

# Run with a specific anomaly type
$ docker run --rm polsala/nightly-void-whistle rift
```

## Supported Sounds

- `rift`: A low-frequency hum signaling a temporal rift
- `tear`: A sharp crackle indicating a temporal tear
- `whisper`: A faint echo from the void
