# Nightly Docker Image Size Estimator\n\n## Overview\n\n`nightly-docker-image-size-estimator` is a tiny, containerized utility that tells you how large a Docker image is *before* you pull it. It queries the Docker Hub Registry API for the image's manifest and reports the total size of all layers in a human‑readable format.\n\n## Why?\n\n* **Save bandwidth** – avoid pulling huge images you don\'t need.\n* **Plan storage** – know ahead of time how much disk space an image will consume.\n* **Whimsical** – because even in a post‑apocalyptic world you still want to know if your next container will fit on the dusty hard drive.\n\n## Usage\n\n```bash\n# Build the Docker image (once)\ndocker build -t nightly-docker-image-size-estimator .\n\n# Run the estimator\n# Syntax: docker run --rm nightly-docker-image-size-estimator <image> [tag]\n# If tag is omitted, "latest" is assumed.\n\n# Example – official nginx latest\ndocker run --rm nightly-docker-image-size-estimator nginx\n\n# Example – specific tag\ndocker run --rm nightly-docker-image-size-estimator python 3.11-slim\n```\n\n## How it works\n\nThe tool contacts the public Docker Hub API endpoint:\n\n````\nhttps://hub.docker.com/v2/repositories/<namespace>/<repo>/tags/<tag>/\n````\n\nFor official images the namespace is `library`. The JSON response contains a `full_size` field (bytes) that represents the total size of the image (all layers). The script fetches this field and formats it into KiB/MiB/GiB.\n\n## Limitations\n\n* Only works for images hosted on Docker Hub (the public registry).\n* Private registries are out of scope.\n* Requires internet connectivity – the tests mock the network calls.\n\n## Testing\n\nRun the test suite with:\n\n```bash\npython -m unittest discover -s tests\n```\n\nThe tests use `unittest.mock` to simulate Docker Hub responses, so they run offline.\n
