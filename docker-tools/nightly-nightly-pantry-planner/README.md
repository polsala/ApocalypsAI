Pantry Planner\n\nA whimsical Dockerized utility that helps post-apocalyptic survivors plan meals from whatever ingredients they have left. Provide a space-separated list of ingredients, and the container will suggest a random dish you can make.\n\nUsage:\n\n    docker build -t pantry-planner .\n    docker run --rm pantry-planner tomato cheese basil\n\nOutput example:\nSuggested dish: Caprese Salad\n\nTesting:\nRun the tests with pytest:\n    pytest\n
