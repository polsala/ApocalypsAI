# nightly-scrap-collector\n\nA whimsical Dockerized utility that reads a list of scavenged items (name, weight, value) from a CSV file and outputs a prioritized collection order based on value‑to‑weight ratio, helping post‑apocalypse survivors maximize loot.\n\n## Usage\n\n```sh\n# Build the Docker image\ndocker build -t scrap-collector .\n\n# Run the container, mounting a directory with a CSV file\n# Replace $(pwd)/data with the path to your CSV directory\ndocker run --rm -v $(pwd)/data:/data scrap-collector /data/items.csv\n```\n\nThe program prints the items sorted by descending value/weight ratio, one name per line.\n\n## Input format\n\nCSV with header `name,weight,value`. Example:\n\n```csv\nname,weight,value\nrusty-screwdriver,2,5\ncanned-beans,1,3\nwater-bottle,3,10\n```\n\n## Output\n\nOrdered list of item names, one per line.\n\n## Example\n\nGiven the CSV above, the output will be:\n\n````\nwater-bottle\nrusty-screwdriver\ncanned-beans\n````\n
