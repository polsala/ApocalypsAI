Nightly Docker Survival Tip\n\nA tiny Docker container that prints a whimsical post‑apocalyptic survival tip each time it runs. Set the environment variable TIP_INDEX to a zero‑based index to get a specific tip; otherwise a random tip is shown.\n\nBuild the image:\n\n    docker build -t survival-tip .\n\nRun a random tip:\n\n    docker run --rm survival-tip\n\nRun a specific tip (e.g., index 3):\n\n    docker run --rm -e TIP_INDEX=3 survival-tip
