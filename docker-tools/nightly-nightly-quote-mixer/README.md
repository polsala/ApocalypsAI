# Nightly Quote Mixer

A tiny Dockerized Go service that returns a whimsical mixed quote combining an inspirational phrase with a post‑apocalyptic warning. Useful for adding flavor to CI logs, chat bots, or just for fun.

## Usage

```sh
docker build -t nightly-quote-mixer .
docker run -p 8080:8080 nightly-quote-mixer
```

Then request:

```sh
curl http://localhost:8080/quote
```

Response:

```json
{"quote":"Stay hopeful, but keep your gas mask handy."}
```

## Implementation

The service is written in Go, compiled into a static binary, and served via the standard library's `net/http`. The quote is generated by randomly picking one part from each of two predefined slices.

## Tests

Run `go test ./...` to execute unit tests.
