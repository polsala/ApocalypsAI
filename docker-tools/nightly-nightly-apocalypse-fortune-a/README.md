# Apocalypse Fortune API\n\nA tiny Dockerized Flask service that returns a random post‑apocalyptic fortune. Useful for adding flavor to chatbots, games, or terminal prompts.\n\n## Build\n\n```sh\n docker build -t apocalypse-fortune .\n```\n\n## Run\n\n```sh\n docker run -p 8080:8080 apocalypse-fortune\n```\n\n## Usage\n\n```sh\n curl http://localhost:8080/fortune\n # {\"fortune\":\"...\"}\n```\n\n## How it works\n\nThe service picks a random line from a built‑in list of whimsical fortunes.\n
