# Docker Ghostbuster\n\nA whimsical utility that scans a Docker image for "ghost" files—common secret or leftover files such as `.env`, `.git`, `.ssh`—and reports them in a spooky style.\n\n## Usage\n\n```sh\n# Build the image\ndocker build -t ghostbuster .\n\n# Run the scanner against an image\ndocker run --rm ghostbuster <image-name>\n```\n\nExample:\n\n```sh\ndocker run --rm ghostbuster myapp:latest\nScanning image myapp:latest for ghost files...\n👻 Found .env\n👻 Found .git\n👻 Found .ssh\n```\n\nThe tool is deliberately simple and deterministic; it does not actually inspect the image layers but demonstrates how a containerized scanner could be structured.\n\n## Implementation\n\nThe scanner is a tiny Python script (`src/ghostbuster.py`) that pretends to find a predefined set of ghost files.\n\n## Tests\n\nRun the unit tests with:\n\n```sh\npython -m unittest discover -s tests\n```
