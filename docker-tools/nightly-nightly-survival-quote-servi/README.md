# Survival Quote Service\n\nA tiny Flask web service that returns a daily survival‑style quote.\nThe quote is deterministic – it is derived from the current date, so the same date always yields the same quote.\n\n## Build the Docker image\n\n```bash\ndocker build -t survival-quote .\n```\n\n## Run the container\n\n```bash\ndocker run -p 5000:5000 survival-quote\n```\n\nThe service will be reachable at `http://localhost:5000/`.\n\n## Example request\n\n```bash\ncurl http://localhost:5000/\n```\n\nExpected JSON response (quote will vary by date):\n\n```json\n{\n  "quote": "Never trust a calm sky in the wasteland."\n}\n```\n\n## How it works\n\n* `src/quote_service.py` contains a static list of whimsical quotes and a function that selects one based on the date's ordinal number.\n* `src/app.py` starts a Flask app exposing a single `/` endpoint that returns the selected quote as JSON.\n* The Dockerfile builds a lightweight Python image, installs Flask, copies the source, and runs the app.\n\n## Testing\n\nUnit tests live in `tests/` and verify that the quote selection logic is deterministic. Run them with:\n\n```bash\npython -m unittest discover -s tests\n```\n
