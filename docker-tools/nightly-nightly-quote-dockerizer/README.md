# Nightly Quote Dockerizer\n\n## Overview\n\nThis utility provides a Docker container that prints a random whimsical post‑apocalyptic quote each time it starts. It’s perfect for adding a splash of drama to CI logs, terminal sessions, or just for fun.\n\n## Usage\n\n```sh\n# Build the Docker image\ndocker build -t nightly-quote .\n\n# Run the container (it will print a random quote and exit)\ndocker run --rm nightly-quote\n```\n\nYou should see output similar to:\n\n```
Even the sun takes a coffee break before the end of the world.
```\n\n## Implementation Details\n\nThe container is based on the lightweight `python:3.11-alpine` image and runs a tiny Python script that selects a quote at random from a curated list. The script lives in `src/quote.py` and is executed as the container’s entrypoint.\n\n## Extending the Quote List\n\nTo add more quotes, edit the `QUOTES` list in `src/quote.py`. The script will automatically include any new entries on the next container run.\n
