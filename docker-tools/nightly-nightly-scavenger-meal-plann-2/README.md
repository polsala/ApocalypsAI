# Nightly Scavenger Meal Planner\n\nA whimsical Dockerized utility that helps post‑apocalyptic survivors plan meals from a list of scavenged ingredients. Provide a plain‑text file `ingredients.txt` (one ingredient per line) and the container will suggest a random recipe that can be made with the available items.\n\n## Usage\n\n```sh\n# Build the image\ndocker build -t scavenger-meal-planner .\n\n# Run the container, mounting a local ingredients file\ndocker run --rm -v "$(pwd)":/data scavenger-meal-planner /data/ingredients.txt\n```\n\nThe container prints a recipe name and required ingredients. If no recipe matches, it suggests improvising.\n\n## How it works\n\nThe tool ships with a tiny built‑in recipe database (JSON). It loads the supplied ingredient list, finds recipes where all required ingredients are present, and picks one at random (deterministic during tests).
