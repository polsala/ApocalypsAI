Nightly Emoji Artifier\n\nOverview:\nThis Dockerized service converts any input text into a whimsical string of emojis, one per character, using a deterministic mapping for reproducibility.\n\nBuild the Docker image:\n    docker build -t nightly-emoji-artifier .\n\nRun the container (exposes port 8080):\n    docker run -p 8080:8080 nightly-emoji-artifier\n\nAPI Endpoint:\nPOST http://localhost:8080/artify\nPayload (JSON): {\"text\": \"your text here\"}\nResponse (JSON): {\"emoji_art\": \"<emoji string>\"}\n\nMapping Details:\nEach character's Unicode code point is taken modulo the length of an internal emoji list (16 emojis). The resulting index selects the emoji for that character. This ensures the same input always yields the same emoji art.\n\nExample:\n    curl -X POST -H \"Content-Type: application/json\" -d '{\"text\": \"AB\"}' http://localhost:8080/artify\nResponse: {\"emoji_art\": \"😂🥰\"}\n
