# Nightly Pantry Mixer\n\nGenerates simple post‑apocalypse recipes from a list of pantry ingredients.\n\n## Usage\n\n```sh\necho '{"ingredients": ["canned beans","spaghetti","tomato sauce"]}' | docker run --rm nightly-pantry-mixer\n```\n\nThe command reads a JSON object from **STDIN** with an `ingredients` array and prints a JSON array of recipe names that can be prepared with the supplied items.\n\n## How it works\n\nThe container runs a tiny Python script that matches the supplied ingredients against a built‑in recipe database.\n\n## Building the container\n\n```sh\n# Build the Docker image\ndocker build -t nightly-pantry-mixer .\n```\n\n## Example\n\n```sh\necho '{"ingredients": ["canned beans", "water", "salt"]}' | docker run --rm nightly-pantry-mixer\n# Output: ["Bean Soup"]\n```
