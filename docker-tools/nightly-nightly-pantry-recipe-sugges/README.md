# Nightly Pantry Recipe Suggester\n\nA tiny, whimsical utility for post‑apocalyptic survivors (or anyone with a limited pantry).\n\n## What it does\n\n* Reads a JSON file containing a list of ingredients you have on hand.\n* Compares that list against a built‑in tiny recipe database.\n* Prints the names of all recipes that can be prepared with *only* the ingredients you have.\n\nIf no recipes match, it prints `No recipes found.`\n\n## How to use\n\n```bash\n# Build the Docker image\ndocker build -t pantry-suggester .\n\n# Prepare an ingredients file (ingredients.json)\n# Example content:\n# [\n#   "bread",\n#   "peanut butter",\n#   "jam",\n#   "cheese",\n#   "butter"\n# ]\n\n# Run the container, mounting the ingredients file into /app\n# The container will read /app/ingredients.json by default\n\n# Simple run (uses default path inside container)\n# Place ingredients.json in the current directory\n\n docker run --rm -v $(pwd)/ingredients.json:/app/ingredients.json pantry-suggester\n\n# Or specify a custom path inside the container\n docker run --rm -v $(pwd)/mylist.json:/data/mylist.json pantry-suggester /data/mylist.json\n```\n\n## Recipe database (hard‑coded)\n\n| Recipe | Required ingredients |\n|--------|----------------------|\n| PB&J Sandwich | bread, peanut butter, jam |\n| Grilled Cheese | bread, cheese, butter |\n| Tomato Soup | tomato, water, salt |\n\n## Development\n\nThe source lives in `src/app.py`. Tests are in `tests/test_app.py` and can be run with:\n\n```bash\npython -m unittest discover -s tests\n```\n
