# Nightly Pantry Recipe Suggester\n\nA whimsical yet useful Docker container that reads a pantry inventory CSV file and suggests which simple recipes can be prepared with the available ingredients. Perfect for post‑apocalypse survivors who need to make the most of their limited supplies.\n\n## Features\n\n- Reads a CSV file where each line is `item,quantity` (quantity is ignored, only presence matters).\n- Contains a small hard‑coded recipe database.\n- Outputs a friendly list of recipes you can make.\n\n## Build the Docker image\n\n```bash\ndocker build -t pantry-suggester .\n```\n\n## Run the container\n\nPlace your pantry CSV somewhere on the host, e.g. `sample.csv`, then run:\n\n```bash\ndocker run --rm -v $(pwd)/sample.csv:/data/pantry.csv pantry-suggester /data/pantry.csv\n```\n\nThe container will print the recipes that can be made.\n\n## Sample pantry CSV\n\n```csv\nbread,2\npeanut butter,1\napple,3\nbanana,2\ncarrot,5\npotato,4\nwater,1\n```\n\nRunning the container with the above CSV yields:\n\n````\nYou can make:\n- Peanut Butter Sandwich\n- Fruit Salad\n- Veggie Soup\n````\n\n## Testing\n\nA deterministic test script is provided under `tests/test_recipe.sh`. It builds the image, runs it against a sample CSV, and asserts the expected output.\n\n```bash\ncd tests && ./test_recipe.sh\n```\n\n## License\n\nMIT
