# Nightly Pantry Recipe Suggester\nUtility that, given a list of ingredients in a pantry (JSON), suggests possible recipes that can be made with those ingredients. Runs inside a Docker container.\n\n## Usage\n```sh\n# Build the container\ndocker build -t pantry-suggester .\n\n# Run the container, mounting your pantry file\ndocker run --rm -v $(pwd)/pantry.json:/data/pantry.json pantry-suggester\n```\nThe container will read `/data/pantry.json` and print any matching recipes.\n
