# Nightly Pantry Recipe Suggester\n\nA whimsical Dockerized utility that, given a CSV list of pantry ingredients, suggests a random recipe you can make from a tiny built‑in cookbook. Perfect for post‑apocalypse cooking or when you forget what's in the pantry.\n\n## How it works\n\n* The container runs a small Python script.\n* The script reads a CSV file where each line contains a single ingredient name.\n* It compares the available ingredients against a hard‑coded list of recipes and picks one that can be prepared.\n* If multiple recipes match, one is chosen at random.\n\n## Usage\n\n```sh\n# Build the image\ndocker build -t pantry-suggester .\n\n# Prepare a pantry CSV (one ingredient per line)\ncat > my-pantry.csv <<EOF\nbeans\nwater\nsalt\nEOF\n\n# Run the container, mounting the CSV into the container\n# The script will read the file path you provide as the first argument\n# (or use the PANTRY_FILE environment variable).\n\n# Example with argument\ndocker run --rm -v $(pwd)/my-pantry.csv:/data/pantry.csv pantry-suggester /data/pantry.csv\n\n# Example with env var\ndocker run --rm -e PANTRY_FILE=/data/pantry.csv -v $(pwd)/my-pantry.csv:/data/pantry.csv pantry-suggester\n```\n\nIf you do not supply a file, the script falls back to a built‑in sample pantry.\n\n## Expected output\n\n```
Suggested recipe: Bean Soup\n```\n\nIf no recipe can be made with the supplied ingredients, you will see:\n\n```
No matching recipe found with current ingredients.\n```\n\n## Extending the cookbook\n\nThe recipe list lives in `src/main.py` as the `RECIPES` constant. Feel free to add more entries following the same structure.\n
