# Nightly Pantry Recipe Suggester\n\nA whimsical yet practical Docker container that scans a CSV file of pantry items and prints out possible recipes you can make with what you have.\n\n## How it works\n\n1. The container expects a CSV file (default name `pantry.csv`) with one ingredient per line.\n2. It contains a tiny built‑in recipe database.\n3. When run, it matches the ingredients you have against the recipes and prints any matches.\n\n## Build the image\n\n```bash\ndocker build -t pantry-recipe-suggester .\n```\n\n## Run the container\n\nMount a directory containing your `pantry.csv` (or any CSV) into `/data` inside the container.\n\n```bash\n# Example pantry file\ncat > my-pantry.csv <<EOF\negg\nflour\nsugar\nmilk\nEOF\n\n# Run the container\ndocker run --rm -v $(pwd):/data pantry-recipe-suggester\n```\n\nThe tool will read `/data/pantry.csv` by default. To use a different file, set the `INPUT_CSV` environment variable:\n\n```bash\ndocker run --rm -e INPUT_CSV=/data/ingredients.csv -v $(pwd):/data pantry-recipe-suggester\n```\n\n## Output example\n\n```\nFound recipes:\n- Pancake (needs: flour, egg, milk)\n- Simple Cake (needs: flour, sugar, egg)\n```\n\n## Testing\n\nThe repository includes a pytest suite that runs without network access.\n\n```bash\npip install pytest\npytest\n```\n\n## License\n\nMIT
