# Pantry Recipe Suggester\n\nUtility that reads a list of available ingredients from a CSV file and suggests possible recipes from a built‑in database. All processing is offline; no external API calls.\n\n## Usage\n\n```sh\n# Build the Docker image\ndocker build -t pantry-suggester .\n\n# Prepare an ingredients CSV (one ingredient per line)\ncat > ingredients.csv <<EOF\nbread\npeanut butter\nEOF\n\n# Run the container, mounting the CSV into /data\ndocker run --rm -v $(pwd)/ingredients.csv:/data/ingredients.csv pantry-suggester\n```\n\nThe container will output suggested recipes.\n\n## How it works\n\n- The container runs a small Python script.\n- The script reads `/data/ingredients.csv` (one ingredient per line).\n- It compares the set of ingredients against a hard‑coded recipe list.\n- Recipes whose required ingredients are all present are printed.\n\n## Testing\n\nRun the unit tests with:\n\n```sh\n# Build the image (if not already built)\ndocker build -t pantry-suggester .\n\n# Run tests inside the container\ndocker run --rm pantry-suggester pytest\n```\n\nOr run locally with `pytest` after installing the requirements.
