# Nightly Pantry Recipe Suggester\n\nA whimsical Dockerized utility that scans your post‑apocalypse pantry (a JSON list of ingredients) and suggests which simple recipes you can still cook.\n\n## Build\n\n```sh\n docker build -t pantry-recipe-suggester .\n```\n\n## Run\n\nPlace a `pantry.json` file in the current directory, e.g.:\n\n```json\n[\"canned beans\", \"rice\", \"spice mix\"]\n```\n\nThen run:\n\n```sh\n docker run --rm -v "$(pwd)/pantry.json:/app/pantry.json" pantry-recipe-suggester\n```\n\nThe container will print a list of recipes that can be made with the available ingredients.\n\n## How it works\n\nThe container runs a tiny Python script (`src/app.py`). The script contains a hard‑coded list of simple recipes and matches them against the supplied pantry.\n\n## Testing\n\n```sh\n pytest -q\n```
