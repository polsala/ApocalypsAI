# Nightly Pantry Recipe Suggester\n\nA whimsical yet practical Docker‑wrapped utility that helps you discover what you can cook with the ingredients you have on hand.\n\n## How it works\n\n1. Prepare a JSON file describing the ingredients you currently have. Example (`ingredients.json`):\n```json\n{\n  "ingredients": [\n    "egg",\n    "flour",\n    "milk",\n    "cheese",\n    "tomato"\n  ]\n}\n```\n2. Build the Docker image:\n```bash\ndocker build -t pantry-suggester .\n```\n3. Run the container, mounting the directory that contains your JSON file:\n```bash\ndocker run -v $(pwd):/data pantry-suggester /data/ingredients.json\n```\nIf you omit the path argument, the tool will look for `/data/ingredients.json` by default.\n\n## Output\nThe container prints a list of recipe names that can be prepared with the supplied ingredients. If no recipes match, it prints a friendly message.\n\n## Extending the recipe database\nThe built‑in recipe list lives in `src/app.py`. Feel free to edit it and add your own favorite dishes.\n\n## Testing\nRun the unit tests locally (outside Docker) with:\n```bash\npython -m pytest tests\n```\nThe tests verify the core matching logic without needing Docker.\n
