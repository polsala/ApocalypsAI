# Pantry Recipe Suggester\n\nA whimsical Dockerized utility that helps post‑apocalyptic survivors discover recipes they can cook with the ingredients they have on hand.\n\n## How it works\n\nThe container expects a JSON file at `/data/ingredients.json` containing an array of ingredient names, e.g.:\n\n```json\n[\n  "canned beans",\n  "rice",\n  "spice mix"\n]\n```\n\nWhen run, it prints a list of recipes that can be prepared using only those ingredients.\n\n## Usage\n\n```sh\n# Build the image\ndocker build -t pantry-suggester .\n\n# Prepare your ingredients file (ingredients.json) in the current directory\ncat > ingredients.json <<'EOF'\n[\n  "canned beans",\n  "rice",\n  "spice mix"\n]\nEOF\n\n# Run the container, mounting the ingredients file\ndocker run --rm -v $(pwd)/ingredients.json:/data/ingredients.json pantry-suggester\n```\n\n## Adding recipes\n\nRecipes are defined inside `src/app.py` in the `RECIPES` dictionary. Each recipe maps a name to a set of required ingredients (lower‑cased).\n\n## Testing\n\nThe repository includes unit tests that can be run locally (outside Docker) with:\n\n```sh\npython -m unittest discover -s tests\n```\n\nOr inside the Docker image (pytest is installed for convenience):\n\n```sh\ndocker run --rm pantry-suggester pytest\n```\n
