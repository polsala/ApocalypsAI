# Pantry Recipe Suggester\n\nA whimsical Dockerized utility that reads a simple pantry inventory file and suggests recipes you can make with the ingredients you have. Perfect for post‑apocalypse cooking or everyday meal planning.\n\n## How it works\n\n1. Create an `inventory.csv` file with one ingredient per line, e.g.:\n\n````\nbread\npeanut butter\njam\negg\n````\n\n2. Build the Docker image:\n\n```sh\n docker build -t pantry-suggester .\n```\n\n3. Run the container, mounting your inventory file:\n\n```sh\n docker run --rm -v $(pwd)/inventory.csv:/app/inventory.csv pantry-suggester\n```\n\nThe container will print a list of recipes you can prepare.\n\n## Recipes\n\nThe tool ships with a tiny hard‑coded recipe database:\n\n- **Peanut Butter Sandwich** – bread, peanut butter\n- **Jam Sandwich** – bread, jam\n- **Egg Fried Rice** – rice, egg, soy sauce\n- **Simple Omelette** – egg, cheese\n- **Toast** – bread\n\n## Extending\n\nAdd more recipes by editing `src/app.py` in the `RECIPES` dictionary.\n\n## Testing\n\nRun the unit tests locally (outside Docker) with:\n\n```sh\n python -m unittest discover -s tests\n```
