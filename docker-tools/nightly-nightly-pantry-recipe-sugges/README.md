# Pantry Recipe Suggester\n\nUtility that reads a list of available pantry items and suggests the first matching recipe from a built‑in collection. Perfect for post‑apocalypse kitchens.\n\n## Build\n\n```sh\n docker build -t pantry-suggester .\n```\n\n## Run\n\n```sh\n docker run --rm -v $(pwd)/pantry.txt:/app/pantry.txt pantry-suggester /app/pantry.txt\n```\n\nThe container will print the name of a recipe that can be prepared with the supplied ingredients, or `No recipe found`.\n\n## How it works\n\nThe script loads a tiny hard‑coded recipe database, reads the pantry file (one ingredient per line), and finds the first recipe whose ingredient list is a subset of the pantry.
