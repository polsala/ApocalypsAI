# Nightly Pantry Recipe Suggester\n\n## Overview\n\nThis Dockerized utility reads a CSV file describing the contents of your pantry and suggests recipes that can be prepared with the available ingredients. It uses a tiny built‑in recipe database and simple set‑based matching.\n\n## CSV Format\n\nThe inventory file must be a CSV with a header row containing the columns `ingredient` and `quantity`. Only the `ingredient` column is used for matching. Example:\n\n```csv\ningredient,quantity\nbread,2\npeanut butter,1 jar\neggs,6\nmilk,1L\n```\n\n## Building the Docker Image\n\n```bash\ndocker build -t pantry-suggester .\n```\n\n## Running the Container\n\nMount your inventory CSV into the container and pass its path as the sole argument:\n\n```bash\ndocker run --rm -v $(pwd)/inventory.csv:/data/inventory.csv pantry-suggester /data/inventory.csv\n```\n\nThe container will print a list of recipes you can make, or a message indicating that no recipes match.\n\n## Extending the Recipe Database\n\nThe built‑in recipes are defined in `src/app.py` as a dictionary mapping recipe names to a set of required ingredients. Feel free to edit that file to add your own favorite dishes.\n\n## Testing\n\nThe repository includes a pytest suite that validates the core matching logic. Run the tests with:\n\n```bash\npytest\n```\n\n---\n\nEnjoy discovering what culinary creations your apocalypse‑proof pantry can support!
