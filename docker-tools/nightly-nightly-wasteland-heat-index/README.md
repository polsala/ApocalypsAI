# Nightly Wasteland Heat Index\n\n## Overview\n\nThis utility computes the heat index (apparent temperature) from ambient temperature (°C) and relative humidity (%), then adds a radiation adjustment to reflect post‑apocalyptic conditions. It outputs the final apparent temperature and a comfort level for survivors.\n\n## Usage\n\n```sh\n# Build the image (once)\ndocker build -t wasteland-heat-index .\n\n# Run the container\n# <temp_c>  : ambient temperature in Celsius\n# <humidity_percent> : relative humidity in percent\n# [radiation_mSv] : optional radiation level in millisieverts (default 0)\n\n# Example\n docker run --rm -v "$(pwd)":/app -w /app wasteland-heat-index 35 70 5\n```\n\nThe container will print something like:\n\n```
Apparent temperature: 48.3°C\nComfort level: Danger\n```\n\n## Installation\n\n```sh\n# Build the Docker image\n docker build -t wasteland-heat-index .\n```\n\n## License\n\nMIT License
