# nightly-docker-image-size-estimator\n\n## Overview\n\n`nightly-docker-image-size-estimator` is a tiny utility that parses a Dockerfile and provides an **estimated total image size** (in megabytes) without actually building the image.  It uses a small built‑in lookup table for common base images and adds a fixed cost for each `RUN`, `COPY`, or `ADD` instruction.  This is handy for quick sanity checks, CI cost‑estimation, or just satisfying curiosity.\n\n## How it works\n\n1. The tool reads the Dockerfile line‑by‑line.\n2. For each `FROM` line it looks up a predefined size (e.g., `python:3.11-slim` → 120 MB).  Unknown bases default to 100 MB.\n3. Every `RUN`, `COPY`, or `ADD` instruction adds a flat 5 MB overhead (a rough average for typical layers).\n4. The sum is printed as `Estimated image size: <size> MB`.\n\n## Usage\n\n```bash\n# Build the Docker image that contains the estimator\ndocker build -t size-estimator .\n\n# Run the estimator against a Dockerfile\n# (the Dockerfile can be anywhere on your host)\n docker run --rm -v $(pwd)/Dockerfile:/Dockerfile size-estimator /Dockerfile\n```\n\nThe container expects a **single argument** – the path to the Dockerfile inside the container (usually `/Dockerfile` when you mount it as shown above).\n\n## Example\n\n```Dockerfile\nFROM python:3.11-slim\nRUN pip install --no-cache-dir requests\nCOPY . /app\n```\n\nRunning the estimator:\n\n```bash\n$ docker run --rm -v $(pwd)/Dockerfile:/Dockerfile size-estimator /Dockerfile\nEstimated image size: 130 MB\n```\n\nExplanation: base 120 MB + 5 MB for the `RUN` + 5 MB for the `COPY`.\n\n## Extending the lookup table\n\nIf you need more accurate base‑image sizes, edit `src/estimate_size.py` and extend the `BASE_IMAGE_SIZES` dictionary.\n\n## Testing\n\nThe repository includes a deterministic pytest suite that runs offline and uses temporary files. Run the tests with:\n\n```bash\npytest\n```\n\nAll tests should pass on any platform.\n
