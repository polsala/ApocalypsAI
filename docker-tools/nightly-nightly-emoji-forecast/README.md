# Nightly Emoji Forecast\n\n## Overview\n\n`nightly-emoji-forecast` is a tiny Docker container that spits out a playful weather forecast made entirely of emojis.  It requires no external APIs – the forecast is randomly generated, making it safe to run offline while still providing a fun, whimsical experience.\n\n## How it works\n\nThe container runs a short Python script (`src/forecast.py`) that picks a random weather condition emoji and a temperature‑related emoji for the city you provide.\n\n## Usage\n\n```bash\n# Build the image (run once)\ndocker build -t emoji-forecast .\n\n# Run with CITY environment variable\ndocker run --rm -e CITY=London emoji-forecast\n\n# Or pass the city name as a command‑line argument\ndocker run --rm emoji-forecast Tokyo\n```\n\nTypical output looks like:\n\n```
London: 🌤️ 🌡️\n```\n\nIf no city is supplied, the container prints a usage hint and exits with status 1.\n\n## Testing\n\nThe repository includes a deterministic test suite that mocks Docker commands, ensuring the build and run steps behave as expected without needing a real Docker daemon. Run the tests with:\n\n```bash\npython -m unittest discover -s tests\n```\n\n## Implementation Details\n\n* **Base image**: `python:3.11-slim`\n* **Dependencies**: only the standard library (no external packages)\n* **Entry point**: `python src/forecast.py`\n\nEnjoy the emoji weather!\n
