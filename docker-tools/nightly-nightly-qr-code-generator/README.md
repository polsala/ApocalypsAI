# Nightly QR Code Generator\n\nA whimsical Dockerized utility that turns any text into a QR code PNG. Perfect for post‑apocalyptic notes, secret messages, or just fun.\n\n## Usage\n\n```sh\n# Build the Docker image\ndocker build -t nightly-qr-code-generator .\n\n# Run the container, mounting the current directory to retrieve the output\ndocker run --rm -v "$(pwd)":/data nightly-qr-code-generator "Your message here"\n# QR code saved as ./qr.png\n```\n\nThe container expects a single argument (the text to encode). It writes `qr.png` to the mounted `/data` directory.
