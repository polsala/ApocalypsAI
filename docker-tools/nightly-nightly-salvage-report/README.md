# Nightly Salvage Report\n\nUtility to generate a whimsical salvage report from a list of found items.\n\n## What it does\n\n- Reads a JSON array of items (either from a file or STDIN)\n- Calculates the total value of all items (value * quantity)\n- Lists the top three most valuable items\n- Provides playful suggestions on how to repurpose each item\n\n## Input format\n\nThe input must be a JSON array where each element is an object with the following keys:\n\n```json\n[\n  {\n    "name": "Scrap Metal",\n    "quantity": 5,\n    "value": 12\n  },\n  {\n    "name": "Canned Food",\n    "quantity": 10,\n    "value": 3\n  }\n]\n```\n\n- `name` (string): descriptive name of the item\n- `quantity` (integer, optional, default 1)\n- `value` (number, optional, default 0) – value per single unit\n\n## Running the tool\n\nThe utility is packaged as a Docker container. Build and run it with:\n\n```bash\n# Build the image\ndocker build -t salvage-report .\n\n# Run with a file\ncat items.json | docker run -i salvage-report\n\n# Or pass a file path\ndocker run -v $(pwd)/items.json:/data/items.json salvage-report /data/items.json\n```\n\nThe output is a pretty‑printed JSON report, e.g.:\n\n```json\n{\n  "total_value": 150,\n  "top_items": [\n    {\n      "name": "Scrap Metal",\n      "total": 120\n    },\n    {\n      "name": "Medicine Kit",\n      "total": 30\n    }\n  ],\n  "suggestions": [\n    "Forge Scrap Metal into tools",\n    "Ration Canned Food for survivors",\n    "Use Medicine Kit to treat injuries"\n  ]\n}\n```\n\n## Testing\n\nUnit tests are provided under `tests/`. Run them with:\n\n```bash\npython -m unittest discover -s tests\n```\n\n## License\n\nMIT
