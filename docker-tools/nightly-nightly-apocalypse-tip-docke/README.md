Apocalypse Tip Docker\n\nA whimsical Docker container that prints a random post‑apocalyptic survival tip each time it runs. Perfect for a quick morale boost in the wasteland.\n\nUsage:\n\ndocker build -t apocalypse-tip .\ndocker run --rm apocalypse-tip\n\nThe container will output one tip, for example:\nAlways keep a spare can‑opener in your backpack.\n\nHow it works:\nThe image is based on Alpine Linux and runs a tiny shell script (entrypoint.sh) that selects a random line from tips.txt.\n\nFiles:\n- Dockerfile – builds the image.\n- entrypoint.sh – script executed at container start.\n- tips.txt – list of whimsical survival tips.\n- tests/ – simple bash tests.
