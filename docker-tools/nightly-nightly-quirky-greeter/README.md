# Nightly Quirky Greeter\n\n## Overview\n\n`nightly-quirky-greeter` is a minimal Docker container that prints a random whimsical greeting whenever it is executed.  It’s perfect for sprinkling a bit of post‑apocalyptic cheer into CI logs, terminal sessions, or any automated script.\n\n## Build the image\n\n```bash\ndocker build -t nightly-quirky-greeter .\n```\n\n## Run the container\n\n```bash\ndocker run --rm nightly-quirky-greeter\n```\n\nEach execution will output one of several playful greetings, e.g. \"Hello, wanderer of the wasteland!\".\n\n## How it works\n\nThe image is based on Alpine Linux and ships a tiny Bash script (`src/greeter.sh`) that selects a random line from an internal array and echoes it.\n\n## Testing\n\nThe utility includes a Python `unittest` suite (`tests/test_greeter.py`) that verifies the script’s output is always one of the expected greetings and checks that the Dockerfile contains the expected base image.\n\n## License\n\nMIT – see the repository LICENSE file.
