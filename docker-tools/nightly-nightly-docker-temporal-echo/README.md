# Nightly Docker Temporal Echo\n\n## Summary\n\nEver wished you could 'rewind' your Docker container to a previous state, or 'echo' a perfect development environment? The `nightly-docker-temporal-echo` utility allows you to snapshot the current state of a running Docker container and restore it later, creating a new container from that exact point in time. Perfect for debugging, consistent testing, or just experimenting without fear!\n\n## Usage\n\nThis utility provides a `temporal_echo.sh` script to manage your container snapshots. It works by committing a running container's filesystem state to a new Docker image, which then acts as your 'temporal echo'.\n\n### Prerequisites\n\n*   Docker installed and running.\n*   Bash shell.\n\n### 1. Build the Demo Application (Optional, for demonstration)\n\nFirst, let's build a simple demo application container that we can snapshot.\n\n```bash\ndocker build -t temporal-echo-demo .\n```\n\n### 2. Run the Demo Application\n\nStart an instance of our demo application. We'll name it `my-temporal-app`.\n\n```bash\ndocker run -d --name my-temporal-app temporal-echo-demo\n```\n\n### 3. Save a Temporal Echo (Snapshot)\n\nNow, let's save the current state of `my-temporal-app` as a snapshot named `initial-state`.\n\n```bash\n./src/temporal_echo.sh save my-temporal-app initial-state\n```\n\n### 4. Make Changes (to demonstrate state change)\n\nLet's simulate some work or changes inside the running container. We'll add a new file.\n\n```bash\ndocker exec my-temporal-app bash -c 'echo "Hello from the future!" > /app/future.txt'\ndocker exec my-temporal-app cat /app/future.txt\n```\n\n### 5. Load a Temporal Echo (Restore)\n\nNow, let's 'rewind' to our `initial-state`. This will create a *new* container from the snapshot.\n\n```bash\n./src/temporal_echo.sh load initial-state my-rewound-app\n```\n\nVerify that `my-rewound-app` does *not* have the `future.txt` file.\n\n```bash\ndocker exec my-rewound-app ls /app/\n# You should not see future.txt here\n```\n\n### 6. List All Temporal Echoes\n\nSee all your saved snapshots.\n\n```bash\n./src/temporal_echo.sh list\n```\n\n### 7. Delete a Temporal Echo\n\nRemove a snapshot image when you no longer need it.\n\n```bash\n./src/temporal_echo.sh delete initial-state\n```\n\n## Development\n\n### Structure\n\n*   `Dockerfile`: Defines a simple Python application for demonstration.\n*   `src/app.py`: The Python application run inside the demo container.\n*   `src/temporal_echo.sh`: The core utility script for managing snapshots.\n*   `tests/test_temporal_echo.sh`: Automated tests for the `temporal_echo.sh` script.\n\n### Running Tests\n\nTo run the automated tests, execute:\n\n```bash\n./tests/test_temporal_echo.sh\n```\n\nThese tests use mocks for Docker commands to ensure determinism and avoid requiring a live Docker daemon during testing.
