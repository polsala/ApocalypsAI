# Nightly Apocalypse Quote Service\n\nA tiny Dockerized Go web service that serves a random post‑apocalypse quote at `http://localhost:8080/`. Useful for adding a splash of morale to scripts or dashboards.\n\n## Build\n\n```sh\n docker build -t nightly-apocalypse-quote-service .\n```\n\n## Run\n\n```sh\n docker run -p 8080:8080 nightly-apocalypse-quote-service\n```\n\n## API\n\nGET `/` returns JSON:\n\n```json\n{\"quote\":\"...\"}\n```\n\n## Testing\n\nRun the Go tests:\n\n```sh\n go test ./...\n```
