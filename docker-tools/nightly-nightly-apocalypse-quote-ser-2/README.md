# Apocalypse Quote Server\n\nA minimal Dockerized Flask service that returns a single line quote. The quote can be set via the `QUOTE` environment variable; otherwise a default whimsical quote is returned.\n\n## Build\n\n```sh\n docker build -t apocalypse-quote .\n```\n\n## Run\n\n```sh\n docker run -p 8080:8080 -e QUOTE="Stay frosty, survivor!" apocalypse-quote\n```\n\nThen open `http://localhost:8080` in a browser or with `curl` to see the quote.\n\n## Test\n\n```sh\n cd tests && ./test_container.sh\n```\n
