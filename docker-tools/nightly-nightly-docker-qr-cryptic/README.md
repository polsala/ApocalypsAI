Nightly Docker QR Cryptic\n\nOverview:\nThis Docker image, when run, selects a random post-apocalyptic phrase, generates a QR code image (/qr.png), and serves it over HTTP on port 8080 using BusyBox httpd.\n\nUsage:\ndocker build -t nightly-qr-cryptic .\ndocker run -d -p 8080:8080 nightly-qr-cryptic\nAccess http://localhost:8080/qr.png to view the QR code.\n\nCustomization:\nSet the PHRASES_FILE environment variable to point to a custom list of phrases (one per line).
