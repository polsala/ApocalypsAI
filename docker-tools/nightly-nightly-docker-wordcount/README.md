# Nightly Docker Wordcount\n\nA tiny Docker image that provides a friendly, apocalypse‑themed word‑count utility. It prints the number of lines, words, and bytes of a given file or stdin, wrapped in a whimsical report.\n\n## Usage\n\n### Count a file\n\n```bash\n# Assuming you are in the directory containing the file\n# Replace <filename> with your file name\n\n docker run --rm -v $(pwd):/data nightly-docker-wordcount /data/<filename>\n```\n\n### Count from stdin\n\n```bash\n echo "Hello world" | docker run --rm -i nightly-docker-wordcount\n```\n\nThe container will output something like:\n\n```
🧭 Apocalypse Wordcount Report 🧭\nLines: 1\nWords: 2\nBytes: 12\n```\n\n## Building the Image\n\nIf you wish to build the image locally:\n\n```bash\n docker build -t nightly-docker-wordcount .\n```\n\n## License\n\nMIT
