# nightly-emoji-mood-analyzer\n\nA whimsical CLI tool that reads a line of text and returns an emoji representing the overall mood (happy 😊, sad 😢, angry 😠, neutral 😐). Uses a tiny built‑in sentiment word list, no external dependencies.\n\n## Installation\n\n```sh\nnpm install -g .\n```\n\n## Usage\n\n```sh\necho "I love sunny days" | node src/index.js\n# => 😊\n```\n\n## How it works\n\nThe script tokenizes the input, counts positive and negative words from predefined lists, and selects an emoji based on the net score.\n
