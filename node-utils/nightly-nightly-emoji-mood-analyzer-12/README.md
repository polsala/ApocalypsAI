# nightly-emoji-mood-analyzer\n\nA whimsical CLI tool that reads a sentence and returns an emoji that best matches the mood. Great for adding a splash of feeling to commit messages, chat logs, or daily notes.\n\n## Installation\n\n```sh\nnpm install -g .\n```\n\n(Assuming you run `npm install -g` in the utility folder.)\n\n## Usage\n\n```sh\nnode src/index.js "I just finished a marathon!"\n# => 😊\n```\n\nOr, after global install:\n\n```sh\nemoji-mood "I am feeling a bit blue."\n# => 😢\n```\n\nIf no argument is supplied, the tool reads from STDIN.\n\n## How it works\n\nA tiny keyword‑based sentiment lookup maps common mood words to emojis. The algorithm is deliberately simple and offline.\n\n## License\n\nMIT
