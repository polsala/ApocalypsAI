# Emoji Mood Analyzer\n\nA tiny Node.js CLI that reads a text file and prints an emoji representing the overall mood (happy 😊, sad 😢, neutral 😐) using simple keyword heuristics.\n\n## Installation\n\n```sh\ngit clone <repo>\ncd <path>\nnpm install\n```\n\n## Usage\n\n```sh\nnode src/index.js <path-to-text-file>\n```\n\nExample:\n\n```sh\necho "I love this awesome day!" > sample.txt\nnode src/index.js sample.txt\n# => 😊\n```\n\n## How it works\n\nThe script counts occurrences of a small set of positive and negative words. If positives outweigh negatives, it returns 😊; if negatives outweigh, 😢; otherwise 😐.\n\n## Testing\n\nRun the test script:\n\n```sh\nnode tests/test_cli.js\n```
