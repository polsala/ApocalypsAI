# nightly-emoji-mood-analyzer\n\nA tiny Node.js CLI that turns a sentence into an emoji reflecting its mood. Uses a handcrafted word list, no external services.\n\n## Installation\n\n```sh\nnpm install -g .\n# or run directly with node src/index.js\n```\n\n## Usage\n\n```sh\nnode src/index.js "I love sunny days"\n# => 😊\n\n# pipe input\necho "I am so angry!" | node src/index.js\n# => 😠\n```\n\n## How it works\n\nThe tool counts positive vs negative words from small dictionaries. If the count is equal, it returns a neutral face (😐).
