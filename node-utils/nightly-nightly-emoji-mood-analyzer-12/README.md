# nightly-emoji-mood-analyzer\n\nA whimsical yet handy command‑line utility that reads plain‑text input (from a pipe or argument) and prints a single emoji that reflects the overall mood of the text.\n\n## Features\n\n- **Zero dependencies** – pure JavaScript, runs on any Node.js 14+ runtime.\n- **Simple sentiment analysis** – uses a small built‑in keyword list, no external APIs.\n- **Works as a filter** – perfect for pipelines, chat bots, or just for fun.\n\n## Installation\n\n```bash\n# Clone the repository (or copy the utility folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/nightly-emoji-mood-analyzer\n# Install (optional, only needed if you want to use it as a global command)\nnpm install -g .\n```\n\n## Usage\n\nYou can pipe text into the tool or pass a string as an argument.\n\n```bash\n# Pipe from another command\necho "I love sunny days" | node src/index.js\n# => 😊\n\n# Direct argument\nnode src/index.js "I am feeling terrible today"\n# => 😢\n```\n\nIf you installed globally, you can use the shorter command:\n\n```bash\nemoji-mood "Just an ordinary day"\n# => 😐\n```\n\n## How it works\n\nThe script tokenises the input, counts occurrences of known positive and negative words, and decides the mood:\n\n- **Positive score > 0** → 😊 (happy)\n- **Negative score < 0** → 😢 (sad)\n- **Score == 0** → 😐 (neutral)\n\nThe word lists are deliberately tiny to keep the utility lightweight and deterministic.\n\n## Testing\n\nRun the bundled tests with Node:\n\n```bash\nnode tests/test_index.js\n```\n\nAll tests should pass, confirming the sentiment mapping works as expected.\n
