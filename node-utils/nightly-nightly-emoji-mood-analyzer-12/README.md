# Nightly Emoji Mood Analyzer\n\nA whimsical utility that reads a piece of text and returns an emoji representing its overall mood. It uses a tiny built‑in sentiment word list, works offline, and can be used as a CLI or imported as a module.\n\n## Installation\n\n```sh\nnpm install\nnode src/index.js "Your text here"\n```\n\n## Usage\n\n```sh\nnode src/index.js "I love sunny days"\n# => 😊\n\nnode src/index.js "I am sad and angry"\n# => 😞\n```\n\n## API\n\n```js\nconst { analyzeMood } = require('./index');\nconst emoji = analyzeMood("I feel great!");\n```\n\n## License\n\nMIT
