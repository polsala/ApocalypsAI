# Nightly Emoji Mood Analyzer\n\nA whimsical CLI utility that reads a sentence and returns an emoji representing its overall mood. Uses a tiny built‑in sentiment word list, works offline, and has no external dependencies.\n\n## Installation\n\n```sh\ngit clone <repo> && cd utils/nightly-emoji-mood-analyzer\nnpm install\n```\n\n## Usage\n\n```sh\nnode src/index.js "I love sunny days"\n# => 😊\n\n# Pipe from stdin\necho "I am so sad today" | node src/index.js\n# => 😢\n```\n\n## How it works\n\nThe tool scores words against a small positive/negative dictionary. Positive score → 😊, negative → 😢, neutral → 😐.\n\n## Testing\n\n```sh\nnode tests/test_index.js\n```
