# nightly-emoji-mood-analyzer\n\nA whimsical CLI utility that reads a line of text and returns an emoji representing the detected mood. It uses simple keyword heuristics to guess whether the sentiment is happy, sad, angry, or neutral.\n\n## Installation\n\n```sh\nnpm install -g .\n```\n\n(Assuming you copy the utility into a folder and run `npm install -g`.)\n\n## Usage\n\n```sh\nnode src/main.js "I just got a promotion!"\n# Output: 😊\n```\n\nOr after global install:\n\n```sh\nemoji-mood "I missed the bus."\n# Output: 😞\n```\n\n## How it works\n\nThe tool looks for keywords associated with four moods:\n\n- Happy: joy, love, great, awesome, fantastic, promotion, win, happy, glad\n- Sad: sad, down, terrible, lost, fail, missed, unhappy, depressed\n- Angry: angry, mad, furious, hate, rage, upset, irritated\n\nIf multiple moods match, the first in the order Happy → Sad → Angry wins. If none match, it returns a neutral face 🤔.\n\n## License\n\nMIT
