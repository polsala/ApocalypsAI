# nightly-apocalypse-chronicle\n\n**Generate a whimsical apocalyptic event for any date**\n\n## Overview\n\n`nightly-apocalypse-chronicle` is a tiny Node.js CLI that, given a date (or using today’s date by default), prints a fun, apocalyptic‑flavored description. The output is deterministic – the same date always yields the same event – making it perfect for puzzles, role‑playing games, or just a daily chuckle.\n\n## Installation\n\n```bash\n# Clone the repository (or copy the utility folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/nightly-apocalypse-chronicle\n\n# Ensure you have Node.js (v14+) installed\nnode -v\n\n# Make the script executable (optional)\nchmod +x src/main.js\n```\n\n## Usage\n\n```bash\n# Use today’s date (default)\nnode src/main.js\n\n# Provide a specific date (YYYY-MM-DD)\nnode src/main.js 2023-04-01\n```\n\n### Example Output\n\n```\nThe Great Pancake Flood of 2023 turned streets into syrup rivers.\n```\n\n## Testing\n\nThe utility ships with a deterministic test suite that runs with Node’s built‑in `assert` module. To execute the tests:\n\n```bash\nnode tests/test_main.js\n```\n\nAll tests should pass, confirming correct handling of known dates, fallback behavior, and error handling for invalid input.\n\n## License\n\nThis utility is released under the same MIT license as the rest of the ApocalypsAI project.\n
