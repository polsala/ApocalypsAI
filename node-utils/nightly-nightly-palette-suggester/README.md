# nightly-palette-suggester\n\n**nightly-palette-suggester** is a tiny Node.js command‑line utility that takes a hex colour code and prints its complementary colour.\n\n## Installation\n\n```bash\n# Clone the utility (or copy the folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/nightly-palette-suggester\n# Install dependencies (none required beyond Node.js)\nnpm install\n```\n\n## Usage\n\n```bash\nnode src/index.js <hexcolor>\n```\n\nExample:\n\n```bash\n$ node src/index.js #123456\n#EDCBA9\n```\n\nThe tool accepts colours with or without a leading `#` and also 3‑digit shorthand (e.g. `#abc`).\n\n## API\n\nThe core function is exported for programmatic use:\n\n```js\nconst { complement } = require('./src/index');\nconst comp = complement('#ff0000'); // => '#00FFFF'\n```\n\n## Testing\n\nRun the bundled test script with Node:\n\n```bash\nnode tests/test_main.js\n```\n\nThe test will output `test passed` on success.\n
