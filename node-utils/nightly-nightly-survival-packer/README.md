# Nightly Survival Packer\n\nA whimsical CLI utility that helps post‑apocalyptic survivors decide what to pack in their limited‑capacity backpack. It uses a simple knapsack algorithm to maximize total weight without exceeding the capacity.\n\n## Usage\n\n```sh\nnode src/main.js --items "water:3,food:2,radio:5" --capacity 5\n```\n\nThe program prints a JSON array of the selected item names. For the example above the output would be:\n\n```json\n[\"water\",\"food\"]\n```\n\n## Options\n\n- `--items`   Comma‑separated list of `name:weight` pairs.\n- `--capacity`   Maximum total weight (integer).\n\nIf no combination fits, an empty array `[]` is printed.\n
