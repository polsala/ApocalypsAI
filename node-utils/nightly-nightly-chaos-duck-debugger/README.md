# nightly-chaos-duck-debugger

A whimsical Node.js CLI utility that generates randomized debugging scenarios with helpful (and humorous) rubber duck hints.

## Usage

```bash
npx nightly-chaos-duck-debugger
```

## Features

- Random debugging scenario generator
- Humorous rubber duck hints
- Lightweight and fun

## Example Output

```
🚨 DEBUGGING CHALLENGE 🚨

You're debugging a function that's supposed to reverse a string, but it's returning numbers instead.

🦆 Rubber Duck says: "Quack! Maybe check if you're accidentally calling .length instead of .reverse()?"
```
