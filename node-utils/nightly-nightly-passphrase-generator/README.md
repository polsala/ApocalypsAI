nightly-passphrase-generator\n\nA whimsical yet useful command‑line utility that generates memorable, secure passphrases.\n\nFEATURES\n- Choose the number of words (default 4)\n- Optionally append a random digit and/or symbol\n- No external dependencies; uses Node's built‑in crypto for randomness\n\nINSTALLATION\n1. Clone the repository or copy the utility folder.\n2. Navigate to the utility directory.\n3. Run `npm install` (no packages are required, but this ensures a package.json is present).\n\nUSAGE\nRun the script with Node. Examples:\n\n    node src/index.js                # e.g., "solar mango river echo"\n    node src/index.js -w 6          # six words\n    node src/index.js -s -n         # include a symbol and a number\n\nOPTIONS\n-w <count>   Number of words to include (1‑10). Default is 4.\n-s           Append a random symbol from !@#$%^&*.\n-n           Append a random digit (0‑9).\n\nLICENSE\nMIT
