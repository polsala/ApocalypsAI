# nightly‑commit‑emoji‑enhancer\n\nA tiny Node.js utility that adds a fitting emoji to the beginning of a git commit message based on common conventional‑commit prefixes.\n\n## Why?\n\nCommit messages are more fun and instantly convey intent when they start with an emoji. This tool works offline, has no external dependencies, and can be used in scripts, git hooks, or manually.\n\n## Installation\n\n```bash\n# Clone the utility (or copy the files into your repo)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/nightly-commit-emoji-enhancer\n# No npm install needed – pure Node.js stdlib\n```\n\n## Usage\n\nYou can pass a commit message as an argument or pipe it via stdin.\n\n```bash\n# As an argument\nnode src/index.js "feat: add user login"\n# => ✨ feat: add user login\n\n# Via pipe (e.g., in a git hook)\necho "fix: correct typo" | node src/index.js\n# => 🛠️ fix: correct typo\n```\n\nIf the message does not start with a recognized conventional‑commit type, it is returned unchanged.\n\n## Supported prefixes and emojis\n\n| Prefix | Emoji |\n|--------|-------|\n| feat   | ✨    |\n| fix    | 🛠️   |\n| docs   | 📚    |\n| test   | ✅    |\n| refactor| ♻️   |\n| perf   | ⚡    |\n| chore  | 🔧    |\n| style  | 🎨    |\n| ci     | 🤖    |\n\n## Running the test suite\n\n```bash\nnode tests/test_index.js\n```\n\nYou should see `All tests passed` if everything works.\n\n## License\n\nMIT – see the LICENSE file in the repository root.
