# nightly-emoji-crypt\n\nEncode and decode messages using a whimsical emoji substitution cipher.\n\n## Installation\n\n```sh\nnpm install -g nightly-emoji-crypt\n```\n\n## Usage\n\n```sh\n# Encode a message\nnightly-emoji-crypt encode "hello world"\n\n# Decode a message\nnightly-emoji-crypt decode "😀 😃 😃 😆 🟦 😗 😃 😆 😃 😁"\n```\n\n## How it works\n\nEach latin letter is mapped to a unique emoji. Spaces become a blue square. The mapping is deterministic and reversible.\n\n## API\n\n```js\nconst { encode, decode } = require('nightly-emoji-crypt');\n\nconst secret = encode('hello');\nconst plain = decode(secret);\n```
