# Nightly Scarcity Knapsack\n\nUtility to compute the optimal set of items to carry given a weight limit, using the classic 0/1 knapsack dynamic programming algorithm. Perfect for post‑apocalypse scavengers who need to maximize the value of their loot while staying within a carrying capacity.\n\n## Installation\n\n```sh\nnpm install -g nightly-scarcity-knapsack\n```\n\n## Usage\n\n```sh\nnode src/index.js --maxWeight 15 --items '[{"name":"Water","weight":3,"value":4},{"name":"Food","weight":5,"value":6},{"name":"Medkit","weight":4,"value":7}]'\n```\n\nThe command prints a JSON array of the selected item names, e.g.:\n\n```json\n["Food","Medkit"]\n```\n\n## API\n\n```js\nconst { optimizeInventory } = require('./src/index');\nconst items = [\n  { name: 'Water', weight: 3, value: 4 },\n  { name: 'Food', weight: 5, value: 6 },\n  { name: 'Medkit', weight: 4, value: 7 }\n];\nconst maxWeight = 10;\nconst selected = optimizeInventory(items, maxWeight);\nconsole.log(selected); // -> [ 'Food', 'Medkit' ]\n```\n\n## License\n\nMIT\n
