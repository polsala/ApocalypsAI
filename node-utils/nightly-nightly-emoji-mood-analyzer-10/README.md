# Nightly Emoji Mood Analyzer\n\nA tiny Node.js command‑line utility that detects the mood of a short piece of text and prints a matching emoji.\n\n## Features\n\n- Simple keyword‑based mood detection (happy, sad, angry, surprised, fear, neutral)\n- Zero runtime dependencies – just Node.js (v12+)\n- Can be used as a global CLI or required as a module in other projects\n\n## Installation\n\n```bash\n# Clone the repository (or copy the utility folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/nightly-emoji-mood-analyzer\n# Install globally (optional)\nnpm install -g .\n```\n\n## Usage\n\n### As a CLI\n\n```bash\nemoji-mood "I am so happy and excited!"\n# => 😄\n```\n\nIf you installed it globally, the command is `emoji-mood`. Otherwise you can run it with Node:\n\n```bash\nnode src/index.js "I am sad about the news."\n# => 😢\n```\n\n### As a module\n\n```javascript\nconst {detectMood} = require('path/to/emoji-mood-analyzer/src/index');\nconsole.log(detectMood('Wow, that was surprising!')); // 😲\n```\n\n## How it works\n\nThe tool lower‑cases the input and checks for the presence of a small set of mood‑related keywords. The mood with the highest hit count wins; if no keywords match, it falls back to a neutral face.\n\n## Testing\n\nRun the bundled tests with Node:\n\n```bash\nnode tests/test_index.js\n```\n\nAll tests should pass, confirming deterministic behaviour.\n\n## License\n\nMIT – see the LICENSE file in the repository root.
