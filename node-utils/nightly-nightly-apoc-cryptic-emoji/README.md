# Nightly Apoc Cryptic Emoji\n\nA whimsical Node.js utility that encodes and decodes messages using a post‑apocalyptic emoji cipher. Perfect for secret notes among survivors.\n\n## Installation\n\n```sh\nnpm install -g nightly-apoc-cryptic-emoji\n```\n\n*(In this repository you can run it directly with Node.)*\n\n## Usage\n\n```sh\nnode src/main.js encode "Stay safe"\n# => 🌪️🧪🧿🧿 🧨🧿🧿🧿🧿\n\nnode src/main.js decode "🌪️🧪🧿🧿 🧨🧿🧿🧿🧿"\n# => stay safe\n```\n\n## API\n\n```js\nconst { encode, decode } = require('./main');\n```\n\n- `encode(text: string): string` – returns the emoji‑encoded string.\n- `decode(emojiText: string): string` – returns the original lower‑cased text.\n\n## Testing\n\nRun the bundled test script:\n\n```sh\nnode tests/test_main.js\n```
