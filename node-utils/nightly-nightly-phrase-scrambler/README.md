# nightly-phrase-scrambler\n\nA tiny Node.js utility that scrambles the interior letters of each word in a sentence while keeping the first and last letters intact. The result is still readable to humans but looks delightfully garbled – perfect for secret notes in a post‑apocalyptic bunker or just for fun.\n\n## Installation\n\n```bash\n# Clone the repository (or copy the utility folder into your project)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/nightly-phrase-scrambler\n# Install dependencies (none required beyond Node.js)\nnpm install\n```\n\n## Usage\n\nRun the CLI directly with a phrase argument:\n\n```bash\nnode src/index.js "The quick brown fox jumps over the lazy dog"\n```\n\nOutput:\n\n```
Teh qciuk bwron fox jpmus oevr teh lzay dgo\n```\n\nYou can also import the function in your own code:\n\n```javascript\nconst { scramblePhrase } = require('./src/index');\nconst result = scramblePhrase('Hello world');\nconsole.log(result); // hlleo wlrod\n```\n\n## Testing\n\nRun the bundled tests with Node:\n\n```bash\nnode tests/test_main.js\n```\n\nAll tests should pass without external network access.
