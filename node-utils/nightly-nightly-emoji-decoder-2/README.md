# nightly-emoji-decoder\n\n**nightly-emoji-decoder** is a tiny Node.js command‑line utility that turns a string of emojis into a space‑separated list of their textual meanings.  It’s perfect for decoding secret messages, adding a playful twist to logs, or just having fun with emojis.\n\n## Installation\n\n```bash\n# Clone the repo or copy the utility into your project\n# Then install globally (optional)\nnpm install -g .\n```\n\nOr run it without installing using npx:\n\n```bash\nnpx nightly-emoji-decoder "🚀🌕"\n```\n\n## Usage\n\n```bash\nnightly-emoji-decoder "<emoji‑string>"\n```\n\nThe utility will output a space‑separated list of words. Unknown emojis are reported as `<unknown>`.*\n\n### Examples\n\n```bash\nnightly-emoji-decoder "🚀🌕"\n# => rocket moon\n\nnightly-emoji-decoder "👽🤖💡"\n# => alien robot idea\n\nnightly-emoji-decoder "🦄✨❓"\n# => unicorn sparkle <unknown>\n```\n\n## How it works\n\nThe tool ships with a small built‑in dictionary mapping common emojis to English words.  The core function `decodeEmojis` is exported so it can be required in other Node projects or tested independently.\n\n## Testing\n\nRun the test suite with Node:\n\n```bash\nnode tests/test_index.js\n```\n\nAll tests should pass, confirming correct decoding and handling of unknown symbols.\n
