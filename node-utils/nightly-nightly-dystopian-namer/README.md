# Dystopian Namer

Generate post-apocalyptic names by combining decayed technology with survivalist motifs. Perfect for naming factions, settlements, or AI projects in dystopian contexts.

## Usage
```bash
node src/main.js
# => 'CrimsonCircuit Bastion'
```

## Examples
- `RustedHive Outpost`
- `AshenGrid Sanctuary`
- `FeralNode Collective`

Tested with deterministic mocks for reproducible naming.
