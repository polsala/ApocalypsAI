# Nightly Signal Sifter\n\n## Summary\nFilters and prioritizes incoming text signals, assigning whimsical interpretations and urgency scores based on configurable keywords and patterns. Essential for discerning meaningful transmissions from the post-apocalyptic static.\n\n## Installation\n\n1.  **Navigate to the utility directory:**\n    ```bash\n    cd nightly-signal-sifter\n    ```\n2.  **Install dependencies:**\n    ```bash\n    npm install\n    ```\n3.  **Make the CLI executable (optional, for global access):**\n    ```bash\n    npm link\n    # Now you can run `nightly-signal-sifter` from anywhere\n    ```\n\n## Usage\n\n### CLI (Command Line Interface)\n\nRun the utility with a direct signal string or a path to a file containing signals (one per line):\n\n```bash\nnightly-signal-sifter "Detected an anomaly in the void!"\n```\n\n```bash\n# Example: Process signals from a file\n# Create a file named signals.txt with content like:\n# Detected an anomaly in sector 7.\n# Urgent: danger detected, resource cache compromised!\n# [DEBUG] Processing heartbeat.\n# Just some random chatter on the comms.\nnightly-signal-sifter signals.txt\n```\n\n**Options:**\n\n*   `-c, --config <path>`: Path to a JSON configuration file to override default keywords, noise patterns, and urgency thresholds.\n*   `-j, --json`: Output results in JSON format instead of a formatted table.\n\n### Example with Custom Configuration\n\nCreate a `custom-config.json` file:\n\n```json\n{\n  "keywords": {\n    "threat": { "score": 12, "interpretation": "A grave threat looms!" },\n    "supply": { "score": 4, "interpretation": "A valuable cache awaits discovery." }\n  },\n  "noisePatterns": [\n    "^\\s*\[IDLE\].*$"\n  ],\n  "defaultInterpretation": "The winds whisper secrets untold.",\n  "urgencyThresholds": [\n    { "threshold": 0, "level": "Calm" },\n    { "threshold": 7, "level": "Warning" },\n    { "threshold": 15, "level": "Critical" }\n  ]\n}\n```\n\nThen run:\n\n```bash\nnightly-signal-sifter signals.txt -c custom-config.json -j\n```\n\n## Configuration Details\n\nThe utility uses a default configuration that can be partially or fully overridden by a custom JSON file.\n\n*   `keywords`: An object where keys are case-insensitive keywords to search for in signals. Each keyword maps to an object with:\n    *   `score`: A number representing the base urgency score added when the keyword is found.\n    *   `interpretation`: A whimsical string describing the meaning of the keyword's presence.\n*   `noisePatterns`: An array of regular expression strings (or actual RegExp objects if used programmatically) that, if matched by a signal, will classify it as noise and ignore it for scoring. Note: When providing in JSON, escape backslashes (e.g., `"^\\s*\[DEBUG\].*$"`).\n*   `defaultInterpretation`: The interpretation string used when no keywords are found in a signal.\n*   `urgencyThresholds`: An array of objects, each with a `threshold` (numeric score) and a `level` (string). These define how the calculated score maps to a human-readable urgency level. They should be sorted by `threshold` in ascending order.\n\n## Development & Testing\n\nTo run tests:\n\n```bash\nnpm test\n```\n
