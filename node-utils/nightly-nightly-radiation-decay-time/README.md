# Nightly Radiation Decay Timer\n\n## Overview\n\nThis tiny CLI tool estimates the remaining fraction of a radioactive isotope after a given elapsed time using its half‑life.  It is useful for post‑apocalyptic scavengers who need to know how much usable material is left in a contaminated object.\n\n## Installation\n\n```bash\n# Clone the repository (or copy the utility folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/nightly-radiation-decay-timer\nnpm install\n```\n\n## Usage\n\n```bash\nnode src/index.js --isotope <symbol> --elapsed <years>\n```\n\n* `--isotope` – Symbol of the isotope (supported: `C-14`, `I-131`, `U-235`).\n* `--elapsed` – Elapsed time in **years** (can be a decimal).\n\n### Example\n\n```bash\nnode src/index.js --isotope C-14 --elapsed 1000\n```\n\nOutput:\n\n```
Remaining fraction of C-14 after 1000 years: 0.8912509381337456\n```\n\n## Supported Isotopes\n\n| Isotope | Half‑life (years) |\n|---------|------------------|\n| C-14    | 5,730            |\n| I-131   | 8                |\n| U-235   | 703,800,000      |\n\n## Testing\n\nRun the bundled tests with:\n\n```bash\nnpm test\n```\n\nAll tests should pass on any platform with Node.js 14+.\n
