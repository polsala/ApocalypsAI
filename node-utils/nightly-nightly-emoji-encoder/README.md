# Nightly Emoji Encoder\n\n## Overview\n\n`nightly-emoji-encoder` is a tiny Node.js utility that transforms any UTF‑8 string into a sequence of emojis and back again. It uses a custom 64‑character emoji alphabet to represent Base64 data, turning ordinary text into a playful, human‑readable emoji string.\n\n## Installation\n\n1. Ensure you have **Node.js 14+** installed.\n2. Clone this repository (or copy the `src/` folder) to your machine.\n3. No external dependencies are required – the utility is self‑contained.\n\n## Usage\n\nThe utility can be run directly with Node:\n\n```bash\nnode src/index.js encode "Hello, world!"\n# 👉 😥😅🤔👽😥😀==\n\nnode src/index.js decode "😥😅🤔👽😥😀=="\n# 👉 Hello, world!\n```\n\n### Commands\n\n- `encode <text>` – Convert the supplied text into an emoji string.\n- `decode <emoji>` – Convert an emoji string back to the original text.\n\n## How It Works\n\n1. The input text is encoded to **Base64**.\n2. Each Base64 character (64 possible values) is mapped to a unique emoji from a predefined alphabet.\n3. Padding characters (`=`) are left unchanged so the output can be safely round‑tripped.\n\nDecoding performs the inverse mapping and restores the original UTF‑8 string.\n\n## Testing\n\nRun the bundled tests with Node:\n\n```bash\nnode tests/test_index.js\n```\n\nAll tests should pass, confirming that encode/decode are lossless.\n\n## License\n\nMIT – see the repository LICENSE file.\n
