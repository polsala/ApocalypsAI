# Emoji Mood Tracker

A whimsical CLI tool to log your mood using emojis and view simple statistics.

## Installation

```sh
npm install -g .
```

- Log a mood:

```sh

```

- Show statistics:

```sh

```

The data is stored in `~/.emoji_mood_log.json`.
