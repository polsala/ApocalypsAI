# nightly-emoji-mood-analyzer\n\nA whimsical CLI utility that reads a sentence and returns an emoji representing its mood. Uses a tiny built‑in sentiment word list, no external dependencies.\n\n## Installation\n\n```sh\ngit clone <repo>\ncd node-utils/nightly-emoji-mood-analyzer\nnpm install\n```\n\n## Usage\n\n```sh\n# Pipe text\necho "I love sunshine" | node src/index.js\n# => 😊\n\n# Pass as argument\nnode src/index.js "I am feeling gloomy"\n# => 😔\n```\n\n## How it works\n\nThe script tokenizes the input, counts positive and negative words from predefined lists, and selects an emoji based on the net score.\n
