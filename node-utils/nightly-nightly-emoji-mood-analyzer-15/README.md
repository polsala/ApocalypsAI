# Emoji Mood Analyzer\n\nA whimsical Node.js utility that reads a line of text and returns an emoji representing the overall mood.\n\n## Installation\n\n```sh\nnpm install -g .\n```\n\n## Usage\n\n```sh\nnode src/mood.js "I love this wonderful day!"\n# => 😊\n```\n\nOr after installing globally (the package sets a bin entry):\n\n```sh\nemoji-mood "I am sad."\n# => 😢\n```\n\n## How it works\n\nThe analyzer uses a simple keyword‑based sentiment scoring system. It looks for positive, negative, and angry words and computes a score to pick an appropriate emoji.\n\n## License\n\nMIT
