# Nightly Emoji Mood Analyzer\n\nA tiny, offline, whimsical CLI tool that examines a piece of text and returns an emoji representing its overall mood. No external dependencies – just a built‑in word list.\n\n## Installation\n\nCopy the utility folder into your project and run it with Node.js.\n\n```bash\nnode src/index.js "Your text here"\n```\n\nYou can also install it globally via npm if you add it to a package.json (see the provided `package.json`).\n\n## Usage\n\n```bash\n# Basic usage\nnode src/index.js "I love sunny days but hate rain"\n# => 😄 (or another emoji depending on the sentiment)\n\n# Using the installed binary (if added to package.json)\nemoji-mood "I am sad today"\n# => 🙁\n```\n\n## How it works\n\nThe analyzer tokenises the input, counts occurrences of a small set of positive and negative words, and maps the resulting score to an emoji:\n\n- Strongly positive (score > 1) → 😄\n- Slightly positive (score > 0) → 🙂\n- Strongly negative (score < -1) → 😞\n- Slightly negative (score < 0) → 🙁\n- Neutral or no recognizable sentiment → 🤔\n\n## Testing\n\nRun the bundled tests with:\n\n```bash\nnpm test\n```\n\nAll tests are deterministic and run offline.\n
