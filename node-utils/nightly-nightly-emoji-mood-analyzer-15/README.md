# Emoji Mood Analyzer\n\nA whimsical CLI utility that reads a line of text from stdin and outputs an emoji representing the overall mood (happy, sad, or neutral). Useful for quick sentiment checks in scripts or chat bots.\n\n## Installation\n\n```sh\nnpm install -g .\n```\n\n(Assuming you run `npm install -g` in the utility directory.)\n\n## Usage\n\n```sh\necho "I love sunny days" | node src/index.js\n# => 😊\n```\n\nYou can also require the module in other Node code:\n\n```js\nconst { analyzeMood } = require('./src/index');\nconsole.log(analyzeMood('I hate rain')); // 😞\n```\n\n## How it works\n\nThe analyzer uses a tiny built‑in word list of positive and negative terms to compute a simple score.
