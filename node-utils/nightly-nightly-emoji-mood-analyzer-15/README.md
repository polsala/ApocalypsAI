# nightly-emoji-mood-analyzer\n\nA tiny Node.js utility that examines a short string and returns a single emoji reflecting the dominant mood.\n\n## Features\n\n- Zero‑dependency, pure JavaScript\n- Simple keyword‑based sentiment detection (happy, sad, angry, love, fear, surprise, neutral)\n- Works as a CLI tool or as a library function\n\n## Installation\n\n```bash\n# Clone the repository (or copy the utility folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/nightly-emoji-mood-analyzer\n# No external packages required\n```\n\n## Usage\n\n### CLI\n\n```bash\nnode src/main.js "I just got a promotion!"\n# Output: 😊\n```\n\n### As a library\n\n```js\nconst { analyzeMood } = require('./src/main');\nconsole.log(analyzeMood('I am feeling terrible today.')); // 😢\n```\n\n## How it works\n\nThe script contains a small dictionary mapping mood‑related keywords to emojis. It tokenises the input, counts keyword occurrences for each mood, and selects the mood with the highest score. If no keywords match, it falls back to a neutral face (😐).\n\n## Testing\n\nRun the bundled tests with Node:\n\n```bash\nnode tests/test_main.js\n```\n\nAll tests should pass without any external dependencies.\n
