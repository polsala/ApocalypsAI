# nightly-emoji-mood-analyzer\n\nA whimsical CLI that reads a line of text from stdin and prints an emoji representing the overall mood.\n\n## Installation\n\n```sh\nnpm install\n```\n\n## Usage\n\n```sh\necho "I am feeling great today!" | node src/index.js\n# => 😊\n```\n\n## How it works\n\nThe tool uses a tiny built‑in sentiment dictionary. Words classified as positive add +1, negative -1. The final score maps to an emoji:\n\n- score > 1 → 😊\n- score < -1 → 😞\n- otherwise → 😐\n
