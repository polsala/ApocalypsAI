# nightly-emoji-mood-analyzer\n\nA whimsical CLI tool that scans a piece of text and returns a single emoji representing the overall mood. Useful for quickly tagging notes, commit messages, or chat logs with an emotional summary.\n\n## Installation\n\n```sh\nnpm install -g .\n```\n\n## Usage\n\n```sh\n# From a file\nnode src/index.js path/to/file.txt\n\n# From stdin\necho "I love sunny days!" | node src/index.js\n```\n\nThe tool prints one emoji to stdout.\n\n## How it works\n\nThe analyzer looks for keywords associated with four moods:\n\n- 😊 happy\n- 😢 sad\n- 😡 angry\n- 😐 neutral (default)\n\nIt counts occurrences and picks the mood with the highest count.\n\n## License\n\nMIT
