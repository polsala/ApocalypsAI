nightly-emoji-mood-analyzer\n\nA whimsical CLI utility that reads a sentence and returns an emoji representing its overall mood. It uses a tiny built‑in sentiment word list, works offline, and has no external dependencies.\n\nInstallation\n-------------\nClone the repository, navigate to the utility folder and install dependencies:\n\ngit clone <repo>\ncd utils/nightly-emoji-mood-analyzer\nnpm install\n\nUsage\n-----\nRun the script with a sentence as an argument:\n\nnode src/index.js "I love sunny days"\n=> 😊\n\nOr pipe text via stdin:\n\necho "I am so sad today" | node src/index.js\n=> 😢\n\nHow it works\n------------\nThe tool scores the input by counting positive and negative words from a small dictionary.\nPositive score yields 😊 (happy), negative score yields 😢 (sad), zero score yields 😐 (neutral).\n\nTesting\n-------\nnpm test
