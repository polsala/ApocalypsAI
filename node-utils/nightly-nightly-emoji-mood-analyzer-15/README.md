# Emoji Mood Analyzer\n\nA tiny Node.js utility that reads a piece of text and returns an emoji representing its overall mood.\n\n## Installation\n\n```sh\nnpm install -g .\n```\n\n## Usage\n\n```sh\nnode src/index.js "I love sunny days but hate the rain."\n# Output: 🙂\n```\n\nOr pipe from a file:\n\n```sh\ncat story.txt | node src/index.js\n```\n\n## How it works\n\nThe tool uses a simple word‑list based sentiment analysis. Positive words increase the score, negative words decrease it, and the final score is mapped to an emoji.\n\n## License\n\nMIT
