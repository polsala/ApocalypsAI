# Emoji Mood Analyzer\n\nA whimsical CLI tool that reads a line of text and returns an emoji representing the overall mood. It uses a tiny built‑in sentiment word list, so it works offline and instantly.\n\n## Installation\n\n```sh\nnpm install -g .\n```\n\n## Usage\n\n```sh\nnode src/index.js "I love sunny days"\n# 😊\n```\n\nOr, after global install:\n\n```sh\nemoji-mood "I love sunny days"\n# 😊\n```\n\n## How it works\n\nThe tool assigns +1 to positive words (e.g., love, happy, great) and -1 to negative words (e.g., hate, sad, terrible). The total score determines the emoji:\n\n- score > 0 → 😊\n- score == 0 → 😐\n- score < 0 → 😞\n\n## License\n\nMIT
