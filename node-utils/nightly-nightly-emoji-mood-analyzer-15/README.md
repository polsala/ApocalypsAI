# nightly-emoji-mood-analyzer\n\nA tiny Node.js utility that analyzes a short piece of text and returns an emoji that reflects the overall mood.\n\n## Features\n\n- **Whimsical**: Turns feelings into emojis.\n- **Zero dependencies**: Pure JavaScript, works on any recent Node.js runtime.\n- **CLI & library**: Use it from the command line or import the `analyzeMood` function in your own code.\n\n## Installation\n\n```bash\n# Clone the repository (or copy the utility folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/nightly-emoji-mood-analyzer\n# No external packages required\n```\n\n## Usage\n\n### As a CLI\n\n```bash\nnode src/index.js "I love sunny days!"\n# Output: 😊\n```\n\nIf no argument is supplied, the utility reads from STDIN:\n\n```bash\necho "I hate traffic" | node src/index.js\n# Output: 😠\n```\n\n### As a library\n\n```javascript\nconst { analyzeMood } = require('./src/index');\nconsole.log(analyzeMood('It is an average day.')); // 😐\n```\n\n## How it works\n\nThe analyzer uses a tiny built‑in sentiment dictionary. Positive words increase a score, negative words decrease it. The final score maps to one of three emojis:\n\n- **Positive (score > 0)** → 😊\n- **Negative (score < 0)** → 😠\n- **Neutral (score == 0)** → 😐\n\n## Testing\n\nRun the bundled tests with Node:\n\n```bash\nnode tests/test_index.js\n```\n\nAll tests should pass, confirming correct mood detection.\n\n## License\n\nMIT © ApocalypsAI
