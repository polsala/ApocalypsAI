# Emoji Mood Analyzer\n\nA whimsical CLI tool that takes a piece of text and returns an emoji representing its overall mood (happy 😊, sad 😢, angry 😠, neutral 😐). It uses a tiny built‑in word list, works offline, and has no external dependencies.\n\n## Installation\n\n```sh\nnpm install -g .\n```\n\n## Usage\n\n```sh\nnode src/index.js "I love sunny days!"\n# => 😊\n```\n\n## How it works\n\nThe script tokenizes the input, counts positive and negative words from a small dictionary, and selects an emoji based on the score.\n\n## Testing\n\n```sh\nnode tests/test_index.js\n```
