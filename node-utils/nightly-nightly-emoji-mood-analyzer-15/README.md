# Nightly Emoji Mood Analyzer\n\nUtility that scans a piece of text and returns a single emoji representing the overall mood. Uses simple keyword matching for happy, sad, angry, surprised, neutral.\n\n## Installation\n\n```sh\nnpm install -g nightly-emoji-mood-analyzer\n```\n\n## Usage\n\n```sh\n# Analyze a file\nnightly-emoji-mood-analyzer path/to/file.txt\n\n# Pipe text\necho "I love sunny days!" | nightly-emoji-mood-analyzer\n```\n\n## How it works\n\nIt tokenizes the input, counts occurrences of words from predefined mood dictionaries, and picks the mood with highest score. If tie or none, returns 🤔.\n\n## License\n\nMIT
