# nightly-emoji-mood-analyzer\n\nA whimsical CLI tool that analyzes a short piece of text and returns an emoji representing its overall mood. Uses a tiny built‑in sentiment word list, works offline, and has no external dependencies.\n\n## Installation\n\n```sh\nnpm install -g .\n```\n\n## Usage\n\n```sh\nnode src/index.js "I love sunny days!"\n# 😊\n\nnode src/index.js "I am so angry about the traffic."\n# 😠\n```\n\n## How it works\n\nCounts occurrences of positive and negative words from a small dictionary. If positives > negatives → 😊, if negatives > positives → 😠, else 😐.\n\n## Testing\n\n```sh\nnpm test\n```
