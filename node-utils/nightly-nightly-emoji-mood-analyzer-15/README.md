# nightly-emoji-mood-analyzer\n\nA tiny Node.js utility that inspects a piece of text and returns an emoji that best matches the detected mood.\n\n## Features\n\n- **Whimsical**: Returns a happy 😄, sad 😢, angry 😠, or thoughtful 🤔 emoji.\n- **Zero dependencies**: Pure JavaScript, works with any recent Node runtime.\n- **Deterministic**: Uses simple keyword matching, no external APIs.\n\n## Installation\n\nCopy the `src/` folder into your project or install via npm (if you publish it). No additional packages are required.\n\n```bash\n# Clone the utility\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/nightly-emoji-mood-analyzer\n# Run the tests to verify\nnode tests/test_index.js\n```\n\n## Usage\n\n```js\nconst { analyzeMood } = require('./src/index');\n\nconsole.log(analyzeMood('I am feeling great and happy!')); // 😄\nconsole.log(analyzeMood('Today was terrible and sad.'));   // 😢\nconsole.log(analyzeMood('I am so angry right now!'));    // 😠\nconsole.log(analyzeMood('Just an ordinary day.'));      // 🤔\n```\n\n## How it works\n\nThe script looks for a set of hard‑coded keywords associated with three basic emotions. The emotion with the highest match count wins. If no keywords are found, a neutral 🤔 emoji is returned.\n\n## Testing\n\nRun the bundled test file with Node:\n\n```bash\nnode tests/test_index.js\n```\n\nYou should see `All tests passed` if everything is working.
