# nightly-emoji-mood-analyzer\n\nA tiny Node.js CLI that scans a sentence and returns an emoji representing the detected mood. Uses a handcrafted word‑to‑emoji map, no external APIs.\n\n## Installation\n\n```sh\nnpm install -g .\n```\n\n## Usage\n\n```sh\necho "I love sunny days!" | nma\n# => 😊\n```\n\nor\n\n```sh\nnma "I am feeling gloomy."\n# => 😔\n```\n\n## How it works\n\nIt tokenizes the input, counts positive and negative keywords, and selects an emoji.\n\n## License\n\nMIT
