# Nightly Emoji Mood Analyzer\n\nA whimsical CLI tool that takes a sentence and returns an emoji representing the overall mood.\n\n## Features\n- Simple sentiment analysis using built‑in word lists\n- Works with command‑line arguments or piped input\n- Zero external dependencies\n\n## Installation\n\n```bash\nnpm install -g nightly-emoji-mood-analyzer\n```\n\n## Usage\n\n```bash\n# Pass the text as an argument\nemoji-mood "I love sunny days!"\n# => 😄\n\n# Pipe text via stdin\necho "I hate rainy weather" | emoji-mood\n# => 😢\n```\n\n## How it works\nThe tool tokenises the input, scores each word against a small list of positive and negative keywords, and maps the final score to one of three emojis:\n- **Score > 1** → 😄 (happy)\n- **Score < -1** → 😢 (sad)\n- **Otherwise** → 😐 (neutral)\n\n## Contributing\nFeel free to open issues or PRs to improve the word lists or add more nuanced sentiment handling.\n\n## License\nMIT
