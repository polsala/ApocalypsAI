# Nightly Emoji Mood Analyzer\n\nA whimsical CLI utility that reads a short piece of text and returns an emoji representing its overall mood.\n\n## Installation\n\n```sh\n# Clone the repository (or copy the utility folder)\ngit clone <repo-url>\ncd utils/nightly-emoji-mood-analyzer\n# No external dependencies required; just ensure Node.js is installed\n```\n\n## Usage\n\n```sh\nnode src/index.js "I love sunny days"\n# => 😊\n```\n\nIf no argument is provided, the tool prints a neutral face.\n\n## How it works\n\nA tiny built‑in word list classifies words as positive or negative, tallies a score and maps the result to one of three emojis:\n\n- Positive → 😊\n- Negative → ☹️\n- Neutral → 😐\n\n## Testing\n\n```sh\nnode tests/test_index.js\n```\nAll tests should pass.\n
