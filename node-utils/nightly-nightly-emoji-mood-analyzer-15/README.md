# nightly-emoji-mood-analyzer\n\nA tiny Node.js utility that reads a string of text and returns an emoji that reflects the overall mood of the message.\n\n## Features\n\n- Simple keyword‑based sentiment analysis (no external APIs)\n- Works as a library (`require`) or a CLI tool\n- Zero runtime dependencies – just plain Node.js\n\n## Installation\n\n```bash\n# Clone the repository (or copy the folder into your project)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/nightly-emoji-mood-analyzer\n# No npm install needed – the code uses only the Node standard library\n```\n\n## Usage as a library\n\n```js\nconst { analyzeMood } = require('./src/index');\n\nconsole.log(analyzeMood('I love sunny days!')); // 😊\nconsole.log(analyzeMood('I am so sad and tired.')); // 😢\n```\n\n## Usage as a CLI\n\n```bash\nnode src/index.js "I am feeling great today!"\n# → 😊\n\nnode src/index.js "Everything is terrible..."\n# → 😢\n```\n\nIf no argument is supplied, the tool reads from STDIN:\n\n```bash\necho "Just okay." | node src/index.js\n# → 😐\n```\n\n## Testing\n\nRun the bundled tests with Node:\n\n```bash\nnode tests/test_index.js\n```\n\nAll tests should pass without any external network calls.\n
