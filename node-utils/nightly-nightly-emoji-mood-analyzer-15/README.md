# Nightly Emoji Mood Analyzer\n\nA whimsical command‑line utility that reads a piece of text (from a file or STDIN) and returns a single emoji representing the overall mood.\n\n## Features\n\n- Tiny built‑in sentiment word list (no external dependencies)\n- Works with files or piped input\n- Returns 😊 for positive, 😢 for negative, 😐 for neutral\n\n## Installation\n\n```bash\n# Clone the repository (or copy the utility folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/nightly-emoji-mood-analyzer\nnpm install\n```\n\n> **Note**: The `package.json` is minimal and only declares the entry point. No additional packages are required.\n\n## Usage\n\n### From a file\n\n```bash\nnode src/index.js path/to/text.txt\n```\n\n### From STDIN (pipe)\n\n```bash\necho "I love this sunny day!" | node src/index.js\n```\n\nThe program will output a single emoji to STDOUT.\n\n## Example\n\n```text\nI am so happy and excited about the new project!\n```\n\n```bash\nnode src/index.js example.txt\n# Output: 😊\n```\n\n## Testing\n\nRun the bundled test script with Node:\n\n```bash\nnode tests/test_index.js\n```\n\nYou should see `All tests passed` if everything works.\n
