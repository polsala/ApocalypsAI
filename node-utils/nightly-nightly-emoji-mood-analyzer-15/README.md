nightly-emoji-mood-analyzer\n\nA whimsical CLI utility that evaluates a short piece of text and returns an emoji that best represents its overall mood.\n\nInstallation\nClone the repository and run the script with Node.\n\nUsage\nnode src/index.js "I am feeling great today!"\n=> 😄\n\nHow it works\nThe tool uses a tiny built‑in sentiment dictionary. It counts words that belong to happy, sad, or angry lists and picks the dominant emotion. If no clear winner, it returns a neutral emoji 🤔.\n\nLicense\nMIT
