Nightly Emoji Mood Analyzer\n\nA whimsical command‑line utility that reads a sentence and returns an emoji representing its overall mood.\nIt uses a tiny built‑in word list, no external dependencies.\n\nInstallation:\n  npm install -g .\n\nUsage:\n  npx nightly-emoji-mood-analyzer "I love sunny days"\n  => 😊\n\n  echo "I am sad" | npx nightly-emoji-mood-analyzer\n  => 😞\n\nIf no input is provided, the tool reads from standard input.\n\nExit codes:\n  0 – successful output\n  1 – no input provided
