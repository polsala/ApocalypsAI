# Emoji Mood Analyzer\n\nA whimsical CLI utility that reads a short piece of text and returns an emoji representing its overall mood. Uses a tiny built‑in sentiment word list, works offline, and has no external dependencies.\n\n## Installation\n\n```sh\ngit clone <repo> && cd utils/nightly-emoji-mood-analyzer\nnpm install   # no runtime dependencies required\n```\n\n## Usage\n\n```sh\nnode src/index.js "I love sunny days"\n# => 😊\n\nnode src/index.js "I hate rainy mornings"\n# => 😢\n\necho "Just another day" | node src/index.js\n# => 😐\n```\n\n## How it works\n\nThe script tokenises the input, counts occurrences of a small set of positive and negative words, and selects an emoji:\n\n- Positive score → 😊\n- Negative score → 😢\n- Zero/neutral → 😐\n\n## Testing\n\n```sh\nnode tests/test_index.js\n```
