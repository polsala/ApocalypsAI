# Emoji Mood Analyzer\n\nA whimsical command‑line utility that reads a short piece of text and returns an emoji representing its overall mood.\n\n## Installation\n\n```sh\nnpm install -g .\n```\n\n## Usage\n\n```sh\n# Pass text as arguments\nemoji-mood-analyzer I love sunny days\n\n# Or pipe text via stdin\necho "I hate rain" | emoji-mood-analyzer\n```\n\nThe tool uses a tiny built‑in word list to score sentiment and chooses an emoji:\n\n- 😊 very positive\n- 🙂 slightly positive\n- 😐 neutral\n- 🙁 slightly negative\n- 😠 very negative\n\n## License\n\nMIT
