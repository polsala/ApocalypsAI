# nightly-emoji-mood-analyzer\n\nA whimsical yet handy command‑line utility that reads a short piece of text and returns an emoji that reflects the overall mood of the message.\n\n## Installation\n\n```bash\n# Clone the repository (or copy the utility folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/nightly-emoji-mood-analyzer\n# Install dependencies (none required beyond Node.js)\n# Ensure you have Node.js 14+ installed\n```\n\n## Usage\n\n```bash\n# Direct CLI usage\nnode src/main.js "I am feeling great and happy today!"\n# => 😄\n\nnode src/main.js "This is terrible, I am sad."\n# => 😢\n```\n\nYou can also use the library programmatically:\n\n```js\nconst { analyzeMood } = require('./src/main');\nconsole.log(analyzeMood('Just an ordinary day.')); // 😐\n```\n\n## How It Works\n\nThe tool contains two small word lists – one for positive sentiment and one for negative sentiment. It tokenises the input, counts matches from each list and decides the mood based on the net score.\n\n* **Positive score** → 😄 (happy)\n* **Negative score** → 😢 (sad)\n* **Zero or neutral** → 😐 (neutral)\n\n## Testing\n\nRun the test suite with Node's built‑in `assert` module:\n\n```bash\nnode tests/test_main.js\n```\nAll tests should pass without external dependencies.
