# nightly-emoji-mood-analyzer\n\nAnalyzes a piece of text and returns a single emoji representing its overall mood.\n\n## Installation\n\n```sh\nnpm install -g .\n```\n\n## Usage\n\n```sh\nemoji-mood "I love sunny days!"\n# => 😊\n```\n\nOr pipe:\n\n```sh\necho "I am so angry about the traffic." | emoji-mood\n# => 😠\n```\n\n## How it works\n\nUses a tiny built‑in word list for positive, negative, and angry words. The first matching category decides the emoji. If none match, returns 🤔.\n\n## License\n\nMIT
