# nightly-emoji-mood-analyzer\n\nA whimsical CLI that turns a sentence into an emoji representing its overall mood.\n\n## Install\n\n```sh\nnpm install -g .\n```\n\n## Usage\n\n```sh\nnode src/index.js "I love sunny days but hate rain"\n```\n\nThe command prints an emoji such as 😊, 😢, 🙂, 🙁 or 😐.\n\n## How it works\n\nThe tool uses a tiny word‑list sentiment analyzer. It counts occurrences of known positive and negative words and selects an emoji based on the net score. No external services are required, making it fast and offline.
