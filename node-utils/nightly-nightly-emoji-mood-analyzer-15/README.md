# nightly-emoji-mood-analyzer\n\nA tiny Node.js command‑line utility that reads a line of text from **STDIN** and prints a single emoji that best matches the overall mood of the sentence.\n\n## Why?\n\nSometimes you just need a quick visual cue of how a message feels – perfect for chat bots, commit messages, or just for fun.\n\n## Installation\n\n```bash\n# Clone the utility (or copy the folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/nightly-emoji-mood-analyzer\n# Install dependencies\nnpm install\n```\n\n## Usage\n\n```bash\n# Pipe a sentence into the CLI\necho "I am thrilled about the new release!" | node src/index.js\n# => 😊\n\n# Or run it interactively\nnode src/index.js\n# (type your sentence and press Enter)\n```\n\n## Supported moods and emojis\n\n| Mood | Emoji | Keywords (partial match) |\n|------|-------|---------------------------|\n| Happy | 😊 | happy, joy, thrilled, excited, love, wonderful |\n| Sad | 😢 | sad, sorrow, upset, depressed, down, miserable |\n| Angry | 😠 | angry, mad, furious, rage, upset, annoyed |\n| Fearful | 😨 | scared, fear, terrified, anxious, nervous |\n| Surprised | 😲 | surprised, wow, amazed, astonished, shocked |\n| Neutral/Unknown | 🤔 | (no matching keywords) |\n\n## Testing\n\n```bash\nnpm test\n```\n\nThe test suite runs a few deterministic cases to ensure the correct emoji is emitted.\n
