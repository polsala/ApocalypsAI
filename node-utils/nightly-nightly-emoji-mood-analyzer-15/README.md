# nightly-emoji-mood-analyzer\n\nA whimsical CLI tool that scans a piece of text and returns an emoji representing its overall mood (happy 😊, sad 😢, angry 😠, neutral 😐). It uses a tiny built‑in sentiment word list, works offline, and has no external dependencies.\n\n## Installation\n\n```sh\nnpm install -g .\n```\n\n## Usage\n\n```sh\necho "I love sunny days!" | nemoji\n# => 😊\n\n nemoji "I am so frustrated with this bug."\n# => 😠\n```\n\n## How it works\n\nThe tool tokenizes the input, counts positive and negative words from predefined lists, and selects an emoji based on the net score.\n\n## Testing\n\n```sh\nnpm test\n```
