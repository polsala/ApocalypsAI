# nightly-emoji-mood-analyzer\n\nA whimsical CLI that turns a sentence into an emoji representing its mood.\n\n## Installation\n\n```sh\nnpm install -g .\n```\n\n## Usage\n\n```sh\nnode src/index.js "I love sunny days"\n# 😊\n```\n\n## How it works\n\nThe tool uses a tiny word‑list sentiment analyzer to count happy, sad, and angry keywords and returns the corresponding emoji. If no sentiment is detected, a neutral face is shown.\n
