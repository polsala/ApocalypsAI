# nightly-emoji-mood-analyzer\n\nA whimsical CLI utility that translates a short piece of text into an emoji representing its overall mood. Useful for adding emotional flair to commit messages, chat bots, or journal entries.\n\n## Installation\n\n```sh\nnpm install -g .\n# or run directly with node\n```\n\n## Usage\n\n```sh\nnode src/index.js "I love sunny days"\n# => 😊\n```\n\n## How it works\n\nSimple keyword‑based sentiment analysis using built‑in word lists. No external dependencies.\n\n## License\n\nMIT
