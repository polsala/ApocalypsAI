# nightly-emoji-mood-analyzer\n\nA whimsical CLI tool that reads a sentence and returns an emoji representing the overall mood. Uses a tiny built‑in sentiment word list, works offline, and has no external dependencies.\n\n## Installation\n\n```sh\n# Clone the utility (or copy the folder)\ngit clone <repo-url> && cd utils/nightly-emoji-mood-analyzer\n# Install (no external deps, but npm init can be used if desired)\nnpm install\n```\n\n(Or just run with `node src/index.js`.)\n\n## Usage\n\n```sh\nnode src/index.js "I love sunny days but hate rain"\n```\n\nWill output an emoji, for example:\n\n```
😊\n```\n\n## How it works\n\nThe tool counts occurrences of positive vs. negative words from a small dictionary and picks an emoji:\n\n- more positives → 😊\n- more negatives → 😢\n- tie or none   → 😐\n\n## Testing\n\n```sh\nnode tests/test_index.js\n```\n\nThe test script runs a few deterministic cases and prints `All tests passed` when successful.
