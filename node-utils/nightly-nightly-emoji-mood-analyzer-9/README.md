# nightly-emoji-mood-analyzer\n\nA tiny Node.js utility that evaluates a short piece of text and returns an emoji reflecting its mood (😊, 😢, 😠, 🤔). Useful for adding emotional flair to logs, commit messages, or chat bots.\n\n## Installation\n\n```sh\nnpm install -g nightly-emoji-mood-analyzer\n```\n\n## Usage\n\n```sh\nnpx nightly-emoji-mood-analyzer "I love the new features!"\n# => 😊\n```\n\nOr pipe input:\n\n```sh\necho "The build failed again." | npx nightly-emoji-mood-analyzer\n# => 😠\n```\n\n## How it works\n\nThe tool uses a simple word‑list sentiment analysis: it counts occurrences of positive and negative keywords. If positives outweigh negatives, it returns a happy emoji; if negatives outweigh positives, an angry emoji; otherwise a neutral thinking emoji.\n\n## Testing\n\n```sh\nnpm test\n```
