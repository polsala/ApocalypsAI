# Nightly Emoji Cryptic Decoder\n\n## Overview\n\n`nightly-emoji-cryptic-decoder` is a tiny Node.js command‑line utility that takes a sequence of emojis and expands each emoji into a list of possible words. It then prints **all** possible combinations, turning cryptic emoji strings into readable phrases.\n\nThe tool is deliberately whimsical – perfect for post‑apocalyptic secret messages, role‑playing games, or just for fun.\n\n## Installation\n\n```bash\n# Clone the repository (or copy the utility folder into your project)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/nightly-emoji-cryptic-decoder\n# No external dependencies required – just Node.js (v14+)\n```\n\n## Usage\n\n```bash\nnode src/main.js "🌞⚔️"\n```\n\nThe above command will output all textual interpretations of the emojis `🌞` (sun/day) and `⚔️` (sword/battle):\n\n```
sun sword\nsun battle\nday sword\nday battle\n```\n\n## Adding New Emoji Mappings\n\nEdit `src/main.js` and extend the `dictionary` object with new emoji keys and an array of possible words.\n\n## Testing\n\nRun the bundled test suite with:\n\n```bash\nnode tests/test_main.js\n```\n\nYou should see `All tests passed` if everything is working.\n\n## License\n\nMIT – see the root LICENSE file.\n
