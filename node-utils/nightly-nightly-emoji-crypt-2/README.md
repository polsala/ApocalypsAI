# nightly-emoji-crypt\n\nA tiny Node.js utility that turns plain text into a string of moon‑phase emojis (🌑 for 0, 🌕 for 1) and back again. Perfect for secret notes, post‑apocalyptic journals, or just a fun way to hide messages.\n\n## Features\n\n- **Encode** any UTF‑8 string into emojis.\n- **Decode** an emoji string back to the original text.\n- Zero external dependencies – pure JavaScript.\n- Works as a CLI tool or as a library.\n\n## Installation\n\n```bash\n# Clone the repository (or let the ApocalypsAI bot add it)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/nightly-emoji-crypt\n# No npm install needed – the script is self‑contained\n```\n\n## Usage\n\n### CLI\n\n```bash\n# Make the script executable\nchmod +x src/emoji-crypt.js\n\n# Encode a message\n./src/emoji-crypt.js encode "Hello"\n# => 🌑🌕🌑🌑🌑🌑🌑🌕 🌑🌑🌑🌕🌑🌑🌑🌑 🌑🌑🌑🌑🌑🌑🌑🌕 🌑🌑🌑🌑🌑🌑🌑🌕 🌑🌑🌑🌑🌑🌑🌑🌕\n\n# Decode the result\n./src/emoji-crypt.js decode "🌑🌕🌑🌑🌑🌑🌑🌕 🌑🌑🌑🌕🌑🌑🌑🌑"\n# => He\n```\n\n### As a library\n\n```js\nconst { encode, decode } = require('./src/emoji-crypt');\n\nconst secret = encode('Apocalypse');\nconsole.log(secret); // 🌑🌕🌑🌑🌑🌑🌑🌕 ...\n\nconst original = decode(secret);\nconsole.log(original); // Apocalypse\n```\n\n## Testing\n\nRun the bundled test with Node:\n\n```bash\nnode tests/test_emoji_crypt.js\n```\n\nYou should see `All tests passed`.\n\n## License\n\nMIT – see LICENSE file in the repository root.\n
