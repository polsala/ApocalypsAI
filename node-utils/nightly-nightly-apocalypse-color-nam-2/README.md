Nightly Apocalypse Color Namer\n--------------------------------\nUtility that translates a hex color code into a post‑apocalyptic themed color name.\n\nFeatures\n- Nearest‑match algorithm against a curated list of wasteland colors.\n- Works as a Node.js library or a command‑line tool.\n- No external dependencies.\n\nInstallation\nSave the files under the utility directory. Ensure Node.js (>=12) is installed.\n\nUsage (CLI)\n  node src/index.js <hex>\nExample:\n  node src/index.js #8B0000\n  Radiation Red\n\nUsage (Library)\n  const { getApocalypseColorName } = require('./src/index');\n  const name = getApocalypseColorName('#8B0000');\n  // => 'Radiation Red'\n\nTesting\nRun the test script with Node:\n  node tests/test_index.js
