# Nightly Gear Optimizer\n\nUtility to select the best combination of survival gear items given a weight limit.\nIt uses the classic 0/1 knapsack dynamic‑programming algorithm.\n\n## Features\n\n- Pure JavaScript, no external dependencies.\n- Can be used as a library (`require('./src/main')`) or as a CLI tool.\n- Deterministic, offline, and fully unit‑tested.\n\n## Installation\n\n```sh\n# Clone the repository and install (optional)\ngit clone <repo-url>\ncd nightly-gear-optimizer\nnpm install   # installs dev dependencies only (none required)\n```\n\n## Usage as a library\n\n```js\nconst { optimizeGear } = require('./src/main');\n\nconst items = [\n  { name: 'Water', weight: 3, value: 10 },\n  { name: 'Food', weight: 2, value: 8 },\n  { name: 'Radio', weight: 1, value: 5 }\n];\nconst maxWeight = 5;\n\nconst bestSet = optimizeGear(items, maxWeight);\nconsole.log(bestSet);\n```\n\n## Usage as a CLI\n\nThe CLI expects a single JSON argument or JSON on STDIN with the shape `{\"items\": [...], \"maxWeight\": number}`.\n\n```sh\n# Pass JSON as an argument\nnode src/main.js '{"items":[{"name":"Water","weight":3,"value":10},{"name":"Food","weight":2,"value":8},{"name":"Radio","weight":1,"value":5}],"maxWeight":5}'\n\n# Or pipe JSON via STDIN\ncat payload.json | node src/main.js\n```\n\nThe output is a pretty‑printed JSON array of the selected items.\n\n## Testing\n\nRun the bundled test suite with:\n\n```sh\nnpm test\n```\n\nAll tests should pass on any Node 12+ runtime.\n
