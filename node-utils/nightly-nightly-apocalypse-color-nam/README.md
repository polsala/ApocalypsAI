# Nightly Apocalypse Color Namer

Generate a dramatic, apocalypse‑themed name for any hex color code.

## Installation

```sh
npm install
```

## Usage

```sh
node src/index.js #ff5733
# => Blazing Ember
```

The utility converts the hex color to HSL, then selects an adjective based on hue and a noun based on lightness/saturation to produce a memorable name.

## Testing

```sh
npm test
```
