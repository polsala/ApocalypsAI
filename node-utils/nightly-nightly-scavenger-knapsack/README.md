# Nightly Scavenger Knapsack\n\nUtility to help survivors choose the most valuable items to carry given a weight capacity. Uses the classic 0/1 knapsack algorithm.\n\n## Install\n\n```sh\nnpm install\n```\n\n## Usage\n\n```sh\nnode src/cli.js --capacity 10 --items '[{"name":"Canned Beans","weight":3,"value":5},{"name":"Water Bottle","weight":2,"value":3},{"name":"First Aid Kit","weight":5,"value":9}]'\n```\n\nThe command prints a JSON array of the selected items.\n\n## How it works\n\nImplements dynamic programming to maximize total value without exceeding capacity.\n\n## Tests\n\nRun `node tests/knapsack.test.js` to execute the deterministic test suite.\n
