# nightly-emoji-mood-tracker\n\nA tiny, whimsical command‑line utility that lets you record your mood using an emoji and later view a quick summary.\n\n## Features\n\n- **Add a mood** – `mood add <mood>` (e.g. `happy`, `sad`, `angry`, `excited`, `neutral`).\n- **View stats** – `mood stats` shows how many times each mood was logged.\n- Stores data locally in `$HOME/.moodlog.json` so your history persists across sessions.\n\n## Installation\n\n```bash\n# Clone the repository (or copy the utility into your project)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/nightly-emoji-mood-tracker\n# Install globally (optional)\nnpm install -g .\n```\n\nIf you prefer not to install globally, you can run it directly with Node:\n\n```bash\nnode src/index.js add happy\nnode src/index.js stats\n```\n\n## Usage\n\n```bash\n# Add a mood entry\nmood add happy\n# or\nnode src/index.js add happy\n\n# Show statistics\nmood stats\n# or\nnode src/index.js stats\n```\n\n## Supported moods and emojis\n\n| Mood      | Emoji |\n|-----------|-------|\n| happy     | 😊    |\n| sad       | 😢    |\n| angry     | 😠    |\n| excited   | 🤩    |\n| neutral   | 😐    |\n\n## Development\n\nThe source lives in `src/index.js`. Tests are in `tests/test_index.js` and can be run with:\n\n```bash\nnpm test\n```\n\nThe test suite uses only Node's built‑in `assert` module and does not require any external dependencies.\n\n## License\n\nMIT – see the LICENSE file in the repository root.\n
