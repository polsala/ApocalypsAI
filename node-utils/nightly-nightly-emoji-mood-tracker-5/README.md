Nightly Emoji Mood Tracker\n\nA whimsical CLI tool to log your mood with emojis and view simple statistics.\n\nInstallation:\n- Ensure Node.js (>=14) is installed.\n- Place the utility in your project or run directly with `node src/main.js`.\n\nUsage:\n- Log a mood: `node src/main.js log 😊 "Feeling great"`\n- List entries: `node src/main.js list`\n- Show stats: `node src/main.js stats`\n\nThe data is stored in a JSON file named .moodlog.json in the current working directory, or you can set the environment variable MOOD_TRACKER_FILE to specify a custom path.
