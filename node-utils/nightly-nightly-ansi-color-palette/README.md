nightly-ansi-color-palette\n\nA whimsical yet handy Node.js CLI that prints the 8-bit ANSI color palette in your terminal. Useful for developers who need to pick colors for terminal output or just want to admire the rainbow of colors.\n\nInstallation\nClone the repository and run the script with Node:\n\ngit clone <repo-url>\ncd utils/nightly-ansi-color-palette\nnode src/index.js\n\nUsage\nnode src/index.js          # show colors as foreground (default)\nnode src/index.js --bg    # show colors as background\nnode src/index.js --help  # display help\n\nLicense\nMIT
