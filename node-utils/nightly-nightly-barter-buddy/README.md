# Nightly Barter Buddy\n\nA whimsical CLI utility for the post‑apocalypse that helps you figure out fair trade ratios for your supplies.\n\n## Installation\n\n```sh\nnpm install -g nightly-barter-buddy\n```\n\n## Usage\n\nProvide a JSON payload describing the items you have and the items the other party offers.\n\n```sh\ncat trade.json | nightly-barter-buddy\n```\n\n### Input format\n\n```json\n{\n  "my": [\n    {"name":"canned beans","qty":10,"rarity":3,"utility":4},\n    {"name":"bottled water","qty":5,"rarity":4,"utility":5}\n  ],\n  "their": [\n    {"name":"first‑aid kit","qty":2,"rarity":5,"utility":5},\n    {"name":"scrap metal","qty":20,"rarity":2,"utility":2}\n  ]\n}\n```\n\n### Output\n\nThe tool prints a simple suggestion:\n\n````\nYour total value: 95\nTheir total value: 70\nFair trade ratio: 0.74\nSuggestion: You have 74% more value. Consider giving more items.\n````\n\n## How it works\n\nEach item gets a **value** = `rarity * utility * qty`. The totals are compared and a ratio is derived.\n\n## License\n\nMIT
