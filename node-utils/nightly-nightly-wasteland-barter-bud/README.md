# Wasteland Barter Buddy\n\nA whimsical command‑line utility for post‑apocalyptic traders.\n\nIt helps you decide which combination of goods maximizes total utility value without exceeding your barter budget. Under the hood it runs a classic 0/1 knapsack algorithm.\n\n## Installation\n\nNo external dependencies are required – just Node.js (v12+). Clone the repository and run the tool directly.\n\n```bash\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/nightly-wasteland-barter-buddy\nnode src/index.js --items items.json --budget 100\n```\n\n## Usage\n\n```bash\nnode src/index.js --items <path-to-items-json> --budget <numeric-budget>\n```\n\n- `--items` – Path to a JSON file describing available items.\n- `--budget` – Maximum total cost you can spend in barter points.\n\n### Items JSON format\n\nThe file must contain an array of objects, each with the following fields:\n\n```json\n[\n  {\n    "name": "canned beans",\n    "value": 10,   // utility value you gain\n    "cost": 5      // barter cost\n  },\n  {\n    "name": "bottled water",\n    "value": 8,\n    "cost": 4\n  }\n]\n```\n\n## Example\n\n```json\n[\n  {"name": "canned beans", "value": 10, "cost": 5},\n  {"name": "bottled water", "value": 8, "cost": 4},\n  {"name": "first aid kit", "value": 15, "cost": 10},\n  {"name": "scrap metal", "value": 4, "cost": 2}\n]\n```\n\nRunning:\n\n```bash\nnode src/index.js --items items.json --budget 12\n```\n\nWill output (pretty‑printed JSON):\n\n```json\n[\n  {\n    "name": "canned beans",\n    "value": 10,\n    "cost": 5\n  },\n  {\n    "name": "bottled water",\n    "value": 8,\n    "cost": 4\n  },\n  {\n    "name": "scrap metal",\n    "value": 4,\n    "cost": 2\n  }\n]\n```\n\n## Testing\n\nA simple deterministic test suite lives in `tests/`. Run it with Node:\n\n```bash\nnode tests/test_barter.js\n```\n\nIf everything is correct you will see `All tests passed.`\n\n---\nEnjoy fair trades in the wasteland!\n
