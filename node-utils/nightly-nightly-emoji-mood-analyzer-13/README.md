# Nightly Emoji Mood Analyzer\n\nA whimsical CLI tool that reads a sentence and returns an emoji representing its overall mood. Uses a tiny built‑in sentiment word list, works offline, and has no external dependencies.\n\n## Installation\n\n```sh\nnpm install -g .\n# or run directly with node\nnode src/index.js "Your text"\n```\n\n## Usage\n\n```sh\nnode src/index.js "I love sunny days"\n# => 😊\n```\n\n## How it works\n\nThe tool counts occurrences of positive and negative words from a small dictionary.\n- If positives > negatives → 😊\n- If negatives > positives → 😞\n- Otherwise (including ties or no matches) → 😐\n\n## License\n\nMIT
