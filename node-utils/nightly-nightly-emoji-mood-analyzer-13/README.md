# nightly-emoji-mood-analyzer\n\nA whimsical CLI that reads a line of text from stdin and prints an emoji representing the overall mood.\n\n## Installation\n\n```sh\nnpm install\nnode src/index.js\n```\n\n## Usage\n\n```sh\necho "I love sunny days" | node src/index.js\n# => 😊\n```\n\n## How it works\n\nA tiny built‑in sentiment word list maps positive words to 😊, negative words to 😞, everything else to 😐.\n
