# Nightly Emoji Mood Analyzer\n\n## Overview\n\n`nightly-emoji-mood-analyzer` is a tiny Node.js utility that reads a line of text and returns an emoji representing the mood of the message. It uses a small built‑in word list for positive and negative cues, so it works completely offline and has zero runtime dependencies.\n\n## Installation\n\n```bash\n# Clone the repository (or copy the utility folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/nightly-emoji-mood-analyzer\n# No external packages are required, but you can run npm install to create a lockfile if you wish\nnpm install\n```\n\n## Usage\n\n### Command‑line\n\n```bash\nnode src/index.js "I love sunny days!"\n# → 😊\n```\n\nThe script prints a single emoji to STDOUT.\n\n### Programmatic API\n\nYou can also import the function in your own Node code:\n\n```js\nconst { analyzeMood } = require('./src/index');\nconst emoji = analyzeMood('This is terrible');\nconsole.log(emoji); // 😞\n```\n\n## Mood Mapping\n\n- Positive sentiment → 😊\n- Neutral / no clear sentiment → 😐\n- Negative sentiment → 😞\n\n## Testing\n\nRun the bundled tests with Node:\n\n```bash\nnode tests/test_index.js\n```\n\nYou should see `All tests passed` if everything is working.\n\n## License\n\nMIT – see the root LICENSE file.\n
