# nightly-void-whispers-affirmations

A Node.js CLI tool that delivers randomized, post-apocalyptic affirmations to keep your spirits high in the wasteland.

## Usage

```bash
npx nightly-void-whispers-affirmations
```

## Example Output

```
 Amidst the ruins, your resilience echoes louder than the silence.
```

## Tests

Run tests with:

```bash
npm test
```
