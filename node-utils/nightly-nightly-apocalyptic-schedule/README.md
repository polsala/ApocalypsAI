# Nightly Apocalyptic Schedule Generator

A CLI tool that generates a humorous daily schedule mixing real tasks with post-apocalyptic whimsy. Outputs ASCII art calendars with randomized tasks like "Barricade the Wi-Fi router" or "Brew radiation coffee".

## Usage
```bash
npx apocalyptic-schedule-gen
```
