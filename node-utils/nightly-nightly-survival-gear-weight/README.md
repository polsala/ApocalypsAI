# Nightly Survival Gear Weight Calculator\n\n## Overview\n\n`nightly-survival-gear-weight` is a tiny Node.js command‑line utility that helps you quickly calculate the total weight of your survival gear.  It accepts a list of items with their weights and tells you whether you are within a sane carrying limit (default **100 kg**).  Perfect for the wanderer who wants to avoid being crushed by a mountain of canned beans.\n\n## Installation\n\n```bash\n# Clone the repository (or copy the utility folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/nightly-survival-gear-weight\n# No external dependencies – just run with Node.js (v14+)\n```\n\n## Usage\n\n### Argument mode\n\nPass items as `name=weight` pairs (weight in kilograms):\n\n```bash\nnode src/index.js water=10 food=5 tent=15\n```\n\nOutput example:\n\n```
Total weight: 30 kg\n✅ Within the 100 kg limit.\n```\n\n### JSON mode\n\nPipe a JSON array of objects (`{name, weight}`) into the tool using the `--json` flag:\n\n```bash\necho '[{"name":"water","weight":10},{"name":"food","weight":5}]' | node src/index.js --json\n```\n\nResult:\n\n```
Total weight: 15 kg\n✅ Within the 100 kg limit.\n```\n\n## API\n\nThe core logic lives in `src/index.js` and can be required by other Node programs:\n\n```js\nconst { calculateWeight } = require('./src/index');\nconst items = [{ name: 'water', weight: 10 }, { name: 'food', weight: 5 }];\nconsole.log(calculateWeight(items)); // 15\n```\n\n## Testing\n\nRun the bundled tests with Node:\n\n```bash\nnode tests/test_index.js\n```\n\nAll tests should pass and print `All tests passed`.\n\n## License\n\nMIT – feel free to adapt for your own wasteland adventures.
