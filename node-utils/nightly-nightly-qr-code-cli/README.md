# Nightly QR Code CLI\n\n## Overview\nGenerates a whimsical QR‑code‑like ASCII art for any text directly in your terminal.\n\n## Why?\n* Fun way to share short strings in a visual form.\n* Deterministic – the same input always yields the same pattern.\n* No external dependencies, pure Node.js.\n\n## Installation\n```sh\ngit clone <repo-url>\ncd utils/nightly-qr-code-cli\nnode src/qr.js "Your text here"\n```\n\n## Usage\n```sh\nnode src/qr.js "Hello World"\n```\n\nThe command prints a 21×21 block of `█` and spaces representing the QR‑like pattern.\n\n## License\nMIT
