# Nightly Emoji Cipher\n\nA whimsical CLI utility that encodes and decodes strings to a sequence of emojis using a Base64‑like mapping. Great for secret notes in the wasteland.\n\n## Installation\n\n```sh\nnpm install\n```\n\n## Usage\n\n```sh\nnode src/index.js encode "Hello world"\n# => 😃😄... (emoji string)\n\nnode src/index.js decode "😃😄..."\n# => Hello world\n```\n\n## API\n\n`encode(text: string): string` – returns an emoji string.\n\n`decode(emojis: string): string` – returns the original text.\n\n## Testing\n\n```sh\nnpm test\n```
