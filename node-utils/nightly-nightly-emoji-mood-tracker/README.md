# nightly-emoji-mood-tracker\n\nA tiny, whimsical command‑line utility that lets you record your mood as an emoji (with an optional note) and later view simple statistics.\n\n## Install\n\n```bash\n# Clone the repo and install globally\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/nightly-emoji-mood-tracker\nnpm install -g .\n```\n\n## Usage\n\n```bash\n# Record a mood\nemoji-mood log 😄 "Feeling great after lunch"\n\n# List all entries\nemoji-mood list\n\n# Show statistics\nemoji-mood stats\n```\n\n## Commands\n\n- `log <emoji> [note]` – Append a new mood entry with the current timestamp.\n- `list` – Print all recorded entries in chronological order.\n- `stats` – Show how many times each emoji has been used.\n\nAll data is stored in a JSON file. By default it lives at `~/.emoji_mood_tracker.json`. You can override the location with the environment variable `EMOJI_MOOD_FILE`.\n\n## Development\n\nRun the test suite with:\n\n```bash\nnpm test\n```\n\nThe project uses only the Node standard library – no external dependencies.\n
