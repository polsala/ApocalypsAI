Nightly Barter Value Estimator\n\nUtility to compare the relative value of two post‑apocalypse items based on predefined scarcity and utility scores. Useful for role‑playing games or community barter decisions.\n\nInstallation\n\nRun with Node: \n    node src/index.js <item1> <item2>\n\nUsage example\n\n    node src/index.js water canned-beans\nResult:\n    "water" is more valuable than "canned-beans"\n\nIf an item is unknown, the tool reports it.\n\nAdding items\n\nEdit the ITEM_SCORES map in src/index.js to add or adjust item scores.
