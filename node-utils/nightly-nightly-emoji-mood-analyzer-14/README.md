Nightly Emoji Mood Analyzer\n\nA tiny Node.js utility that reads a piece of text and returns an emoji representing its overall mood. It uses a simple word‑based sentiment list, works offline, and can be used in pipelines or as a fun CLI.\n\nInstallation\n------------\n\n    npm install -g nightly-emoji-mood-analyzer\n\nUsage\n-----\n\nFrom a file:\n\n    node src/index.js path/to/file.txt\n\nFrom stdin:\n\n    echo "I love sunny days!" | node src/index.js\n\nThe program prints a single emoji: 😊 for positive, 😢 for negative, or 😐 for neutral/no clear sentiment.\n\nHow it works\n------------\n\nThe tool counts occurrences of a small set of positive words (happy, love, great, etc.) and negative words (sad, hate, terrible, etc.). If positives > negatives it outputs 😊, if negatives > positives it outputs 😢, otherwise 😐.\n\nTesting\n-------\n\nRun the bundled tests with:\n\n    npm test\n\nAll tests should pass, confirming the sentiment logic works as expected.
