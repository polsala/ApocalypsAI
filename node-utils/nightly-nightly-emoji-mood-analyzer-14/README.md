# nightly-emoji-mood-analyzer\n\nA whimsical Node.js CLI that reads a piece of text and returns an emoji representing its overall mood (happy, neutral, sad). Useful for quickly gauging sentiment in chat messages, commit messages, or any short text.\n\n## Installation\n\n```sh\nnpm install -g .\n```\n\n*(Assuming you have Node.js installed.)*\n\n## Usage\n\n```sh\nnode src/main.js "I love sunny days!"\n# => 😊\n\necho "I am feeling terrible today." | node src/main.js\n# => 😢\n```\n\n## How it works\n\nThe tool uses a tiny built‑in word list of positive and negative terms to compute a simple sentiment score.\nScore > 1 → 😊 (happy)\nScore < -1 → 😢 (sad)\nOtherwise → 😐 (neutral)\n\n## Testing\n\n```sh\nnode tests/test_main.js\n```
