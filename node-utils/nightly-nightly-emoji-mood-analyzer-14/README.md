# nightly-emoji-mood-analyzer\n\nA whimsical CLI tool that reads a piece of text and returns an emoji representing its overall mood. Uses a tiny built‑in sentiment word list, works offline, and has no external dependencies.\n\n## Installation\n\n```sh\nnpm install -g .\n# or just run with node\n```\n\n## Usage\n\n```sh\nnode src/index.js \"I love sunny days but hate rain\"\n# => 😊\n```\n\nIf no argument is provided, the tool reads from STDIN.\n\n## How it works\n\nCounts occurrences of positive and negative words from a small dictionary. If positives > negatives → 😊, if negatives > positives → 😢, else 😐.\n\n## Testing\n\n```sh\nnode tests/test_index.js\n```
