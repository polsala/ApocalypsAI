# Apocalypse Calendar\n\nA whimsical CLI tool that reveals a fictional apocalyptic event for any given date.\n\n## Installation\n\n```sh\nnpm install -g .\n```\n\n## Usage\n\n```sh\nnode src/index.js 2023-10-31\n```\n\nThe command prints an event description to stdout.\n\n## How it works\n\nThe tool contains a small set of hard‑coded date‑specific events and a fallback list of generic apocalyptic happenings. If the supplied date matches a specific entry, that event is shown; otherwise a random generic event is selected.\n\n## Testing\n\nRun the tests with:\n\n```sh\nnode tests/test_index.js\n```\n\nAll tests should pass without external network access.
