# Emoji Mood Analyzer\n\nA tiny Node.js utility that reads a short piece of text and returns an emoji representing its mood.\n\n## Installation\n\n```bash\n# Clone the repository (or copy the utility folder)\ngit clone <repo-url>\ncd nightly-emoji-mood-analyzer\nnpm install\n```\n\n## Usage\n\n```bash\n# As a CLI tool\nnode src/index.js "I love sunny days!"\n# => 😊\n\n# Or using the installed binary (if linked)\nemoji-mood "I am sad about the news."\n# => 😢\n```\n\n## API\n\nYou can also require the module in your own code:\n\n```js\nconst { analyzeMood } = require('./src/index.js');\nconst emoji = analyzeMood('Wow, that was surprising!');\nconsole.log(emoji); // 😲\n```\n\n## How it works\n\nThe analyzer performs a simple keyword match against a few mood categories (happy, sad, angry, surprised, neutral). If no keywords are found, it returns a thinking face (🤔). This keeps the utility lightweight and deterministic.\n\n## Testing\n\nRun the test suite with:\n\n```bash\nnpm test\n```\n\nAll tests should pass, confirming the keyword‑to‑emoji mapping works as expected.
