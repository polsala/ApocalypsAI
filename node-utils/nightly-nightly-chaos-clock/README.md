# nightly-chaos-clock

A Node.js utility that displays the current time with simulated temporal disruptions. Each second, there's a small chance the clock will display a "temporal anomaly" instead of the time — like a random emoji, a silly message, or a time warp!

## Usage

```bash
node src/chaos-clock.js
```

Press `Ctrl+C` to exit.

## Features

- Displays real-time clock with HH:mm:ss format
- Randomly disrupts time with fun chaos events
- Lightweight and fun for terminal enthusiasts

## Example Output

```
🕒 12:34:56
🌀 Temporal Anomaly Detected!
🕒 12:34:58
```
