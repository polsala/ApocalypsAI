## Wasteland Barter Buddy\n\nA whimsical CLI tool that helps post‑apocalyptic survivors calculate fair trade ratios for their supplies based on scarcity scores.\n\n### Usage\n```sh\nnode src/main.js < supplies.json\n```\nThe input JSON should be an array of objects:\n```json\n[{\"name\":\"canned beans\",\"qty\":10},{\"name\":\"water\",\"qty\":5}]\n```\nThe tool prints a table of each item, its computed value and its share of the total trade value.\n\n### How it works\nEach item is multiplied by a *scarcity weight* (hard‑coded in the script). The weight reflects how rare the item is in the wasteland. The resulting value is used to compute each item's proportion of the total value, giving a fair barter ratio.\n\n### Example\n```json\n[{\"name\":\"canned beans\",\"qty\":10},{\"name\":\"water\",\"qty\":5}]\n```\nOutput:\n````\nItem          Qty  Value  Share\ncanned beans   10    20   0.57\nwater           5    15   0.43\n````
