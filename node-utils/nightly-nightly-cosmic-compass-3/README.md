# Nightly Cosmic Compass

A whimsical Node.js CLI utility that assigns cosmic alignments and cryptic whispers to your tasks or ideas, offering a playful perspective. When decision paralysis strikes or you just need a fresh, cosmic take on your to-do list, let the Nightly Cosmic Compass guide your way!

## ✨ Cosmic Lore

The universe is vast, and so are your tasks. The Cosmic Compass taps into the ethereal energies to provide guidance:

-   🌌 **Stellar Core**: Focus: Illumination. _Shine a light on this path._
-   ✨ **Nebula Veil**: Focus: Contemplation. _Pause and ponder its cosmic dust._
-   🌠 **Galactic Drift**: Focus: Re-evaluation. _The universe suggests a new trajectory._
-   🌀 **Quantum Quirk**: Focus: Expansion. _Grow beyond its current orbit._
-   🕳️ **Event Horizon**: Focus: Compression. _Condense its essence into a singularity._
-   🔊 **Astral Echo**: Focus: Resonance. _Listen for its vibrational frequency._
-   🌪️ **Void Vortex**: Focus: Dispersion. _Let it scatter and reform._
-   🌸 **Celestial Bloom**: Focus: Genesis. _A new beginning awaits._

## Installation

1.  Navigate to the `node-utils/nightly-cosmic-compass` directory.
2.  Install dependencies:
    ```bash
    npm install
    ```

## Usage

Run the utility directly using `node` or via `npx` if you've installed it globally or want to run it from the directory.

```bash
# From the utility directory
node src/index.js "My urgent task" "That tricky bug" "Brainstorm new ideas"

# Or, after `npm install`, using the defined bin script
npx nightly-cosmic-compass "My urgent task" "That tricky bug" "Brainstorm new ideas"
```

### Example Output

```
🌌 My urgent task: Aligned with the Stellar Core. Illumination: Shine a light on this path.
```
