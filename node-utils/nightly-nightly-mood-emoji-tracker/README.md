# Nightly Mood Emoji Tracker\n\nA whimsical CLI utility to log your daily mood using emojis and retrieve a summary of mood distribution. Perfect for post‑apocalypse survivors to keep spirits high.\n\n## Installation\n\n```sh\n# Clone the utility (or copy the folder into your project)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/nightly-mood-emoji-tracker\n```\n\n## Usage\n\n```sh\n# Record a mood entry\nnode src/index.js add 😊 "Feeling hopeful"\n\n# Show a summary of recorded moods\nnode src/index.js summary\n```\n\nThe data is stored in `$HOME/.mood_tracker.json`.\n\n## Commands\n\n- `add <emoji> <note>` – Record a mood entry. The note is optional.\n- `summary` – Print a JSON object mapping each emoji to the number of times it has been recorded.\n\n## License\n\nMIT
