# Nightly Cryptic Emoji Decoder\n\nA whimsical command‑line utility that turns plain text into a secret emoji string and back again. Perfect for leaving cryptic notes in the wasteland or just having fun with friends.\n\n## Features\n\n- **Encode**: Convert any lower‑case alphabetic string (a‑z and spaces) into a sequence of emojis.\n- **Decode**: Turn an emoji sequence produced by this tool back into the original text.\n- No external dependencies – pure Node.js.\n\n## Installation\n\n```bash\n# Clone the repository (or copy the utility folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd node-utils/nightly-cryptic-emoji-decoder\n# Install (optional, only for npm scripts)\nnpm install\n```\n\n## Usage\n\n```bash\n# Encode a message\nnode src/index.js encode "hello world"\n# => 😆😄😅😅😗⬜😐😗😑😅😅\n\n# Decode a message\nnode src/index.js decode "😆😄😅😅😗⬜😐😗😑😅😅"\n# => hello world\n```\n\nThe tool only supports lower‑case letters and spaces. Any other characters are ignored.\n\n## Development\n\nRun the test suite with:\n\n```bash\nnode tests/test_index.js\n```\n\nFeel free to extend the emoji mapping or add support for punctuation!\n
