# Nightly Radiation Dose Estimator\n\nEstimates cumulative radiation dose from a series of exposure events.\n\n## Installation\n\n```sh\nnpm install -g .\n```\n\n## Usage\n\n```sh\nnode src/radiation.js exposures.json\n```\n\n`exposures.json` format:\n\n```json\n[\n  {"hours": 2, "rate_mSv_per_h": 0.5},\n  {"hours": 1.5, "rate_mSv_per_h": 1.2}\n]\n```\n\nThe tool prints total dose in millisieverts (mSv).\n\n## API\n\n```js\nconst { calculateDose } = require('./radiation');\nconst total = calculateDose(events);\n```
