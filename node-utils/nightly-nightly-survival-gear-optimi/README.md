# nightly-survival-gear-optimizer\n\nA tiny Node.js CLI that solves the classic 0/1 knapsack problem for post‑apocalypse gear selection. Feed it a JSON list of items (name, weight, utility) and a maximum carry weight, and it returns the optimal subset of items maximizing utility.\n\n## Installation\n\n```sh\nnpm install -g .\n# or just run with node\n```\n\n## Usage\n\n```sh\nnode src/index.js items.json 10\n```\n\n`items.json` example:\n\n```json\n[\n  {\"name\":\"Water\",\"weight\":3,\"utility\":10},\n  {\"name\":\"Food\",\"weight\":4,\"utility\":12},\n  {\"name\":\"Bandage\",\"weight\":1,\"utility\":4}\n]\n```\n\nOutput will be a JSON array of selected item names, e.g.:\n\n```json\n[\"Water\",\"Food\"]\n```\n\n## Testing\n\n```sh\nnode tests/test_main.js\n```\n\nThe test suite creates a temporary items file, runs the optimizer, and checks the result.
