# nightly-qr-code-cli\n\nGenerate a QR code representation of a string directly in your terminal.\n\n## Installation\n\n```sh\nnpm install -g nightly-qr-code-cli\n```\n\n## Usage\n\n```sh\nnightly-qr-code-cli "Hello, world!"\n```\n\nThe command prints a QR‑code‑like pattern made of Unicode block characters.\n\n## How it works\n\nThe utility uses a tiny built‑in QR generator (for demo purposes) and prints the result to stdout. It is intentionally simple and deterministic, making it easy to test without external dependencies.
