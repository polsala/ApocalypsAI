# Nightly Barter Price Estimator\n\nEstimates a fair trade ratio between two items in a post‑apocalyptic setting based on predefined scarcity and utility scores.\n\n## Installation\n\n```sh\nnpm install\nnode src/index.js <itemA> <itemB>\n```\n\n## Usage\n\n```sh\n$ node src/index.js water cannedFood\n1.80\n```\n\nThe command prints the ratio **value(itemA) / value(itemB)** rounded to two decimal places.\n\n## How it works\n\nEach item has a *base* value and a *scarcity* multiplier. The effective value is `base * scarcity`. The estimator divides the effective value of the first item by that of the second.\n\n## Adding new items\n\nEdit `src/index.js` and extend the `ITEMS` object with a new entry `{ base: <number>, scarcity: <number> }`.\n\n## Testing\n\n```sh\nnpm test\n```\n\n## License\n\nMIT
