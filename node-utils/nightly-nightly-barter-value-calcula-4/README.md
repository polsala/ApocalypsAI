# Nightly Barter Value Calculator\n\nA whimsical CLI utility that helps survivors determine fair trade values for common post‑apocalyptic items based on a configurable rarity index.\n\n## Installation\n\n```sh\nnpm install -g nightly-barter-value-calculator\n```\n\n## Usage\n\n```sh\nnightly-barter-value-calculator <item> [quantity]\n```\n\n- `<item>`: name of the item (e.g., `water`, `canned-food`, `ammo`, `medicine`, `gasoline`).\n- `[quantity]` (optional): number of items, defaults to `1`.\n\n## Example\n\n```sh\nnightly-barter-value-calculator ammo 4\n# => 20 barter points\n```\n\n## Configuration\n\nThe rarity index is defined in the source file `src/index.js`. Feel free to edit the `rarityMap` object to add or adjust items and their values.\n\n## License\n\nMIT
