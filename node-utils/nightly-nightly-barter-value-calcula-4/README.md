# Nightly Barter Value Calculator\n\nA whimsical Node.js CLI that takes a JSON list of survival items with a scarcity rating (1-10) and produces a barter ledger assigning each item a trade value. Useful for role‑playing games, post‑apocalyptic story planning, or just for fun.\n\n## Installation\n\n```sh\ngit clone <repo>\ncd utils/nightly-barter-value-calculator\n# No external dependencies required\n```\n\n## Usage\n\n```sh\nnode src/main.js --input items.json --output ledger.json\n```\n\n`items.json` example:\n\n```json\n[\n  {"name": "canned beans", "scarcity": 3},\n  {"name": "water filter", "scarcity": 8}\n]\n```\n\nThe tool will create `ledger.json`:\n\n```json\n[\n  {"name":"canned beans","scarcity":3,"value":80},\n  {"name":"water filter","scarcity":8,"value":30}\n]\n```\n\n## How it works\n\nValue = base * (11 - scarcity) / 10, rounded to the nearest integer. Base defaults to 100 but can be changed in the source code.\n\n## Testing\n\nRun the bundled test:\n\n```sh\nnode tests/test_main.js\n```
