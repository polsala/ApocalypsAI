# nightly-emoji-cryptic-encoder\n\nEncode and decode messages using a whimsical emoji cipher.\n\n## Installation\n\n```sh\nnpm install -g .\n```\n\n## Usage\n\nEncode a message:\n\n```sh\nnode src/emoji-encoder.js encode "hello world"\n```\n\nDecode a message:\n\n```sh\nnode src/emoji-encoder.js decode "😀😁😂"\n```\n\n## How it works\n\nEach letter a‑z is mapped to a unique emoji. Spaces are preserved. Non‑alphabetic characters are ignored.\n
