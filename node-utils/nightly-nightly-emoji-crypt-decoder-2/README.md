# nightly-emoji-crypt-decoder\n\nDecode hidden messages encoded as emojis using a simple substitution cipher.\n\n## Installation\n\n```sh\nnpm install -g .\n```\n\n## Usage\n\n```sh\nnightly-emoji-crypt-decoder 😀😁😂\n# => ABC\n```\n\nYou can also pipe input:\n\n```sh\necho "😀😁😂" | nightly-emoji-crypt-decoder\n```\n\n## How it works\n\nEach emoji maps to a letter (A‑Z). Unknown emojis become "?". See the source code for the full mapping.\n
