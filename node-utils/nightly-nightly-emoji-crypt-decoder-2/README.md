# Nightly Emoji Crypt Decoder\n\n## Overview\nA whimsical command‑line utility that can **encode** plain text into a sequence of emojis and **decode** an emoji sequence back to text. It uses a fixed, deterministic dictionary, making it useful for secret messages in post‑apocalyptic chat rooms or just for fun.\n\n## Installation\n1. Clone the repository (or copy the utility folder).\n2. Ensure you have Node.js (v14+) installed.\n3. No external dependencies are required – everything runs with the Node standard library.\n\n## Usage\n```bash\n# Encode a phrase\nnode src/main.js encode "hello world"\n\n# Decode an emoji string\nnode src/main.js decode "👢📧💲💲⚽⬜〰️⚽📧⚽"\n```\n\nThe above decode example corresponds to the phrase "hello world".\n\n## Commands\n- `encode <text>` – Converts each character to its emoji representation (unknown characters are left unchanged).\n- `decode <emoji‑string>` – Converts the emoji sequence back to the original text (unknown emojis are left unchanged).\n\n## Example\n```bash\n$ node src/main.js encode "ab"\n🅰️🅱️\n\n$ node src/main.js decode "🅰️🅱️"\nab\n```\n\n## Testing\nRun the bundled test script with Node:\n```bash\nnode tests/test_main.js\n```\nYou should see `All tests passed` if everything works.\n\n## License\nMIT – feel free to adapt, extend, or weaponize it for your own post‑apocalyptic communications!\n
