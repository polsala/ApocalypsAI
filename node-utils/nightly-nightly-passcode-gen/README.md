# nightly-passcode-gen\n\nA tiny Node.js CLI that creates a fun, deterministic "post‑apocalypse" passcode.\n\n## What it does\n\nGiven a seed string (or the current timestamp if none is supplied) it:\n1. Computes a SHA‑256 hash of the seed.\n2. Takes four 4‑character chunks from the hash.\n3. Upper‑cases the chunks and interleaves them with a set of quirky emojis.\n\nThe result looks like:\n\n``\n2CF2 🌵 5FB0 🦖 26E8 🌪 C5B9 ☢\n```\n\nBecause the hash is deterministic, the same seed always yields the same passcode – handy for generating repeatable, memorable codes without storing secrets.\n\n## Installation\n\n```bash\n# Clone the repository (or copy the generated folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/nightly-passcode-gen\n# Install dependencies (none required beyond Node's built‑in crypto)\nnpm install\n```\n\n## Usage\n\n```bash\nnode src/index.js <seed>\n```\n\nIf `<seed>` is omitted, the current timestamp is used, producing a different code each run.\n\n## Testing\n\n```bash\nnpm test\n```\n\nThe test suite checks that a known seed produces the expected output.\n
