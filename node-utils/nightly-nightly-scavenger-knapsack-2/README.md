# Scavenger Knapsack\n\nA whimsical CLI utility that helps post‑apocalypse scavengers pick the most valuable items to carry without exceeding their pack capacity.\n\n## Installation\n\n```sh\nnpm install -g .\n```\n\n## Usage\n\n```sh\nnode src/index.js <capacity> <items.json>\n```\n\n`<capacity>` – maximum total weight the pack can hold (integer).\n`<items.json>` – JSON file containing an array of items, each with `name`, `weight`, and `value`.\n\nExample `items.json`:\n\n```json\n[\n  {"name":"Canned Beans","weight":2,"value":3},\n  {"name":"Water Bottle","weight":3,"value":4},\n  {"name":"First Aid Kit","weight":5,"value":10}\n]\n```\n\nRunning:\n\n```sh\nnode src/index.js 5 items.json\n```\n\nOutputs the optimal selection:\n\n```json\n{\n  "totalWeight":5,\n  "totalValue":10,\n  "selected":[{\"name\":\"First Aid Kit\",\"weight\":5,\"value\":10}]\n}\n```\n\n## API\n\nThe module exports a single function `knapsack(items, capacity)` that returns the same object as the CLI output.\n\n```js\nconst { knapsack } = require('./src/index');\nconst result = knapsack(myItems, 10);\n```\n\n## License\n\nMIT
