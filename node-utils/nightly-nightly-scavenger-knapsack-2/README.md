# Scavenger Knapsack Optimizer\n\nA whimsical CLI utility for post‑apocalypse scavengers. Given a list of items with weight and value, and a maximum carry weight, it computes the most valuable combination of items.\n\n## Installation\n\n```sh\nnpm install -g .\n```\n\n## Usage\n\n```sh\nnode src/cli.js <capacity> <items.json>\n```\n\n`items.json` format:\n\n```json\n[\n  {"name":"Canned Beans","weight":2,"value":5},\n  {"name":"Water Bottle","weight":3,"value":4}\n]\n```\n\nThe tool prints the selected items and total value.\n\n## Example\n\n```sh\nnode src/cli.js 5 items.json\n```\n\nOutputs:\n\n````\nSelected items:\n- Canned Beans (weight: 2, value: 5)\n- Water Bottle (weight: 3, value: 4)\nTotal value: 9\n````\n\n## Testing\n\nRun tests with:\n\n```sh\nnpm test\n```
