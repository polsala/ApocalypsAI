# Nightly Supply Barter Calculator\n\n## Overview\n\nA whimsical yet practical command‑line utility for the post‑apocalyptic trader.\nGiven a JSON list of supplies (name and quantity), it computes a total barter value using built‑in base values and rarity multipliers.\n\n## Installation\n\n```bash\n# Clone the repository (or copy the utility folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/nightly-supply-barter-calculator\n# No external dependencies required – just Node.js (v14+)\n```\n\n## Usage\n\nYou can pipe a JSON array via **STDIN** or pass it as a single argument.\n\n### Pipe example\n\n```bash\necho '[{"name":"canned-beans","qty":10},{"name":"water","qty":5}]' | node src/index.js\n```\n\nOutput:\n```
Total barter value: 35
```\n\n### Argument example\n\n```bash\nnode src/index.js '[{"name":"medicine","qty":2},{"name":"fuel","qty":1}]'\n```\n\nOutput:\n```
Total barter value: 46
```\n\n## How it works\n\n- Each item has a **base value** (e.g., canned‑beans = 2).\n- Items are assigned a **rarity** (common, uncommon, rare, legendary) which applies a multiplier.\n- Total value = Σ (base × rarity‑multiplier × quantity).\n- Unknown items default to a base value of 1 and common rarity.\n\n## Testing\n\nRun the bundled test suite with Node:\n\n```bash\nnode tests/test_index.js\n```\n\nAll tests should pass, confirming deterministic calculations.\n\n## License\n\nMIT – see LICENSE file in the repository root.
