# nightly-morse-communicator\n\nA whimsical Node.js CLI that encodes and decodes messages to/from Morse code, perfect for post‑apocalyptic radio chatter.\n\n## Installation\n\n```sh\ngit clone <repo> && cd utils/nightly-morse-communicator\nnpm install\n```\n\n## Usage\n\n```sh\nnode src/index.js --encode "HELLO WORLD"\n# => ".... . .-.. .-.. --- / .-- --- .-. .-.. -.."\n\nnode src/index.js --decode ".... . .-.. .-.. --- / .-- --- .-. .-.. -.."\n# => "HELLO WORLD"\n```\n\n## Options\n\n- `--encode <text>` – encode plain text to Morse.\n- `--decode <code>` – decode Morse to plain text.\n- `--help` – show help.\n\n## Notes\n\n* Only letters A‑Z, digits 0‑9 and spaces are supported.\n* Unknown characters are ignored during encoding.\n* Decoding treats `/` or spaces as word separators.\n
