# Apocalypse Fortune\n\nA whimsical CLI utility that prints a random apocalypse‑themed fortune to the terminal. Perfect for a quick dose of post‑apocalyptic optimism.\n\n## Installation\n\n```sh\ngit clone <repo>\ncd utils/nightly-apocalypse-fortune\nnpm install\n```\n\n## Usage\n\n```sh\nnode src/index.js\n```\n\nEach execution prints a different fortune.\n\n## Example\n\n``\nYou will find shelter under a broken billboard.\n``\n
