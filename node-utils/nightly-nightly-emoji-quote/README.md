# nightly-emoji-quote

CLI that fetches a random quote from "https://api.quotable.io" and displays it with a random emoji.

## Installation

```bash
npm install -g nightly-emoji-quote
```

## Usage

```bash
emoji-quote
```

It will print something like:

```
😄 The only limit to our realization of tomorrow is our doubts of today.
```

## Development

```bash
git clone <repo>
cd utils/nightly-emoji-quote
npm install
npm test
```
