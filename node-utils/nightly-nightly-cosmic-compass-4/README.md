# Nightly Cosmic Compass

A whimsical Node.js utility that provides celestial navigation advice for the apocalypse.

## Purpose

In the event of a societal collapse, traditional navigation methods might fail. The Cosmic Compass leverages ancient wisdom and a touch of stardust to offer guidance using celestial bodies. It's designed to be a fun, albeit slightly fantastical, tool for those venturing into the unknown.

## Features

*   **Star Alignment Guidance**: Provides advice based on the current (simulated) position of prominent stars.
*   **Lunar Phase Wisdom**: Offers insights based on the moon's phase.
*   **Solar Path Suggestions**: Gives directional hints based on the sun's simulated position.
*   **Whimsical Lore**: Intersperses practical advice with apocalyptically-themed folklore.

## Installation

1.  Clone the repository:
    ```bash
    git clone https://github.com/polsala/ApocalypsAI.git
    cd ApocalypsAI/utils/nightly-cosmic-compass
    ```
2.  Install dependencies:
    ```bash
    npm install
    ```

## Usage

Run the utility from your terminal:

```bash
node src/main.js
```

## How it Works

The utility simulates celestial positions and lunar phases to generate advice. It uses a combination of pre-defined celestial events and random generation to create unique navigation tips.

## Testing

To run the tests, use:

