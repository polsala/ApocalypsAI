## Nightly Cosmic Compass

A whimsical Node.js utility that provides a celestial direction based on the current time and a randomly generated 'cosmic event'. Think of it as a fun, unpredictable compass for your daily journey through the cosmos.

### How it Works

1.  **Time-Based Alignment**: The utility uses the current time to determine a base celestial alignment.
2.  **Cosmic Event Infusion**: A randomly selected 'cosmic event' (e.g., 'Nebula Bloom', 'Comet's Kiss', 'Stardust Shower') is introduced, subtly shifting the direction.
3.  **Whimsical Direction**: The final output is a playful, yet directionally suggestive, phrase.

### Installation

```bash
npm install @polsala/nightly-cosmic-compass
```

### Usage

Run the utility from your terminal:

```bash
npx @polsala/nightly-cosmic-compass
```

### Example Output

```
Your cosmic direction is: Towards the Whispering Nebula, guided by a Comet's Kiss!
```
