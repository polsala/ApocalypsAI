# Nightly Cosmic Compass

A whimsical Node.js utility that provides a celestial bearing based on the current time and a randomly generated 'cosmic event'. Imagine you're lost in the cosmic void, and this little tool helps you find your way with a touch of stardust and absurdity.

## Features

*   Generates a random "cosmic event" (e.g., "Nebula's Whisper", "Quasar's Giggle").
*   Calculates a "celestial bearing" based on the current time and the cosmic event.
*   Provides a whimsical interpretation of the bearing.
*   Cross-platform Node.js application.

## Installation

1.  Clone the repository:
    ```bash
    git clone https://github.com/polsala/ApocalypsAI.git
    cd ApocalypsAI
    ```
2.  Navigate to the utility directory:
    ```bash
    cd utils/nightly-cosmic-compass
    ```
3.  Install dependencies:
    ```bash
    npm install
    ```

## Usage

Run the utility from your terminal:

```bash
node src/main.js
```
