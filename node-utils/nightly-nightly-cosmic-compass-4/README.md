# Nightly Cosmic Compass

A whimsical Node.js utility that generates celestial navigation coordinates for fictional star systems. Perfect for adding a touch of cosmic flair to your tabletop RPGs, creative writing projects, or just for fun.

## Features

*   Generates star system names with a celestial theme.
*   Assigns random, yet plausible-sounding, galactic coordinates (X, Y, Z).
*   Provides a "Star Type" for added flavor.
*   Outputs in a human-readable format.

## Installation

```bash
npm install -g @polsala/nightly-cosmic-compass
```

## Usage

Run the utility from your terminal:

```bash
nightly-cosmic-compass
```

## Example Output

```
Star System: Nebula Prime
Galactic Coordinates: X: 123.45, Y: -67.89, Z: 98.76
Star Type: Blue Giant
```

## Development & Testing

This utility includes unit tests to ensure its functionality. You can run them using:

```bash
npm test
```
