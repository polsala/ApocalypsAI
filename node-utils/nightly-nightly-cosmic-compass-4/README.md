## Nightly Cosmic Compass

A whimsical Node.js utility that generates celestial navigation coordinates for fictional journeys.

This tool is designed to spark creativity for writers, game developers, or anyone who enjoys a touch of cosmic fantasy. It produces plausible-sounding star coordinates, nebulae names, and warp lane designations.

### Usage

Install the package:
```bash
npm install -g @polsala/nightly-cosmic-compass
```

Run the utility:
```bash
nightly-cosmic-compass
```

### Example Output

```
Navigating towards:
  Star System: Xylos Prime
  Coordinates: RA 14h 32m 18s, Dec +25° 10′ 05″
  Nebula: The Whispering Veil
  Warp Lane: Nexus-7

May your journey be swift and your discoveries wondrous!
```

### Development

To run locally:
```bash
npm install
node src/index.js
```

To run tests:
```bash
npm test
```
