# Nightly Cosmic Compass

A whimsical CLI tool for the post-apocalypse, guiding your daily actions based on simulated cosmic energies. Get a "cosmic direction" and a suggested activity to align with the universe's subtle whispers.

## Features

*   **Daily Cosmic Guidance**: Provides a unique direction and activity suggestion for each day.
*   **Simulated Celestial Alignments**: Uses deterministic, simplified calculations for lunar phases, zodiac signs, and planetary influences.
*   **Whimsical & Thought-Provoking**: Designed to inspire reflection and creative problem-solving in uncertain times.

## Installation

1.  Navigate to the `node-utils/nightly-cosmic-compass` directory.
2.  Install dependencies:
    ```bash
    npm install
    ```

## Usage

Run the utility from the command line:

```bash
npm start
```
