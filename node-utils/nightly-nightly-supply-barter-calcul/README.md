# Nightly Supply Barter Calculator\n\nUtility to compute fair trade values between common post‑apocalypse supplies based on rarity and utility scores.\n\n## Items and their base scores\n\n| Item | Rarity | Utility | Base Value (rarity × utility) |\n|------|--------|---------|-------------------------------|\n| water | 1 | 5 | 5 |\n| cannedFood | 2 | 4 | 8 |\n| medicine | 5 | 10 | 50 |\n| ammo | 3 | 6 | 18 |\n| fuel | 4 | 8 | 32 |\n\n## Usage\n\n```sh\nnode src/index.js <itemA> <qtyA> <itemB> <qtyB>\n```\n\nExample:\n\n```sh\nnode src/index.js water 10 cannedFood 5\n```\n\nOutput:\n\n```
Trade ratio: 50 (water) vs 40 (cannedFood)\n1 water ≈ 0.80 cannedFood\n```\n\n## API (for developers)\n\nThe module exports three functions that can be required in other Node scripts:\n\n- `getItemValue(name)` – returns the base value for a single unit of the item.\n- `totalValue(name, qty)` – returns the total value for a quantity of the item.\n- `tradeWorth(itemA, qtyA, itemB, qtyB)` – returns an object `{ totalA, totalB, ratioAtoB }` describing the trade totals and the ratio of A to B.\n\nAll functions throw an error if an unknown item name is supplied.\n
