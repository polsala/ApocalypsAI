# Nightly Supply Barter Calculator\n\nA whimsical CLI utility for post‑apocalypse traders. It converts a list of supplies into a single barter‑point score based on predefined rarity values.\n\n## Installation\n\n```sh\ngit clone <repo>\ncd utils/nightly-supply-barter-calculator\n# No external dependencies required\n```\n\n## Usage\n\n```sh\nnode src/main.js --items "water:3,food:2,ammo:5"\n```\n\nOutput:\n\n````\nTotal barter points: 37\n````\n\n## How it works\n\nEach item has a static rarity score:\n\n- water: 2\n- food: 3\n- ammo: 5\n- medicine: 8\n- fuel: 4\n- tools: 6\n\nThe total is the sum of `quantity × score` for each supplied item. Unknown items default to a score of 1.\n\n## Testing\n\n```sh\nnode tests/test_main.js\n```\n\nThe test suite runs offline and validates the parsing and scoring logic.
