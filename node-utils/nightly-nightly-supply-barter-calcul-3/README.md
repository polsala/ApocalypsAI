# nightly‑supply‑barter‑calculator\n\n## Overview\n\n`nightly‑supply‑barter‑calculator` is a tiny Node.js command‑line utility that, given a list of supplies with their barter values and a target budget, enumerates **all** possible combinations of items whose total value exactly matches the budget.  It’s perfect for those moments when you need to know how many cans of beans, bottles of water, or rounds of ammo you can trade for a precious piece of tech.\n\n## Features\n\n- Accepts a comma‑separated list of `item:price` pairs.\n- Unlimited quantity of each item (you can trade multiple of the same supply).\n- Outputs every distinct combination that hits the exact budget.\n- Pure JavaScript – no external dependencies.\n\n## Installation\n\n```bash\n# Clone the repository (or copy the utility into your project)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/nightly-supply-barter-calculator\n# No npm install needed – the code uses only the Node standard library.\n```\n\n## Usage\n\n```bash\nnode src/cli.js --items "water:3,food:5,ammo:2" --budget 10\n```\n\nThe above command will print all ways to spend a budget of **10** barter points using water (3), food (5) and ammo (2). Example output:\n\n````\n[\n  { water: 0, food: 2, ammo: 0 },\n  { water: 2, food: 0, ammo: 2 },\n  { water: 1, food: 1, ammo: 1 },\n  { water: 0, food: 0, ammo: 5 }\n]\n````\n\n## Running Tests\n\n```bash\nnode tests/test_barter.js\n```\n\nAll tests should pass without any network access.\n\n## License\n\nMIT – see LICENSE file in the repository root.\n
