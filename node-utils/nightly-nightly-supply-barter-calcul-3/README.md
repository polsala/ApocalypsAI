# Nightly Supply Barter Calculator\n\nA whimsical CLI tool for post‑apocalyptic traders to quickly compute the fair trade value of a bundle of supplies based on rarity.\n\n## Installation\n\n```sh\n# Clone the utility (or copy the folder into your project)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/nightly-supply-barter-calculator\n# No external dependencies – just Node.js 14+\n```\n\n## Usage\n\n```sh\nnode src/main.js --item "water:5:common" --item "ammo:2:rare"\n```\n\nExpected output:\n\n````\nTotal barter value: 85\n````\n\n## How it works\n\nEach rarity has a base price:\n\n- **common**: 5\n- **uncommon**: 10\n- **rare**: 30\n- **epic**: 80\n\nThe total value is the sum of `quantity × base price` for every supplied item.\n\n## API\n\nThe module also exports a programmatic function:\n\n```js\nconst { calculateValue } = require('./src/main');\nconst items = [\n  { name: 'water', quantity: 5, rarity: 'common' },\n  { name: 'ammo', quantity: 2, rarity: 'rare' }\n];\nconsole.log(calculateValue(items)); // 85\n```\n\n## Testing\n\nRun the bundled tests with Node:\n\n```sh\nnode tests/test_main.js\n```\n\nAll tests should pass and print `All tests passed`.\n
