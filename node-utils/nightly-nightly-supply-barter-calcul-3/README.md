# Nightly Supply Barter Calculator\n\nA whimsical CLI tool for post‑apocalyptic traders to quickly compute fair trade ratios between common supplies.\n\n## Installation\n\n```sh\ngit clone <repo> && cd utils/nightly-supply-barter-calculator\nnpm install\n```\n\n(Only uses built‑in Node modules.)\n\n## Usage\n\n```sh\nnode src/index.js water 5 canned-food 2\n```\n\nOutputs something like:\n\n````\n5 water ↔ 2 canned-food\nFair trade value: 1 water ≈ 0.40 canned-food\n````\n\n## How it works\n\nEach item has a base scarcity score. The tool multiplies quantity by score to get a "value". The ratio of values determines fairness.\n\n## Testing\n\n```sh\nnode tests/test_index.js\n```\n\nIf all assertions pass you will see `All tests passed.`
