# Supply Barter Calculator\n\nA whimsical CLI utility for post‑apocalypse traders. It estimates a fair trade ratio between two supplies based on predefined base values and scarcity factors.\n\n## Installation\n\n```sh\nnpm install -g .\n```\n\n*(The utility is self‑contained; no external dependencies.)*\n\n## Usage\n\n```sh\nnode src/index.js --give water --receive food\n```\n\nOutput:\n\n````\nFair trade: 1.67 units of food per 1 unit of water\n````\n\n## How it works\n\nEach item has a *base value* and a *scarcity multiplier*. The trade ratio is:\n\n````\n(give.base * give.scarcity) / (receive.base * receive.scarcity)\n````\n\nRounded to two decimal places.\n\n## Adding items\n\nEdit the `ITEMS` object in `src/index.js`.\n
