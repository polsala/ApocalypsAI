# Supply Barter Calculator\n\nA whimsical CLI utility to help survivors determine fair trade values for common supplies in a post‑apocalyptic world.\n\n## Installation\n\n```sh\nnpm install -g nightly-supply-barter-calculator\n```\n\n## Usage\n\nList available items:\n\n```sh\nsupply-barter --list\n```\n\nCalculate value:\n\n```sh\nsupply-barter --value water 3\n```\n\n## How it works\n\nEach item has a base value and a scarcity multiplier. The total trade value is:\n\n`value = base * scarcity * quantity`\n\n## License\n\nMIT
