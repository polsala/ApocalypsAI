# Nightly Supply Barter Calculator\n\n## Overview\n\n`nightly-supply-barter-calculator` is a tiny Node.js command‑line utility that helps you figure out a fair total barter value for a list of supplies.  It takes into account the quantity of each item, its base value, and a *scarcity factor* (0‑1) that represents how rare the items are in the wasteland.  The higher the scarcity, the higher the total value.\n\n## Installation\n\n```bash\n# Clone the repository (or copy the generated folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/nightly-supply-barter-calculator\n# No external dependencies – just Node.js (v14+)\n```\n\n## Usage\n\nCreate a JSON file describing your supplies, e.g. `supplies.json`:\n\n```json\n[\n  {\n    "name": "canned beans",\n    "qty": 10,\n    "baseValue": 5\n  },\n  {\n    "name": "water bottle",\n    "qty": 5,\n    "baseValue": 2\n  }\n]\n```\n\nRun the calculator:\n\n```bash\nnode src/main.js supplies.json --scarcity 0.2\n```\n\nThe output will be something like:\n\n```
Total barter value: 72\n```\n\n## API\n\nThe core logic is exposed as a module function so you can embed it in other scripts:\n\n```js\nconst { calculateBarterValue } = require('./src/main');\nconst items = [{ name: 'medkit', qty: 2, baseValue: 50 }];\nconst total = calculateBarterValue(items, 0.1); // => 110\n```\n\n## Testing\n\nRun the bundled tests with Node:\n\n```bash\nnode tests/test_main.js\n```\n\nYou should see `All tests passed` if everything works.\n\n---\n\n*Feel free to tweak the scarcity factor to reflect the ever‑changing market of the wasteland!*
