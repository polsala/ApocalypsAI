# nightly-supply-barter-calculator\n\nA whimsical yet practical Node.js utility that helps you compute fair barter values for supplies in a post‑apocalypse setting.\n\n## Features\n\n- Accepts a list of items with base values, quantities, and scarcity scores (0‑1).\n- Adjusts values based on scarcity: rarer items are worth more.\n- Outputs a total barter value and a per‑item adjusted price.\n- Can be used as a CLI tool or imported as a module.\n\n## Installation\n\n```bash\n# Clone the repository (or copy the utility folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/nightly-supply-barter-calculator\nnpm install\n```\n\n## Usage as a CLI\n\n```bash\nnode src/index.js '{"items":[{"name":"canned beans","baseValue":10,"quantity":5,"scarcity":0.2},{"name":"bottled water","baseValue":8,"quantity":10,"scarcity":0.8}]}'\n```\n\nThe command prints a JSON summary with adjusted prices and total value.\n\n## Usage as a module\n\n```javascript\nconst { calculateBarterValue } = require('./src/index');\n\nconst items = [\n  { name: 'canned beans', baseValue: 10, quantity: 5, scarcity: 0.2 },\n  { name: 'bottled water', baseValue: 8, quantity: 10, scarcity: 0.8 }\n];\n\nconst result = calculateBarterValue(items);\nconsole.log(result);\n```\n\n## How the calculation works\n\nAdjusted price per unit = baseValue * (1 + (1 - scarcity) * 0.5)\n\n- `scarcity` is a float between 0 (common) and 1 (extremely rare).\n- The formula gives a maximum 50% premium for the most common items and no premium for the rarest.\n\n## Testing\n\n```bash\nnpm test\n```\n\nThe test suite runs deterministic offline tests using Node's built‑in `assert` module.\n
