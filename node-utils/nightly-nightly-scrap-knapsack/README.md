# Nightly Scrap Knapsack\n\n**Utility:** `nightly-scrap-knapsack`\n\nA whimsical yet practical command‑line tool for post‑apocalyptic survivors. Given a list of scavenged items (each with a name, weight, and value) and a maximum cargo weight, the tool computes the optimal subset of items that maximizes total value while staying within the weight limit – the classic 0/1 knapsack problem.\n\n## Features\n\n- Pure JavaScript (Node.js) – no external dependencies.\n- Reads items from a JSON file.\n- Simple command‑line flags: input file and weight limit.\n- Outputs selected item names, total weight, and total value.\n- Includes a deterministic test suite.\n\n## Installation\n\n```bash\n# Clone the repository (or copy the utility folder)\ngit clone https://github.com/polsala/ApocalypsAI.git\ncd utils/nightly-scrap-knapsack\n# Ensure you have Node.js (v14+) installed\nnode -v\n```\n\n## Usage\n\nCreate an `items.json` file describing your scavenged loot, for example:\n\n```json\n[\n  {\n    "name": "Rusty Pipe",\n    "weight": 10,\n    "value": 60\n  },\n  {\n    "name": "Old Battery",\n    "weight": 20,\n    "value": 100\n  },\n  {\n    "name": "Makeshift Radio",\n    "weight": 30,\n    "value": 120\n  }\n]\n```\n\nRun the tool with a maximum cargo weight (e.g., 50 units):\n\n```bash\nnode src/main.js -i items.json -w 50\n```\n\nExpected output:\n\n```
Selected items: Old Battery, Makeshift Radio\nTotal weight: 50\nTotal value: 220\n```\n\n## Testing\n\nThe utility ships with a self‑contained test suite that runs without network access. To execute the tests:\n\n```bash\nnode tests/test_knapsack.js\n```\n\nYou should see `All tests passed` if everything is working correctly.\n\n## License\n\nThis utility is released under the MIT License – see the repository root for details.
