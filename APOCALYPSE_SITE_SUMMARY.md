## 🏗️ Technical Architecture

### Frontend Stack
- **React 19.2.0** - Latest React
- **Vite 7.2.5** - Build tool with Rolldown
- **Three.js** - 3D graphics (via React Three Fiber)
- **GSAP** - Animation library
- **Howler.js** - Audio framework

### Components Structure
```
src/components/
├── MatrixRain.jsx          # Falling code background
├── VaporwaveBackground.jsx # Retro grid animation
├── GlitchText.jsx          # Text distortion
├── FloatingMemes.jsx       # Rising meme bubbles
├── FakeAlerts.jsx          # Popup warnings
├── CursorTrail.jsx         # Mouse trail effect
├── ExplosionEffect.jsx     # Click explosions
├── AsciiArt.jsx            # Text logo
├── Countdown.jsx           # Timer component
└── TerminalSection.jsx     # CLI interface
```
