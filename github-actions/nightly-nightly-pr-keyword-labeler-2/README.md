# Nightly PR Keyword Labeler\n\nA tiny GitHub Action that scans the pull‑request title for configured keywords and outputs a whimsical label name. The label can then be applied in the workflow using `gh` CLI, `actions/github-script`, or any other method.\n\n## Inputs\n\n| Name | Description | Default |\n|------|-------------|---------|\n| `keywords` | Comma‑separated list of keywords to look for in the PR title. | `fix,bug,feature` |\n| `label` | The label to suggest when any keyword matches. | `🧙‍♂️ Spellbound` |\n\n## Outputs\n\n| Name | Description |\n|------|-------------|\n| `label` | The label that should be applied (only set when a keyword matches). |\n\n## Example workflow\n\n```yaml\nname: Auto‑label PRs\n\non:\n  pull_request:\n    types: [opened, edited]\n\njobs:\n  label:\n    runs-on: ubuntu-latest\n    steps:\n      - name: Checkout\n        uses: actions/checkout@v3\n\n      - name: Run keyword labeler\n        id: labeler\n        uses: ./\n        with:\n          keywords: "fix,bug,feature"\n          label: "🧙‍♂️ Spellbound"\n\n      - name: Apply label if suggested\n        if: steps.labeler.outputs.label != ''\n        run: gh pr edit ${{ github.event.pull_request.number }} --add-label "${{ steps.labeler.outputs.label }}"\n        env:\n          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}\n```\n\n## How it works\n\nThe action reads the event payload from the `GITHUB_EVENT_PATH` environment variable, extracts the PR title, and checks whether any of the supplied keywords appear (case‑insensitive). If a match is found, it sets the `label` output using the special `::set-output` command and prints a friendly message.\n\n## License\n\nMIT
