Nightly Emoji PR Labeler\nA GitHub Action that automatically adds labels to a pull request based on emojis found in its title.\n\nHow it works\n- Scans the PR title for a set of known emojis.\n- Maps each emoji to a predefined label (e.g., 🐛 -> bug, ✨ -> enhancement).\n- Uses the GitHub token to apply those labels to the PR.\n\nSupported emojis and labels\n🚀 launch\n🐛 bug\n✨ enhancement\n📝 documentation\n⚡ performance\n🔥 hotfix\n\nUsage\nCreate a workflow file (e.g., .github/workflows/emoji-labeler.yml) with:\n\nname: Emoji PR Labeler\non:\n  pull_request:\n    types: [opened, edited, reopened]\n\njobs:\n  label:\n    runs-on: ubuntu-latest\n    steps:\n      - uses: actions/checkout@v3\n      - uses: ./utils/nightly-emoji-pr-labeler\n        with:\n          github_token: ${{ secrets.GITHUB_TOKEN }}\n\nThe action will read the PR title and add any matching labels.
