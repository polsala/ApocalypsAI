# Nightly Emoji Reaction\n\nThis utility provides a GitHub Actions workflow that automatically adds a random whimsical emoji reaction to every newly created issue comment.\n\n## How it works\n\n- The workflow triggers on the `issue_comment` event (type `created`).\n- A small Bash script (`src/add-reaction.sh`) selects a random emoji from a curated list and calls the GitHub Reactions API using `curl`.\n- No external dependencies are required beyond the default GitHub Actions runner environment.\n\n## Setup\n\n1. Copy the `src/add-reaction.sh` script into your repository (e.g., `src/add-reaction.sh`).\n2. Add the workflow file `src/workflow.yml` to `.github/workflows/emoji-reaction.yml` in your repository.\n3. Ensure the default `GITHUB_TOKEN` secret is available (GitHub provides it automatically).\n\n## Files\n\n- `src/add-reaction.sh` – Bash script that selects an emoji and posts the reaction.\n- `src/workflow.yml` – GitHub Actions workflow definition.\n- `tests/test_add-reaction.sh` – Offline deterministic test using a mocked `curl`.\n\n## License\n\nMIT License – see LICENSE file in the repository root.
