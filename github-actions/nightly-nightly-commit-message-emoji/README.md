# Nightly Commit Message Emoji Enhancer\n\nA tiny GitHub Action that adds a relevant emoji prefix to a commit message based on simple keyword detection.\n\n## Features\n\n- Detects common commit intents (fix, feature, docs, removal, etc.)\n- Returns the enhanced message as an output variable `enhanced_message`\n- Works as a Docker‑based action (no Node.js runtime required)\n\n## Usage\n\n```yaml\nname: Enhance commit messages\n\non:\n  push:\n    branches: [ main ]\n\njobs:\n  emoji:\n    runs-on: ubuntu-latest\n    steps:\n      - name: Checkout\n        uses: actions/checkout@v3\n\n      - name: Get latest commit message\n        id: commit\n        run: echo "::set-output name=msg::$(git log -1 --pretty=%B)"\n\n      - name: Add emoji\n        id: enhancer\n        uses: ./github-actions/nightly-commit-message-emoji-enhancer\n        with:\n          message: ${{ steps.commit.outputs.msg }}\n\n      - name: Show result\n        run: echo "Enhanced: ${{ steps.enhancer.outputs.enhanced_message }}"\n```\n\n## Inputs\n\n| Name | Description | Required | Default |\n|------|-------------|----------|---------|\n| `message` | The raw commit message to enhance | yes | N/A |\n\n## Outputs\n\n| Name | Description |\n|------|-------------|\n| `enhanced_message` | The original message prefixed with an emoji |\n\n## Implementation Details\n\nThe action runs a tiny shell script inside an Alpine Docker container. The script performs a case‑insensitive keyword match and selects an emoji accordingly. It then emits the result using the legacy `::set-output` syntax for maximum compatibility.\n\n## License\n\nMIT
