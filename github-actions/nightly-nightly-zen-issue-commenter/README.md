# Nightly Zen Issue Commenter\n\n## Overview\n\n`nightly-zen-issue-commenter` is a lightweight GitHub Action that automatically leaves a calming Zen quote as a comment whenever a new issue is opened. It adds a touch of whimsy to your repository while reminding contributors to stay mindful.\n\n## Features\n\n- Picks a random Zen‑style quote from a built‑in list.\n- Posts the quote as a comment using the `gh` CLI (or any compatible HTTP client).\n- Implemented as a **composite** action, so no extra runtime dependencies are required.\n\n## Usage\n\nAdd the following step to your workflow (e.g., `.github/workflows/issue-zen.yml`):\n\n```yaml\nname: Zen Issue Welcomer\n\non:\n  issues:\n    types: [opened]\n\njobs:\n  comment:\n    runs-on: ubuntu-latest\n    steps:\n      - name: Checkout repository\n        uses: actions/checkout@v4\n\n      - name: Post Zen Quote\n        uses: ./github-actions/nightly-zen-issue-commenter\n        with:\n          # No inputs required\n        env:\n          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}\n```\n\nThe action will automatically select a quote and post it as a comment on the newly opened issue.\n\n## Development\n\nThe core logic lives in `src/zen_comment.sh`. It can be run locally for testing:\n\n```bash\ncd github-actions/nightly-zen-issue-commenter\nRANDOM=0 ./src/zen_comment.sh\n```\n\n## Testing\n\nA deterministic Bash test is provided under `tests/`. It forces the random seed to a known value and verifies the output. Run it with:\n\n```bash\ncd github-actions/nightly-zen-issue-commenter\nchmod +x tests/test_zen_comment.sh\n./tests/test_zen_comment.sh\n```\n\n## License\n\nMIT
