# Good First Issue Labeler\n\nA GitHub Action that automatically adds the `good first issue` label to newly opened issues when their title or body contains any of a configurable list of beginner‑friendly keywords.\n\n## Usage\n\n```yaml\nname: Good First Issue Labeler\non:\n  issues:\n    types: [opened]\n\njobs:\n  label:\n    runs-on: ubuntu-latest\n    steps:\n      - uses: ./ # uses the action from this repository\n        with:\n          github_token: ${{ secrets.GITHUB_TOKEN }}\n          keywords: "help,beginner,first-timer,good first issue"\n```\n\n## Inputs\n\n| Name | Description | Required | Default |\n|------|-------------|----------|---------|\n| `github_token` | Token with `issues:write` permission. | Yes | |\n| `keywords` | Comma‑separated list of keywords that trigger the label. | No | `help,beginner,first-timer,good first issue` |\n\n## How it works\n\nThe action reads the issue title and body, checks for any of the keywords (case‑insensitive) and, if a match is found, adds the `good first issue` label via the GitHub REST API.\n\n## License\n\nMIT
