# Nightly PR Thematic Sentry\n\nA GitHub Action that acts as a thematic guardian for your Pull Requests. It ensures that PR titles and descriptions align with your project's specific thematic guidelines by checking for the presence of required keywords and the absence of forbidden ones. Perfect for maintaining a consistent tone, lore, or specific terminology across your repository, especially in a post-apocalyptic world where thematic consistency is key to survival!\n\n## Usage\n\nAdd this action to your workflow to automatically check PRs.\n\n```yaml\nname: PR Thematic Check\n\non:\n  pull_request:\n    types: [opened, reopened, synchronize]\n\njobs:\n  thematic_sentry:\n    runs-on: ubuntu-latest\n    steps:\n      - name: Check PR Thematic Alignment\n        uses: polsala/ApocalypsAI/utils/nightly-pr-thematic-sentry@main # Replace 'main' with your branch/tag\n        with:\n          github-token: ${{ secrets.GITHUB_TOKEN }}\n          required-keywords: 'wasteland, survival, scavenge'\n          forbidden-keywords: 'luxury, comfort, peace'\n```\n\n### Inputs\n\n*   `github-token`: **(Required)** Your GitHub token, usually `${{ secrets.GITHUB_TOKEN }}`, to access PR details.\n*   `required-keywords`: **(Optional)** A comma-separated string of keywords that *must* be present in either the PR title or description. Case-insensitive. Default: `''`.\n*   `forbidden-keywords`: **(Optional)** A comma-separated string of keywords that *must not* be present in either the PR title or description. Case-insensitive. Default: `''`.\n\n### Outputs\n\n*   `thematic-check-status`: `success` if all checks pass, `failure` otherwise.\n*   `thematic-check-message`: A detailed message explaining the outcome of the thematic check.\n\n## Development\n\nTo run tests locally:\n\n```bash\nnpm install\nnpm test\n```
