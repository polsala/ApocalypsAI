# Nightly PR Labeler\n\nA tiny, whimsical GitHub Action that examines the list of files changed in a pull request and suggests labels based on configurable substring patterns.\n\n## Features\n\n- **Configurable mapping** – Provide a JSON object where keys are substrings to look for in file paths and values are the labels to apply.\n- **Zero external dependencies** – Uses only the official `@actions/*` toolkit.\n- **Deterministic & offline** – The core logic is pure JavaScript and fully unit‑tested.\n\n## Inputs\n\n| Name | Description | Required | Default |\n|------|-------------|----------|---------|\n| `changed_files` | New‑line separated list of file paths changed in the PR. Usually supplied via `${{ join(github.event.pull_request.changed_files, '\n') }}` or a custom step that extracts the list. | **true** | – |\n| `label_map` | JSON string mapping substrings to label names, e.g. `{ "docs/": "documentation", "src/": "code" }`. | **true** | – |\n| `token` | GitHub token with `issues:write` permission (optional – if omitted the action only outputs the suggested labels). | false | `${{ github.token }}` |\n\n## Outputs\n\n| Name | Description |\n|------|-------------|\n| `labels` | JSON‑encoded array of labels that should be applied to the PR. |\n\n## Example Workflow\n\n```yaml\nname: Auto‑label PRs\n\non:\n  pull_request:\n    types: [opened, synchronize]\n\njobs:\n  label:\n    runs-on: ubuntu-latest\n    steps:\n      - name: Checkout repository\n        uses: actions/checkout@v3\n\n      - name: Get list of changed files\n        id: files\n        uses: jitterbit/get-changed-files@v1\n        with:\n          format: "newline"\n\n      - name: Suggest labels\n        id: suggest\n        uses: ./\n        with:\n          changed_files: ${{ steps.files.outputs.all }}\n          label_map: '{"docs/":"documentation","src/":"code","tests/":"tests"}'\n\n      - name: Apply labels\n        if: steps.suggest.outputs.labels != '[]'\n        uses: actions-ecosystem/action-add-labels@v1\n        with:\n          github_token: ${{ secrets.GITHUB_TOKEN }}\n          labels: ${{ fromJson(steps.suggest.outputs.labels) }}\n```\n\nThe action itself only **suggests** labels; you can pair it with any label‑adding action (as shown above) or handle the output yourself.\n\n## Development & Testing\n\nRun the unit tests with:\n\n```bash\nnpm install\nnpm test\n```\n\nAll tests are deterministic and do not hit the network.\n
