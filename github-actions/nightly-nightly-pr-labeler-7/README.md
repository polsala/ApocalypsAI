# Nightly PR Labeler\n\nA reusable GitHub Actions workflow that automatically adds whimsical labels to pull requests based on the file types that were modified.\n\n## Features\n\n- Detects frontend files (JS/TS/TSX) and adds `✨ frontend‑sparkle`\n- Detects backend files (Python, Go, Rust, Java) and adds `🛠️ backend‑tinker`\n- Detects documentation files (MD/TXT) and adds `📚 docs‑delight`\n- Detects image assets and adds `🖼️ art‑gallery`\n- Fully self‑contained; just call the reusable workflow from any repo.\n\n## Usage\n\nCreate a workflow in your repository that calls this reusable workflow. Example:\n\n```yaml\nname: PR Labeler\n\non:\n  pull_request:\n    types: [opened, synchronize]\n\njobs:\n  label:\n    uses: polsala/ApocalypsAI/.github/workflows/pr-labeler.yml@main\n    with:\n      token: ${{ secrets.GITHUB_TOKEN }}\n```\n\nThe workflow will automatically compute the changed files, run the labeler script, and apply the appropriate labels to the PR.\n\n## Implementation Details\n\n- **src/labeler.js**: Node.js script that reads a newline‑separated list of changed files from the `CHANGED_FILES` environment variable and prints the labels to stdout.\n- **.github/workflows/pr-labeler.yml**: Reusable workflow that checks out the code, determines changed files via `git diff`, invokes the labeler, and applies the labels using `actions/github-script`.\n- **tests/test_labeler.py**: Python unittest that runs the Node script with mocked environment variables to verify label selection logic.\n\n## License\n\nMIT
