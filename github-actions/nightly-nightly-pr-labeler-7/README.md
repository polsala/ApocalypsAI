# Nightly PR Labeler\n\nUtility that automatically adds labels to a pull request based on keywords found in the PR title. Useful for triaging PRs without manual effort.\n\n## Usage\n\nCreate a workflow that uses this action:\n\n```yaml\nname: Auto Label PRs\non:\n  pull_request:\n    types: [opened, edited]\n\njobs:\n  label:\n    runs-on: ubuntu-latest\n    steps:\n      - uses: actions/checkout@v3\n      - uses: ./path/to/nightly-pr-labeler\n        with:\n          github-token: ${{ secrets.GITHUB_TOKEN }}\n```\n\nThe action reads the PR title and adds labels:\n\n- `bug` → adds `type: bug`\n- `feat` or `feature` → adds `type: feature`\n- `docs` → adds `type: documentation`\n- `refactor` → adds `type: refactor`\n\n## Inputs\n\n- `github-token` (required): Token with repo scope.\n\n## Implementation\n\nThe action runs a small Node.js script that determines labels and calls the GitHub REST API.
