# nightly-chaos-report-aggregator

A GitHub Action that scans for chaos engineering reports generated by ApocalypsAI's Ansible playbooks and aggregates them into a single markdown summary for easy review.

## Features

- Scans a specified directory for chaos report files (`chaos_report.md`).
- Aggregates findings into a unified markdown output.
- Uploads the summary as a build artifact.
- Comments on pull requests with the summary (if triggered from a PR).

## Usage

```yaml
- name: Aggregate Chaos Reports
  uses: polsala/ApocalypsAI/utils/nightly-chaos-report-aggregator@main
  with:
    reports_dir: ./ansible-reports
```

## Inputs

| Input        | Description                      | Default       |
|--------------|----------------------------------|---------------|
| `reports_dir`| Directory to scan for reports    | `./reports`   |

## Outputs

- `summary_path`: Path to the aggregated markdown summary.
