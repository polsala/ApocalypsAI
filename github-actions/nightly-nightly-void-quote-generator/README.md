# Nightly Void Quote Generator\n\n## Overview\n\n`nightly-void-quote-generator` is a tiny GitHub Action that picks a random apocalyptic‑themed quote and makes it available as the `quote` output.  It can be used to add flavor to CI runs, PR comments, release notes, or any other step in a workflow.\n\n## Inputs\n\n| Name | Description | Required | Default |\n|------|-------------|----------|---------|\n| `prefix` | Optional text to prepend to the generated quote. | No | (empty) |\n\n## Outputs\n\n| Name | Description |\n|------|-------------|\n| `quote` | The final quote string (with optional prefix). |\n\n## Example usage\n\n```yaml\nname: Add apocalyptic flavor\n\non:\n  push:\n    branches: [ main ]\n\njobs:\n  quote:\n    runs-on: ubuntu-latest\n    steps:\n      - uses: actions/checkout@v3\n      - id: quote\n        uses: ./github-actions/nightly-void-quote-generator\n        with:\n          prefix: "⚠️"\n      - name: Echo the quote\n        run: echo "Quote: ${{ steps.quote.outputs.quote }}"\n```\n\n## Development\n\nThe action is implemented in JavaScript and runs on `node12`.  It depends only on `@actions/core`.  To run the tests locally:\n\n```bash\nnpm install\nnpm test\n```\n\n## License\n\nMIT
