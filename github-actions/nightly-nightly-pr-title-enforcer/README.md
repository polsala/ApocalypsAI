# Nightly PR Title Enforcer\n\nEnforces that every pull request title starts with a configurable emoji or string prefix (default "🚀"). Useful for teams that tag PRs with priority or type emojis.\n\n## Usage\n\nAdd a workflow that runs this action on `pull_request_target` events.\n\n```yaml\nname: PR Title Check\non:\n  pull_request_target:\n    types: [opened, edited, synchronize]\n\njobs:\n  title-check:\n    runs-on: ubuntu-latest\n    steps:\n      - uses: actions/checkout@v3\n      - uses: ./path/to/nightly-pr-title-enforcer\n        with:\n          prefix: "🚀"\n```\n\n## Inputs\n\n| Name | Description | Default |\n|------|-------------|---------|\n| `prefix` | Required prefix for PR titles | "🚀" |\n\nThe action will fail the job if the title does not start with the given prefix.\n\n## How it works\n\nThe action reads the GitHub event payload (available via `GITHUB_EVENT_PATH`), extracts the PR title, and checks whether it begins with the supplied prefix. If the check fails, the step exits with a non‑zero status, causing the workflow to fail.\n
