# Nightly PR Quote Commenter\n\nA whimsical GitHub Action that automatically comments a random post‑apocalypse quote on newly opened pull requests. Helps keep the community entertained while reminding contributors that even code can survive the end of the world.\n\n## Usage\n\n```yaml\nname: PR Quote Commenter\non:\n  pull_request:\n    types: [opened]\n\njobs:\n  comment:\n    runs-on: ubuntu-latest\n    steps:\n      - uses: actions/checkout@v3\n      - uses: ./ # uses this action\n        with:\n          github-token: ${{ secrets.GITHUB_TOKEN }}\n```\n\n## Inputs\n\n- `github-token` (required): Token with `repo` scope to post comments.\n- `quotes` (optional): Multiline string of custom quotes; one per line. If omitted, a built‑in list is used.\n\n## How it works\n\nThe action selects a random quote and posts it as a comment on the PR that triggered the workflow.\n\n## License\n\nMIT
