# Nightly PR Language Labeler\n\nA GitHub Action that automatically determines the programming languages present in a pull request's changed files and outputs a list of labels (e.g., `language:python`, `language:javascript`). Useful for triaging PRs.\n\n## Usage\n\n```yaml\nname: Auto label PRs\non:\n  pull_request:\n    types: [opened, synchronize]\n\njobs:\n  label:\n    runs-on: ubuntu-latest\n    steps:\n      - uses: actions/checkout@v3\n      - uses: ./ # uses the action in this repository\n        with:\n          github-token: ${{ secrets.GITHUB_TOKEN }}\n```\n\nThe action reads the pull request diff, detects file extensions, maps them to language labels, and sets the output `labels`. You can then use `actions/github-script` to apply the labels.\n\n## Inputs\n\n- `github-token` – (required) Token with `issues:write` permission.\n\n## Outputs\n\n- `labels` – JSON array of label strings.\n\n## License\n\nMIT
