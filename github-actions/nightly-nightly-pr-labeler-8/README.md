# Nightly PR Labeler\n\nA tiny GitHub Action that scans the title of a pull request and automatically adds helpful labels.\n\n## How it works\n\n1. The action reads the PR title from the `GITHUB_EVENT_PATH` environment variable (the default event payload provided by GitHub).\n2. It matches a set of predefined keyword‑to‑label mappings.\n3. Using the GitHub REST API it adds any matching labels to the PR.\n\n## Keyword → Label map (default)\n\n| Keyword (case‑insensitive) | Label added |\n|----------------------------|-------------|\n| `bug`                      | `bug`       |\n| `feature` or `feat`        | `enhancement`|\n| `docs`                     | `documentation`|\n| `test`                     | `tests`|\n| `refactor`                 | `refactor`|\n\nYou can extend the map by editing `src/index.js`.\n\n## Usage\n\nAdd the following step to your workflow (e.g. `.github/workflows/label-pr.yml`):\n\n```yaml\nname: PR Labeler\n\non:\n  pull_request_target:\n    types: [opened, edited]\n\njobs:\n  label:\n    runs-on: ubuntu-latest\n    steps:\n      - uses: actions/checkout@v3\n      - name: Label PR\n        uses: ./nightly-pr-labeler\n        with:\n          github-token: ${{ secrets.GITHUB_TOKEN }}\n```\n\nThe action expects a `github-token` input with permission to label PRs.\n\n## Testing\n\nRun the Jest test suite locally with:\n\n```bash\nnpm install\nnpm test\n```\n\nThe tests mock the GitHub API, so no network calls are made.\n
