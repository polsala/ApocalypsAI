# Nightly PR Labeler\n\nUtility that examines the list of files changed in a pull request and automatically adds a label (`python`, `docs`, `javascript`, or `misc`) to the PR. Ideal for keeping repositories tidy without manual effort.\n\n## Usage\n\nCreate a workflow that uses this action:\n\n```yaml\nname: Auto label PR\non:\n  pull_request:\n    types: [opened, synchronize]\n\njobs:\n  label:\n    runs-on: ubuntu-latest\n    steps:\n      - uses: actions/checkout@v3\n      - name: Get changed files\n        id: files\n        run: |\n          echo "files=$(git diff --name-only ${{{{ github.event.pull_request.base.sha }}}} ${{{{ github.event.pull_request.head.sha }}}})" >> $GITHUB_OUTPUT\n      - name: Apply label\n        uses: ./github-actions/nightly-pr-labeler\n        with:\n          files: ${{{{ steps.files.outputs.files }}}}\n          github-token: ${{{{ secrets.GITHUB_TOKEN }}}}\n```\n\n## Inputs\n\n- `files` – Space‑separated list of changed file paths (required).\n- `github-token` – Token with `issues:write` permission (required).\n\n## How it works\n\nThe action runs a small Bash script that scans the file extensions and decides which label to apply. It then calls the GitHub REST API to add the label to the PR.\n\n## License\n\nMIT
