# Nightly PR Labeler\n\nA reusable GitHub Actions workflow that inspects the title of a pull request and automatically applies helpful labels.\n\n## Features\n\n- Detects common keywords like `bug`, `feature`, and `doc` in PR titles.\n- Adds the corresponding GitHub labels (`bug`, `enhancement`, `documentation`).\n- Works as a **reusable workflow** that can be called from any repository.\n\n## Usage\n\nAdd the following to your repository's workflow file (e.g., `.github/workflows/auto-label.yml`):\n\n```yaml\nname: Auto‑Label PRs\n\non:\n  pull_request_target:\n    types: [opened, edited, reopened]\n\njobs:\n  label:\n    uses: <owner>/<repo>/nightly-pr-labeler/.github/workflows/labeler.yml@main\n    with:\n      github-token: ${{ secrets.GITHUB_TOKEN }}\n```\n\nReplace `<owner>/<repo>` with the repository that hosts this utility. The workflow will run on every PR open/edit/reopen event and apply labels accordingly.\n\n## How It Works\n\nThe workflow uses the official `actions/github-script` action to run a short JavaScript snippet that:\n\n1. Reads the PR title.\n2. Checks for the presence of predefined keywords.\n3. Collects matching labels.\n4. Calls the GitHub REST API to add those labels to the PR.\n\nFeel free to fork and extend the keyword‑to‑label mapping to suit your project's conventions!\n
