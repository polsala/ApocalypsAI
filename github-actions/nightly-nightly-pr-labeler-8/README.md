# Nightly PR Labeler\n\nA reusable GitHub Actions workflow that automatically adds labels to pull requests based on title keywords.\n\n## Usage\n\nCreate a workflow in your repository that calls this reusable workflow:\n\n```yaml\nname: Apply PR Labels\non:\n  pull_request:\n    types: [opened, edited, reopened]\n\njobs:\n  label:\n    uses: your-org/ApocalypsAI/.github/workflows/nightly-pr-labeler.yml@main\n```\n\nThe workflow will add `bug`, `enhancement`, or `documentation` labels when the PR title contains `[bug]`, `[feature]`, or `[doc]` respectively.\n\n## How it works\n\nIt runs on `pull_request_target` and uses `actions/github-script` to inspect the PR title and apply labels via the GitHub REST API.
