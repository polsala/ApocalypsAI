# Nightly PR Labeler\n\nA whimsical GitHub Action that scans the title of a pull request for predefined keywords,\napplies matching labels, and posts a playful comment.\n\n## Inputs\n\n| Name | Description | Required | Default |\n|------|-------------|----------|---------|\n| `github-token` | Token with `repo` scope (usually `${{ secrets.GITHUB_TOKEN }}`) | true | |\n| `label-map` | JSON string mapping keywords to label names, e.g. `{"fix":"bug","feat":"enhancement"}` | false | `{}` |\n| `comment-template` | Template for the comment; `{keyword}` will be replaced with the matched keyword | false | `✨ Your PR looks like a **{keyword}**! Keep it up!` |\n\n## Outputs\n\nNone.\n\n## Example workflow\n\n```yaml\nname: Auto‑label PRs\non:\n  pull_request:\n    types: [opened, edited, reopened]\n\njobs:\n  label:\n    runs-on: ubuntu-latest\n    steps:\n      - uses: actions/checkout@v3\n      - name: Label PR\n        uses: ./github-actions/nightly-pr-labeler\n        with:\n          github-token: ${{ secrets.GITHUB_TOKEN }}\n          label-map: '{"fix":"bug","feat":"enhancement","docs":"documentation"}'\n```\n\n## How it works\n\nThe action runs a tiny Node.js script that:\n\n1. Reads the PR title.\n2. Finds the first keyword that appears in the `label‑map`.\n3. Adds the corresponding label to the PR.\n4. Posts a comment using the `comment-template`.\n\nIf no keyword matches, the action does nothing.\n\n## License\n\nMIT\n
