# Nightly PR Labeler\n\nA tiny GitHub Action that automatically adds labels to a pull request based on keywords found in its title.\n\n## Usage\n\n```yaml\nname: Auto‑label PRs\non:\n  pull_request:\n    types: [opened, edited, reopened]\n\njobs:\n  label:\n    runs-on: ubuntu‑latest\n    steps:\n      - uses: actions/checkout@v3\n      - uses: ./  # uses the action in this repository\n        with:\n          token: ${{ secrets.GITHUB_TOKEN }}\n          mapping: |\n            {\n              "bug": "bug",\n              "feat": "feature",\n              "doc": "documentation"\n            }\n```\n\nThe `mapping` input is a JSON object where each key is a keyword (case‑insensitive) and each value is the label to apply when the keyword appears in the PR title.\n\n## License\n\nMIT\n
