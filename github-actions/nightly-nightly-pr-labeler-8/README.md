# Nightly PR Labeler\n\nA tiny GitHub Action that automatically adds labels to a pull request based on the files that were changed.\n\n## Why?\n\n* Keep your PR board tidy – docs changes get a `documentation` label, test changes get a `tests` label, etc.\n* No manual labeling required – the action does the work for you.\n\n## Inputs\n\n| Name | Description | Required |\n|------|-------------|----------|\n| `github_token` | The `GITHUB_TOKEN` used to call the API. | Yes |\n| `label_map` | A JSON string that maps glob patterns to label names. Example: `{ "**/*.md": "documentation", "src/**/*.js": "code" }` | Yes |\n\n## Example Workflow\n\n```yaml\nname: Auto‑label PRs\n\non:\n  pull_request:\n    types: [opened, synchronize]\n\njobs:\n  label:\n    runs-on: ubuntu‑latest\n    steps:\n      - uses: actions/checkout@v4\n      - name: Label PR\n        uses: ./nightly-pr-labeler\n        with:\n          github_token: ${{ secrets.GITHUB_TOKEN }}\n          label_map: '{"**/*.md":"documentation","src/**/*.js":"code","tests/**/*.py":"tests"}'\n```\n\n## How It Works\n\n1. The action reads the `label_map` input and parses it as JSON.\n2. It fetches the list of files changed in the PR via the GitHub REST API.\n3. For each glob pattern, if any changed file matches, the corresponding label is queued.\n4. All collected labels are added to the PR in a single API call.\n\n## Development\n\nThe action is written in JavaScript and runs on `node12`. To run the tests locally:\n\n```bash\nnpm install\nnpm test\n```\n\n## License\n\nMIT – feel free to copy, remix, and spread the labeling love!\n
