Nightly PR Labeler\n\nThis GitHub Action examines the title of a pull request and automatically adds one or more labels based on predefined keyword groups. It also posts a short whimsical comment to lighten the review mood.\n\nUsage:\nCreate a workflow that triggers on pull_request_target and calls this action.\n\nInputs:\n- github-token (required): token with repo scope.\n\nConfiguration:\nEdit the keyword-to-label map inside src/labeler.sh to suit your repository.\n
