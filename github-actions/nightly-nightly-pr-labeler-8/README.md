# Nightly PR Labeler\n\nA reusable GitHub Actions workflow that automatically adds labels to a pull request based on the files changed and optional whimsical keywords.\n\n## Features\n- Detects changes in `docs/` and adds a `documentation` label.\n- Detects test files (`*_test.py`, `*.test.js`) and adds a `tests` label.\n- Looks for the word **wizard** in any changed path and adds a fun `🧙‍♂️ wizardry` label.\n- Fully reusable via `workflow_call` – can be referenced from any repository.\n\n## Usage\nCreate a workflow in your repository that calls this reusable workflow.\n\n```yaml\nname: PR Labeler\non:\n  pull_request:\n    types: [opened, synchronize]\n\njobs:\n  label:\n    uses: your-org/ApocalypsAI/.github/workflows/label-pr.yml@main\n    with:\n      token: ${{ secrets.GITHUB_TOKEN }}\n```\n\nReplace `your-org/ApocalypsAI` with the actual owner/repo where this utility lives.\n\n## How it works\n1. **Checkout** the repository.\n2. Use the `jitterbit/get-changed-files` action to obtain a JSON array of changed file paths.\n3. Run a small JavaScript snippet (via `actions/github-script`) that decides which labels to apply.\n4. Apply the labels to the PR using the GitHub REST API.\n\n## License\nMIT
