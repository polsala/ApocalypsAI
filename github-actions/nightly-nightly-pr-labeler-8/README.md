# Nightly PR Labeler\n\nA tiny GitHub Action that inspects the title of a pull request, adds appropriate labels (e.g., `bug`, `enhancement`, `documentation`) and leaves a friendly comment with a random emoji.\n\n## Features\n\n- **Keyword‑based labeling** – simple pattern matching on the PR title.\n- **Whimsical feedback** – posts a comment like "🚀 Your PR is ready to launch!" to brighten reviewers' day.\n- **Zero external services** – runs entirely inside the GitHub Actions runner.\n\n## Usage\n\nAdd the action to a workflow that triggers on `pull_request_target` (or `pull_request` if you trust the action). Example:\n\n```yaml\nname: PR Labeler\n\non:\n  pull_request_target:\n    types: [opened, edited, reopened]\n\njobs:\n  label:\n    runs-on: ubuntu-latest\n    steps:\n      - uses: actions/checkout@v3\n      - name: Run PR labeler\n        uses: ./github-actions/nightly-pr-labeler\n        with:\n          github-token: ${{ secrets.GITHUB_TOKEN }}\n```\n\nThe action expects a `github-token` input with permission to read and write PR metadata.\n\n## Inputs\n\n| Name | Description | Required | Default |\n|------|-------------|----------|---------|\n| `github-token` | Token used to authenticate with the GitHub API. Usually `secrets.GITHUB_TOKEN`. | Yes | – |\n\n## How it works\n\n1. The action reads the event payload (`GITHUB_EVENT_PATH`) to obtain the PR number and title.\n2. It matches the title against a small set of keywords and decides which labels to apply.\n3. Using the Octokit REST client it adds the labels to the PR.\n4. It selects a random emoji from a curated list and posts a comment on the PR.\n\n## Development\n\nThe source lives in `src/index.js`. Tests are written with Jest and can be run locally with:\n\n```bash\nnpm install\nnpm test\n```\n\n## License\n\nMIT – see the LICENSE file in the repository.\n
