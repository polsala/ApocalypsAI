# Nightly PR Labeler\n\n## Overview\n\n`nightly-pr-labeler` is a lightweight GitHub Action that examines the title of a pull request, matches configured keyword‑to‑label mappings, and finally appends a random emoji label for a touch of fun. It is designed to be composable and requires no external services – the action simply outputs the labels it would apply, leaving the actual labeling to a downstream step if desired.\n\n## Inputs\n\n| Name | Description | Required | Default |\n|------|-------------|----------|---------|\n| `pr_title` | The title of the pull request to analyse. | Yes | – |\n| `label_map` | JSON object mapping lower‑case keywords to GitHub label names. Example: `{\"bug\":\"bug\",\"feature\":\"enhancement\"}` | No | `{}` |\n\n## Outputs\n\nThe action prints one label per line to `STDOUT`. Consumers can capture this output and feed it to the `github-script` or `actions/github-script` action to actually apply the labels.\n\n## Example Workflow\n\n```yaml\nname: PR Labeler Demo\n\non:\n  pull_request:\n    types: [opened, edited]\n\njobs:\n  label:\n    runs-on: ubuntu-latest\n    steps:\n      - name: Checkout repository\n        uses: actions/checkout@v3\n\n      - name: Run PR Labeler\n        id: labeler\n        uses: ./github-actions/nightly-pr-labeler\n        with:\n          pr_title: ${{ github.event.pull_request.title }}\n          label_map: '{"bug":"bug","feature":"enhancement","doc":"documentation"}'\n\n      - name: Apply suggested labels\n        uses: actions/github-script@v6\n        with:\n          script: |\n            const labels = `${{ steps.labeler.outputs.result }}`.trim().split('\n');\n            await github.rest.issues.addLabels({\n              owner: context.repo.owner,\n              repo: context.repo.repo,\n              issue_number: context.issue.number,\n              labels\n            });\n```\n\n## Testing\n\nThe repository includes a deterministic Bash test (`tests/test_labeler.sh`). Run it locally with:\n\n```bash\nchmod +x tests/test_labeler.sh\n./tests/test_labeler.sh\n```\n\nThe test forces `RANDOM` to a known value, supplies a sample title and label map, and verifies the exact output.\n
