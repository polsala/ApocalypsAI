Nightly PR Labeler\n\nThis GitHub Actions workflow automatically adds labels to pull requests based on keywords in the PR title and appends a random whimsical emoji label. It helps keep your repository organized without manual effort.\n\nUsage\n-----\nAdd the workflow file to `.github/workflows/pr-labeler.yml` in your repository. The workflow runs on `pull_request` events (opened, reopened, edited). No additional configuration is required.\n\nCustomization\n-------------\nYou can modify the keyword‑to‑label mapping or the list of emojis directly in the workflow file.\n\nLicense\n-------\nMIT
