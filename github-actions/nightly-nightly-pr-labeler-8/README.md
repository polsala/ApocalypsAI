# Nightly PR Labeler\n\nA tiny GitHub Action that automatically adds labels to a pull request based on keywords found in the PR title.\n\n## Features\n\n- Detects common prefixes like `feat:`, `fix:`, `docs:` and applies corresponding labels (`feature`, `bug`, `documentation`).\n- Fully configurable via a simple Python script – easy to extend with more patterns.\n- Works with the default `GITHUB_TOKEN` provided to actions, no extra permissions required.\n\n## Usage\n\nAdd the action to a workflow that runs on `pull_request` events:\n\n```yaml\nname: PR Auto‑Labeler\n\non:\n  pull_request:\n    types: [opened, edited]\n\njobs:\n  label:\n    runs-on: ubuntu-latest\n    steps:\n      - uses: actions/checkout@v3\n      - name: Auto‑label PR\n        uses: ./github-actions/nightly-pr-labeler\n        with:\n          github-token: ${{ secrets.GITHUB_TOKEN }}\n```\n\nThe action reads the PR title, decides which label(s) to apply, and calls the GitHub REST API to add them.\n\n## Inputs\n\n| Name | Description | Required | Default |\n|------|-------------|----------|---------|\n| `github-token` | Token with `issues:write` scope (usually `GITHUB_TOKEN`). | Yes | `${{ github.token }}` |\n\n## Extending\n\nEdit `src/labeler.py` and modify the `PATTERN_LABEL_MAP` dictionary to add more keyword‑to‑label mappings.\n\n## Testing\n\nRun the unit tests with:\n\n```bash\npython -m unittest discover -s tests\n```\n\n## License\n\nMIT
