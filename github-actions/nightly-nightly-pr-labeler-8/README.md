# Nightly PR Labeler\n\nA reusable GitHub Actions workflow that automatically adds labels to a pull request based on the types of files changed.\n- Docs changes → `documentation`\n- Test changes → `tests`\n- Code changes → `enhancement`\n\n## Usage\n\nCreate a workflow (e.g., `.github/workflows/auto-label.yml`) that calls the reusable workflow:\n\n```yaml\nname: Auto Label PR\non:\n  pull_request:\n    types: [opened, synchronize, reopened]\n\njobs:\n  label:\n    uses: your-org/ApocalypsAI/.github/workflows/nightly-pr-labeler.yml@main\n    with:\n      github-token: ${{ secrets.GITHUB_TOKEN }}\n```\n\n## Inputs\n\n| Name | Description | Required |\n|------|-------------|----------|\n| `github-token` | Token with `repo` scope to add labels. | Yes |\n\n## How it works\n\nThe workflow checks the list of changed files via the GitHub API, determines categories, and applies the appropriate labels using the `actions/github-script` action.\n\n## License\n\nMIT
