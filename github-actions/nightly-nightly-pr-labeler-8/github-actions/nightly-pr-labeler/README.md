Nightly PR Labeler\n\nA whimsical GitHub Action that automatically adds appropriate labels to a pull request based on its title. It looks for keywords such as bug, feature, docs and also adds a random emoji label for fun.\n\nInputs:\n- title (required): The pull request title.\n- github-token (required): Token with repo scope to add labels.\n\nOutputs:\n- labels (string): Comma‑separated list of labels that were added.\n\nUsage example (in a workflow):\n\njobs:\n  label:\n    runs-on: ubuntu-latest\n    steps:\n      - uses: ./github-actions/nightly-pr-labeler\n        with:\n          title: ${{ github.event.pull_request.title }}\n          github-token: ${{ secrets.GITHUB_TOKEN }}\n\nThe action will add the detected labels to the PR and expose them via the "labels" output.
