# Nightly PR Labeler\n\nUtility that automatically adds labels to a pull request based on its title.\n\n## How it works\n\nThe action reads the `pull_request.title` field from the GitHub event payload and applies a simple keyword‑to‑label mapping:\n\n- titles containing the word **bug** → `bug`\n- titles containing the word **feature** → `enhancement`\n- titles containing **doc** or **documentation** → `documentation`\n\nIf one or more keywords are found, the action emits the special `::add-labels::` command so that GitHub adds the labels to the PR.\n\n## Usage\n\nAdd the action to any workflow that runs on `pull_request` events:\n\n```yaml\nname: PR Labeler\n\non:\n  pull_request:\n    types: [opened, edited, reopened]\n\njobs:\n  label:\n    runs-on: ubuntu-latest\n    steps:\n      - name: Checkout repository\n        uses: actions/checkout@v3\n\n      - name: Run Nightly PR Labeler\n        uses: ./github-actions/nightly-pr-labeler\n```\n\nThe action is a **composite** action that runs a small Bash script, so no additional runtime dependencies are required beyond the default Ubuntu runner (including `jq`).\n\n## Testing\n\nThe repository includes a deterministic Bash test that mocks the GitHub event payload and verifies the correct label output. Run it locally with:\n\n```bash\ncd github-actions/nightly-pr-labeler\nchmod +x tests/test_labeler.sh\n./tests/test_labeler.sh\n```\n\n## License\n\nMIT
