Nightly Apocalypse Tip Action\n\nThis GitHub Action selects a post‑apocalyptic survival tip from a built‑in list and prints it. It can be used in workflows to add a whimsical tip to PR comments or logs.\n\nUsage:\n\nCreate a step that uses this action. Optionally provide the \"tip-index\" input to select a specific tip; otherwise a tip is chosen based on the GitHub run number modulo the number of tips.\n\nInputs:\n- tip-index (optional) – integer index of the tip to use.\n\nOutputs:\n- tip – the selected tip string.\n\nImplementation details: The action runs a Node script that selects the tip and echoes it. The script can be imported in other actions.
