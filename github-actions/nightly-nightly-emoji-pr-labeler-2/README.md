# Nightly Emoji PR Labeler\n\nA whimsical GitHub Action that scans the title of a pull request for specific emojis and automatically adds corresponding labels. Useful for quickly categorizing PRs without manual labeling.\n\n## How it works\n\n- 🌟 → `enhancement`\n- 🐛 → `bug`\n- 📚 → `documentation`\n- ⚡ → `performance`\n- 🎨 → `design`\n\nAdd any of these emojis to your PR title and the action will apply the matching label.\n\n## Usage\n\nCreate a workflow file:\n\n```yaml\nname: Emoji PR Labeler\non:\n  pull_request:\n    types: [opened, edited, reopened]\n\njobs:\n  label:\n    runs-on: ubuntu-latest\n    steps:\n      - uses: actions/checkout@v3\n      - name: Label PR by Emoji\n        uses: ./github-actions/nightly-emoji-pr-labeler\n        with:\n          github-token: ${{ secrets.GITHUB_TOKEN }}\n```\n\n## Inputs\n\n| Name | Description | Required |\n|------|-------------|----------|\n| github-token | Token with `repo` scope to add labels | Yes |\n\n## License\n\nMIT
