# Issue Quote Replier\n\nA tiny GitHub Action that adds a random post‑apocalyptic quote as a comment whenever a new issue is opened.  It brings a bit of drama to the triage process while keeping things light‑hearted.\n\n## How it works\n\n1. The action is triggered on the `issues` event with `opened` type.\n2. It reads a small built‑in list of quotes.\n3. It picks one (pseudo‑random) and posts it as a comment using the provided `GITHUB_TOKEN`.\n\n## Usage\n\nAdd the following step to your workflow (or call the reusable workflow directly):\n\n```yaml\nname: Issue Quote Replier\n\non:\n  issues:\n    types: [opened]\n\njobs:\n  quote-reply:\n    runs-on: ubuntu-latest\n    steps:\n      - uses: actions/checkout@v3\n      - name: Add quote comment\n        uses: ./github-actions/issue-quote-replier\n        with:\n          github-token: ${{ secrets.GITHUB_TOKEN }}\n```\n\n## Inputs\n\n| Name | Description | Required | Default |\n|------|-------------|----------|---------|\n| `github-token` | Token with `issues:write` permission (usually `GITHUB_TOKEN`). | Yes | N/A |\n\n## Development\n\nThe action is a simple Bash script located in `src/quote.sh`.  Tests are provided in `tests/test_quote.sh` and can be run with `bash tests/test_quote.sh`.\n\n## License\n\nMIT – see the LICENSE file in the repository root.
