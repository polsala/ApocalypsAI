# Nightly Apocalypse Quote Generator\n\nA GitHub Action that generates a random post‑apocalypse themed quote and makes it available as an output `quote`. Use it to sprinkle some dramatic flair into your CI runs.\n\n## Usage\n\n```yaml\nsteps:\n  - uses: ./github-actions/nightly-apocalypse-quote-generator\n    id: quote\n  - run: echo \"Quote: ${{ steps.quote.outputs.quote }}\"\n```\n\n## Inputs\n\nNone.\n\n## Outputs\n\n- `quote`: The selected quote.\n\n## License\n\nMIT
