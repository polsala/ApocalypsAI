# Nightly Survival Tip Commenter\n\nA whimsical GitHub Action that posts a random survival tip comment on every new pull request. The tip is chosen deterministically based on the PR number, so the same PR always gets the same tip.\n\n## Inputs\n\n- `tips-file` (optional): Path to a JSON file containing an array of custom tips. If omitted, a built‑in list of apocalypse‑themed tips is used.\n\n## Usage\n\n```yaml\nname: Survival Tips\n\non:\n  pull_request:\n    types: [opened]\n\njobs:\n  tip:\n    runs-on: ubuntu-latest\n    steps:\n      - uses: actions/checkout@v3\n      - id: tip\n        uses: ./path/to/nightly-survival-tip-commenter\n        with:\n          tips-file: .github/tips.json\n        env:\n          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}\n```\n\nThe action prints the selected tip to the log. In a real deployment you could extend it to post a comment via the GitHub API.\n\n## License\n\nMIT
