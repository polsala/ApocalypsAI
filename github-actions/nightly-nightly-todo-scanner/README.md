# Nightly TODO Scanner\n\nA GitHub Action that scans the repository for stray `TODO` comments and fails the workflow if any are found. Helps keep the codebase clean before merging.\n\n## Usage\n\n```yaml\nname: CI\non: [push, pull_request]\n\njobs:\n  todo-check:\n    runs-on: ubuntu-latest\n    steps:\n      - uses: actions/checkout@v3\n      - name: Run TODO scanner\n        uses: ./\n```\n\nThe action will exit with a non‑zero status if any `TODO` comments are detected, causing the job to fail.\n\n## How it works\n\nThe action runs a small Bash script that recursively searches all tracked files for the string `TODO`. If matches are found, it prints the file paths and aborts the workflow.\n\n## Customization\n\n- Adjust the `IGNORE_PATHS` variable in `src/scan_todo.sh` to exclude directories (e.g., `vendor/`, `node_modules/`).
