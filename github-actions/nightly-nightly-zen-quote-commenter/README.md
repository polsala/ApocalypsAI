# Nightly Zen Quote Commenter\n\nA whimsical yet useful GitHub Action that leaves a random zen quote as a comment on every pull request. Perfect for sprinkling a bit of wisdom (or silliness) into the review process.\n\n## Features\n\n- Picks a quote from a curated list of zen sayings.\n- Posts the comment using the built‑in `actions/github-script` action (no custom runtime needed).\n- Fully reusable – add it to any workflow with a single step.\n\n## Usage\n\nAdd the action to your workflow (e.g., `.github/workflows/zen-comment.yml`):\n\n```yaml\nname: Zen Commenter\n\non:\n  pull_request:\n    types: [opened, reopened, synchronize]\n\njobs:\n  zen-comment:\n    runs-on: ubuntu-latest\n    steps:\n      - name: Add Zen Quote\n        uses: ./github-actions/nightly-zen-quote-commenter\n        with:\n          github-token: ${{ secrets.GITHUB_TOKEN }}\n```\n\nThe action will automatically comment on the PR with a random quote like:\n\n> 🧘 *"Simplicity is the ultimate sophistication."*\n\n## Customization\n\nIf you want to provide your own list of quotes, fork the action and edit the `quotes` array in `action.yml`.\n\n## License\n\nMIT – see the repository LICENSE file.\n
