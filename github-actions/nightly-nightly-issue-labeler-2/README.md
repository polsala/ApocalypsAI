# Nightly Issue Labeler\n\nA tiny, reusable GitHub Actions workflow that watches for newly opened or edited issues and applies labels based on a user‑provided `labeler.yml` configuration.\n\n## How to use\n\n1. **Add the workflow** to your repository under `.github/workflows/issue-labeler.yml` (or any path you prefer).\n2. **Create a label configuration** file at `.github/labeler.yml`. The file follows the format used by the official `actions/labeler` action – map label names to arrays of keyword patterns. Example:\n\n```yaml\nbug:\n  - "bug"\n  - "error"\nfeature:\n  - "feature request"\n  - "enhancement"\n```\n\n3. **Commit both files**. The workflow will automatically run on every new or edited issue and apply the matching labels.\n\n## What the workflow does\n\n- Triggers on `issues` events of type `opened` and `edited`.\n- Checks out the repository (required by the labeler action).\n- Executes `actions/labeler@v3` with the repository token and the path to your label configuration.\n\n## Customisation\n\nIf you need a different label configuration path, edit the `configuration-path` input in the workflow file.\n\n## License\n\nThis utility is released under the same MIT license as the rest of the ApocalypsAI repository.\n
