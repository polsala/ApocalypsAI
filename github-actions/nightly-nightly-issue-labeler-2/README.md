# Nightly Issue Labeler\n\nA whimsical GitHub Action that automatically adds post‑apocalypse themed labels to newly opened issues based on keyword detection.\n\n## Usage\n\n```yaml\nname: Auto label issues\non:\n  issues:\n    types: [opened]\n\njobs:\n  label:\n    runs-on: ubuntu-latest\n    steps:\n      - uses: actions/checkout@v3\n      - name: Run Issue Labeler\n        uses: ./ # assumes the action is in the repository root\n        env:\n          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}\n```\n\n## How it works\n\nThe action reads the issue title and body, looks for keywords such as `radiation`, `mutant`, `zombie`, `survivor`, or `bug`. If a keyword is found, the corresponding label is added. If no keyword matches, a generic `post‑apocalypse` label is applied.\n\n## Inputs\n\nNone.\n\n## Outputs\n\nThe action prints the list of labels it intends to add.\n\n## License\n\nMIT
