# Nightly Morale Boost Action\n\nA whimsical GitHub Action that generates a daily morale‑boosting message for your CI runs. It selects a quote based on the day of the week (or a provided seed) and exposes it as the `morale_message` output.\n\n## Usage\n\n```yaml\njobs:\n  morale:\n    runs-on: ubuntu-latest\n    steps:\n      - uses: ./github-actions/nightly-morale-boost-action\n        id: boost\n        with:\n          seed: ${{ github.run_number }}\n      - run: echo "Message: ${{ steps.boost.outputs.morale_message }}"\n```\n\n## Inputs\n\n- `seed` (optional): An integer used to deterministically pick a quote. If omitted, the current day of week is used.\n\n## Outputs\n\n- `morale_message`: The selected morale‑boosting quote.\n\n## License\n\nMIT
