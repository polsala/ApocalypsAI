# Nightly PR Labeler Action\n\nA tiny GitHub Action that determines whether a file matches a glob pattern and outputs a label. Useful for automatically labeling PRs based on changed file types.\n\n## Inputs\n\n- `filename` – The name of the file to test.\n- `pattern` – Glob pattern (e.g., `*.md`).\n- `label` – Label to output when the pattern matches.\n\n## Outputs\n\n- `label` – The label if the pattern matches, otherwise empty.\n\n## Example usage\n\n```yaml\nuses: ./github-actions/nightly-pr-labeler\nwith:\n  filename: ${{{{ github.event.pull_request.title }}}}\n  pattern: "*.md"\n  label: documentation\n```\n
