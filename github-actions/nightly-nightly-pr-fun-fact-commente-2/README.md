# Nightly PR Fun Fact Commenter\n\n## Overview\n\n`nightly-pr-fun-fact-commenter` is a tiny GitHub Action that adds a splash of whimsy to your pull‑request workflow. Whenever a PR is opened, the action posts a random fun fact as a comment, giving reviewers a light‑hearted icebreaker before they dive into the code.\n\n## Features\n\n- **Zero configuration** – just add the action to a workflow and it works.\n- **Deterministic list** – fun facts are stored locally, so the action works offline and is fully testable.\n- **Lightweight** – runs on the built‑in `node12` runtime, no extra dependencies required.\n\n## Usage\n\nAdd the following step to any workflow that triggers on `pull_request` events (typically on `opened`).\n\n```yaml\nname: PR Fun Fact\n\non:\n  pull_request:\n    types: [opened]\n\njobs:\n  fun-fact:\n    runs-on: ubuntu-latest\n    steps:\n      - name: Post a fun fact\n        uses: ./github-actions/nightly-pr-fun-fact-commenter\n        env:\n          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}\n```\n\nThe action reads the `GITHUB_TOKEN` secret automatically (provided by GitHub Actions) and posts a comment like:\n\n> 🤖 **Fun Fact:** Bananas are berries.\n\n## Implementation Details\n\nThe action is a simple Node.js script (`src/index.js`) that:\n\n1. Checks that the event is a `pull_request` with the `opened` action.\n2. Picks a random fact from a hard‑coded array.\n3. Uses the Octokit REST client (available via `@actions/github`) to create a comment on the PR.\n\n## Testing\n\nThe repository includes a Jest test suite under `tests/`. The tests mock the random selection to ensure deterministic results and verify that the exported `getFunFact` function returns one of the expected strings. Run tests with:\n\n```bash\nnpm install\nnpm test\n```\n\n## License\n\nMIT – see the LICENSE file in the repository root.\n
