# PR Fun Fact Action\n\nThis GitHub Action posts a random fun fact as a notice comment on every pull request. It adds a touch of whimsy to the review process while demonstrating how to write a simple JavaScript‑based action.\n\n## Usage\n\nAdd the following step to your workflow (e.g., `.github/workflows/pr-fun-fact.yml`):\n\n```yaml\nname: PR Fun Fact\n\non:\n  pull_request:\n    types: [opened, reopened]\n\njobs:\n  fun-fact:\n    runs-on: ubuntu-latest\n    steps:\n      - name: Checkout repository\n        uses: actions/checkout@v3\n\n      - name: Post a fun fact\n        uses: ./nightly-pr-fun-fact\n```\n\nThe action does not require any inputs. It simply prints a notice with a random fact, which GitHub renders as a comment on the PR.\n\n## Implementation Details\n\n- **src/fun_fact.js** – contains a small list of facts and a `getFact()` function that selects one at random.\n- **src/main.js** – calls `getFact()` and outputs the result using the GitHub Actions logging command `::notice::`.\n- **tests/** – includes a deterministic unit test that forces `Math.random` to return `0` and verifies the first fact is selected.\n\n## License\n\nMIT – see the repository LICENSE file.
