Nightly Emoji Issue Labeler\n\nThis GitHub Action adds a label containing a chosen emoji to the issue or pull request that triggers the workflow. It helps highlight important items in a whimsical way during the apocalypse.\n\nInputs:\n- emoji (required): The emoji character to include in the label.\n- label (required): The base label name without emoji.\n\nOutputs: none.\n\nExample usage:\nuses: your-org/nightly-emoji-issue-labeler@v1\nwith:\n  emoji: \"⚡\"\n  label: \"high-priority\"\n\nThe action will create or update a label named \"high-priority ⚡\" and apply it to the current issue or PR.
