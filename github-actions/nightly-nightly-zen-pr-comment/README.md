# Nightly Zen PR Comment\n\nA whimsical GitHub Action that posts a random Zen‑inspired quote as a comment on a pull request, bringing a moment of calm to code reviews.\n\n## Usage\n\n```yaml\nname: Zen Comment\non:\n  pull_request:\n    types: [opened, reopened]\n\njobs:\n  zen:\n    runs-on: ubuntu-latest\n    steps:\n      - uses: ./.github/actions/nightly-zen-pr-comment\n        with:\n          github_token: ${{ secrets.GITHUB_TOKEN }}\n          pr_number: ${{ github.event.pull_request.number }}\n```\n\nThe action selects a quote from a built‑in list and posts it via the GitHub API.\n\n## Inputs\n\n- `github_token` (required): Token with `repo` scope.\n- `pr_number` (required): Number of the pull request to comment on.\n\n## Implementation\n\nThe action is a composite action that runs a small Bash script (`src/post_zen_comment.sh`). The script picks a random quote and uses `curl` to post the comment.\n
