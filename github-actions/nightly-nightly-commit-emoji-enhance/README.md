Nightly Commit Emoji Enhancer\n\nThis GitHub Action adds a whimsical emoji that matches the conventional commit type. It can be used in workflows to prepend an emoji to generated commit messages, making the history more colorful.\n\nInputs\n------\n- **type** (required): The conventional commit type. Accepted values are `feat`, `fix`, `docs`, `chore`, `refactor`, `test`, `style`, `perf`, `build`, `ci`, `revert`. Any other value will result in a question‑mark emoji.\n\nOutputs\n-------\n- **emoji**: The emoji string that corresponds to the provided type.\n\nExample usage in a workflow\n--------------------------------\n```yaml\nname: Add Emoji to Commit Message\n\non:\n  push:\n    branches: [ main ]\n\njobs:\n  add-emoji:\n    runs-on: ubuntu-latest\n    steps:\n      - uses: actions/checkout@v3\n      - id: emoji\n        uses: ./nightly-commit-emoji-enhancer\n        with:\n          type: feat\n      - name: Create commit with emoji\n        run: |\n          git config user.name "github-actions"\n          git config user.email "github-actions@github.com"\n          echo "Some changes" >> file.txt\n          git add file.txt\n          git commit -m "${{ steps.emoji.outputs.emoji }} Add new feature"\n          git push\n```\n\nThe action is lightweight, written in Bash, and requires no external dependencies.
