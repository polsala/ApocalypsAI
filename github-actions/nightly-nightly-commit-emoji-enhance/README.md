# Commit Emoji Enhancer\n\nA GitHub Action that appends a random emoji to a commit message, making CI logs more lively.\n\n## Inputs\n\n- `message` (required): The original commit message.\n\n## Outputs\n\n- `enhanced_message`: The commit message with a random emoji appended.\n\n## Example usage\n\n```yaml\n- uses: ./nightly-commit-emoji-enhancer\n  with:\n    message: "Fix typo in README"\n```\n\nThe action will output something like `Fix typo in README 🚀`.\n
