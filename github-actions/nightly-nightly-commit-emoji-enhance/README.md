# Nightly Commit Emoji Enhancer\n\n## Overview\n\n`nightly-commit-emoji-enhancer` is a tiny GitHub Action that takes a commit message and appends a playful emoji.  It can be used in any workflow to make log output a little brighter, or just to celebrate a successful build.\n\n## Inputs\n\n| Name | Description | Required | Default |\n|------|-------------|----------|---------|\n| `commit_message` | The original commit message you want to enhance. | Yes | – |\n| `emoji` | An optional emoji to use. If omitted, the action picks a default (or random) emoji. | No | – |\n\n## Outputs\n\n| Name | Description |\n|------|-------------|\n| `enhanced_message` | The original commit message with the chosen emoji appended. |\n\n## Example usage\n\n```yaml\nname: Demo Emoji Enhancer\n\non:\n  push:\n    branches: [ main ]\n\njobs:\n  add-emoji:\n    runs-on: ubuntu-latest\n    steps:\n      - name: Checkout\n        uses: actions/checkout@v3\n\n      - name: Enhance commit message\n        id: enhancer\n        uses: ./\n        with:\n          commit_message: "Deploy to production"\n\n      - name: Show result\n        run: echo "Enhanced: ${{ steps.enhancer.outputs.enhanced_message }}"\n```\n\n## How it works\n\nThe action is implemented as a **composite** action that runs a small Bash script (`src/enhance.sh`).  The script either uses the emoji you provide or falls back to a deterministic default (🚀) so that tests are repeatable.\n\n## Testing\n\nThe utility ships with a Python `unittest` suite that invokes the Bash script directly, ensuring the output is exactly as expected.  Run the tests with:\n\n```bash\npython -m unittest discover -s tests\n```\n\n---\n\nEnjoy sprinkling a little extra joy onto your commit messages!\n
