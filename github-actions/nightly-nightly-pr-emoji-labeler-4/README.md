# PR Emoji Labeler\n\nA whimsical GitHub Action that adds an emoji label to a pull request based on the length of its title. The longer the title, the more exotic the emoji!\n\n## Usage\n\n```yaml\nuses: your-org/nightly-pr-emoji-labeler@v1\nwith:\n  title: ${{ github.event.pull_request.title }}\n```\n\nThe action outputs `emoji` which you can use in subsequent steps.\n\n## How it works\n\nThe action maps the title length modulo a small emoji list and returns the selected emoji as an output.
