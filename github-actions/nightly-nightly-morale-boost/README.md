# Nightly Morale Boost Action\n\nGenerates a deterministic morale‑boosting message for a given date, suitable for post‑apocalyptic themed repositories.\n\n## Usage\n\n```yaml\nuses: your-org/ApocalypsAI/github-actions/nightly-morale-boost@v1\nwith:\n  date: '2023-12-31' # optional, defaults to today\n```\n\nThe action outputs `morale` which can be used in subsequent steps.\n\n## Inputs\n\n- `date` – Optional ISO date string (YYYY‑MM‑DD). If omitted, the current date is used.\n\n## Outputs\n\n- `morale` – The generated morale‑boosting message.\n\n## How it works\n\nThe action hashes the provided date to select a message from a curated list, ensuring the same date always yields the same message.
