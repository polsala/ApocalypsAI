# Nightly Morale Boost Action\n\nThis GitHub Action posts a whimsical morale‑boosting comment to the issue or pull request that triggered the workflow. It selects a phrase from a curated list of post‑apocalypse encouragements. The action is useful for keeping contributors' spirits high during long runs.\n\n## Inputs\n\n- `seed` (optional): integer to make the selection deterministic, useful for testing.\n- `custom_message` (optional): override the random phrase with a custom message.\n\n## Usage\n\n```yaml\nuses: your-repo/github-actions/nightly-morale-boost@v1\nwith:\n  seed: 42\n```\n\nThe action runs a small Bash script and posts the comment via the GitHub API (requires `GITHUB_TOKEN`).
