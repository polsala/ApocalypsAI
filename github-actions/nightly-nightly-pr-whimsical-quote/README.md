# Nightly PR Whimsical Quote\n\nA reusable GitHub Action that posts a random whimsical quote as a comment on a pull request. Perfect for adding a touch of inspiration (or chaos) to code reviews.\n\n## Usage\n\n```yaml\njobs:\n  whimsical-quote:\n    runs-on: ubuntu-latest\n    steps:\n      - uses: ./.github/actions/nightly-pr-whimsical-quote\n        with:\n          github-token: ${{ secrets.GITHUB_TOKEN }}\n```\n\n## Inputs\n\n- `github-token` (required): Token with repo scope to post comment.\n\n## How it works\n\nThe action is a composite action that runs `actions/github-script` with an inline JavaScript snippet selecting a random quote from a built‑in list and posting it to the PR.\n
