# Nightly PR Title Length Checker\n\nA tiny GitHub Action that inspects the title of a pull request and, if it exceeds a configurable length, adds the label `title-too-long` to the PR.\n\n## Features\n\n- Configurable maximum title length (default: 72 characters)\n- Optional dry‑run mode for testing without touching the GitHub API\n- Works with any repository that provides a `GITHUB_TOKEN` secret\n\n## Usage\n\nAdd the following step to your workflow (e.g. `.github/workflows/pr-title-check.yml`):\n\n```yaml\nname: PR Title Length Check\n\non:\n  pull_request:\n    types: [opened, edited, synchronize]\n\njobs:\n  title-check:\n    runs-on: ubuntu-latest\n    steps:\n      - name: Checkout repository\n        uses: actions/checkout@v4\n\n      - name: Run title length checker\n        uses: ./github-actions/nightly-pr-title-length-checker\n        with:\n          max-length: 72\n          dry-run: false\n        env:\n          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}\n```\n\n## Inputs\n\n| Name | Description | Default |\n|------|-------------|---------|\n| `max-length` | Maximum allowed characters for the PR title. | `72` |\n| `dry-run` | If `true`, the action only prints what it would do without calling the GitHub API. | `false` |\n\n## How it works\n\nThe action reads the `GITHUB_EVENT_PATH` environment variable (automatically provided by GitHub Actions) to obtain the pull‑request payload. It then checks the `title` field. If the title length exceeds `max-length`, the action either prints a message (dry‑run) or sends a `POST` request to the GitHub REST API to add the `title-too-long` label to the PR.\n\n## License\n\nMIT
