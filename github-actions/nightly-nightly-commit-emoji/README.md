# Nightly Commit Emoji\n\nA whimsical GitHub Action that appends an appropriate emoji to commit messages based on their content. Helps teams add a splash of personality to their history.\n\n## Usage\n\n```yaml\nuses: ./github-actions/nightly-commit-emoji\nwith:\n  # No inputs needed\n```\n\nThe action reads the commit message from STDIN and outputs the enriched message to STDOUT. It can be used in a workflow step like:\n\n```yaml\n- name: Get latest commit message\n  id: msg\n  run: echo "::set-output name=msg::$(git log -1 --pretty=%B)"\n- name: Enrich commit message\n  id: enriched\n  run: echo "${{ steps.msg.outputs.msg }}" | ./src/enrich.sh\n```\n\n## Emoji mapping\n\n- `fix` → 🐛\n- `add` → ✨\n- `docs` → 📚\n- otherwise → 🎉\n\n## License\n\nMIT
