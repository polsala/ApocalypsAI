# Nightly Cryptic Commit Signer\n\nA whimsical GitHub Action that generates a cryptic phrase based on a commit message. Useful for adding mysterious flair to PR comments.\n\n## Usage\n\n```yaml\nuses: polsala/ApocalypsAI/github-actions/nightly-cryptic-commit-signer@v1\nwith:\n  commit-message: ${{{{ github.event.head_commit.message }}}}\n```\n\nThe action outputs `cryptic-phrase` which can be used in subsequent steps.\n\n## Inputs\n\n- `commit-message` – The commit message to base the phrase on.\n\n## Outputs\n\n- `cryptic-phrase` – Generated cryptic phrase.\n\n## How it works\n\nThe action hashes the commit message and selects a phrase from a predefined list, ensuring deterministic output.
