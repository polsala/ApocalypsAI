Nightly Fortune Cookie Action\n\nThis GitHub Action produces a short, whimsical fortune message and exposes it as an output named `fortune`.\n\nThe action is deterministic: you can provide an optional numeric `seed` input to select a specific fortune from the built‑in list. If no seed is supplied, the default seed is 0, which always returns the first fortune.\n\nUsage\n-----\nAdd the action to a workflow step. Example:\n\n```yaml\nsteps:\n  - name: Generate Fortune\n    uses: ./github-actions/nightly-fortune-cookie\n    id: fortune\n    with:\n      seed: 3  # optional, any integer\n\n  - name: Show Fortune\n    run: echo "Your fortune: ${{ steps.fortune.outputs.fortune }}"\n```\n\nInputs\n------\n- `seed` (optional): Integer used to pick a fortune. Defaults to `0`.\n\nOutputs\n-------\n- `fortune`: The selected fortune string.\n\nThe action runs on any runner that supports Node.js (uses the `node12` runtime). No external network calls are made; all fortunes are baked into the source code.
