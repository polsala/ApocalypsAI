# Nightly Motivational Quote Action\n\nA tiny GitHub Action that generates a deterministic motivational quote based on the provided `name` input and outputs it as `compliment`. Useful for adding a friendly note to issues or PRs.\n\n## Usage\n\n```yaml\nuses: your-org/nightly-motivational-quote-action@v1\nwith:\n  name: \"Alice\"\n```\n\nThe action sets an output `compliment` that can be used in subsequent steps.\n\n## How it works\n\nThe action runs a Node.js script that selects a quote from a built‑in list using a simple hash of the `name` input, ensuring the same name always gets the same quote.\n\n## License\n\nMIT
