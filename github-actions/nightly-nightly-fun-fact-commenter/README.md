# Nightly Fun Fact Commenter\n\nA whimsical GitHub Action that automatically posts a random fun fact as a comment on every new pull request. Great for lightening the mood during code reviews!\n\n## Features\n\n- Picks a random fact from a built‑in list or a custom file.\n- Posts the fact as a comment on the PR.\n- Configurable via action inputs.\n- No external network calls – all facts are bundled or supplied by the repository.\n\n## Usage\n\nCreate a workflow file (e.g., `.github/workflows/fun-fact.yml`) and add the following step to your PR trigger:\n\n```yaml\nname: Fun Fact on PR\n\non:\n  pull_request:\n    types: [opened]\n\njobs:\n  fun-fact:\n    runs-on: ubuntu-latest\n    steps:\n      - uses: actions/checkout@v3\n      - name: Add fun fact\n        uses: ./nightly-fun-fact-commenter\n        with:\n          repo-token: ${{ secrets.GITHUB_TOKEN }}\n          # Optional: path to a custom facts file in the repo\n          # facts-file: ".github/fun-facts.txt"\n```\n\n## Inputs\n\n| Name | Description | Required | Default |\n|------|-------------|----------|---------|\n| `repo-token` | GitHub token with `pull-requests: write` permission. Usually `secrets.GITHUB_TOKEN`. | Yes | – |\n| `facts-file` | Relative path to a plain‑text file containing one fact per line. If omitted, a built‑in list is used. | No | – |\n\n## Outputs\n\n| Name | Description |\n|------|-------------|\n| `fact` | The fact that was posted. |\n\n## License\n\nMIT – feel free to adapt and share!\n
