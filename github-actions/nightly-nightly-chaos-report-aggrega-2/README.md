# nightly-chaos-report-aggregator

A GitHub Action to collect and summarize chaos engineering reports generated by Ansible playbooks into a single cohesive markdown document.

## Features

- Scans a specified directory for chaos report files (`.md`)
- Merges them into one unified report
- Uploads the final report as a build artifact

## Usage

In your workflow YAML:

```yaml
- name: Aggregate Chaos Reports
  uses: polsala/ApocalypsAI/utils/nightly-chaos-report-aggregator@main
  with:
    reports_dir: ./chaos-reports
    output_file: ./final_chaos_report.md
```

### Inputs

| Input         | Description                          | Default              |
|---------------|--------------------------------------|----------------------|
| `reports_dir` | Directory containing markdown reports| `./chaos-reports`    |
| `output_file` | Path to write the aggregated report  | `./chaos_summary.md` |

## Example Output

The action produces a merged markdown file combining all input reports, preserving headers and content structure.
