# Nightly PR Emoji Labeler\n\nA GitHub Action that automatically adds an emoji label to a pull request based on its title. The label is whimsical and helps surface fun vibes in the repo.\n\n## Inputs\n\n- `github-token` (required): Token with repo scope.\n- `title` (optional): Pull request title. If omitted, the action reads the title from the GitHub context.\n\n## How it works\n\nThe action examines the title and selects an emoji label:\n\n- titles containing "fix" → 🛠️ `fix-it`\n- titles containing "feat" → ✨ `new-feature`\n- titles containing "docs" → 📚 `documentation`\n- otherwise → 🎲 `random-emoji`\n\nThe selected label is created (if missing) and attached to the PR.\n\n## Example workflow\n\n```yaml\nname: PR Emoji Labeler\non:\n  pull_request:\n    types: [opened, edited]\n\njobs:\n  label:\n    runs-on: ubuntu-latest\n    steps:\n      - uses: actions/checkout@v3\n      - uses: ./nightly-pr-emoji-labeler\n        with:\n          github-token: ${{ secrets.GITHUB_TOKEN }}\n```\n\n## License\n\nMIT
