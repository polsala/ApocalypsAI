# nightly-pr-emoji-labeler\n\n## Overview\n\n`nightly-pr-emoji-labeler` is a lightweight GitHub Action that reads the title of a pull request, extracts any emojis present, and maps them to fun, community‑friendly labels.  It then prints the labels that *would* be added (real implementation can use the GitHub API to apply them).\n\n## Why?\n\n- Adds a splash of personality to PR workflows.\n- Helps maintainers quickly see the intent of a PR (bug, feature, documentation, etc.) based on emojis.\n- Fully offline‑testable – the action only needs the `GITHUB_EVENT_PATH` JSON payload.\n\n## Emoji → Label Mapping\n\n| Emoji | Suggested Label | Description |\n|-------|----------------|-------------|\n| \uD83D\uDC1B (🐛) | `bug` | Indicates a bug fix. |\n| \uD83D\uDCA1 (💡) | `enhancement` | New feature or improvement. |\n| \uD83D\uDCDD (📝) | `documentation` | Docs or comment updates. |\n| \uD83C\uDF89 (🎉) | `celebration` | Major release or milestone. |\n| \uD83D\uDE80 (🚀) | `rocket` | Performance or deployment related. |\n| \u2728 (✨) | `sparkles` | Minor polish or refactor. |\n\n## Usage\n\nAdd the following step to your workflow (e.g., `.github/workflows/label-pr.yml`):\n\n```yaml\nname: PR Emoji Labeller\n\non:\n  pull_request:\n    types: [opened, edited]\n\njobs:\n  label:\n    runs-on: ubuntu-latest\n    steps:\n      - uses: actions/checkout@v3\n      - name: Run Emoji Labeler\n        uses: ./github-actions/nightly-pr-emoji-labeler\n        env:\n          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}\n```\n\nThe action will output something like:\n\n```
Would add labels: bug, documentation\n```\n\n## Development\n\nThe action is implemented in JavaScript (Node.js) and requires no external dependencies beyond the standard library.\n\n### Running Tests\n\n```bash\ncd github-actions/nightly-pr-emoji-labeler\nchmod +x tests/test_labeler.sh\n./tests/test_labeler.sh\n```\n\nThe test script creates a mock `event.json` payload, runs the action, and verifies the expected labels are printed.\n\n## License\n\nMIT
