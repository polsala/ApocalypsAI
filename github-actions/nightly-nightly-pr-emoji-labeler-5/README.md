Nightly PR Emoji Labeler\n\nThis GitHub Action scans the title of a pull request for emojis and suggests label names based on a predefined mapping. It outputs a comma-separated list of labels via the `labels` output, which can be consumed by a subsequent step to actually apply the labels.\n\nSupported emojis and their label equivalents:\n- 🌟 => feature\n- 🐛 => bug\n- 🧹 => refactor\n- 📚 => documentation\n- 🚀 => enhancement\n\nIf no known emoji is found, the action outputs an empty string.\n\nUsage example (YAML):\nsteps:\n- uses: ./nightly-pr-emoji-labeler\n  id: emoji\n- name: Apply suggested labels\n  if: steps.emoji.outputs.labels != ''\n  uses: actions-ecosystem/action-add-labels@v1\n  with:\n    labels: ${{ steps.emoji.outputs.labels }}
