# PR Emoji Labeler\n\nA lightweight GitHub Action that adds a random emoji label to every pull request.\n\n## Features\n\n- Picks a random emoji from a configurable list (default: 🚀,✨,🔥,💡,🎉)\n- Uses the provided `GITHUB_TOKEN` to call the GitHub API\n- Outputs the chosen emoji as an action output\n\n## Usage\n\nCreate a workflow file (e.g. `.github/workflows/emoji-label.yml`) with the following content:\n\n```yaml\nname: PR Emoji Labeler\n\non:\n  pull_request:\n    types: [opened, reopened]\n\njobs:\n  add-emoji-label:\n    runs-on: ubuntu-latest\n    steps:\n      - name: Add Emoji Label\n        uses: ./nightly-pr-emoji-labeler\n        with:\n          github_token: ${{ secrets.GITHUB_TOKEN }}\n          # optional custom list\n          # emoji_labels: "🦄,🌟,🍕"\n```\n\n## Inputs\n\n| Name | Description | Required | Default |\n|------|-------------|----------|---------|\n| `github_token` | Token with repo scope to call the API | Yes | – |\n| `emoji_labels` | Comma‑separated list of emojis to choose from | No | `🚀,✨,🔥,💡,🎉` |\n\n## Outputs\n\n| Name | Description |\n|------|-------------|\n| `emoji` | The emoji that was added as a label |\n\n## License\n\nMIT – feel free to remix and spread the joy!\n
