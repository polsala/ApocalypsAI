# Nightly PR Emoji Labeler\n\nA tiny GitHub Action that scans the title of a pull request for certain keywords and adds a matching emoji label.\n\n## Features\n\n- Detects **bug**, **feature**, and **docs** keywords in the PR title.\n- Creates the label in the repository if it does not already exist.\n- Adds the label to the PR, giving a quick visual cue.\n\n## Usage\n\n```yaml\nname: PR Emoji Labeler\non:\n  pull_request:\n    types: [opened, edited, reopened]\n\njobs:\n  label:\n    runs-on: ubuntu-latest\n    steps:\n      - uses: actions/checkout@v3\n      - uses: ./nightly-pr-emoji-labeler\n        with:\n          github-token: ${{ secrets.GITHUB_TOKEN }}\n```\n\n## Inputs\n\n| Name | Description | Required |\n|------|-------------|----------|\n| `github-token` | Token with repo scope (usually `secrets.GITHUB_TOKEN`). | Yes |\n\n## How it works\n\nThe action looks for the following keywords (case‑insensitive) in the PR title:\n\n- `bug` → label **bug** with emoji 🐞\n- `feature` → label **feature** with emoji ✨\n- `doc` or `docs` → label **docs** with emoji 📚\n\nIf none of the keywords are found, the action does nothing.\n\n## License\n\nMIT
