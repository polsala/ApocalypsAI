# Nightly PR Title Emoji Checker\n\nA tiny GitHub Action that ensures every pull request title begins with an emoji.\nIf the title does not start with an emoji, the action fails the workflow, nudging contributors to add a little flair.\n\n## Usage\n\nAdd the action to your workflow (e.g., `.github/workflows/pr-emoji.yml`):\n\n```yaml\nname: PR Title Emoji Lint\n\non:\n  pull_request:\n    types: [opened, edited, synchronize]\n\njobs:\n  check-title:\n    runs-on: ubuntu-latest\n    steps:\n      - name: Checkout repository\n        uses: actions/checkout@v3\n\n      - name: Validate PR title emoji\n        uses: ./nightly-pr-title-emoji-checker\n        with:\n          pr_title: "${{ github.event.pull_request.title }}"\n```\n\n## Inputs\n\n| Name | Description | Required |\n|------|-------------|----------|\n| `pr_title` | The title of the pull request to validate. | Yes |\n\n## Behavior\n\n- If `pr_title` starts with any Unicode emoji, the action succeeds and prints a friendly message.\n- Otherwise, the action fails (`exit code 1`) and prints an error explaining the rule.\n\n## Development\n\nThe action is implemented in plain JavaScript with no external dependencies, making it fast and easy to audit.\nRun the tests locally with:\n\n```bash\nnode tests/test_check.js\n```\n\n## License\n\nMIT
