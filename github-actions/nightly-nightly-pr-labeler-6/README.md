# Nightly PR Labeler\n\nA whimsical GitHub Action that automatically adds descriptive labels to pull requests based on their title keywords and sprinkles a random emoji label for fun.\n\n## Features\n\n- Detects keywords: `bug`, `feature`, `docs`, `refactor`, `test`.\n- Adds corresponding labels (`bug`, `enhancement`, `documentation`, `refactor`, `tests`).\n- Adds one random emoji label from a curated list.\n- Works on pull request events (`opened`, `edited`, `reopened`).\n\n## Usage\n\n```yaml\nname: PR Labeler\non:\n  pull_request:\n    types: [opened, edited, reopened]\n\njobs:\n  label:\n    runs-on: ubuntu-latest\n    steps:\n      - uses: actions/checkout@v3\n      - uses: ./path/to/nightly-pr-labeler\n        with:\n          github-token: ${{ secrets.GITHUB_TOKEN }}\n```\n\n## Inputs\n\n| Name | Description | Required | Default |\n|------|-------------|----------|---------|\n| github-token | Token with repo scope to add labels | true | N/A |\n\n## License\n\nMIT\n
