# Nightly TODO Guardian\n\n## Overview\n\n`nightly-todo-guardian` is a tiny GitHub Action that walks through every file in the repository (excluding common ignored directories) and looks for lingering `TODO` comments. If any are found, the action fails the job and prints a whimsical admonition, nudging developers to clean up their code before it becomes a zombie apocalypse.\n\n## Usage\n\nAdd the action to any workflow after checking out the code. No inputs or outputs are required.\n\n```yaml\nname: CI\n\non:\n  push:\n    branches: [ main ]\n  pull_request:\n    branches: [ main ]\n\njobs:\n  lint:\n    runs-on: ubuntu-latest\n    steps:\n      - uses: actions/checkout@v3\n      - name: Check for TODOs\n        uses: ./utils/github-actions/nightly-todo-guardian\n```\n\n## What It Does\n\n1. Recursively scans the repository root (the `GITHUB_WORKSPACE`).\n2. Skips `.git`, `node_modules`, and `.github` directories.\n3. Looks for the case‑insensitive pattern `TODO` (with optional colon).\n4. If any matches are found, the action prints a random whimsical message and exits with status `1`.\n5. If no matches are found, it prints a happy ✅ message and exits with status `0`.\n\n## No Dependencies\n\nThe action is pure JavaScript and runs on the built‑in `node12` runtime provided by GitHub Actions. No external npm packages are required.\n\n## Testing\n\nA deterministic offline test suite lives in `tests/run.sh`. It creates a temporary workspace, runs the action with and without TODOs, and asserts the correct exit codes.\n\n## License\n\nMIT – see the repository root for details.\n
