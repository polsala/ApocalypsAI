# Icebreaker Issue Comment Action\n\nThis GitHub Action posts a random icebreaker comment on every newly opened issue to encourage friendly conversation.\n\n## Usage\n\n```yaml\nname: Icebreaker on Issue Open\non:\n  issues:\n    types: [opened]\n\njobs:\n  icebreaker:\n    runs-on: ubuntu-latest\n    steps:\n      - uses: ./  # assuming the action is checked out\n        with:\n          github_token: ${{ secrets.GITHUB_TOKEN }}\n```\n\n## How it works\n\nThe action selects a random phrase from a built‑in list and creates a comment on the issue via the GitHub REST API.\n\n## Inputs\n\n| Name | Description | Required |\n|------|-------------|----------|\n| `github_token` | Token with `repo` scope (usually `${{ secrets.GITHUB_TOKEN }}`) | Yes |
