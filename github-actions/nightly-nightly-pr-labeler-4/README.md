# Nightly PR Labeler\n\nA tiny GitHub Action that scans the title of a pull request and adds one or more labels based on a user‑provided keyword‑to‑label map.\n\n## Features\n\n- **Zero‑runtime dependencies** – pure Node.js (no external packages).\n- **Configurable mapping** – supply a JSON object where keys are keywords (case‑insensitive) and values are the labels to apply.\n- **Safe defaults** – if no keyword matches, the action does nothing.\n\n## Inputs\n\n| Name | Description | Required | Default |\n|------|-------------|----------|---------|\n| `github-token` | A token with `pull_request` write permissions (usually `{{ secrets.GITHUB_TOKEN }}`). | true | – |\n| `label-mapping` | JSON string mapping keywords to label names. Example: `{ "bug": "bug", "feat": "feature" }`. | true | – |\n\n## Example workflow\n\n```yaml\nname: Auto‑label PRs\n\non:\n  pull_request:\n    types: [opened, edited]\n\njobs:\n  label:\n    runs-on: ubuntu‑latest\n    steps:\n      - uses: actions/checkout@v3\n      - name: Apply labels\n        uses: ./github-actions/nightly-pr-labeler\n        with:\n          github-token: ${{ secrets.GITHUB_TOKEN }}\n          label-mapping: '{"bug":"bug","feat":"feature","doc":"documentation"}'\n```\n\n## How it works\n\n1. The action reads the event payload from `GITHUB_EVENT_PATH` (provided by GitHub).\n2. It extracts the PR title.\n3. It iterates over the supplied mapping; for each keyword that appears in the title (case‑insensitive) the corresponding label is collected.\n4. If any labels are found, the action calls the GitHub REST API `POST /repos/{owner}/{repo}/issues/{issue_number}/labels` to apply them.\n\n## Development & Testing\n\nThe core label‑matching logic lives in `src/index.js` and is unit‑tested in `tests/test_index.js`. Run the tests locally with:\n\n```bash\nnode tests/test_index.js\n```\n\n## License\n\nMIT
