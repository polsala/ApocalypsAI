# Nightly Greeting Action\n\nA whimsical GitHub Action that prints a friendly greeting based on the time of day. Useful for adding a touch of personality to CI runs.\n\n## Usage\n\n```yaml\nuses: owner/repo/path/to/nightly-greeting-action@v1\n```\n\nThe action runs a small bash script that determines the current hour (or uses `FIXED_HOUR` env for testing) and echoes a greeting.\n\n### Inputs\n\n*None* – the action does not require any inputs.\n\n### Environment variables\n\n- `FIXED_HOUR` (optional) – Override the hour (0‑23) for deterministic output, useful in tests.\n\n### Outputs\n\n*None* – the action simply prints the greeting to the log.\n
