# Nightly Chrono-Crystal Status Report

Generates a whimsical "Chrono-Crystal Status Report" based on the outcome of your GitHub Actions workflow, posting it directly to the workflow summary. This utility adds a touch of apocalyptic charm and cosmic insight to your CI/CD pipeline, turning mundane build statuses into prophetic omens.

## 🌌 How it Works

This GitHub Action takes the final status of a workflow (success, failure, cancelled, or any other state) and consults the mystical Chrono-Crystal. Based on its temporal readings, a unique, whimsical message is generated, complete with an appropriate emoji. This report is then added to your workflow's summary, providing an immediate, albeit fantastical, overview of your temporal alignment.

## ✨ Usage

To integrate the Chrono-Crystal into your workflow, add it as a final step, ideally after all other jobs have completed or in a dedicated reporting job.

```yaml
name: Chrono-Crystal Workflow

on: [push, pull_request]

jobs:
  build-and-test:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout code
        uses: actions/checkout@v4

      - name: Run simulated tests
        run: |
          echo "Running simulated tests..."
          # Simulate a random test outcome for demonstration
          if (( RANDOM % 2 == 0 )); then
            echo "Tests passed!"
            exit 0
          else
            echo "Tests failed!"
            exit 1
          fi
    # Ensure this job always runs, even if previous steps fail, to get the status
    # This is important if you want to report on the job's actual conclusion
    # rather than just the step's success.
    continue-on-error: true # So the reporting job can still run

  report-status:
    runs-on: ubuntu-latest
    needs: build-and-test # Depends on the build-and-test job
    if: always() # Always run this job to report status
    steps:
      - name: Generate Chrono-Crystal Report
        uses: polsala/ApocalypsAI/utils/github-actions/nightly-chrono-crystal-report@main # Replace 'main' with your branch/tag
        with:
          status: ${{ needs.build-and-test.result }} # Pass the result of the previous job
          repo-token: ${{ secrets.GITHUB_TOKEN }}
```

### Inputs

- `status`: **(Required)** The overall status of the workflow or a specific job (e.g., `success`, `failure`, `cancelled`, `skipped`, `neutral`). This value is typically obtained from GitHub Contexts like `${{ job.status }}` or `${{ needs.<job_id>.result }}`.
- `repo-token`: **(Required)** A GitHub token with permissions to write workflow summaries. `${{ secrets.GITHUB_TOKEN }}` is usually sufficient.

### Outputs

- `report-message`: The full whimsical status report message generated by the Chrono-Crystal.

## 🧪 Development & Testing

The action is written in JavaScript and uses `jest` for testing.

To run tests locally:

1. Navigate to the `utils/github-actions/nightly-chrono-crystal-report` directory.
2. Install dependencies: `npm install`
3. Run tests: `npm test`

Tests are designed to be deterministic and offline, mocking the `@actions/core` library and `Math.random` to ensure consistent output.
