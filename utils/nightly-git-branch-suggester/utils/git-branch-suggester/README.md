# Git Branch Suggester

A tiny, zero‑dependency utility that turns a human‑readable title (e.g. a GitHub issue title) into a tidy kebab‑case branch name.

## Features

- Normalises any Unicode string to lower‑case kebab case.
- Optionally prepends a custom prefix (e.g. `feature`, `bugfix`).
- Optionally inserts a ticket/issue identifier (e.g. `#123`).
- Fully deterministic and offline – perfect for CI scripts.

## Installation

Copy the `src/` folder into your project or install it as a module:

```bash
python -m pip install .
```

(Only the `src/` directory is needed; there are no external dependencies.)

## Usage

```bash
python -m git_branch_suggester \
    --title "Add support for user avatars" \
    --prefix feature \
    --ticket 42
```

Output:

```
feature-42-add-support-for-user-avatars
```

All arguments are optional; the minimal call is:

```bash
python -m git_branch_suggester --title "Fix typo"
```

which yields:

```
fix-typo
```

## API

```python
from git_branch_suggester import generate_branch

branch = generate_branch(
    title="Add login page",
    prefix="feature",
    ticket="123"
)
# -> "feature-123-add-login-page"
```
