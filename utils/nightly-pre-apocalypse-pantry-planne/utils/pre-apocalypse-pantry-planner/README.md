# Pre-Apocalypse Pantry Planner

## Overview
Prepare for the inevitable (or just a long power outage!) with the `Pre-Apocalypse Pantry Planner`. This utility helps you calculate the essential supplies you'll need to stock up on, based on the number of people in your group and the duration you need to be self-sufficient. It provides a basic estimate for water, non-perishable food, first-aid, and batteries.

## Features
- Calculates water, food, first-aid kits, batteries, and flashlights.
- Customizable for different numbers of people and durations.
- Simple command-line interface.

## How to Use
1.  Navigate to the `utils/pre-apocalypse-pantry-planner/src` directory.
2.  Run the `pantry_planner.py` script from your terminal.
3.  Follow the prompts to enter the number of people and the duration in days.

```bash
python3 src/pantry_planner.py
```
