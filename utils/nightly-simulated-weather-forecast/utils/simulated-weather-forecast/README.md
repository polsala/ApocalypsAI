# Simulated Weather Forecast

A **stand‑alone utility** that produces a deterministic, whimsical weather forecast for any location and ISO‑format date.

## Features
- No external API calls – completely offline.
- Deterministic output: the same `(location, date)` pair always yields the same forecast.
- Tiny footprint – pure Python 3.11, only the standard library.

## Installation & Usage
```bash
# Clone the repository (or copy the folder) and run the module directly:
python -m utils.simulated-weather-forecast.src.forecast "New York" 2025-10-31
```

### Expected output
```
Weather forecast for New York on 2025-10-31: foggy
```

## How it works
1. Concatenates `location` and `date`.
2. Computes a SHA‑256 hash of the string.
3. Maps the hash to one of ten whimsical weather conditions.

The mapping is deterministic, so the same inputs always give the same result.
