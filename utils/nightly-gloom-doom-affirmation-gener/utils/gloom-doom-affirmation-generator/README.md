# Gloom & Doom Daily Affirmation Generator

## Overview

In the grim darkness of the far future (or present, depending on your perspective), a little morale boost can go a long way. The `gloom-doom-affirmation-generator` is a whimsical CLI utility designed to provide daily, slightly sarcastic, yet ultimately uplifting affirmations. Because even when the world is ending, you deserve a moment of self-care and a chuckle.

## Features

*   **Offline Operation**: No internet required, perfect for post-apocalyptic scenarios.
*   **Whimsical Affirmations**: A curated list of affirmations tailored for the discerning survivor.
*   **Simple CLI**: Easy to run and integrate into your daily routine (or survival script).

## How to Use

1.  Navigate to the `src` directory:
    ```bash
    cd utils/gloom-doom-affirmation-generator/src
    ```
2.  Run the generator:
    ```bash
    python generator.py
    ```

### Example Output

```
✨ Your daily dose of existential dread, served with a side of hope:
"Even if the world ends, your coffee machine might still work. Keep hope alive!"
```

## Development

### Running Tests

To ensure the generator is functioning correctly, run the tests from the `tests` directory:

```bash
cd utils/gloom-doom-affirmation-generator/tests
python -m unittest test_generator.py
```
