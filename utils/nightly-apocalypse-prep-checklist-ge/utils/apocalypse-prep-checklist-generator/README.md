# Apocalypse Prep Checklist Generator

Prepare for the inevitable with a touch of whimsy! This utility generates a personalized preparedness checklist based on various doomsday scenarios, from the mundane to the utterly fantastical. Whether you're bracing for a zombie horde or an AI uprising, we've got you covered (mostly).

## Usage

Run the Python script with your chosen apocalypse scenario.

```bash
python src/checklist_generator.py "zombie_outbreak"
```

### Examples

```bash
# For a classic zombie apocalypse
python src/checklist_generator.py "zombie_outbreak"

# When the machines rise
python src/checklist_generator.py "ai_uprising"

# If the sun decides to get spicy
python src/checklist_generator.py "solar_flare"

# For any other unspecified global catastrophe
python src/checklist_generator.py "general_catastrophe"
```

## Scenarios

Currently supported scenarios:
*   `zombie_outbreak`
*   `ai_uprising`
*   `solar_flare`
*   `general_catastrophe` (default if no specific scenario is recognized)

Feel free to expand the `checklist_generator.py` to include your own unique doomsday visions!
