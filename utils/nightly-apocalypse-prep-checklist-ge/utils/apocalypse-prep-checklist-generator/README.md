# Apocalypse Prep Checklist Generator

## Overview

Prepare for the inevitable with the `apocalypse-prep-checklist-generator`! This utility provides a whimsical yet surprisingly practical checklist tailored to various doomsday scenarios. Whether you're bracing for a zombie horde, an AI uprising, or something even more outlandish, this tool helps you organize your survival strategy.

## Usage

Run the script from the `src/` directory, specifying your desired apocalypse scenario. If no scenario is provided, it will list available scenarios.

```bash
python3 src/checklist_generator.py --scenario "Zombie Outbreak"
```

### Available Scenarios:

*   `Zombie Outbreak`
*   `Rogue AI Uprising`
*   `Solar Flare Cataclysm`
*   `Giant Hamster Invasion`

## Example Output (for 'Zombie Outbreak')

```
--- Apocalypse Prep Checklist: Zombie Outbreak ---

General Preparedness:
-   ✅ 5-gallon water supply per person
-   ✅ 2 weeks of non-perishable food
-   ✅ Comprehensive first-aid kit
-   ✅ Hand-crank radio/flashlight
-   ✅ Emergency shelter plan (local safe zones)

Scenario-Specific Preparedness (Zombie Outbreak):
-   ✅ Durable melee weapon (crowbar, machete)
-   ✅ Secure perimeter plan (board up windows, reinforce doors)
-   ✅ 'Headshot Training Manual' (for target practice)
-   ✅ Quiet footwear for stealth
-   ✅ Emergency escape route (multiple options)

Stay vigilant, survivor!
```
