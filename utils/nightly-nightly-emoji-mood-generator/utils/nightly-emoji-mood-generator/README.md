# Nightly Emoji Mood Generator

## Overview
`emoji-mood` is a whimsical‑yet‑useful utility that turns any input string (commonly a date) into a deterministic emoji representing a “mood”. It uses a SHA‑256 hash to ensure the same input always yields the same emoji, while different inputs produce varied results.

## Features
- **Zero dependencies** – pure Python 3.11 standard library.
- **Deterministic** – the same string always maps to the same emoji.
- **CLI friendly** – run it from the command line or import it as a module.
- **Self‑contained** – includes a tiny test suite.

## Installation
Copy the `utils/nightly-emoji-mood-generator` folder into your repository and run the script directly with Python:
```bash
python -m utils.nightly-emoji-mood-generator.src.emoji_mood "2025-01-01"
```
