# Commit Message Linter

A lightweight, zero‑dependency Python utility that checks whether a Git commit message follows the **Conventional Commits** style.

## Features

- Validates the header length (max 72 characters).
- Ensures the header matches the `<type>(<scope>): <description>` pattern.
- Checks that the type is one of the allowed Conventional Commit types.
- Provides a simple CLI for quick local use.

## Installation

```bash
# Clone the repository (or copy the folder) and install the utility locally
python -m pip install -e utils/commit-message-linter
```

## Usage

```bash
# Lint a single commit message
python -m commit_message_linter "feat(parser): add support for YAML"
```

The command prints any linting issues; an empty output means the message is valid.

## Development

Run the test suite with:

```bash
python -m unittest discover -s utils/commit-message-linter/tests
```
