# Emoji ID Generator

A tiny, self‑contained utility that creates short identifiers made of random emojis.

## Features
- Deterministic output when a seed is supplied.
- Simple CLI (`python -m emoji_id generate`).
- Pure Python 3.11, no external dependencies.

## Installation
Just copy the `utils/emoji-id-generator` folder into your project and run it with Python 3.11.

## Usage
```bash
# Generate a 4‑emoji identifier (default length)
python -m emoji_id generate

# Generate a 3‑emoji identifier with a reproducible seed
python -m emoji_id generate --length 3 --seed 42
```

## API
```python
from emoji_id import generate_id

# Returns a string of emojis, e.g. "🐱🚀🌟"
identifier = generate_id(length=4, seed=None)
```

- `length` (int): Number of emojis (must be > 0). Default is 4.
- `seed` (int | None): Optional random seed for reproducible results.
