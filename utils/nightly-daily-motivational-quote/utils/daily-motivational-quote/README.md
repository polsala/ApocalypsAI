# Daily Motivational Quote

Utility that prints a random motivational quote from a curated list. Useful for terminal startup messages, scripts, or as a light‑hearted break.

## Installation

Copy the folder into `utils/daily-motivational-quote` and run:

```bash
python -m utils.daily-motivational-quote.src.quote
```

or import `get_random_quote` in your code.

## Usage

```bash
$ python -m utils.daily-motivational-quote.src.quote
"Believe you can and you're halfway there." – Theodore Roosevelt
```

## Testing

Run tests with:

```bash
python -m unittest discover -s utils/daily-motivational-quote/tests
```
