# Daily Zen Quote Fetcher

A whimsical yet useful utility that prints a deterministic "zen" quote for the current day.

## Features
- **Zero network** – quotes are stored locally in `data/quotes.json`.
- **Deterministic** – the same date always yields the same quote.
- **CLI friendly** – run `python -m daily_zen_quote_fetcher` to get today’s wisdom.
- **Tested** – includes offline unit tests with mocked dates.

## Installation
```bash
# From the repository root
cd utils/daily-zen-quote-fetcher
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt  # (none required beyond stdlib)
```

## Usage
```bash
python -m src.quote_fetcher
# or
python -m src.quote_fetcher --date 2025-01-01  # for a specific date
```

## How it works
The utility loads a small list of quotes from `data/quotes.json`. It then hashes the ISO‑formatted date (defaulting to today) and selects a quote by taking the modulo of the hash with the number of available quotes. This guarantees the same quote for a given date without any external dependencies.
