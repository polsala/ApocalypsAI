# Nightly Doom Scroll Digest

## Overview
The `Nightly Doom Scroll Digest` is a whimsical yet practical utility designed to help you keep track of changes within a specified directory. Each night (or on demand), it scans the target directory, compares its current state to a previously recorded state, and generates a markdown report detailing new, modified, and deleted files. Think of it as your daily 'what's new' report for your project's files, ensuring no change goes unnoticed in the face of impending digital entropy.

## Features
- Scans a target directory recursively.
- Detects new files, modified files (based on modification time and size), and deleted files.
- Generates a clear, human-readable markdown report.
- Stores the directory state in a hidden JSON file for subsequent comparisons.

## Usage

### Prerequisites
- Python 3.8+

### Installation
This utility is self-contained. Simply place the `nightly-doom-scroll-digest` folder within your `utils/` directory.

### Running the Digest Generator
To run the utility, execute the `digest_generator.py` script with the target directory as an argument:

```bash
python3 src/digest_generator.py --path /path/to/your/project --output-file /path/to/output/digest.md
```

**Arguments:**
- `--path <directory>`: The root directory to scan for changes. (Required)
- `--output-file <file.md>`: The path where the markdown digest report will be saved. (Required)
- `--state-file <file.json>`: (Optional) The path to store/load the previous state. Defaults to `.doom_scroll_state.json` in the `--path` directory.

### Example
Let's say you want to track changes in your `my_project` directory and save the report to `reports/daily_digest.md`:

```bash
python3 utils/nightly-doom-scroll-digest/src/digest_generator.py \
  --path /home/user/my_project \
  --output-file /home/user/reports/daily_digest.md
```
