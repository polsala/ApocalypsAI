# nightly‑rot13‑encoder

A whimsical yet useful utility that applies the ROT13 cipher to any text.

## What is ROT13?
ROT13 is a simple letter substitution cipher that rotates each alphabetic character by 13 places. Because the Latin alphabet has 26 letters, applying ROT13 twice returns the original text, making it a reversible transformation.

## Features
- **CLI**: Encode/decode strings directly from the command line.
- **Library**: Import `rot13` function in your own Python code.
- **Zero external dependencies** – pure Python 3.11.

## Installation
Copy the `utils/nightly-rot13-encoder` folder into your repository and run the tests to ensure everything works:
```bash
python -m unittest discover utils/nightly-rot13-encoder/tests
```

## Usage
### As a script
```bash
python utils/nightly-rot13-encoder/src/rot13.py "Hello, World!"
# => Uryyb, Jbeyq!
```
If you omit the argument, the script reads from **stdin**:
```bash
echo "Secret Message" | python utils/nightly-rot13-encoder/src/rot13.py
```
### As a library
```python
from utils.nightly-rot13-encoder.src.rot13 import rot13
print(rot13("ApocalypsAI"))  # => NcbpnylcFNV
```
