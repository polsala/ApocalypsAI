# Nightly Zen Quote Dispenser

A tiny, self‑contained Python utility that prints a random Zen‑style quote.

## Usage
```bash
python -m nightly_zen_quote_dispenser
```

The script selects a quote from an internal list and prints it to stdout. No network access required.

## Why?
* **Whimsical morale boost** – a quick line of wisdom during CI runs.
* **Zero dependencies** – pure Python 3.11 standard library.
* **Fully tested** – deterministic unit tests using mocks.
