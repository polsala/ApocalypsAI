# Daily Survival Skill Suggester

A whimsical utility designed to inspire preparedness and personal growth by suggesting a random, practical survival skill to learn or practice each day. Each suggestion comes with a brief description and a note on why it matters.

## Purpose

In a world of uncertainties, being prepared isn't just practical – it's empowering. This tool aims to make learning essential survival skills fun and accessible, one small step at a time. Whether you're a seasoned prepper or just curious, there's always something new to master.

## How to Use

1.  Navigate to the `src` directory:
    ```bash
    cd utils/daily-survival-skill-suggester/src
    ```
2.  Run the Python script:
    ```bash
    python skill_suggester.py
    ```

## Example Output

```
--- Your Daily Survival Skill ---

Skill: Fire Starting (with Ferro Rod)
Description: Practice igniting tinder using a ferrocerium rod, a reliable method even in wet conditions.
Why it matters: Fire provides warmth, cooks food, purifies water, and offers psychological comfort.

---------------------------------
```
