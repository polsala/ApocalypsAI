# Cosmic Lint Roller

A whimsical utility to help keep your project's configuration files tidy and free of "cosmic dust." This initial version focuses on streamlining your `.gitignore` file.

## Features

-   **Deduplication**: Removes identical entries from your `.gitignore`.
-   **Sorting**: Organizes your `.gitignore` entries alphabetically for better readability and maintainability.
-   **Report Generation**: Provides a clear report of suggested changes without modifying your files directly.

## Usage

To analyze your `.gitignore` file and see suggested improvements:

```bash
python src/lint_roller.py --file .gitignore
```

The utility will print a summary of changes and the suggested new content for your `.gitignore`. You can then manually apply these changes if you wish.
