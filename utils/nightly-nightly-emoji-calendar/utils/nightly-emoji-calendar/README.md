# Nightly Emoji Calendar

Utility that prints a month calendar where each day is represented by an emoji: 🌞 for weekends (Saturday, Sunday) and 🌜 for weekdays (Monday‑Friday). Useful for a quick visual schedule in terminals or chat.

## Usage
```bash
python -m src.calendar <year> <month>
```
Will output the calendar to stdout.

## Example
```text
2023-10
Mon Tue Wed Thu Fri Sat Sun
 🌜  🌜  🌜  🌜  🌜  🌞  🌞
 🌜  🌜  🌜  🌜  🌜  🌞  🌞
 ...
```
