# Nightly Emoji Mood Tracker

## Overview

`emoji-mood-tracker` is a **stand‑alone** Python 3.11 utility that converts a date into a single emoji that reflects the "mood" of that day. The mapping is **deterministic** and **offline** – it uses a simple hash of the ISO‑formatted date to pick an emoji from a curated list.

## Why?

- Add a fun, visual cue to daily logs or commit messages.
- No external APIs – works in air‑gapped environments.
- Fully tested with deterministic mocks.

## Usage

```bash
python -m utils.nightly-emoji-mood-tracker.src.mood [YYYY-MM-DD]
```

If no date is supplied, the utility uses the current system date.

## Example

```bash
$ python -m utils.nightly-emoji-mood-tracker.src.mood 2025-11-21
🤖
```
