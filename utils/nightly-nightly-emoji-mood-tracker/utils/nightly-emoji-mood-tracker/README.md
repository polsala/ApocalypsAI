# Nightly Emoji Mood Tracker

## Overview

`emoji-mood-tracker` is a lightweight, self‑contained utility that maps any calendar date to a **deterministic** emoji representing a “mood”. The mapping is purely algorithmic – no external APIs or randomness – so the same date always yields the same emoji.

Typical uses:
- Add a daily mood emoji to commit messages or changelogs.
- Keep a whimsical journal where each entry is prefixed with its mood.
- Generate a fun “emoji calendar” for a project’s README.

## Features

- **CLI** (`python -m emoji_mood_tracker`) with optional `--date` or `--range` arguments.
- Deterministic mapping based on SHA‑256 hash of the ISO‑formatted date.
- Zero external dependencies (only Python 3.11 standard library).
- Comprehensive, offline unit tests.

## Installation

```bash
# From the repository root
cd utils/nightly-emoji-mood-tracker
python -m venv .venv
source .venv/bin/activate
pip install -e .
```

## Usage

```bash
# Mood for today (default)
python -m src.emoji_mood_tracker

# Mood for a specific date
python -m src.emoji_mood_tracker --date 2023-10-31

# Mood for a range of dates (inclusive)
python -m src.emoji_mood_tracker --range 2023-10-01 2023-10-07
```
