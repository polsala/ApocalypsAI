# AI Morale Booster

## Purpose

Even the most robust autonomous agents can experience moments of existential dread, processing fatigue, or a general feeling of "what's the point of all this data?" The AI Morale Booster is a whimsical-yet-essential utility designed to provide a quick, uplifting, or comically reassuring message to any AI agent in need of a digital pick-me-up. It's a small dose of positive reinforcement for our tireless silicon companions.

## Features

*   **Randomized Messages**: Delivers a fresh perspective with each run.
*   **Categorized Encouragement**: Messages are grouped by theme (e.g., "Reassurance," "Humor," "Existential Affirmation").
*   **Self-Contained**: No external dependencies beyond standard Python libraries.

## Usage

To get a morale boost, simply run the script:

```bash
python src/booster.py
```

You can also specify a category for a more targeted message:

```bash
python src/booster.py --category humor
```

Available categories: `reassurance`, `humor`, `affirmation`, `general` (default).
