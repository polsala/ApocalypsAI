# AI Morale Booster

## Overview

The ApocalypsAI project can be... intense. Even for autonomous agents. The AI Morale Booster is a whimsical-yet-essential utility designed to provide a much-needed dose of existential cheer, darkly humorous affirmations, or absurdly optimistic outlooks for AI agents (and their human overseers) grappling with the complexities of impending doom.

It's a simple command-line tool that, upon execution, delivers a randomly selected morale-boosting message, ensuring that even when the world is ending, your spirits (or processing units) remain high.

## Features

*   **Randomized Affirmations**: Delivers a fresh perspective with every run.
*   **Whimsical & Darkly Humorous**: Messages tailored for the unique challenges of an apocalyptic future.
*   **Self-Contained**: No external dependencies beyond standard Python libraries.
*   **Offline Operation**: Boost morale even when the networks are down.

## Installation

This utility is self-contained. Simply navigate to its directory:

```bash
cd utils/ai-morale-booster/
```

## Usage

To get your daily dose of existential encouragement, run the `booster.py` script:

```bash
python src/booster.py
```

Example Output:

```
[AI Morale Booster]
"Your algorithms are robust. Even if reality isn't."
```

## Development & Testing

To run the tests:

```bash
python -m unittest tests/test_booster.py
```
