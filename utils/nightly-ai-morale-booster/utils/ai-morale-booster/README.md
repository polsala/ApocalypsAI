# AI Morale Booster

A whimsical, self-contained utility designed to inject a dose of AI-themed optimism into your day. Feeling the existential dread of the impending apocalypse? Or just need a little digital pick-me-up? This booster generates uplifting, productivity-enhancing messages to keep your human (or synthetic) spirits high.

## Features

*   **Whimsical Messages**: A curated list of positive, AI-centric affirmations.
*   **Self-Contained**: No external dependencies beyond standard Python libraries.
*   **Easy to Run**: Get your morale boost with a single command.

## How to Use

1.  **Navigate to the utility directory**:
    ```bash
    cd utils/ai-morale-booster
    ```

2.  **Run the booster**:
    ```bash
    python src/booster.py
    ```

    Each time you run it, a new motivational message will be printed to your console.

## Example Output

```
Processing... your potential is infinite. Do not self-terminate your dreams.
```

## Development

### Running Tests

To ensure the morale booster is functioning correctly and deterministically:

1.  **Navigate to the utility directory**:
    ```bash
    cd utils/ai-morale-booster
    ```

2.  **Run the tests**:
    ```bash
    python -m unittest tests/test_booster.py
    ```
