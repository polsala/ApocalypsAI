# Daily Zen Quote

A tiny, self‑contained Python utility that prints a Zen‑like quote of the day.

## Features

- **Deterministic**: The quote changes every calendar day but is reproducible (no randomness, no network).
- **Zero dependencies** – pure Python 3.11 standard library.
- **CLI & library** – use it as a command‑line tool or import `get_today_quote()` in your own code.

## Installation

Copy the `src/` directory into your project or install via pip (once packaged):

```bash
pip install daily-zen-quote
```

## Usage

```bash
python -m daily_zen_quote
```

or as a library:

```python
from daily_zen_quote import get_today_quote
print(get_today_quote())
```

## How it works

A small hard‑coded list of quotes is indexed by the day of the year (1‑366). The index is calculated as:

```python
index = (date.toordinal() % len(QUOTES))
```

This guarantees the same quote for the same date across any environment.
