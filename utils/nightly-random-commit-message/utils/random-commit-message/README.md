# Random Commit Message

A whimsical utility that generates a random, git‑ready commit message. Perfect for practice commits, demos, or adding a splash of fun to your workflow.

## Usage

```bash
python -m random_commit_message
# or
python utils/random-commit-message/src/main.py
```

Outputs something like:

```
✨ Refactor mysterious widget
```

## How it works

Selects an emoji, an adjective, a verb, and a noun from short curated lists and joins them.

## Testing

Run `pytest` in the utility folder.
