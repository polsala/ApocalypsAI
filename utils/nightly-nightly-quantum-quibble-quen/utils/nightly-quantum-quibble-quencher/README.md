# Nightly Quantum Quibble Quencher

A whimsical yet practical command-line utility designed to swiftly resolve minor disagreements, stalemates, or indecisions within your post-apocalyptic team. When consensus is elusive, let the Quantum Quibble Quencher provide a fair, randomized, and unbiased resolution.

## Features

*   **Coin Flip**: For binary decisions.
*   **Rock-Paper-Scissors**: A classic for quick, two-person disputes.
*   **Random Choice**: Pick one from a list of user-defined options.

## Installation

This utility is self-contained and requires no special installation beyond having Python 3.x available. Simply place the `quibble_quencher.py` file in a directory accessible by your system's PATH, or run it directly.

## Usage

Run the script from your terminal:

### Coin Flip

For a simple "yes" or "no" decision:

```bash
python src/quibble_quencher.py coin
```

Example output:
```
Quibble Quenched! Result: Heads
```

### Rock-Paper-Scissors

To resolve a two-party dispute with a classic game:

```bash
python src/quibble_quencher.py rps
```

Example output:
```
Quibble Quenched! Result: Rock
```

### Random Choice

When you have multiple options and need a neutral party to pick one:

```bash
python src/quibble_quencher.py choose "Repair the generator" "Scavenge for food" "Fortify the perimeter"
```

Example output:
```
Quibble Quenched! Result: Scavenge for food
```

You can provide any number of options, each enclosed in double quotes if they contain spaces.

## Why use the Quibble Quencher?

In high-stress environments, minor disagreements can escalate. The Quantum Quibble Quencher provides a lighthearted, yet effective, mechanism to:
*   **Break stalemates**: When no one can agree.
*   **Save time**: Avoid lengthy debates over trivial matters.
*   **Maintain morale**: Introduce an element of fun and fairness, reducing personal friction.
*   **Promote decisive action**: Get to a resolution quickly so you can focus on survival.
