# Random Emoji Commit Generator

Ever felt your commit history could use a little sparkle?  
`random-emoji-commit-generator` takes a plain commit message and sprinkles a handful of emojis into it – all while preserving the original wording.

## Features
- **Deterministic**: Provide a `seed` to get reproducible emoji placement (useful for testing).
- **Configurable**: Choose how many emojis to insert (default: 2).
- **Zero external dependencies** – pure Python 3.11 standard library.

## Installation
```bash
# Clone the repo and install the utility (no extra deps needed)
python -m venv .venv && source .venv/bin/activate
pip install -e utils/random-emoji-commit-generator
```

## Usage
```python
from random_emoji_commit_generator.src.generator import generate_commit_message

msg = "Fix bug in user authentication"
new_msg = generate_commit_message(msg, count=3, seed=42)
print(new_msg)
# Example output: "Fix 🦄 bug 🐍 in user authentication 🚀"
```
