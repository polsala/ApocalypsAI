# Nightly Zen Quote Generator

`nightly-zen-quote-generator` is a tiny, self‑contained Python utility that prints a random Zen‑style quote to stdout.

## Features

- **Zero dependencies** – pure Python 3.11 standard library.
- **Deterministic mode** – pass `--seed <int>` to get reproducible output (useful for testing or CI).
- **Extensible** – the quote list lives in a single module; add your own!

## Usage

```bash
python -m nightly_zen_quote_generator
# or with a seed for reproducible output
python -m nightly_zen_quote_generator --seed 42
```

## Development
