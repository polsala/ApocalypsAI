# Nightly Zen Quote Generator

A whimsical yet useful utility that prints a random zen-inspired quote to the console.

## Features
- Curated list of calming, thought‑provoking quotes.
- Simple CLI: `python -m src.quote` prints a quote.
- Deterministic unit tests using mocks.

## Usage
```bash
cd utils/nightly-zen-quote-generator
python -m src.quote
```

## Development
Run tests with:
```bash
python -m unittest discover -s tests
```
