# Whispers of the Void: Daily Affirmations for the End Times

## Overview

In the grim darkness of the far future (or perhaps just tomorrow), a little bit of self-care goes a long way. `Whispers of the Void` is a whimsical command-line utility designed to provide you with a daily dose of darkly humorous or ironically positive affirmations, perfectly suited for navigating the various stages of the apocalypse. Whether it's a zombie horde, an AI uprising, or just another Tuesday, these affirmations will help you maintain your sanity... or at least a good laugh.

## Features

*   Generates unique, context-aware affirmations.
*   Lightweight and self-contained.
*   Perfect for boosting morale when the world is literally falling apart.

## Usage

1.  Navigate to the `src` directory:
    ```bash
    cd utils/whispers-of-the-void-affirmations/src
    ```
2.  Run the script:
    ```bash
    python affirmations.py
    ```

## Examples

```
$ python affirmations.py
"Today, I will find joy in the small things, like not being eaten by a rogue AI."

$ python affirmations.py
"My resilience is stronger than any mutant fungus. Probably."

$ python affirmations.py
"I am a beacon of hope, even if that hope is just finding an un-looted can of beans."
```
