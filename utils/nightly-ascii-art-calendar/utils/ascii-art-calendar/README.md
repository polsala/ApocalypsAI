# ASCII Art Calendar

A whimsical utility that prints a month calendar with emojis for weekends:
- Saturdays get a ☀
- Sundays get a 🌙

## Usage

```sh
python -m src.calendar <year> <month>
```

Example:

```sh
python -m src.calendar 2023 3
```

Will output a nicely formatted calendar for March 2023.

## Installation

Just run the script with Python 3.11; no external dependencies.
