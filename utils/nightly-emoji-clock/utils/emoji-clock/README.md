# Emoji Clock Utility

A tiny, self‑contained Python utility that translates a specific time into the closest clock‑face emoji. Perfect for adding a visual touch to chat messages, commit logs, or any text where a quick time reference is helpful.

## Features
- Supports full hour and half‑hour emojis (🕐, 🕜, …).
- CLI for quick command‑line usage.
- Pure Python 3.11 standard library – no external dependencies.

## Installation
```bash
# Clone the repository (or copy this folder) and install the utility in a venv
python -m venv .venv
source .venv/bin/activate
pip install -e utils/emoji-clock
```

## Usage
```bash
python -m utils.emoji-clock.src.emoji_clock --hour 14 --minute 20
# → 🕑
```

The utility rounds to the nearest hour or half‑hour. Minutes 0‑14 → hour, 15‑44 → half‑hour, 45‑59 → next hour.

## API
```python
from utils.emoji-clock.src.emoji_clock import time_to_emoji

emoji = time_to_emoji(9, 30)  # returns "🕤"
```
