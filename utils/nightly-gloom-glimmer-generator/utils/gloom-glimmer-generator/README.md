# Gloom Glimmer Generator

## Purpose

In the darkest of times, even a tiny spark of hope can make a difference. The Gloom Glimmer Generator is a whimsical utility designed to provide a daily dose of morale-boosting "glimmers" – short, positive affirmations or micro-tasks – to help you navigate the post-apocalyptic landscape with a slightly lighter heart. Whether it's a reminder to appreciate a mutated daisy or a suggestion to organize your scavenged bottle caps, these glimmers aim to keep the gloom at bay.

## How to Run

1.  Navigate to the `utils/gloom-glimmer-generator/` directory.
2.  Run the Python script:
    ```bash
    python src/glimmer_generator.py
    ```

## Example Output

```
✨ Your daily glimmer: Remember to appreciate the resilience of that mutated daisy. ✨
```
