# Daily Cryptic Puzzle Generator

A tiny utility that prints a random cryptic‑style clue and its answer. Useful for a quick brain teaser in terminals or chat.

## Usage

```bash
python -m utils.daily-cryptic-puzzle-generator.src.puzzle
```

Will output something like:

```
Clue: Day star (3)
Answer: SUN
```

## How it works

Selects a random clue‑answer pair from a built‑in list.

## Testing

Run `pytest` in the utility folder.
