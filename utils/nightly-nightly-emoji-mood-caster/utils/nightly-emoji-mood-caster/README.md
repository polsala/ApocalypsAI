# Nightly Emoji Mood Caster

`nightly-emoji-mood-caster` is a whimsical‑yet‑useful utility that scans a short piece of text and returns a single emoji representing the overall mood.

## Features
- Pure Python, no external services.
- Simple keyword‑based heuristics (happy, sad, angry, love, surprise, neutral).
- CLI entry‑point for quick one‑liners.
- Fully tested with deterministic offline unit tests.

## Installation
```bash
# From the repository root
cd utils/nightly-emoji-mood-caster
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt  # (empty for now)
```

## Usage
```python
from src.mood_caster import get_mood_emoji

print(get_mood_emoji("I just finished the project, feeling great!"))
# → 😊
```

Or via the command line:
```bash
python -m src.mood_caster "I am so frustrated with bugs"
# 😠
```
