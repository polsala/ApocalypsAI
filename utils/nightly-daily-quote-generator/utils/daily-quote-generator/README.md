# Daily Quote Generator

A lightweight, self‑contained utility that prints a random whimsical quote each time it runs.  It can also filter quotes by category (e.g., *inspiration*, *humor*, *philosophy*).

## Features

- No external dependencies beyond the Python standard library.
- Deterministic behavior for testing via `random.seed`.
- Simple CLI:
  ```bash
  python -m src.quote_generator          # random quote
  python -m src.quote_generator --category humor
  ```
- Fully documented and covered by unit tests.

## Installation

The utility lives entirely under `utils/daily-quote-generator`.  To use it, ensure you have Python 3.11+ installed and run the module directly:

```bash
cd utils/daily-quote-generator
python -m src.quote_generator
```

## Development

Run the test suite with:

```bash
python -m unittest discover -s tests
```
