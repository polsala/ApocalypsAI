# Nightly Mutant Morale Booster

## Overview

In the grim darkness of the far future (or just, you know, tomorrow), maintaining high spirits is crucial for survival. The **Nightly Mutant Morale Booster** is a whimsical utility designed to provide a random, encouraging, and slightly apocalyptic-themed message to keep your resolve firm and your spirit uncrushed. Whether you're fending off irradiated squirrels or just facing another Monday, a little boost can go a long way.

## Usage

To get your daily dose of post-apocalyptic encouragement, simply run the Python script:

```bash
python src/booster.py
```

## Example Output

```
[2023-10-27 03:42:15] Remember, even a broken clock is right twice a day. You're better than a broken clock! Keep going!
```

```
[2023-10-27 03:42:16] Your resilience is stronger than a reinforced bunker door. Don't let the gloom get to you!
```

## Features

*   **Randomized Morale Boosts**: Delivers a unique message each time.
*   **Apocalyptic Charm**: Messages are tailored to the unique challenges of a world teetering on the brink.
*   **Simple & Self-Contained**: No external dependencies, just pure Pythonic encouragement.
