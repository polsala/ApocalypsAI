# Nightly Mutant Morale Booster

## Overview

Even in the darkest of post-apocalyptic days, a little morale boost can go a long way. The `Nightly Mutant Morale Booster` is a simple, standalone utility designed to provide a daily dose of whimsical, apocalypse-themed affirmations or survival tips. Run it whenever you need a moment of grim inspiration or a chuckle amidst the chaos.

## Features

*   **Thematic Quotes**: Delivers randomly selected quotes tailored for the discerning survivor.
*   **Self-Contained**: No external dependencies, just pure, unadulterated morale.
*   **Easy to Run**: A single Python script to brighten your wasteland wanderings.

## Usage

To get your daily morale boost, simply run the Python script:

```bash
python3 src/booster.py
```

### Example Output

```
✨ Mutant Morale Boost ✨

"Remember: every piece of scrap metal is a potential future fortress wall. Stay resourceful!"
```

## Development

### Running Tests

To ensure the morale booster is functioning correctly (and deterministically), navigate to the utility's root directory and run the tests:

```bash
python3 -m pytest tests/
```
