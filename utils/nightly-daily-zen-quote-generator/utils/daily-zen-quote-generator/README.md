# Daily Zen Quote Generator

A whimsical yet practical command‑line utility that prints a random Zen‑inspired quote each time you run it. You can optionally filter quotes by a tag (e.g., `mindfulness`, `humor`).

## Features
- Zero external dependencies – pure Python 3.11.
- Small curated list of Zen quotes with tags.
- Deterministic unit tests using mocks.

## Installation
```bash
# Clone the repository (if you haven't already)
git clone https://github.com/polsala/ApocalypsAI.git
cd ApocalypsAI
```
The utility lives under `utils/daily-zen-quote-generator`. No additional packages are required.

## Usage
```bash
python -m utils.daily-zen-quote-generator.src.quote_generator          # random quote
python -m utils.daily-zen-quote-generator.src.quote_generator --tag mindfulness  # filtered quote
```

## Development
Run the test suite with:
```bash
python -m unittest discover utils/daily-zen-quote-generator/tests
```
