# Daily Zen Quote Generator

`daily-zen-quote-generator` is a self‑contained Python 3.11 utility that prints a short, uplifting Zen quote that changes every day. The quote is selected deterministically from a static list based on the day‑of‑year, so the same date always yields the same quote without any external API calls.

## Features
- Zero runtime dependencies (only the Python standard library).
- Deterministic output – great for reproducible CI logs.
- Simple CLI: `python -m daily_zen_quote_generator` prints today’s quote.
- Easily importable: `from daily_zen_quote_generator import get_daily_zen`.

## Usage
```bash
# As a script
python -m daily_zen_quote_generator

# As a library
from daily_zen_quote_generator import get_daily_zen
print(get_daily_zen())
```

## Testing
Run the bundled tests with:
```bash
python -m unittest discover -s utils/daily-zen-quote-generator/tests
```
