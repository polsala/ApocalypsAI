# Daily Zen Quote Generator

A tiny Python utility that prints a deterministic "quote of the day" based on the current date. No network access required – quotes are bundled in the package.

## Features

- **Deterministic**: The same date always yields the same quote.
- **Offline**: All quotes are stored locally; works without internet.
- **CLI**: `python -m daily_zen_quote_generator` prints the quote.
- **Library**: `get_quote(date: datetime.date) -> str` can be imported.

## Usage

```bash
python -m daily_zen_quote_generator
```

Or in code:

```python
from daily_zen_quote_generator import get_quote
print(get_quote())
```

## Testing

Run the test suite with:

```bash
python -m unittest discover -s utils/daily-zen-quote-generator/tests
```
