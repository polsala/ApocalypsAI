# Daily Zen Quote Generator

A whimsical yet useful utility that prints a random Zen‑style quote each time you run it. No network access – all quotes are bundled with the package, making it fast, deterministic, and perfect for scripts, CI messages, or a daily splash screen.

## Features
- **Zero dependencies** – pure Python 3.11 standard library.
- Choose a **tag** (e.g., `mindfulness`, `humor`) to filter quotes.
- Simple CLI: `python -m src.zen_quote [--tag TAG]`.
- Comes with **offline deterministic tests** that mock randomness.

## Installation & Usage
```bash
# Clone the repository (or copy the utils folder) and run:
python -m utils.daily-zen-quote-generator.src.zen_quote
# With a tag:
python -m utils.daily-zen-quote-generator.src.zen_quote --tag humor
```

## Development
Run the test suite with:
```bash
python -m unittest discover -s utils/daily-zen-quote-generator/tests
```
