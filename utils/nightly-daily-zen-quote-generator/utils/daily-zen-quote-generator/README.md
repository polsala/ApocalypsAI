# Daily Zen Quote Generator

A tiny utility that prints a random zen quote to brighten your day (or calm your nerves during an apocalypse). It reads from a bundled list of quotes, selects one at random, and outputs it to stdout. The utility is self‑contained, requires only the Python standard library, and includes deterministic unit tests using mocks.

## Usage

```bash
python -m utils.daily-zen-quote-generator.src.zen
```

Will print a quote.
