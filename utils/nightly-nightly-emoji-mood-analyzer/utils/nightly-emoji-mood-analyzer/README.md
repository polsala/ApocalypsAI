# Nightly Emoji Mood Analyzer

A tiny, self‑contained utility that turns a string of text into an emoji reflecting its mood.

## Features
- **Zero dependencies** – pure Python 3.11 standard library.
- **Deterministic** – uses a static word list; no randomness or network calls.
- **CLI & library** – import `analyze_mood` in your code or run the script directly.

## Usage
```bash
python -m utils.nightly-emoji-mood-analyzer.src.mood_analyzer "I love sunny days!"
# Output: 😊
```

Or as a library:
```python
from utils.nightly-emoji-mood-analyzer.src.mood_analyzer import analyze_mood
print(analyze_mood("I am so frustrated"))  # 😠
```
