# Nightly Emoji Mood Analyzer

A whimsical‑yet‑useful utility that reads a piece of text and returns a single emoji representing the overall mood.

## Features
- **Zero external dependencies** – pure Python, works offline.
- **CLI** – `python -m nightly-emoji-mood-analyzer "I love this!"`
- **Python API** – `from nightly_emoji_mood_analyzer import get_mood_emoji`
- Simple keyword‑based heuristics (happy, sad, angry, surprised, neutral).

## Installation
```bash
# From the repository root
cd utils/nightly-emoji-mood-analyzer
python -m venv .venv
source .venv/bin/activate
pip install -e .
```

## Usage
```bash
# CLI
python -m nightly-emoji-mood-analyzer "I am thrilled about the new release!"
# => 😄
```

```python
# Python API
from nightly_emoji_mood_analyzer import get_mood_emoji
print(get_mood_emoji("Feeling a bit down today..."))  # => 😢
```
