# nightly-emoji-lookup

A whimsical‑yet‑useful command‑line tool that lets you look up emojis by keyword.

## Features
- **Offline** – ships with a curated emoji dictionary, no network calls.
- **Case‑insensitive** keyword search.
- Returns **all** matching emojis for a given term.
- Simple Python 3.11 implementation, no external dependencies.

## Installation
```bash
# From the repository root
cd utils/nightly-emoji-lookup
python -m venv .venv
source .venv/bin/activate
pip install -e .
```

## Usage
```bash
python -m src.emoji_lookup smile
# → 😄 😊 😁
```

You can also pipe a list of keywords:
```bash
echo "heart" | python -m src.emoji_lookup
# → ❤️ 💖 💘
```
