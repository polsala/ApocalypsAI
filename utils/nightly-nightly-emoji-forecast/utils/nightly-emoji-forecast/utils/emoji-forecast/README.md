# Emoji Forecast

A tiny utility that prints a whimsical weather forecast using emojis, derived deterministically from the current date. Perfect for adding a splash of fun to your terminal or CI logs.

## Usage

```sh
python -m emoji_forecast
```

or

```sh
python src/forecast.py
```

Outputs a single line like:

```
🌞☁️🌧️
```

## How it works

The forecast is generated by mapping the day of the year to a sequence of emojis from a predefined list. The algorithm is deterministic and requires no network access.

## Testing

Run the tests with:

```sh
python -m unittest discover -s tests
```
