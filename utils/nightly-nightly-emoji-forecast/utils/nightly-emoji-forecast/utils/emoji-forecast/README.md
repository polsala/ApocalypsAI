# Emoji Forecast Utility

**nightly-emoji-forecast**

A tiny, self‑contained Python utility that returns a deterministic "weather" emoji for a given day. The algorithm is deliberately simple and offline‑only, making the utility safe to run in any CI environment.

## How it works
- The utility defines a short list of weather‑themed emojis.
- It computes a deterministic index by summing the Unicode code points of the ISO‑8601 date string (`YYYY‑MM‑DD`) and taking the modulo of the list length.
- The same date always yields the same emoji, without any network calls or randomness.

## Usage
```bash
# Install (no external deps required, just Python 3.11+)
python -m venv .venv && source .venv/bin/activate && pip install -e .

# Run the script directly
python -m emoji_forecast.src.forecast
# => Today's forecast: 🌤️

# Or import in your own code
from emoji_forecast.src.forecast import get_daily_emoji_forecast
print(get_daily_emoji_forecast("2025-01-01"))  # 🌨️
```
