# Nightly Emoji Forecast

A tiny, self‑contained utility that produces a daily "weather" forecast expressed entirely in emojis. The forecast is deterministic – the same calendar date always yields the same emoji string – making it safe for offline testing and reproducible CI runs.

## Features
- No external network calls; all logic runs locally.
- Deterministic output based on the input date (seeded by ISO‑format string).
- Simple CLI: `python -m forecast <YYYY‑MM‑DD>` prints the forecast.
- Easy to embed in CI logs, Slack messages, or any place you need a daily smile.

## Usage
```bash
# Install (no dependencies beyond the Python standard library)
python -m venv .venv && source .venv/bin/activate
pip install -e utils/nightly-emoji-forecast

# Get today's forecast
python -m forecast $(date +%F)

# Or import in your own script
from forecast import get_forecast
print(get_forecast(date.today()))
```

## Testing
