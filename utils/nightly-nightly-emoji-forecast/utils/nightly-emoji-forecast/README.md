# Nightly Emoji Forecast

A tiny, self‑contained Python utility that prints a deterministic, whimsical "weather" forecast made entirely of emojis.

## Features
- Deterministic output per calendar day (so the same date always yields the same forecast).
- Works offline – no external APIs.
- Simple CLI: `python -m forecast [--date YYYY-MM-DD]`
- Easy to embed in CI logs, commit messages, or Slack bots.

## Usage
```bash
# Forecast for today
python -m forecast

# Forecast for a specific date
python -m forecast --date 2025-12-25
```

## Example Output
```
🌤️ 2025-12-25: 🌈☔️⛈️
```

## Implementation Details
- The forecast is generated by seeding Python's `random` module with the ISO string of the target date.
- A small pool of weather‑related emojis is shuffled and the first three are joined.

## Testing
Run the bundled tests with:
```bash
python -m unittest discover -s utils/nightly-emoji-forecast/tests
```
